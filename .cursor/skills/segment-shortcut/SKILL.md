# Segment Shortcut

把已经读完的章节正文写成段落总结序列。

档由形容词定义，不随标签增减而改。标签是那些形容词的具体化，来自本文件目录；换载体时只改目录。本次不增标签。

## 档

- 第一档：不可取缔的，必需的，定义的
- 第二档：可替换的，旁证的
- 第三档：依附于某段的，过渡的，主旨无关的

## 标签目录

从下表取用。每项含：体现哪组形容词、含义、与其他标签的关系。

| 标签 | 档 | 含义 | 关系 |
|---|---|---|---|
| 陈述 | 第一档 | 直接说出本标题某条主旨 | 被限定、例外划界 |
| 必要依据 | 第一档 | 删掉则主旨缺机制或定义 | 与可替换例证互替：先出现的机制用本标签 |
| 限定 | 第一档 | 缩小主旨适用范围 | 划界→陈述 |
| 例外 | 第一档 | 通例在此处不适用 | 划界→陈述 |
| 可替换例证 | 第二档 | 支撑主旨，同标题还有同类例子 | 与必要依据互替：机制已有之后的作品、引文、场景用本标签 |
| 次要观点 | 第二档 | 不是本标题主旨，但能旁证主旨 | 旁证→陈述 |
| 续 | 第三档 | 跨页未完的引文、同一套曲辞的后续阕、接在「……」后的续抄 | 依附→起始段 |
| 过渡/场景 | 第三档 | 转场、纯景物，或与主旨无关 | — |

## 顺序

先通读全文，确定两件事：

1. **主旨**：当前原书小节标题下 1～3 条，每条一句话，依据该标题原文。若与章首核心论点不完全重合，在序列开头标明差异。
2. **最小标签集**：从目录中取出一组标签，恰好够概括本标题段落之间的关系。不得使用目录外的词。同义槽只留一个。

再按原文物理段顺序写成有序列 `1.` `2.` `3.`，条数等于物理段数。对每一段：先定档，再从最小标签集里分配一个标签。续段标「续 n」（n 为起始段号）。

## 关联与篇幅

每段至多 3 条出边，关系仅限：`证明→` `被证明←` `实例←` `例外于` `限定→` `续`。写在条目末尾括号内，如 `(证明→6,12)` `(续 8)`。

枢纽段：被至少两条指向，或第一档且指出至少两条。

- 第一档或枢纽段，写三块：功能一句；依据（并列的因分条）；在本标题主旨中的位置一句。
- 第二档：不超过三句。
- 第三档：一句；续段为「续 n：……」。

## 格式

```
3. 【第一档·必要依据】童心说把市民写实转成个性解放的创作标准。
   依据：……
   位置：本标题主旨「上层浪漫」的机制段。
   (证明→6,12,14)(被证明←2)
```

第一行含段号、档、标签、本段功能。括号只放关联。
