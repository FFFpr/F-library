# Segment Shortcut

把已经读完的章节正文写成段落总结序列。

档由形容词定义。标签只从本文件目录取用。本段的档，按该段所用标签的含义对照档的形容词判定。

## 档

- 第一档：不可取缔的，必需的，定义的
- 第二档：可替换的，旁证的
- 第三档：依附于某段的，过渡的，主旨无关的

## 标签目录

每项含含义与关系。含义写清该标签做什么，并含若干分档用的形容词，供对照定档。

| 标签 | 含义 | 关系 |
|---|---|---|
| 陈述 | 直接说出本标题某条主旨，给该条一个定义；没有这段则该条主旨缺命题，是必需的 | 被限定、例外划界 |
| 必要依据 | 给出主旨所依赖的机制或定义；删掉则主旨不能成立，是不可取缔的、必需的 | 与可替换例证互替：先出现的机制用本标签 |
| 限定 | 缩小并定义主旨的适用范围；没有这段则适用范围不清，对该边界是必需的 | 划界→陈述 |
| 例外 | 标明通例在此处不适用，从而定义主旨在此处的边界；这条划界是不可取缔的 | 划界→陈述 |
| 可替换例证 | 用作品、引文、场景旁证主旨；同标题还有同类例子，这段是可替换的 | 与必要依据互替：机制已有之后的作品、引文、场景用本标签 |
| 次要观点 | 所说不是本标题主旨，只作旁证；可替换 | 旁证→陈述 |
| 续 | 跨页未完的引文、同一套曲辞的后续阕、或接在「……」后的续抄；依附于起始段，不能单独成立 | 依附→起始段 |
| 过渡/场景 | 转场、纯景物，或与主旨无关的文字；是过渡的，依附于上下文 | — |

## 顺序

先通读全文，确定两件事：

1. **主旨**：当前原书小节标题下 1～3 条，每条一句话，依据该标题原文。若与章首核心论点不完全重合，在序列开头标明差异。
2. **最小标签集**：从目录取出一组标签，覆盖本标题段落之间实际出现的关系。每个段的标签必须来自这组。

再按原文物理段顺序写成有序列 `1.` `2.` `3.`，条数等于物理段数。对每一段：从最小标签集分配一个标签，再按该标签含义对照档的形容词定档。续段标「续 n」（n 为起始段号）。

## 关联

序列按原文物理段编号。括号只标论证关系，不标「下一段接着读」这种顺序。写在条目最后，数字是本序列的段号。没有论证关系就不写括号。关系只准用下面六种：

| 写法 | 含义 |
|---|---|
| `证明→n` | 本段给第 n 段提供理由或机制 |
| `被证明←n` | 第 n 段给本段提供理由或机制 |
| `实例←n` | 本段是第 n 段的例子 |
| `例外于 n` | 本段是第 n 段通例的例外 |
| `限定→n` | 本段缩小第 n 段的适用范围 |
| `续 n` | 本段接着第 n 段未写完的原文 |

本段主动指出的段（`证明→` `限定→` `例外于` `续`）合计不超过 3 个。`被证明←` `实例←` 是别人指向本段，不计入这 3 个。同一关系可并列段号，如 `(证明→6,12)` `(续 8)`。

## 篇幅

档决定这段写多长：主旨所必需的段写清机制和位置，可替换、依附的段压短，避免每段一样长。

- 第一档，或枢纽段：固定三块。第一行写这段干什么；`依据` 写原文里并列的因（多因分条）；`位置` 写它落在本标题哪条主旨、起什么作用。
- 第二档：整条不超过三句，不写 `依据` `位置`。
- 第三档：一句。续段写成 `续 n：……`。

枢纽段：被至少两条关联指向，或第一档且主动指出至少两段。枢纽只加长篇幅，不改标签、不改档。第二档若是枢纽，仍按三块写。

## 格式

```
3. 【第一档·必要依据】童心说把市民写实转成个性解放的创作标准。
   依据：……
   位置：本标题主旨「上层浪漫」的机制段。
   (证明→6,12,14)(被证明←2)
```

第一行含段号、档、标签、本段功能。括号只放关联。
