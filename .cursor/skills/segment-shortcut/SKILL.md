# Segment Shortcut

把已经读完的章节正文写成段落总结序列。按 1→7 做。

### 1. 本标题主旨

对当前原书小节标题写 1～3 条主旨，每条一句话，依据该标题下的原文。若与章首核心论点不完全重合，在序列开头标明差异。

### 2. 编号与续段

按原文物理段顺序写成有序列 `1.` `2.` `3.`，条数等于物理段数。

跨页未写完的引文、同一套曲辞的后续阕、接在「……」后的续抄，标为「续 n」（n 为起始段号），正文一句指回 n。

### 3. 每段一个标签

| 标签 | 何时用 |
|---|---|
| 陈述 | 直接说出本标题某条主旨 |
| 必要依据 | 删掉则主旨缺机制、定义或作者限定 |
| 可替换例证 | 支撑主旨，同标题还有同类例子 |
| 次要观点 | 不是本标题主旨，但能旁证主旨 |
| 限定 | 缩小主旨适用范围 |
| 例外 | 通例在此处不适用 |
| 续 | 第 2 步的续段 |
| 过渡/场景 | 转场、纯景物，或与主旨无上表关系 |

本段第一次给出定义、因果机制或作者自限 → 必要依据或限定。同标题已有更完整的机制段之后出现的作品、引文、场景 → 可替换例证。

### 4. 定档

- 第一档：陈述、必要依据、限定、例外
- 第二档：次要观点、可替换例证
- 第三档：续、过渡/场景

### 5. 关联

每段至多 3 条出边，关系仅限：`证明→` `被证明←` `实例←` `例外于` `限定→` `续`。写在条目末尾括号内，如 `(证明→6,12)` `(续 8)`。

枢纽段：被至少两条指向，或自身为陈述/必要依据且指出至少两条。

### 6. 篇幅

- 第一档或枢纽段，写三块：功能一句；依据（并列的因分条）；在本标题主旨中的位置一句。
- 第二档：不超过三句。
- 第三档：一句；续段为「续 n：……」。

### 7. 格式

```
3. 【第一档·必要依据】童心说把市民写实转成个性解放的创作标准。
   依据：……
   位置：本标题主旨「上层浪漫」的机制段。
   (证明→6,12,14)(被证明←2)
```

第一行含段号、档、标签、本段功能。括号只放关联。
