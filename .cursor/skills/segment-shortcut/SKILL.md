# Segment Shortcut

把已经读完的章节正文写成段落总结序列。

档由形容词定义。标签只从本文件目录取用。本段的档，按该段所用标签的含义对照档的形容词判定。

## 档

- 第一档：不可取缔的，必需的，定义的
- 第二档：可替换的，旁证的
- 第三档：依附于某段的，过渡的，主旨无关的

## 标签目录

每项含含义与关系。含义写清该标签做什么，并含若干分档用的形容词，供对照定档。

| 标签 | 含义 | 关系 |
|---|---|---|
| 陈述 | 直接说出本标题某条主旨，给该条一个定义；没有这段则该条主旨缺命题，是必需的 | 被限定、例外、必要依据、可替换例证、次要观点指向 |
| 必要依据 | 给出主旨所依赖的机制或定义；删掉则主旨不能成立，是不可取缔的、必需的 | 指向它所支撑的陈述。与可替换例证互替：先出现的机制用本标签 |
| 限定 | 缩小并定义主旨的适用范围；没有这段则适用范围不清，对该边界是必需的 | 指向被它划界的陈述 |
| 例外 | 标明通例在此处不适用，从而定义主旨在此处的边界；这条划界是不可取缔的 | 指向被它划界的陈述 |
| 可替换例证 | 用作品、引文、场景旁证主旨；同标题还有同类例子，这段是可替换的 | 指向它所旁证的陈述。与必要依据互替：机制已有之后的作品、引文、场景用本标签 |
| 次要观点 | 所说不是本标题主旨，只作旁证；可替换 | 指向它所旁证的陈述 |
| 续 | 跨页未完的引文、同一套曲辞的后续阕、或接在「……」后的续抄；依附于起始段，不能单独成立 | 指向起始段 |
| 过渡/场景 | 转场、纯景物，或与主旨无关的文字；是过渡的，依附于上下文 | — |

## 顺序

先通读全文，确定两件事：

1. **主旨**：当前原书小节标题下 1～3 条，每条一句话，依据该标题原文。若与章首核心论点不完全重合，在序列开头标明差异。
2. **最小标签集**：从目录取出一组标签，覆盖本标题段落之间实际出现的关系。每个段的标签必须来自这组。

再按原文物理段顺序写成有序列 `1.` `2.` `3.`，条数等于物理段数。对每一段：从最小标签集分配一个标签，再按该标签含义对照档的形容词定档。续段标「续 n」（n 为起始段号）。

## 关联

括号把本段接到本标题里与它有关的段，不标「下一段接着读」。

本段标签的关系列若写明指向哪类段，在条目最后写 `(本段标签 段号)`，段号是被接到的那段。多个段号并列，如 `(限定 5,14)` `(续 11)`。只写必要的关联。关系列未写指向的，不写括号。

## 篇幅

档决定这段写多长：第一档按原文结构提炼；可替换、依附的段压短，避免每段一样长。

- 第一档，或枢纽段：按该段原文的实际结构提炼内容。
- 第二档：整条不超过三句。
- 第三档：一句。续段写成 `续 n：……`。

枢纽段：被至少两条关联指向，或第一档且主动指出至少两段。枢纽只加长篇幅，不改标签、不改档。第二档若是枢纽，按第一档写。

## 格式

```
3. 【第一档·必要依据】童心说把市民写实转成个性解放的创作标准。
   依据：……
   位置：本标题主旨「上层浪漫」的机制段。
   (必要依据 6,12,14)
```

第一行含段号、档、标签、本段功能。括号只放关联。
