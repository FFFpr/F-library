# Segment Shortcut

把已经读完的章节正文写成**段落总结序列**。本 skill 只管这一段输出的格式和取舍，不负责找书、OCR、写核心论点链、落盘路径或题外话。那些仍由调用方或用户指定。

未点名本 skill 时，不要用这里的规则去改写其他 skill 里已经规定的三句等权序列。

## 要修的现象

等权、每段不超过三句时，枢纽段被削薄，拆开的引文占很多条，一段里并列的几条因被焊成一句。本 skill 用标签和档拉开长度，不用百分数。

## 禁止

- 不要给段落打百分比，不要做「一个标题下加总 100%」。
- 不要用「超过 50% 才写长」当开关。
- 不要计算「和其他所有段落」的相关矩阵，也不要再乘一个未说明的比例。
- 不要输出「第 i 档分数不低于第 i+1 档」这类基数约束。
- 不要因为某段写长了或边多了而回头改档。
- 第三档不要用随机性凑条目。

## 操作顺序

必须按 1→7。不要先写概述再倒推档，也不要按篇幅倒推标签。

### 1. 先写本标题主旨

针对**当前原书小节标题**（不是整本书）写 1～3 条主旨，每条一句话。主旨以该标题下的原文为准。

若本标题主旨和章节开头的核心论点不完全重合，在序列开始处用一两句标明差在哪里。不要拿整章总论去套每一个小节。

### 2. 给物理段编号，并标出续段

有序列按原文物理段的先后编号：`1.` `2.` `3.` ……条数仍等于物理段数，顺序不变。

下面这类**不单独占重要性**：上一页没写完的引文、同一套曲辞的后续阕、明显接在「……」之后的续抄。在条目上标「续 n」（n 为该引文或曲辞的起始段号）。续段正文用一句指回 n，不再当独立论证段定档。

### 3. 每段只选一个标签

标签互斥，按下表选一个。

| 标签 | 何时用 |
|---|---|
| 陈述 | 本段直接说出本标题某条主旨 |
| 必要依据 | 删掉本段，主旨会缺机制、缺定义、或缺作者明确的限定 |
| 可替换例证 | 支撑主旨，但同标题里还有同类例子；删掉后主旨仍成立 |
| 次要观点 | 不是本标题主旨，但能给主旨加一条旁证 |
| 限定 | 缩小主旨的适用范围 |
| 例外 | 明确说这条通例在此处不适用 |
| 续 | 第 2 步标出的续段 |
| 过渡/场景 | 转场、纯景物铺陈，或与主旨没有上表中的关系 |

**必要依据 / 可替换例证的决胜：** 本段第一次给出定义、因果机制或作者自限 → 必要依据或限定。同标题里已经有更完整的机制段，后出现的作品、引文、场景 → 可替换例证。凡是论据都算第一档——不要这样切。

作者用来防止读者把主张读满、读死的句子（如「尚无……」「是否存在尚可研究」「挂一漏万」「并非……而是……」）标成**限定**，不要标成过渡或旁支。

### 4. 由标签定档

档由标签决定，不由印象分决定。

- 第一档：陈述、必要依据、限定、例外
- 第二档：次要观点、可替换例证
- 第三档：续、过渡/场景

### 5. 只连稀疏的边

每段至多 3 条出边。关系只许：

- `证明→` 本段给目标段提供机制或理由
- `被证明←` 本段的主张由源段提供机制或理由
- `实例←` 本段是源段的例子（可替换例证常用）
- `例外于` 本段把目标段的通例划出界外
- `限定→` 本段缩小目标段主张的适用范围
- `续` 本段是段 n 的续写

写在该条末尾的括号里，只写段号和关系，例如 `(证明→6,12)` `(实例←3)` `(限定→1)` `(续 8)`。

不要给每段交代它和其余所有段的关系。枢纽段 = 被至少两条指向的段，或自身是陈述/必要依据且指出至少两条。

### 6. 按档写篇幅

- **第一档，或枢纽段：** 取消三句上限。固定写三块，能短则短，该长则长：
  1. 本段主张或完成的功能（一句）
  2. 依据（原句压缩、作品、因果）。若一段里有并列的因、并列的命题，必须分条写，禁止焊成一个口号
  3. 限定，或它在本标题主旨里的位置（一句）
- **第二档：** 不超过三句
- **第三档：** 一句；续段写「续 n：……」

不输出百分数。需要比较重要性时，只看档和是否枢纽。

### 7. 条目格式

```
3. 【第一档·必要依据】童心说把市民写实转成个性解放的创作标准。
   依据：……
   位置：本标题主旨「上层浪漫」的机制段，不是例证。
   (证明→6,12,14)(被证明←2)
```

第一行必须能单独读懂：段号、第几档、标签、这段在干什么。括号只放关联，不承担正文。用有序列，不用 `- `。

## 冲突时谁让步

先标签，再定档，再连边，再写长度。

不允许：因为写长了而升档；因为边多了而改标签；先丢进第三档再靠「相关性」抬回第一档。全文支点若是定义、机制或自限，第 3 步就应标成必要依据或限定。

## 写完自查

1. 主旨是不是该标题原文里的那几句，而不是执行者另造的总论。
2. 每段是否只有一个标签，档是否由表中那一行推出。
3. 限定句是否在第一档；例外是否在第一档。
4. 第一档是否把段内并列的因拆开了。
5. 续段是否短，且指回起始段号。
6. 每条出边是否 ≤3，关系词是否只用上面六个。
7. 没有百分数、没有 50% 阈值、没有全段配对打分。

## 形态示例（不是输出模板的唯一题材）

标题主旨若是「清初倒退使上层浪漫转为感伤；感伤的内容是家国空幻；通道接到批判」，则：

- 清初总论段 → `【第一档·必要依据】`，依据里分成并列几条（政策与闭关、市民萎缩、上层变感伤），不要焊成单一口号；`(证明→` 后文标本段 `)`
- 标本作品论空幻的段 → `【第一档·陈述】`；`(被证明←` 总论段 `)(实例→` 主题曲起始段 `)`
- 主题曲第一阕 → `【第二档·可替换例证】`，不超过三句
- 同一套曲辞的后几阕 → `【第三档·续】`，一句指回第一阕
- 「并非 A 而是 B」的划界段 → `【第一档·限定】` 或 `【第一档·例外】`，写到足够防止读成 A

核对时只查：主旨、标签与档、第一档是否拆开并列因、出边是否稀疏。不要查百分数是否加总为 100。
