# 3.3 谁负责你的游戏故事？ (Who Controls the Story)

> **所属课程**：加州艺术学院《游戏设计入门》(CalArts: Introduction to Game Design)  
> **对应章节**：第三周·讲好一个故事 (Week 3: Tell a Story) · 第 3.3 讲  
> **主讲导师**：弗兰·克劳斯 (Fran Krause)  
> **时长**：01分11秒

---

## 一、 前置核心概念与理论基石补全

### 1. 共同创作 (Co-Authorship)
- 在交互媒介中，故事不再是作者单向输出的成品，而是**设计者搭建的舞台规则与玩家在游玩中的自主决策共同谱写的交响乐**。
- 设计者控制着“可能性空间 (Possibility Space)”，玩家控制着“实际轨迹 (Actualized Path)”。

---

## 二、 导师核心观点与论证推理链条

### 1. 核心观点
> **游戏叙事中最根本的权衡是：故事的主导权到底交给编剧（作家主导），还是交给玩家（玩家主导）？这是决定游戏类型与架构的关键十字路口。**

### 2. 论证推理链条
```
[核心问题]
在游戏里，到底是谁在决定故事的走向？
        ↓
[光谱分析]
- 左端：完全由作家掌控（线性剧情、固定主角命运、电影化过场）；
- 右端：完全由玩家涌现（沙盒模拟、开放探索、自发行为）。
        ↓
[核心结论]
没有绝对优劣之分，关键在于设计师必须在一开始就明确自己的叙事定位，并维持体验承诺的一致性。
        ↓
[延伸启示]
接下来的两节课将分别深入剖析“作家驱动”与“玩家主导”的具体实现手法。
```

---

## 三、 实操与教学细节沉淀

### 叙事控制权光谱图

```
[ 完全作家掌控 (Author-Led) ] ──────────────────────────────→ [ 完全玩家主导 (Player-Led) ]
 • 电影互动 / 视觉小说 / JRPG                                    • 沙盒模拟 / 策略战争 / 桌游对战
 • 强剧情、高情绪张力                                            • 强涌现、高自由度、个性化经历
 • 重玩价值较低                                                  • 重玩价值无限
```
