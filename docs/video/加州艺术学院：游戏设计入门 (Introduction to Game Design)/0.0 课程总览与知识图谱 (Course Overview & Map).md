# 课程总览与全景导航 (Course Overview)

> **课程机构**：加州艺术学院 (California Institute of the Arts, CalArts)  
> **授课导师**：弗兰·克劳斯 (Fran Krause) 等加州艺术学院动画与游戏教研团队  
> **课程原名**：Introduction to Game Design（Coursera 专项课程《游戏设计：艺术与概念》第 1 门课）  
> **视频来源**：哔哩哔哩 (BV1wkBrBJEnK / 短链: https://b23.tv/Lg1Mitu)  
> **课程规格**：共 27 讲（涵盖 4 大教学周、4 次进阶纸面原型实战作业、以及资深独立游戏设计师特别访谈）  
> **核心主旨**：脱离具体编程代码与引擎技术负担，纯粹从**规则构建、机制发现、系统平衡、叙事驱动、角色生态与纸面快速原型 (Paper Prototyping)** 层面，系统讲授如何构思、设计并落地一款引人入胜的自洽游戏。

## 核心教学理念与方法论

1. **零代码纸面原型 (Paper Prototyping First)**：
   - 所有的作业与设计验证均以纸笔、卡牌、骰子、硬币等物理组件完成。
   - 强制剥离华丽美术与代码渲染的干扰，直接检验“核心规则与玩家互动本身是否足够好玩”。
2. **自下而上的迭代循环 (Iterative Evolution)**：
   - 第 1 周设计极简纸面规则 → 第 2 周注入非对称与机制突变 → 第 3 周赋予叙事与世界观解释 → 第 4 周完善角色生态与多人博弈闭环。
3. **自闭环学习建议**：
   - 建议按照分 P 顺序逐篇阅读各章节笔记。每一篇笔记均包含独立的前置概念解析、论证推理链条、落地实操步骤与题外话汇总。
