## 一、 前置核心概念与理论基石补全

### 1. 经典三幕剧与英雄之旅 (The Three-Act Structure & The Hero's Journey)
- 约瑟夫·坎贝尔的“英雄之旅”模型在游戏线性关卡设计中的经典映射：
  ```
  [ 第一幕：平凡世界与启程冒险 ] ──→ [ 第二幕：考验、盟友与至暗危机 ] ──→ [ 第三幕：终极对决、蜕变与归途 ]
  ```

---

## 二、 导师核心观点与论证推理链条

### 1. 核心观点
> **在作家主导的结构中，作者必须精准掌控节奏（Pacing）。如果紧张感一直拉满，玩家会麻木疲劳；如果一直平淡，玩家会感到无聊。必须在“高强度战斗/解谜”与“叙事喘息期”之间交替切换。**

### 2. 论证推理链条
```
[核心挑战]
如何在固定的线性流程中保持玩家的情绪张力？
        ↓
[推导过程]
通过“压力-释放 (Tension-Release)”的情绪过山车设计：
在重大 Boss 战或危机解谜后，紧接着安排一段安全的营地对话、探索收集或剧情揭秘，让玩家消化刚刚经历的情感冲击。
        ↓
[核心结论]
作者意志的把控体现在对“关卡节奏曲线”的精巧编排上。
```

---

## 三、 实操与教学细节沉淀

1. **情绪节奏曲线绘制法**：
   - 纵轴为“玩家情绪紧张度 (Tension)”，横轴为“关卡游玩时间”。
   - 检查曲线是否呈现波浪上升形态，杜绝一条直线到头。
2. **安全屋效应 (Safe Room Effect)**：
   - 在高压关卡之间设置绝对安全、带有温暖音乐与剧情交流的区域（如生化危机的打字机房、魂类游戏的篝火）。
