## 一、 前置核心概念与理论基石补全

### 1. 退化策略 (Degenerate Strategy / Dominant Strategy)
- **博弈论定义**：在某一规则系统中，存在一种不论对手采取何种行动都优于其他所有选择的“绝对最优解”。
- **危害**：一旦玩家发现了退化策略（如某个角色无脑连招必中、某个棋子走法无敌），游戏原本丰富的策略树会瞬间坍缩为单一机械重复，导致游戏失去生命力。

---

## 二、 导师核心观点与论证推理链条

### 1. 核心观点
> **完美的游戏平衡不等于“把所有数值削减到绝对平庸”，而是创造多样化但相互克制的有意义抉择；平衡性分为对称平衡与非对称平衡两种截然不同的设计哲学。**

### 2. 论证推理链条
```
[事实与现象]
在国际象棋中，双方棋子配置与棋盘完全对称；而在《星际争霸》或《苏格兰场》(Scotland Yard) 中，不同阵营的兵种、资源和玩法完全不同，但两者都极具竞技深度与趣味。
        ↓
[推导过程]
- 对称平衡：依靠纯粹的智力与战术推演取胜，但容易陷入“先手优势”或枯燥背棋谱；
- 非对称平衡：通过“不同优势维度的代偿”制造张力（如高攻击但脆皮 vs 高防御但迟缓；隐蔽逃亡者 vs 人多势众的搜捕者）。
        ↓
[核心结论]
设计非对称游戏时，关键是让每个玩家都能体验到属于自己阵营独特的“掌控感 (Sense of Empowerment)”，同时给对手留下反制的窗口。
        ↓
[延伸启示]
在纸面原型迭代中，尝试将双方的胜负条件或移动方式做非对称化改造，往往能让枯燥的游戏瞬间焕发生机。
```

## 三、 实操与教学细节沉淀

### 平衡性设计对照与调优法则

```
                     ┌───────────────────────────────────┐
                     │          系统平衡调优策略         │
                     └─────────────────┬─────────────────┘
                                       │
            ┌──────────────────────────┴──────────────────────────┐
            ▼                                                     ▼
┌───────────────────────┐                             ┌───────────────────────┐
│     加权代偿法则      │                             │     剪刀石头布循环    │
│  (Cost-Benefit Law)   │                             │  (Rock-Paper-Scissors)│
│ • 高收益必须伴随高成本│                             │ • 机制 A 克制 机制 B  │
│ • 高机动必须牺牲护甲  │                             │ • 机制 B 克制 机制 C  │
│ • 强力技能需要预备轮  │                             │ • 机制 C 克制 机制 A  │
└───────────────────────┘                             └───────────────────────┘
```

1. **消除先手优势的 3 种纸面技巧**：
   - *方案一*：后手方获得额外补偿资源（如炉石传说的幸运币和额外抽牌）；
   - *方案二*：“一人切蛋糕，一人先选”（Pie Rule / Swap Rule，如五子棋三手交换）；
   - *方案三*：同时秘密下达指令并同时翻开结算（Simultaneous Action Resolution）。
