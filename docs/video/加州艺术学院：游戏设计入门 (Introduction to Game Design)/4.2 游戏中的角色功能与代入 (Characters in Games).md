## 一、 前置核心概念与理论基石补全

### 1. 角色三维立体设计模型 (The Three Dimensions of Character)
- 经典戏剧理论（拉约什·埃格里的《编剧的艺术》）在游戏角色设计中的应用：
  ```
  ┌─────────────────────────────────────────────────────────────┐
  │ 1. 生理/外在维度 (Physical)  │ 外貌、体态、剪影、辨识度、移动速度 │
  ├──────────────────────────────┼─────────────────────────────┤
  │ 2. 社会/阵营维度 (Social)    │ 出身、阵营、阶级、盟友羁绊与世仇   │
  ├──────────────────────────────┼─────────────────────────────┤
  │ 3. 机制/心智维度 (Ludic)     │ 核心欲望、性格弱点、专属技能与代价 │
  └─────────────────────────────────────────────────────────────┘
  ```

---

## 二、 导师核心观点与论证推理链条

### 1. 核心观点
> **游戏中的角色必须具备“机制独特性 (Mechanical Distinctiveness)”与“视觉剪影辨识度 (Silhouette Clarity)”。如果两个角色的数值和打法完全一致，仅仅换了一套衣服，这种角色设计就是虚假的。**

### 2. 论证推理链条
```
[事实与现象]
在经典格斗游戏《街头霸王》或 MOBA 游戏中，玩家仅凭一个模糊的剪影或走姿，就能立刻在 0.1 秒内认出该角色并预判其攻击范围与危险程度。
        ↓
[推导过程]
视觉上的极端夸张与机制上的极端特化（如一个慢速但有一击必杀投技的摔跤手 vs 一个超高速但缺乏霸体的忍者）形成了强烈的认知示能。
        ↓
[核心结论]
角色设计必须做到“形意合一”——外貌传达机制，机制印证人设。
        ↓
[延伸启示]
在纸面棋盘游戏中，给不同棋子画上截然不同的几何剪影与专属技能卡。
```

## 三、 实操与教学细节沉淀

### 纸面原型角色卡设计模板

```markdown
### 🏷️ 角色属性卡 (Character Sheet)

- **角色名与称号**：[例如：荒野斥候·雷恩]
- **视觉剪影特征**：[例如：披风、长弓、瘦长身形]
- **基础机能参数**：
  - 生命值 / 护甲：3 点
  - 每回合基础移动力：3 格（可穿过灌木）
- **核心专属技能 (Unique Ability)**：
  - 【鹰眼预警】：可在 2 格距离外提前翻开未知的陷阱卡。
- **致命弱点 / 代价 (Fatal Flaw / Weakness)**：
  - 【近战乏力】：受到相邻格子的直接攻击时，受到的伤害翻倍。
```

## 四、 全信息捕获与题外话汇总

> **除了视频主要内容外，作者还讨论了/提及了：**  
> 1. 结合加州艺术学院角色动画专业的经典设计教学法，展示了如何通过简单的几何图形（圆形、正方形、三角形）塑造不同性格倾向的角色；  
> 2. 提及了在多人派对游戏中，给角色起幽默诙谐的外号有助于快速破冰。
