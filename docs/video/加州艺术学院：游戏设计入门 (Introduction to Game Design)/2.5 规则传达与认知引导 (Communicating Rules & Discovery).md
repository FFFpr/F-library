## 一、 前置核心概念与理论基石补全

### 1. 示能性 (Affordance) 与认知负荷 (Cognitive Load)
- **示能性（唐·诺曼《设计心理学》）**：物体所呈现出的能够直观提示用户如何操作的物理属性（如门上的把手提示“拉”，平板提示“推”）。
- **游戏中的认知引导**：通过视觉线索、棋盘布局与触觉反馈，让玩家在未经文字告知的情况下，本能地猜测出正确的交互方式。

---

## 二、 导师核心观点与论证推理链条

### 1. 核心观点
> **最好的规则教学不是让玩家背诵说明书，而是通过精巧的关卡空间与反馈设计，让玩家“自己发现规则（Discovery）”。自主发现带来的顿悟感是游戏最核心的愉悦来源之一。**

### 2. 论证推理链条
```
[事实与现象]
在经典《超级马里奥兄弟》1-1 关卡中，没有任何一段文字教程，但玩家自然而然学会了按向右走、跳跃顶问号砖块、踩蘑菇。
        ↓
[推导过程]
通过安全受限的环境（第一只板栗仔速度极慢且无法回头），系统逼迫玩家进行试错；一旦玩家做出正确动作，系统立即给予清脆的音效与金币正反馈。
        ↓
[核心结论]
“展示，而非说教 (Show, Don't Tell)”。将复杂的规则拆解为阶梯状的微型情境，让玩家一步一步在试错中顿悟。
        ↓
[延伸启示]
在纸面游戏中，可以通过棋盘上的符号箭头、颜色指引或第一局的简短教学范例来实现直观引导。
```

## 三、 实操与教学细节沉淀

### 认知引导的“四步顿悟阶梯”模型

```
[ 1. 直觉尝试 (Intuitive Probe) ]
玩家根据视觉示能性做出第一步试探
               ↓
[ 2. 边界碰撞与即时反馈 (Boundary Hit) ]
系统立即给出清晰的状态反馈（成功/受阻/得分）
               ↓
[ 3. 验证假设并掌握规则 (Hypothesis Confirmation) ]
玩家在脑海中建立因果心智模型：“原来踩这个会触发机关”
               ↓
[ 4. 熟练组合与策略涌现 (Mastery & Mastery Testing) ]
系统逐步提高难度，要求玩家在复杂局面下综合运用该规则
```
