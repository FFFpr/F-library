# 第07章 力量与荣耀

## 本章位置

第四部「预言」。前六章把生命史收束到嵌合线粒体；本章从呼吸链的马赛克结构出发，预言物种分化、性别决定、生育力与有氧能力的权衡、衰老与「休息有害」。能量约束第一次直接碰到人体。

> 两性、种系与凋亡的起源见：[第06章_性以及死亡的起源.md](第06章_性以及死亡的起源.md)

## 核心论点

1. 呼吸链由线粒体基因与核基因嵌合编码，中心间距 1 Å 可使电子传递改变十倍；这是短视但不可避免的工程。
2. 两套基因组配合不良 → 电子堆积 → 超氧自由基 → 心磷脂氧化、细胞色素 c 脱落 → 膜电位崩溃 → 凋亡；这是所有真核共有的功能选择。
3. 线粒体—核不兼容可造成杂种衰退与物种起源；霍尔丹法则可用代谢率与死亡门槛解释，而不必依赖性染色体。
4. 死亡门槛低：有氧能力高、疾病少、生育力低；门槛高则相反。健康与生殖力是同一权衡。
5. 自由基是报警烟雾，不是单纯的磨损剂；盲目补抗氧化剂可能关掉警报。不用则废：需求下降同样使呼吸链过还原。

## 一、马赛克与嵌合呼吸链

西西里切法卢大教堂穹顶的基督马赛克：每一贴片不知自己在整体中的位置，一粒放错可毁掉神性。作者用来比视网膜、意识，以及呼吸蛋白。复合体 I 有 45 个亚基；深色核心多由线粒体基因编码、埋在膜内，浅色亚基由核基因编码（图 31）。线粒体基因组极小，表面自主分裂是假象。电子靠量子隧穿，中心距离必须小于约 14 Å；每远 1 Å，传递速率降为十分之一。一个氨基酸改变氢键，中心位移 1 Å，即可造成线粒体病：神经肌肉退化、早夭，严重程度难测。

核基因每代重组，动物线粒体基因几乎不重组且演化快 10–50 倍，却仍须在几埃上配合。基因迁入核的原因包括：雄性有利突变无法经母系线粒体传递；腾出膜空间；远离自由基。约 1,500 个蛋白从胞质运回线粒体。留下的是现场控制所必需的那一小撮——送错的谱系死亡。没有工程师会这样设计；从「细菌进细菌」出发，自然选择只能走到这里。

## 二、自由基、细胞色素 c 与凋亡

配合不良时电子在上游铁硫簇堆积，Fe³⁺ 被还原为 Fe²⁺，直接与氧生成超氧自由基 O₂·⁻（图 32）。超氧化物歧化酶等清除系统受严格调控：清太多等于捂掉烟雾、留下火灾。自由基超过阈值氧化心磷脂，细胞色素 c 脱落，电子流中断，膜电位崩解。1990 年代中期发现这套事件启动凋亡：半胱天冬酶把大分子切碎，膜泡交给邻细胞，数小时内了无痕迹。胚胎塑形与清除损伤细胞需要凋亡；令人吃惊的是，从植物到酵母，同一套线粒体信号都通向自杀。杜布赞斯基：不从演化看，生物学现象没有道理。这是剔除两套基因组不匹配细胞的功能选择。

两性放大卵子之间线粒体克隆的差异；不匹配的在发育中凋亡。过严则流产、不育；过宽则线粒体病儿出生。品质对生殖力，是选择的核心权衡。

## 三、物种起源与霍尔丹法则

序列显示：与呼吸链直接互动的核基因，变化速度跟上线粒体；其他核基因慢得多——补偿性共同演化。伯顿让圣克鲁斯岛两侧虎斑猛水蚤杂交：F1 还好，杂种雌性与父本回交的后代 ATP 合成降约 40%，存活、生殖力、发育时间全面恶化；与母本回交则恢复。线粒体永来自母亲，核基因越不像母亲越糟。果蝇、黄蜂、小麦、酵母、小鼠都有 mito-nuclear 衰退。桡足线粒体相对核快约 50 倍，果蝇约 2 倍，衰退强度随之而变。华莱士认为线粒体处于适应前线，先改生理再改形态；作者喜欢此说，证据仍少。霍尔丹 1922 年法则：杂种中缺失、稀少或不育的是异配性别（哺乳类雄性 XY，鸟类雌性 ZW）。性选择、性染色体解释都有漏洞：许多爬行两栖用温度决定性别，仍有一性衰退。共同基础更像代谢率。「暖男假说」可追溯到古希腊；哺乳动物雄性胚胎数小时内就长得略快。需求超过供给的组织先死：线粒体病打击脑、骨骼肌、视力。花药是植物中代谢高到能触发退化的组织，于是有细胞质雄性不育。果蝇胞质杂合体的睾丸基因表达大面积响应，也只伤雄性性器官。鸟类中生长/代谢格局不同，受伤的是雌性。希尔关于雄鸟羽色与线粒体品质信号的假说证据不多，但展示了同一逻辑的延伸。

## 四、死亡门槛：健康对生育力

供给低于需求，器官死亡；个体死亡是高需求细胞先倒下的连续过程。种系隔离使肉体成为用完即弃的载体。给定线粒体输出，代谢快的细胞、代谢快的性别更容易暴露缺陷。

「死亡门槛」：呼吸链稍有迟滞就漏自由基、触发凋亡。门槛低（蝙蝠、鸟、高有氧需求）：胚胎稍不匹配即终止，成体有氧能力高、患病少，代价是不育。门槛高（大鼠、树懒、久坐的人）：轻微泄漏可忍，生育力高，衰老与疾病风险高。抗氧化剂若系统性压掉自由基信号，可能让本该凋亡的不匹配细胞活下去——小鼠实验中，某些线粒体 DNA 变异的表型可被抗氧化剂「掩盖」或恶化（图 35）。休息同样危险：需求下降、ADP 少、电子堆积、泄漏上升（图 36）。运动保持需求与容量匹配。作者把这些写成可检验预言，而非养生箴言：从嵌合线粒体出发，应当看到有氧能力、生殖力、寿命与疾病沿同一条门槛分布。

除了本章主要内容外，作者还讨论了/提及了：1. 东正教圣像的神人二性与工匠匿名，2. 克格勃在莫斯科大剧院抹去存在的比喻，3. 塑料袋套头时脑先死、皮肤后死，4. 沉迷电视的人类被用来对比蝙蝠的门槛，5. 自由基泄漏与寿命相关但是否因果仍需小心。

## 段落总结序列

**主旨**：1. 嵌合呼吸链使两套基因组必须在埃尺度配合。2. 配合不良经自由基通向凋亡，成为发育与物种层面的选择。3. 死亡门槛把有氧健康与生育力、衰老绑在同一权衡上。

**最小标签集**：陈述；必要依据；限定；例外；可替换例证；次要观点；过渡/场景。

1. 【第三档·过渡/场景】教堂马赛克：一粒贴片放错可毁掉整体。
2. 【第一档·陈述】呼吸链由线粒体基因与核基因嵌合，中心间距 1 Å 可使电子传递改变十倍。
3. 【第一档·必要依据】基因迁核有若干好处，但现场控制迫使一小撮基因必须留下，否则膜电位灾难。
   （本段是第2段配置为何存在的必要依据）
4. 【第一档·必要依据】电子堆积产生超氧自由基，氧化心磷脂并释放细胞色素 c，膜电位崩溃启动凋亡。
   （本段是功能选择的必要依据）
5. 【第二档·限定】清除自由基的酶必须受控；烟雾不等于火灾本身。
   （本段划定第4段）
6. 【第二档·可替换例证】猛水蚤回交实验把杂种衰退归因于母系线粒体与外来核基因不匹配。
   （本段旁证第4段在物种层面的后果）
7. 【第一档·陈述】霍尔丹法则与细胞质雄性不育，可用代谢需求超过供给来统一，而不必先假定性染色体。
8. 【第一档·陈述】死亡门槛低换有氧能力与低疾病，门槛高换生育力，健康与生殖力是同一权衡。
9. 【第一档·限定】抗氧化剂与长期休息都可能提高泄漏或关掉警报，运动则使需求与容量匹配。
   （本段划定第8段的生活推论）
10. 【第二档·次要观点】从嵌合线粒体可预言复杂生命共有凋亡、两性品质选择与衰老，宇宙别处若有线粒体式细胞也会如此。
    （本段把第8段接到后记的预见性）
