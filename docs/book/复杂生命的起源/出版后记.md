# 出版后记

## 本章位置

后浪作为简体中文版出版方的说明。把本书放进「自达尔文以来最好的生物学书都是一场辩论」的传统，并解释为何找严曦翻译。署 2020 年 7 月。

> 译者对莱恩文风的判断见：[译后记.md](译后记.md)

## 核心内容

出版方称：从《氧气》到《能量、性、死亡》再到本书，能出三部曲中任何一部都是荣幸。莱恩面对的修辞挑战与达尔文类似：把新想法写得像常识，把颠覆写得像作者脑中一样直白。前者要在已积累的事实里厘出规律——听起来像异端：生物学也能做出可验证预测吗？后者对读者要求极高。出版方理解的「普及」不是降低门槛的傲慢，而是相信稍加学习即可见证推理。

关键之一是环境与基因不可二分。若新达尔文主义把环境当选择的施予者、基因当被施予者，莱恩更接近理查德·陆温顿：没有环境就没有生物，没有生物就没有环境。于是薛定谔的「什么是生命」被改写成「什么是活着」：生长与繁殖受制于能量，能量在于结构与环境的关联。出版方强调：莱恩不同意「生命抵抗熵」的口号式理解；有序以环境更高的无序为代价，限制路径的是能量本身。若论证成立，宇宙类似环境应上演同样的能量限制；解开地球生命为何如此，也有助于寻找别处的生命，并突破「生物学无法预测」的桎梏。只盯 DNA 是在记载过去；结合能量才能找出促使演化的环境。

非二分视角的基石是化学渗透。米切尔：「我无法脱离环境来考虑生命……膜既隔开生命和环境，又让它们紧密相连。」2012 年有网友在豆瓣科学松鼠会读者花园发《二十世纪最「反直觉」的伟大生物学发现：化学渗透》，笔力像会写中文的莱恩；出版方联系到作者严曦。门肯讽刺伪音乐爱好者从不尝试创作；出版方希望本书遇到会「创作」的读者。文末为服务热线与信箱 reader@hinabook.com。

除了本章主要内容外，出版方还讨论了/提及了：1. 陆温顿的环境—基因不可分，2. 用米切尔引文作为找译者的航标。

## 段落总结序列

**主旨**：1. 本书把生物学写成可预测的能量辩论，不靠降低门槛来普及。2. 化学渗透体现生命与环境的连续，也引导出版方找到译者。

**最小标签集**：陈述；必要依据；次要观点；过渡/场景。

1. 【第一档·陈述】出版方把莱恩视为能接过达尔文式长篇辩论的写作者，要求读者跟上推理而非被降低门槛。
2. 【第一档·必要依据】环境与基因不可二分，活着受制于能量，故生物学应能从环境约束做出预测。
   （本段是第1段的必要依据）
3. 【第二档·次要观点】米切尔论膜的引文既是科学锚点，也是发现译者严曦的线索。
   （本段旁证第2段）
4. 【第三档·过渡/场景】服务信息与 2020 年 7 月署期结束出版说明。
