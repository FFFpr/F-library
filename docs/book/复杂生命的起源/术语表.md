## 核心定义（按原书逻辑重排）

**能量货币与膜**

- ATP：三磷酸腺苷，通用能量货币；水解为 ADP 与磷酸基团。乙酰磷酸是更简单的二碳类似物，地球化学或可直接合成。
- ATP 合酶：膜上纳米涡轮，质子回流驱动 ATP 合成。
- 膜：脂双层；膜电位是两侧电荷差。质子梯度是两侧质子浓度差；质子动力是浓度差与电荷差合在一起的电化学力。
- 化学渗透偶联：呼吸把质子泵出膜外，质子经 ATP 合酶回流，把呼吸与 ATP 合成偶联起来。

**氧化还原**

- 氧化 / 还原：失电子 / 得电子。氧化还原对是一对供体与受体。
- 呼吸作用：经呼吸链把电子从食物或氢等供体交给氧或其他受体，能量用于泵质子。有氧呼吸用氧；无氧呼吸用硝酸盐、硫酸盐等。发酵不是呼吸，不经质子梯度与 ATP 合酶，人产乳酸、酵母产酒精。
- 铁硫簇：Fe₂S₂ 或 Fe₄S₄ 类矿物核心，嵌在呼吸蛋白中。
- 自由基：带未成对电子的原子或分子；呼吸泄漏的氧自由基与衰老、疾病有关。

**遗传与信息**

- DNA / RNA：遗传物质与其近亲。RNA 有信使、转运、核糖体三种主要形式。RNA 世界假说认为早期 RNA 兼作模板与催化剂。
- 基因 / 基因组；染色体；流动染色体指重组中的染色体。
- 转录 / 转译：DNA→RNA；RNA 在核糖体上按密码装配蛋白质。
- 内含子：基因中非编码间隔；移动内含子是自我复制的基因寄生物。真核内含子可能是早期细菌移动内含子扩散后突变衰退的残骸。
- 直系同源基因：不同物种中继承自共祖、功能相同的基因。旁系同源基因：同一基因组内复制形成的基因家族成员。
- 水平基因转移：同代细胞间交换基因或从环境摄入 DNA。垂直继承是亲代把整套基因组传给子代。
- 质粒：小环状寄生 DNA，可带抗药性等基因。寄生 DNA：自私复制的 DNA。

**细胞类型**

- 细菌 / 古菌 / 真核生物：生命三域。前二者为原核生物（无细胞核）。真核有核与线粒体等。
- 露卡（LUCA）：最后共同祖先，由比较现代细胞特征重建。
- 线粒体：真核动力工厂，源于 α-变形菌，保留微小基因组。叶绿体源于蓝细菌。
- 细胞核：真核基因控制中心。细胞质：核外胶状物质。
- 原生生物：单细胞真核的统称；有的可有 4 万基因，体积至少是细菌 15,000 倍。源真核生物：曾被误认为缺失环节的简单真核，不要与古菌混淆。
- 内共生：一个细胞生活在另一个细胞内并交换代谢物。吞噬作用：整细胞吞入再消化。渗透营养：先在体外消化再吸收，真菌如此。

**起源与物理**

- 碱性热液喷口：海底喷出富氢碱性热液，蛇纹岩化（橄榄石等与水反应）的产物。
- 热泳：热梯度或对流使有机分子浓缩。
- 耗散结构：靠持续注能维持的稳定结构，如漩涡、飓风。
- 不平衡状态：有反应潜力但尚未反应，如有机物与氧气。
- 放能 / 吸能：放出 / 需要自由能。放热 / 吸热针对热量。自由能：可做功的能量，不是热能。熵：失序倾向。
- pH：质子浓度；小于 7 为酸。质子即 H⁺（氢核）。
- 埃（Å）：约一个原子尺寸；1 nm = 10 Å。

**性、选择与死亡**

- 有性生殖：减数分裂形成单倍配子再结合。有丝分裂：普通细胞分裂。
- 单亲遗传：线粒体系统地只从一方（通常卵子）继承。
- 种系：专司传递基因的生殖细胞。
- 凋亡：基因编码的耗能自杀，自我拆解并回收。
- 等位基因；固定：某等位基因传遍种群。选择性清除：强选择使某变体取代其他。
- 重组：同源染色体交换对应区段。
- 单源 / 多系辐射：从一个祖先或从多个祖先分别爆发出许多物种。
- 雪球地球：赤道海平面也有冰川的全球冰期。
- 自私冲突：内共生体之间或质粒与宿主的利益冲突。
- 性别决定：发育为雄或雌的过程。
- 多态性 / 方差：一组同源实体（等位基因、线粒体）的分散程度。

**其他构件**

- 氨基酸：20 种，连成蛋白质。核苷酸：DNA/RNA 构件，也作酶辅因子。
- 酶：催化蛋白，常加速数百万倍。基质：被酶转化的基础物质。
- 脂肪酸：细菌与真核膜脂的疏水尾。反向转运蛋白：膜上「旋转门」，如 H⁺ 换 Na⁺。
- 光合作用：用光从水等取电子还原二氧化碳。
- 核糖体：按 RNA 脚本装配蛋白质。
- 复制：细胞或 DNA 从一份变两份。
- 突变：序列改变或缺失、多余复制。
