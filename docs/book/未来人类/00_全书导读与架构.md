# 全书导读与架构

## 版本与阅读说明

本书据 Scott Solomon《Future Humans: Inside the Science of Our Continuing Evolution》（Yale University Press，2016）整理笔记。版权页载：Copyright © 2016 by Scott Solomon；ISBN 978-0-300-20871-9（精装）；美国国会图书馆控制号 2016936483。中文书名取《未来人类》，副题译为「我们持续进化的科学内幕」。

源文件为仓库 `z-library` 中的本地 PDF（约 234 页、有文字层），笔记只依据该文件正文，不以他书、百科或记忆补章。页码对照：PDF 页码与书内页码大致相差 9（目录页标 Introduction 为书内第 1 页，对应 PDF 第 10 页）。

作者 Scott Solomon 是进化生物学家，以昆虫（尤其切叶蚁与微生物共生）为专业，任教于莱斯大学（Rice University）。本书不是科幻推演，而是把基因组学、人口记录、医学队列、微生物组与田野访谈串成一条问题：智人（*Homo sapiens*）是否仍在进化，以及我们能对「明天的人」说什么、不能说什么。

> 「智人」指现存唯一人属物种，即我们自己。后文凡写「我们」「人类」，除非另注，都指智人。

## 作者要回答的总问题

人类进化是不是早已停在几万年前？博物馆里的骨架看起来和今天的人差不多，空调、抗生素、飞机、体外受精似乎也让「适者生存」失效。作者的总答案是：**进化从未停止**；现代化改变的是选择的方向、强度与可预测性，而不是进化这件事本身。

总答案分三层：

1. **定义层**：只要某一性状或其基因在代际间的频率变了，就算进化。它不要求出现新种，也不要求外形大变。
2. **证据层**：疟疾与镰状细胞、高原适应、乳糖酶持续表达、魁北克岛屿与弗雷明汉心脏研究，都表明选择、漂变、基因流、突变仍在现代人群中起作用。
3. **未来层**：我们能指出哪些历史力量仍强（传染病、高原低氧、生育力差异），哪些被文化改写（初育年龄、肤色与紫外线、微生物伙伴），哪些几乎无法外推（行星殖民、生殖系基因编辑）。唯一可确定的是：明天的人不会和今天的人完全一样。

## 一条主线：进化四力仍在，文化改写规则

作者反复使用同一套进化力学，再把「文化—技术」当作改写这些力的环境：

| 力量 | 含义（本书用法） | 在书中的典型位置 |
|--|--|--|
| 自然选择 | 能留下更多后代的性状变常见 | 第1章病菌；第2章肤色、高原、乳糖；第3章初育年龄 |
| 性选择 | 因择偶与交配竞争而变常见，即使不利于存活 | 第4章面容、身高、精子竞争 |
| 遗传漂变 | 随机涨落改变基因频率，小群体里更强 | 第2章中性理论、基因冲浪、脑容量基因假阳性 |
| 基因流 | 群体（甚至近缘种）之间因交配交换基因 | 第2章尼安德特人、丹尼索瓦人、藏族 EPAS1 |
| 突变 | 新遗传变异的最终来源 | 第2章每婴约 60 个新突变；第3章高龄父亲 |
| 文化 | 可遗传的知识与技术，既缓冲选择，也制造新选择 | 第2章饮食；第3章人口转变；第4章避孕与网恋；第5章抗生素 |

贯穿全书的方法是：**先看其他物种如何进化，再问人类是否适用；先看历史基因组签名，再问当代人口与医学数据能否证实选择仍在响应。**

## 六章逻辑地图

```text
引言：进化停了吗？（Mayr / Gould / Attenborough vs Dobzhansky / Wills）
    → 第1章 基因组与病菌：传染病是近期选择的主引擎
        → 第2章 大数据：漂变、基因流、地方适应（肤色、高原、乳糖）与变异激增
            → 第3章 转型中的世界：人口转变后，选择从「活下来」转向「生多少」
                → 第4章 性：生育力时代的择偶、精子竞争、避孕与辅助生殖
                    → 第5章 微小的伙伴：共进化微生物正在被现代化消灭
                        → 第6章 地平线之外：灭绝、物种形成、火星殖民
                            → 结语：全球基因池 + 生殖系编辑这一无先例变量
```

各章不是并列百科，而是把时间尺度拉长：第1–2章主要回答「过去几万年发生了什么」；第3–5章回答「工业化之后规则怎么变」；第6章与结语才把视野放到千年世代与行星尺度。

## 阅读本书时可用的判断框架

作者虽写科普，却给出可操作的提问顺序：

1. 先问：这一变化是频率变了（进化），还是个人一生的驯化/习服（不是进化）？
2. 再问：签名像选择，还是像漂变、人口结构、基因冲浪？脑容量基因 *microcephalin* / *ASPM* 是反面教材。
3. 再问：选择作用在存活还是生育？人口转变之后，后者通常更强。
4. 再问：文化是在缓冲选择（防晒、维生素、剖宫产），还是在制造新选择（加工食品、避孕、网恋照片）？
5. 最后问：这件事能否外推到未来？高原低氧几乎仍在；初育年龄则生物学与文化对着干。

## 本书明确不作的事

- 不画「未来人长蹼或细腿」式科幻外形。
- 不主张优生学干预；引言把高尔顿优生学标为误导，结语再次警告「好意的人类改良仍是社会控制」。
- 不为单一基因贴「智商种族差异」标签；第2章专门拆穿把脑容量候选基因读成智力差异的做法。
- 不把微生物组现状写成已完成的医学定论；第5章保留 Graham 的反对意见。

除了导读本身，作者在全书还反复回到同一句：我们是一种古怪的物种，但故事没有结束。
