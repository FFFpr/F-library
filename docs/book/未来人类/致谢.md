# 致谢

## 本章位置

致谢不是论证章，而是交代这本书如何被写出来：课堂提问、杂志试写、经纪人与出版社、科学写作工坊，以及允许作者走进办公室、实验室、田野、家庭和模拟火星殖民地的研究者。读它可以看见正文里那些访谈不是装饰，而是方法。

> 各章访谈对象在正文中的位置，见：[00_全书导读与架构.md](00_全书导读与架构.md)

## 核心内容

作者称写书是一段惊人过程，没有许多人的善意、慷慨与支持则不可能。

- **课堂**：莱斯大学「导论生物学 II」六年来的学生，其好奇心与尖锐提问激发了他对「我们物种仍在进化」的兴趣。
- **从文章到书**：第3章部分内容曾作为文章发表于 *Nautilus*，得益于迈克尔·西格尔的编辑。与琼·斯特拉斯曼、罗布·邓恩的讨论推动他找文学经纪人。感谢 Trident Media Group 的唐·费尔及其同事接纳、鼓励，并耐心回答他对出版业的全部问题。耶鲁大学出版社的琼·汤姆森·布莱克、安-玛丽·因博诺尼及团队平衡了学术细节与公众可读性，并做了原创视觉设计。罗宾·杜布朗的文字编辑让叙述流动、语法失误最少。感谢圣菲科学写作工坊组织者桑德拉·布莱克斯利、乔治·约翰逊，以及蒂姆·阿彭策勒和其他教师学员，帮他发展出分享科学热情的工具箱。
- **访谈与接待**：许多人为他讲解工作与生活细节，回答问题，并请他进入办公室、实验室、野外地点、家以及模拟火星殖民地。名单包括（正文已出现的人名此处不重复展开）：罗宾·贝克、保罗·巴肯、辛西娅·比尔、马丁·布莱泽、塞思·博登斯坦、帕迪斯·萨贝蒂、大卫·赖希、里克·波茨、埃马纽埃尔·米洛、妮娜·雅布隆斯基、克里斯滕·霍克斯、史蒂夫·斯蒂恩斯、兰迪·桑希尔、萨拉·蒂什科夫、火星沙漠研究站第 149 乘组等。特别感谢米洛、萨贝蒂、EMBO 人类进化基因组时代会议组织者与参会者、以及第 149 乘组的长时间接待。
- **读稿**：多位受访者与同事读了部分草稿；杰弗里·刘易斯、琼·斯特拉斯曼、凯利·韦纳史密斯读了全书并在短通知下提供批评。两位匿名审稿人指出不准确处，并要求补充例子、观点与解释以平衡叙述。剩余错误归作者。
- **材料与后勤**：斯蒂芬·布拉德肖、弗雷明汉历史学会等帮找来源；加布里埃拉·赞布拉诺协助访谈转写。莱斯同事与两位系主任支持。莱斯咖啡馆、Café Brasil 与贝克学院 A-Team 在研究写作各阶段提供咖啡与镇定。
- **家庭**：核心是子女 Nyala、Nicholas、Thomas。感谢父母 Ira 与 Susan Solomon 鼓励他追梦并相信梦可及；家庭旅行培养了对新观念与旅行的爱。延伸家庭与岳父岳母。鲍勃与弗拉维娅·霍思的榜样给他对物种未来的希望——不仅因为他们养了四个出色的女儿。
- **最后**：妻子 Catharina，提醒他生命中什么最重要；没有她的耐心、爱与支持这本书不存在。谢谢她愿意给「穿错外套的那个人」一个机会。

除了本章主要内容外，作者还讨论了/提及了：1. 出版业对他而言很陌生，2. 咖啡馆作为写作基础设施，3. 第4章网恋穿错外套的私人回声。

## 段落总结序列

**主旨：** 本书是课堂、访谈、编辑与家庭共同产物；田野访问是方法不是点缀。

**最小标签集：** 陈述；可替换例证；过渡/场景。

1. 【第一档·陈述】学生提问、Nautilus 试写与经纪人/耶鲁编辑把研究变成面向公众的书。
2. 【第二档·可替换例证】长串受访者与米洛、萨贝蒂、EMBO 会议、火星 149 乘组的接待，对应正文各章现场。（本段是第1段的可替换例证）
3. 【第二档·可替换例证】全书审读与匿名审稿用来纠错、补观点、平衡叙述。（本段是第1段的可替换例证）
4. 【第三档·过渡/场景】咖啡馆、子女与妻子（含穿错外套）把写作锚回日常生活与第4、6章的私人线索。
