# 全书导读与架构

## 版本与阅读说明

本书是罗伯特·C·所罗门（Robert C. Solomon）、凯思林·M·希金斯（Kathleen M. Higgins）所著 *The Big Questions: A Short Introduction to Philosophy* 第 10 版的中译本，张卜天译，清华大学出版社 2018 年 7 月第 1 版（「悦·读人生」丛书）。ISBN 978-7-302-49887-2；约 523 千字。原书 Cengage Learning，2017。

源文件为仓库 `z-library` 中的扫描 PDF（约 455 页、无文字层，Pdg2Pic）。笔记据同一文件的中文 OCR 整理。识别有形近错字，行文已按上下文校正明显讹误，不以他书或记忆补章。术语表个别条目在扫描中截断，已在该文件标明，不臆补。

这是一本**按问题而不是按编年**组织的哲学导论：先逼读者说出自己相信什么，再把历史上的大哲学家当作组织这些信念的启发。第 10 版调换「美」与「非西方哲学」两章顺序，并大幅改写「道德和良好生活」。中译经历第 6、7、9、10 版修订，详见译后记。

## 作者要回答的总问题

人已经在过一种生活、已经有一套关于上帝、实在、真理、自我、自由、对错、正义和美的看法。问题不是「要不要从事哲学」，而是：这些看法能不能被明确表达、彼此协调、经得起反驳，还是停留在时髦词语和廉价替代品上。

总答案分两层：

1. **做哲学**就是反思、明确表达和论证，把概念框架从想当然的地基变成可以检查、修补、必要时重塑的东西（导言）。
2. **大问题没有唯一教科书答案**，但每章都给出一组彼此竞争的经典立场、各自的代价，以及把你自己的看法定位进去的篇末问题。作者的教学偏见是：先让你说话，再让传统发言；没有原著，教科书不能代替思考。

## 一条主线：先占位，再对阵

各章共用同一工序：

```text
开篇问题（逼出己见）
    → 澄清关键词 / 时髦词语
        → 若干经典立场对阵（传记框 + 引文框 + 掌握概念框）
            → 指出每条路的代价与交叉
                → 篇末问题（把自己放回传统）+ 阅读原著书目
```

## 笔记体例

各章笔记按「核心论点 → 概念补全 → 论证推理链 → 题外一句 → 段落总结序列」组织。段落总结按 segment-shortcut：每小节先给 1–3 条主旨和最小标签集，再按重建后的物理段编号，标档与关联。OCR 无缩进，物理段由标题、方框、编号问题和换题切开，与印本可能有一两处出入。

除了本导读所归纳的结构外，原书还包含：1. 封底陈嘉映、靳希平、孙正聿、邓晓芒、张祥龙的推荐语，2. 各章插图（大卫《苏格拉底之死》、居里夫人、莫里索《普绪刻》、马丁·路德·金等），3. 与 Cengage MindTap、Cognero 题库配套的美国大学课包信息。
