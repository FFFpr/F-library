# 附录三 常见的非形式谬误

## 本章位置

导言已把「谬误」分成形式的与非形式的：前者违背推理规则，后者用含混、偏颇或回避来「欺骗」。附录二处理形式；本附录列出几乎总是不好的非形式谬误，并收束为：用最有说服力的方式把演绎与归纳结合起来。

> 💡 形式有效与可靠详见：[附录二_演绎逻辑.md](附录二_演绎逻辑.md)  
> 💡 导言中的循环论证、人身攻击、同义反复详见：[导言.md](导言.md)

## 核心论点

1. **许多论证形式有效，却仍是坏论证**（非形式谬误）。重言式「如果 P 则 P」直接有效，但对讨论毫无推进。
2. **陈述观点不是论证**；常识被挑战时也必须论证——这正是大部分哲学要做的。
3. **循环与恶性循环都已假设所要证明的东西**；但整套世界观的相互支撑可称「良性循环」，与粗心的小圈不同。
4. **离题、人身攻击、结论含糊、改变含义、分散注意力、伪问题、不可靠的权威、滑坡、稻草人、诉诸感情或力量、不恰当的论证类型**，都会危及整个论证。
5. **说服的有效方式是巧妙结合演绎与归纳，辅以类比和对其他立场的恰当批评。**

## 关键概念补全

各条谬误本身即本附录要定义的概念，下面按原文顺序给工作定义，便于后文论证链引用。

**只作断言**：你接受一种观点，不足以让别人也相信。除回答民意调查外，每种意见都需要论证。大家都照字面接受的陈述仍可被挑战。

**循环论证**：把待证结论当前提。例：人人应成为基督徒，因为《圣经》如此说——对不信基督、因而也不信《圣经》的人无效。「这本书会提高分数，因为它能帮你考得更好」是改装过的结论。

**恶性循环**：用 B 证 A、用 C 证 B、再用 A 证 C。例：因宗教场景而知上帝存在 → 场景只能由上帝引起 → 因为上帝在场景中亲自告诉他；或「他一定犯罪了，脸上表情可证」→「因为他就是做那件事的人」。

**良性循环**：宗教徒与无神论者、自由市场支持者与马克思主义者的长期争论显示，每人接受一个大信念体系，信念互相依赖。逻辑学家或称之为良性循环：一整套世界观的充分思考与组织。恶性循环通常只是粗心，通不到任何地方。

**离题**：抛统计图表、抱怨宇宙、说笑话，什么都做就是不谈正题。或可拖垮对方，但不能说服。

**人身攻击**：攻击人的外表、声誉、举止、智力、朋友或财产，而不反驳观点。了解动机或许有助于理解他为何持此立场，但不能证明或否证该观点。量多了冒犯且往往害己。

**结论含糊或变动**：值得捍卫的事物应被清楚表达并坚持。若主张「服药者应受罚」却分不清海洛因与阿司匹林，观点无考虑价值；若改口「非法毒品」又转谈「药品对身体有害」，则合法非法药品同样有效，目标已经滑动。

**改变含义**：表面有效，关键词中途换义。例：只要人们可以为自己打算就是自由的；监狱里的罪犯可以不受约束地为自己打算；因此罪犯是自由的——前句心理自由，后句身体自由。密尔「人们想要的就是值得要的」被指拿英语含糊处做手脚：被欲求的不必应当被欲求（酒鬼要酒）；密尔本人认为 x 值得要的唯一判据是人们事实上想要它。

**分散注意力**：「用题外话引开」。神经学家大谈奇特事实、脑手术、哲学家的愚蠢理论，若与心—脑问题无关，只是周末消遣。时间有限时特别有利，故课堂上盛行。

**伪问题**：看上去深刻，却基于无意义假设，无法回答。有哲学家认为「心灵怎样与肉体相联系」「上帝能否造一座连他也搬不动的山」是伪问题：前者预设心灵与肉体有合理区分；后者预设全能包括逻辑不可能之事。

**不可靠的权威**：近代哲学假设我们有权、有时有责任质疑权威；但大多数知识仍基于权威。问错人即谬误：内科医生谈核政策、物理学家谈高中教育。印刷物不必然有权威，要看作者与出版物。

**滑坡隐喻**：一旦踏上去必定滑到底。政治上或称寒蝉效应（对不法活动的管制吓退合法活动）或多米诺骨牌。例：禁止在拥挤礼堂喊「着火了」迟早导致一切有益政治讨论消失。攻击极端情况不一定危及整体；隐喻常让人以为有不可避免性，其实没有。

**攻击稻草人**：不反驳过硬的真实对手，转而攻击容易打倒的假想对手。例：把萨特「绝对自由」（总能找到对付困难处境的方式）解释成能扇动耳朵飞到月球。

**同情以及诉诸其他感情**：受苦照片可刺激社会行动，同情与行动之间的关联本身不是论证。诉诸感情在哲学中有合法位置，但本身不构成对特定立场的论证。

**诉诸力量**：身体力量永远不能造就哲学正确性。人可被威吓却不因此被驳倒。力量可支持信念，却构不成辩护。

**不恰当的论证**：强有力的归纳反对你时仍坚持演绎，或抽象问题只需演绎时却去找归纳证据，都是方法选择上的逻辑错误。例：演绎「Q 先生是好人故其国无刑讯」，面对成百上千可靠证人仍不放弃是愚蠢的。宗教等抽象问题的关键往往是基本概念及其含义，相关事实证据可能无关紧要。

## 论证推理链

**论据**

上列各条均附课堂与公共讨论中的实例：圣经循环、宗教体验的小圈、药品立法的滑动目标、监狱自由的换义、心脑讨论中的神经学八卦、萨特被漫画化、刑讯证人对抗「好人统治者」演绎。

**推导**

非形式谬误的共同点不是「违反三段论格式」，而是论证没有做它假装在做的事：没有把理由连到结论，或中途换了问题、换了词、换了对手、换了方法。重言式提醒：有效也可以空洞。良性循环提醒：互相支撑的世界观不是小圈，但必须被充分组织，不能用小圈冒充。

**结论**

出现以上任何一种几乎都令人窘迫，且往往危及整个论证。若意见重要，就用最好的论证支持：巧妙结合演绎与归纳，辅以类比和对其他立场的恰当批评。

**启示**

选择论证类型要匹配问题：事实争议让路于归纳证据；概念与含义问题走演绎。权威要用对领域。

除了本章主要内容外，作者还讨论了/提及了：1. 重言式作为「形式有效但无用」的极限，2. 民意调查是「只需断言」的例外场合，3. 礼仪小姐该用哪副叉子作为问对权威的日常例，4. 寒蝉效应的法律释义，5. 课堂上特别盛行分散注意力。

## 段落总结序列

### 非形式谬误总说与断言、循环

主旨：1. 形式有效仍可能是坏论证。2. 只作断言、循环论证和恶性循环都没有真正给结论新理由；良性循环则是整套世界观。

最小标签集：陈述；必要依据；可替换例证；限定。

1. 【第三档·过渡/场景】附录题：常见的非形式谬误。
2. 【第一档·陈述】许多论证形式有效却仍是谬误；重言式直接有效但对讨论无推进。
3. 【第一档·陈述】只作断言：接受一种观点不足以让别人相信；除民意调查外每种意见都需要论证；常识被挑战时也必须论证。
4. 【第一档·陈述】循环论证把待证结论当前提；诉诸《圣经》劝人信基督，对不信《圣经》者无效。
5. 【第二档·可替换例证】「这本书能提高分数，因为它帮你考得更好」是改装过的结论。
   （本段旁证第4段）
6. 【第一档·必要依据】恶性循环用 B 证 A、C 证 B、A 证 C；宗教场景与「他就是罪犯」是例。
   （本段是第4段的必要依据）
7. 【第一档·限定】信念体系内部互相依赖可称良性循环（宗教与无神论、市场与马克思主义的长期争论）；恶性循环只是粗心。
   （本段限定第6段）

### 离题到改变含义

主旨：1. 不谈正题、攻击人、结论滑动或中途换义，都不能算在辩护原主张。

最小标签集：陈述；可替换例证。

1. 【第一档·陈述】离题是抛别的东西不谈正题，或可拖垮对方，但不能说服。
2. 【第一档·陈述】人身攻击品评外表声誉等，至多有助于理解动机，不能证明或否证观点，量多了害己。
3. 【第一档·陈述】结论含糊或每段变动，使观点无考虑价值；服药惩罚若分不清海洛因与阿司匹林或从「非法」滑到「对身体有害」，目标已失。
4. 【第一档·陈述】改变含义使表面有效的论证得出悖谬结论；监狱「自由」换了心理/身体二义。
5. 【第二档·可替换例证】密尔「想要的就是值得要的」被指利用英语含糊；被欲求的不必应当被欲求。
   （本段旁证第4段）

### 分散注意力、伪问题、权威与隐喻

主旨：1. 题外话、伪问题和问错权威把讨论带进死胡同。2. 滑坡隐喻常伪造不可避免性。

最小标签集：陈述；可替换例证。

1. 【第一档·陈述】分散注意力是没完没了谈偏离主题的话；时间有限时特别有利，课堂上盛行。
2. 【第二档·可替换例证】神经学家大谈手术与哲学家的愚蠢，若与心脑关系无关就只是消遣。
   （本段旁证第1段）
3. 【第一档·陈述】伪问题基于无意义假设，无法回答；心—身如何联系、全能山是常被举的例子。
4. 【第一档·陈述】大多数知识基于权威，但问错领域或把印刷物当权威即不可靠的权威。
5. 【第一档·陈述】滑坡隐喻让人以为踏出一步必滑到底（寒蝉、多米诺）；禁止礼堂喊着火并不必然取消一切政治讨论。

### 稻草人、感情、力量与方法错配

主旨：1. 假想对手、感情和暴力都不能代替理由。2. 在该用归纳处死守演绎（或相反）是方法谬误。3. 最好的论证结合两种推理。

最小标签集：陈述；可替换例证。

1. 【第一档·陈述】攻击稻草人是不打真实对手，转打易倒的假想对手。
2. 【第二档·可替换例证】把萨特「绝对自由」解释成能扇耳朵飞月，并以为就此驳倒他。
   （本段旁证第1段）
3. 【第一档·陈述】诉诸同情及其他感情可刺激行动，在哲学中有合法位置，但本身不是对特定立场的论证。
4. 【第一档·陈述】诉诸力量：身体力量不能造就哲学正确性；人可被威吓却不因此被驳倒。
5. 【第一档·陈述】不恰当的论证：归纳证据成堆时仍演绎「好人不允许刑讯」，或宗教概念问题却去堆事实，都是方法错误。
6. 【第一档·陈述】出现这些谬误几乎都令人窘迫且危及全盘；要用最有说服力的方式，把演绎与归纳结合起来，辅以类比和恰当批评。
