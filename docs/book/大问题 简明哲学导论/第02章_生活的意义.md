# 第02章 生活的意义

## 本章位置

第一章先问「哲学是什么」，把明确表达、论证和概念框架立为工具；本章转入全书第一个实质性大问题：生活有没有意义、意义在哪里、用何种隐喻去过。开篇用托尔斯泰《伊凡·伊里奇之死》把「也许我过去生活得不对头」抛到读者面前，再以加缪的西西弗斯把日常忙碌写成可能的荒谬。作者先拆「意义」一词（指向、语境、外在答案只会延后问题），再列出历史上和学生试卷中反复出现的生活隐喻，强调这个问题既是发现也是创造。下一章才进入「上帝」；本章已表明：单凭信仰上帝并不能结束追问。

## 核心论点

1. **生活意义是最难回答、最需要回答、又最模糊的大问题。**「意义」一词本身不明确，回答并不总是可用论证辩护的字面真理；但正是理性才使回答成为可能，才使追问成为必然。
2. **把意义理解成「指向生活之外的某物」只会把问题延后。**孩子、上帝、来生，以及「生活毫无意义／荒谬」，每一种都可能在个人生活中无比重要，但都没有在生活之中给出答案。
3. **意义必须在语境中找到。**词的所指只在意义共同体里才可能；类比地，生活的意义只能在生活情境中找到，不能诉诸生活以外。真正为上帝或孩子而活的人，那件事就回答了意义。
4. **外在意义不等于生活的意义；上帝不在场推不出生活无意义。**加缪有时用无神论为荒谬辩护，作者指出这一跳跃不成立。
5. **虚无主义也可以赋予生活一种意义。**若人真正把生活致力于「生活毫无意义」，清掉通常赋予生活的、有时自以为是、错误而有害的意义，虚无主义同样可以成为一种过法（加缪近于此）。
6. **这个问题更像不可或缺的隐喻或洞察，并且是一种创造活动。**它让人看出自己在扮演何种角色、有哪些合理期待；对它的看法从多方面决定未来走向。哲学既表述已有世界观，也参与塑造世界观。
7. **对生活的看法决定人能在其中发现的意义。**游戏、故事、悲剧、喜剧、使命、艺术、冒险、疾病、欲望、涅槃、利他、荣誉、学习、苦、投资、关系等隐喻各有不同的成功标准与危险；清单不可能完整，读者可以加入更好的看法。

## 关键概念补全

**意义（作为所指）**：日常里一个标记或词的「意义」常常等于它指向的、超出自身的东西（「小心狗」指向某条凶狗，「苏格拉底」是苏格拉底的名字）。本章要表明：若把整个人生也理解成这种「指向」，就会把意义推到孩子、上帝、来生或「什么也不指」上，问题只是被延后。

**语境／意义共同体**：一个词能有所指，必须在某种语言或实践共同体之内。「pepino」（西班牙语「黄瓜」）对不说西班牙语的人没有意义；高尔夫球手喊「fore!」（前面当心）对不打球的人不知所云。作者用这个语言学事实类比：生活意义也只能在生活情境中找。

**荒谬**：用来表达「生活并无意义」的常用词。加缪认为荒谬感已成为时代的共同感受：日常节奏（起床、电车、工作、吃饭、睡觉，星期一到星期六）某天突然冒出「为什么」。荒谬不等于「不值得过」：加缪主张通过反抗荒谬、拒绝参与不公、尽情享受生活，使生活值得过。

**虚无主义**：认为生活毫无意义。作者指出一个反讽：若人真正按这一命题生活，清掉错误有害的「意义」，虚无主义本身也可以赋予一种意义。

**西西弗斯**：希腊神话中被罚永远把巨石推上山顶、石头再滚落的人。加缪用来写劳动的无用与无望；又强调主人公有意识，下山时的洞察同时完成胜利，「应该设想西西弗斯是幸福的」。开篇问题 4 即问生活是否像这一使命。

**永恒轮回**：尼采《快乐的科学》中的思想实验：有恶魔说你现在和过去的生活将周而复始、绝无新意。你是瘫倒咒骂，还是称之为神圣？这被写成「人人必须回答的问题」和「最沉重的负荷」。

**乌托邦**：哲学家用来称呼人们为将来抽象谋划的全然安宁快乐之地。用「孩子的孩子……将生活在乌托邦」来给自己的生活赋义，仍会把「乌托邦里的人活着为了什么」留在原地。

**教育小说**：19 世纪德国哲学用来称呼生活的一种说法，即青年人在追求、失望和发现中的个人发展。作者把它放在「生活是一个故事」之下，强调时间性的情节与个性连续展开。

**涅槃**：梵语意思是「处于平和状态」；佛教目标是减少对欲望的执着，达到没有东西能打扰的宁静，并包含直面死亡时的镇定。弗洛伊德早期称「恒常性原则」，后称「涅槃原则」，有时也叫「求死的愿望」。

**利他主义**：即使对自己没有任何好处，也要为他人利益而行动。可以是单向的（帮助别人以赋予自己的生活以意义、不期待回报），也可以是普遍理想（希望有朝一日每个人都无私地帮助所有人）。

**斯多亚派哲学**：约公元前 300 年到公元四五世纪。把人类大多数欲望和情感视为非理性，主张控制激情，过正直、有责任的简朴生活，看重荣誉感和正义感甚于无常的生活。代表包括塞涅卡、马可·奥勒留。

## 一、开篇题辞与开篇问题

### 论证推理链

**论据 / 案例 / 事实**

- 章首图为雅克-路易·大卫《苏格拉底之死》：苏格拉底在牢中受刑，后文「荣誉」一节会回到他为原则而死。
- 题辞出自托尔斯泰《伊凡·伊里奇之死》：伊凡突然想到「也许我过去生活得不对头」，随即自辩「我做什么都是兢兢业业的」，又立刻把这唯一能解决生死之谜的想法当作完全不可能的事，从脑子里驱逐掉。
- **开篇问题 1（填空「生活是……」）**作者先给一组例句，再追问你的答案、你怎样看自己、最终的目标、期待、希望和恐惧是什么。例句包括：生活是一幅拼图（你不知道最终图样，甚至不知道是否已拿到所有碎片）；生活是一个迷宫（你总试图避开出口）；生活是一场扑克游戏（需要运气，既可能以大对子胜出，也可能以一手清一色落败）；生活是输赢（少数人是赢家，大多数人是输家）；生活是一场冒险；生活是一种学习经历；生活是一种恩赐；生活是受苦。
- **开篇问题 2**：假定天使在云端注视人类，像我们端详一窝终日忙个不停的蚂蚁。天使会怎样评价这种忙碌？在天使眼中这种生活是什么样子？
- **开篇问题 3**：举出三四种你不希望今生无法了结的事情。其中有多少已经做完或已经开始？哪些是你现在本可以做却没有做的（为什么没有）？
- **开篇问题 4**：加缪认为生活像西西弗斯：被罚把石头滚上山，到顶又滚落，于是一切从头再来，直到永远。生活真的像这样吗？为什么？
- 正文起句：生活的意义是什么？这是最难回答、最需要回答、同时又最模糊不清的大问题。认真的读者往往回避正面作答，因为很难说清楚。「意义」的意义本身不明确，回答并不总是一种字面上的真理、可以用论证和理性加以辩护。然而正是理性才使回答成为可能，才使追问成为必然。本章将思考生活意义的某些可能基础，然后讨论一些候选的有意义的生活类型。

**论证推导过程**

先用伊凡·伊里奇的自我驱逐表明：生死之谜的入口往往是「我是否生活得不对」，而非常体面的兢兢业业可以把这个想法赶出去。开篇四问逼读者先交出自己的隐喻、外在视角、未了结之事和对重复劳动的判断，而不是先背哲学家的定义。引论则把问题的模糊性说成不可回避：不能因为「意义」含混就拒绝理性。

**核心结论**

进入候选答案之前，必须先承认问题既必需又含混，并已经用自己的填空和判断占了一个位置。

**延伸推论 / 现实启示**

后文明确说：对开篇问题 1 和问题 4 的回答，将对你可能持有的生活态度给出相对清楚的说明，即使答案显得滑稽或富有诗意——正是在戏剧、诗歌和做严肃哲学的时候，看法才变得明晰。

## 二、什么样的意义

### 论证推理链

**论据 / 案例 / 事实**

- 对大多数人来说，生活意义的问题最可能在情绪低落或命运多舛时产生，这时头脑大都混乱。日常生活里，当不对事情做哲学思考或一般性思考时，生活似乎充满意义：有试要考，有汽车滤油机要更换，有宴会要参加，有数天后的重要面试要准备。
- 一旦不得不抽象思考，就会发觉这些小目标和期待无一能担负起生活的意义。精力转向更大的事情：快乐、事业、成功、权力和爱情。然而好景不长，《传道书》的预言隐隐传来：「万事皆空。」于是开始超越生活本身来寻找生活的意义——这也是哲学的最终问题。
- 「意义」有时就是一个标记或词所指向的、超越自身的东西。「小心狗」可能指向某条看不到的很大很凶的狗；「苏格拉底」就是苏格拉底的名字。若这样理解，每个人生活的意义就是他的生活所指向的无论什么东西。
- 候选所指：周围的其他人（家庭、朋友、同事），故意义就是他人；更大的共同体、国家或整个人类；造物主，故意义就是上帝。但「指向」在此处很单薄：完全可以反驳说生活并不指向任何东西，生活就是生活。这似乎并未提供答案；也许问题出在把意义当成它的所指上。

**引文资料：生活的意义（《传道书》，公元前 3 世纪）**

传道者说：虚空的虚空，凡事都是虚空。人在日光之下的劳碌有什么益处？一代过去，一代又来，地却永远长存。万事满有困乏，人不能说尽。眼看，看不饱；耳听，听不足。已有的事，后必再有；已行的事，后必再行。日光之下，并无新事。

他以喜乐、嬉笑、酒、愚昧、大工程（房屋、葡萄园、园囿、水池、仆婢）试验自己，查看手所经营的一切，都是虚空，都是捕风，在日光之下毫无益处。

他转念观看智慧、狂妄和愚昧：智慧胜过愚昧如同光明胜过黑暗，但这两等人都必遇见同一件事（死亡）。于是恨恶生命，因为日光之下所行的事都是烦恼、虚空、捕风。

总意：敬畏神，谨守他的诫命，这是人所当尽的本分；人所做的事，连一切隐藏的事，无论善恶，神都必审问。

**指向需要语境**

- 个别的词和标记有所指，必定是在某种语境或意义共同体之内才可能。「pepino」对不说西班牙语的人没有什么意义；「fore!」在不打高尔夫的人听来不知所云。
- 每一种特定活动的意义可以由习俗和它的目的来解释（「他这样做是为了给招聘者留下深刻印象」，或「他这样做是为了发出左转弯的信号」）。但能以类似方式解释全部生活的意义吗？极少数人可能把全部生命奉献给唯一目标，如赢得革命胜利，或寻找癌症的治疗办法。大多数人却不可能如此一心一意，生活并不能这样简单地加以规定——但这并不意味着他们的生活缺乏意义。
- 可以问「pepino」一词的意思是什么，却不能从理智上对整个语言的意义发问（「西班牙语的意义是什么？」这样的问题没有任何意义）。因此或许可以说，追问整个生活的意义是没有意义的；但这似乎说明我们不可能给出这一关键问题的解答。
- 当人们问及生活的意义时，头脑中想到的往往正是这些外在于生活的超越的东西。它们可能极为重要，甚至就是生活中最重要的东西。但在某种意义上，这并没有彻底解决问题，而只是把它延后了。有四种回答值得说一说：孩子、上帝、来生，以及在绝望中忙不迭地认为生活没有意义。

**论证推导过程**

日常忙碌把意义「填满」，抽象思考把小目标抽空，于是目光被推到生活之外。若坚持「意义＝所指」，所指候选（他人、共同体、上帝）都经不起「指向」这一薄概念的追问；「生活什么也不指」又像拒绝回答。语言学类比把问题转了一层：局部活动可以像词一样在语境里解释，整个人生却不像「整门语言」那样可以被问「意义是什么」。作者既不接受「问题无意义所以不必答」，也不接受「到生活之外找一个所指就算答完」。

**核心结论**

先要问的不是「生活指向什么」，而是「意义」在何种意义上被使用；把意义当成所指，会把关键问题延后而不是解决。

### 孩子作为意义

**论据 / 案例 / 事实**

许多人会说，生活的意义在于他们的孩子以及他们孩子的孩子。仔细琢磨会得到一个奇特推论：若意义不在我们自己的生活而在他人的生活，那么什么使他人的生活有意义？——他们的孩子；再下一代，依此类推。人们总试图以这种方式为将来抽象谋划一个全然安宁快乐的地方（乌托邦），希望孩子或更远的后代生活在那里。但这怎样使自己的生活有意义？对那些快乐地生活在乌托邦中的远亲来说，生活的意义又是什么？问题依然存在。

成功的配偶往往会一起回首共同奋斗过的岁月，并且认为那才是度过的最美好的时光。这符合「最终安宁的乌托邦才是生活意义」吗？难道快乐本身就显然是生活的意义吗？

**核心结论**

把意义外包给后代或乌托邦，会形成无穷后推；连「奋斗岁月比安宁更美好」也与「乌托邦＝意义」不合。

### 上帝作为意义

**论据 / 案例 / 事实**

一种传统回答是：上帝。常听到的观点是：对信仰上帝的人来说，这个问题根本不成其为问题；在上帝的存在受到怀疑之前，生活的意义从不会成为困惑。作者说事实并非如此。大哲学家、最虔诚的基督徒奥古斯丁问这个问题的次数要多于任何无神论者；马丁·路德以及在他之前和之后的许多基督教思想家也是如此。

认为单凭信仰上帝就回答了生活的意义，只是又把问题回推了一步。上帝为什么要创造我们？为什么恰恰是我们？他指望我们什么？有些人认为上帝把我们创造成为某种特殊的东西：不仅「按着他的形象造的」，而且为了代他完成使命来到地球。然而，如果他是无所不能的，为什么还要这样做？是为了证明什么（向谁证明）？是为了满足虚荣心吗？（《旧约》中的耶和华首先是一个不容违抗的上帝，可能也就是一个虚荣的上帝。）我们为什么要认为自己被创造出来是为了实现某种特殊使命或目的？如果确实如此，什么才是这个使命或目的？基督教大思想家早已认识到，问题还停留在原处。信仰上帝似乎只能使问题显得更为棘手，而并没有解决它。

**核心结论**

信仰并不自动取消意义问题；它把「我们为什么在这里、要做什么」问得更具体，因而往往更难。

### 来生作为意义

**论据 / 案例 / 事实**

有些人认为生活的意义可以在作为今生之回报的来生中找到。不论你是否相信有这样一个「来生」，这种形式的回答总是很奇怪：认为今生今世只相对于来生才有意义，就等于说——像《传道书》所说——今生是无关紧要的和没有意义的。那么在这个无足轻重的今生中，应当如何行事才能使来生得到报偿？仅凭信仰？善行？尽情享受生活？发掘艺术潜质或社会潜力？使异教徒皈依？学习烹饪？问题又在原地打转。

可以追问：如果今生如此无关紧要，什么才能保证来生更有意义？是此世短暂、彼世长久吗？但如果生活本身——哪怕只是其中的几分钟——是无关紧要的，永恒的生活又有什么意义？如果一堂课上了一个小时已经厌倦，被告知还要再上 10 个小时，一定会更加厌倦。另外，基督教思想家、特别是过去几个世纪的基督教思想家常常认为，只有对于那些尽情享受今生的人来说，来生的报偿才是可能的。于是问题又出现了：怎样才算尽情享受生活？发现今生是有意义的是什么意思？

**核心结论**

用「更长的来生」给「无意义的今生」赋义，在逻辑上站不住；连传统神学也常常把问题送回今生如何过。

### 没有任何意义（荒谬）

**论据 / 案例 / 事实**

一些哲学家以及今天的许多学生持另外一种意见：生活其实没有任何意义。用语通常是「荒谬」。「生活是荒谬的」也就是生活并无意义。信仰或不信仰上帝的人都会持有这种看法，尽管最极端、最彻底的表述均源自那些没有信仰的人。法国哲学家阿尔贝·加缪在《西西弗斯的神话》中说，荒谬已经成为我们这个时代的共同感受。

**引文（加缪）**：在任何一条街的拐角，荒谬感会袭上每一个人的脸孔。有时候布景倒塌了：起床，电车，四小时办公室或工厂里的工作，吃饭，电车，四小时的工作，吃饭，睡觉，星期一到星期六，总是一个节奏，大部分时间里都轻易地循着这条路走下去。仅仅有一天，产生了「为什么」的一问，于是，在这种带有吃惊色彩的厌倦中一切就开始了。

**与哲学家相遇：阿尔贝·加缪（1913—1960）**

加缪 1913 年出生于阿尔及利亚。他是直言不讳的新闻工作者，在政治上终生采取艰难的中立：一边是激进派和改革派，另一边是纳粹的严酷统治和殖民地的不公正待遇。第一部小说《局外人》使其在欧洲一举成名，直到今天仍是美国大学校园里最流行的小说之一。他的哲学基于：生活本质上是「荒谬」的，宇宙永远也不会满足我们对于意义和正义的期盼。然而这样回答并不是说生活就不值得过了，而是必须通过反抗这种荒谬性、通过拒绝参与世界的这种不公、尽情地享受生活，来使生活值得过。1960 年他不幸在一场车祸中丧生。

**四种外在答案的总评**

要指出的是，在一个人的生活中，这些答案中的每一个可能都是无比重要的。一个人当然可以全身心致力于培养自己的孩子，把生命全都奉献给上帝也是可能的（尽管人们通常说得多、做得少）。然而这些体面的回答并未解决我们的问题，因为它们仅仅是把问题沿着原有方向推进了一步而已。我们孩子的生活意义是什么？人应当怎样服务于上帝？我们要的答案是在自己的生活之中，而不是在它之外。

对于认为生活毫无意义或荒谬的看法，同样的话也适用。加缪有时会基于自己的无神论来为这种观点辩护：如果没有外在的意义，那就不会有任何意义。但外在的意义未必就是生活的意义，况且由上帝的不在场（如果他果真不存在的话）并不能推出生活就没有意义。

**引文资料：「永恒轮回」的思想（尼采《快乐的科学》，1882）**

最沉重的负荷——假如有个恶魔在某一天或某个夜晚闯入你最难耐的孤寂中，并对你说：「你现在和过去的生活，就是你今后的生活。它将周而复始，不断重复，绝无新意。你生活中的每种痛苦、欢乐、思想、叹息，以及一切大大小小、无法言说的事情都会在你身上重现，而且均以同样的顺序降临……」

你听了这恶魔的话，是否会瘫倒在地？是否会咬牙切齿，诅咒这个口出狂言的恶魔？你以前或许经历过这样的时刻，那时你回答恶魔说：「你真是神明，我从未听见过比这更神圣的话呢！」

倘若这种想法压倒了你，恶魔就会改变你，说不定会把你碾得粉碎。「你是否还要这样回答，并且一直这样回答呢？」这是人人必须回答的问题，也是你最沉重的负荷。或者，你无论对自己还是对人生，均愿安于现状，放弃去追求比这最终的永恒更为热烈的东西吗？

**引文资料：西西弗斯和巨石（加缪《西西弗斯的神话》，1942）**

诸神处罚西西弗斯把一块巨石不断地推上山顶，石头因自身的重量又从山顶上滚落下来。他们有某种理由认为，最可怕的惩罚莫过于既无用又无望的劳动。

如果说这神话是悲壮的，那是因为它的主人公是有意识的。如果每一步都有成功的希望支持着他，那他的苦难又将在哪里？今日之工人劳动，一生中每一天都干着同样的活计，这种命运是同样地荒谬。因此它只在工人有了意识时才是悲壮的。

西西弗斯，这神的无产者，无能为力而又在反抗，他知道他的悲惨状况有多么深广：他下山时想的正是这种状况。造成他的痛苦的洞察力同时也完成了他的胜利。没有轻蔑克服不了的命运。

登上顶峰的斗争本身足以充实人的心灵。应该设想，西西弗斯是幸福的。

**收束：意义在生活情境中；虚无主义也可以赋义**

语言学家们现在认为，意义必须在语境中才能找到。一个词之所以有意义，并非仅仅因为它的所指，而更是因为它在语言中的含义。于是也可以通过类比说：生活的意义只有在我们的生活情境中才能找到，而不能诉诸生活以外的什么东西。对于一个真正为上帝活着的人而言，把自己献给上帝回答了生活的意义；对于一个真正为孩子活着的人而言，孩子回答了生活的意义。

具有讽刺意味的是，只要一个人能够真正把生活致力于「生活毫无意义」这一命题，把人们通常赋予生活的、有时是自以为是的错误而有害的意义清除掉，那么虚无主义——即认为生活毫无意义——同样可以赋予生活一种意义。加缪似乎就是以这种方式活着的。

**论证推导过程**

四种「体面」答案（孩子、上帝、来生、无意义）都把求解方向指到生活之外或对生活的否定。作者用同一把尺子量它们：只要答案不在「自己的生活之中」，问题就被沿原方向推进一步。加缪的无神论跳跃（无外在意义 → 无任何意义）被单独拆开：外在意义不是生活意义的唯一样式。尼采的永恒轮回把「你是否愿再过一遍同样的生活」变成检验，加缪的西西弗斯把有意识的反抗写成幸福的来源。最后用语言学类比落地：真正投入某种生活（包括真正投入虚无主义）才构成意义，而不是先在生活外面找一个所指。

**核心结论**

要的答案在生活之中。真正为某事而活（包括真正按「无意义」而活）可以赋义；仅仅宣布一个外在答案或宣布荒谬，并不自动完成这一步。

**延伸推论 / 现实启示**

后文所有隐喻（游戏、故事、使命等）都应读成「在生活情境中创造意义」的候选方式，而不是新的外在所指。

## 三、生活的各种意义

### 论证推理链（总论：隐喻、创造、看法决定意义）

**论据 / 案例 / 事实**

节前四则题辞：

- 毕达哥拉斯（公元前 6 世纪）：生活就像奥林匹克赛会；聚到这里来的人通常抱有三种目的：有些人摩拳擦掌以折桂，有些人做买卖以赢利，但还有一些人只是单纯作旁观者，冷眼静观这一切。
- 塞缪尔·巴特勒（1612—1680，英国诗人）：生活就像公开演奏小提琴，在演奏的同时学习这门乐器。
- 无名氏：生活是一碗樱桃（老歌名，意思是一碗樱桃里总是有酸有甜，生命也是苦乐兼备）。
- 罗德尼·丹杰菲尔德（1921—2004，美国喜剧演员）：生活是一碗果核（对前一句的曲解，为笑谈）。

生活的意义问题不是那种需要给出或能够给出确切答案的问题。它更像是一则不可或缺的隐喻，或是对生活的看法和洞察，从中可以看出自己正在扮演何种特定的角色，有哪些合理的期待。这个问题之所以重要，是因为你对它的看法从多方面决定了你未来生活的走向。

例：你抱着生活就是「狗咬狗」和人人为我的态度去经商或上学，就会把所有人都当作自己的威胁和对手；不会做到完全诚实，而且无论如何都不会从与他人的交往中得到乐趣。人们会逐渐觉察到你的竞争敌意，开始不信任你，甚至偶尔用一些让你恼火的行为来检验你的意图。于是不久就将发现自己的确身处一个「狗咬狗」的气氛中——这种气氛在很大程度上正是你自己造出来的。

所以生活意义的问题并非只是发现的问题，它也是一种重要的创造活动。你自己的哲学仅仅在部分程度上是对你已有世界观的表述和澄清，因为你所提出的哲学也将为这种世界观的形成提供一臂之力。于是，有些对世界持一种晦暗的悲观情绪的哲学家，会故意把他们的哲学表述得甚为欣喜和乐观，这不是为了欺骗自己，而是为了改变自己，其中的确有一些人获得了很大的成功。

正是我们对生活的看法决定了我们在其中所能发现的意义。于是，你对开篇问题 1 和问题 4 的回答将对你可能持有的生活态度给出一个相对清楚的说明，即使答案显得滑稽或富有诗意（正是在戏剧和诗歌中，以及做严肃哲学的时候，我们的看法才变得明晰起来）。若认为「生活是一场游戏」，意思是说生活不应当非常严肃地对待（不论你自己是否严肃对待了），生活最终不会增添任何东西，最好的生活方式就是去享受它。若认为「生活是上帝的恩赐，应当明智地加以利用」，意思是说生活实际上是严肃的，它多少有着确定的使命（这一点你必须去领会），而且何谓成功、何谓失败（在上帝面前）也是比较清楚的。

下面将简要描述几种关于生活的主要看法，无论是在历史上，还是在学生的试卷中，这些看法都时常出现。这张清单不可能完整，你也可以把自己的某些看法加进去，说不定会比列出的几种还要好。

**论证推导过程**

确切答案被放下，换成隐喻：隐喻规定角色和合理期待，并反馈到你如何对待他人，从而部分地「造出」你所相信的那种生活。因此哲学不只是描述已有世界观，也是改造它的杠杆。开篇填空不是热身游戏，而是诊断仪。

**核心结论**

生活意义首先是你用来过生活的那则隐喻；它既被发现，也被创造。

**延伸推论 / 现实启示（实操）**

课堂与自学用法：先写下开篇问题 1、4 的答案，再对照下列隐喻；故意把悲观处境写成另一种哲学，不是自欺，而是作者承认有效的自我改变方式。清单开放，鼓励增补。

### 生活是一场游戏

若生活是一场游戏，那么它就不会被严肃地对待。游戏是一种自足的活动，即使它的确增添了某种东西（如打篮球提高协调能力，跑步提高耐力），游戏的意义也在于玩本身（输赢并不重要，重要的是怎样去玩）。不过，有人因此便会以狂热的竞争眼光来看待游戏，所以才有文斯·隆巴迪（Vince Lombardi，1913—1970，美国职业橄榄球教练）那句著名的话：「胜利不是一切，而是唯一！」以这种方式来看待生活，就是把生活当作一场不间断的你死我活的斗争。因此，若认为生活是一场游戏，追问一下这种游戏属于何种类型是重要的。

有些游戏仅仅是为了消遣，有些是为了证明你的优越（掰腕子），另有一些则是为了消磨时间（单人纸牌）；有些别具交际性（桥牌），有些则是有意制造紧张（下高赌注的扑克）；有些在伤害对手（拳击），有些则是为了帮助别人（如借助游戏来资助慈善事业，看谁能为同一目标筹款最多）。

许多作家都曾把生活看作一种游戏。三十多年前排在畅销书榜首的就是埃里克·伯恩（Eric Berne，1910—1970，美国心理学家，20 世纪 60 年代创立沟通分析理论 TA 用于心理治疗）写于 1964 年的《人们玩的游戏》（*Games People Play*），它是 TA 理论的奠基著作之一。有些哲学家也认为，语言、经济学和哲学本身都是游戏。认为生活是场游戏，是用一种特殊的眼光考察生活，避免把它看得太过严肃，同时也是为了强调一些东西：对规则的遵守、「生活要精彩」、享受生活、要尽力争取成功等。然而我们却往往以一种危险的方式来谈论「胜败」。比如，当我们将世界杯亚军称为一帮「败将」时，我们给自己定下的标准又是什么呢？

**核心结论**

「游戏」隐喻的要点是自足与玩法，不是好胜；若不先问是哪一种游戏，它会滑成你死我活，并用「败将」一类话说出苛刻标准。

### 生活是一个故事

「生活是对艺术的模仿。」相对于柏拉图的「艺术是对生活的模仿」，英国剧作家和散文家奥斯卡·王尔德曾这样针锋相对地写道。显然，我们的生活并不是断断续续的，也不是朝向唯一一个大目标的，而是因循着某个相当详尽的剧本、故事或传记不断展开着的，我们（至少在某种程度上）一边前行，一边构造着这个剧本。故事的轮廓以及我们所扮演的角色可能首先是由我们的家庭和文化所赋予的，其次是由我们身处的环境赋予的。把生活当作一个故事，就是以一种特殊的时间方式来思考生活，把生活看成不断展开的情节和个性的连续发展（19 世纪的德国哲学家称生活为一种「教育小说」，即一个青年人在经历生活中各种追求、失望和发现的过程中的个人发展）。

当我们做出生活中的决定时，经常发现自己所使用的标准也正是评价文学作品或电影时所采用的标准：它有趣吗？令人厌烦吗？有悬念吗？是否得体？时机选得如何？是否过分？这种做法符合主人公（即你自己）的性格吗？美国小说家约翰·巴斯（John Barth，1930— ）在《路的尽头》中暗示，我们每个人都是自己故事中的主人公。他写道：「波洛纽斯这个人物并不认为自己是《哈姆雷特》中的一个小人物。」《哈姆雷特》可以从波洛纽斯的角度加以重写，正如剧作家汤姆·斯托帕德的确已在其《罗森克兰茨和吉尔登斯特恩已死去》中从两个更不重要的人物的角度重写了《哈姆雷特》。

（关于巴斯：其小说将辛辣讽刺、犀利粗俗的幽默与深奥复杂的哲理融为一体，许多作品描写在一个没有绝对价值的世界里，人似乎不可能选择正确的行动。关于斯托帕德：捷克裔英国剧作家；罗森克兰茨和吉尔登斯特恩本是《哈姆雷特》中受篡位国王之命陪伴哈姆雷特去英国的两个朝臣，斯托帕德将这段情节放大，两个弄臣反配为主；主题是人只不过是一个处于更大系统之中的、由不可理解的力量所主宰的小角色而已。）

当然，《哈姆雷特》是一部悲剧，但有些人是按照喜剧或闹剧的方式生活的，还有一些人则按照冒险故事的方式——选择那些有挑战性的工作或危险的嗜好——来生活。他们不失时机地做一些富有戏剧性的事情，为的是给自己的光辉履历添上几笔。在这种观点看来，赋予生活以意义的不是终极的目标或生活的结局，而是故事的质量、一个人生活和扮演角色的质量。如果选错了角色（选择了不适当的或高于自己能力的角色），或者没有意识到自己的角色，或者扮演了多个相互矛盾的角色，都会毁掉一个人在生活中所发现的意义。

**核心结论**

故事隐喻用情节、性格与角色质量代替「唯一大目标」；意义毁于错角、无意识和互相矛盾的角色，而不是毁于没有结局。

### 生活是一场悲剧

毫无疑问，我们每个人都会死。但这个事实往往会被忽视，死亡会被看成一件倒霉事、通往来生的路或最终的灾难。如果我们把自己的生活看得少一些戏剧性，视之为《哈姆雷特》《麦克白》《奥赛罗》或《浮士德》的稍逊一些的版本，那么就会发现，我们每个人身上都有悲剧的一些关键要素（某些悲惨的缺陷、判断的错误、严重的矛盾等），它们伴随着我们的一生，直到最后与死亡同归于寂。在小说《局外人》的结尾，加缪让一个角色说出：「人人皆为兄弟，等待他们的是同一个结局——死亡。」与游戏隐喻相反，悲剧隐喻把生活变成了一个严肃的、不愉快的过程，尽管偶尔也会碰上一些快乐的事情，但生活终将有一个不可抗拒的悲惨结局。在这种观点看来，活得好意味着把一个人的悲剧角色扮演好——英雄式地承受它，也许时而孤独地发出几声哀鸣。

**核心结论**

悲剧隐喻以死亡为不可抗拒的结局，把「活得好」定义成把有缺陷的角色承受到底，与「游戏不必严肃」正相反。

---

### 生活是一场喜剧

「生活是一个玩笑。」也许并非如此，但相对于把生活当作悲剧，这样想或许能使人重新振作起来。长期以来，笑作为生活中的一个要素，甚至是作为好生活所特有的要素，是备受忽视的。关于笑，柏拉图没有费多少笔墨，不过在其苏格拉底对话中，他确实赋予了幽默以很深的含义。16 世纪的荷兰哲学家伊拉斯谟写了一本有关人类生活的非常深刻的书，名曰《愚人颂》，即是对人的愚蠢进行颂扬。尼采所虚构的先知查拉图斯特拉教我们不要太过严肃，要享受欢笑与无常。

**引文资料：等死（加缪《局外人》，1942）**

默尔索在狱中等待被处决。白天他考虑上诉，总是想到最坏的一面，即上诉被驳回。「那么，我就去死。」不会有别的结果。但是谁都知道，活着是不值得的。30 岁死或 70 岁死关系不大，因为不论哪种情况，别的男人和女人就这么活着，而且几千年都如此。反正总得死去，现在也好，40 年后也好。推理中使他为难的，是想到还要活 40 年时心中所产生的可怕飞跃；不过在设想 40 年后会有什么想法时，把它压下去就是了。假如要死，怎么死、什么时候死都无关紧要。所以（困难的是念念不忘这个「所以」所代表的一切推理）上诉如被驳回，他也应该接受。

幽默有各种各样的：既有好的，也有糟的；既有令人不快的，也有冗长杂乱的。有些思想家可能会强调幽默所含深意的重要性，但另一些人会说，笑本身就是重要的，而不应是笑声背后的东西。不过，笑话应当在短时间内就能奏效，一个花费过长时间去讲笑话的人很容易使人觉得乏味。然而也有一些更为严肃的喜剧，它们不是一个劲地做诙谐独白，而是关于抱负与挫折、欲求与失望的一个个故事。它们没有用加缪所说的「荒谬」进行加工，而是赋予荒谬一种幽默的含义。

悲剧和喜剧可以在「黑色幽默」或讽刺中融合起来。在由亨弗莱·鲍嘉任男主角、约翰·休斯顿任导演兼编剧的影片《碧血金沙》的结尾，那位老人（由约翰·休斯顿的父亲沃尔特·休斯顿扮演）失去了一切，但他却突然放声大笑，并鼓励其他人也这样去做。对于这样一个关于贪婪、失望与死亡的故事来说，这也许是唯一可能的「欢乐收场」。无可否认，我们每个人都可以更多地使用一些幽默，但不是用在我们的生活中（电视已经提供得够多了），而是用在我们对生活的态度上，用在我们审视自己弱点和不足的方式上。

**核心结论**

喜剧隐喻把笑从点缀升为好生活的要素；严肃喜剧给荒谬以幽默含义，黑色幽默让悲剧收场仍可能是一场笑。要用在态度和自我审视上，而不是再往生活里加笑料。

### 生活是一种使命

**与思想家相遇：约翰·沃尔夫冈·冯·歌德（1749—1832）**

歌德至今仍被认为是德国最伟大的作家。此外他还是科学家、律师、艺术家、冒险家、物理学家和政治家。他在植物学上做出了重大发现，还就牛顿的物理学写了不少文章。从简单的情诗到复杂的鸿篇巨制，著作实际上涵盖所有文学体裁，最著名的当数花费六十余载写成的《浮士德》。他曾经主张要「让诗歌讲德语」，后来黑格尔在哲学上继承了他。这两位伟人都把自己的著作基于生长的生物自然观，从而与牛顿之后在很大程度上占支配地位的机械自然观相抗衡。

基督徒经常教导说，生活是一种使命，是一种把他人也变成基督徒的使命。然而，把生活当作一种「召唤」的并不仅仅是基督徒。歌德把自己生活的使命描述为诗歌创作，以使德国人获得一种文化身份；哲学家黑格尔（大致与歌德同时）则把法国大革命之后用哲学来澄清世界的意义当作自己的使命；政治激进分子经常声称，自己生活的使命就是解放被压迫的人民，或是反抗自己国家的暴政；科学家有时会认为，自己的使命就是增加人类的知识或治疗某些可怕的疾病；有了孩子的人经常认为，他们的使命就是好好培养自己的孩子，尽力使他们生活得更好。如果一个人的使命首先是道德上的，那么这种使命就会依据其道德哲学进行表述。一个像边沁那样的功利主义者，会把一切行动都基于最多数人的最大幸福这一目的之上；而一个像康德那样的伦理理性论者则会说，我们的目标应当是培养我们的道德人格，通过履行理性所规定的义务来使世界变得更好。

**核心结论**

使命是一种有确定方向的召唤，不限于传教；一旦落到道德上，就会随功利论或义务论而写成不同的成功标准。

---

### 生活是艺术

「把你的生活当作一件艺术品去过。」尼采这样写道。他所认为的生活不是一个故事，而是一件像雕塑那样的艺术品。人的生活就是为自己打磨出一个形体，「塑造性格」，发展出所谓「风格」那样的东西。谢林把全部生活都视作上帝的艺术品（我们实际上就是上帝的学徒）。艺术家经常把生活的使命感简单地描述为「创造」，但在他们看来，创造活动本身与他们的努力结果是同样重要的。大致说来，这种看法就是主张要活得精彩，即使无法做到，也至少要活出风格，活出「格调」。由是观之，生活应被当成一件艺术品来评价——或令人感动、激动人心、设计合理、富有戏剧性、色彩斑斓，或粗俗不堪、冥顽不化、让人留不下记忆。

**与哲学家相遇：弗里德里希·尼采（1844—1900）**

尼采是德国哲学家。他一生中的大部分时间都在攻击基督教和基督教道德，还做出了一些关于女性的尖刻评论。他宣称自己是一个「不道德的人」，并且转而强调生活的审美价值。不过，他仍被公认为所有时代最伟大的道德哲学家之一（见第八章）。

**与哲学家相遇：弗里德里希·冯·谢林（1775—1854）**

谢林是德国哲学家，19 世纪早期浪漫主义诗歌的热情支持者和崇拜者。因此，他的哲学罕见地强调了创造力的重要性和艺术的中心地位。他所阐释的上帝不仅是一个创造者，而且从根本上说还是一个伟大的艺术家：至今仍在通过我们创造这个宇宙。谢林是黑格尔最要好的大学同窗之一，他们两人共同发展了他们的哲学，直到后来发生争执、分道扬镳。

**核心结论**

艺术隐喻用形体、性格、风格和创造活动本身来评价生活，而不是用故事情节或外在结果；尼采把它对立于基督教道德，谢林则把宇宙写成上帝仍在进行的艺术品。

---

### 生活是一场冒险

无论是把生活看成艺术还是一个故事，这都是令人振奋的，但这样一来，生活的价值就成了文学作品或雕塑的价值——它们的形态、合不合潮流、对旁观者的吸引等。但生活不必总是考虑整体的形态或在观者看来是什么样子，也可以富有美感和令人激动：「尽情享受」生活、听天由命、迎接挑战和刺激也会让人心动不已。把生活看作冒险就是此：一个人活着可以甘冒风险，让自己沉醉于各种技巧和不确定当中。这当然不是生活在所有人心目中的形象。中国有一则古老的咒语说：「祝你生活在有趣的时代！」（May you live in interesting times！常出现在美国报刊封面和讲演中。乍一看有趣的时代应当活起来更舒服；然而我们的时代虽然提供了各种各样的选择机会，但过多的选择对人也是一种折磨和压迫，所以才有这句极富讽刺意味的咒语。不过这句话其实并非来源于中国，而很可能是第一个说这话的人为了显示其神秘而故意归之于中国的。）但在那些的确这样对待生活的人看来，这也许是唯一的生活方式，任何其他方式都是乏味的和令人厌倦的。与把生活看作艺术或文学作品不同，把生活看作一场冒险不会预先规定一个恰当的结局。如果它要完结，那就完结好了。

**核心结论**

冒险隐喻拒绝为旁观者设计整体形态，也拒绝预先规定恰当结局；价值在风险、技巧与不确定本身。

---

### 生活是一种疾病

**引文资料：生活的意义（尼采《偶像的黄昏》，1889）**

在一切时代，智慧的人对生活都做了相同的判断：它毫无用处。无论何时何地，从他们嘴里听到的总是同一种腔调——一种充满怀疑、充满忧伤、充满对生活的厌倦的腔调。……连苏格拉底似乎也厌倦了生活。这表明什么？这指点人们走向何处？从前人们会说（我们的悲观主义者带的头）：「这里无论如何有点东西是真的！智者的一致证明了真理。」我们今天还要这样说吗？我们可以这样吗？

「这里无论如何有点东西是患了病的。」我们这样回答。这些历代最智慧的人，人们应当首先就近观察他们。智慧之所以出现在世上，就像一只闻到腐尸气息而兴奋的乌鸦？

倘若一个人不得不把理性变成暴君，如苏格拉底所为，那么必是因为有不小的危险，别的什么东西已成为暴君。这时，理性被设想为救星，无论苏格拉底还是他的「病人们」都不能随心所欲地成为有理性的：这是严格规定的，这是他们的孤注一掷。整个希腊思想都狂热地诉诸理性，这表明了一种困境：人们已陷于危险，只有一个选择：或者毁灭，或者——成为有荒谬理性的人。……无论如何必须理智、清醒、明白，向本能和无意识让步会导致崩溃。

如果说把生活看作悲剧还有某种庄严意味的话，那么把生活当成疾病就很悲惨了。弗洛伊德曾多次讲过一个古已有之的看法：「全部生活的目的就是死亡」。前些年，美国小说家库尔特·冯内古特说我们是「可怕的动物」，地球的免疫系统正试图除掉我们。这种「疾病」隐喻曾被用于现代生活、西方文明和资本主义等。但「疾病」首先就预设了「健康」，对于那些认同这一隐喻的人来说，首先面临的一个问题就是：什么才是健康的生活？是不朽吗？是像蚂蚁那样高的社会生产率吗？纯粹的快乐？丝毫不含敌意的绵绵爱情？这些当然都令人向往，但这并不意味着，没有它们的生活就是一种疾病。

然而，我们今天的大部分语言都受到了这类「健康」隐喻的感染（另一个表示类似观点的词是「自然的」：自然的就是健康的，非自然就意味着疾病或畸形）。我们谈论一种「健康经济」，把以往称呼游戏的词叫作「锻炼」以增进健康。透过这种健康隐喻来看，生活本身必定像是一种致命的疾病，至少最终是这样，因为它似乎无药可救。

**与理论家相遇：西格蒙德·弗洛伊德（1856—1939）**

弗洛伊德出生于奥地利，通常并不被看作哲学家。作为现时代最伟大的思想家之一，他改变了我们关于自己和心灵的观念，甚至还抛弃了为大多数哲学家所最津津乐道的一些假设。例如，他认为像笛卡儿那样的哲学家所谈论的明晰的自我知识可能往往是一种幻觉，我们绝大多数的观念和欲望实际上都是无意识的产物。当我们自以为知道得很清楚时，那些被禁止的冲动和欲望其实是被压抑和扭曲了。然而，弗洛伊德仍被看作一个伟大的理性思维的维护者：他曾经写道，其心理分析的全部技巧都不过是为了把无意识变得有意识起来，从而把无意识的内容置于理性理解的范围和控制之内。

**核心结论**

疾病隐喻比悲剧更悲惨，且逻辑上依赖一个往往未加论证的「健康」理想；健康话语一旦支配语言，生活本身就会显得像无药可救的死症。

### 生活是欲望

把生活看作欲望，往往会同西西弗斯神话把生活看成连续不断的受挫联系起来。希腊寓言中的这类形象是坦塔罗斯（宙斯之子，因泄露天机被罚永世站在上有果树的水中，水深及下巴，口渴想喝水时水即减退，腹饥想吃果子时树枝即升高；「干着急」tantalizing 一词即来源于此）：众神罚他永世被捆在一串葡萄的不远处，他老想去接近它，却总是无法得到。这个故事的近代版本是浮士德，近代一些最伟大的剧作都是因他而写的，包括克里斯托弗·马洛于 1589 年所写的《浮士德博士》，以及前面已经提到的歌德的《浮士德》。浮士德为了他的欲望而活着，当一个欲望被满足时，它马上就会被另一个欲望所替代。生活就是这样一连串无休止的欲望。

一个只求「挣钱能够养家糊口」的人最后会发现，他其实还想要更多的东西，于是这又成了新的生活目标，直到它被满足为止；但到时又不够了，他发现自己还想要更多的东西，于是只好这样无止境地走下去。这并不是说生活就是受挫，因为这些欲望通常都能得到满足，而是说生活就是永无休止的欲望，人不可能最终获得满足。正是欲望和欲望的满足才赋予了生活以意义，没有欲望便是已经离开了这个世界。

**核心结论**

欲望隐喻的要点不是「永远得不到」，而是「得到了还会要下一个」；意义在欲望及其满足的连续本身，无欲等于离世。

---

### 生活是涅槃

与「生活是欲望」相对立的看法是：生活是不去欲望或克服欲望。弗洛伊德在其早期的心理分析著作中把这称为「恒常性原则」，后来又称之为「涅槃原则」。在他看来，生活的目标在于尽可能达到一种无欲无求的宁静状态。「涅槃」一词来自佛教，在梵语中的意思是「处于平和状态」。佛教的目标是减少我们对于欲望的执着，使我们达到一种没有东西能够打扰的宁静状态。在佛教中，涅槃包含一种直面死亡时的镇定，弗洛伊德有时也把他的这一原则称为「求死的愿望」。在西方哲学中，宁静的感觉有时会被擢升为哲学活动或沉思（不断地学习和思考）的目标。

**核心结论**

涅槃隐喻把意义放在减欲与宁静，与欲望隐喻互为反题；弗洛伊德和西方沉思传统都曾靠近这一目标。

---

### 生活是利他主义

**引文资料：我们在这里是为了什么**

「我们被置于这个地球来帮助别人，但别人为什么要在这里我却说不出。」——约翰·福斯特·霍尔（1867—1945，英国喜剧演员）

利他主义是指：即使对一个人自身没有任何好处，也要为他人的利益而行动。有些人认为他们身处地球，就是要帮助那些处境不如他们的人。这种生活观有着非常确定的使命感，对于成功、失败以及应当怎样行事也有着相当明确的看法。对于某些人来说，利他主义的生活一定是单向的：他们帮助别人是为了赋予自己的生活以意义，他们并不期待能够换回什么。对于另一些人来说，利他主义的生活是一个普遍的理想，他们希望有朝一日，每个人都会无私地帮助其他所有人。

**引文资料：最看重什么？**

「不要把你的孩子、生活或任何其他东西看得比善更重。」——苏格拉底《克力同篇》

**核心结论**

利他把意义写成帮他人，带有清晰的成败标准；它可以是给自己赋义的单向行为，也可以是希望人人如此的普遍理想。霍尔的笑话点出单向利他的自指困难。

---

### 生活是荣誉

荣誉是一个随时间不断变化的概念。在荷马《伊利亚特》中的希腊人看来，生活本质上是真正做到无愧于集体的期待，在战斗中证明自己，不以任何方式使自己丢脸。这并不是说你不能有不佳的表现：当国王把阿基里斯最宠爱的一个女奴从他身边夺走时，阿基里斯像小孩一样在帐中生起了闷气。但当他返回战场为其最好的朋友复仇时，他又重新赢得了荣誉。对于那些希腊英雄来说，荣誉是比生命本身更重要的东西，如果需要在光荣地死去和不光彩地活着之间做出抉择，他们会毫不犹豫地选择前者。

但荣誉的概念并非仅限于军事英雄。苏格拉底也是为荣誉而死的，但不是在战场上，而是在牢狱中，为的是表明他重视原则甚于自己的生命。然而，我们的荣誉概念却并不如此清晰。美国士兵当然也是带着荣誉而死的，但在美国的日常生活中，更一般意义上的（能够充当生活的指导原则的）荣誉感肯定不像古代雅典那么突出。不过我们的确有一种义务感，许多人会说，无论怎样，生活的意义都在于尽你应尽的义务——无论是为了上帝、国家、家庭、朋友还是你的雇主。

**掌握概念：斯多亚派哲学**

斯多亚派哲学兴盛于公元前 300 年（距亚里士多德的死不久）到公元四五世纪左右（接近罗马帝国灭亡）。斯多亚派把人类的大多数欲望和情感都视为非理性，主张为了与宇宙和谐统一，我们需要控制自己的激情，过一种正直的、有责任的简朴生活。生活在尼禄皇帝宫廷中的塞涅卡（公元前 4—65）是晚期斯多亚派最著名的代表。像苏格拉底一样，他也是由于自己的名望和观点而被判处了死刑。这个学派还包括一位罗马皇帝马可·奥勒留（121—180）以及其他数以百计的人，这些人当时都是他们那个时代强有力的代言人。绝大多数斯多亚派并不像塞涅卡的命运那样悲惨，但事实上，他们都强调要看重一个人的荣誉感和正义感甚于无常的生活。

**核心结论**

荣誉从战场上的集体期待扩到原则高于生命；当代日常中它淡化为义务感。斯多亚派把荣誉与正义置于激情和无常之上。

### 生活是学习

有一种常见的看法是把生活当作一种学习经历。当然，我们为什么要学习所有这一切的确是个问题，但至少有些学习本身就是让人满足的。也许，这种满足本身就是学习生活的全部意义所在。只要有了什么糟糕的经历（如失恋、由于吸烟被学校开除等），我们就会把它们「记录在案」。有些人感到有必要经历尽可能多的东西；「什么东西都要至少试一次」，仅仅是为了知道它是怎么回事。在他们看来，「尽情地享受生活」就意味着什么都做一遍。

但需要注意的是，这种说法对于不同的人有着非常不同的含义：把生活当作一种使命的人尽情享受生活的方式是尽一切可能来实现自己的使命；把生活当作悲剧的人会把这种说法理解为相当程度地受苦。时下有一则流行的比喻说，生活是一种「成长经历」，活着就是「开发你的个人潜力」。大约 200 多年前，这种生活观曾在德国流行过，我们也能在古希腊哲学比如亚里士多德那里找到这种说法。我们学习是为了什么？由来已久的答案是，学习出智慧，相应地，沉思的生活自古以来就是哲学家的建议。

**核心结论**

学习隐喻可停在「经历本身的满足」，也可通向智慧与沉思；「尽情享受」随你先前选定的隐喻而完全变义。

### 生活是苦

**掌握概念：佛教的「四圣谛」**

1. 苦谛：生活是苦。
2. 集谛：苦源于欲念。
3. 灭谛：欲念可以被消除。
4. 道谛：人可以通过遵循「正道」来消除欲念。

「生活是苦」，这是佛教四圣谛中的第一谛。也许「苦」更应被译成「烦恼」或「不满足」，但要点是生活充满了混乱和痛苦。深受佛教影响的伟大的悲观主义者阿图尔·叔本华也认为生活是苦，我们的欲望终将是非理性的和无果的。他所给出的回答是：人因为认识到不可能获得最终的满足而超然物外。叔本华的解答类似于古代的斯多亚派哲学，这种学说认为，我们的绝大部分激情都是非理性的，运用理性的超然智慧可以最好地使我们免受它们的干扰。

我们可以在这里重提西西弗斯的故事：他把石头滚上山，换来的不过是石头又重新滚落，这反映了生命无法最终实现这一观念。我们有时看到生活正是一遍遍地重复，最终什么也没有增加。有一个现代小说中的人物，当她看到自己的牙刷，并且意识到自己今后不得不一次又一次地刷牙时，她自杀了。不错，有些事情猛然回想起来，的确显得没有意义。有时你虽然定出了某个计划，但你很清楚不久以后又会把它打破。你第十七次学会了做某样事情，但你知道自己一个星期后仍会把它忘掉。你争取高中文凭是为了上大学，是为了拿到学士学位，为了进医学院，为了拿到医学博士，为了实习，为了学习外科，为了动手术，为了过你在高中时梦想的生活，但你那时年纪已经很大，工作太忙，以致不能享受它了。有些人会以同样的方式说，生活是荒谬的。但值得指出的是，尽管加缪认为西西弗斯的任务具有荒谬性，但他的生活还是有意义的，因为他以一种有意识反抗着自己的命运。我们的生活中有没有类似的东西？

**引文资料：唯一严肃的哲学问题（加缪《西西弗斯的神话》，1942）**

「真正严肃的哲学问题只有一个，那就是自杀。生活是否值得过，这就是哲学的基本问题。其余的……都在其次，必须首先给出回答。」

**核心结论**

苦谛把混乱、痛苦、无果欲望写成生活的基本相；重复劳动和「为了下一步」的教育链会把人推向荒谬判断。作者再次插入加缪：意识中的反抗仍可使荒谬的任务有意义；自杀作为「唯一严肃的哲学问题」把「值得过与否」置于一切其余问题之前。

### 生活是一场投资

由于我们生活在一个以商业为主导的社会里，因此有时会很自然地把生活看成一桩买卖（「美国人民的主要事务就是做生意」，卡尔文·柯立芝这位有幸当上总统的商人如是说）。以这种方式看待生活，是把我们的有生之年看作为取得回报而在各种事业中——职业、上学、婚姻、孩子——所投入的资本。由于回报的东西并不都那么清楚，因此投资成败的标准颇受争议。一位父亲可能会由于他的儿子决定要当一个诗人，而认为他「浪费了自己的才能」（也就是做了坏的投资）；而儿子却有可能指责父亲「唯利是图」，其实是在背地里打他的如意算盘。

这则隐喻很容易同它最突出的表现混淆起来，即认为一个人一生赚的钱和积累的财产才是检验成功的标准。然而稍加考虑就会发现，这并不总是一条可靠的衡量标准。如果一项好的投资要用一个人最后得到的东西加以衡量，那么这里就有一个非常真切的问题：这种生活之外的东西怎么可能是生活的意义？

**核心结论**

投资隐喻把年岁当资本，成败标准必争；若成功等于「最后得到的东西」，就再次把意义推到生活之外——与本章第二节的批评闭合。

### 生活是各种关系

**引文资料：论友谊和善（亚里士多德《尼各马可伦理学》，公元前 4 世纪）**

杰出的人用心很专一，他的全部灵魂都欲求同样的东西。卓越的人对待他的朋友就像对待自己一样，朋友是他的另一个自我。因此，友谊似乎是良好生活的一个特征。

关于爱情、婚姻和友谊，前文还没有谈多少，但在许多人看来，他们生活中最重要的以及使生活获得意义的显然就是人与人之间的关系——不是身为人类的一员或国家公民那种抽象意义上的关系，而是一个人与另一个或另几个人之间达成的非常特殊的关系。因此人们会说，生活中真正重要的是友谊或爱情。但为什么我们会用「关系」这个平淡的词来形容如此重要的东西？为什么我们会认为两个人的结合就是两个分离的存在者发生了「关系」，而不是先从结合开始思考？的确，我们语言中关于「关系」的大部分内容都呈现给我们这样一幅令人难堪的图景，即两个孤独的灵魂试图相互「理解」，彼此「沟通」或者「打破壁垒」。然而，另一幅图景是更加使人振奋的，即如黑格尔所主张的，我们所有人都业已被一种无所不包的精神联系起来。根据这种观点，正是我们之间的距离而非亲密才是偏离常规的东西。生活的意义就在于人与人之间的关系之网；理想地说，生活的意义就是爱。

**核心结论**

关系隐喻把意义放在具体的友谊与爱情之网；作者质疑「两个分离者再去沟通」的语言图景，改用黑格尔式的先已联系，理想表述是爱。

### 实操方法

**篇末问题 1**：根据你的偏好，对下列关于生活的看法排序。用 1～5 给它们打分，5 代表完全赞同，1 代表几乎完全不赞同。有没有一些尽管你并不喜欢（例如，生活作为疾病或受苦），但仍认为有道理的条目？如果有，就用 * 标出。除此之外，还可以任意添加你自己的看法。清单：生活是一场游戏；一个故事；一场悲剧；一种使命；一场喜剧；艺术；一场冒险；一种疾病；欲望；利他主义；荣誉；学习；受苦；一场投资；各种关系。

### 开篇题辞与开篇问题

主旨：1. 生活意义是最难、最需要、又最模糊的大问题，但理性仍使追问成为必然。2. 读者须先用自己的隐喻、未了结之事和对西西弗斯的判断占位。与章首核心论点相比，本序列尚未展开「意义即所指」的批评，只把问题摆上台。

最小标签集：陈述（直接说出本标题某条主旨，给该条一个定义；没有这段则该条主旨缺命题，是必需的）；可替换例证（用作品、引文、场景旁证主旨；同标题还有同类例子）；过渡/场景（转场、纯景物，或与主旨无关的文字）。

1. 【第三档·过渡/场景】章首图：雅克-路易·大卫《苏格拉底之死》。

6. 【第二档·可替换例证】开篇问题 3：举出三四种不希望今生无法了结的事，并追问哪些已开始、哪些本可做却没做。

8. 【第一档·陈述】生活的意义是最难、最需要、又最模糊的大问题；回答并不总是字面真理，但正是理性使回答成为可能、使追问成为必然；本章先想可能基础，再讨论候选的有意义生活类型。

### 什么样的意义

主旨：1. 日常小目标不能担负生活意义，于是人转向生活之外。2. 「意义」若被理解成所指，指向概念过于单薄。3. 词与活动的意义依赖语境，但「整个生活／整门语言的意义」可能问法本身不成立；即便如此仍不能放弃求解。与核心论点第 3 条相比，本序列刚提出语境类比，尚未用它收束四种外在答案。

最小标签集：陈述；必要依据；限定；可替换例证；过渡/场景；续。

1. 【第三档·过渡/场景】节题「什么样的意义」。
2. 【第一档·陈述】意义问题最可能在情绪低落或命运多舛时产生；日常生活里不去哲学思考时，生活似乎充满意义：考试、换滤油机、宴会、面试。
3. 【第一档·必要依据】一旦抽象思考，这些小目标无一能担负生活意义；精力转向快乐、事业、成功、权力和爱情，随即听到「万事皆空」，于是超越生活本身寻找意义——哲学的最终问题。
   （本段是第2段的必要依据）
4. 【第一档·陈述】须先问此处「意义」是什么意思：有时是标记或词所指向的超越自身的东西，「小心狗」「苏格拉底」即如此；若这样理解，生活的意义就是生活所指向的无论什么东西。
5. 【第一档·必要依据】所指候选包括他人、共同体或人类、造物主／上帝；但「指向」很单薄，也可说生活什么也不指、生活就是生活；问题可能出在把意义当成所指。
   （本段是第4段的必要依据）
6. 【第三档·过渡/场景】方框标题：引文资料「生活的意义」。
7. 【第二档·可替换例证】《传道书》：虚空的虚空，日光之下劳碌无益，并无新事。
   （本段旁证第3段）
8. 【续 7】续：以喜乐、酒、愚昧和大工程试验，手所经营皆是虚空、捕风。
9. 【续 7】续：智慧胜过愚昧如光明胜过黑暗，但智愚同一结局，于是恨恶生命。
10. 【续 7】续：总意是敬畏神、谨守诫命；善恶神都必审问。
11. 【第一档·必要依据】个别词和标记有所指，只在语境或意义共同体之内才可能；「pepino」「fore!」对圈外人没有意义。
    （本段是第4、5段的必要依据）
12. 【第一档·限定】特定活动可用习俗和目的解释，但多数人并非把全部生命献给唯一目标，而这并不意味着他们的生活缺乏意义。
    （本段限定第11段）
13. 【第一档·陈述】不能问整门语言的意义，故或许也不能问整个生活的意义；但这似乎等于说关键问题不可能有解答。
14. 【第一档·陈述】人们问生活意义时想到的往往是外在于生活的超越者，它们可能极为重要，但只是把问题延后；四种回答值得说：孩子、上帝、来生、生活没有意义。

### 孩子、上帝、来生

主旨：1. 用孩子或乌托邦赋义会无穷后推。2. 信仰上帝并不取消问题，往往使问题更棘手。3. 用来生给今生赋义，等于宣布今生无关紧要，逻辑上站不住。本序列是核心论点第 2 条的展开，尚未处理「荒谬」。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】小节标题「孩子作为意义」。
2. 【第一档·陈述】许多人说意义在孩子以及孩子的孩子；若意义总在下一代，则推向乌托邦，而乌托邦中远亲的生活意义问题依然存在，自己的生活如何因此有意义仍未答。
3. 【第二档·可替换例证】成功的配偶回首共同奋斗的岁月，认为那才是最美好时光；这并不符合「最终安宁的乌托邦才是意义」，快乐本身也并不显然就是意义。
   （本段旁证第2段）
4. 【第三档·过渡/场景】小节标题「上帝作为意义」。
5. 【第一档·陈述】传统回答是上帝；常有人说信徒根本不会困惑，但奥古斯丁问此问多于任何无神论者，路德及许多基督教思想家亦然。
6. 【第一档·必要依据】单凭信仰只是回推一步：为何创造、为何是我们、指望什么；全能者何必让人代行使命，难道为了证明或虚荣？使命是什么仍未答，信仰使问题更棘手。
   （本段是第5段的必要依据）
7. 【第三档·过渡/场景】小节标题「来生作为意义」。
8. 【第一档·陈述】把意义放在作为回报的来生，等于说今生无关紧要；今生应如何行事（信仰、善行、享受、艺术、皈依、烹饪）问题又在原地打转。
9. 【第一档·必要依据】今生若无关紧要，长久并不能保证来生更有意义；课已上厌再加十小时只会更厌；若干基督教思想家反而认为唯尽情享受今生者才可能得来生报偿，于是问题回到何谓今生有意义。
   （本段是第8段的必要依据）

### 毫无意义、荒谬与语境中的意义

主旨：1. 「荒谬」是「生活并无意义」的时代感受，但体面的外在答案和「无意义」都只是把问题推进一步。2. 外在意义不等于生活意义，上帝不在场推不出无意义。3. 意义在生活情境中；真正按虚无主义生活也可以赋义。本序列把核心论点第 3、4、5 条收拢。

最小标签集：陈述；必要依据；限定；可替换例证；次要观点；过渡/场景；续。

1. 【第三档·过渡/场景】小节标题「没有任何意义」。
2. 【第一档·陈述】一些哲学家和许多学生说生活没有任何意义，用语通常是荒谬；有神无神者均可持此见，最极端表述多出自无信仰者；加缪称荒谬已成为时代的共同感受。
3. 【第二档·可替换例证】加缪：街角袭来的荒谬感；起床、电车、工作、吃饭、睡觉的节奏某一天被「为什么」打断，一切在吃惊的厌倦中开始。
   （本段旁证第2段）
4. 【第二档·可替换例证】加缪生于阿尔及利亚，政治上在激进派与纳粹／殖民不公之间取中立；《局外人》成名；主张生活本质上荒谬，须靠反抗不公并尽情享受使生活值得过；1960 年死于车祸。
   （本段旁证第2段）
5. 【第一档·限定】孩子、上帝等答案在个人生活中可能无比重要，但它们只把问题推进了一步；要的答案在自己的生活之中，不在它之外。
   （本段限定第2段，并回指前一序列）
6. 【第一档·必要依据】对荒谬说同样适用；加缪有时用无神论辩护「无外在意义则无任何意义」，但外在意义未必是生活的意义，上帝不在场并不能推出生活无意义。
   （本段是第2、5段的必要依据）
7. 【第三档·过渡/场景】方框标题：引文资料「永恒轮回」的思想。
8. 【第二档·可替换例证】尼采：恶魔宣告你的生活将周而复始、绝无新意，一切按同样顺序重现。
   （本段旁证第6段）
9. 【续 8】续：你会瘫倒咒骂，还是称之为从未听过的神圣之言？
10. 【续 8】续：这是人人必须回答的最沉重负荷；你是否安于现状、放弃追求比这永恒更热烈的东西？
11. 【第三档·过渡/场景】方框标题：引文资料「西西弗斯和巨石」。
12. 【第二档·可替换例证】诸神罚西西弗斯永推巨石，最可怕的惩罚是既无用又无望的劳动。
    （本段旁证第2段）
13. 【续 12】续：神话悲壮是因为主人公有意识；工人每日同样活计同样荒谬，只在有意识时才悲壮。
14. 【续 12】续：西西弗斯这神的无产者在无能为力中反抗；下山时的洞察完成胜利，没有轻蔑克服不了的命运。
15. 【续 12】续：登上顶峰的斗争本身足以充实心灵；应该设想西西弗斯是幸福的。
16. 【第一档·陈述】词的意义更在语言中的含义而非仅仅所指；类比地，生活意义只能在生活情境中找到。真正为上帝或孩子而活的人，那件事就回答了意义。
17. 【第一档·陈述】若真正把生活致力于「生活毫无意义」并清掉错误有害的赋义，虚无主义同样可以赋予意义；加缪似乎这样活着。

### 生活的各种意义（总论）

主旨：1. 生活意义问题给出的是隐喻和角色洞察，不是确切答案。2. 看法会造出相应的生活气氛，故此事也是创造。3. 对生活的看法决定能发现的意义；清单开放。本序列对应核心论点第 6、7 条，尚未进入各个隐喻的内部标准。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】节题「生活的各种意义」。
2. 【第二档·可替换例证】毕达哥拉斯：生活像奥林匹克赛会，有人争胜，有人赢利，有人旁观。
3. 【第二档·可替换例证】巴特勒：生活像公开演奏小提琴，边演边学。
4. 【第二档·可替换例证】无名氏：生活是一碗樱桃，苦乐兼备。
5. 【第二档·可替换例证】丹杰菲尔德：生活是一碗果核，是对前句的曲解笑谈。
6. 【第一档·陈述】这个问题不需要也不能给出确切答案，更像不可或缺的隐喻或洞察，从中看出自己扮演何种角色、有哪些合理期待；看法从多方面决定未来走向。
7. 【第一档·必要依据】若抱「狗咬狗」去经商或上学，就会把他人当对手，不诚实也无交往之乐，别人察觉敌意后以恼人行为检验你，于是你真的造出了那种气氛。
   （本段是第6段的必要依据）
8. 【第一档·必要依据】故此事不只是发现，也是创造：哲学既表述已有世界观，也参与形成它；有的悲观哲学家故意把哲学写得乐观，为的是改变自己，有人成功了。
   （本段是第6段的必要依据）
9. 【第一档·陈述】对生活的看法决定能发现的意义；开篇问题 1 与 4 可诊断态度（游戏＝不必太严肃、去享受；恩赐＝严肃、有使命、成败较清楚）；下列主要看法历史上和学生试卷中常见，清单不完整，读者可增补更好者。

### 生活是一场游戏

主旨：1. 游戏隐喻的本义是自足、意义在玩法。2. 若不先问是哪类游戏，它会变成你死我活的好胜。

最小标签集：陈述；必要依据；可替换例证。

1. 【第一档·陈述】若生活是游戏，就不应被严肃对待；游戏自足，意义在玩本身；但隆巴迪「胜利不是一切，而是唯一」会把生活变成不间断的你死我活，故须追问是何种游戏。
2. 【第二档·可替换例证】游戏类型包括消遣、证明优越（掰腕子）、消磨时间（单人纸牌）、交际（桥牌）、制造紧张（高赌注扑克）、伤害对手（拳击）、助人筹款。
   （本段旁证第1段）
3. 【第二档·可替换例证】伯恩《人们玩的游戏》曾畅销；有哲学家视语言、经济学和哲学本身为游戏；此隐喻强调守规则、精彩、享受、尽力成功，但「胜败」话语危险，称世界杯亚军为「败将」暴露了苛刻标准。
   （本段旁证第1段）

### 生活是一个故事

主旨：1. 生活按我们边走边写的剧本在时间中展开，而非朝向唯一大目标。2. 意义在故事与角色的质量；错角、无意识和互相矛盾的角色会毁掉意义。

最小标签集：陈述；必要依据；可替换例证；次要观点。

1. 【第一档·陈述】王尔德说生活模仿艺术，以对柏拉图「艺术模仿生活」；生活并非断续或奔向唯一大目标，而是因循详尽剧本展开，我们边走边构造；角色先由家庭文化、再由环境赋予；这是一种把生活看成情节与个性连续发展的时间方式，德国人称之为教育小说。
2. 【第一档·必要依据】做决定时常用文学或电影标准（有趣、厌烦、悬念、得体、时机、是否过分、是否符合主人公性格）；巴斯写每个人都是自己故事的主人公，波洛纽斯并不自视为《哈姆雷特》里的小人物，斯托帕德则从更次要人物重写该剧。
   （本段是第1段的必要依据）
3. 【第二档·次要观点】夹注介绍巴斯小说的讽刺与无绝对价值世界，以及斯托帕德把两个朝臣反配为主、人只是更大系统中的小角色。
4. 【第一档·陈述】有人按喜剧、闹剧或冒险故事生活，做戏剧性之事以光辉履历；赋义的不是终极目标或结局，而是故事质量与扮演质量；选错角色、不意识到角色或扮演互相矛盾的角色，都会毁掉所发现的意义。

### 生活是一场悲剧

主旨：1. 人人必死，生活带有缺陷、误判与矛盾，终局悲惨。2. 活得好等于把悲剧角色承受好。与「游戏不必严肃」相对。

最小标签集：陈述；可替换例证。

1. 【第一档·陈述】人人会死，死亡常被看成倒霉、来生之路或最终灾难；把生活看作稍逊的《哈姆雷特》《麦克白》《奥赛罗》《浮士德》，会发现悲惨缺陷、判断错误和严重矛盾伴随一生直至死亡；与游戏隐喻相反，这是严肃不愉快的过程，活得好即英雄式地扮演悲剧角色，偶尔孤独哀鸣。
2. 【第二档·可替换例证】《局外人》结尾：人人皆为兄弟，等待他们的是同一个结局——死亡。
   （本段旁证第1段）

### 生活是一场喜剧

主旨：1. 笑是生活甚至好生活的要素，长期被忽视。2. 严肃喜剧和黑色幽默给荒谬以幽默收场；幽默应用于生活态度，而非再往生活里加笑料。

最小标签集：陈述；必要依据；可替换例证；过渡/场景；续。

1. 【第一档·陈述】「生活是一个玩笑」或许不然，但相对于悲剧能使人振作；笑作为好生活要素长期被忽视；柏拉图对话赋予幽默深意，伊拉斯谟《愚人颂》颂扬愚蠢，查拉图斯特拉教人不要太严肃、享受欢笑与无常。
2. 【第三档·过渡/场景】方框标题：引文资料「等死」。
3. 【第二档·可替换例证】默尔索在狱中按最坏设想上诉被驳回，推论 30 岁死或 70 岁死关系不大，怎么死、何时死都无关紧要，故应接受驳回。
   （本段旁证第1段）
4. 【第一档·必要依据】幽默有好有糟；有人重深意，有人说笑本身重要；笑话须短时奏效；更严肃的喜剧写抱负与挫折，不用「荒谬」加工，而给荒谬以幽默含义。
   （本段是第1段的必要依据）
5. 【第二档·可替换例证】《碧血金沙》结尾老人失尽后大笑，或是贪婪、失望与死亡故事唯一可能的欢乐收场；幽默该用在态度和自我审视上，电视已提供够多生活中的笑料。
   （本段旁证第4段）

### 生活是一种使命

主旨：1. 使命是召唤，不限于把他人变成基督徒。2. 若使命首先是道德的，就会按功利论或康德义务论来表述。

最小标签集：陈述；必要依据；可替换例证。

1. 【第二档·可替换例证】歌德传记：德国最伟大作家，兼科学家与政治家，主张「让诗歌讲德语」，《浮士德》写六十余年；与黑格尔同持生物生长的自然观，对抗牛顿后的机械自然观。
2. 【第一档·陈述】基督徒常把生活当作使人皈依的使命，但歌德、黑格尔、政治激进分子、科学家、父母都可以有各自的召唤。
3. 【第一档·必要依据】使命若首先是道德上的，边沁式功利主义者把行动基于最多数人的最大幸福，康德式伦理理性论者则要培养道德人格、履行理性规定的义务。
   （本段是第2段的必要依据）

### 生活是艺术

主旨：1. 生活应如雕塑般打磨形体、性格与风格，创造活动与结果同样重要。2. 评价标准是艺术品式的感人、设计、格调或粗俗、遗忘。

最小标签集：陈述；可替换例证。

1. 【第一档·陈述】尼采要人把生活当艺术品过，不是故事而是雕塑：打磨形体、塑造性格、发展风格；谢林视全部生活为上帝的艺术品、人为学徒；艺术家重创造活动本身；要活得精彩，至少活出风格；按感动、设计、戏剧性、色彩或粗俗、冥顽、难忘与否来评价。
2. 【第二档·可替换例证】尼采攻击基督教道德，自称「不道德的人」，转而强调审美价值，仍被视为伟大道德哲学家。
   （本段旁证第1段）
3. 【第二档·可替换例证】谢林强调创造力与艺术中心地位，上帝是仍通过我们创造宇宙的伟大艺术家；曾与黑格尔同学共创哲学，后争执分手。
   （本段旁证第1段）

### 生活是一场冒险

主旨：1. 生活不必按旁观者眼里的整体形态来估价。2. 冒险在于风险、技巧与不确定，并且不预先规定恰当结局。

最小标签集：陈述；次要观点。

1. 【第一档·陈述】艺术或故事隐喻虽振奋，却把生活的价值变成形态、潮流与对观者的吸引；冒险则是尽情享受、听天由命、迎接挑战，沉醉于技巧和不确定；对这样活的人而言这或许是唯一不乏味的方式，完结就完结，不预定恰当结局。
2. 【第二档·次要观点】所谓中国咒语「祝你生活在有趣的时代」其实很可能是为显神秘而误归之于中国的；讽刺在于选择过多也是折磨。

### 生活是一种疾病

主旨：1. 疾病隐喻比悲剧更悲惨，并预设未加澄清的「健康」。2. 健康／自然话语一旦支配语言，生活本身会显得像无药可救的死症。与核心论点第 7 条相比，本序列多出尼采对「智者一致厌世」的病理诊断。

最小标签集：陈述；必要依据；限定；可替换例证；过渡/场景；续。

1. 【第三档·过渡/场景】方框标题：引文资料「生活的意义」。
2. 【第二档·可替换例证】尼采：一切时代智者都判断生活毫无用处，连苏格拉底也似厌倦生活；从前把智者一致当作真理的证明。
3. 【续 2】续：今日应回答「这里有点东西是患了病的」；智慧或如闻到腐尸而兴奋的乌鸦。
4. 【续 2】续：苏格拉底把理性变成暴君，是因别的东西已成暴君；希腊狂热诉诸理性是困境中的孤注一掷：毁灭，或成为有荒谬理性的人。
5. 【第一档·陈述】疾病隐喻很悲惨；弗洛伊德谓全部生活的目的就是死亡；冯内古特谓人类是地球免疫系统要除掉的可怕动物；此隐喻曾用于现代生活、西方文明和资本主义。
6. 【第一档·限定】疾病预设健康；健康若是不朽、蚁式生产率、纯粹快乐或无敌意的爱情，这些虽令人向往，其缺失并不使生活成为疾病。
   （本段限定第5段）
7. 【第一档·必要依据】今日语言受健康隐喻感染，「自然的」等于健康；我们说「健康经济」，把游戏改叫「锻炼」；透过此隐喻，生活本身必像致命且无药可救的疾病。
   （本段是第5段的必要依据）
8. 【第二档·可替换例证】弗洛伊德通常不被看作哲学家，却改变了心灵观念：笛卡儿式明晰自我知识可能是幻觉，观念欲望多是无意识产物；心理分析仍要把无意识变成有意识，置于理性控制之内。
   （本段旁证第5段）

### 生活是欲望／涅槃

主旨：1. 生活可以是永无休止的欲望及其满足，无欲即离世。2. 反题是减欲入涅槃式宁静。两条合为一个序列，因原文将二者对举。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】小节标题「生活是欲望」。
2. 【第一档·陈述】欲望隐喻常与西西弗斯式受挫相连；坦塔罗斯永够不着葡萄，近代对应是浮士德：一欲既满足立刻被下一欲替代，生活是无休止的欲望链。
3. 【第一档·必要依据】「挣钱养家」会变成「还要更多」；这不是说欲望得不到满足，而是不可能最终满足；正是欲望及其满足赋予意义，没有欲望便已离开世界。
   （本段是第2段的必要依据）
4. 【第三档·过渡/场景】小节标题「生活是涅槃」。
5. 【第一档·陈述】对立看法是不去欲望或克服欲望；弗洛伊德先称恒常性原则、后称涅槃原则，目标是无欲无求的宁静；佛教涅槃为平和状态，含直面死亡的镇定；弗洛伊德或称之为求死愿望；西方哲学有时把宁静擢升为沉思的目标。

### 生活是利他主义

主旨：1. 利他是即使对自己无好处也为他人利益行动。2. 它可以是单向赋义，也可以是普遍理想。

最小标签集：陈述；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】方框标题：引文资料「我们在这里是为了什么」。
2. 【第二档·可替换例证】霍尔：我们被置于地球来帮助别人，但别人为什么在这里我却说不出。
3. 【第一档·陈述】利他主义即使对自己无好处也要为他人行动；有非常确定的使命感与行事标准；或单向（帮人以为自己赋义、不求回报），或普遍理想（希望人人无私互助）。
4. 【第二档·可替换例证】苏格拉底《克力同篇》：不要把孩子、生活或任何其他东西看得比善更重。
   （本段旁证第3段）

### 生活是荣誉

主旨：1. 荣誉随时代而变，希腊英雄可把荣誉置于生命之上。2. 它可以是原则高于生命，当代则淡化为义务感；斯多亚派把荣誉与正义置于激情之上。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第一档·陈述】荷马世界里生活本质是无愧于集体期待、在战斗中证明自己、不丢脸；阿基里斯可生闷气，但为友复仇即重赢荣誉；希腊英雄会选光荣死去而非不光彩地活着。
2. 【第一档·必要依据】荣誉不限于军事：苏格拉底在牢中为表明原则重于生命而死；美国士兵亦带着荣誉而死，但日常生活中可作指导原则的荣誉感不如古代雅典突出，于是意义常被说成尽对上帝、国家、家庭、朋友或雇主的义务。
   （本段是第1段的必要依据）
3. 【第三档·过渡/场景】方框标题：掌握概念「斯多亚派哲学」。
4. 【第二档·可替换例证】斯多亚派视多数欲望情感为非理性，主张控制激情、过正直简朴生活；塞涅卡被处死，马可·奥勒留亦属此派；他们看重荣誉感与正义感甚于无常的生活。
   （本段旁证第2段）

### 生活是学习

主旨：1. 学习本身的满足可以就是意义。2. 「尽情享受」随先前隐喻而变义；古老答案是学以成智、过沉思生活。

最小标签集：陈述；限定。

1. 【第一档·陈述】常见看法把生活当作学习经历；为何要学这一切仍成问题，但有些学习本身让人满足，这满足或即全部意义；糟糕经历被「记录在案」，有人要什么都至少试一次，把尽情享受理解成什么都做一遍。
2. 【第一档·限定】使命中人靠实现使命来享受，悲剧中人把这话理解成受苦；「成长经历」「开发个人潜力」约两百年前在德国流行，亦见于亚里士多德；由来已久的答案是学出智慧，沉思的生活是哲学家自古的建议。
   （本段限定第1段）

### 生活是苦

主旨：1. 苦谛说生活充满混乱、痛苦与无果欲望，超然是一种答法。2. 重复与「为了下一步」的链条显出无意义，但有意识的反抗仍可使荒谬任务有意义。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】方框标题：掌握概念「佛教的四圣谛」。
2. 【第一档·必要依据】苦谛：生活是苦。集谛：苦源于欲念。灭谛：欲念可被消除。道谛：可循正道消除欲念。
   （本段是第3段的必要依据）
3. 【第一档·陈述】第一谛或应译为烦恼、不满足，要点是生活充满混乱和痛苦；叔本华认欲望终将非理性无果，因认识到不可能最终满足而超然，近于斯多亚派以理性超然免受激情干扰。
4. 【第二档·可替换例证】西西弗斯滚石再落，写生命无法最终实现；重复刷牙令小说人物自杀；计划必破、学会必忘、从文凭到外科的长链使人老到不能享受梦想；有人因此说生活荒谬，但加缪的西西弗斯仍因有意识反抗而有意义。
   （本段旁证第3段）
5. 【第二档·可替换例证】加缪：真正严肃的哲学问题只有一个，就是自杀；生活是否值得过是基本问题，其余都在其次。
   （本段旁证第4段）

### 生活是一场投资

主旨：1. 商业社会易把年岁当资本投入职业、学业、婚姻、孩子。2. 若用「最后得到的东西」衡量好投资，意义又被推到生活之外。

最小标签集：陈述；必要依据；可替换例证。

1. 【第一档·陈述】柯立芝谓美国人民的主要事务就是做生意；此隐喻把有生之年看作求回报的资本，而回报并不都清楚，故成败标准必争。
2. 【第二档·可替换例证】父亲可因儿子要当诗人而责其浪费才能（坏投资），儿子可责父亲唯利是图。
   （本段旁证第1段）
3. 【第一档·必要依据】隐喻易与「赚钱积产即成功」混淆，而那并非可靠标准；若好投资要用最后得到的东西衡量，则生活之外的东西怎么可能是生活的意义？
   （本段是第1段的必要依据）

### 生活是各种关系

主旨：1. 对许多人而言意义在具体的友谊与爱情，而非抽象的人类或公民身份。2. 「关系」一词预设两个分离者再去沟通；黑格尔式图景则认为先已联系，理想是爱。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】方框标题：引文资料「论友谊和善」。
2. 【第二档·可替换例证】亚里士多德：杰出的人灵魂专一；卓越的人待朋友如待自己，朋友是另一个自我；友谊是良好生活的一个特征。
3. 【第一档·陈述】许多人认为最重要的是一个人与另一个或几个人之间非常特殊的关系，真正重要的是友谊或爱情，而不是抽象的人类成员或国家公民身份。
4. 【第一档·必要依据】「关系」这词平淡，且把结合想成两个分离存在者再发生关系；语言图景常是两个孤独灵魂试图理解、沟通、打破壁垒。黑格尔主张人业已被无所不包的精神联系起来，距离而非亲密才是偏离常规；意义在关系之网，理想地说就是爱。
   （本段是第3段的必要依据）

### 篇末问题与阅读建议

主旨：1. 用打分、标星和增补把自己的隐喻排序。2. 练习反驳「尽量争取属于你的东西」，并比较「保持世界原样」与「留下标记」。3. 进一步阅读指向正文用过的欲望、苦、悲剧与文明不满线索。

最小标签集：陈述；可替换例证。

1. 【第一档·陈述】篇末问题 1：用 1～5 给游戏、故事、悲剧、使命、喜剧、艺术、冒险、疾病、欲望、利他、荣誉、学习、受苦、投资、关系打分，不喜欢但认为有道理的标星，并可自增条目。
2. 【第一档·陈述】篇末问题 2：朋友说生活意义不过是「尽量争取属于你的东西」；问你怎么看、会否说它自私、将怎样去做。
3. 【第一档·陈述】篇末问题 3：美洲印第安谚语「让世界保持原样」对许多美国人的「在世界上留下标记」；问二者优缺点、如何调和、各给出何种生活意义。
4. 【第二档·可替换例证】阅读建议列出 Cheney 与 Sanders 的意义文选、弗洛伊德《文明及其缺憾》、歌德《浮士德》、Moore《灵魂的关怀》、尼采《悲剧的诞生》、叔本华《作为意志和表象的世界》、冯内古特《没有祖国的人》。
   （本段旁证第1段）
