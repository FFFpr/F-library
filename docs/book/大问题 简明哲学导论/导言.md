# 导言 做哲学

## 本章位置

导言是全书的操作手册：先规定「做哲学」是什么，再教人躲开时髦词语，把明确表达与论证立为两项特征，引入概念与概念框架，强调有风格地做哲学，最后用一小套逻辑把好论证与坏论证分开。第一章起才进入「什么是哲学」等大问题；本篇几乎不回答那些问题，只训练读后面各章所需的工具。

> 💡 有效论证形式见：[附录二_演绎逻辑.md](附录二_演绎逻辑.md)

## 核心论点

1. **哲学是关于自身和世界的信念及态度的总和**，做哲学首先是尽可能清晰有力地陈述这些信念，并把它们发展成彼此协调、经得起反驳的整体。
2. **时髦词语替代思考**：「自由」「真理」「科学」听上去像「狗」一样具体，其实最难定义；哲学命令是「定义你的术语」，而定义通常出现在思想过程的结尾而非开端。
3. **明确表达与论证是哲学的两个重要特征**；分析与综合是配套工序；最终目的是把关于自身和世界的看法整合为可辩护的统一看法。
4. **概念赋予经验以形式**；概念组成概念框架（也可称生活方式、意识形态、舆论气候或世界观）。哲学不是任意发明框架，而是澄清业已相信的东西。
5. **有风格地做哲学**：质量取决于独创性、彻底性、观念联系的严密性和鲜活印象；六点清单（思想、批判性思考、论证、一个真正关注的问题、想象、风格）把「做」落到写作上。
6. **逻辑给论证分类**：演绎有效且前提为真才可靠；归纳只有强弱，从个别到一般不能保证结论为真；批判包括反例、不一致性、悖论、循环论证、同义反复和人身攻击。

## 关键概念补全

**明确表达（articulation）**：用清晰、简洁、易懂的语言把思想说出来。导言强调：许多信念在「感觉很清楚」时一经写出或向朋友解释就蒸发；也有人自以为没看法，一讨论就有了明确立场。

**论证（argument）**：用源自其他思想、原理和观察的理由支持说法、得出结论并驳斥反对意见。日常语言里「论证」像火药桶，哲学里它不必充满敌意，最好的论证冷静、平和，由逻辑规定。

**分析 / 综合**：分析通过区分组分来理解观念（「谋杀」含杀害、错误、意图）；综合把不同观念结成统一看法（毕达哥拉斯「天球和谐」综合数学、音乐、物理学和天文学）。

**概念 / 概念框架**：概念是哲学体系和观点的基本单元，使经验有形式、使明确表达成为可能。概念罕有孤立，总组成概念框架。从实践看可称生活方式；侧重政治社会称意识形态；历史学家或称舆论气候；强调对世界的整体看法则称世界观（Weltanschauung）。

**经验概念 / 先天概念**：经验概念来自经验（如「狗」）；先天（a priori）概念在概念上先于经验（如「数」），对象无法简单触及，须在抽象概念系统中定义。

**经验知识 / 先天知识**：前者基于自己或他人的观察实验（「芝加哥今天 17℃」）；后者独立于任何特殊经验（「2+3=5」）。

**形而上学、伦理学、认识论、逻辑、宗教哲学、政治哲学、美学**：导言为授课方便列出的领域。形而上学含本体论（排列构成宇宙的不同实体之优先性）；伦理学有时称道德哲学，但后者只是其一部分。各领域最终交织。

> 💡 形而上学专章见：[第04章_实在的本性.md](第04章_实在的本性.md)；认识论见：[第05章_真理的追寻.md](第05章_真理的追寻.md)；伦理学见：[第08章_道德和良好生活.md](第08章_道德和良好生活.md)；政治哲学见：[第09章_正义和好的社会.md](第09章_正义和好的社会.md)；美学见：[第10章_美.md](第10章_美.md)；宗教哲学见：[第03章_上帝.md](第03章_上帝.md)

**演绎 / 归纳**：演绎中结论之真由前提之真保证；归纳即使前提为真结论也未必为真。哲学家把「有效/无效」留给论证形式，「真/假」留给陈述；有效且前提为真的演绎论证称为可靠。归纳只说强弱，不说有效无效。

**三段论**：最出名的演绎形式。例：所有哲学家都是智慧的；苏格拉底是哲学家；因此苏格拉底是智慧的。形式：所有 P 是 Q；S 是 P；因此 S 是 Q。同形式也可以前提全假而仍有效（所有牛都是紫色的；苏格拉底是牛；因此苏格拉底是紫色的）。

**假说**：据信可由实验证实或否证的陈述。不仅科学使用：找车钥匙、谁吃了冰箱里的蛋糕，都先有假说再归纳。

**反例**：反驳「所有 X 是 Y」或「没有 A 是 B」的有力方式——举一个不是 Y 的 X，或一个是 B 的 A。

**悖论**：基于显然好的论证得出自相矛盾或荒谬的结论。有的只是表述问题；有的会迫使整个学科重新思考。导言例：全能上帝能否造出连自己也搬不动的山；「这句话是假的」；理发师悖论；芝诺飞矢。

**归谬法**：因某观点会导致悖论或荒谬而驳斥它，再修改原主张（如把全能改成「能做任何逻辑上可能的事情」）。

**循环论证**：把试图解决的问题当作前提。「他人存在着，因为我同他们交谈过」已预设他人存在。

**同义反复**：必然为真、正确性明显到反面即自相矛盾的陈述（「A 是 A」「如果一个人是自由的，那么他就是自由的」）。说一种哲学「愚蠢或平凡」常因它沦为同义反复。

**人身攻击**：针对人而非问题（骂对方是无神论者或纳粹）。

**谬误**：坏论证的总称。形式谬误违背推理规则；非形式谬误用含混术语、偏颇语言、回避事实或分散注意力来「欺骗」。

## 一、做哲学：陈述、协调、经得起反驳

### 论证推理链

**论据 / 案例 / 事实**

- 题辞：苏格拉底「未经审视的生活是不值得过的」；德尔菲神谕「认识你自己」（作者称为苏格拉底的箴言）。
- 哲学=关于自身和世界的信念及态度的总和。做哲学首先是陈述：尽可能清晰有力地表达所思所想。
- 这不等于宣称赞成听起来顺耳的观念。哲学要发展这些观念，发掘全部意义和结构关系，联系其他哲学家（包括经典论述），评价与其他观点的区别，与持不同意见者争论并尝试解决困难。
- 一位学生说：把主要观点列在一张纸上很容易，说清它们如何联系、别人反对时如何作答则很难。作者用橄榄球比喻：只想当四分卫却不必与队友合作、直到另一支球队上场——但比赛就是与己队配合以对抗挑战。
- 苏格拉底传记框：约前 469/470–前 399，述而不作，所知来自柏拉图及其他人；终身在雅典，擅修辞辩论；婚姻有传言，有几个孩子，大部分时间贫困；哲学基于「认识你自己」和「经过审视的生活」；智慧表现为知道自己有多么无知；致力于智慧、正义、良好生活；前 399 年被控「腐蚀青年」处死，放弃逃跑，以尊严接受判决。

**推导**

若一种信念无法与其他信念联系、又经不起批评，就可能根本不值得相信。哲学不是口号收藏，而是把若干不同思想协调成一种观点，并用自己的想法回应反驳。

**结论**

做哲学=陈述 + 发展 + 关联 + 争论；单列出「我相信的几条」还不够。

## 二、避免时髦词语

### 论证推理链

**论据**

- 说自己信仰「自由」可以使人骄傲，但不能说清赞成什么、相信什么、为何值得追求，则与哲学或自由都无关。
- 「时髦词语」听上去指称明确具体的东西（像「狗」），其实属于最难理解的词，引出哲学中最困难的问题。「自由」好像意味着出狱或批评政府，但两例之间的共同点说不清。几乎人人信仰「自由」，问题是所信仰的到底是什么。
- 「真理」「实在」「道德」「爱」「上帝」同样常被当徽章使用，快慰来自说出它们，而不是说明含义。
- 有多少可疑广告打着「科学」赚钱，多少过激行为凭「艺术」被容忍，多少政治活动打着「国家安全」或「民族自决」正当化。这些词妨碍理解行为的真正本质，成为哲学的绊脚石。
- 「主观」「客观」本是有用区分，一经滥用几乎不知所云。有学生以为把引人注目的术语连成一长串就是做哲学。
- 「定义你的术语」被反复强调，但定义极难，多数情况下出现在思想过程结尾而非开端。学会几个新词不等于了解某种哲学，好比试穿过冰靴就以为学会了滑冰。

**结论**

哲学术语只有紧紧扣住所要解决问题、含义业已明确时才有用。时髦词语非但不能帮助思考，还会替代思考。

## 三、明确表达和论证

### 论证推理链

**论据**

- 哲学首先是反思：后退一步，听自己和他人（包括大哲学家），理解并评价，尽可能清晰透彻说出想法。
- 两种日常经验：自以为相信的东西一写就模糊；自以为没看法一讨论就有了明确立场。
- 写出想法是明确表达的极好方式；与同学、朋友、家人甚至陌生人讨论往往更轻松，且会把人逼进第二特征——论证。
- 明确表达不能保证观点值得相信或经得起批评；论证检验观点，之于哲学好比训练之于正式比赛。
- 掌握概念框给出四词：明确表达、论证、分析、综合（谋杀三组分；天球和谐之综合）。
- 表述和辩护能在很大程度上把观点变成自己的。学生常把大哲学家当智力博物馆展品；一旦采纳某种历史上被天才辩护过的观点，它就成了你的。做哲学几乎总要借助其他哲学家的论证和例证（脚注说明）。
- 最终目的是综合：把关于自身和世界的看法整合为独立、统一、可辩护的看法。凌乱的想法和论证不是哲学，正如一堆无关语词不是诗歌。

**哲学的各个领域（掌握概念框）**

形而上学（含本体论）、伦理学/道德哲学、认识论、逻辑、宗教哲学、政治或社会政治哲学、美学（含艺术哲学）。研究某一领域问题时往往会不经意进入另一领域。

**结论**

通过反思、明确表达和论证，哲学帮助分析并批判性考察自己的思想，再综合成可辩护的世界观。

## 四、概念与概念框架

### 论证推理链

**论据**

- 概念使我们看到具体人或物，而不是焦距没对准的一团模糊；除规定经验形式外，还组织经验。
- 「狗」的习得：起初把任何四腿动物都叫狗，经纠正而精确，并能在狗不在场时思考一般的狗，再按凶恶/温顺精致化。概念在实践上决定何时跑、何时礼尚往来，也成为世界观的一部分：一个划分成狗与非狗的世界。旁注：犬儒主义得名于希腊词「狗」，因苦行生活在同时代人看来比狗好不了多少。
- 经验概念来自经验，把世界分成可区分部分。先天概念（如数、无理数）无法对应日常经验中的一件东西，须在抽象系统中定义。
- 哲学关注最困难的抽象概念：「好人」「良好生活」在不同社会含义不同；「上帝」困难到有的宗教拒绝定义甚至拒绝名号；犹太—基督与伊斯兰传统内部、《圣经》内部含义已多样，再加宙斯、阿波罗、毗湿奴、湿婆，或把上帝等同于宇宙、生命力、「生命的终极关切」。
- 克塞诺芬尼引文：埃塞俄比亚人的神黑肤扁鼻，色雷斯人的神蓝眼红发；若牛马狮子有手，就会按自己模样塑神。
- 「自由」：有人认为是能做任何想做的事，有人认为只在社会允许范围内才有意义——分歧针对的是概念，而概念决定看待世界的方式。
- 「自我」：语法上只指某人；但自我是整个人、意识、灵魂，还是由社会角色定义的社会建构？今天早上忘梳头算不算自我的事实？
- 「真理」：是「事物真实存在的方式」，还是依赖我们相信什么？我们是否被有限世界观限制，无法超出语言概念和有限经验？
- 最抽象的是用来理解世界整体含义的大概念。宗教是传达整体理解的传统渠道；在当代文化中也受到科学、艺术、法律、政治和哲学的挑战。这些包容一切的图景即最终的概念框架。
- 爱因斯坦《宗教与科学》（1930）长引：教会常与科学斗争；「宇宙宗教情感」是科学研究最强动机；开普勒、牛顿多年寂寞劳动出于对宇宙合理性的信念；唯物论时代「只有严肃的科学工作者才是深信宗教的人」。
- 概念框架通常被想当然地当作地基。建房须看土质和断层；大学生带着从未质疑的宗教、道德、政治和个人观点入学，被室友或老师一问就混乱、防御、感到被侵犯；经过哲学思考后，会重新明确相信什么以及为什么，把空隙填实，免于「思想地震」。
- 人可能同时使用多种框架：学校里的科学、周末的享乐主义、周日早晨的宗教。问题是如何联系、哪种最重要、是否互不相容；要生活得一致，是否必须把信念统一起来。
- 三位人物框：柏拉图（前 427–前 347）苏格拉底学生与代言人，因老师被处决而震惊，前 385 年创学园；亚里士多德（前 384–前 322）柏拉图学生但多不赞同，兼科学家，思想统治科学尤其生物学直到近代，为亚历山大大帝家庭教师，创吕克昂，亚历山大死后被迫出逃，称不让雅典「第二次触犯哲学家」；康德（1724–1804）终身哥尼斯堡，生活极有规律（邻居据午后散步对表），未娶，却热情支持法国大革命，扭转知识、宗教和道德的许多传统看法。

**结论**

明确表达概念框架不是任意创造思想结构，而是澄清业已相信的东西，从而更能辩护，必要时有能力改变它们。理解框架的同时就在创造、丰富、巩固它们，赋予日常生活新的意义和清晰性。

## 五、有风格地做哲学

### 论证推理链

**论据**

- 哲学质量取决于：思想的独创性、彻底性、观念联系的严密性、整套看法留给读者的鲜活程度。柏拉图、亚里士多德、康德与同时代人的想法未必相差很大，成为大哲学家是因为雄辩提出、出色辩护，并建成宏伟大厦。
- 附录一列有哲学家独特风格的例子。任何哲学文章或著作本质上都在为某种观点提出充分理由——这也是哲学训练对法律、政治、商业几乎任何职业有价值的原因。
- 不针对特定听众（哪怕只是室友或老师）的杂乱表述没有意义。哲学应当有说服力：除批判性思考和智慧外，还应当风趣、机智、有戏剧性甚至诱惑性，以绝非平凡的方式得出平凡的观点。一年级学生的稳妥思考与数百页经典，活动本身一样：尽可能吸引人地明确表达和澄清自己关于世界的看法。学完这门课，读者也将成为定义「西方」（也包括一点「非西方」）哲学世界之传统的一小部分。

**六点（实操清单）**

1. **你的思想**：没有被明确表达的思想，就没有东西可思考或写下来。
2. **批判性的思考**：未经审察、批评、发展和论证的思想还不是哲学。课上最有价值的收获之一是批判性阅读和思考：收集信息的同时细究其思想。
3. **论证**：不只陈述观点，还要用论证支持并对他人观点反驳。最好的哲学总是针锋相对。尽早预期反对意见（「你可能会反驳说……但我想指出……」）。
4. **一个问题**：不是对这个或那个话题随随便便的思考，而是被自己真正关注的问题激发。死亡与生活的意义成为哲学问题，因为我们关心生与死。知识问题来自「我们是否真知道自以为知道的」：你怎么知道现在没在做梦？怎么知道世界不是五分钟前连同化石、遗迹和记忆一同被造出来的？哲学可始于好奇，但必须关注某一个问题。
5. **想象**：一连串合理思想和论证也许算哲学，却可能死板无趣。不要害怕比喻和类比。某些最伟大哲学家把对世界的看法既写成哲学文章又写成诗。
6. **风格**：只有生动的风格可读性才强。写作好文章的规则适用于哲学，悦人耳目（激动、吸引、魅力、说服）的规则同样适用。优雅的起承转合使批评更有力。

苏格拉底本可以平淡地说「每个人都应当思考他的生活，因为至少有时能帮助我们摆脱困境」——那样也许没人记住；他说的是「未经审视的生活是不值得过的」。警句只是概括，他的整个哲学包含全部思想、形象和论证。你的哲学也应尽所能有力而优雅地明确表达和论证所相信的一切。

## 六、逻辑准备

### 论证推理链

皮尔士题辞：逻辑的核心问题是对论证分类，把坏的归一类、好的归另一类。

**论证是什么**

好哲学表述的关键是论证：用理由、例子和周到考虑支持理论。例：「我知道自己现在没有做梦，因为梦从未如此鲜活；我刚刚捏了自己；若在做梦可能已经在打鼾。」论证把信念与其他信念联系起来。论证类型包括例子、类比（「生活就像一部小说……」）、科学研究、抽象的语词之争、对对手的恶意攻击，以及徒有其表根本不是论证的东西。真假适用于陈述，不适用于论证；论证按陈述之间的关系分为好的和坏的。两大类：演绎与归纳。

**演绎**

结论的真由其他陈述的真保证。高中几何定理证明是熟例：公理依定义为真或显然为真；再经推理规则推出新陈述（一条陈述不能既真又假；「如果 A 或 B，现在非 A，那么 B」）。有时定义为：结论为真完全由前提为真保证。

三段论及其形式见上文「关键概念」。严格按照形式则演绎有效，否则无效。演绎保证结论至少与前提同样可靠：前提真则结论必然真。前提和结论都假仍可能有效（紫牛苏格拉底）。故好的演绎论证既要有效，又要前提公认为真。

用词：哲学家把「有效/无效」严格用于论证，「真/假」用于前提和结论。「三加二等于八」是假的，不是无效的；「如果苏格拉底是人，而且所有山羊都吃卷心菜，那么苏格拉底是羊」是无效的，不是假的。有效且前提为真=可靠；否则不可靠。详细有效形式见附录二。

**归纳**

即使前提为真，结论也未必为真。最常见形式是由个别事例概括：每只前齿锐利的动物都食肉 → 所有前齿锐利的动物都食肉——概括仍可能错。须细心挑选尽可能不同的事例（随机抽样）。归纳只分强弱，不说有效无效；它不可能演绎有效，但仍有其他功能。

掌握概念框对照：演绎保证前提真则结论真（狱中的 M 做不了案，故是 S）；归纳只使结论较其他可能更合理（烟斗、脚印、临行前的报复言论 → 认定有罪最能解释事实）。

归纳可支持任何目前无法直接观察的事实陈述：恺撒于前 44 年 3 月 15 日在罗马被谋杀，只能靠史书、戏剧想象、年表、政治记录、遗迹；关键是论据的融贯性。审讯中「有罪/无罪」都可能有证据，问题是哪边更一致。福尔摩斯所谓「惊人的演绎」其实多是从蛛丝马迹取事实论断的归纳。

假说组织研究：谁吃了巧克力蛋糕，室友还是小偷？找车钥匙、思考黑洞，都依赖假说和归纳。

**什么不是论证**

- 强有力地、充满信心地复述意见 ≠ 论证。
- 单独一个例子至多是论证的一部分；多数归纳需要许多例子，并应对不符合假说的例子。
- 诉诸权威性在哲学里往往正是受质疑处：以上帝存在因为《圣经》如此说，问题立刻指向《圣经》权威；以母亲或杰斐逊的政治立场，问题指向该权威。哲学的主要功用之一是质疑权威，亲自思考该信什么。单单诉诸权威未必表示尊重该权威，而表示对我们自己的不尊重。正当的权威性既要尊重，又要博得。

**对论证进行批判**

批判不等于日常的「反对」，而是认真查验论证是否真是好论证；包括对自己的立场，以便修改或巩固。

典型方式：指出演绎前提不真；指出归纳所基证据错误或虚假；表明含无效演绎或弱归纳。反例特别有力。对「没有人能够确切知道某种事物」，举起手指说「这是一根手指，我确切知道」——未必结束争论，但能使断言更精确。

即使各论证似乎可靠，哲学仍可能因不一致而出问题：从不同论证得到相互矛盾的结论。若导致悖论，必须重新审查。全能山悖论是归谬法，迫使把全能修改为逻辑上可能之事。掌握概念框另举说谎者悖论、理发师、芝诺飞矢（永远过半故永远到不了 B）。

此外：不连贯（陈述无关系或只能荒谬解释）；循环论证；愚蠢或平凡（同义反复）；人身攻击。坏论证统称谬误；形式与非形式之别见附录三。

掌握概念框「逻辑的基本概念」汇总：论证、结论、前提、演绎/归纳、有效/无效、真/假、可靠/不可靠、强/弱、逻辑=对好论证的运用与研究。

**合作与尊重**

哲学特别需要合作。论证和批判不是对抗，而是让思想及其含义变清晰。苏格拉底：最真诚的朋友也是最好的批评者；从不批评的朋友不可信任。在多元民主社会中，意见有分歧的人之间相互尊重至关重要；并非每种意见同等有价值——思考深度与论证质量使某些意见更好。合作的尊重、就论证重要性达成共识、诚恳提出否定意见，是所向往生活的前提。

同义反复框举例：「如果一个人是自由的，那么他就是自由的」；并问「公是公私是私」「男孩子总归是男孩子」、施泰因「玫瑰就是玫瑰」、尼采「你是什么，就成为什么」是否同义反复。

收束：提出哲学想法时必会兼用演绎与归纳，发现错误论证完全正常；重要的是能辨别形式。论证不是哲学的全部——结论无趣则论证也不可能有趣；但没有好论证，最好的思想也可能被认作无效或无人问津。

## 段落总结序列

### 做哲学

主旨：1. 哲学是信念与态度的总和，做哲学首先是清晰有力地陈述并发展它们。2. 信念必须彼此协调并经得起反驳，否则可能不值得相信。

最小标签集：陈述；必要依据；可替换例证；过渡/场景。

1. 【第三档·过渡/场景】章题「导言 / 做哲学」。
2. 【第二档·可替换例证】题辞：未经审视的生活是不值得过的（苏格拉底）。
3. 【第二档·可替换例证】题辞：认识你自己（德尔菲神谕，作者称为苏格拉底的箴言）。
4. 【第一档·陈述】哲学是关于自身和世界的信念及态度的总和；做哲学首先是尽可能清晰有力地陈述所思所想，但不是宣称赞成顺耳字眼，而是发展观念、发掘结构、联系他人观点并与之争论。
5. 【第一档·必要依据】学生能列出观点却说不清联系与答辩；哲学像橄榄球：必须与己方思想配合以对抗挑战；无法联系又经不起批评的信念可能不值得相信。
   （本段是第4段的必要依据）
6. 【第二档·可替换例证】苏格拉底述而不作，基于「认识你自己」和经过审视的生活，因「腐蚀青年」被处死而仍以尊严捍卫思想。
   （本段旁证第2、3段）

### 避免时髦词语

主旨：1. 时髦词语听上去具体，其实最难定义，会替代思考。2. 「定义你的术语」必要，但定义通常出现在思想结尾。

最小标签集：陈述；必要依据；可替换例证。

1. 【第一档·陈述】为思想辩护与仅仅坚持好听的词非常不同；不能说清「自由」赞成什么、为何值得追求，则与哲学或自由都无关。
2. 【第一档·必要依据】时髦词语乍听像「狗」一样具体，实属最难理解的词；人人信仰「自由」，问题是所信仰的到底是什么；真理、实在、道德、爱、上帝同样常被当徽章。
   （本段是第1段的必要依据）
3. 【第二档·可替换例证】「科学」「艺术」「国家安全」「民族自决」使广告、过激行为和政治活动正当化；主观/客观等词滥用后几乎不知所云；把术语连成串不是做哲学。
   （本段旁证第2段）
4. 【第一档·陈述】滥用说明「定义你的术语」的重要性；定义极难，多出现在过程结尾；学会新词不等于了解哲学，正如试穿冰靴不等于会滑冰。

### 明确表达和论证

主旨：1. 明确表达与论证是哲学两项重要特征。2. 分析与综合配套；最终目的是统一可辩护的看法。3. 哲学分成若干交织的领域。

最小标签集：陈述；必要依据；可替换例证。

1. 【第一档·陈述】哲学首先是反思：后退倾听并评价，尽可能清晰说出想法；一写就模糊或一讨论就有看法，说明明确表达是首要步骤。
2. 【第一档·必要依据】与人交谈会迫使表达更具体，并进入第二特征——论证；论证检验观点，如训练之于比赛。
   （本段是第1段的必要依据）
3. 【第一档·必要依据】明确表达=用清晰简洁语言说出思想；论证=用理由支持并驳斥反对；分析=区分组分（谋杀含杀害、错误、意图）；综合=结成统一看法（天球和谐）。
   （本段是第1、2段的必要依据）
4. 【第二档·可替换例证】表述和辩护使观点变成自己的；大哲学家不是博物馆展品，做哲学要借助他们的论证并加脚注。
   （本段旁证第2段）
5. 【第一档·陈述】反思、明确表达和论证指向综合：整合为独立统一可辩护的看法；凌乱想法不是哲学，正如无关语词不是诗歌。
6. 【第一档·陈述】为授课方便，哲学分成形而上学（含本体论）、伦理学、认识论、逻辑、宗教哲学、政治哲学、美学等领域，它们最终交织。

### 概念与概念框架

主旨：1. 概念赋予经验形式并组成概念框架。2. 哲学关注抽象概念（上帝、自由、自我、真理）及最终的整体框架。3. 哲学是澄清业已相信的东西，必要时重塑地基。

最小标签集：陈述；必要依据；可替换例证；限定；次要观点；续。

1. 【第一档·陈述】概念是哲学观点的基本单元，使经验有形式、使明确表达可能，并几乎总组成概念框架。
2. 【第一档·必要依据】儿童习得「狗」：从四腿动物到精确区分，并能在狗不在场时思考一般的狗；概念既指导行动，也划分世界。
   （本段是第1段的必要依据）
3. 【第二档·次要观点】犬儒主义得名于「狗」，因苦行在同时代人看来比狗好不了多少。
   （本段旁证第2段）
4. 【第一档·限定】来自经验的称经验概念；先于经验、须在抽象系统中定义的称先天概念（如数、无理数）。
   （本段限定第1段）
5. 【第一档·必要依据】经验知识基于观察实验；先天知识独立于特殊经验（2+3=5）。
   （本段是第4段的必要依据）
6. 【第一档·陈述】哲学关注最困难的抽象概念；「好人」「良好生活」因社会而异；「上帝」困难到有的宗教拒绝定义。
7. 【第二档·可替换例证】希腊众神、印度教神祇，或把上帝等同于宇宙、生命力、终极关切，说明仅就语词达成一致不能解决「上帝是什么」。
   （本段旁证第6段）
8. 【第二档·可替换例证】克塞诺芬尼：各族按自己形貌说神；若牲畜有手也会按自己模样塑神。
   （本段旁证第6段）
9. 【第二档·可替换例证】「自由」或被定义为能为所欲为，或仅在社会允许范围内有意义——分歧针对概念，概念决定看待世界的方式。
10. 【第二档·可替换例证】「自我」在语法上只指某人，但未定义它是整个人、意识、灵魂还是社会建构。
11. 【第二档·可替换例证】「真理」是事物真实存在的方式，还是依赖信念？我们是否被有限语言和经验限制？
12. 【第一档·陈述】最抽象的是理解世界整体含义的大概念；它们构成最终概念框架，也可称为生活方式、意识形态、舆论气候或世界观。
13. 【第二档·可替换例证】爱因斯坦认为宇宙宗教情感是科学研究最高尚动机，开普勒与牛顿的寂寞劳动出于对宇宙合理性的信念。
   （本段旁证第12段）
14. 【续 13】续：被怀疑世界包围的研究者靠这种情感坚持志向；有人说唯物论时代只有严肃科学工作者才是深信宗教的人。
15. 【第一档·必要依据】框架通常被想当然当作地基；大学生未加质疑的信念一经挑战会混乱，哲学思考后才能填实空隙、重塑信念。
    （本段是第12段的必要依据）
16. 【第一档·限定】人可能同时使用科学、享乐、宗教等多种框架，必须追问如何联系、哪个最重要、是否必须统一才能生活得一致。
    （本段限定第12段）
17. 【第二档·可替换例证】柏拉图创学园传播苏格拉底；亚里士多德多不同意老师且兼科学家，为亚历山大教师；康德终身哥尼斯堡，生活极规律却发动知识、宗教与道德上的革命。

### 有风格地做哲学

主旨：1. 伟大哲学靠雄辩、辩护和体系化，而不只靠想法与众不同。2. 做哲学需要思想、批判、论证、真正的问题、想象和风格。

最小标签集：陈述；必要依据；可替换例证。

1. 【第一档·陈述】哲学质量取决于独创性、彻底性、联系的严密性和鲜活印象；柏拉图、亚里士多德、康德成为大家，是因为把相近想法建成雄辩可辩护的大厦。
2. 【第二档·可替换例证】任何哲学著作都在为某种观点提供充分理由，故哲学训练对法律、政治、商业几乎任何职业都有价值。
   （本段旁证第1段）
3. 【第一档·必要依据】哲学应针对听众、有说服力，风趣甚至诱惑，以不平凡的方式说出平凡观点；一年级习作与经典的活动本身相同。
   （本段是第1段的必要依据）
4. 【第一档·陈述】六点：必须有被明确表达的思想；必须经批判发展；必须用论证支持并反驳；必须被一个真正关心的问题激发；需要想象与比喻；必须有生动风格。
5. 【第二档·可替换例证】做梦怀疑与「世界五分钟前被造出来」说明知识问题如何被真正的不安激发。
   （本段旁证第4段）
6. 【第二档·可替换例证】苏格拉底若说得平淡，警句不会被记住；「未经审视的生活是不值得过的」有力，但仍须有全部思想与论证撑住。
   （本段旁证第4段）

### 逻辑准备

主旨：1. 好哲学表述的关键是论证，逻辑把好论证与坏论证分开。2. 演绎有效且前提为真才可靠；归纳只有强弱。3. 批判用反例、不一致性、悖论等；哲学同时是合作。

最小标签集：陈述；必要依据；限定；例外；可替换例证；次要观点。

1. 【第二档·可替换例证】皮尔士：逻辑的核心是把坏论证与好论证分类。
2. 【第一档·陈述】哲学必须为观点提供理由；论证就是用理由支持想法，不必充满敌意，最好由正当推理的科学即逻辑来规定。
3. 【第二档·可替换例证】论证可用例子、类比、科学研究或纯言辞；也有人身攻击和徒有其表者。真假属于陈述，好坏属于陈述间关系。
   （本段旁证第2段）
4. 【第一档·限定】论证方便地分为演绎与归纳，评判标准随类型而变。
   （本段限定第2段）
5. 【第一档·陈述】演绎中结论之真由前提之真保证；几何证明与推理规则是熟例；最著名形式是三段论。
6. 【第一档·必要依据】严格合形式则有效：前提真则结论必然真；前提全假仍可有效（紫牛苏格拉底）；好的演绎须既有效又前提为真，即可靠。
   （本段是第5段的必要依据）
7. 【第一档·限定】「有效/无效」只用于论证，「真/假」只用于陈述。
   （本段限定第6段）
8. 【第一档·陈述】归纳即使前提为真结论也未必为真；由个别概括是最常见形式，必须多样抽样，只分强弱不分有效无效。
9. 【第一档·必要依据】演绎保证前提真则结论真；归纳只使某结论更合理。归纳可支持无法直接观察的事实（恺撒被刺），关键是融贯性；福尔摩斯的「演绎」其实是归纳。
   （本段是第8段的必要依据）
10. 【第二档·可替换例证】假说组织归纳：谁吃了蛋糕、钥匙在哪、黑洞是否存在，都先有假说。
    （本段旁证第8段）
11. 【第一档·例外】强有力复述意见、单个例子、单纯诉诸权威都还不是论证；哲学要质疑权威并亲自思考。
    （本段标明第2段通例在此处不适用）
12. 【第一档·陈述】批判是查验论证是否真好，包括对自己的立场；方式含否定前提或证据、指出无效或弱归纳、举反例。
13. 【第二档·可替换例证】「所有美国人都热爱足球」举一个不喜欢的美国人即可反驳；对「没人能确切知道任何事物」可举起手指。
    （本段旁证第12段）
14. 【第一档·必要依据】各论证看似可靠仍可能不一致或导致悖论；全能山是归谬法，可把全能改为逻辑上可能之事。
    （本段是第12段的必要依据）
15. 【第二档·可替换例证】说谎者句、理发师、芝诺飞矢说明悖论如何逼人重新表述。
    （本段旁证第14段）
16. 【第二档·可替换例证】哲学还可能不连贯、循环论证、沦为同义反复，或用人身攻击。
    （本段旁证第12段）
17. 【第一档·陈述】形式谬误违背推理规则，非形式谬误用含混、偏颇或回避来欺骗；细节见附录三。
18. 【第一档·必要依据】逻辑基本词汇：论证、结论、前提、有效/可靠、归纳强弱。
    （本段是第2段的必要依据）
19. 【第一档·陈述】哲学是合作：最好的朋友是最好的批评者；多元社会须尊重分歧，但意见并不同等有价值。
20. 【第二档·次要观点】同义反复例如「若自由则自由」；并追问若干俗语是否也是同义反复。
21. 【第一档·陈述】提出想法时必兼用两种论证，发现错误正常；但结论无趣则论证无趣，没有好论证则最好的思想也会无人问津。

### 篇末问题与阅读建议

主旨：1. 用十三则论证练习区分演绎/归纳与有效/可靠。2. 进一步阅读指向标准逻辑教材。

最小标签集：陈述；可替换例证；过渡/场景。

1. 【第一档·陈述】篇末要求判断一组论证是归纳还是演绎、是否有效可靠、还错在何处。
2. 【第二档·可替换例证】题目覆盖因果决定论、上帝与意义、错位三段论、以偏概全的实用主义、笛卡尔式「我疑故我在」、看不见狐狸、威胁、诉诸圣经、外貌定罪、肯定后件、柏拉图城邦类比、以及「两人不在家所以在一起」的弱归纳。
   （本段旁证第1段）
3. 【第二档·可替换例证】阅读建议列出 Copi、Engel、Fogelin、Hurley、Weston、Wright 等逻辑与论证教材。
4. 【第三档·过渡/场景】导言结束，进入第一章。
