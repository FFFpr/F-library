# 附录二 演绎逻辑：有效的论证形式

## 本章位置

本附录接导言「逻辑准备」：那里已经区分陈述的真假与论证的有效无效，并定义可靠=有效且前提为真。这里把「有效」再落实为一套可检验的形式，并给出肯定前件、否定后件、归谬法，以及必须躲开的肯定后件、否定前件。附录三处理并不违反形式、却仍然不好的非形式谬误。

> 💡 演绎、归纳、可靠/不可靠的定义详见：[导言.md](导言.md)  
> 💡 非形式谬误详见：[附录三_常见的非形式谬误.md](附录三_常见的非形式谬误.md)

## 核心论点

1. **即使前提和结论全假，论证仍可能有效**；要保证结论为真，必须前提为真并且形式有效。
2. **有效=具有正确形式**，正确形式基于推理规则。检验办法：若能找到「同形式、真前提、假结论」的例子，该形式就无效。
3. **最熟悉的演绎形式是直言三段论**（两前提一结论，含中项）；并非所有演绎都是三段论。
4. **肯定前件与否定后件有效**；看起来像它们的肯定后件、否定前件无效，必须避免。
5. **归谬法是一种有特殊哲学用途的否定后件**：从 P 推出荒谬的 Q，从而否定 P。
6. **憎恶逻辑（misology）是比论证失败更大的不幸**：因反复失望而认定没有任何论证可靠。

---

## 关键概念补全

**有效论证形式**：一套推理规则所允许的结构。有效不保证结论真，只保证：若前提真，则结论不能假。

**检验无效的办法（实操）**：把可疑论证译成「所有 P 是 Q……」之类形式符号，再找另一则同形式但前提真、结论假的论证（「那就好比说……」）。只要有一例，该形式就不是有效形式。

**直言三段论**：由两个前提和一个结论组成；两前提项都含中项。陈述在量上有全称/特称等分别。OCR 对量词细节残缺，正文只强调「并非所有演绎都是三段论」。

**肯定前件（modus ponens）**：如果 P，则 Q；P；因此 Q。

**否定后件（modus tollens）**：如果 P，则 Q；非 Q；因此非 P。

**肯定后件谬误**：如果 P 则 Q；Q；因此 P。例：起床太晚则错过早饭；你错过了早饭；因此你起床太晚。

**否定前件谬误**：如果 P 则 Q；非 P；因此非 Q。例：起床太晚则错过早饭；你起床不晚；因此你没有错过早饭。

**归谬法（reductio ad absurdum）**：主张 P；若 P 则 Q；Q 显然荒谬故假；因此 P 假。例：若正义是强者所坚持的任何东西，则强者不公正也就是公正的——荒谬，故原主张假（苏格拉底的著名论证）。攻击一种哲学的好办法：说明它表面合逻辑，结果却荒谬。

## 一、有效与形式检验

### 论证推理链

**论据 / 案例 / 事实**

- 绿狗苏格拉底：所有的狗都是绿的；苏格拉底是狗；因此苏格拉底是绿的——有效，但前提和结论都假。
- 有效三段论形式：所有 P 是 Q；S 是 P；因此 S 是 Q。
- 无效：所有 P 是 Q；S 是 Q；因此 S 是 P。反例：所有柠檬都是黄的；萨姆（金丝雀）是黄的；因此萨姆是一个柠檬。

**推导**

演绎有效的定义就是前提真能保证结论真。故若存在同形式的真前提+假结论，该形式无效。哲学里怀疑某论证无效时，先符号化，再构造「那就好比说」的反例。

**结论**

有效是形式问题；可靠还要求前提为真。

## 二、肯定前件、否定后件及其赝品

### 论证推理链

**论据**

- 肯定前件例：如果苏格拉底老是给人添麻烦，那么他将会有麻烦；他不会停止给人添麻烦；因此他将会有麻烦。
- 否定后件例：如果你足够认真，那么你将考第一；你没有考第一；因此你不够认真。
- 两种赝品必须避免：肯定后件、否定前件（早饭例子见上）。
- 满足形式只保证有效，是否正当仍取决于前提是否为真。
- 归谬法：正义=强者意志 → 强者不公正即公正 → 荒谬 → 否定原主张。

**结论**

先认形式，再查前提；用归谬法攻击表面合逻辑的立场。

## 三、憎恶逻辑与推理规则表

### 引文资料：憎恶逻辑

柏拉图《斐多篇》：苏格拉底警告「憎恶逻辑」类似憎恶人——因对最亲近者反复失望而认定任何地方都找不到真诚。对论证也一样：未用逻辑技艺就轻信某论证为真，随后多次发现它是错的，最后自以为比谁都聪明，认定事实和论证中没有任何稳定可靠的东西，一切像渠中流水。但若存在真实而有效的论证，却一生抱怨论证、错过认识实体真理的机会，乃可悲之事。

## 段落总结序列

### 有效与形式检验

主旨：1. 有效是形式，可靠还要前提为真。2. 能构造真前提假结论的同形式例子，该形式就无效。

最小标签集：陈述；必要依据；可替换例证。

1. 【第三档·过渡/场景】附录题：演绎逻辑 / 有效的论证形式。
2. 【第一档·陈述】导言已区分陈述真假与论证有效无效；前提结论全假仍可能有效（绿狗苏格拉底）；要保证结论真，须前提真且有效。
3. 【第一档·必要依据】有效论证具有正确形式，基于推理规则；全称三段论「所有 P 是 Q；S 是 P；故 S 是 Q」有效，「S 是 Q 故 S 是 P」无效。
   （本段是第2段的必要依据）
4. 【第二档·可替换例证】柠檬都黄、金丝雀萨姆也黄、推萨姆是柠檬，证明后一种形式无效。
   （本段旁证第3段）
5. 【第一档·陈述】怀疑哲学论证无效时，先译成形式符号，再找同形式真前提假结论的「那就好比说」。
6. 【第二档·可替换例证】最熟悉的是直言三段论（两前提一结论，含中项）；并非所有演绎都是三段论。

### 肯定前件、否定后件、归谬法

主旨：1. 肯定前件与否定后件有效。2. 肯定后件与否定前件是必须避免的赝品。3. 归谬法是哲学上特别有用的否定后件。

最小标签集：陈述；必要依据；可替换例证；例外。

1. 【第一档·陈述】肯定前件：如果 P 则 Q；P；故 Q。否定后件：如果 P 则 Q；非 Q；故非 P。
2. 【第二档·可替换例证】苏格拉底添麻烦会有麻烦；认真才能考第一——分别例示两种形式。
   （本段旁证第1段）
3. 【第一档·限定】满足形式只保证有效，是否正当仍看前提是否为真。
   （本段限定第1段）
4. 【第一档·例外】貌似二者、实为无效的是肯定后件与否定前件；早饭例子说明二者必须避免。
   （本段标明第1段通例在赝品处不适用）
5. 【第一档·必要依据】归谬法：从 P 推出荒谬的 Q，从而否定 P；正义=强者意志是苏格拉底式例子；攻击哲学的好办法是揭示其荒谬后果。
   （本段是第1段的必要依据）
