# 卷一 第07章 全球商业化中的设计

## 本章位置

第六章承认理想 HCD 撞上预算。本章把真空外的力写全：竞争、功能蔓延、科技融合、从构想到被接受的几十年、渐进 vs 颠覆，以及原则为何能用到 2038。致谢在下一篇。

## 核心论点

1. 真空中的以人为本不存在。厂家主要靠价格、功能、质量竞争（重要性也常是这个次序），速度怕被人抢先，完整迭代很难。
2. **功能主义 / 功能蔓延**：成功产品会被用户愿望、对手对标、饱和后的升级点逼着加功能，却无人要求、也无预算删旧功能。穆恩：对标会让产品同质化；应让强者更强，忽略不相干劣势。贝索斯「被用户附体」。
3. 科技改变外观与交互，基本心理需求不变。手势词形输入仍困在 QWERTY。阅读远快于聆听。
4. 发明可数月，文化接受要几十年。经验法则：实验室到商用约 20 年，商用到普及再 10～20 年；多数创新完全失败。可视电话 1879 年已入画，约 2010 年才在昂贵会议室流行。
5. 渐进式（登山法，HCD 核心）最常见也最有影响力；颠覆式改变模式但稀少、失败多、要很久。HCD 适合渐进，不能引发颠覆。
6. 人+机器比单独的人或机器更强（分布式认知，自由式象棋）。科技改任务，不使人变蠢。原则仍适用，因心理不变。

## 关键概念补全

**时代思潮 (Zeitgeist)**：时机成熟则主意「风行」，不是被偷。作者参与的厨具创业刚要出手工模具样品，展会上已有相似概念；真客户是经销商。

**功能蔓延 (creeping featurism)**：1976 年命名。乐高警摩从 15 件无说明书变成 29 件要说明书。

**斯蒂格勒法则**：创新常被记在成功商业化的名人/公司头上，原发明者被忘。

**登山法 (hill climbing)**：每步若更好就留下。保证爬到当前山峰，发现不了更高的山——那要颠覆。

**QWERTY**：为减少机械连动杆碰撞而拉开高频字母，并非为了减慢；两手交替反而快。德沃夏克略优但不够推翻既得利益。「足够好」的胜利。

## 一、竞争压力与功能主义

### 论证推理链

**论据 / 案例 / 事实**

- 家电汽车电脑仍常在未充分测试时上市。创业厨具：实地、样品、世界级工业设计，多次按用户与专家改；大公司无钱硬拼，须改方案取悦投资者、经销商和用户。成熟公司 1～2 年周期，下一型号在上一型号交给客户前就得开做。有的公司禁止设计师接触客户，防泄密、防客户等新品不买现货。诺曼法则在此重申。
- 蔓延三因：现用户要更多；对手在加；市场饱和要亮点促换代。音乐播放器手机电脑汽车冰箱电视灶具都更大更复杂。穆恩《差异》：一一对应对手最终无人可偏爱。贝索斯无视竞争问用户要什么；创始人兼 CEO 才较可能做到，交给传统 MBA 后短期利润或升、质量终降。

**推导**

竞争把「完整 HCD」变成奢侈。功能一一对标是致命诱惑。

**结论**

优秀设计要领导能挡住市场部每条「某细分很重要」。焦点在真正使用者。

## 二、新技术、上市时间与可视电话

### 论证推理链

**论据 / 案例 / 事实**

- 电话：摇柄人工转接 → 十孔转盘 → 12 键（+*#）→ 手机触摸。电脑与电话融成「智能屏幕」。大触屏逼物理键盘消亡；词形追踪（Swype）仍基于 QWERTY，翟树民/IBM 优化布局败于习惯。读约 300 词/分、略读上千；听约 60，压缩培训或可翻倍仍落后且难略读。书写五千年角色在变，非正式短信息增多。3D 打印、游戏、电动/混动——说得出的行业几乎都会被改，有时更好有时只因技术而变。
- 多点触控 1980 年代初多伦多大学，三菱卖给院校；到消费市场约 30 年。大公司不容失败；小公司可跳点子。加州失败是荣誉。FingerWorks 将崩被苹果买下。QuickTake、早期数码相框因贵、市场未弃胶片而失败，后人成功。胶片电影/数字放映、HDTV（NTSC/PAL/SECAM、台与计算机争标准）都耗几十年。
- 杜·莫里耶 1878/79《潘趣》「爱迪生的视频电话」宽屏平板，爱迪生其实没做。贝尔 1890 年代才想细节。能工作的视频电话约 40 年到 1920s，德国 1930s 中期产品失败；1960s 美商业服务再失败；2010 左右高价沉浸式会议室（思科连桌子）才流行，个人智能屏仍比不上，也比不上同屋面对面。杜里埃汽车、第一台打字机、第一数码相机、Altair 8800 都是首次商用失败。

**推导**

想到主意容易，细节、可靠、负担得起、公众接受极难。太超前会失败，即使别人后来做成。

**结论**

用十年而不是月份来想「点子到成功」。多数创新公众永远看不见。

## 三、打字机键盘；渐进与颠覆

### 论证推理链

**论据 / 案例 / 事实**

- 早期圆盘、钢琴式、长方形三种；机械连杆决定键大小间隔。肖尔斯为防连动杆卡住重排，成雷明顿/QWERTY（欧有 QZERTY、AZERTY、QWERTZ）。传言「为减慢」是错的。未证实故事：销售为能在第二行打 typewriter 把 R、P 移到第二排；早期图第二排是句号不是 R。第一个雷明顿模型未成功。腕管综合征：分离键盘、托盘、垫、休息。德沃夏克 1930s 略快，作者实验室认为不够推翻；字母序键盘因不知在哪换行，并不比随机快。音节式法庭键盘 300+ 词/分，知识全在脑子里，键上标不出组合，临时速记员没好运。
- 渐进：蒸汽车约 1700，本茨 1888 商用是颠覆，其后百年渐进让车更静更快更安全按通胀更便宜。杜里埃作为美国第一家只活几年。打字机、汽车、电灯、飞机、广播电视、家用电脑、社交网络、手机、分组交换都是颠覆，伴随社会代价（污染、车祸每年超百万死）。真空管、半导体、GPS、互联网把出版电话电视音乐重定义为信息形式，游戏混合影视与书。每年百万级渐进，颠覆极少。可能待颠覆：教育、交通、医药、住宅。登山法是 HCD 核心，找不到别的山。

**推导**

遗产布局（QWERTY）因「足够好 + 既得利益」锁死。颠覆改变生活模式，渐进把产品做完善，都需要。HCD 在现有山上爬，不发明新山。

**结论**

人人想要颠覆，事实是多数颠覆失败，成功也要几十年。

## 四、1988～2038、智慧、书与道义

### 论证推理链

**论据 / 案例 / 事实**

- 法谚：改变越多终归于同。人类进化以千年计，文化十年到世纪，亚文化一代可变。社交、通讯、音乐、吃不会消失，技术只改形状。预测「下一个伟大变革」应看这些基本项，加上教育商业交通自我表达艺术性，以及健康食衣住。门、锁、龙头仍难用，新困惑来自智能设备、大数据、社交网络。手势、穿戴/墙面/眼内显示、语音、AI 恒温器到汽车。植入假肢听力晶体记忆通信或造半生物半技术合成人；机器更像人。皆有伦理。
- 苏格拉底/柏拉图忧书籍削弱记忆与辩论。作者：不再记电话号码是解放琐碎。布伦乔夫森：自由式象棋胜者是人机协作；卡斯帕罗夫：业余+三机+好程序胜大师与更强计算机。「弱队员+机器+好程序」> 强机或「强队员+机器+劣程序」。哈钦斯分布式认知。作者《增进智慧之事》：无助的头脑被高估，外部辅助让人聪明。
- 书何必线性？非虚构可跳读；小说或仍要次序。作者早年交互电子书尝试因太早失败。专业设计有道义：产品影响生活。DIY/草根改变构思与上市（自序所称草根崛起）。原则能再用 25 年，因须满足人的需求与能力，而心理特点不变。

**推导**

科技改任务分配，人机结合强于任一方。原则迁移到新手势与植入，不迁移到「人已变成另一种物种就不需要示能」。

**结论**

《设计心理学》适用于 20 世纪，增订本为 21 世纪而写；心理不变，应用方式要调。

（道义、书籍未来、草根在原文后半与自序呼应；笔记不另用他书补细节。）

## 段落总结序列

主旨：商业竞争与功能蔓延扭曲理想设计；创新要按十年计；渐进普遍、颠覆稀少；原则因人类心理不变而仍有效。
