# 卷三 个人感想及致谢

## 本章位置

卷三收束。交待情感三层次如何从认知科学、产业与机器人顾问工作拼起来，以及手稿如何从《日常用品的未来》改写成以情感为框架。

## 核心论点

1. 「这本书的诞生是乔治·曼德勒的错」：聘作者到刚成立的 UCSD 心理系，促成《记忆与注意》《人类信息处理》（与林德赛），并转入失误与事故——「多数人类失误其实是设计失误」。
2. 与吉布森暑假共事的愉快争辩（作势拿掉助听器）加上对失误的兴趣，写出卷一。曼德勒也是情感名家，但作者当时仍不知如何把情感接入认知与产品。1979 年认知科学大会「十二个问题」把情感列为第十二；奥托尼因此转向情感研究，多年后在西北大学把作者拉回来。
3. 1993 离学术：苹果副总裁、惠普、在线教育；1998 与尼尔森办咨询，接触各产业；再回西北计算机系，一半大学一半公司。产业让他看到：人们往往更在乎外观与感觉，而不是多好用、有什么功能。
4. 与奥托尼、雷维尔重读文献：情绪情感不可从认知、行为、动机、人格切开。格罗斯的进化机器人公司顾问工作让他认定机器人需要情感；1986 与夏利斯写的「意志」控制已被用于机器人。三层次主张用来统合美/乐趣 vs 营销定位 vs 实用困难——采购与使用的不同时刻各层权重不同。
5. 先有一本缺凝聚力的《日常用品的未来》课堂失败；用情感框架重写后学生反响好。18 章收成 7 章+序+后记，米勒督促两次大改。

## 段落总结序列

主旨：情感设计是认知科学、产业观察与机器人问题碰到一起的产物；三层次用来解开「好用 vs 好看 vs 营销」的表面矛盾。

最小标签集：陈述 / 必要依据 / 次要观点 / 可替换例证

1. 【第一档·陈述】曼德勒把作者推进记忆、失误与设计。
2. 【第二档·可替换例证】与吉布森争示能，写成卷一。
3. 【第一档·必要依据】产业十年让作者感到情感影响；奥托尼与雷维尔提供科学，机器人顾问提供应用。
4. 【第一档·陈述】三层次统合相悖主题；放弃旧稿以情感重写。
5. 【第二档·次要观点】编辑、实验室、CHI、学生把 18 章收成可读的 7 章。
