## 核心论点

1. 人是社会性动物，会自发把人类动机、信念、感情赋予动物和无生命物（拟人化）；物展现的行为越多，越容易被当社会行为人。
2. 责备与赞扬是反思层的社会性判断；只有把机器当成能做决定的动因，才会对其发火。对现代科技发脾气往往合理——系统不透明、不道歉、还像在责备用户。
3. 信任＝信赖、信心、正直；对设备而言是反复按预期完成任务。概念模型与持续反馈决定信任能否建立。
4. 合作依赖信任，信任也是弱点：复杂检查会造成旁观者冷漠；过严过复杂的安全反而逼人把密码写下来。安全更像社会问题，不是纯技术问题。
5. 社交互动是几乎能保证成功的产品类别；短信与即时通讯的真正目的常是联络感情与存在感，不是传递信息。
6. 一个人的「保持联系」是另一个人的干扰；有意识注意力在反思层且能力有限。设计的共同主题是把控制权交回使用者。

## 关键概念补全

**拟人化**：将人类的动机、信仰和感情赋予动物和无生命物体。来自解读他人情感的生物遗传：面部、身体语言是情感启动肌肉的副产品。

**福格五种社交提示**：身体的（脸、眼、身体、动作）；心理的（偏好、幽默、性格、感情、移情、「对不起」）；语言；社会动力学（轮换、合作、表扬、回答、互惠）；社会角色（医生、队友、对手、老师、宠物、向导）。

**责备/赞扬的情绪结构**（据奥托尼、克罗尔、柯林斯，作者略改为强调设计）：负面结果＋责己→懊悔、生自己的气、羞愧；责人→生气、失望。正面＋功归己→骄傲自满；功归人→感激钦佩。希望＝预期正面；焦虑＝预期负面；未发生则解脱或失望。

**旁观者的冷漠**：围观越多、插手越少。拉坦纳与达利实验室与实地重现；源于人人假设别人会行动或「若严重周围早该反应」。

**飞行员人力资源管理**：非驾驶中的飞行员必须积极检查询问；质疑被重新定义为尊重而非不信任。

**持续地分散注意力**：琳达·斯通对频繁短交流、不断打断的描述。

## 一、拟人化：可怜的椅子也有心事

### 论证推理链

**论据 / 案例 / 事实**

- 图5.1：椅子的球掉了，伸出脚想在人发现前拿回来。作者不相信椅子有生命头脑，反应却完全感性。
- 情感与行为联系密切：情感系统启动肌肉准备动作，他人即可从紧张放松、脸、四肢读出心理状态。经数百万年，理解别人的能力成为生物遗传，也可用于近似生命的事物。
- 对动物同样有用，因面部手势身体姿势同源。无生命物的人性化诠释看来古怪，来源相同。网球拍、球、手工工具干得好就称赞，不如期望就责备。
- 李维斯与纳斯多次实验：人们对待电脑、电视和新媒体的方式像对待真实人物和场所。福格《说服性科技》：人们把电脑视作社会行为人。
- 对椅子屈服于身体层面；对电脑常关注社会动力学（或不当的社会动力学）。互动越像轮换、语言、常规应答，越可能被视作社会行为人。清单适用于人、动物、生物、无生命物。
- 推断椅子心理并无事实基础，对他人也一样：并不比接近椅子更接近另一个人的思想。对别人的判断是观察与推断。对自己思维也掌握不多：只有反思层有意识；大多数动机信念感觉在本能行为层潜意识运作。反思设法理解潜意识，所以需要心理医生，也才有弗洛伊德本我、自我、超我。
- 最初诠释自发、建于本能，不能控制；可通过反思分析控制最终情绪。这种行为润滑社会互动齿轮。
- 设计师请注意：拟人化一方面可带来极大快乐——运作正常、优雅漂亮好玩时，我们赞美甚至强烈依赖产品；行为受挫时则埋怨。为人与产品设计愉悦有效互动的原理，跟人与人之间一样。

**结论**

人总会把情感投射到物上。设计互动，等于设计一段社会关系。

### 实操方法与设计原则

- 互动越强，越要按社交提示（表情、轮换、道歉、角色）来设计，否则会被读成无礼的社会行为人。
- 正面拟人化能制造依恋；失败时同样会变成被责备的「人」。

## 二、责备没有生命的物品

### 论证推理链

**论据 / 案例 / 事实**

- 再引「电脑狂躁症」：厌烦→手心出汗→捶打电脑朝屏幕大叫→可能痛打旁边的人。
- 机器目前不会生气、没有意图。生气来自我们的思维方式：我们认为自己做的每件都正确，不恰当就是电脑的错。「我们」来自反思层。负面判断带来负面情绪，再使判断火上加油：不愉快→不满→生气→愤怒。
- 责备/赞扬比单纯愉悦不满更复杂，需把机器视为非预谋动因、能做决定——即拟人化。本能行为层无法确定因由；理解、诠释、找原因是反思的责任。丰富深刻的情感多在找出缘由之后。
- 期望被违背就破坏信任，很快生气。合作依赖信任：含蓄明晰的期望、明确意图、清楚迹象。简单机器因操作简单、符合期望而被信任；支架刀片折断已是小物最严重过错。复杂机械故障更多，人会喜欢或痛恨汽车等。最惹气的是电子设备尤其电脑（手机正迅猛发展）：制造商承诺奇妙功能，技术看不见、神秘、反复多变、自相矛盾；无法掌控，信任变愤怒。
- 作者认为对现代科技发脾气有道理：不理智又如何？是电脑、软件、还是程序设计师忽视真正需求？用户不在乎这些，在意它妨碍生活。「他们」包括电脑发展的所有人与物。系统丢失文件死机常无明显原因，毫不羞愧自责，不道歉，似乎在责备毫不知情的用户。被激怒是合理反应。

**结论**

怒火烧向物品，是因为反思层在找责任人，而系统拒绝扮演可被理解、会道歉的合作者。

### 实操方法与设计原则

- 减少怒火的设计：可见的运作、可理解的失败原因、道歉与补救，而不是把过错推给用户。
- 期望来自广告、实际可靠性、概念模型——三处都要一致。

## 三、信任和设计

### 论证推理链

**论据 / 案例 / 事实**

- 一位回复者谈 10 英寸三叉牌（Wüsthof）厨刀：手感美感之外，情感依恋主要基于切身体验带来的信任。知道无论切什么都游刃有余，不会滑落、刀刃不会折、异常锋利可切断骨头、不会毁待客食物。讨厌在别人厨房用他们的刀，即使质量很好。耐用品一生买一到两次；情感随千百次持续正面体验增长，物品成为朋友。
- 信任特性：信赖、信心、正直。对人是性格；对设备是反复多次可靠完成任务。对信任系统抱很高期望：「准确地按预期完成任务」意味着已设定特定期望。来源：广告推荐、购买后表现、以及概念模型。
- 良好准确的概念模型 + 产品一直让你知道它在做什么、到哪一阶段、是否顺利 → 结果不意外。
- 燃油表：多数人知道百分比；希望快没油时闪灯；有人觉得表太保守、想给回旋余地。表显示空、灯闪、你拖沓把油用完 → 责备自己，反而更信任车。灯不亮 → 责备汽车。表上下波动 → 不知道如何解释，不相信。新车须测试信任：把读数开低再加油；真正测试是故意把油用光，多数人不需要那么确切。有的车有剩余里程。信任必须由经验获取。

**结论**

信任不是第一眼产生的，是概念模型被一次次证实之后长出来的。

### 实操方法与设计原则

- 反馈必须让人能校准「还剩多少」「还能不能信」。
- 宁可让人责备自己没按警告行事，也不要让指示器不可读。
- 耐用品的情感是用出来的，不是外观一次性买到的。

## 四、生活在一个不可靠的世界

### 论证推理链

**论据 / 案例 / 事实**

- 米特尼克与西蒙《欺骗的艺术》：信任同伴是天性，尤其要求看起来合理时；社会工程师利用这一点。日常物品越来越多芯片、联网，须提防偶然伤害、恶作剧、恶意欺骗。
- 提高安全常用严格程序与重复检查；参与检查的人越多，安全性下降——旁观者冷漠。基蒂·吉诺维斯 1964 年纽约街头被杀，多人目击无人援手；起初谴责纽约冷漠，拉坦纳与达利重现：围观越多帮忙越少。独自可能寻求帮助；人群中会假设若严重别人早该动，没人动就表示没事，甚至以为在拍电影。
- 电力公司仪表：你信同事，主管还会再查 → 你不特别在意。人人这样想。越多人负责，每个人越不仔细。信任阻碍工作。
- 商用航空「飞行员人力资源管理」对抗此趋势：两人轮流开，非驾驶者充当积极批评者，不断检查询问；驾驶者应感谢问题，即使不必要或错误。困难在于文化，尤其资历差时——质疑像缺乏信任。航空界花时间把质疑学成尊重；资深者坚持要求资浅者质疑。安全系数提高。
- 罪犯会重复触发警铃再躲起来，保安找不出原因，最后不再相信，再乘虚而入。少数人破坏力强，社会常被迫对每个人每件事怀疑。取舍残酷：使安全更缜密的事物往往让生活更难甚至不可能。需要出自对人类行为了解的实际措施。安全更像社会/人类问题：想偷窃贿赂破坏的人总会找利用人性的方法；过多科技反而妨碍安全，因尽责完成日常变得更难。密码或程序太复杂，人记不住，写下来贴屏幕、放键盘电话下、放抽屉前端。
- 作者任美国国家研究委员会委员研究信息科技与反恐怖主义，发现社会工程原理流传数世纪，前罪犯、执法书、犯罪小说指南、网络都容易找到资料。总论点：抱着一堆设备请人开门、在空房间找贴着的账号、或开口问「有人记得这台电脑的密码吗」，许多人会回答。图：显示器边纸条写着密码；电脑在办公家具制造商总部，「CHAIR」谁还需要猜。恼人的密码规则逼人依赖纸条。
- 当安全程序妨碍善良忠诚员工，他们会找应对方式使程序失灵。让人高效合作有创造性的特质，也让人难防被利用。

**结论**

信任是合作必需，也是攻击面。设计安全若不顾人如何图省事，人就会把安全拆掉。

### 实操方法与设计原则

- 检查人数加到某点之后会降低而不是提高安全；需要明确的「必须质疑」角色（航空模式）。
- 密码规则若导致纸条贴屏，规则本身就是漏洞。
- 安全失败首先当社会与流程问题处理，不要只加技术。

## 五、情感交流：短信、即时通讯与手机

### 论证推理链

**论据 / 案例 / 事实**

- 塞内加：到处都有就是到处都没有；终生在国外旅游，结识很多人但没有朋友。作者被问下一个杀手级应用：精确预测不可能，正确预测也可能很久才发生（自动驾驶也许 20 年也许 100 年；视频电话「几年内普及」已说了 50 年）。几乎能保证成功的是社交互动。100 年来科技变，交流重要性仍高：信、电话、电邮、手机、即时通讯、短信；机构还有电报备忘录传真内联网；群体有小商贩日报广播电视。
- 旅行变容易曾削弱纽带。现在电邮即时通讯短信语音邮件打破时空；全球每天数十亿短信。多数短信没什么内容：watrudoin、wru、cul8r；上班族「无聊的会议」「下班喝一杯」。频繁通讯目的不是分享信息，是联络感情：「我在这里」「你在那里」「我们仍然彼此喜欢」。为舒服安心需要不断沟通。
- 短信优点：做其他事时可同时用。可在上课开会甚至交谈时偷偷回。回复者：没有 IM 像窗户被关上；真正力量不是通讯而是存在感——拿起电话就知道将有真实的人、正是你要找的人来接。手机基本上是情感工具和社交助手，内容不够正式反思，却充满情感。
- 话机本身却不是情感对象：人们爱互动力量，不爱设备，更换频率极高，无产品忠诚度。
- 弗诺·文奇《深渊上的火》：爪族行星上像狗的共生体，靠声音交流形成分布意识；个体离开群体太远就丧失智慧。大城市用手机的人：物理在某处，情感在别处；害怕在陌生人中变成孤独个体，于是与别处的群体保持联系。手机建立虚拟私人空间，沿街走都会迷路。

**结论**

通讯革命维持的是存在感与群体，不一定是深刻友谊；设备若只有功能没有情感对象，就不会有忠诚。

## 六、联系无间，骚扰不断

### 论证推理链

**论据 / 案例 / 事实**

- 电影院、董事会、梵蒂冈：红衣主教金十字架，引导员金项链上挂手机；仪式中铃声，「嘘，我在听教皇演说」。座谈会成员被提问时接电话。
- 保持联系对一方正面，对受干扰一方负面。午餐同伴接电话：接的人觉得仍在一起、电话重要不算干扰；作者觉得分心、时间空虚漫长。感知不对称：忙碌则时间快，无事则漫长。
- 有意识注意力属反思，只能集中单项，又随时被环境打断——是本能层防意外的保护，不是广告游戏造成的现代病。威廉·詹姆斯约 19 世纪末说注意力大约 10 秒。危险焦虑时注意变窄高度集中；不焦虑则易被干扰。
- 人会开拓私人空间：书房锁门、办公室隔间、图书馆安静、街上小群交谈若短暂周围似乎不注意。电话把人放进两个空间：物理位置与精神私密场所，导致脱离真实物理空间。
- 开车讲电话：本能行为仍可驾车，反思的监督预测受损。看起来正常会蒙蔽自己。危险来自交谈占用心理空间，不是手持——免提同样危险（早期研究）。与乘客聊可能较少危险，因心理空间仍包括汽车与周围；电话另一方远离驾车。进化无法预见远距离互动。
- 不能同时高质量进行两场紧张对话。IM/短信的「同时」是交替：构思需反思，输入可由行为层自动，反思再切到另一场。多数活动不需持续有意识注意，分散注意让人与环境保持联系。边走边聊仍能看新店、报纸标题、偷听。机械活动如驾车需要即时反应时，轻松完成会造成「不需要注意」的错觉。社交中转移注意常是优点；机械世界里危险。
- 终生与各地朋友短交流，增加肤浅、付出无法建立深交的代价。越允许打断进行中的交谈，友谊越肤浅。无论怎么指责，持续分散注意已成为日常。

**结论**

联系的情感收益与骚扰的情感成本不对称。注意力的生理结构决定了设计不能假设人能「一心二用」地安全驾驶或深度交谈。

## 七、设计的角色

### 论证推理链

**论据 / 案例 / 事实**

- 科技常迫使离开它就无法生活；或喜欢它提供的东西，使用受挫就讨厌。爱恨共同组成稳定而不舒服的关系。希望消除恨只留爱。设计师力量有限：部分愤怒来自不当设计，大部分来自只能由社会改变的规范。
- 现代化科技实际是社交互动、信任和情感联系的科技，却常未被用于设计，只是偶然副产品。技术人员看成通讯方式，我们看成社交方法。
- 缺乏信任由缺乏理解引起：失去控制、不知发生什么、为何、下次怎么办。电脑狂躁症属于设计范畴：缺陷、信任缺失、糟糕程序、不理解需求、操作与想做的工作不符。都可以解决。
- 媒介差异减少：日本朋友用手机给刚出生外孙拍照发给美国的作者——算电邮、摄影还是电话？
- 好消息与坏消息是同一件事：随时随地分享想法感受；也 24 小时充满干扰。单次互动可快乐，整体难以忍受。简短交流便利妨碍每天正常社交。希望在社会接纳度：或把不断进入私人空间视为常态；或学习限制互动，方便时再回。可想象设备与来电者协商、查行程、预订交谈时间而不打扰个体。
- 共同主题是控制。并非所有互动需即时在线。存储转发（电邮、语音邮件）让双方在方便时进行。需要混合信件、电邮、电话、声音、文本，并安排不受打扰的专注时段。人们已在做：关手机、不随身带、过滤来电、去私人空间写作思考休息。
- 科技早期：潜力与缺陷较量，既喜欢潜力也憎恨现状。随时随地可用很好，只要选择权在接收方。作者对社会有信心：设计改善后可把憎恨降到最低，关系转变成喜欢。

**结论**

设计要做的不是更多连接，而是可协商的连接：丰富互动、没有被迫的干扰、控制权在人。

### 实操方法与设计原则

- 先补概念模型与反馈，减少狂躁症。
- 提供振动、过滤、预约回电、存储转发，让接收方做主。
- 承认爱恨并存的稳定，把恨从「无法生活」降到「可以选择何时使用」。
