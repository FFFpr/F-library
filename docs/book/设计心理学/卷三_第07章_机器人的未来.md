# 卷三 第07章 机器人的未来

## 本章位置

本册正文章节的收束。第六章论证机器需要适合自身的情感与真实表情；本章用阿西莫夫定律检验人机互动，指出今日机器已在不经意间执行部分条款，并讨论伦理：危险任务、自动驾驶、教师、医学、失业、宠物责任，以及真正自主之后的法律归属。后记回到日常：我们都是设计师，个性化与定制。

> 💡 机器情感与家用生态见：[卷三_第06章_情感化机器.md](卷三_第06章_情感化机器.md)
> 💡 后记个性化见：[卷三_后记_我们都是设计师.md](卷三_后记_我们都是设计师.md)

## 核心论点

1. 阿西莫夫用四条定律处理机器人可能因作为或不作为而伤人；定律之间经常冲突，小说就是在演这些冲突。
2. 今日机器已装入部分条款：安全感应（第一）、必须服从否则关机（第二）、防跌落与回充（第三）。最难的是「不作为造成的伤害」以及命令与安全的冲突，需要反思、元知识与自我意识。
3. 阿西莫夫的主要错误：假定中央控制的个体机器人、由人控制、很少人机混编团队。自然界与现代控制论是分散互动涌现；定律应分布在各模块中。
4. 作者欢迎能接危险任务、让驾驶更安全、辅助终身学习与医疗的机器，同时正视失业过渡、犯罪滥用、情感依恋后的法律责任。
5. 科技是双刃剑。贫穷战争更多源自人类邪恶而非科技；解决方案必须是社会和政治的，不是技术的。真正自主可能是几个世纪后的事，但现在开始想伦理并不早。

## 关键概念补全

**阿西莫夫机器人四大定律**（第零定律后加，因第一已占用「第一」之名）：

- **第零定律**：机器人不可以伤害人类的整体利益，也不可以在人类整体利益遭遇危险时袖手旁观。
- **第一定律**：不可以伤害某一个人，也不可以在那个人遭遇危险时袖手旁观，除非与第零定律冲突。
- **第二定律**：必须服从人类命令，除非与第零或第一定律冲突。
- **第三定律**：在不与第零、第一、第二定律冲突的情况下，必须保护自身安全。

**元知识 (meta-knowledge)**：对自身知识的认识。彻底执行定律需要元知识以及对自身状态、行为、意图的自我意识。

**DWIM**：「按照我的意思去做，而不是按照我说的话去做」——早期人工智能（沃伦·泰特曼 1972 年引入 LISP 命令诠释）的旧概念。

## 一、定律从何而来，以及作者对小说的再阅读

### 论证推理链

**论据 / 案例 / 事实**

- 科幻是发掘想法的有效来源，因须写日常细节。阿西莫夫是最早一批把机器人写成自主、智商能力等同或高于主人的思想家。他发现作为或不作为都可能伤人，于是立基本原理，又发现原理互相冲突：伤自己还是伤人类，应保护人类；其他冲突更微妙。先有三大定律，情节更复杂后加更基本的第零定律。
- 作者重读：当年美好回忆与现在反应反差强烈。书中人类粗鲁、男性主义、天真；除辱骂打斗嘲笑外仿佛无法交谈。虚拟的美国机器人和机械人公司神秘、爱操控、不许出错、一错就解雇。阿西莫夫一生在大学度过，对现实世界见解怪异。
- 对社会反应与机器人对人类反应的分析仍有趣。他曾写：大多数政府将于 2003–2007 年禁止任何目的的机器人（科研除外，允许太空探索和采矿，小说里这些在 21 世纪初已广泛开展）。定律为打消疑虑：机器人不是威胁，一直服从。
- 今天最强实用机器人仍无法长时间无人控制协助。即便如此，定律仍是检验人机应如何互动的最佳工具。来源：与约翰·坎贝尔 1940 年讨论；克拉克著作与网站注明日期。

**结论**

当故事工具用，定律仍值得当检验清单；当未来史用，则已证伪。把小说里的公司与对话当现实指南不可。

## 二、四条定律在今日机器里执行到哪一步

### 论证推理链

**论据 / 案例 / 事实**

- **第零**：超出目前能力。早期小说不需要，因确定某行动或不作为是否伤害人类整体已非常复杂，也许超出大多数人能力。
- **第一（安全定律）**：制造伤人物品非法且不恰当。机器多重安全：工业与家用接近/碰撞感应；电梯车库门防夹；割草吸尘近高处边缘停下或退后；工业机器人围栏，有人则停；家用尽量降风险，多数电量不足即使想伤害也无法做到。律师也防：会给小孩读书并看家、意外时拍照邮件通知主人的家用机器人，仍规定不能靠近小孩、不能单独留家。大部分工作在本能层：违规就用简单机械关掉。第二部分「不可袖手旁观」属反思：须大量分析计划，超出现有大多数。简单解：UPS 断电切电池并通知从容关机；汽车监视路线调动力刹车；自适应巡航保距；车道变更探测器在研。不采取行动会出事时，这些保障车与乘客。
- **第二（服从）**：现在机器无独立思想，只能遵守，失败则关机送修。可为保护第一而违反第二，灵活性不高：电梯感应有人挡门则拒绝运行。更复杂时失效；人通常可越过安全系统继续——许多火车汽车飞机工厂事故原因。也许阿西莫夫对：应让机器决定某些事。奔驰：探测快速刹车但未踩到底，自动压到底——联合第一与第二；或引用 DWIM，推测驾驶者打算尽快停。正确执行应让车先看路再决定速度刹车转向。有的车太靠近前车会自动降速。尚未遇到机器人命令与人类管理者冲突，很快会有，须排优先权。阿西莫夫设想汽车拒绝启动：「今晚路况太危险」——尚未达到，将会达到。
- **第三（自我保护）**：阿西莫夫认为最不重要故列最后。因目前性能有限、很少用到第一第二，第三反而最重要：昂贵机器人弄坏烧坏会懊恼。吸尘防跌落、割草撞击探测、低电睡眠或回充电站。与其他定律矛盾时，除非操作员在场判断何时可忽略安全，否则解决得不好。玩具机器人已有自我意识萌芽：既想与主人玩，低电仍回充。
- 彻底执行除非具备强大反思、元知识、自我意识——哲学科学难题，也是工程师程序员的复杂执行问题，进展缓慢。即便当今简单设备，矛盾时忽略操作员命令也可能明智：飞机自动系统若能在飞向崇山峻岭前改航，能救命；许多自动系统已开始这种检查。

**结论**

本能级安全与自我保护已经常见；缺的是反思级的「袖手旁观也是伤害」，以及命令与安全冲突时谁说了算。

### 实操方法与设计原则

- 安全优先做本能层硬约束（感应即停、防夹、防跌）。
- 「不作为条款」从 UPS、自动刹车、偏离车道这类具体场景做起。
- 允许人越过安全时，要意识到这正是事故高发点。
- 低电回充是第三与「继续陪玩」冲突的已存在实例。

## 三、阿西莫夫错在中央控制

### 论证推理链

**论据 / 案例 / 事实**

- 执行类似四大定律的最大障碍：自动操作和中央控制的基本假设可能无法应用于现在的系统。
- 阿西莫夫的机器人像个体，给任务就去做；少数以团队工作则由一个当管理者；从不让人类和机器人组成工作团队。我们更想要合作性机器人：人机或机器人团队如一群工人。合作要求充分交流意图、当前状态和进展——另一套规则。
- 主要错误：认为机器必须由人控制，智能机器需要中央协调控制、等级组织（军队政府企业数千年组织方式）。自然界不是：蚁蜂、鸟群、城市、股票市场由多个团体互动产生，不是中央架构。现代控制理论标志是分散式控制。定律应是结构的一部分，分布在各模块，模块互动产生遵循定律的行为。他写作时还不理解，难怪没达到今天对复杂系统的理解。约翰逊《紧急状态》评论自生性系统。
- 仍领先年代：小说 1940–50 年代，《机械公敌》引用虚拟 2058 年《机器人技术手册》三大定律，预测超 100 年。到 2058 年可能真需要。定律现在很多系统不经意遵循。困难在：不作为造成的伤害，以及服从命令 vs 避免自己/他人受伤。
- 机器越能干、越自动、越少直接监管，将面对法律问题。意外时由法律定孰是孰非。出现前先设道德规范有益。已有工业机器人和机器人系统安全守则（OSHA 技术手册），很基本，需要更多。现在开始思考实践、道德、法律、伦理问题并不算太早。

**结论**

把四大定律当成分布式约束嵌入合作系统，而不是给每个机器人一个中央道德官。

## 四、含义和伦理议题

### 论证推理链

**论据 / 案例 / 事实**

- 接替人类某些工作的智能机器有伦理含义；对可形成强烈情感依恋的仿人机器人尤甚。我们真想要自主、自我定向、行为自由、高智能、有情感的机器吗？作者想，因益处多；须确保人永远监督掌控、它们妥善服务人。
- **教师**：不会取代人类，可补充；旅途、偏远、找不到教师时可开展学习，使终身学习、按需要与兴趣而非武断课表成为可能。困扰者把智能机器当不道德邪恶拒之门外——作者体谅但不认同；发展势不可当且有益。
- **益处**：危险任务（搜救、勘探采矿，某程度已如此）；问题是用于抢劫谋杀恐怖主义。机器人汽车：希望如此。每年数万死、数十万重伤；若能像商业航空一样安全极佳。可更近距离行驶缓解拥堵、更高效有助能源。驾驶多数时候看似简单造成安全错觉；危险突如其来，心不在焉、不精、毒酒病乏的人不能及时反应，职业司机也会出事。不能杜绝全部意外，可大降伤亡。享受驾驶可到专用道路娱乐区赛道。日常自动化将使商用驾驶员失业，总体挽救生命。
- **教学**：现行一位教师照本宣科、强迫听不感兴趣且无关日常的内容，对教师最简单对学生效率最低。最有效：对劲头十足的主题努力把概念用到关心的事上——努力是积极动态过程的一部分，真正关注时努力愉快。优秀教学靠讲授辅导指导，不是说教；运动员与电动游戏如此（游戏学到的几乎无实用价值）。学习科学称问题导向、探索式、构建式。情感：只有充满动力、感情投入才最佳。范例图表影像有效。每个主题都可振奋某些人。电脑提供可探索的模拟世界；机器人使搜索图书馆知识库容易。人类教师不必讲课，当教练指导者，教如何学，使学生终身好奇并能自学。斯蒂芬森小说里明星学生对真实世界真实人类一无所知，因封闭在幻想里——自动化教师只能辅助。
- **医学**：高精度活动可选机器（眼科激光几乎全由机器控制）。诊断复杂，有经验医师仍将参与，由能评估病例记录知识药物庞大数据库的动态智能机器帮助。信息数量与新资讯增长已近无法承受；体液生理 DNA 扫描从家里工作场所直接发送，只有机器跟得上。人善综合与创造性决策、综观全局；机器善快速搜索、较少记忆偏误。训练有素的人员+机器助手远胜各自单独。
- **失业**：将接管越来越多例行工作，含管理。历史每次技术浪潮淘汰部分工人，总体延长寿命提升生活品质并增加就业，工作性质不同。过渡期被淘汰者技能与新工种差距大，是必须重视的社会问题。过去被替代的多是低端；未来倾向高端：电脑生成演员、机器人运动员（即便只在机器人群体内赛也会使人类竞赛式微）、国际象棋电脑已击败最优秀人类、会计簿记绘图仓管简单管理。机器人音乐家？可能被取代的工作不胜枚举，有社会动荡潜在危险。用于太空、矿、搜救、家务吸尘不至于强烈抵制；接管大量工作则真正忧虑。
- 作者欢迎消除沉闷文书与低报酬例行服务的机器——假设能解放人投入更有创造性的活动。曾见印度丝绸厂女童被锁厂房从早到晚纺织，火灾也无法逃——此类不公平在现代技术之前已存在。看到使用的弊端，也看到不使用的弊端。自称乐观：创造这些设备的聪明才智最终也将创造更丰富活动。乐观未蒙蔽：仍见不公平；贫穷饥饿政治不公战争更多源自人类邪恶。看不出引进智能情感机器人会在好坏上改变这一点。要改变邪恶必须直面：社会政治人类问题，不是技术问题。
- 视野扩到短期之外更复杂。真正自主也许几个世纪后必将发生：耕种采矿生产配置销售、教育医药、甚至艺术音乐文学娱乐很多工作；还可自我生产。人已有电子人倾向：医学修复术，也有按需求移植提升。类固醇、角膜激光、作者白内障后人造角膜视力更好但不能变焦——将来或能聚焦甚至远视，无白内障者也可能愿意替换。完全超出本书范围。
- 本书重点在情感及人与所有物、宠物、他人的联系。机器人先将成为有清晰个人情感的所有物：伴随大半生、互动、回想经历、给建议或解闷。今日简陋宠物已唤起强烈情感；几十年内或拥有真实宠物所有属性，许多人看来更好。今日有人虐待遗弃宠物，社区有流浪猫狗。同样问题会发生在机器人宠物吗？谁对照看维护负法律责任？伤人谁负责——机器人、主人、设计师、生产商？真实宠物是主人。当机器人作为独立、有感官、有梦想抱负的生物：定律够不够？造成破坏伤害死亡责任归谁、何赔偿？阿西莫夫在《机械公敌》总结：机器人终将接管，人类丧失话语权。在可能性变成现实前，这只是科幻。
- 机器已相当智能，还将更智能；运动功能发展，很快还将有情感情绪。正面巨大，负面值得关注。所有科技的问题：双刃剑。

**结论**

现在该写的规范，不是「禁止机器人」，而是：人保持监督；用机器补人所短（搜索、精确、危险）；用社会政策接住被替代的人；预先想宠物与自主体的法律责任。

### 实操方法与设计原则

- 教师/医生角色改成教练与综合决策者，机器做检索、模拟、高精度操作。
- 自动驾驶的伦理论据首先是死亡率，不是驾驶乐趣；乐趣可隔离到专用场所。
- 机器人宠物按真实宠物想责任归属：至少先能指出主人。
- 不要把社会不公推给「有没有机器人」；那是政治问题。
