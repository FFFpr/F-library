# 卷二 致谢

## 本章位置

卷二正文与挑战之后。说明本书从「反对复杂」转到「反对混淆」，以及手稿曾差点叫「交际设计」。

> 💡 全书立场见：[卷二_00_序言与导读.md](卷二_00_序言与导读.md)

## 核心论点

1. 作者曾激烈主张简化；后来认为敌人是混淆与无条理，办法是协调一致性和理解，不是靠减少控制器数量那种「标准简单」。
2. 想法先在 ACM SIGCHI 刊物《交互》2007 年起的专栏里练，感谢编辑安德森与科科允许「歪理邪说」。
3. 书名与结构几经反复：代理公司耐住从交际设计到复杂性的转向；MIT 出版社拒绝困惑、复杂、冗长的初稿后培育出定稿。

## 论证要点

受益于教学与演讲反馈；博布罗看穿弱点；尼尔森持续指出设计缺点。早期片段读者波特努瓦、亚比斯卓。照片与故事来自许多人：萨格鲁艺术、泰特「不是出口」门、福克斯愿望线、斯普拉里根重绘图、赫尔曼银器工作台（并叹银器在美国快消失）。西北大学科尔盖特、赫尔本课程与双学位 MBA+工程学生；院长奥蒂诺要工程师做「鲸鱼脑」（左右脑同样大：分析与整体）。迪克斯彻团队；黑尔克图与许可、费尔德曼删减、塞里编辑。妻子朱莉指出闲扯、重复、一句里改立场。

## 题外话

除了本章主要内容外，作者还讨论了/提及了：1. 用专栏练笔直到想法成型，2. 鲸鱼脑工程师隐喻，3. 初稿被出版社以「令人困惑的复杂」退回——正好是书要反对的那种复杂。

## 段落总结序列

主旨：复杂可驯，混淆不可；本书亏欠专栏、学生、辩友与说真话的编辑家人。

最小标签集：陈述 / 次要观点 / 可替换例证

1. 【第一档·陈述】敌是混淆不是复杂；解是一致性与理解。
2. 【第二档·次要观点】《交互》专栏与教学是实验室。
3. 【第二档·可替换例证】照片故事与银器工作台把原则钉在实物上。
4. 【第一档·陈述】从交际设计改到复杂性，初稿过冗被拒后才成书。
