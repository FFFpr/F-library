## 核心论点

1. 复杂是必需的，不等于高科技功能堆砌；真正构成「复杂」的，往往是文化背景与使用习惯不同所造成的、不知不觉的理解差异。
2. 「简单」作为道德口号很可能是伪命题：人人喜欢强大功能，没有复杂科技就没有细致服务；强制性减功能，反而可能让生活更复杂。
3. 要区分**良性的复杂**与**令人困惑的复杂**：前者匹配生活中的活动，后者把人搞糊涂。文化不同，但人对困惑技术的沮丧是共同的。
4. 好设计驯服复杂：不是在复杂符合需求时硬把它变简单，而是去**管理**复杂；苹果一类成功案例的关键，是把寻找、购买、播放与法律问题整条系统一起简化。
5. 消费者也不能只被动接受或盲目拒绝复杂：选择复杂的同时，也在使用中管理它、享受它。

## 关键概念补全

**复杂 vs 困惑**：推荐序引诺曼原句「复杂是世界的一部分，但它不该令人困惑」。自序进一步把「困惑的复杂」标为贬义——技术把人搞糊涂。第一章会把词典义钉成：复杂描述世界状态，费解/困惑描述心理状态。

> 💡 完整定义与驾驶舱、凌乱办公桌案例详见：[卷二_第01章_设计复杂生活.md](卷二_第01章_设计复杂生活.md)

**管理复杂**：不是密斯式「少即是多」的禁令，也不是把装饰一律视为罪恶；管理本身应成为当代设计的组成部分。

**社会性语义符号**：推荐序指出，同样功能在不同用户手里，因文化与习惯不同，对「使用」的理解产生差异，这种不知不觉的差异才真正构成复杂。本册后文用「语义符号」展开；卷一用「意符 / 示能」。

## 推荐序

杭间，2011年6月30日于清华大学美术学院。标题：「复杂设计的含义」。

### 论证推理链

**论据 / 案例 / 事实**

- 设计界长期服膺密斯「少即是多」，对「复杂」噤若寒蝉，并把与复杂沾边的「装饰」也视为「罪恶」。
- 科技发展后，简单设计越来越少，复杂东西越来越多——人人面对、却不愿承认。
- 诺曼原句：复杂是世界的一部分，但不该令人困惑；好设计帮助驯服复杂，不是让事物变简单（若复杂符合需求），而是管理复杂。
- 功能简单的物品与头脑简单的人一样不受看好；人人喜欢好功能，功能强大意味着服务更好；没有复杂科技就不可能有细致入微的功能。
- 心理学上：复杂事物更容易理解，简单事物反倒令人困惑；通过强制性功能降低复杂性，只会使生活「更加复杂」。
- 复杂另有社会性语义符号上的原因：同样功能因文化背景与生活习惯不同，使用理解产生差异。
- 书中例子涉及医院、银行、新产品与服务、秩序、体验等，把复杂扩大到社会层面。

**推导**

设计师普遍把复杂等于失败，但这是被道德化的「常识」。实际购买与使用都在要功能。若「简单」只停在道德层，就是伪命题。真正要处理的，是文化性使用差异所造成的、不知不觉的复杂，以及系统意义上的成因与解法。

**结论**

复杂不仅不可避免，还是设计的新出发点和解决问题的契机；好设计师必须学会管理复杂。对消费者：被动接受或盲目拒绝都不可取；选择复杂的同时，也在使用中管理、享受复杂，物品才在互动中产生新生命，好设计才沉淀为生活经典。

**启示**

面对「少即是多」的压力时，先问：复杂是否符合需求？若是，任务是管理而非删除。看产品时，把文化习惯造成的理解差也算进「复杂」，不要只怪按钮数量。

### 实操方法与设计原则

- 把「管理复杂」本身做成当代设计的组成部分，而不是事后补救。
- 对复杂采取辩证法：既不把装饰一律定罪，也不把功能堆砌当成高科技完善。
- 杭间提醒：专业读者或觉论证烦琐，但这正是中文书名仍叫「设计心理学」的用意——智者娓娓道来，耐心本身也是一种心理承受力。

## 自序

唐纳德·诺曼，2011年5月11日。联系：www.jnd.org，don@jnd.org。

### 论证推理链

**论据 / 案例 / 事实**

- 中国正迅速成为消费技术主要力量：手机、网站、冰箱、电视、汽车；设计学校迅速增加，工程设计仍是重要职业。
- 普通人在家和工作中承受越来越多新技术冲击：有些简单，更多复杂；更糟的是许多令人困惑和沮丧——他称之为「困惑的复杂」。
- 常见误解：亚洲人比西方人更喜欢复杂；证据常拿中日韩印网站与「看起来简单」的西方网站比较。
- 反例：网站该简单还是复杂，由要完成的活动决定。想快速查看许多项目，复杂网站合适——许多亚洲网站如此，美国雅虎或几乎所有美国报纸也如此。只想做一项活动（如搜索），简单网站最好——中国百度，美国谷歌或必应。
- 这些想法第一次提出，是在南京「友好对待用户」（User Friendly）国际会议，副标题「拥抱亚洲文化」。

**推导**

文化不同，许多行为与交互由传统决定；但人作为人类与公民、现代技术（电话/手机、电视、汽车、计算机）在全世界一样。相似性总是多于差异性。书对文化差异敏感，但前提是强调「我们多么相似」。复杂是全世界的生活现实：良性复杂匹配生活活动；令人困惑的复杂把人搞糊涂——所有文化都会因此沮丧。

**结论**

希望本书澄清良性复杂与令人困惑的复杂之别，使全世界过上更少沮丧、更少困惑的生活。主题对中国尤为重要。

**启示**

不要用「亚洲人喜欢复杂界面」一句话结束设计决策；先问活动是「扫很多项」还是「做一件事」。跨文化设计先找人类共性（对困惑的共同厌恶），再处理文化差异。

### 实操方法与设计原则

- 用活动类型决定界面密度，不用地域刻板印象。
- 设计目标：减少「困惑的复杂」，保留匹配活动的良性复杂。

## 导读

筱诃，通用电气研发经理。标题：「与复杂共生」。

### 论证推理链

**论据 / 案例 / 事实**

- 技术让生活更好，也让人无所适从：买东西时反复权衡，又常迷失在复杂而「强大」的功能里。
- iPod 做到了极致的「简单」；但苹果真正秘诀是明白：核心不只是产品设计，而是对寻找、购买、播放音乐以及克服法律问题的**整个系统**进行简化。复杂与简单得到该有的平衡——这是诺曼揭示的「不是秘诀的秘诀」。
- 卷一《设计心理学》曾给国内同行上过基础课；卷二则教如何管理当下设计中的复杂：复杂是必需的，不一定不好；设计者可以管理复杂；简单也可以让生活更复杂。
- 诺曼原句：「糟糕的设计带来情感上的痛苦，人们把它与现代科技联系在一起。而好的设计则能够提供令人满意的、愉快的感受。」
- 筱诃本职：医疗影像。传统 X 射线摄影设备庞大复杂，走廊排满等待病人，每次拍照耗时数十分钟：摆位、球管定位、对焦、调角、再确认、曝光、预览，然后几天后再取片子。新产品用新科技把功能做强、流程做简：操作者把射线球管摆到要拍的部位、选好模式，系统几秒内自动完成调节，按下手柄图像即上传到诊断医生面前，「像傻瓜相机一样简单」。
- 诺曼直白句：「我们必须适应世界的复杂性，技术的复杂性是无法避免的。」

**推导**

简单与复杂是事物两极，却可调和：因科技与客户期望需要复杂结构与功能，同时设计者要简化使用方式、提供友好界面——这是对设计者的挑战。书里没有太多现成答案，只揭开面纱后的真相。

**结论**

「与复杂共生」是每一个设计者终极的追求。

**启示**

做「简单」产品时，先画整条服务链（找、买、用、法律/后勤），不要只打磨物件本身。医疗影像案例说明：后台可以极复杂，前台操作仍可被驯服到「摆位 + 选模式 + 曝光」。

### 实操方法与设计原则

- 结构/功能可复杂，使用方式与界面应力求简易。
- 把「与复杂共生」当成设计目标，而不是把复杂藏起来假装不存在。
- 导读提醒：诺曼新书「并没有太多答案」，价值在于把日常体验分剥离析。
