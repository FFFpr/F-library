# 卷四 第04章 机器的仆人

## 本章位置

上章给出自然互动、可预测性与应激自动化。本章翻到另一面：**我们已成为自己工具的工具**（梭罗）。以愚人节虚构的「车道维持困在环岛十四小时」开场，说明谨慎的车、爱发牢骚的厨房、难伺候的设备正在变成「老大」。然后写汽车变成有轮子的电脑、爱八卦的车与广告牌、学术会议的解放/奴役两阵营、半自动化的「危险中间态」，以及车群/车队的许诺与陷阱。下一章用莫扎之家 vs 微软剑桥「增强」住宅，把自主与增强摊开。

## 核心论点

1. **人已成为科技的奴隶、工具的仆人**：不仅维修安抚，灾难来时还高高兴兴照它们的话做；想回头已晚。
2. **科技一词**常被用来指新奇神秘之物，实则指系统应用知识于人工制品与流程——铅笔、衣服、书写、音乐艺术工具都是科技。
3. **真正危险在自动化尚未完全取代人、人必须处理自动化失败之处**——压力、意外与死亡集中于此。
4. **要么完全自动化，要么不要自动化**；现在的半自动在正常时接管、不妙时无预警退出，与期望背道而驰。
5. **过度自动化**让人无法保持警觉；故障时用高科技的人比不用者更容易出事；盲从导航可把车开进河里。
6. **完全人工危险，完全自动可能更安全；危险在过渡期**——部分功能自动、车与车能力不一、已装设备仍有限制。作者担心部分驾驶自动化会降低单次车祸概率，却使事故牵连更多车、更多伤亡。

## 关键概念补全

**融入系统 / 操作系统回路（in the loop / control loop）**：持续感受状况、决定行动、观察结果。做饭、清洗、游戏只要持续判断也算在回路中。

**状况感知（situation awareness）**：对周遭背景、现在状况、下一步可能的了解。

**警觉（vigilance）**：实验心理学：人很难长时间盯单调工作，警惕随时间减弱。被动观察（只监控自动）尤其无趣。

**过度自动化（overautomation）**：设备太好，使用者不必太注意；理论上应随时准备介入，实际上做不到。

**车群 vs 车队**：车群像蜂拥，无明确头领、可多方向交错、车距可极近（约 1 米）、靠无线通信预告制动；车队是简化：单方向跟随前车，理想中只有头车要人开。

## 一、小心翼翼的车子：纽旺困在环岛

### 论证推理链

**论据 / 案例 / 事实**

- 开篇新闻体：「驾驶人受困环岛十四小时」——皮特·纽旺，哈姆斯德，新豪华车「车道维持」不让他离开内侧车道，方向盘不让步，声音重复「警告！右边车道有车」，至晚十一点才出来，路旁昏迷脱水。公司代表纳姆若：超过八成扭矩功能失效，驾驶可一直控制；警方称小概率+当日学校庆典与赛事导致全天高峰。国家交通安全委员会认为非典型、不属调查范围。
- 日期 4 月 1 日；作者为《RISKS 电子通讯》写的虚构。技术确实存在、已在售车。理论上 80% 扭矩即可夺回；纽旺或许太不自信，一感到反作用力就放弃；或零件/程序故障需要用尽全力。似是而非才真正让人担心。
- 产品将发号施令、把缺点怪到你身上。

**推导**

车道维持这类「安全」功能在持续拥挤的边缘情况下，可以把人锁进规则里。设计规定的「大力可覆盖」在心理上或故障时都可能失效。

**结论**

谨慎的汽车已经存在；爱发牢骚的厨房快了；难伺候的设备已经是「老大」。它们进入人与机器的社会生态，需要社交礼仪、沟通技巧、乃至机器情绪。

## 二、我们已成为自己工具的工具

### 论证推理链

**论据 / 案例 / 事实**

- 梭罗《湖滨散记》：「人已成为他们工具的工具。」即使斧头农具木匠工具也界定生活；年轻人继承农场房屋牛舍牲畜农具「来之不易，去之不易」。赫尔克里斯十二劳役相对邻居无穷工作算小事，因为十二件有终结。
- 作者套用：人们成了科技的奴隶、工具的仆人——使用、修缮、擦亮、安抚，灾难时还照做。
- 「科技让人困惑受挫」方向有点错：大部分科技性能良好，包括梭罗写下抱怨的文具。梭罗家族做铅笔，他还改进制造——铅笔也是科技。
- 工作定义：科技 = 系统应用知识于人工制品、材料与流程；衣服、文字、音乐艺术（若无乐器画板油彩毛笔）都是。
- 直到最近科技大致在人控制中：启动停止瞄准指挥。现已不同：废水处理不引人注目地自动；ATM 让银行职员失业——社会议题重要，但本章关注**人还要留下处理自动失败**的那一面。
- 《纽约时报》：汽车「已经变成有轮子的电脑」——分区空调、音视频娱乐、通讯、导航、付费、下载；完全自动而不被察觉的时序、火花塞、节气门、冷却、动力刹与助力转向；半自动的刹与稳定；互动的导航、巡航、车道维持、自动泊车。撞击预警：前视雷达、竖直椅背、束紧安全带、启动刹车；摄像头监控，不注视则光/声提醒，无反应则自动刹。作者想象法庭上传唤「汽车先生」作证，被告企图清记忆卡，车有密码防窜改存储。
- 车与车即时网络（adhoc）：互提醒路况，像对向闪灯告知有警察。也可能交换隐私。广告牌无线接入导航，改程序把人导向客户；车能控方向盘时或载你去它选的饭店并预点「你爱吃的」。网络一通，广告、恶搞、犯罪都可能；专家会说没有如果，只有何时。

**推导**

抱怨应指向失控的自动与失败交接，而不是「凡科技皆奴役」。一旦联网，难以想象的事都会发生，好人与坏人永远竞赛。

**结论**

工具仆人化的当代形式是：电脑化汽车与社交化设备开始替你做主，并把责任留在你身上。

### 实操方法与设计原则

- 区分「完全自动且人未觉察的底层」与「半自动且人须互动的表层」；危险在后者。
- 联网前问：谁能改导航目的地、记忆能否被当事人清除、对向车能拿到哪些个人资料。

## 三、一大堆的学术会议

### 论证推理链

**论据 / 案例 / 事实**

- 学术界好处：佛罗伦萨夏、海德拉巴冬、斯坦福春、大田秋；企业豪华会议中心。资助者要书、报告、发明、突破；人文哲学会议则讨论科技危险。
- 两阵营都邀作者：一方期待解放，一方担心退化奴役。作者跟双方唱反调：科技不带来自由、不能解决所有问题，解决了会冒出新问题；也不会比目前更严重地奴役——习惯后日常要求不像奴役而像想改进。每日多次梳洗、换衣服、复合材料炊具、远方电网管道，作者不觉得是奴役。
- 新科技常带来设计者没想到的好处与困难。主张「进入生活前充分权衡优缺点」几乎不可能——无法预料的后果超出可预测范围。
- 概念到商品化可数十年；实验室公开交流，产业则密室。会议名目：辅助/聪明/智慧型；无所不在、隐藏、孕育中的电脑；环境科技要融入生活，人的生活也须改变才能结合。
- 引文：「智能助理的互动挑战」（斯坦福）——琐事、日程健康、写报告、废墟寻生还；监护建议；家/办公室/汽车/公共场所管理时间经费知识流程。「人工智能国际会议」（海德拉巴一月）——超越键鼠，像人一样的互动、了解模仿行为与示意信号。
- 「像人一样的互动」指向非生物机器做我们的工作：教小孩、保护老人按时吃药、跌倒求救。智慧屋全球冒出。现实与梦想距离大：游戏 AI 到处有，日常生活实质帮助少。吸尘科技可拓展到泳池、落叶、割草——范围内足够彻底即可。困难出现在**与人真正互动**时。
- 工业 vs 居家：任务清楚环境受控+操作者受训 vs 家庭只愿花几十几百美元、用户缺训、开车反应以秒计。车船飞机特定工作已有进步；显示器上的虚拟影像不必真物体；游戏里误会可增趣味。统计推荐（书店）相当好。制造能上下楼梯、抓取自然物品的机器仍远；人类行为科学不知远超已知，能创造的自然互动仍十分有限。

**推导**

解放叙事与奴役叙事都过满。不能事先完全预测后果，不等于放任设计；作者要处理的是互动失败，不是抽象的「要不要科技」。

**结论**

与人真正合作仍超出能力；特殊任务、受控环境、娱乐与推荐可以；通用社交机器人不行。

## 四、自动驾驶的汽车、自动清洁的房子

### 论证推理链

**论据 / 案例 / 事实**

- 下一步清单：自动驾驶；按衣料颜色设洗涤；厨房整合健康记录与冰箱做大餐；娱乐选乐并录像扣款；房子调温浇草；清洁机器人扫地吸尘拖地；割草。许多已面世或将面世。影响日常的自动最先在汽车。私家车完全自动估计还要二十到五十年——何时读这本书都较靠谱。特定场合已能自动。
- 航空术语「随时通报」（in the loop）：变道时如何提醒旁车道有车、障碍、路口来车？两车将撞，车认为加速离开、人认为该刹——车要不要不顾人踩刹仍加速？要不要阻止变道、超速、低于最低限速、过于靠近前车？时间太仓促，几乎不可能询问或只提供信息。
- 主动巡航+车道稳定+自动付费 ≈ 沿标志自动行驶。车道稳定仍不可靠；巡航问题见第一章。车—车沟通（部分试验中）会增安全。科技不必最佳才增安全，人类驾驶者也没那么完美。
- 把这些装一起 = **训练驾驶者三心二意**。车可自己开几小时几乎不互动，人甚至可睡。航空已发生：海军实验飞机上机组成员沉睡，物理学家朋友小组呼叫驾驶舱无人应答。飞机在不拥挤、天气好、燃油足时自动飞较安全；开车则眼睛离路超过两秒肇事概率急剧增加——不必睡，低头调收音机就够。
- 过度自动化：工厂可连续几天不需人，人难保持注意。

**推导**

有意义的自动化必须让车接管某些过程的同时，驾驶者保持警觉与路况了解。半套系统在训练分心。

**结论**

汽车是日常自动化最前沿，也是「回路外+两秒」最致命的地方。

## 五、成群结队的车子

### 论证推理链

**论据 / 案例 / 事实**

- 雁蜂鱼群：无明确头领，简单法则——避撞、靠近但不接触、同向快速。通讯限感觉（视听、鱼侧线压力、蚁嗅）。
- 人工组群可沟通预定计划，事前反应。全自动车群：高速、间距约 1 米；前车要刹则毫秒内全部刹。人开车必须留远距给人反应时间。
- 理论上不再需要车道（车道为避免撞，车群不相撞）、标志与信号；路口交错自行调速。行人穿街，车群减速转弯留空——听来可怕，要毫无保留的信任，理论上可。
- 离群/不同目的地：告诉车 → 车与他车沟通；或转向灯表示变道，右侧前车微加速、后车微减速腾空；轻刹示意慢停。反向车群可分享前方路况；密集时前方告知后方车祸塞车。
- 挑战：并非所有车都有合群无线设备；如何辨认能力有限的车并配合；害群之马高速冲入指望他车让路——一辆或可行，人人效仿则灾难；车能力不一（卡车制动距离、轿车性能差）；仍有人控时还要考虑技术、注意、清醒、分心。
- 好处：密度高、缓交通压力；贴近减风阻（如自行车尾随）。仍有待时日。
- **车队**：单方向跟随，理想仅头车要人；部分公路实验显示可大增流量。进出队、混车型、部分有通讯、自私或蓄意制造车祸仍是挑战。主动巡航已能让人插入后追随，直到低于设定。完全自动则车距可更小、增速不必大增间距。须高度可靠的刹、转向、速度控制——「理想的可靠性，绝对没有问题」。今日难以实施。作者想象专用车道，入前检查通讯与控制；增流量、减塞、省油。进入离开与设备确保会相当复杂。车群实验室好、难上公路；车队可行性较高。

**推导**

生物群是反射；人工群可预测。优点都依赖「没有人为控制且系统作用良好、无意外」。混入未装备车辆与恶意行为会拆掉前提。

**结论**

车队比车群更接近可落地；两者都不是今日交通的即插即用方案。

## 六、不适当自动化的问题

### 论证推理链

**论据 / 案例 / 事实**

- 作者 1990 年已论：半自动不完善，处在危险中间态。正常时自动发挥作用，不妙时无事先警示就退出。
- 在回路 vs 置身事外：重新融入要很多时间精力，到时恐已晚。
- 史坦顿与杨恩驾驶模拟：巡航正常时一切好，**故障时用巡航者比不用高科技者更容易车祸**。安全设备未失效时的确增安全；依赖后置身事外又过度信任，故障时还不如从未用过。飞机、火车、汽车研究都有。
- 盲从指南：威特夏居民靠从阿旺河拖出落水汽车赚钱——司机按导航开进河，尽管常识应知道；皇家号邮轮搁浅，船员过信智能导航。
- 制造商又怕诉讼又要安全 → 小心再小心。全球年约 120 万以上死于车祸，五千多万受伤。开车本身危险，状况瞬间难反应，注意随时变化是人的自然状态。
- 未完全自动则须格外小心：有时不干涉，有时比真正需要更多地让人投入以保持状况感知。完全人工很危险，完全自动反而更安全。困难在过渡：部分功能自动、不同车不同功能、已装设备有限制。部分驾驶自动化会降车祸几率，作者担心实际意外成倍增加、牵连更多车更多伤亡，必须小心处理人机关系。

**推导**

> 💡 过度信任自动、警觉下降、失灵时更糟，与卷一差错章的自动化相关讨论同构，见：[卷一_第05章_人为差错不拙劣的设计.md](卷一_第05章_人为差错不拙劣的设计.md)

信任的两端（不信则不用，过信则盲从）都要设计来校准，而不是用更多自动来「解决」。

**结论**

不适当的是半自动的交接方式，不是「有自动」本身。过渡期是安全上的深谷。

### 实操方法与设计原则

- 设计原则口号：要么全自动，要么别自动；中间态必须把人留在回路并在退出前预警。
- 不要用「正常时更安全」推销会在故障时把人置于更糟境地的系统。
- 导航等建议系统必须允许常识否决，且否决要容易。

## 段落总结序列

主旨：人已成工具的仆人；真正危险在半自动失败交接；车群车队许诺密度与安全，却卡在混装与恶意；过渡期可能比两端更致命。

2. 【第一档·陈述】产品成为社会生态一员，需要礼仪、沟通与机器情绪；下一代会发号施令并把错怪到你身上。
3. 【第一档·必要依据】梭罗「人成为工具的工具」；作者改为科技奴隶。抱怨「科技困惑」部分错向——铅笔也是科技；系统应用知识才是定义。
   （本段是第4段的必要依据）
4. 【第一档·限定】本章不主攻完全取代人的社会失业问题，而攻「人必须处理自动失败」的压力与死亡。
5. 【第二档·可替换例证】汽车成有轮电脑：底层全自动、中层半自动、表层互动；法庭传唤车、车际八卦、广告改导航。
6. 【次要观点】学术会议解放派 vs 奴役派；作者两边唱反调：不自由也不更奴役；后果不可全预测。
7. 【第一档·陈述】与人真正互动仍超出现能力；工业受控+受训 vs 家居低成本+缺训+秒级。游戏与推荐可以，通用社交机器人不行。
8. 【第一档·陈述】汽车自动化最前沿；「在回路」与两秒离路；过度自动训练人睡觉/分心。
9. 【第二档·可替换例证】车群 1 米车距毫秒制动、可取消车道标志；行人穿街要无保留信任。混装、害群、性能差是硬挑战。车队较可行，设想检查后进专用道。
10. 【第一档·必要依据】半自动危险中间态：正常接管、不妙无预警退出。警觉随时间降；故障时用巡航者更易车祸；导航开进河、邮轮搁浅。
    （本段是第11段的必要依据；自动化悖论见卷一第05章）
11. 【第一档·陈述】完全人工危险，完全自动或更安全；过渡期作者担心事故牵连面更大。必须小心处理人机关系。
