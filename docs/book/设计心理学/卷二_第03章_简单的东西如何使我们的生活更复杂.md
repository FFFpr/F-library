# 卷二 第03章 简单的东西如何使我们的生活更复杂

## 本章位置

第二章说简单在头脑里的概念模型中。本章翻转镜头：**单个门锁、开关、密码都很简单；许多简单事物各有一套任意规则，合在一起就大于各部分之和。** 对策是把知识投入物质世界（小绿点、地面标线），并慎用标志与强制性功能——设计得不好，强制减复杂会制造新复杂。第四章起，这些「投到世界上的线索」被命名为社会性语义符号。

## 核心论点

1. 复杂不一定令人困惑，令人困惑不一定复杂。简单事物也可导致困惑：不是难懂，而是每个范本有独特工作方式，头一次碰到新案例就生厌。
2. **一个简单事物的特定范本：简单。许多简单事物在一起、各有操作规则：复杂。** 整体大于各部分的总和。
3. 日常压力常来自琐碎决定的合取：锁往哪边转、油箱在哪侧、遥控哪键管声音。密码规则在「只有一个」时从容，数量级变大后崩盘；过苛的安全要求反而减弱安全。
4. 非保密信息应直接投入物质世界：线、标记、即时贴、小圆点胶，出现在需要它们的地方，就不占头脑。
5. 标志是设计不完善的标记；失效或过量的标志造成安全隐患，并培养人忽略真正重要的标志。专家把过量信息塞进短时间（路况、BBC 天气），普通人无法用。
6. 通过「强制性功能」降低复杂性时，必须按人的真实行为设计，而不是按希望中的行为；否则如双轴卫生纸架，最自然的选择（拿大卷）会同时用完两卷。
7. 人的行为、尤其社会行为极度复杂。设备应使事情显而易见，提供温和指引、语义符号、强制性功能和反馈。

## 关键概念补全

**规模化**：计算机术语——方法在小规模很好，大规模失败。颜色编码红/绿在少数灯上可用，控制室 4000 个指示灯时就难。

**标记语言规范**：无标记=正常状态，有标记=反常。作者用小点一律表示「锁定」。须保证人人知道规则，并对何为正常一致（通常锁开启、灯关闭算正常故无标记，但并不总对）。

**规则系统**：计算机科学用语，指行为规则的系统性应用。卫生纸双卷上的大/小/随机即三种规则系统。「以大为先」即「平衡使用」，两卷几乎同时空。

**强制性功能**：作者在《设计心理学》（卷一）中的术语——约束使正确行为成为唯一（或几乎唯一）可能，用最少决策引出恰当行为。

## 一、许多简单之物的合取

### 论证推理链

**论据 / 案例 / 事实**

- 图3.1：多种门锁与钥匙。旋转上锁、反方向解锁，钥匙插入旋转——单套很简单。问题是每人面对许多把手：有的逆时针上锁，有的顺时针。没有视觉指示就记不住。四张照片里人们都加了帮助性指示。任何时候标志或标签被附加到设备上，就是糟糕设计的标记；简单的锁不需要指示，设备不该迫使使用者自己加标志。
- 琐碎决定一整天加总：锁的钥匙顺/逆时针？汽车油箱左/右？遥控哪键声音哪键频道？持续不断的潜在压力。
- 密码：多数人爱用名字、配偶、宠物。「password」「password1」「123456」「jesus」「love」最常见。社交网络几分钟可取个人资料。专家要求：够长、字母数字大小写、有时符号、频繁更换、不能再用旧密码、不许简单词。善意明智，却把「选择并记住密码」变成复杂活动；每人很多密码，复杂大幅度增加。
- 作者对安全专家解释：许多增安全要求实际减弱安全。所在大学基本认定他是疯子，忽略他。
- 人怎么应付：写下来贴键盘下；非常多人贴电脑屏幕前。作者夫妻把所有网络密码和安全代码记在加密电脑文件：19 页、很小字体、5000 词——又多了一个「密码文件的密码」。有公司靠售卖密码管理软件发达；自动填充姓名地址信用卡用户名密码，简化合法用户，也方便窃贼。
- 许多人不同活动用同一密码，违反所有安全规则（很多安全专家承认私下也这么做）。图3.2(a)(b)：屏幕纸条写着用户名密码、或「密码是 CHAIR」。图3.2(c)：废纸篓撑住安全门——墙上读卡器本只许有卡者通过，却妨碍需经常往返的工作者。越苛刻的安全性要求反而可能带来越不安全的状况。

**推导**

一把锁、一个密码，规则再怪也能从容。数量级上升后，任意性无法记，人把秘密外置或复用，安全目标反转。标签出现 = 设计已经失败到要用户补课。

**结论**

把大量简单活动合在一起，结果复杂且令人困惑。过苛安全与锁的复杂性同构。

**启示**

安全政策按「每人几十个密码、每天开关十几扇门」做规模化测试，不要按实验室里的单密码测试。看见用户贴标签，先改物件，再责备「不认真」。

### 实操方法与设计原则

- 见到附加标签，当作糟糕设计的诊断信号。
- 安全规则必须把「人会写下、复用、用废物卡住门」算进系统，否则纸面更安全、现场更不安全。

## 二、把信息直接投入物质世界

### 论证推理链

**论据 / 案例 / 事实**

- 非保密记忆负担：把必要信息投入物质生活。密码除外——投入物质就失去保密（图3.2）。
- 图3.3：跑道上的飞机。地面绘制标志显示各型飞机前轮该停哪里，保证舱门位置正确。飞行员看不见下方轮子，机场人员用手势指挥，前轮到位即停。装配时卡车/飞机停哪：也靠线条标记。组织完善的工厂广泛用线、标志、物理屏障作记忆与管理辅助。书名《视觉的工作场所——视觉的思考方式》(Visual Workplace-Visual Thinking) 描述这类信息的力量。
- 诀窍：张贴小提示、警告、图片，把线、标记、即时贴、说明放到需要时就能发现的地方。信息不给头脑添乱，需要时出现。
- 研究生汉克·施特鲁布推荐圆形五颜六色可循环小圆点胶（包装写「颜色编码标签」），作者叫它们「小绿点」，忽略实际颜色。用途：控制器旁、钥匙转动方向、锁旁提示哪边「锁上/没上锁」、音响旋钮、电插口（哪个由墙上开关控制）、汽车仪表板（哪边汽油加注口开着）。每晚查门：一路走过去看把手是否对齐小点。图3.1 即此用法。
- 标记位置到底表示锁上还是没锁？三方案：①学习规则——除非普遍使用，否则不好；②颜色分类，红关绿开——大家是否都知道？约 10% 男性红绿色盲，而红绿恰是普遍标记色；把红改橙红、绿改蓝绿可缓解色盲，仍难克服大规模应用，即「规模化」失败。③标记语言：无标记=正常，有标记=反常；作者让所有小点不论颜色都意味「锁定」。须保证人知规则、对正常状态一致。
- 核电站控制室可能超过 4000 个控制器和指示灯，有的通常开、有的通常关。操作员如何知道是否都在正确正常状态？标志可能是技术问题的解决方案：不断提供运转如何、指示请求诱导恰当表现。同时：需要贴标志体现设计不完善；理想世界正确操作应自然而然。不完美世界里很多人向不完善设计投降，用标志弥补。

**推导**

航空与工厂已经把「记在哪」从脑移到地。家庭同样可做。颜色编码在小数量有效，在数千灯时崩溃。标志是补丁，不是荣誉。

**结论**

把知识投入物质生活，简化必须记住的特定情况。标志提醒我们：设计还不够让正确操作成为自然。

**启示**

先做位置化提示（油箱在仪表板画哪侧、锁对齐点），再考虑颜色。安全色不要只靠红绿。控制室类环境需要「何为正常」的全局可见，而不是 4000 个各自为政的灯。

### 实操方法与设计原则

- 工厂/机场做法可家庭化：提示出现在决策点，而非说明书里。
- 三种锁定指示策略中，作者实际采用「有点=锁上」的标记语言，并承认规则共识是前提。
- 色盲与规模化是颜色方案的硬约束。

## 三、当标志失效时

### 论证推理链

**论据 / 案例 / 事实**

- 自己提供的标志有帮助，因知道何时该忽略；别人的标志、过期标志则危险。陌生地方如何知哪些正确、哪些失效？
- 图3.4 左：门曾是出口，情况变后加「NOT AN EXIT / 不是出口」，而不是去掉原 EXIT。莱恩·泰特摄。右：工业设施防火门总开着，门上「FIRE DOOR KEEP CLOSED / 防火门请保持关闭」；问起则答「标志是旧的」。作者自摄。两情况都是安全隐患：①着火时出口标志给假希望；②培养人们忽略至关重要的安全标志。对熟悉变动的常客也许没事，对新来或不常来的人，简单事变复杂困惑。
- 图3.5：美国西北大学土木工程系会议室，从入口到出口一连串警示：用后关投影仪。专用灯泡昂贵，教授下课忘记关，周末可连开数日，预算赤字增加。教授迟到仓促，要钥匙开锁住的键鼠或触摸屏开投影仪并选输入（教室电脑或自带笔记本）。课开始时标志提醒的是结束时的事，被忽略；课结束超时，抓笔记电脑冲出，门外更多「关闭投影仪」——太晚，已在想别的。部门会议公告也不起作用。
- 需要设计方案：自动化。许多放映机：长时间无输入信号则自动关闭。

**推导**

繁忙管理员依赖标志，但标志像说明书：几乎没人读。任务目标在「打开并讲完」，关闭是目标完成后的记忆，与冲向下一个地点冲突。标志数量越多，越证明方法不管用。

**结论**

过量警示是失败证据。过期标志制造假希望并训练人忽略安全信息。该上自动化的地方，不要加第 N 张贴纸。

**启示**

审计标志：是否仍真、对陌生人是否成立。行为若与当下目标冲突（下课冲走 vs 关投影），改系统（无信号自动关），不要加训诫。

### 实操方法与设计原则

- 失效标志必须移除，不要叠加否定句。
- 「需要这么多警示来提醒 X」= X 的设计路径错了。
- 把收尾动作自动化，对准的是教授的真实时间压力，不是道德说教。

## 四、为什么专家会把简单的事情变得混乱

### 论证推理链

**论据 / 案例 / 事实**

- 互联网搜索：行为简单，结果太多且视觉上难分对错。多数人只看头几个，从不看后面。
- 收音机路况：只想知道一小段高速是否堵；大城市播音员要满足所有人，数分钟连珠炮，地名只有最博学当地居民才熟，还分进出城——经验上你很可能错过自己关心的那部分。
- 亨利·亚比斯卓电子邮件（2009，经许可）：BBC 电视天气相当复杂困惑、基本无用。除非极集中，且摄像机在巨型倾斜英国地图上「飞行」时，搞不清自己住处 12 小时天气。几分钟内两条矛盾渠道塞太多信息：①军团般的预报员（网站 50 个名字）讲今后 5 天、英格兰各分区+北爱苏格兰威尔士海峡群岛，用华丽语言手势避重复；②超级地图倾斜、地面褐色（伦敦南部干旱但不是沙漠）、有的区域黑褐色（仍猜是多云？）、雨显示成蓝色像上帝造湖。摄像头迅速放大，主持人以高速列车语速报现在+五天。34 秒后普通观众不知所措麻木。
- 航空交通管制对比：标准化技术语言，每条指令前有航班号。飞行员「一词点动」——只在听到自己航班号后才细听，从次要任务切到首要。飞行员须复诵确认。信息组织好，飞行员受训且有数千至数万小时经验。
- 普通人不必成为专家才能懂天气或路况；提供信息的专家知道得太多，很难理解普通人的问题。
- 作者夫妻「鸟类鉴赏」课：本想徒步时知道见到的鸟。书按种类排列，意味着查找前必须已经知道是什么鸟。作者问导师要不要按大小、斑纹、行为、颜色分类。导师同情：「学一段时间就没问题了。」——但正需要学习上的帮助。轮廓、野外痕迹、体态、大小、飞行模式、栖息地是专家声称的关键特征，书却不按此编。复杂性来自纸质书的技术限制：装订页刚性，只有一个固定组织结构。
- 电子指导书可按地理位置、颜色、大小、叫声、行为分类，可指定多特征再筛，可出鉴定列表再提问缩小。这些书已存在，改变了观鸟方法。
- 矛盾：纸书固定结构，对已知名种的专家好查；电子书更复杂、甚至无固定结构，像互联网要搜索——对初学者即使难解读，却最好用；专家更爱固定结构纸书。

**推导**

专家优化的是自己的分类法和表达欲（避重复、炫技术图），不是听众的一个问题。空管证明：给接收者一个「这是给你的」开关（呼号），连珠炮也可听。媒介的结构刚性（纸书一个排序）会把简单问题做成先有结论才能查表。

**结论**

信息过量且无针对接收者的索引时，简单问题变复杂。新手与专家需要不同组织结构；动态组织对新手更友善。

**启示**

路况/天气：按用户位置过滤，或先给「呼号」再给细节。帮助文档：专家按分类法，新手按可观察特征。不要对新手说「过一段时间你就懂了」而不给入门索引。

### 实操方法与设计原则

- 空管模式：标准化用语 + 接收者标识 + 复诵确认。
- 纸媒一个排序 vs 电子多维筛选：按用户是专家还是新手选。
- 搜索结果默认「只看头几个」是人的策略，设计应让头几个真有区分度。

## 五、通过强制性功能来降低复杂性：卫生纸架

### 论证推理链

**论据 / 案例 / 事实**

- 图3.6 单轴卫生纸架司空见惯但不方便：用完怎么办？共享时有社会问题。改造家时改双轴，图3.7，以为一卷完总有另一卷。
- 两卷同时出现，用完时间变成两倍，仍会两卷一起空。必须有选择规则 = 规则系统。朋友圈子讨论，公众环境三规则：大、小、随机。
  - 大：总从最大卷取。
  - 小：总从最小卷取。
  - 随机：不思考，随机选。
- 随机若真随机，两卷平均消耗，同时用完——不适用。最自然倾向是选更大的。效果：A>B 则用 A 直到明显小于 B，再换 B……两卷减速大致相同 = 平衡使用。A 空后不久 B 也空。街上问路人多数表示会选大的。
- 以小为先才对：始终用小的直到完，再开始另一卷（仍是全新）。最自然选择推翻了设计目标。图3.7 在两卷大小差异明显时，恰好导致很多人错误行为。同一原则一处可行，另一处导致错误。看似简单的设备有隐藏复杂性。
- 设计方案：强制性约束，第二卷在第一卷用完前不能被使用。市场上很多纸架已用适当强制性功能。新设计常在损失其他方面的前提下解决某问题，同时导致新问题。
- 有的：下面用完，按下空轴放开上面卷——但备用藏在牢固金属壳后不可见。清洁工必须每天打开所有外壳确认有备用？作者怀疑。于是改良：透明边缘使备用可见即使还不能用；或备用可见但被正用卷挡住。
- 说明：需要沟通（看见备用是否存在）+ 用设计约束行为（总从较小卷直到用完）= 强制性功能，正确行为是唯一可能性。连最简单设计都有社会意义，卫生纸架也是社会性事物。
- 必须按人们的行为方式设计，不是按希望他们应有的行为。设备使事情显而易见，提供温和指引、语义符号、强制性功能和反馈时，人用起来顺手。合理强制性功能：最少需求解决问题或作决定，人被温和指引出恰当行为。
- 复杂性是无法改变的事实，必须学会处理。有时设备复杂，有时设备简单但环境使之复杂。需要应变行为管理生活中的复杂。
- 物质生活中的知识也适用于陌生行为：看周围，遵循别人示例。陌生文化点餐：看别人吃什么，指出你感兴趣的——使用他人已积累在生活中的知识。
- 有时带来复杂的，正是本想拯救我们的科技：自动化、更好设计、或动态组织在需要时提供信息。

**推导**

加一卷是「功能更多」，若不约束选择，人的默认启发式（拿看起来更多的）会抵消备用的意义。强制功能要配可见性，否则清洁工/用户无法计划。社会性：共享资源的消耗规则必须被设计进物理约束，不能靠告示。

**结论**

用强制性功能降低复杂时，先观察自然选择会偏向哪边，再决定约束哪边。沟通（可见）与约束（不可用错卷）要一起做。

**启示**

任何「备用」设计都问：用户会不会把两份备用当两份主用平行消耗？若会，就锁住第二份直到第一份尽。锁住时仍要让人看见「还有没有」。按希望中的理性行为写说明书，不如改物理。

### 实操方法与设计原则

- 三种取纸规则里，以小为先才达到「始终有一卷满的」；以大为先 = 平衡使用 = 双空。
- 强制性功能：正确行为成为唯一可能；配套让备用状态可见。
- 把知识投入世界：小圆点、强制功能、张贴指南，或用更强的动态工具替换固定结构（电子鸟类指南替换纸书）。
- 陌生环境：模仿在场者，复用他们已投入世界的知识。

## 段落总结序列

主旨：许多各自简单的物件与规则合在一起，整体大于部分之和；把知识放到世界上，并用符合真实行为的强制性功能来管选择。

最小标签集：陈述 / 必要依据 / 限定 / 例外 / 可替换例证 / 次要观点 / 续 / 过渡/场景

1. 【第一档·陈述】单套锁/钥匙简单；许多套各转不同方向就需要标签——标签是糟糕设计的标记。（本段是第2、3段的必要依据）
2. 【第一档·陈述】一天里大量琐碎任意决定（锁、油箱、遥控）合取，造成持续压力；整体大于部分之和。
3. 【第二档·可替换例证】密码规则在单条时从容，数量上升后人写下、复用、用管理软件；过苛安全减弱安全（废纸篓撑门）。
4. 【第一档·陈述】非保密信息应投入物质世界：机场停机线、工厂标线、小绿点出现在决策点。
5. 【第一档·限定】密码不能外置。颜色编码有色盲与规模化问题；「有标记=反常」需共识何为正常。控制室数千灯使红绿意义崩溃。
6. 【第二档·可替换例证】过期 EXIT / 常开防火门培养忽略安全标志；对陌生人尤其危险。
7. 【第二档·可替换例证】会议室一墙关投影警示证明方法失败；无信号自动关才对得上教授下课就走的真实行为。
8. 【第一档·陈述】专家把对所有人的信息塞进短时连珠炮，普通人错过自己那一条；空管用呼号让人「一词点动」。
9. 【第二档·可替换例证】纸质鸟类书按种分类，新手必须先知道答案才能查；电子多维筛选对新手更有用，专家反而爱固定结构。
10. 【第一档·陈述】双轴纸架不加约束时，人自然选大卷 → 平衡消耗 → 双空；以小为先才对。强制第二卷不可用直到第一卷尽，并让备用可见。
11. 【第一档·陈述】按人的真实行为设计，提供可见性、温和指引、语义符号、强制性功能与反馈。复杂是事实，用投到世界上的知识与应变来管理。
12. 【第三档·过渡/场景】陌生地点看别人怎么做、点别人正在吃的——复用他人留在世界上的知识；有时「拯救我们的科技」本身又制造新复杂。
