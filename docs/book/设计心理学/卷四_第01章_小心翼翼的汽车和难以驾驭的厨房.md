# 卷四 第01章 小心翼翼的汽车和难以驾驭的厨房：机器如何主控

## 本章位置

本册是唐纳德·诺曼《设计心理学》系列第四卷《未来设计》（*The Design of Future Things*，小柯译，中信2015），讨论智能、自主设备进入日常后，人如何与之共事。本章是正文章首：机器已经开始用安全带、座椅、刹车和导航「主控」驾驶，两句独白却构不成对话。下一章把汽车+驾驶者写成一种新的人机混合体，并用本能/行为/意识三层说明双方如何分摊控制。

> 💡 下一章见：[卷四_第02章_人类和机器的心理学.md](卷四_第02章_人类和机器的心理学.md)

## 核心论点

1. **两句独白不是对话。** 人对机器下指令，机器对人回以指令；导航、自动刹车、智能贷款与医疗系统都在「要么这样，否则免谈」——而这「免谈」往往不是选项。
2. **人比机器能力更强，机器却往往权力更大。** 机器像无权拍板的低阶谈判代表：你无法说服它的「上司」（程序与设计者），只能接受或放弃整套系统。
3. **所谓智能并不在机器里，而在设计者脑中。** 设计者预先想象场景并写入规则；意外必然发生且时刻不可预期，设计者不在场时机器就会出错。
4. **责备—培训（blame-and-train）解决不了设计问题。** 事故常被归为「人为错误」，真正元凶是不良设计、不良流程与不良操作习惯。
5. **有效合作需要把人机互动看成不同族类之间的共事**（更像人与动物，而不是人与人），关键是**增强，而不是全面自动化**。
6. **自然、共生的关系**（李克莱德）是目标：艺术家与工具、骑手与马、驾驶者与车、只建议不强制的推荐系统，是四种可对照的关系。

## 关键概念补全

**两句独白 vs 对话**：对话要双向问答、可协商理由；独白是各说各的指令。汤姆的导航给出路线却「不让我做主」，就是独白。

**责备—培训**：出事后怪操作者、要求培训与惩处。作者认为这让责备者自我感觉良好，却不改设计。

**共生（symbiosis）**：李克莱德（J. C. R. Licklider, 1960）所说人脑与电脑密切协作，成效超过任一方单独工作。作者强调应尽量让合作**自然发生**，而不是必须先经过大量训练。

**H—比喻（H-metaphor）**：H 代表马（horse）。缰绳松则马自主、缰绳紧则人控；NASA 兰利与德国布蓝兹维运输中心把这种连续控制权变化用到汽车、飞机乃至家居。

## 一、机器如何主控：从紧张的妻子到紧张的汽车

### 论证推理链

**论据 / 案例 / 事实**

- 作者在旧金山湾区到太平洋的山路上开车，自己觉得从容，妻子脚蹬底板、肩耸、臂抵仪表盘。
- 对照想象：同一路段上**车子**紧张——座椅直立、安全带收紧、仪表盘发讯、刹车自动开启，作者于是减速。
- 已有豪华车：偏离车道时犹豫、鸣笛、振方向盘或座椅、侧镜闪光；厂商试验逐步矫正回车道。
- **转向灯的新含义**：过去告诉别的驾驶员；新设计中转向灯是告诉**自己的车**「我确实要变道，不要拦我」。
- 莎瑞·特克（Sherry Turkle，MIT，人与科技关系）：「为什么你想倾听车子，而不是妻子？」
- 汤姆送作者去机场：喜欢新车，但从不用导航——「它就不让我做主。」
- 谈判：低职位代表常谈出更有利条件，因为无权拍板，「要问上司」；律师朋友会直接打电话给对方上司。机器也会这一招，且无法拒绝。
- 关掉导航仍可开车；关掉防抱死刹车或稳定控制则可能致命。除资深专业驾驶员外，这两类系统通常比一般人控车更好、挽救生命。
- 柏拉图《对话录》：苏格拉底说书写物看似有智慧，你再问它却只重复同样的话。作者认为书面文字仍有教诲功能，因人可彼此辩论；但**没机会讨论、解释或辩论的科技不是好科技**。
- 圣赫勒纳（St. Helena）到帕洛阿托（Palo Alto）的导航表给出最快/最短/最便宜三条；景色最好的路线并不在内；仍是「有三个方案，选一个」，不是对话。
- 未来用品：智能银行决定贷款、智能医疗决定治疗用药、监测饮食阅读音乐电视偏好、违规则通知保险/租车/警察、监控盗版。

**推导**

妻子埋怨可以追问、同意或改开法；汽车沟通是单向的。人能力更强却权力更小：机器像「对不起，上司不同意」的谈判代表，而「免谈」不是选项。高科技标榜「沟通能力」是用词不当。设计师倾向尽可能全面自动化；技术与成本限制造成**部分自动化**，人必须在机器失灵时接手——双方必须知道彼此在做什么、用意是什么。

成功对话需要共通知识、环境脉络、历史与多方目标；作者起初以为关键是更好的对话系统，后来认为这正是当今科技的根本局限。应把人机看成不同认知系统：有时跟随机/机器，有时它们听从人。

**结论**

智能设备已经在用身体语言和强制动作主控；它们根据有限事例推测意向，行动难免武断。机器需要更多社交、承认自身限制，才能真正有用——这是全书主题之一。

**启示**

评估「智能」产品时先问：能否协商、能否关掉、关掉有没有安全替代、决策理由是否可见。不要把单向指令当成沟通。

### 实操方法与设计原则

- 合作 = 协调行动 + 提供说明和理由 + 由经验建立互信。
- 部分自动化时：**人和机器任何一方都必须知道彼此在做什么和其用意。**
- 导航改良方向（仍不够）：地图上同时显示备选、距离、时间、费用；允许追问细节与修改。
- 不要强制专业驾驶员无法关闭自动系统；计算正确不等于假设（路况、交通、驾驶能力）正确。

## 二、我们将去向何方？谁将主宰？

### 论证推理链

**论据 / 案例 / 事实**

- **吉米**：高速公路上用自适应巡航（adaptive cruise control）跟车减速；转出口匝道时忘了系统仍开着，前方无车后系统加速到高速限速。他及时刹车才未出事。
- 工程师三种反应：(1) 怪驾驶员为何不关巡航；(2) 怪驾驶技术不好；(3) 有人承认变道插入时空档很近，巡航会因距前车太近而刹车，后车不知道会追尾。玩笑：自动刹车时点亮特殊刹车灯——「别怪我，是车自己刹的。」
- 洗衣机：封闭环境，启动后机器接手，作者不干涉则顺利。一旦想中途改设定，新设定何时生效（立刻还是下一加水段）就不清。
- 「智能」微波炉：感应器测温湿度来**推论**熟度，不能试硬度、看颜色、测内部温度；手册写「对同一道菜不要连续用两次感应系统，否则可能烹煮过度或烧焦」。
- 实验室：感应居住者的房子（灯、室温、选音乐）；冰箱防变质食品；马桶把体液状况发给医生；体重计监控；茶壶尖叫报水开。
- 机器失败时，操作者常在无预警下接手、时间不够；事故仍常被归为人为错误。

**推导**

直到晚近人都在主宰机器（开关、指示、引导）。电脑介入后我们仍自以为在主宰，实际上机器逐步接管。正常时它们更安全、减无聊、更精确（前车硬挤进来时平稳减速；微波炉知马铃薯熟了）。突发时同一套逻辑会降安全、降舒适、失准确。

意外经常发生、时刻无法预期。机器「智能」在设计者办公室里，不在现场。机器觉察与人不同，缺高层目标，不理解人的目标与动机；强在速度、动力、一致性，弱在社交、创意、想象力、同理心。这不是加一个传感器或改几行程序能消掉的本质冲突。

完全可控、无人干扰、可预测的环境才是自动化的舞台。一旦需要人机共同合作或人中途改主意，钩心斗角就会造成激愤、挫折、损害。

**结论**

人机行为冲突是根本问题：机器对环境、人的目标动机和异常状况了解不够。当聪明设备把有效率、有创意的使用者变成随时监控、修理、维护的仆人，生活就会变坏。现在还来得及改进。

**启示**

- 定速巡航应提示「正在使用哪些系统」；出口匝道应断开或切到安全车速——但补丁仍是设计者再想象一种场景，不是真正智能。
- 封闭家电（洗衣）与开放协作（开车、中途改程序）要分开设计控制权交接。
- 传感器测的是代理量（温湿度），不是目标量（熟度、洁净度）；手册与界面应说明推论限度。

### 实操方法与设计原则

- 设计应**契合使用者实际行为**，而不是规定他们「应该」记住模式。
- 巡航几乎不给系统现况线索：应提醒驾驶员正在使用哪些系统。
- 人或机器谁对谁错不重要；**不一致**会导致激愤、挫折、伤害。

## 三、智能设备的崛起：迈向自然、共生的关系

### 论证推理链

**论据 / 案例 / 事实**

- 李克莱德《人与电脑共生理论》（1960）：人脑与电脑密切协作，进行人脑想象不到的思考。
- **四种自然互动**：
  1. **人与传统工具**：画家、雕塑家、木工、音乐家的工具如身体延伸，注意力在材料与作品上，不在「使用工具」。
  2. **马与骑手**：双方都有感知；马用步伐、机警/惊恐/急躁等身体语言，骑手用坐姿、膝、跟、缰绳；图1.1。
  3. **汽车与驾驶者**：一方有感知、一方是精巧但无感知的机器。作者看儿子在租来的赛道开德国跑车：轻点刹车让重心前移、转向、车尾可控外滑（转向过度）、回正加油——人、子、车同时享受掌控。
  4. **推荐系统**：较慢、不甚优雅但更「智能」；**只建议不控制**；分析你的选择与相似兴趣者；可给摘要、目录、书评；有的解释推荐理由、可设定条件；实验室系统可在阅读写作时旁供相关资料。好系统：切题、不冒昧打扰、需要时才召唤。坏系统会窜入、侵隐私。
- **告诫**：作者骑马时人马都不愉快——共生需要训练与技巧。第四类系统使用者不必高技巧，但设计者仍须注意社交方式。
- 网站草稿引出研究者用 H—比喻做汽车/飞机操控；作者访布蓝兹维（第三章再述）。缰绳松紧连续调节控制权。
- **易惊的马 / 敏感的机器**：车太近前车或危险车速时能否犹豫、惊恐？对合理指令顺从、对不合理指令迟疑？车身反应能否传安全信息？智能住宅按「心情」控灯、选乐、换台——是否要上课学「如何与房子相处」？
- 汽车如何表现紧张：马用后退、颈肌紧绷；车能否突然后退、尾坠、头抬、头左右摇？已有车在方向盘轴装摄像头，驾驶员东张西望且将撞车则自动刹。
- 欧洲实验室：先玩费力游戏，再到舒适椅、温馨家具、放松灯光的房间；研究房间能否感压力而疏解，或用亮光、活泼音乐、暖色打气。
- **机器易懂，动作难行**：思考（逻辑、细节）机器进步大；站立走动跳跃避障对人易、对机器难；情绪在判断好坏安危与通讯上对人重要，机器情绪仍很简单。斯特罗斯《终端渐速》里行李箱「跟我来」会滚轮跟随，熟知主人密码与显性指纹；现实中轮式箱如残障物件，需坡道电梯，都市视觉易失效。
- 科幻对照：C-3PO 笨拙、HAL 无所不知、《刀锋战士》瑞克·迪卡人/复制品难辨。21 世纪机器人几乎不能有意义沟通、不能像人行走、操控实物能力极有限。家居智能只能集中于煮咖啡、洗衣洗碗、灯、冷暖、吸尘擦地除草。
- 新闻与会议：会拥抱的泰迪熊教外语、开车时打瞌睡仍自动驾驶、吉娃娃大小恐龙知你是否爱抱、屏幕随坐姿心情移动、派对机器人招呼来宾；「感性的智慧型环境座谈会」（纽卡索）；环境智慧、生物感应。
- **RFID**：微小标签贴服装产品食品甚至人与宠物，查询时从讯号取电、不需电池；与摄像、麦克、传感器一起可唠叨「多吃花椰菜」「奶油用完了」。
- MIT 媒体实验室 **厨房通（KitchenSense）**：摄像 + 地板压力计；「用了冰箱再站微波炉前，很可能在解冻」——「很可能」= 猜测；OpenMind / CommonSense（故意与 common sense 混淆）是设计者写入的有限常识；失效弱化（功能失效也不伤安全）；工作台显示预测选项，对则按键，不对则忽略——如果你不在乎满屋建议。
- 《关键报告》（斯皮尔伯格 / 菲利普·K·迪克）：逃亡中广告牌喊安德顿名字、推车与阿鲁巴度假。现实：Mini Cooper 车主 RFID 让广告牌显示车主自选字句；研究者用步态、脸、车型颜色车牌辨认；伦敦用此追踪入市车辆；安全部门与广告公司都要用。

**推导**

自然互动应下意识、不费力、双向。工具共生只发生在技巧纯熟的人与精心设计的工具之间。推荐系统之所以不讨厌，因为人可拒绝。智能住宅与厨房的「知道你」是统计猜测，不是读心。广告识别一旦开始，「何处是终点？」

深夜起床不想吵醒妻子，房子却欢快「早安」、开灯开收音机——要解释场合与意向，需要高水平沟通，短期做不到。自动装置仍需人控；最坏是人机冲突，最好是共同体，**人让机器更聪明**。

早期蒸汽机、汽船会爆炸，后来几乎不会；早期飞机常坠，现今很少。吉米那种匝道加速，未来或可用巡航+导航结合、公路输出限速、或按弯道湿滑行人决定安全车速来避免。作者相信科技能丰富生活，但**目前方向**会妨碍、挫折、增危险。第一次出现了**想与我们社交互动**的机器。老办法不够；需要冷静、可靠、人性化：**重要的是增强，而不是自动化。**

**结论**

智能设备崛起后，主控权正在从人滑向机器；出路不是拟人对话，而是自然共生、只建议不强制、承认不同族类与科技极限。

**启示**

- 优先做「推荐/增强」而不是「代你做主」。
- 评估智能家居：错了会不会强制、建议是否可忽略、是否需要上课才能住。
- 不要把「很可能」写成系统「知道」。

### 实操方法与设计原则

- 四种关系对照：工具延伸身体；双感知系统互读；人+精巧无感知机器；慢但可拒绝的建议。
- H—比喻：用连续的「松/紧」分配控制权，而不是开关式全有全无。
- 厨房通式系统：显示选项、人确认；失效弱化；不要假装有常识。
- 全书收束句：**增强，而不是自动化。**

- **必要依据**：给出主旨依赖的机制；删掉则主旨不立。
- **限定**：划定适用范围。
- **可替换例证**：用产品、场景、引文旁证；同类例子可换。
- **次要观点**：非主旨，只作旁证。
- **过渡/场景**：转场或铺垫。

1. 【第二档·可替换例证】山路驾驶：作者自认从容，妻子身体紧绷；对照想象中汽车用座椅、安全带、仪表与自动刹车表达惊恐。
   （旁证第4段「机器已能主控」）
2. 【第一档·陈述】豪华车已能在偏离车道时犹豫、示警、逐步矫正；转向灯从告诉别人变成告诉自己的车「不要拦我」。
3. 【第二档·可替换例证】特克追问：为何听车不听妻子；作者答沟通单向——可追问人，不能追问车。
4. 【第一档·必要依据】汤姆不用导航：「它不让我做主。」人能力更强、机器权力更大：低阶谈判代表无权拍板；机器会这一招且无法拒绝。
   （本段是第5、6段的必要依据）
5. 【第一档·陈述】所谓沟通常是两句独白；关掉导航仍可开，关掉防抱死/稳定控制则可能致命；部分自动化时双方必须知道彼此在做什么。
6. 【第二档·可替换例证】苏格拉底论书写只重复同一句话；作者承认书仍可教，因人可彼此辩论；没机会讨论的科技不是好科技。决策过程比决定本身更影响信任与执行。
7. 【第二档·可替换例证】圣赫勒纳到帕洛阿托三条路线仍是「选一个」；最美风景不在表内。自动竖直座椅或刹车既不问也不商议；专业驾驶员会关自动，新车常不给关。
8. 【第一档·限定】智能贷款、医疗、偏好监测、违章通知、盗版监控都按有限事例推测意向；机器不可能掌握影响人决策的全部因素，仍须改善沟通并承认限制。
9. 【第一档·陈述】成功对话需要共通知识与脉络，这是科技根本局限；人机应看成不同族类，有时追随、有时被听从。
10. 【过渡/场景】「我们将去向何方？谁将主宰？」转入自适应巡航事故。
11. 【第一档·必要依据】吉米在出口匝道上被仍开启的巡航加速到高速限速；正常有用的系统在突发时降安全。事故常被归为人为错误。
    （本段是第12、13段的必要依据）
12. 【第一档·陈述】责备—培训不能当不良设计的借口；设计应契合实际行为；巡航几乎不提示现况。工程师补丁（匝道自动断开）仍是设计者再想象场景——智能在设计者脑中，意外必然且不可预期。
13. 【第二档·可替换例证】变道插入时巡航急刹、后车不知情；玩笑式「自动刹车灯」道出人机紧张：机器一致但缺高层目标与同理心。
14. 【第一档·限定】封闭环境（洗衣不干涉）机器可接手；共同合作或中途改意则冲突。智能微波炉测温湿度推论熟度，不能二次感应。传感器设备不解释「为什么」，手册也不写。
15. 【第二档·可替换例证】实验室房子、冰箱、马桶、体重计、尖叫茶壶：满足所愿则好，把人变成机器仆人则坏。
16. 【第一档·陈述】李克莱德共生：自然、下意识、双向融合。四种关系——工具如身体、马与骑手双感知、人与精巧车、只建议不控制的推荐系统。
17. 【第一档·限定】共生常需训练技巧（作者不善骑、乘客怕生手驾驶）；推荐系统可降低技巧门槛，仍须社交方式得体。H—比喻用缰绳松紧连续分配控制权。
18. 【第二档·可替换例证】易惊的车/房子：车如何表现紧张；方向盘摄像头在分心将撞时自动刹；放松实验室用光与乐配合情绪。
19. 【第一档·陈述】对人易的动作对机器难，对机器易的逻辑对人不必是顶峰；家居智能只能做环境可控的单调工作。会走的行李箱仍受轮子、台阶、都市视觉限制。
20. 【第二档·可替换例证】科幻机器人、会议新闻、环境智慧邀请函、RFID 唠叨厨房、厨房通把「很可能」当知道、电影广告牌与 Mini Cooper / 伦敦摄像追踪。
21. 【第一档·陈述】场合与意向沟通短期做不到；最坏冲突、最好共同体（人让机器更聪明）。科技专家说弱点会被克服，作者承认部分对，但当前方向会妨碍与增险。
22. 【第一档·陈述】老办法不够；关键是增强，而不是自动化。
