# 卷二 第05章 善于交际的设计

## 本章位置

第四章说明人靠社会性语义符号读懂世界。本章问：**机器、官僚机构和空间为什么经常不会交际？** 停车收费机、寂静电话线、「舒适的噪声」、愿望线、推荐系统，都指向同一处方——顺从、宽容、沟通发生了什么；设计要支持高级目标、中断和真实使用环境，而不是把每件产品做成孤岛。第六章把「交际」放大到服务系统的俄罗斯套娃。

## 核心论点

1. 机器只能处理设计师考虑过的事件，意外总是未被预先考虑到。故障合理（人也犯错）；不善交际的是：不道歉、不解释、不帮忙、用嗡嗡声对待困境中的人。
2. 工程师常从机器角度思考，把人当阻碍，被迫适应真实行为时说成做「傻瓜版本 / 白痴版本」。寂静电话线被加回噪声后，他们称为「舒适的噪声」——作者称为**有意义的反馈**，必不可少，不是侮辱性的安慰。
3. 现在必须让技术适应人：力求**顺从的系统和宽容的系统**。善于交际的机器要关心与之互动的人、理解立场、沟通发生了什么。
4. 工具多为低级别任务而设计，人却为高级别目标行动；不善交际的「智能」工具无法应对目标改变、步骤替换、多工具并用。
5. 生活充满中断；当今技术很少支持保存位置与状态。中断造成高认知负荷、错误、重复或跳步。
6. 忽视真实使用环境（电线、背面、插头）会把简单美丽变成复杂丑陋。
7. **愿望线**显示人的真实路径与规划的错位；能量最小化是物理规律。明智规划师据此改路径；艺术、安全、非法行为则可以不适应。
8. 电子痕迹构成推荐系统与社会网络：可简化交互，用于预测个人非法行为时则制造困惑的复杂。群体理解通常比个体更强；对机器与服务的设计都应被视为社会性活动。

## 关键概念补全

**善于交际的设计 (sociable design)**：本册一度几乎以此为书名。机器与服务在出错时表现得像善于交际的人：道歉、试图解决、积极帮助、保持礼貌；平时则沟通状态，支持高级目标与中断。

**有意义的反馈**：相对工程师所谓「舒适的噪声」——让人知道系统仍在工作的信号。

**信心显示器**：演讲者前方（或讲堂后墙）的显示器，使其面对观众仍能看到与观众相同的画面。

**网状曲线 (Reticulating splines)**：备份软件 Mozy 进度用语，源自威尔·赖特插入《模拟城市 2000》因为「听起来挺酷」，后成业内笑话；荒谬短语仍令人放心。

**愿望线 (desire lines)**：人踩出的土路，显示希望的路径与规划师矩形人行道不匹配。可扩大为任何自然行为留下的痕迹（刹车印、长椅磨损、表格填到方块外）。

**间接通信 / 痕迹**：第四章 stigmergy 在电子世界的延续：摄像头、信用卡、搜索前后活动、试图删除仍留下的通信记录。

## 一、愚蠢的机器：停车收费机与反馈

### 论证推理链

**论据 / 案例 / 事实**

- 图5.1：常见停车场收费机，通常运转很好，用人类（女性）声音对顾客说话；出错时标准愉快形象被冷漠不善交际的嗡嗡声取代。大厦大厅电梯旁：插停车票、算费、现金或信用卡、验证票、15 分钟内可将车开走。女士付费后一直没收到验证票，无引导，该做的都做了。踢机器，按按钮得「哔——」，「它不给我票！」漫无目的喊、按更多钮、更多嗡嗡。设计师在右侧放了大「援助」按钮：按下有人扬声器回应，必要时服务员从三层办公室下来用人类智慧解决。
- 机器接管日常常规可简化生活；12 层停车库昼夜取车因机器而简单。不工作时机器带来复杂。想设计能处理所有复杂性尤其意外的机器，一般都很难成功。明智做法：找人求助。次要问题：设计师对必须使用机器的人缺乏同情——可克服。
- 善于交际的人处理错误：道歉、试图解决、自始至终积极帮助并保持礼貌。机器应表现这种基本态度。
- 官僚机构：请求被幕后不可知活动阻碍延迟；打交道的人友好合作，除道歉无法帮助。不利于交际：无解释、不知问题在哪、不知为何得不到帮助。办事员也可能同样沮丧，聚在一起抱怨规章妨碍有效帮助。问题不是某人不合情理，是信息不足。
- 设计师通常只关注正确行为。出错时机器常感觉不到问题，不断要求下一操作，意识不到客户陷入困境——即收费机前愤怒女士的情况。
- 工程师：「要是没有周围这些人，我们的机器会工作得很好。」适应人的真实行为被说成傻瓜/白痴版本。
- 打电话完全无提示 → 挂断再试。人们先抱怨线路噪音，工程师努力完全安静，人们又抱怨安静。加回噪声时称为「舒适的噪声」。作者：有意义的反馈，不舒适但必不可少。
- 演讲：舞台灯目眩看不见观众；图在身后。无经验发言者背对观众对着屏幕讲完全场。方案：前方放显示器（地面、讲台、第一排前）或后墙大屏——反馈让发言者看到与观众相同内容。尚未解决：对机器缺乏信心。图片不能正确显示、视频练习正常正式崩溃。作者放弃尝试显示视频。要的是恢复信心、信任；千万别叫舒适噪音、信心显示器、傻瓜版本、白痴版本。
- 作者收集大量人与官僚、机器、人与人之间误解的例子，问题都在设计师缺乏社会交际规则。曾写：工程师程序员逐渐从机器角度思考，他们不是普通人、不是服务对象，但掌握科技所以控制科技团体，是需要说服的人。建议回到人类范畴：人需要顺从和宽容。让工程师程序员设计师力求顺从的、宽容的系统。现状是人适应技术，是时候技术适应人（诺曼，2009）。
- 顾问经历：美国所得税网上应用全新版本。无数规则表格，对专家都难。程序允许任意顺序输入、跳过未准备好的步骤；每步明确确认，显示已完成步骤与假定结果；一直有「更多」按钮，解释为何这步必需、出问题怎么办。软件仅上市很短因公司内部原因叫停；出现时因舒适辅助方法评价很高。客户当时称之为「情感化设计」。那是作者在善于交际设计上的第一次尝试。
- 启示：使与技术的交互社会化。需要善于交际的机器、沟通技巧基本课、机器礼仪规则。机器需显示关心、理解立场，最重要是沟通，让大家都明白发生了什么。

**推导**

自动化在「设计师画过的路径」上简化生活，在路径外把人丢进无模型、无反馈的空间。官僚与机器同构：前台友好，后台不透明。工程师把反馈污名为舒适/傻瓜，暴露立场在机器一边。税务软件证明：确认、可跳过、可解释「为什么这步存在」，就是交际。

**结论**

意外必须被当作设计对象。失败时要像人一样交际；平时要有有意义的反馈。让技术适应人，做顺从、宽容的系统。

**启示**

每个流程画「出错/无票/无声」分支：道歉、解释、人工入口、状态可见。禁止用嘲讽内部名称呼用户需要的反馈。允许乱序与跳过，并显示目前假定结果。

### 实操方法与设计原则

- 预设「找人求助」通道（援助按钮、人工下来），不要假装机器能处理一切意外。
- 反馈：让人知道系统在工作、卡在哪、下一步要什么。
- 交互：确认已完成、当前结果、为何需要某步、出问题怎么办。
- 用语：有意义的反馈、信任；不用舒适噪声、傻瓜版本。

## 二、网状曲线；目标与技术错位；中断

### 论证推理链

**论据 / 案例 / 事实**

- 家用备份 Mozy：扫描文件、连远程安全服务器、不断进度报告。某时显示 “Reticulating splines”，手册无解释。网上约 4 万条。威尔·赖特因「听起来挺酷」插入 SimCity 2000，此后游戏与 Mozy 沿用。技术人员社交平台通常很少沟通、很少社交技巧，荒谬短语仍暗示「把复杂留给专家、神秘服务器云」。屈尊口吻：「请不要用你漂亮的小脑袋想这件事……把讨厌的曲线结成网。」
- 我们依赖无法理解的系统：国际银行、贸易、货物乘客调度、航空票价——规则复杂到无人期望完全掌握。家用操作系统也可超 50 万行命令。不理解是双向的：技术不了解我们，甚至不尝试。出错时缺信息则不可能知道发生了什么。技术世界越来越不善于交际。世界级领导人也会因简单问题陷入技术困境，原因就是缺相关信息。
- 机器无智能（尽管工程界在努力给一些），但无论有无智能都需要社交态度，很少被考虑。责任在设计师：智能、礼貌、同情、理解由设计师工程师植入。用户看见的是机器，归咎于机器。
- 人通常为较高级别目标做事，单任务是步骤。例：愉快夜晚 → 烹饪晚餐（已是高级活动）→ 更低级别含磨刀、切菜。磨刀远没有晚会目标重要。工具却是为低级别行动准备的。机械工具因性质稳定易懂，人能在高级需要与工具能力间平衡。智能工具的问题：机器规划的行为/预期与人的不匹配；人常在中途改目标、替换步骤、颠倒次序。不善交际的工具无法应对。多数活动需多工具多技术，但每件工具被设计得好像它是唯一被使用的。孤立、与使用环境无关的智能工具不可能善于交际。善于交际的设计要同样好地支持高级活动与低级任务。
- 中断：多数工具假定一口气干完、无其他任务。现实：朋友同事老板、个人生活、休息进食下班、多任务并行。阅读中断要找回页码并重建思考；编程写作设计等全心投入时更严重。文献：中断引起高认知工作量、低效率、错误（忘位置/状态、重复已完成或跳过未完成）。一任务打断另一，因重启动时间，总时间可能远大于无打断。关键行业可威胁生命：商用航空起飞降落禁止随便交谈或与机舱工作人员相互影响；医疗紧急中高度集中被不断打断。即使每任务简单，交织后不断造成出错可能。技术侵入日常，打断数量增加，最简单任务变复杂，增错、降效、增压力混乱。
- 对策：中断不能停，需要辅助保持位置与状态。工具应内置自动方位记录和提醒；能离开并迅速返回；快速方便记住已做、需做、当前状态；关键信息断电也可恢复中断前精确位置状态；一活动被清去跑另一活动后，能很容易回到初始活动并从中断处继续（伴身份与状态显示）。当今技术很少支持中断。

**推导**

「听起来很酷」的进度词碰巧满足了「有人在干活」的社会需求，说明交际阈值可以很低，但不应停留在笑话。目标层级与工具层级错位，是「智能」比锤子更气人的原因。中断是默认环境，不是异常。

**结论**

机器必须有社交态度（设计师的责任）。设计要支持高级目标、多工具、改计划。必须为中断做状态保存与恢复。

**启示**

进度文案宁可具体（正在上传第 n 个文件）也不要装神；但有文案仍优于死寂。写用户故事时从晚会/出差等高级目标写起，再映射到工具。任何超过数分钟的任务都做：离开、断电、被叫走、再回来。

### 实操方法与设计原则

- 沟通：持续状态、即使技术细节是安慰性的也比无声好；更好是可理解的模型。
- 支持改目标、改顺序、跳步、多工具交替。
- 中断：自动记录位置状态、断电可恢复、可切走再切回并显示身份与状态。

## 三、对使用方式的忽视；愿望线

### 论证推理链

**论据 / 案例 / 事实**

- 杂志建筑室内：一尘不染，草坪修剪，人行道无裂，桌面无文件，厨房只有漂亮果碗无脏盘。设计竞赛与工业设计杂志同样忽视真实环境。作者当评委：创意展在原始环境中，无电线插头、无人、无周围活动。他试改规则：将来展品必须展示使用中状态，带电源线、扬声器连线、网络外设。同事宽容微笑，什么都没改。
- 设备前面被造得美丽优雅，背面被忽视。商业甚至家里，美的一面只被使用者看到，访客顾客朋友家人看着后面。图5.2：国家科学基金会设计会议室地板上电源板电线乱糟（讨论优雅美丽的两天不得不盯着）；帕罗奥多一家银行；西北大学工程学图书馆；斯坦福詹姆斯·克拉克中心窗外看进去是丑陋背面。纠结电线在难以触及位置，连接、断开、检修变复杂。不善交际的、不必要的复杂。
- 公园大学：整洁人行道间凌乱足迹穿过空场草地甚至花坛 = 社会性语义符号，人的愿望与规划者设想不匹配。人走路尽量简化路径，喜欢更短路线，即使穿过花园或跑上丘陵。图5.3：(a) 矩形人行道 vs 夹角捷径；(b)(c) 埃文斯顿；(d) 凯文·福克斯摄于加州大学伯克利分校。
- 规划师厌恶，当自私懒人破坏精心成果，称愿望线。传言：有大学先不铺路，用一年再沿踩出的路径铺——作者怀疑：太明智太人性化；施工要尽快让人进去工作；延迟则抱怨一年泥泞；预算含人行道且须在财年用完。家具同样：新建筑一次性家具拨款须在财年底前花掉，不管空间是否故意空置扩充，未来使用者需求未清也必须买完。
- 菲利普·沃伊斯博客「景观充电」：愤怒景观师称捷径为「景观中的污点」，要因那些宁可 A 到 B 最短而不用预设路径的懒人；主张篱笆树木池塘花盆迫使走预设路。
- 大量使用公共空间常带来破坏：窗上纸板铝箔挡阳光和海报；海报标志通知把校园墙和人行道弄乱。令人恼火，但根本上应恼的是缺乏社交能力的设计所引发的回应。人穿越草坪花坛因为路不在需要处；挡窗因为眩光无法看电脑、室内过热；标志到处是因为解释如何用、为何不工作、或发公告没有更好地点。
- 为何不把愿望线当参考并改路径？为何添不必要复杂？懒惰=能量最小化，物理系统都采取尽量减少能源消耗的状态，人也如此。用障碍阻止更有效路径，不是在为必须使用这空间的人设计。公共空间为人准备，除非它是艺术作品。以人为本、善于交际的设计：为使用者利益，考虑真正需要和愿望。
- 卡尔·迈希尔：使用糟糕系统时的尝试痕迹与愿望线基本相同——刹车痕迹、长椅楼梯磨损、表格正确信息没填进设计师预设方块。只观察行为，意图与观察差异提供设计信息。
- 简单简化法：用实际行为痕迹，设计支持愿望的系统。
- 有时设计为了激发：艺术品有意创造思考讨论争论。作者有菲利普·斯塔克「外星人榨汁机」，不太擅长制果汁，网上无数「榨不出汁」评论。斯塔克说过目的是创造对话。作者当艺术陈设客厅，厨房用更功能性的榨汁机。
- 忽略愿望、制约行为以适应美景：适用于艺术品（引起争论），也适用于防止不安全、危险或非法。此时设障碍、警告、法律合理；有意识使不当行为难以出现。标志不总起作用（图4.6），有时增加复杂。愿望线表明真实偏好，并非所有偏好都要被适应。

**推导**

竞赛照片删除电线，等于删除真实任务。背面是社会性界面——给所有非操作者看的那一面。愿望线是第四章社会性语义符号在景观上的版本。能量最小化不是道德污点。例外要显式：艺术、安全、非法，而不是「我的平面构图更重要」。

**结论**

孤立设计组件放在一起会变成恼人的复杂。愿望线是应被聆听的语义符号；艺术与安全可以不听从。

**启示**

交付物包含背面、线缆、维修空间。校园/软件先观察踩踏再固化导航。挡光、抄近路、贴告示先当需求信号。艺术作品与危险行为不要用同一套「用户总是对的」。

### 实操方法与设计原则

- 评图/评奖要求「使用中」：人、线、插头、脏。
- 前后面都是设计范围；线缆管理是交际问题不是售后。
- 愿望线：改路；例外：艺术、安全、非法才设障。
- 观察痕迹（磨损、填表越界）= 免费用户研究。

## 四、痕迹与网络；推荐系统；支持群体

### 论证推理链

**论据 / 案例 / 事实**

- 物质愿望线因踩乱地面损坏植物而可见，人越多标记越强。读书：污迹、卷角、折痕、批注、书脊。电子痕迹不借助技术看不见。穿走廊被摄像头记录；信用卡留下买什么、多少钱、在哪；查询留下问了什么以及前后刹那活动。语音或电子通信必须被记录才能传递；收发双方试图删除仍留痕迹。
- 痕迹提供关于自己与普遍人类行为的信息。越来越多科学家研究互联网络：人—人、人—地点、人—系统组织。可简化生活或使更复杂。
- 阅读痕迹的重要性：保罗·奥特莱 1934《条约文件》；万尼瓦尔·布什 1945 大西洋月刊「麦麦克斯存储器」(memex)——显示书籍电影等并自动创建跟踪交叉参照（超文本与互联网半世纪前）。奥特莱工作受二战干扰弱化。布什设想读者痕迹本身有价值，简化后来者：百科全书带关联痕迹；律师综合案例；专利代理人调百万专利；医生循类似病例；化学家按反应痕迹工作；历史学家沿跳跃性痕迹；新专业从庞大记录中找出有用痕迹；大师遗产含弟子全部记录。
- 今日实现虚弱：互联网链接多由网站开发者或算法给出，或经搜索引擎。奥特莱与布什想的是遵循任意一人明确行为痕迹。
- 作者不信盲目跟他人研究痕迹有多大价值：写本节时他徘徊大英百科、维基、图框箭头网站、伯克利信息学院、邮件往来，近两月失败挣扎；读者跟随恐怕得不到启发，不如接受成果。虚假痕迹：早期假定用户善良；今日有人为乐、为制造麻烦、狭隘压迫、传播自己理论并消除其他提示。
- 论文引用是痕迹。法律从 19 世纪晚期列出观点到观点的参考。20 世纪 50 年代尤金·加菲尔德逆向分析科学论文引用，手工到全自动。引文索引可向前追影响，也成学者评级：「过去一年多少人引用你？」用于雇用保留晋升。
- 社会性语义符号成为电子信息重要工具基础：推荐系统。
- 原始推荐：畅销书榜、店员「这是我们最受欢迎的」、避开空餐馆——基于纯粹受欢迎程度。不同于报纸杂志专家评论（须判断是否同意其偏好、是否利益写作）。畅销榜按销售：优点也是缺点。没有人是一般的。现代推荐：电子捕捉行为（电脑电话信用卡），按活动、年龄、居住工作地、对相关物品喜好程度区分用户。只遵循兴趣目标与你相似的人的痕迹。店知你买过什么；虚拟店还知考虑过未买的。节目知看过、跳过、重复。电子书同样。详情可含如何、何时、有时与何人。书商、租赁、音乐体育餐厅服装皆然。执法也用来画像：「喜欢这种东西的人已经制造了麻烦」——麻烦可以是抢劫、谋杀、甚至抱怨警方行动。
- 简化还是复杂化？靠针对共同背景兴趣的一般性假设，积累大量个人信息故通常能工作，非每个特定情况。推荐书或餐厅且可自由忽略 → 受益，简化与复杂成分的交互。用于预测个人行为尤其非正常非法行为 → 平均值预测不恰当，出错可能性和代价都高，为个体和社会制造令人困惑的复杂。
- 支持群体是善于交际设计的标志。图5.4：人机交互社团年度会，落基山冬季独立营地，「空余」时间自然聚集。房间有食物、椅子、聚处、拼图游戏，促进非正式讨论辩论——科学观点跨群体传播的关键。通过隔离优化社会性互动：少即是多，更少机会提供更多关注和深度。即使看不到其他人，群体几乎总卷入活动。所有设计都有社会性成分；群体不同哲学见解议程能使活动复杂化。
- 人自然具社会性和交际性。恰当设计让人了解正在发生的活动，出问题则可能的行动方针能被理解。**理解将复杂系统转换成简单的。** 群体理解通常比个体更强大牢靠。
- 对机器和服务的设计都应被认为是社会性活动，交互的社会性属性应得到与活动成功完成一样的关注。这就是善于交际的设计。

**推导**

布什式「跟随大师脚印」在恶意与死胡同环境中会复杂化。引用分析从帮助科研滑向人事指标。推荐在「可忽略的建议」时是社会性语义符号的善意使用；在「预测谁会犯罪」时把平均值当成个人事实。会议设计说明：有时减少与外界连接，反而增加交际质量。

**结论**

痕迹可简化或复杂化生活，取决于能否选择相似者、能否忽略、是否拿去给个人定罪。善于交际的设计支持群体、让状态可被共同理解。

**启示**

做推荐先保证可忽略。执法/风控用群体画像时，写明平均值不等于个体。协作工具要让「正在发生什么、出了问题能怎么办」对群体可见。有时隔离（关掉外部 distractions）是社交设计。

### 实操方法与设计原则

- 保留使用痕迹，但提供「哪些路径值得跟」的筛选，不要强迫跟作者的两个月死胡同。
- 推荐：相似者 + 可忽略 = 简化；预测个人非法 = 危险的困惑复杂。
- 空间：食物、可聚的椅、共同动手的物件（拼图）促进跨群体交流。
- 机器/服务设计指标同时看任务完成与社交属性。

## 段落总结序列

主旨：机器与空间要像善于交际的人那样沟通、道歉、支持高级目标与中断；愿望线和推荐系统都是社会痕迹，用得好简化，用在个人定罪上则制造困惑。

最小标签集：陈述 / 必要依据 / 限定 / 例外 / 可替换例证 / 次要观点 / 续 / 过渡/场景

1. 【第一档·陈述】机器处理不了未预见到的意外；不善交际的是出错后不解释、不求助、对困境嗡嗡作响。（本段是第2、3段的必要依据）
2. 【第一档·陈述】工程师从机器角度看人是阻碍；「舒适的噪声」实为有意义的反馈。应做顺从、宽容的系统，让技术适应人。
3. 【第二档·可替换例证】停车收费机「援助」按钮、演讲信心显示器、税务软件可跳过+确认+「更多」解释，都是交际设计。
4. 【第二档·可替换例证】Reticulating splines 作为笑话仍能安慰人，说明技术沟通极度匮乏；不理解是双向的。
5. 【第一档·陈述】人追求高级目标，工具停在低级任务；智能工具若不能改目标、改顺序、与别的工具并用，就不善于交际。
6. 【第一档·陈述】中断是默认环境，造成错误与超时；工具须保存/恢复位置状态，当今很少做到。
7. 【第二档·可替换例证】忽视背面与电线把美丽产品变成难用的线团；评奖照片删除了真实使用。
8. 【第一档·陈述】愿望线是社会性语义符号，反映能量最小化；应据此改设计。艺术、安全、非法可以不适应。
9. 【第二档·可替换例证】挡窗、抄近路、贴告示是需求信号；篱笆强迫走远路是不为人设计。
10. 【第一档·限定】电子痕迹可简化也可复杂化；盲目跟随研究路径含死胡同与恶意欺骗；推荐可忽略则受益，用来预测个人非法则制造困惑的复杂。
11. 【第一档·陈述】理解把复杂变简单；群体理解更强。机器与服务设计是社会性活动，交际属性与任务完成同等重要。
12. 【第三档·过渡/场景】隔离式会议用更少机会换更深互动，说明善于交际有时是少即是多。
