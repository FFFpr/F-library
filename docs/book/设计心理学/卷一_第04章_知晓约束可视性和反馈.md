# 卷一 第04章 知晓：约束、可视性和反馈

## 本章位置

第三章讲头脑里的知识；本章讲外界如何把「从没见过的东西」变成可操作：四种约束、强制功能、惯例，以及声音当意符。下一章把约束失效时的后果写成差错分类。

## 核心论点

1. 面对陌生设备，只能结合外界知识（示能、意符、映射、物理约束）与头脑知识（概念模型，文化/语义/逻辑约束，类比）。
2. 四种约束——物理、文化、语义、逻辑——合在一起，可让人无说明书拼出乐高摩托车。
3. 约束若在行动前可见，效用最大；否则只能在试错后挡住后继差错。遗留标准（圆柱电池、USB、钥匙方向）会长期阻碍更好设计。
4. **强制功能**是强物理约束：互锁、自锁、反锁。过烦会被人关掉，所以要在安全与不便之间折中。
5. 惯例是特殊文化约束。打破惯例（目标层控制电梯）即使客观上更高效也会惹怒；新方式必须明显优于旧方式才值得全体改。
6. 水龙头的心理变量是温度和流速，物理结构却是冷热两管。缺标准时，标准化是终极原则：把必须放在头脑里的东西统一起来，且标准应反映心理概念模型而非物理结构。
7. 声音是不可见状态的意符。电动车过静会杀人；声音须报警、定位、不骚扰。拟真可帮助过渡。

## 关键概念补全

**物理约束**：结构把可能操作限定在范围内（大木栓进不了小洞）。最好在实施前就能看出。

**文化约束**：社交行为准则，在头脑中以范式 (schema)、稿子 (script，尚克与埃布尔森)、框架 (frame，戈夫曼) 出现。随时间变（黄灯曾是欧洲前灯）。

**语义约束**：用境况的意义限定操作（骑手面朝前、挡风玻璃在脸前）。新技术会改意义（全自动驾驶后红尾灯提醒谁？）。

**逻辑约束**：其余都装好后只剩一处，最后一块只能去那儿。自然映射是空间/功能上的逻辑约束。

**强制功能 (forcing function)**：在某阶段挡住差错蔓延。三种：互锁（次序正确，如微波炉开门断电、自动挡须踩刹才能换挡、失知制动装置）；自锁（操作保持激活，如退出前提保存）；反锁（不让进入危险区，如一楼到地下室的防火门、儿童锁、灭火器保险销）。

**目标层控制电梯**：厅外选楼层，轿厢内无楼层键，把同层乘客分到同一部电梯。1985 年发明，1990 年迅达首次商用。违反「进梯再按层」的惯例。

**拟真 (skeuomorphic)**：把旧形式带进新技术，即使已无功能（无马马车、文件夹图标）。帮助过渡，纯粹派会批评。

## 一、四种约束：乐高摩托车与电池钥匙

### 论证推理链

**论据 / 案例 / 事实**

- 乐高摩托车 15 件：两组相似件（police 长方块、警察手臂），其余尺寸外形可配但颜色不同。物理上可互换，但角色毫不含糊。试验：不告知是摩托车、未见成品，无人困难。圆柱与圆孔给出组装规则；文化定三灯位置（红尾、蓝顶、黄前——欧洲黄前灯记忆已过时）；语义不让车手头朝后或警察标倒贴；最后一块靠逻辑。
- 圆柱电池两向可装，盒底标识在黑塑料暗处几乎看不见。两端同心圆、中心正极中间环负极的电池几乎未见普及。微软 InstaLoad 触点让旧电池任意向插入，两年后连微软产品都没用。改外形则新旧不兼容 = 遗留问题。
- 钥匙平坦顶 vs 锯齿底易分，锁孔方向在暗处难判；USB 约束太微妙要手忙脚乱。对方向不敏感的汽车钥匙和电器接头早已存在，企业常「一直这么做」。根本需求不是钥匙形状，是只让授权者接近：密码锁、证件卡、遥控、生物特征。

**推导**

物理约束若不可见，就退化成试错。遗留标准把「更好」卡在兼容成本上。认清根本需求（授权）比改钥匙齿形打开的解空间更大。

**结论**

有效约束应在行动前可见。简单插入困难本身未必影响购买，却是「不关心顾客」的前兆。

### 实操方法与设计原则

- 物理约束尽量在尝试前可感知。
- 能做成方向无关就做成方向无关；否则用形状缺口强制唯一方向。
- 问根本需求，不要只改遗产外形。

## 二、文化、语义、逻辑与习俗标准

### 论证推理链

**论据 / 案例 / 事实**

- 熟悉文化里从没去过的餐厅仍知道该怎么做；陌生文化原准则会招反感。新机器难用常因还没有被广泛接受的惯例。
- 违反框架自讨苦吃：电梯里面对墙或盯陌生人；公交上把座让给健壮者。
- 墨西哥窄桥闪前灯 = 我先过；英国 = 请你先过。专家警告即使一国之内也不要用闪灯，解释可能相反。
- 正式晚宴几十件餐具：洗手碗当汤喝会成粗鲁圈外人。
- 行车道哪边、路口优先权（先到、右边、或最高地位）都曾用过；加州合并车道交替前行是不成文惯例。

**推导**

习俗用有效行为约束体现文化。汇集可成法规或国际标准，但同一信号跨文化会冲突。

**结论**

文化约束有力但会变；设计新产品时暂时找不到惯例，就要用另外三种约束补上。

## 三、门、开关与以活动为中心的控制

### 论证推理链

**论据 / 案例 / 事实**

- 门须回答从哪边开、在何处开。平板/门闩同时示能+约束「推」。紧急推杆用另一颜色标出外推位置。汽车外把手凹槽+水平切缝=拉开、竖直切缝=滑动；内把手常找不到、不会用。橱柜：向内推释放挂钩再弹开，设计师不愿破坏平滑面板；玻璃柜后明显没有内开余地，新用户用指甲刀片撬。有人推自动门被带倒。巴黎地铁到站须自己按/转/推门，有人耐心等自动开而误下一站。
- 礼堂灯开关几乎总能当第一课例子。小型飞机襟翼与起落架开关紧挨，起飞收错轮，NTSB 报告称合理原则 50 年前就有。开关越多难度急速上升。德尔玛悬崖边获奖住宅：前厅四开关一行、起居室六开关一列，建筑师说「会习惯」，作者从未习惯。解决：把开关装在稍倾斜的房间平面图上，与灯的二维位置对应；倾斜还提供反示能，杯子放不上。无线/互联网开关可摆脱墙内电缆，但触摸屏失去肘部按实体开关的示能。
- 以活动为中心：礼堂标「视频」「计算机」「灯光全开」「演讲」。以设备为中心则灯光、音响、投影分屏，演讲中切换是认知中断。作者答问时要调亮灯，系统当「非演讲」把幕收回、投影关掉。故活动控制仍须手动覆盖，且切换时不应取消当前活动。

**推导**

门贴推拉说明 = 设计失败。成排相同开关无映射。活动控制对预设场景出色，对「例外」脆弱。

**结论**

先做任务分析再谈以人为本（第六章）。空间映射不是唯一解，活动映射在礼堂往往更好，但必须留逃生般的手动。

### 实操方法与设计原则

- 推门：推的部位给平板；拉门：给可抓把手。内外门把手问题分开解。
- 多灯：二维自然映射，或按活动分组；无线可重构。
- 活动预设 + 手动覆盖，覆盖不拆掉当前活动。

## 四、强制功能：互锁、自锁、反锁

### 论证推理链

**论据 / 案例 / 事实**

- 汽车：过去钥匙开门再点火；现可用口袋里的卡/手机，但未验证不能走，仍是强制功能。
- 互锁：微波炉开门断电；自动挡踩刹才能换挡；火车/割草机/油锯/过山车的失知制动（英国称司机安全装置）——须压紧弹簧，人失控则停。有人捆绑按钮或放重物绕过，于是改成中压、周期性减压、或响应查问。
- 自锁：退出未保存则对话框拦住；作者故意把它当「先退出再保存」的捷径。牢房/婴儿床围栏也是自锁。企业用格式不兼容锁定客户，最终除主导厂商外大家都损失。
- 反锁：美国公建楼梯一楼不让轻易冲进地下室；儿童锁、药瓶盖、灭火器销。公共卫生间弹簧置物架放低挡住门，拿走东西才能出门——防遗忘。图4.7 的门：够让人意识到要离开一楼，用力仍能撑开，折中安全与通行。
- 强制功能太烦会被禁用，从而否定安全。

**推导**

强制功能把差错挡在某阶段。设计要让绕过它比遵守它更麻烦，但日常使用仍可接受。

**结论**

不是每种境况都要极端强制；原则可扩展。聪明折中保留安全、减少日常麻烦。

## 五、惯例、目标层电梯与水龙头

### 论证推理链

**论据 / 案例 / 事实**

- 球形把手的抓握示能是物理的；用它开关门是文化习得。同一装置在墙上则是支撑。
- 目标层电梯：厅外按层，屏引导到某梯，厢内只有开关门和警报。把去同层的人分到一部梯。传统：厅外只按上下，五人进同一梯可能五层都停。打破惯例的设计师写文怒斥。改变主意：下一站下，到厅外重选。公制优于英制两世纪，美、利比里亚、缅甸仍拒；英国大部分已转。一致性让已学知识迁移；新方式只好一点点则不如一致；必须改则全体改，新旧混杂最乱。
- 谢菲尔德研讨班手册教「洗脸池上方水龙头请轻轻按压」；听众许多人拧过，有人去大堂求演示。心理要的是温度与流速，物理是冷热两管。方案：双阀各管冷热；只控温流速恒定；只控水量水温恒定；开关（手势龙头）；分阀分管温与流速（作者从未见过）；单控两方向。双阀有四个映射问题。全球惯例常左热右冷、顺时针关（英格兰常违背；美国也不普遍；垂直淋浴更不知上下谁热）。圆球把手应同向旋转减水；手柄则人会当推拉，拉应加水，即使左右旋转方向因此相反——这是心理概念化。镜像「左右手对称」装反：肥皂进眼时一只手乱拧会把冷搞成烫。延迟：把手在浴缸中部、花洒在墙顶，作者测过 5 秒才变温。单控漂亮却常藏掉运动部件，四类映射无标准。终极：标准化（如上下控水量向上增、左右控温向左升温），标准反映心理模型。

**推导**

惯例被打破，优点暂时无关紧要。水龙头失败在「物理两管」与「心理两变量」不对齐，再加无标准。

**结论**

新方法须明显优于旧法才值得全体改。一切方法用尽，标准是唯一方向，但会妨碍未来发展，常须政治争斗（第六章）。

## 六、声音作为意符；寂静杀手

### 论证推理链

**论据 / 案例 / 事实**

- 有用的声音：门闩咔嚓、门未关好的金属声、消音器轰鸣、未固定碰撞、水壶咝咝、烤面包弹出、吸尘器堵塞变响、机器故障异响。纯哔哔不传隐含信息。电话接通的蜂鸣嗡嗡咔嚓让人知道在通。自然声反映材料、空心实心、撞击滑动破裂。人造声若声谱丰富、不恼人，可同样有用。优点是不看也能听见，缺点是扰邻、难遮盖。
- 慕尼黑乡间评宝马电动车声学：闭眼听蜂鸣+呜呜+胎噪。电动车几乎只有胎、风、电机高频。车迷喜静，盲人怒：过马路靠声。美 NHTSA：行人更易被混动/电动撞，尤其慢行近乎全静。倒车哔哔、喇叭本为提醒却常当泄愤。盲人建议轮毂放石头：低速摩擦、加速啪嗒、高速离心贴住靠胎噪、停车则静（停车静是问题）。保时捷样品扩音器模拟汽油机咆哮；尼桑考虑百灵鸟；有人要统一标准；有盲人要听起来像汽油车。拟真：无马马车、早期塑料像木头、文件夹图标。NHTSA 248 页：低于 30 km/h、静止已启动、倒车须有最低声音，使盲人等能在背景中辨出车辆。原则：报警、定位（位置、速度、接近/远离）、减少骚扰（夜与拥堵不能恼人）。

**推导**

静音取消了汽车作为意符的声音通道。品牌想用声做个性，行人需要可学习的标准。拟真降低学习成本。

**结论**

无声音 = 无那条反馈。声音设计与视觉意符同等，须标准化到「听得出是车、在哪、多快」。

## 段落总结序列

主旨：外界用四种约束、强制功能、惯例和声音意符，让陌生设备在行动前就可知晓；遗留与无标准是长期障碍。

2. 【第二档·可替换例证】乐高 15 件无说明书可拼：物理孔柱、文化灯位、语义朝向、逻辑最后一块。
