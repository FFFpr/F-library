## 核心论点

1. 即便世界复杂，人仍能在全无经验的新状况下 orient：靠他人活动留下的痕迹。这些附加效果是重要社会信号，即**社会性语义符号**。
2. 语义符号像指示器，使社会中的信号可被有意义解读。**蓄意性**：有意识创建布置；**附带性**：行为与事件的意外副产品；**社会性**：来源于他人行为。设计师用蓄意放置的语义符号辅助恰当使用。
3. 在设计词汇里，语义符号通常被称为「功能可见性」，或更准确地说「可感知的功能可见性」——这是作者在《设计心理学》（卷一）里的用词造成的。功能可见性比「标志信号」更深：一种功能可见性甚至不需要能够被感知。引入「语义符号」是为使设计词汇更精确。
4. 社会性语义符号不能保证正确，但富于强烈暗示。准确解读取决于其他知识（是否高峰、是否繁忙大站）。
5. 文化是复杂性的另一来源：盐胡椒瓶每个都简单，装填者与使用者必须社会性同步。好设计把信息放到生活中（透明、标签、孔排成 S/P），使操作不言自明。功能性设计主要是沟通。
6. 对接受者有用即可，不必要求发送方有沟通意图（作者与许多理论家不同）。误导性语义符号存在（高速路「慢速行进波」被当成前方事故）。
7. 语义符号是约定，有时自愿，有时法律强制；对权威级别敏感；只在相关其他人了解时才起作用。

## 关键概念补全

**语义符号 (signifier)**：可被感知、用来引导正确行为的信号。本册中文译文用「语义符号」；卷一常用「意符」。二者指同一设计工具，用来让人知道**可以/应当在何处做何操作**。

**功能可见性 (affordance)**：吉布森意义上，生物与环境之间可能的操作关联，无论是否被意识到。设计师口语里常把它缩小成「能看出来的可用性」。卷一译「示能」。本册强调：示能可以不可见；设计师真正在加的往往是语义符号。

**社会性语义符号**：由他人行为（或其痕迹）构成的语义符号，如月台人群、雪地脚印、书页污迹、推荐系统。

**间接通信 (stigmergy)**：生物学/人造生命用语——通过先前活动的踪迹间接协同（蚂蚁化学痕迹等），无需设定目标或领导人，自组织出复杂结构。

**符号学**：学术领域，致力于「在社会中符号的生命」。

**误导性语义符号**：看起来像某事件的直接证据，实际由完全不同的原因造成。

## 一、月台上的人群：何谓社会性语义符号

### 论证推理链

**论据 / 案例 / 事实**

- 图4.1：火车月台。等待乘客在与不在，暗示火车尚未到或已离开。不能保证正确，但暗示强烈。
- 急着赶火车赶到月台：如何判断已走还是未到？月台状态充当语义符号。等待人群是「尚未到来」的有力证据；空月台暗示可能已离开——也可能尚未到但没人想坐。繁忙中心车站车次频繁，拥挤无法提供特定车次信息，只表示通勤匆忙。与期望值的偏差仍有意味：周末正午为何这么挤？本该忙碌却无人？意味存在，但不清楚表示什么。解读取决于时段等其他知识。
- 即使只是生活副产品，仍表示关键证据。蓄意：有意设计设置、具信息功能。非蓄意附加：阴影是人或物在光源前的附加效果，一看到立刻推断对象存在——既附带又自然，不是被放在某处，而是物质世界自然结果。
- 餐馆：自己找座还是等领位？环顾。不熟的食物/餐具？看别人。雪地走哪条？跟脚印。密集人群难前行？紧随某人。选书、电影、餐馆？问口味类似的朋友。人群提供明确信息（回答、公布）与含蓄信息（足迹、餐厅人群、损耗痕迹）。
- 孩子恶作剧：街角指天看。很快有人一起盯，其实什么没有，不久聚集一群。他人行为通常有信息功能；恶作剧利用这种自然行为。
- 物质世界里社会语义符号是物质的；电子社区里不是，但活动痕迹同样强大：推荐系统、社会网络、基于定位和主题的消息。「喜欢这个的人们也很喜欢……」= 虚拟雪地脚印。
- 希尔等 1992：廉价平装书装订弯曲裂缝可找到上次读到的页；汽配店目录纵向栏的污渍、裂痕、松页标出最常翻的页；铜锈门把手抛光部分显示常抓处；食谱卡片中最佳者通常卷皱沾污。据此他们做了会留下「阅读痕迹和编辑痕迹」的计算机系统，模仿实体书污迹。
- 进化可能「故意」让蚂蚁能留化学痕迹、用先前踪迹建巢；每种动物基因里被赋予建造其独特建筑物的能力。人类非蓄意语义符号可被设计师利用。

**推导**

人在复杂潜藏混乱的环境中找方向，靠的是可读的痕迹，不靠事先背完整地图。电子推荐只是把脚印数字化。设计师既可以布置蓄意符号，也可以放大本就会出现的损耗痕迹。

**结论**

社会性语义符号让我们在复杂中 orient。它们强烈但不保证正确，解读是条件性的。

**启示**

做环境与软件时，问：用户能看到前人怎么做的吗？不要擦掉所有使用痕迹（书脊、路径、最近项目）。推荐系统是社会性语义符号的产品化。

### 实操方法与设计原则

- 三类符号都要用：蓄意布置、保留附带痕迹、让他人行为可见。
- 电子世界用「阅读/编辑痕迹」、协同过滤，对应物质损耗。
- 评估符号时声明依赖的背景知识（是否高峰、是否大站）。

## 二、文化的复杂性：盐和胡椒瓶

### 论证推理链

**论据 / 案例 / 事实**

- 图4.2：哪瓶是盐？作者世界各地问，总是一半人说左、一半说右。理由充分且相反：「盐在左，孔更多」「胡椒在左，孔更多」。哪种正确不重要，重要的是**装调料的人的想法**。
- 设备简单，但是社会系统：一人填充，他人使用。好设计师提供语义符号线索，且不破坏美观、功能、不增加成本。需要换位思考。少数（作者有时觉得大多数）有换位能力的设计师只专注外观、或工程、或价格，结果做出这种盐瓶、现代电视、或第一章罗兰钢琴。设计师说「每个人都知道哪一个是盐瓶」不可原谅。正确使用需要同样知识背景 = 社会性同步，在所有活动中最难达到。
- 问侍者与餐厅经理，总得到权威答案，不同餐厅完全不同。阿姆斯特丹一家高级餐厅：成对放置时盐瓶总更接近大门。随机问几个侍者都赞同，训练不错。作者在几个房间检验，若干桌不成立。经理马上调整：「这些是摆错了。」规则有用，除非不被遵守。
- 寓意：①了解如何活动，必须了解如何与他人相互作用。②现实许多未知不确定、不受控，最佳策略常是小心行事、可能的话先实验——多数人面对不透明金属盐瓶会先撒一点到手上看看。③好设计使整个问题消失。图4.3(a) 内容物可见；(b) 美国联合航空廉价容器，既有吸引力又易懂。也可贴标签，或开孔排成 S/P。信息放到生活中，操作不言自明。
- 文化解读大量隐含在观点中，引出不必要复杂、潜在困惑错误尴尬，除非设计师特别努力提供标识。功能性设计——使周围对象可用并可以理解的那部分——主要是沟通。沟通失败：最好受挫，最糟事故灾难。正确设计最小化对晦涩知识或体验的需求；但生活在人类社会，必须理解社会互动、团体和文化扮演的角色。

**推导**

孔的多少没有物理必然对应盐或胡椒；意义全是约定。约定若只存在于装填者或某家餐厅的培训里，使用者只好做小实验。透明/标签把约定变成世界里的事实，社会性同步不再必要。

**结论**

文化是复杂性来源之一。好设计用可见内容或标签取消对共享文化知识的依赖；不能取消时，人的理性策略是先试一下。

**启示**

凡「每个人都知道」的用法，用异文化或新员工测一遍。成对物（盐胡椒、冷热水、推拉）不要只靠孔数、左右、颜色这类有争议约定。先实验、小心行事，是用户侧合理策略，不应被设计师嘲笑。

### 实操方法与设计原则

- 换位：装填者 ≠ 使用者。
- 优先：可见内容 > 标签 > 开孔字母 > 纯约定（孔多/近门）。
- 规则必须被遵守才有用；培训过的侍者仍会摆错。
- 同一原则适用于任意精密的机械/电子/通信物品，不只调料瓶。

## 三、社会性语义符号：世界如何告诉我们该做什么

### 论证推理链

**论据 / 案例 / 事实**

- 月台人群、路面线条都是信号系统实例。生物学家人类学家长期研究动物与人如何表示对另一对象感兴趣。符号学研究社会中符号的生命。
- 进化信号：体型、吼叫、犄角茸角。行为：求偶；强壮动物「设障」炫耀——雄孔雀长尾妨碍飞行，一当代理论认为是宣扬强大到足以克服障碍。瞪羚见狮不逃而跳：「哈哈你抓不住我」；狮子去追显示脆弱的第一个逃离者或幼小者。
- 作者观点不同于很多理论家：他们要求发送方和接受方都有意图。为存活，信号蓄意或偶然对个人无所谓，对接受方无必要差别。旗帜有意作风向提示（机场、帆船桅杆）还是广告/爱国主义，对看风的人关系不大。图4.4：作者从西北大学附近家窗口看旗：(a) 平静温和；(b) 持续北风；(c) 持续南风；(d) 街对面两旗相反——也许该待在家，阵风出乎意料（照片皆真实；呼应第一章埃文斯顿旗）。
- 图4.5：袋状风向标，蓄意人造语义符号。机场有严格规格，飞行员按伸展程度辨风速；照片略有伸展，风速少于 15 节（每小时 17 英里）。
- 我们要在社会性科技世界正常生活，须研发事物意味着什么、如何运作的内部模型。寻求一切能找到的帮助，都像侦探。有时细心设计师提供线索，否则靠自己创造力想象力。

**推导**

沟通理论若坚持「必须双方有意」，会丢掉阴影、损耗、风向旗这些对行动最有用的线索。设计应同时布置蓄意符号，并承认用户会征用一切偶然符号。

**结论**

无论蓄意或偶然，语义符号都提供自然与社会活动的有价值线索。对接受者有效即可。

**启示**

不要因为「那不是我们设计的信息」就忽略用户已经在用的旗、影、脚印。机场风袋说明：把偶然符号标准化，可变成可靠仪器。

## 四、世界各地的社会性语义符号；约定、权威与误导

### 论证推理链

**论据 / 案例 / 事实**

- 图4.6 伦敦交叉路口：栅栏约束行人；道路隔离带限制汽车；地上「向右看」；疏虚线、密虚线、波浪斑马线、箭头、实线；闪烁绿/红交通灯。行人显然漠视标记，走在完全违反规定的地方。锯齿线是独特英国交通文化，美国人不明白。红停绿行相当普遍，但约 10% 男性分不清红绿（感知心理学家与人类工程学家熟悉，早期交通灯发明者不了解）。物理屏障（栅栏）比灯光与油漆更能限制行为。车辆正确位置也由文化决定：货车在路左行驶，伦敦正确，多数欧洲国家违法。
- 社会性语义符号不能促使人们做出适当行为。它们是约定：有时提示帮助、完全自愿；有时法律定义、警察强制。许多社会对轻微违反宽容：违章行人很少受罚，同样违章的汽车会成惩罚目标。取决于社会解读、制度、文化结构。
- 对权威级别高度敏感。正式晚宴低级别客人：拿错刀叉尴尬；用手指拿炸鸡（快餐郊游正常）可能被驱逐。正确做法：看周围人然后照做。若是主人或贵宾，可做任何觉得惬意的事；用手指吃沙拉，其他客人可能跟随领导者。网上搜「从洗指碗喝水」表明这会是大问题。传闻：维多利亚女王客人误喝洗指碗，女王跟着做以免尴尬——可能虚构，都市传奇，但文化观点真实。顾问建议：有人不知情喝了，主人也跟着，避免尴尬。故意创造「明显适当行为」：一人违反标准时，其他人跟着违反者，使其行为显得正常。
- 漆在地上的车道人行横道是蓄意明确的社会语义符号，一旦习惯无处不在：大批工人被雇来刷油漆。机场跑道坡道、酒店、医院、几乎任何须保持在适当行车线、适当位置停、甚至适当位置游泳跑步骑车的地方都有。蓄意符号通常被设计成可见。作者怀疑明白含义的人少于设计放置它们的人。
- 《欧普拉》网站：坐下不久餐巾放膝盖；用餐期间短暂离开，餐巾折或不折放椅子上再把椅子推进桌；用完餐餐巾折叠放盘子左侧，信号告诉服务员可清理。极好的蓄意、明确、社会性符号案例。多少客人知道？多少服务员知道？作者写此章才在网站发现。即使最讲究清晰的符号，也只在相关其他人了解时起作用。
- 蓄意但完全不可见：排队。许多文化中队伍存在表明有序等待，实际存在充当排队的蓄意语义符号；除从队尾加入皆不恰当，违反者立即被制止。有的文化允许朋友插入靠前，有的不允许，有的不遵循整齐排队。法国游乐园：欧洲文化混合——有的耐心有序，有的认为尽快移到队前恰当；工作人员不断介入防打架。解决方案放到第七章。
- 误导性语义符号：拥挤高速路上车速缓慢停止，多数人当成前方事故。有时是非交通事件：路边房子着火，司机减速看一眼，后方必须减速避撞，延迟累加，形成交通工程师熟识的「慢速行进波」，可传到起火点几公里外全部停滞。「一定是有事故」——误导。远方小幅度缓慢造成的停滞，既是偶然性语义符号，也是无计划行动集合造成突发行为的例子。
- 即使含糊、有时误导，社会性语义符号仍是有关世界运作的有价值线索，帮助通过观察他人有意或无意识行为来安排自己的行为。

**推导**

物理屏障 > 油漆约定 > 对色盲不友好的灯。法律对行人与汽车执行不对称。符号的效力随地位变：贵宾重写规范，其他人跟随。不可见的排队规范在跨文化场所会冲突。系统层的涌现（慢速波）会生成看起来像「前方事故」的假线索。

**结论**

社会性语义符号依赖共享解读，不能单靠布置保证行为；对权威敏感；可能误导。尽管如此，仍是弄清复杂世界、观察他人以安排自己的强线索。

**启示**

跨国路口不要假设线条含义自明（英国锯齿线）。安全色补色盲通道。正式礼仪不要假设「最清晰的规范」已被双方知道。排队规则必须明示或由工作人员执行，尤其在文化混合处。交通 App 若只显示「前方拥堵」可能在传播误导性符号。

### 实操方法与设计原则

- 约束强度：物理屏障 > 法律执行的符号 > 自愿约定。
- 地位高者的行为会被当成新规范（正反都成立：女王喝洗指碗）。
- 蓄意符号必须被接收方 equip 才能工作（餐巾规范）。

## 段落总结序列

主旨：社会性语义符号是可读的他人痕迹与约定；它不是吉布森意义上不必被感知的功能可见性（示能），而是可感知的意符；文化同步失败时要用设计把信息放到世界里。

最小标签集：陈述 / 必要依据 / 限定 / 例外 / 可替换例证 / 次要观点 / 续 / 过渡/场景

1. 【第一档·陈述】人靠他人活动的痕迹在复杂中找方向；这些附加效果是社会性语义符号。（本段是第2–4段的必要依据）
2. 【第一档·陈述】蓄意 / 附带 / 社会性三类。设计词汇里常把语义符号叫「可感知的功能可见性」，源自卷一用词；功能可见性（示能）可以不被感知，故本册改用语义符号（意符）以求精确。
3. 【第二档·可替换例证】月台有人/空：强烈暗示但非证明；解读依赖是否高峰、是否大站。
4. 【第二档·可替换例证】阴影、脚印、餐厅人群、孩子指天、书页污迹、门把手抛光、推荐系统、stigmergy，都是可被征用的痕迹。
5. 【第一档·陈述】盐胡椒瓶的复杂来自文化与装填/使用分工，不是瓶子机械；社会性同步最难。设计师说「人人都知道」不可原谅。
6. 【第一档·陈述】好设计让内容可见或加标签，问题消失；功能性设计主要是沟通。未知时用户侧合理策略是先试一点。
7. 【第一档·限定】对接受者有用即可，不要求发送方有意；旗作风向标不必原是气象设备。
8. 【第二档·可替换例证】伦敦路口符号密集仍被行人违反；栅栏比灯和线更限制行为；红绿对约 10% 男性失效；左行是文化法规。
9. 【第一档·限定】符号是约定，效力随法律、宽容度、权威级别而变；贵宾可改写规范，他人跟随。
10. 【第一档·限定】最清晰的蓄意符号（餐巾放哪）也只在双方都知道时工作；不可见的排队规范在跨文化场会冲突。
11. 【第一档·例外】误导性语义符号：慢速行进波让远方司机以为前方事故。
12. 【第三档·过渡/场景】尽管含糊或误导，它们仍是弄清世界、观察他人以安排自己的线索库。
