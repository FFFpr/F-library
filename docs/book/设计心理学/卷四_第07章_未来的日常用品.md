## 核心论点

1. **日用品正在变聪明**，汽车上的科技明日会出现在厨房浴室客厅；市场驱动会推出顾客未必要求的附加服务。
2. **机器人家用成功条件**是可靠、安全、实用、负担得起；通用人形侍者尚远，形式应服从功能。
3. **特殊用途机器人**（吸尘、割草、特定家电）因任务边界清楚，共通领域较易；通用机器人仍撞上沟通与协调难题。
4. 「科技易改，人性难移」只对了一半：生理结构出生时与几千年前几乎无别，但**经验改变大脑**（伦敦出租车司机海马体等），儿童早期接触会改变反应与思维方式；生物增强将引发争斗。
5. **人必须向机器解释意向**（真的要左转、现在不要清客厅），因机器智力有限，人负沟通重任；人配合科技不是新现象，但「人配合机器」不得成为不良设计的借口。
6. **设计应成为科学**：跨学科通才，把商业与工程的严密和社交艺术美学结合起来；智能机器要求设计者还要考虑**机器的观点**。

## 关键概念补全

**智能代理 / 智慧型住宅 / 周边环境（ambient environments）**：大学与研究机构项目名，选乐、调光色、监控饮食活动乃至交往对象。

**自主型系统（Autonomous Systems）**：作者觉得比含混的「机器人」更合适；有人把不移动的智慧家电也算机器人，很多人因它们不在房间里移动而不承认。

**特殊用途 vs 通用机器人（special-purpose vs general-purpose robots）**：前者本领有限、期望清楚、误会少；后者如电影角色，面临共通领域、如何指挥、如何不彼此牵制。

**以人为本的设计箴言**（对照 1933 芝加哥世博「科学发现、工业应用、人类适应」）：人类规划，科学研究，科技配合——出自作者 1993《让我们更聪慧》/《心科技》。后来想法有修正：仍希望机器配合我们，但机器能力有限、僵硬，人更灵活，适应的担子会落在人身上。

**设计（与赫斯克特讨论后的定义）**：有计划地改变环境来满足个人和社会的需要。

## 一、活的物件、魔镜与被推销的智能

### 论证推理链

**论据 / 案例 / 事实**

- 派蒂·梅斯（MIT 媒介实验室）：「假如身边物件都活生生，能感觉我们的存在、注意的事、行动，并回应讯号建议行动？」正在发明：拿起书告诉你可能感兴趣的章节；抬头看墙上祖母照片则更新祖母近况。
- 白雪公主魔镜总说实话。现在的科技是较谨慎的镜子，答更简单的问题：「这件衣服搭配吗？」明日之镜：把影像发给亲友点评；让你看起来瘦一点；把新衣套上影像免真试穿；改发型。「棕色和蓝色不适合你。试试这外套，配这双鞋子。」
- 先进科技有潜能提升乐趣、简化、增安全——**只要毫无瑕疵运作，只要我们知道怎么驾驭。**
- 卷一开篇：20 世纪 80 年代英国，普通人不会用微波炉、不会设家电时间、开错灶头、甚至开关门困难；某电脑公司创办人兼 CEO 承认不会用公司微波炉热咖啡。
- 智能车为部件驾驶自动、舒适安全；能自动驾驶指日可待，部分自动已出现。
- 韩国手机人说：人人已有手机，必须想附加服务——提醒见友、付账、了解不熟的人、行车时刻、感受心情给建议。汽车当流行商品过时以促换新；手机同样；手表当珠宝不是因技术；冰箱前门彩色屏（冰水分配器旁）显示设计师认为你该知道的。未来包装可被电脑读，冰箱知里面有什么、放取什么、有效期、体重与节食，经常给建议。
- 机器越来越爱社交：影片出租公司比较你和朋友的片单电邮推荐；冰箱或与邻居冰箱比食品；电视：「你的朋友正在看《未来总动员》，我给你转到，已开始也可从头播。」
- 材料：轻耐用可植入不害人体；易回收可生物分解；弹力；能展示照片的衣物——「就快了」。纳米到桥梁轮船；生化金属陶瓷塑胶有机。感应器探移动辨人与物；显示器几乎随处显示。
- 3D 传真/打印：激光与多维测量数字化物体，接收端分层叠薄料（塑胶聚合物，有时金属粉），加热或紫外固化。当时多在公司大学，价钱下降中。不需实物原型，图纸即可。孩子陶雕发给爷爷复制；铰链坏了传真一个；屏幕上设计再造出实物。「客人来盘子不够，」房子或说，「我自己做主打印了同花色盘子。」

**推导**

市场驱动 ≠ 需求驱动。社交化机器会比较邻里、替你改频道。3D 打印把「能画就能造」带进家，也把「房子自作主张」带进家。

**结论**

未来日常用品的问题与卷一微波炉同构，只是对象从按钮变成会说话、会打印、会推荐的系统——驾驭条件仍是：无瑕疵，且人知道如何驾驭。

**启示**

每加一项「贴心建议」，问它能否被关、能否解释、会不会在你招待客人时自作主张。

## 二、机器人的进展

### 论证推理链

**论据 / 案例 / 事实**

- 专家要你相信机器人已能健康管理（遵医嘱）、安全、教育、打杂、娱乐；生产线上、搜救、军事也有。普通个人合理价格的应用大多梦想多于实际，可靠性低，只能示范。
- 家用成功必须可靠、安全、实用、负担得起。会像图7.1 人形侍者吗？（埃里森·王所画，作者希望有但尚需时日。）在家形式服从功能：厨房机器人或集成在厨柜，与洗碗、餐具柜、咖啡机、炉具沟通传递；娱乐或可人形；吸尘割草就应像吸尘割草机。
- 感知受限于感应器价格与诠释（尤其常识），仍实验大于实用。手臂贵且不太可靠。吸尘割草可以；洗完碗分拣有困难但可做；家中捡垃圾恐怕难；照顾老人病人很多人努力，作者怀疑——不可靠、不多才、不够聪明。很多所谓机器人是远程遥控。能与人沟通的自主型很难；社交沟通与共通领域远比技术复杂，狂热科技迷常忽略。
- 三方向：娱乐、家用电器、教育。从已有物品逐步加 AI、操控、功能。可爱机器人已开拓市场（吸尘割草）。自动咖啡机微波洗碗洗衣烘干或可归为机器人，因贵且自动；很多人不承认因不移动。
- 教育：已能迷人声音朗读；准智能动物玩具可爱；可教字母阅读词汇发音算术推理、音乐美术地理历史；不必限于儿童。不取代学校与人际，而是补充。妙处：不需移动或精密操作。科学家梦想史蒂芬逊《钻石年代》里的家教读本成为现实。
- 通用机器人：如何沟通、协调才不牵制、如何指挥。作者猜想它们出现时仍难真正沟通：接受指令（清扫、收拾碗盘、递饮料）就转身去做，**让人去适应它们的习惯，不要影响它们工作**。
- 特殊用途：本领不多、服务有限，沟通不成问题——双方了解设计能执行的任务、长处短处、工作环境，误会更少。
- 危险不易到达处已有效：火山内部、污水管、火星月亮表面；灾后评估与搜生还。非经常发生，费用非关键，但也在要求降成本。
- 另一类：彼此沟通的机器人。汽车开始互通讯、与公路通讯以变道、与路口灯同步；不久或让餐厅知位置以建议菜单。洗衣与烘干讨论设定；美国家庭两机分开，或有一天衣服自动从洗进烘（欧亚常一机两用则没这麻烦）。碗盘自动进洗碗再进柜。家电自协调噪音、避开电价巅峰。
- 到来顺序：先玩具娱乐小宠物 → 同伴读故事教语文数学、远程探视老人 → 家居与汽车进智能通讯网。特殊用途在数量能力种类上增加；**通用机器人几十年后最后一个出现。**

**推导**

本书关于自主辅助系统的全部问题，对机器人更尖锐。通用机撞共同领域；专用机因边界清楚而可沟通。

**结论**

把期望从「人形仆人」改到「集成厨柜的专用自动 + 教育娱乐伴侣」，才与当时技术现实相符。

### 实操方法与设计原则

- 家用机器人清单：可靠、安全、实用、买得起；形式服从功能。
- 先专用后通用；先不移动的教育/家电，后行走抓取。
- 设计时假定通用机不会「懂你」，而会要求环境迁就它的习惯——这是要避免的未来。

## 三、科技易改，人性难移——真的吗？

### 论证推理链

**论据 / 案例 / 事实**

- 老生常谈：自然进化慢，个人行为也慢，保守性减弱科技影响。科技日新月异，行为文化要数十年，生物进化历数千年。
- 若科技改变的不仅是制品而是人本身？仿生增强、基因改造。已植入人工晶体、助听器，很快盲人视觉增强；手术已能使视力超常。移植与生物增强对普通人已渐成现实。运动员已用药物手术改天生能力；增强脑力还要太久吗？
- 即使无基因手术，经验改变大脑：伦敦出租车司机海马体增大以记街道细节；专家在专长相关脑区发达。习惯（乐器、手机手指）影响大脑。
- 作者多年被问儿童接触新科技会否发育不同大脑，通常答生理结构决定、经验不影响进化。结构不会遗传式改变是对的——现代人刚出生大脑与几千年前几乎无别。但他说经验不影响则错了：尤其儿童长时间持久早期经验。运动强肌、心智活动增脑区，改变不遗传；科技越早进入幼儿生活，一定影响反应思考行为，大脑从小改变来配合新技能。
- 生物科技缓慢不可阻挡，或体内植入增强知觉记忆体能。有人坚持改变，有人反对，争斗不可避免。科幻将成为科学事实。社会须解决对个人与社会的影响。设计者在前线，因把概念转现实；比以往更需了解行动的社会影响。

**推导**

「人性难移」不能当设计可以忽略学习与儿童发展的借口，也不能当可以任意改造身体的许可证。设计者处在争斗前线。

**结论**

制品在变，大脑在用中变，身体增强将至；设计伦理与社会影响进入日常用品议程。

## 四、顺应我们的科技

### 论证推理链

**论据 / 案例 / 事实**

- 1933 芝加哥世博：科学发现，工业应用，人类适应。21 世纪以人为本箴言：人类规划，科学研究，科技配合。
- 《让我们更聪慧》：科技应配合我们，而不是人适应科技。1993 年后想法有变：仍希望机器配合，毕竟机器能力太有限、僵化，人灵活能适应、能离开。
- 危险：有人断章取义「人必须配合机器」= 为机械效率与生产方便自由设计。不应成为不良设计借口。一定不能顺从不良设计。
- 须做最好的、为人设想的设计，遵从以人为本、以活动为中心的原则，以及第六章法则。即使最佳设计，机器仍缺弹性、需人照料、感测有限、能力与人不同、共同领域鸿沟难跨。
- 谁想到要向机器解释意向？但有必要：告诉车真的要左转；告诉吸尘现在不要清客厅；通知厨房饿了请准备；告诉播放器要跑步请选节奏合适的乐。若彼此了解意向会好办得多；因机器智力有限，人只好负沟通重任。彼此适应对两者有好处，像无障碍设计对大家都有益。
- 人配合科技不是新现象：第一件工具起每件新工具都改行为。19 世纪为马车汽车修路；20 世纪电力代煤气而布线、卫浴入室铺管、电话电视互联网插座。21 世纪为享受机器便利须改造房子。
- 图7.2 比利时广告「拒绝交易：你已经有很多鞋子了」：店里终端想促销配套袜皮带衬衫，个人助理要拦花钱——聪明系统会建议，也可能与你争论。人口老龄化：改装居室（电梯、斜坡、把手代球柄、宽走道、开关插座高度、料理台高度）。有趣的是，为老人做的改变同样便利机器——机器也像年长成员，活动灵活性视力有类似限制。
- 或将面临互相对抗的智能：冰箱诱惑多吃、体重计反对；商店引诱、手机助理反对；电视和手机合伙。作者：不用担心，可以反抗。智囊或就在推销鞋的电视电话里，一个说拒绝，另一个说下星期晚宴需要新鞋。

**推导**

适应是双向的，但责任不对称：人必须解释意向，同时有权拒绝不良设计与互斗代理。为老人的环境改造与为机器人的环境改造碰巧同构。

**结论**

科技配合人是原则；人向机器说明意向是现实；无障碍式改造是两者的交汇。

### 实操方法与设计原则

- 「人适应」不得为差设计开脱。
- 给每台自动设备一个「解释意向」的通道（转向灯告诉车、暂停清扫客厅）。
- 无障碍改造可当机器通行的设计指南。
- 互斗代理：用户须能关掉其中一方或做最终裁断。

## 五、设计科学

### 论证推理链

**论据 / 案例 / 事实**

- 设计定义：有计划地改变环境以满足个人和社会需要。各行各业都触及。大学重抽象理论轻实用，学科分割培养窄专家不适合跨学科通才。新设多元课程很快又专业化。
- 设计师必须是跨学科创新通才，必要时请各行专家确保部分可行。新学科，不像传统院系，有点像商学院：通才了解各部门、能领导专业人士。也许设计系应隶属商学院。
- 现在设计以艺术或手工艺传授：师徒、工作室车间。好学手艺，不适用于科学。时机已到：已从社科艺术工程商业知道很多原则。工程师尝试正规方法优化机械数理，忽略社会与美学；艺术界强烈反对系统化，怕毁创造性。朝向智能系统则**绝对需要严密设计**——不是工程师那种只关注可衡量物的冰冷原则。需要新方法：商业与工程的精确严密 + 社交艺术美学。
- 智能机器对设计者：过去考虑人如何与科技互动，现在还要考虑机器的观点。智能机需要互动、共生、合作，对象是人或其他智能机。新领域，过去知识无法指导。已有名称：互动设计、监督控制、自动化设计、人机交互，研究其实还很少。认知心理可作开端；人因工程与人机工程学已提供有用研究和方法，须继续往前。
- 图7.3 艾奥瓦州立大学虚拟现实应用中心「洞窟」：前后左右上下超高解析影像；作者站在植物细胞内学生物，或站在海滩。数百万美元、一亿像素、特殊显卡、巨大电力与空调。实验室研究一二十年后会进寻常家庭。共享体验，几组人一起探索，图体现不出神奇。词汇借自戴维·克森「智能产品的经验」。
- 未来生活新需求：过去只不过使用产品；未来与产品共事，像合作者、老板，有时像服务员和助理。越来越多指导监督机器，同时自己也被机器管理和监督。
- 智慧自主不是唯一方向：虚拟世界、阿凡达漫谈、难辨虚实；全球化社交与以假乱真的新经验改变娱乐。
- 已来到困惑又精彩、危险又有趣的时代：本能上令人兴奋，行为上令人满意，意识上令人快乐。或许还没达到；成功有赖未来产品的设计。

**推导**

智能日常用品把设计从「人如何用物」扩成「人机如何共事、机机如何共事」。学科要严密但不能只量化；虚拟洞窟说明实验室经验会家用化，且是共享而非孤岛。

**结论**

设计科学 = 跨学科严密 + 美学社交 + 机器观点。本卷的六条法则是这门科学的一块砖，不是全部。

### 实操方法与设计原则

- 用赫斯克特讨论后的定义约束「什么算设计工作」。
- 检查智能项目：是否同时考虑人的观点与机器的观点。
- 章末三层次对应卷三：未来产品应在本能、行为、意识都站得住。

## 段落总结序列

主旨：日常用品将更聪明、更社交、更能造物；家用机器人应走专用与教育娱乐；人须解释意向且不许差设计借「人适应」开脱；设计要成为兼顾人与机器观点的科学。

最小标签集：陈述 / 必要依据 / 限定 / 可替换例证 / 次要观点 / 过渡/场景

1. 【过渡/场景】梅斯的活物件与魔镜试衣：潜能取决于无瑕疵运作与人能驾驭。
2. 【第一档·陈述】智能从汽车渗入厨卫厅；市场为销售额推附加服务（手机、冰箱屏、可读包装）。机器互相比较片单食品频道。
3. 【第二档·可替换例证】新材料「就快了」；3D 分层打印使图纸成物，房子或擅自打印盘子。
4. 【第一档·必要依据】家用机器人须可靠安全实用买得起；形式服从功能。感知常识与手臂限制用途。很多「机器人」是遥控。社交共通领域比技术难。
   （本段是第5段的必要依据）
5. 【第一档·限定】三方向娱乐/家电/教育；专用机沟通易，通用机让人适应它的习惯。到来顺序：玩具→同伴与远程照护→家居汽车网络；通用机几十年后最后出现。
6. 【第一档·陈述】科技也改人：经验改大脑（出租司机海马体），儿童早期经验改反应方式；植入与基因增强将引发社会争斗。设计者在前线。
7. 【第一档·陈述】世博「人适应」vs 以人为本「科技配合」。人灵活故担沟通（解释意向），但人配合不得成不良设计借口。无障碍改造碰巧也便利机器。互斗代理可被用户反抗。
8. 【第一档·陈述】设计=有计划改变环境以满足个人与社会需要。应成科学：跨学科通才、严密+美学，并考虑机器观点。名称已有，研究还少。
9. 【次要观点】洞窟 VR 一二十年后进家庭；虚拟世界是自动之外的另一未来。
10. 【第一档·陈述】未来是共事不是单纯使用；本能兴奋、行为满意、意识快乐有赖设计。
