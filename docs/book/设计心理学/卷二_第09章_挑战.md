# 卷二 第09章 挑战

## 本章位置

卷二收束。复杂可带来深刻满意，但结构差就变挫折。挑战在设计师（组织体验、概念模型、即时指令）与使用者（愿意学）双方。销售链、评论家、社交网络、安全绕开、不当自动化是尚未被原则自动消灭的阻力。

> 💡 自动化代价见：[卷一_第05章_人为差错不拙劣的设计.md](卷一_第05章_人为差错不拙劣的设计.md)、[卷四_第05章_自动化扮演的角色.md](卷四_第05章_自动化扮演的角色.md)

## 核心论点

1. 不是所有东西都该复杂；许多被过度设计。需求蠕变仍在肆虐。
2. 简单产品常死在销售员与评论家手里：为 50 岁以上设计的三功能大按键手机，用户测喜爱，销售员嫌不酷无摄像头，目标用户根本没见到。链路：设计师→制造商→运营商→店铺→用户。家电常由承包商决定。提成推高价。
3. 柯达易享：观察销售过程后做店内自助演示，功能少价高仍成销售最快系列——设计的是终端到终端体验。
4. 评论家是技术爱好者，用专业指标评家用产品。施瓦茨《无从选择》：选项越多满意越少。商铺减品牌会被写成「限制选择」——而这正是重点。
5. 21 世纪设计对象常是群体而非单人设备：重叠社群、工作被娱乐打断、隐私与恶意者。群体既可优于个体也可冲突。
6. 功能蠕变叙事：音乐播放器→视频→照片→摄像头→网络→消息位置→电话电子书；细节虚构，iPod 路径真实。汽车与家电仪表已达分心危险；视线离路超两秒事故率急升。
7. 安全越细越可能更不安全：人会写密码、开门、复制以免碍事（第三章跨安全之篱）。简便与安全妥协。自动化移走对人的要求，增加底层复杂与新事故形式（守恒）。须向其他领域学习。
8. 与科技共生是合作：用户用标记、列表、日历、社交、手册学习概念模型；设计师给组织、沟通、可学的交际性技术。

## 关键概念补全

无新核心术语。需求蠕变 ≈ 卷一功能蔓延在组织与销售层的表现。

## 一、销售链与评论家

### 论证推理链

**论据 / 案例 / 事实**

- MBA 学生达夫访设计师：定位 50+，观察原型测试，三功能大键，消费者爱，失败因销售员不推。
- 烤箱冰箱洗衣机：制造商→分销→零售或开发商安装，住户无发言。合同提成、特定商品更高提成。店员以演示特色为荣。
- 柯达：消费者与店员都被数码复杂困住；易享一键+导出打印+店内演示，少功能最高价仍卖得最快。
- 相机评论要全手动胶片速度白平衡；汽车评论弯道加速转向过度——多数驾驶者从不在意。测试杂志仍列功能评级。五金店减品牌，记者写「极简却限制选择」。

**推导**

HCD 测过用户仍可死在中间人的概念模型里。要设计销售演示本身。

**结论**

购买者真实需求在链路中极易被忘。排除「热心店员的帮助」有时是一种设计。

## 二、社交、蠕变、安全与自动化

### 论证推理链

**论据 / 案例 / 事实**

- 脑慢变，技术快变，文化最慢。20 世纪一人一设备；21 世纪持续群交流，地理时间可分隔。好处：保持朋友、临时工作组；坏处：网状重叠、干扰、跟踪盗窃。为群体设计有协同新要求，次级圈子可支持也可疏远竞争。
- 播放器功能叠罗汉。汽车交互使驾驶员分心。家电菜单+微处理器。恐怖分子骗子好事者迫使认证加层，人绕开后整个篱笆垮。
- 自动化简化对人要求时增加技术复杂与故障可能；航空工厂有记录，医药家居汽车在重复。设计师须给可感知语义符号（正在哪步、状态、将来怎样）和「即时」指令。

**推导**

复杂增长有真实需求也有销售与安全的叠加。每层安全若妨碍工作就会被诚实的人拆掉。

**结论**

可接受的复杂必须明晰且必要。自动化要警惕不当水平。

## 三、合作关系

即使最好设计也要用户配合：标志、笔记、列表、电子提醒、帮助、花时间掌握结构。设计师给构造与交际性互动；用户愿学规则。与科技共生是持续但必要的挑战。

## 题外话

除了本章主要内容外，作者还讨论了/提及了：1. 销售员真心发问「有人会买这么少功能的手机吗」，2. 记者把减 SKU 写成满足极简主义者，3. 虚构播放器故事的结局在真实 iPod 上发生。

## 段落总结序列

主旨：管理复杂的剩余障碍在销售评论、社交规模、安全绕开和不当自动化；最终仍是设计师与用户的合作。
