# 卷三 后记 我们都是设计师

## 本章位置

三层次与机器人伦理之后。后记用读者来信证明喜爱跨越本能、行为、反思；再谈个性化不是目录勾选，而是磨损、故事与居住者改造。收句：我们都是设计师。

>
> 💡 「物品的意义」见：[卷三_第02章_情感的多面性与设计.md](卷三_第02章_情感的多面性与设计.md)

## 核心论点

1. 网上征集爱憎产品约 150 封回信。存在「鱼最后看见水」：太融入生活的真爱或已移出视线的憎恶会被漏报。技术从业者仍把最高名次给非技术物。
2. 喜爱覆盖三层次一切组合：iPod 拆封小心（本能）；OXO、刨子、安全开罐器、杠杆开瓶器（行为）；吉他信任、四季酒店书签、感热釉杯、节日 Google 标志、即时通讯（反思/社交）。电脑家电普遍不讨喜。缺点可成为反思吸引力（「真专家才能用的意式机」；甲壳虫蠢把手仍爱车）。
3. 大批量定制（选色、辅料、数码量体、接单组装）降低库存，很少产生情感依恋。讨厌的遗产物反而可在家庭叙事里变成正面联系。
4. 真正个人化：渐进而非策划的摆放；磕碰烧焦裂痕背后的故事；能优雅老化的材料（牛仔裤钱包印、书页笔记）。布拉德利故意摔 PDA 并没增加魅力——磨损须「令人舒服」。
5. 五条路：凑合用便宜量产；定制（软件喜好项常更复杂，真想改的却改不了；钢笔家具是用法定制）；接单生产；自己做（缝衣、花园、甚至飞机游艇）；买回后改（哈雷、车用音响、改房）。
6. 哈里森与杜里西：空间由居住者变成场所；设计师最好把工具交到他们手里。选、放、整理都是设计。

## 关键概念补全

**过于明显反而没注意到**：民间故事里鱼看不见水。调查方法的盲区，不是否定回信。

## 一、爱憎清单与三层次

### 论证推理链

**论据 / 案例 / 事实**

- 日本具良治菜刀（枕下玩笑）；乔治·杰森无数字银表看了六年；甲壳虫油耗停放乐趣 vs 座位升降把手谁也找不准。
- 帕萨特蓝橙仪表灯光；爱宝琳娜矿泉水「放架上好看」，喝起来碰巧也好。尼尔森刨子、库恩力康撕密封边开罐器、Screwpull 一天开三瓶。泰勒吉他高音不嗡、不走调。奥斯汀四季床上电视导览翻到当日并放书签，促使向所有朋友讲述。感热釉：热了变透明知咖啡何时不能喝。Google 小恶魔从 O 后探头、冬日积雪。IM：「无法想象没有它」；电邮爱恨数量。家电电脑：「几乎每件都糟」，而抱怨者多是业内。意式机：掌握窍门后的回报，易用专家也爱其难用。
- 作者承认漏了塞克斯哈里式「椅子照片盆栽书」以及烹饪运动同学聚会等活动类别。两研究都指出日常生活有强烈爱憎联结。

**推导**

热情落在服务与故事上（四季书签）比落在参数表上更多。可用性失败有时被反思层收编为身份。

**结论**

设计的情感后果以大相径庭的方式反映三层次；特殊服务会被口耳相传。

## 二、个性化、客户定制、我们都是设计师

### 论证推理链

**论据 / 案例 / 事实**

- 手机换壳、网站「设计自己的鞋」实为尺寸款式颜色材质。量体裁衣曾慢而贵；相机测量+激光裁切+接单组装减库存。选项固定，不保证情感。不喜欢的遗物在聚会上被深情回忆，共同负面可结成正面。
- 椅移近灯、书堆椅边、再搬桌——对活动独特，无法转移给下一住户。布兰特：建筑会被后住者改到带上个人价值观。锅的缺口是「属于我们的」。IDEO 布拉德利找优雅老化材料；牛仔裤补丁成功，摔 PDA 失败。
- 软件定制项多到找不到，独特输入拼写格式却不能改。哈雷改装费可超过车本身。哈里森/杜里西：设计师给工具。咖啡杯铅笔书纸放哪就是设计；房子变家、空间变住所。

**推导**

目录勾选 ≠ 拥有感。时间、痕迹、叙事才个人化。过度「喜好项」把系统变得更复杂。

**结论**

我们无法控制所买之物的原设计，但能控制挑哪件、何时何地如何用——这就是设计。

主旨：爱憎证明三层次；个人意义来自故事与老化而非菜单定制；人人都在设计自己的场所。
