唐纳德·A·诺曼 (Donald A. Norman)：认知科学家出身，后任苹果等公司高管与顾问。卷一初版 1988 年名为 *The Psychology of Everyday Things*（POET），商业平装改为 *The Design of Everyday Things*（DOET）；2013 年增订。作者自述原则仍基于不变的人类心理，案例与产业约束则按 21 世纪重写。

## 作者要回答的总问题

日用品、复杂服务、情感体验和未来智能机器，为什么常常让人困惑、自责或被机器反客为主？过错在人，还是在设计？

总答案分四层，四册各管一层：

1. **卷一**：困惑来自缺少可视性、意符、映射、反馈和概念模型；「人为差错」多半是拙劣设计。
2. **卷二**：生活需要复杂；该驯服的是**令人困惑的复杂**，不是复杂本身。简单存在于头脑中的概念模型。设计师与使用者是伙伴。
3. **卷三**：成功不只靠好用。本能、行为、反思三层情感往往比单纯可用性更能决定是否喜爱、是否坚持用。
4. **卷四**：机器开始主控时，人机必须用自然信号沟通；自动化能做枯燥的，做不了最需要人的复杂；人不应沦为机器的仆人。

贯穿四册的方法关键词是 **概念模型 (conceptual model)**：人靠简化的「它如何工作」故事来行动；系统映像必须把这个故事说清楚。

## 一条主线：人机沟通的责任在设计

```text
日用品为何难用（可视性 / 意符 / 映射 / 反馈）
    → 人如何行动（执行鸿沟 / 评估鸿沟 / 七阶段 / 三层次）
        → 知识放头脑还是放世界（记忆、约束、自然映射）
            → 出错先查设计（失误 vs 错误 / 瑞士奶酪 / 防呆）
                → 真实产品如何做出来（双钻、HCD、预算竞争）
                    → 复杂是必需的，困惑不是（语义符号、服务、等待）
                        → 情感三层次（本能 / 行为 / 反思）
                            → 未来机器如何说话（自然信号、增强而非取代）
```

与这条主线平行的几组对照：

| 对照 | 大致归属 |
|------|----------|
| 示能（可能做什么）/ 意符（提示在哪做） | 卷一第 1、4 章；卷二把社会性语义符号展开 |
| 失误（做滑了）/ 错误（想错了） | 卷一第 5 章 |
| 复杂 / 困惑 | 卷二全文 |
| 本能 / 行为 / 反思 | 卷一第 2 章点到，卷三展开 |
| 自主自动化 / 增强智能 | 卷四第 5 章；卷一第 5 章已预警悖论 |
| 渐进式创新 / 颠覆式创新 | 卷一第 7 章：HCD 适合前者 |

作者明确：**心理学基本理论不变**；变的是工具、文化与应用方式。卷一增订自序说，1988 年的原则仍适用于 2038 年，但必须换例子、补上用户体验、情感与商业约束。

## 阅读时可用的检查清单

看一件日用品或一项服务，可按卷一第 2 章的七问走一遍：

1. **可视性**：能看出有哪些合理操作、系统现在什么状态吗？
2. **反馈**：行动后果是否及时、有信息、有优先权？
3. **概念模型**：外观和说明是否让人形成「它如何工作」的故事？
4. **示能**：想做的动作物理上能否做？
5. **意符**：提示是否标出该摸/推/滑的位置？（看见手写用法贴条，先当失败信号。）
6. **映射**：控件布局是否对应结果的空间关系？
7. **约束**：物理、文化、语义、逻辑是否把错误路径挡住？

再补三问：这是**复杂**还是**困惑**（卷二）？三层情感谁在主导（卷三）？自动化是在**增强**人还是把人赶出环路（卷四）？

## 本书明确不作的事

- 不是某一软件或品牌的操作手册；作者有意少用易过时的公司名。
- 不是把「简单」当成道德命令（卷二反对这一点）。
- 不是主张用户从不犯错（卷一第 5 章承认酒驾、缺觉、无执照）；而是反对把高比例事故停在谴责个人。
