# 卷四 第05章 自动化扮演的角色

## 本章位置

上章把半自动写成危险中间态，人成为工具的仆人。本章问「为什么还要自动」以及**两种智慧型物品路线**：自主（房子替你决定）vs **增强（augmentation）**（工具给你，你决定何时用）。莫扎之家的神经网络、微软剑桥备忘磁铁与厨房显示器、乔治亚「厨师拼贴」、丹佛机场行李系统 vs 航站电车、儒博夫的「资讯化」，把增强与自主的适用边界写清。下一章专讲沟通：反馈、概念模式、自然映射与六条设计法则。

## 核心论点

1. **自动的经典理由**是枯燥、危险、肮脏；此外还有简化复杂、减劳动力、娱乐、乃至为自动而自动。成功也有代价：新问题、更多维修、非技术看守取代技术操作者、工作重组与失业。
2. **连煮咖啡这种简化都会把不便从「刚醒赶时间」挪到「你得维护机器」**——注意点转移，不是消失。
3. **「智能住宅」多半是适应性系统，不是真智能**；不能推断心境/意向时，娱乐这类任务应保持人工。
4. **错失与假警报代价不同**；多次假警报摧毁信赖，真火会被当成又一次假警报。
5. **增强路线**：人而不是科技让房子更聪明；工具自愿、友善、可不用；微软剑桥与乔治亚明智之家选择增强而非从头到尾自动烤蛋糕。
6. **自主适合**任务清楚、环境受控、或对人过危/过闷的工作；环境一复杂（丹佛行李）就失败。未来设计应多增强，少强制自主。

## 关键概念补全

**适应性（adaptive）系统**：莫扎对自己房子的称呼——神经网络做形态辨识与预测，不是「聪明」。

**错失（misses） vs 假警报（false alarms）**：该做未做 vs 不该做时做了。火警：错失=火了不报；假警报=没火却报（若触发喷淋和消防队则损失惨重）。

**增强 vs 自动化（augmentation vs automation）**：给工具让人做主 vs 系统自己完成任务。

**资讯化（informate）**：儒博夫——自动不仅取代操作，还让工人获得全盘信息，从而能与中高层交流。

## 一、为什么需要自动化？

### 论证推理链

**论据 / 案例 / 事实**

- 科技专家三理由：枯燥、危险、肮脏。还有简化复杂、减劳动力、娱乐、为自动而自动。
- 自动咖啡机：一键加水温、磨豆、煮、丢渣。早晨煮咖啡曾有点乏味，现在更麻烦：加水加豆、定期打开清洗、除咖啡粉与钙化物、再冲洗去掉垢剂。好处是把「刚醒未清醒赶时间」的事推迟到方便时做。
- 自动倾向看似不可阻挡，但并非无法避免，也没理由一定带来大量缺点。应开发真能减少 3D 工作又不带来大量负面作用的技术。

**推导**

自动化是系统问题：改变工作方式、重组内容、负荷从一群人转到另一群、取消某些功能又在别处增加新功能。对有些人有帮助，对有些人是灾难（换工作、失业）。

**结论**

先问自动把不便挪到了谁身上、挪到了什么时刻，再宣称「简化」。

**启示**

家电自动化清单里必须写维护成本与技能转移，不能只写一键。

## 二、智慧型住宅：莫扎之家

### 论证推理链

**论据 / 案例 / 事实**

- 科罗拉多博德，麦克·莫扎深夜看书、打哈欠、回卧室。房子判断他要睡：关起居灯，开过道、主卧、浴室灯，调低室温。电脑持续监控并预测。不是寻常程序，是模仿脑神经形态辨识与学习的**神经网络**：看行动次序与当日时间，预测下一步。出门关暖气热水器省能源，预期回家再打开。
- 约 75 个感应器：各室温、光、音量、门窗位置、屋外气候日照、居住者活动。电磁开关控室温、热水器、灯、通风。8 km 以上线路。不合适则莫扎修正，系统改模式。
- 记者见：进浴室灯开在最低亮——省能源；不满则敲墙上开关「惩罚」，下次较高亮。房子适应主人，主人培训房子。
- 办公室忙到深夜仍须回家，因房子在等他、已开空调热水器。为何不打电话说晚归？修硬件时系统觉浴室停留太久；修复后仍保留广播音讯，因提供「他们在哪里花了多少时间」——浴室太久房子会警告？唠叨。
- 莫扎自评（引 2005）：把案例延伸到音响电视收音机是定错方向。节目选择与心境有关，外界环境很少给有用线索，影像辨识也难测心境 → 经常误判，更多地惹恼。室温不适是逐渐觉察；视听若与心里所要不同会加倍不悦。要什么只需按一个钮，几乎不发生错误。面对难题时音响咆哮，成本收益上视听应依赖人工。
- 不能知心境/推断意向，问题超过缺共识。与人同住都难确切知意向。小说电影里的英国管家能预期，主要因主人生活有规律、社交规范、预先日程。

**推导**

错失与假警报：家居误判（突然开音响、旅行时早开暖气）多是恼怒不大危险；汽车上跟车距离错失可致命，误判离车道就改方向或误判障碍就刹，可能惊吓邻车。无论是否危险，假警报都降信赖；几次之后人忽视警告，真火当成又一次假警报。信赖需要时间、经验与持续可靠互动。

莫扎是神经网络专家，家是实验室，对问题较宽容。作者觉参观会有趣，**不打算住在那里**。

**结论**

适应性房子展示了学习与预测的上限：规律行为可，心境与意向不可。汽车类高代价错误与家居类低代价错误不可用同一套「智能」话术。

### 实操方法与设计原则

- 先问错误类型：错失 vs 假警报，各自代价。
- 心境驱动的任务（娱乐）不要自动。
- 给系统「惩罚/纠正」通道（如敲开关），并承认那是培训不是魔法。

## 三、让人聪明的家：增强而非自动化

### 论证推理链

**论据 / 案例 / 事实**

- 对照完全自动住宅：微软剑桥研究院一组科学家设计**增强居住者智慧**的住宅。协调一家四口（两上班大人、两青少年）不容易。传统科技路线=智能日程表统筹、决定用餐与接送，用电邮/即时通讯/短信/电话提醒约会、晚餐、载人、顺路购物 → 再推荐文章电视。很多研究者同意；全球实验室朝这方向：有效、现代、最没有人情味。
- 剑桥前提：**是人而不是科技让房子更聪明。** 不把任何解决方案都自动化，让每个家庭有独特满足需求的方法。做「人类研究」/应用型人类研究/快速人类学：观察真正日常，不侵犯、不改变发生的事。有经验的家庭能适应带录音摄像的研究者，包括偶尔吵嘴。目标：主要挫折是什么？什么简单办法得最大正面效果。
- 家庭交流：短信便条放在会被看到处——桌椅键盘显示器、楼梯床门；厨房是中心，最常见是冰箱。铁壳+磁铁固定便条、通知、小孩画、照片，催生磁铁夹子白板相框笔小行业。高档不锈钢或木饰板破坏磁铁用途，作者先不悦：失去家庭联络中心。商人推出可钉墙的消息看板，有些表面铁质给磁铁新家。
- 图5.1：冰箱门字条太多难辨哪些相关；智能磁铁——与星期三有关的字条放「星期三」磁铁下，当天微光提醒但不讨厌。「星期三早晨倒垃圾」可放「星期二」下，提醒前一晚把桶拿到路旁。有些磁铁被移动后一段时间微光，标示新字条。
- 图5.2：电子记事本可放冰箱旁或任何告示处；简讯可从任何地方电邮或手机来；电子笔手写、电邮或短信（「开会中……不必等我吃晚餐」）。孩子威尔短信请人接，因不知谁方便，发到中央看板而非特定人；提姆手写「威尔在足球场，我会载他回家」，其他人不必担心。系统提供工具，让人自己决定何时何况如何用。
- 乔治亚理工学院「明智之家」的「厨师拼贴」：烤蛋糕时电话打断，不记得加了几杯面粉。碗碟架下摄像拍每步，显示已完成部分，帮回忆做到哪。自愿、友善、合作；用或不用取决于你。
- 两团队都可以做更「智能」：感测谁在家改显示、读日记日程通知赴约；AI 读食谱逐步指导甚至自动烤完。他们没选这条，希望系统自然融入生活方式。都依赖强高科技，原则是**增强，而非自动化**。

**推导**

冰箱当看板的「意外」：高档材质毁掉磁贴示能，说明设计要看见已有社会实践。增强设备延续便条文化，只补「哪条是新的/今天的」与「远程写入」。

**结论**

让人聪明的家 = 更好的共享信息表面，不是替全家排程的管家。

**启示**

做智能家居前先做快速人类学：便条贴哪、谁看、什么时候看。先增强现有实践，再考虑自动。

### 实操方法与设计原则

- 非强制：不同用户不同选择，组合适合自己生活方式的科技。
- 提醒用微光等低扰方式，不要哔哔。
- 中央看板解决「不知发给谁」的协调，而不是系统指定谁去接。

## 四、智慧之物：自主或是增强？

### 论证推理链

**论据 / 案例 / 事实**

- 两方向：智能自主（了解使用者意向）vs 智能增强（有用工具，人决定何时何地用）。各有优点问题。
- 增强：舒服，决定权在人；可用可不用；非强制故不同人不同选。
- 枯燥危险不干净 → 自动有帮助。灾后废墟搜生还等对人过危的，不得不自主。有时人能做，机器代做也很好。
- 《纽约时报》：「自动化通常听起来很迷人……有时候你还是需要真正的人手。」丹佛机场行李自动搬运：几乎挤坏传送带上所有行李并送错位置；数十年、上千万美元后拆除。行李形状各异、随意落带、去向多、标签二维码折弯打褶破碎、埋在把手捆带或其他行李下——对当时自动太复杂、未知数太多。**同机场**航站间自动电车却顺畅高效：差别在工作环境与性质，不在机器智能程度。电车路线事前固定，在轨道上只需何时开、多快；感应是否有人在门口。状况稳定、工作清楚、机械问题少、突发少 → 自动可行，造福。
- 儒博夫分析生产线：工人离开直接经验（触、嗅、听）→ 空调室靠仪表显示器了解；加速与一致性的同时，多年经验得来的预测改正能力无法让公司受益。另一方面电脑让工人更强：过去只有有限知识，现在了解完整制造过程与对公司贡献，能与中高阶交流。**资讯化**：工人被资讯化了。

**推导**

人有许多独特能力不能被机器复制（至少当时）。引入自动与智能须虚心正视问题与失败，知道人机工作差异大。反应灵敏系统有价值，但受共同领域限制可能无法良好运作。

对人过危的环境，偶尔故障也值得用自主设备。无聊单调例行（基建维修、调参数、确认状况）也可交机器。增强已证实价值：网购导购只是建议，不侵扰，偶尔成功即够满意。智慧住宅的增强试验针对当前日常问题，非强制让人产生好感。

显而易见的未来叙事（开车、备餐、监控健康、清理、告诉你吃什么何时运动）仍会来。只要工作项目清楚、环境合理受控、人机互动尽可能少，自主系统自有价值。挑战是：增加智能设备弥补人力、增乐趣便利成就感，**但不增加生活压力**。

**结论**

自主 vs 增强不是道德口号，是匹配问题：受控轨道 vs 变形行李标签；建议磁铁 vs 替你选电视。设计的未来更应站在有增强作用的智慧型物品一边。

### 实操方法与设计原则

- 任务/环境清单：可变性高、标签脏、意向含心境 → 不要自主。
- 自动若抽走感知经验，须用资讯化把全盘信息还给人，否则能力被废。
- 明确挑战句：帮忙而不增压。

## 段落总结序列

主旨：自动会转移而非消灭麻烦；住宅「智能」分自主与增强两路；增强把决定权留在人；自主只在受控或过危过闷时划算。
