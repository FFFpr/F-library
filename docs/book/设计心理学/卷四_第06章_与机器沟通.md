# 卷四 第06章 与机器沟通

## 本章位置

上章把增强定为更可取的智慧路线。本章回答「增强之后如何共事」：机械时代靠看得见的部件与自然声音形成心智/概念模式；电子时代内部静默，全靠设计师给出的反馈。没有反馈就没有合作（M 教授演示、智利无声玻璃电梯）。牛顿手写识别说明：**错误必须可理解**，否则用户骂机器；可理解的错会变成学习。章末给出人机自然沟通**六条设计法则**，并指向第七章的未来用品与设计科学。

## 核心论点

1. **沟通、解释、理解**是与聪明共事者（人、动物、机器）合作的关键；机器被假设完美运转，因而常被忽略持续沟通。
2. **反馈必须持续提供运作状况且不干扰**；否则无法形成合适概念模式，失败时不知哪一步出问题。
3. **自然产生的声音**比外加灯/哔哔信息更丰富；完全无声与无意义编码同样失败。
4. **有时怪自己比怪设计更好**——若错误可理解、可改正，用户会学习而不是放弃产品（牛顿 vs 萝西塔 vs Palm 涂鸦）。
5. 提供反馈的好方法即第三章的自然互动：内隐沟通、自然声与事件、安静有意义的信号、与外界理解之间的**自然映射**。
6. 六条法则：丰富自然信号；可预测；好概念模式；输出易懂；持续感知但不反感；自然映射。最大障碍仍是缺共同领域。

## 关键概念补全

**心智模式 / 概念模式（mental model / conceptual model）**：根据可见部件、声音与反馈，在心里形成「这东西如何运作、下一步会怎样」。无法按计划使用时，靠它找原因、试下一步。

**安静技术（calm technology）**：魏瑟与布朗——同时影响中心与边缘注意力，并可在两者间切换。「告知但不造成过分负担」。

**中心 vs 边缘注意力**：中心=有意识焦点；边缘=能觉察但不特别注意（如开车时引擎噪音，异常才拉到中心）。

**自然映射（natural mappings）**：控制与被控在空间（或其他维度）上的对应，使人几乎不必标签。卷一灶具：田字四灶 vs 一字四开关导致按错。

**抖杆（Stick Shaker）**、**路感（Road Feel）**、减速标线（rumble strips）：把已失去的自然警告用人工方式加回来，但仍走自然映射（振动位置/频率对应空间或速度）。

## 一、没有反馈的演示与电梯

### 论证推理链

**论据 / 案例 / 事实**

- 机械物品：活动部件看得见，自然声音帮助了解状况，不看也能推断。今日强指标藏进安静电子零件；除硬盘咔咔与风扇，内部不展现。全靠设计师让我们得知一点内部工作。
- 生物沟通是进化来的：肢体、姿态、脸；人有语言，宠物用尾耳姿态，骑手感马紧张或放松。
- IBM 艾曼登，MIT 的 M 教授演示：网页上变出新按钮，「一般使用者都可加控制指令」（未解释为何要这样做），按下后众人干等。听众给建议，科学家查电脑趴地查线，轻笑传开。程序其实正常，是公司内部网安不允许连外网。缺：按键已激活、内部指令在走、已开始搜网、正在等结果。违反基本规则：**持续提供系统运作状况，但不要对用户造成干扰。**
- 乔纳森·古迪电邮：智利威纳得玛喜来登，玻璃电梯门轻柔无到达/离开提示，周围有噪音则听不到运行；不站在正到达的门旁看不到在动或哪扇开了；唯一迹象是升降指示灯熄灭，在厅中央基本看不见。第一天开会错过三趟电梯。

**推导**

与面无表情、沉默的人交往令人挫折：有没有在听、理解、同意？没有反馈，电梯、他人、智能机器都无法合作。人机反馈可能比人人更重要：要知道机器在做什么、感测到什么、状态、将采取什么行动；运转顺畅时仍需确定真实状态。

若电梯这般简单都做不到适当回馈，未来全自动自主设施怎么办？

**结论**

无反馈 = 无概念模式 = 失败时无法定位问题。这是沟通章的第一课。

### 实操方法与设计原则

- 任何长于瞬间的操作：确认已接收、显示进展、区分「在工作」与「死了」。
- 电梯类：到达要多通道（声、灯位置、运动可见性），不能只靠厅中央看不见的灯灭。

## 二、反馈：家电声音、灯光编码、为何需要

### 论证推理链

**论据 / 案例 / 事实**

- 冰箱低沉声，洗碗洗衣烘衣声，空调送风，电脑风扇与硬盘咔咔：自然附加产物，不是设计师外加。不同运作状况声音常不同，故能告诉是否在转、在做什么、是否正常。
- 降低杂音有理由（背景噪音心烦），完全消除则不知是否在运作。安静好，完全无声未必好。
- 若声扰人，为何不用灯？外加灯/哔哔是人为编码，通常只提示两种状态（转/停、正常/有问题、通电/无电），须查手册。红灯或表示通电仍关机、或已开机正常、或出问题；有的频闪变色。不同设备用同样信号指完全不同状态。反馈不能准确传达就无意义。
- 出问题或改常规时，靠反馈指示如何操作，再确认要求已照办，并提示接下来：会恢复正常还是长期留在特殊模式？
- 反馈理由清单：重复确认；进度报告和时间估算；学习；特殊状况；证实；引导期望。
- 现有自动多最低限度反馈，且经哔哔嘟嘟铃闪——干扰多于沟通，最多部分信息。工厂、电厂、手术室、驾驶舱出事时许多警报齐鸣，须先花宝贵时间关掉刺耳声才能处理。
- 智能自主设备越多，越需要双向互支持：探明状况、引导反应；即使不行动也要确认。必须持续、大多无侵犯性，稍加留意即可，仅真正必要时要人关注。运转良好时只需关照、了解当前、预知可能。单靠哔哔甚至语音警告不够；要有效、全方位，不致影响其他活动。

**推导**

自然副产品编码丰富；人工灯声编码贫乏且不统一。警报设计常与「先处理问题」抢时间。

**结论**

反馈规范要从「响一下表示完了」升级为持续、可学、可定位的状态语言。

### 实操方法与设计原则

原文列出的反馈功能须写全：

- 重复确认
- 进度报告和时间估算
- 学习
- 特殊状况
- 证实
- 引导期望

互动原则：持续、无侵犯、必要时才拉中心注意。

## 三、谁应该被抱怨？牛顿、萝西塔、Palm 涂鸦

### 论证推理链

**论据 / 案例 / 事实**

- 卷一立场：难以驾驭科技时一定是技术或设计问题，「不要责怪自己，抱怨科技。」通常对，并非完全正确。若全是设计问题，人除埋怨无所事事；若是可改正的人为方式问题，人可以学习驾驭。
- 1993 年作者入苹果：先参与是否接受 AT&T 并购或合资，再监督牛顿上市。两件都不成功，牛顿更可深思。牛顿是早期 PDA，手写转印刷文字。当时手写识别极难，至今仍未完全成功。帕拉格拉夫国际：笔画数学转换到多维空间坐标，与词库对照取最近。用户看不到这复杂数学关系，失败时手写与认出字母好像无实际关系。正常时出色，失败时很惨。杜鲁道《杜恩斯伯利》讥讽。
- 教训：系统反应须能被理解和阐释；不符期望时，应让用户明确知道如何得到该有的反应。
- 耶格的萝西塔：克服「让用户理解错误」。写 hand 得到 nand：h 与 n 接近，用户可接受并改第一笔长度。写 Catching on 得到 Egg Freckles：骂愚蠢机器。概念模式改变怪罪对象：以人为中心的传统是产品没达期望就怨产品；萝西塔让人舒心怪自己、下次更小心，不失望。真正扼杀牛顿的是：用户抱怨它不能认出他们的手写；后来更好系统已无法挽回负面印象。若首次就「不够准但可领会」可能成功。无有意义回馈注定市场失败。
- 1996 Palm（初名 Palm Pilot）「涂鸦」：学一套接近打印字母、重组以便机器认的字母；以字母为单位，错只错一个字母；错误原因易懂，帮助避免再犯，起再次确认、形成心智模式、增强信心的作用。牛顿失败，Palm 成功。

**推导**

怪罪对象由概念模式决定，不是由「客观上谁错」单独决定。可理解的错 = 学习与信任；不可理解的错 = 产品死亡。

**结论**

反馈的最高任务之一是让输出可被纳入用户的因果故事。

**启示**

识别/推荐/自动纠错类产品：宁可暴露「差一个笔画」的错误，不要给「数学上最近、感知上莫名」的替代。

### 实操方法与设计原则

- 保证反应可理解可阐释。
- 错误单元尽量小（字母级优于词级），且与用户感知距离一致。
- 首次上市的识别体验会锁定品牌印象，后来技术救不回。

## 四、自然的、意味深长的信号与自然映射

### 论证推理链

**论据 / 案例 / 事实**

- 基本答案在第三章：自然互动、内隐沟通、自然声与事件、安静有意义信号、显示器与对外理解之间的自然映射。
- 帮司机倒车：人站可见处，两手分开示意与障碍距离，车动双手靠近——自然，不必事先默契说明。
- 泊车辅助连串哔：越近间隔越短，连续声=该停。与手势一样无须训练。
- 硬盘咔咔、开水沸腾：足够反馈、不增认知负担。魏瑟与布朗安静技术：边缘可巡视更多事；异常拉到中心仍能掌控。开车注意路/收音机/乘客时仍巡视引擎噪音。
- 卷一灶具：田字四头 vs 一字四开关，标签仍按错；不同品牌映射不同。开关排成与灶头一样的矩形则可不需标签。自然映射不限于空间：声音、振动同重要。
- 早期飞机失速：升力缺乏使杆振动；大型自动驾驶机失去这自然警告，故故意加抖杆。助力转向初引入时司机得不到路况回馈、技术受损，故现代车小心计算所需力量并人工加入路感。
- 高速公路侧减速标线：轮碾浅沟隆隆，偏离车道警告；需减速路段横纹间距越来越近，未有效减速则频率升高——人为但有效。研究者在座椅下装振动器：右偏右振、左偏左振，仿压到左/右振动带；过近前车或超速则座椅前半振。说明两原理：自然映射 + 持续感知（不打扰）。轻柔如自然声，不侵犯意识。

**推导**

人人已有无语言、几乎不训练的距离与方位沟通；应搬到人机。映射可以从空间扩展到频率、振动部位。持续轻反馈优于突然警报。

**结论**

自然信号使人与机器的互动清楚有效；这是六条法则的经验基础。

## 五、六条设计法则与未竟目标

### 论证推理链

**论据 / 案例 / 事实**

人人沟通有几千年传统礼节，多下意识。人机等不及几千年，但已了解许多法则，可写入机器构造：

1. 提供丰富、有内涵和自然的信号。
2. 具有可预测性。
3. 提供一个好的概念模式。
4. 让输出易于理解。
5. 提供持续的感知，但不引起反感。
6. 利用自然映射，让互动清楚有效。

挑战：让人投入与机器互动，提供适量自然环境讯号，把人解放去做喜欢的事，真正得到自动的好处；必要时随时回去控制。

智能系统不易维持这种平衡，最重要原因是缺共同领域——单凭新设计不见得能解决，需多年研究。有一天或可有更生动完善的智能代理，再谈建立共同领域与自然对话，路还很长。

有效沟通要求：机器可预测、可被理解；人能了解状况、行动、下一步；自然方式互动；持续、不侵犯、有效地了解状况与行动。今日机器仍未真正满足，但是要追求的目标。

**结论**

六条是给人类设计师的清单；后记里机器会给出一套傲慢的「镜像」五条，再被作者补上第六条「不要用错误形容人的行为」。

### 实操方法与设计原则

把六条当检查表：每个自动功能问——信号是否自然丰富、行为可否预测、概念模式是否可学、输出是否可解释、是否持续且不烦、映射是否自然。

## 段落总结序列

主旨：无反馈则无合作；反馈应自然、可持续、可理解；错误的可阐释性决定怪谁、也决定产品生死；六条法则是人机沟通的设计清单。

最小标签集：陈述 / 必要依据 / 限定 / 可替换例证 / 过渡/场景

1. 【过渡/场景】机械时代可见可听，电子时代内部静默，沟通解释理解对任何聪明共事者都关键，机器却常被假定完美而无须沟通。
2. 【第二档·可替换例证】M 教授演示无进展指示，问题其实是内网禁外连；智利玻璃电梯因无声无可见到达而错过三趟。
3. 【第一档·必要依据】无反馈无法建概念模式，无法与人/电梯/智能机器合作；人机反馈可能更要紧。
   （本段是第4、8段的必要依据）
4. 【第一档·陈述】家电自然声是有效确认；完全无声不好。外加灯/哔哔编码贫乏不统一。反馈用途：确认、进度与时间、学习、特殊状况、证实、引导期望。警报齐鸣会先抢处理时间。
5. 【第一档·限定】智能设备需要持续、无侵犯、必要时才拉注意的双向互动；哔哔和语音警告不够。
6. 【第一档·陈述】卷一「只怪设计」通常对但不完全：可理解的「自己的错」让人学习。牛顿多维空间错不可阐释 → 骂机器、漫画、品牌死亡；萝西塔 hand/nand 可改笔；Palm 涂鸦字母级、形态近打印。
7. 【第一档·陈述】好反馈=自然互动+内隐+安静信号+自然映射。倒车手势与泊车频率哔、硬盘/沸水、安静技术的中心/边缘。
8. 【第二档·可替换例证】灶具矩形映射；抖杆、路感、隆隆标线、座椅分区振动 = 映射+持续轻感知。
9. 【第一档·陈述】六条法则；平衡难因缺共同领域。目标：可预测、可理解、自然、持续不侵犯。今日未满足，但是方向。
