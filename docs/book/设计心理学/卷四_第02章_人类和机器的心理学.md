# 卷四 第02章 人类和机器的心理学

## 本章位置

上章说明机器已用安全带、巡航和导航主控，两句独白构不成对话。本章回答「这些机器到底像什么」：把人的特性投射到机器上已不只是比喻——新一代设备自己判断、自己决定。作者用本能/行为/意识三层画出**汽车+驾驶者**这种人机混合体，再指出目标、行动、感觉上的鸿沟，以及人机几乎没有**共同领域（common ground）**。下一章转向自然互动、内隐信号与可预测性。

## 核心论点

1. **自动化设备的拟人属性已变成真实描述**：它们自己判断、自己决定，无须人授权每一步。
2. **我们夹在两个世界之间**：完美自动机器人的科幻尚未到来，纯手工无自动的世界正在远离；不懂又失灵时生活并不更方便。
3. **日常「智能」用品并不智能，只是反应灵敏**；智慧在设计团队脑中（测心术式预设）。
4. **汽车+驾驶者是一种新杂交有机体**：车管本能层，人管意识层，双方共管行为层；21 世纪车还在接手意识层，终有一日车上的人都是乘客。
5. **人机缺乏共同领域**是沟通的超级鸿沟：人与人可共享，机器与机器可握手，人与机器生活在逻辑规则 vs 依状况灵活反应的两个世界。
6. **可行路径**：只做建议不强制、让人了解和选择；自然互动见下一章。

## 关键概念补全

**自动魔术（automagical）**：自动化 + 魔术。制造商希望你相信并信赖魔术；说明书充满神秘机械术语与行销拼词（如「智慧住宅感应器」），却不解释如何运作。

**三位一体的脑 / 三层次**：保罗·马克廉（Paul MacLean）从脑干到皮质的简化。作者在《情感化设计》里再简化给设计师：

- **本能的（visceral）**：自动、下意识，由生物遗传决定。
- **行为的（behavioral）**：习得能力的大本营，仍相当下意识；预期行为后果。
- **意识的（reflective）**：有意识、自觉；自我与自我形象；分析过去与未来希望/恐惧。

**共同领域（common ground）**：克拉克《语言使用》——互动所依赖的共享知识、信仰与臆想。机器间的「握手」（handshaking）是建立共同协议、状态与语法。

**拟人论（anthropomorphism）**：把信仰、情绪、人格套到非人对象上。作者说当机器认知与情绪增进后，这些特质或许不再牵强。

## 一、现在与未来的三种呼叫

### 论证推理链

**论据 / 案例 / 事实**

- **已经发生**：飞机喊「拉升！拉升！」（通常女声）；汽车滴滴、收紧安全带、调靠背、假装刹车，摄像监控驾驶员，雷达感潜在碰撞且人未看路则嗡嗡/振动，仍无反应则自动刹并为撞车做准备；凌晨三点洗碗机哔哔报洗完，除吵醒人别无用处。
- **未来想象**：冰箱禁止再吃鸡蛋（体重计、诊所血脂）；下班后车子查智能手机日志，改走你爱的盘山路并选你爱的音乐；房子抱怨你出门不谢它倒垃圾，并推销邻居已装的新控制器。
- 人机交互研究几十年，但多在工业与军事（工作就是用机器）；作者关切的是**未受特别训练、偶尔使用**的普通用户：家电、娱乐、开车。
- 学习方式：尝试与错误 + 无休止挫折。设计者假定设备够聪明所以无须训练。

**推导**

有些机器顽固、有些情绪化；投射到机器上的人的特性，对自主系统已是真实描述。厂商说「让生活更方便」——完美可靠时不必了解运作；手工操作自己懂的机器时也快乐；夹在中间则既不懂自动、机器又不如期，谈不上享受。

**结论**

普通用户如何学智能设备，是本章关切；「自动魔术」让人在失灵时不知道如何反应。

**启示**

说明书应解释运作机制，而不是用命名冒充解释。评估产品时问：失灵时用户知不知道下一步。

### 实操方法与设计原则

- 不要假设普通用户会读厚说明书或理解行销术语。
- 完全可靠的自动 或 用户理解的手工，两端都可接受；半懂半失灵最糟。

## 二、人机心理学简介

### 论证推理链

**论据 / 案例 / 事实**

- 智能机器史：钟表、会下棋的机械。1769 年沃尔夫冈·冯·坎佩伦的「土耳其人」（Turk）轰动欧洲皇室，实为箱子里藏职业棋手——人们愿意相信机械可有智慧。
- 真正开始：20 世纪中叶控制理论、伺服与回馈、控制论、资讯与自动机理论；电子电路约每两年翻倍，四十多年后集成电路比早期大型机强百万倍；再 20 年或强千倍，再 40 年或再强百万倍。
- 人工智能约 1950 年代成科学：从冷硬数理逻辑转到常识推理、模糊逻辑、概率、定性推理、启发式。今日可检视辨认物件、理解部分口语书面语、说话、在环境中移动、复杂推理。
- 日常成功例：电脑游戏里恼人的聪明角色；银行信用卡诈骗追踪；汽车刹车、防抖、车道、自动停车；洗衣烘干感测衣料脏污；微波炉感测熟度；相机对焦曝光、脸部识别与追踪。功能与可靠性会增、价钱会降，进入更多非贵重产品。
- 硬件 vs 身体：机器直线直角弧线、马达显示器线路；生物柔性组织韧带肌肉。大脑大规模并行、电化学反应趋稳；机器信息处理更快但少并行。人强于形态辨识、创造、适应、异中求同、类比扩展；记忆不精确但能发现关系类似性；日常常识快而强——机器没有普通常识。
- 图2.1「汽车+驾驶：一种新的杂交有机体」（Marta Thoma 雕刻 *Rrrun*，帕洛阿托鲍登公园）。
- 机械演化靠设计者分析改进，数百年；生物自然演化不同。但两者都须在真实世界有效、可靠、安全运作，因而都需要感知、决策、以及**机器特有的类似情绪**（不是与人相同）——避险、捉机会、预期后果、反思、学习。

**推导**

世界对动物、人、人工产品提出同样要求。要把情绪状态建在机器里，可迅速避险、保护附近的人、有学习意愿。已有萌芽：电梯门遇障碍打开；自动吸尘器避陡降（掉落恐惧在电路里）——都是设计者把人体自动恐惧存进机器的**本能反应**。意识层检讨经验、给正负评价，机器尚未有，一旦有将大增学习与预测。

**结论**

人与机器能力结构不同；日常智能是反应系统。未来用品关键在：知道自己在哪、主人是谁、与其他用品和环境沟通，以及移动、物理控制环境、感知旁边的人与机器。

**启示**

不要用「电脑每 20 年强数千倍」推出「很快就会懂你」；常识、类比、并行与身体灵巧仍是鸿沟。

## 三、新个体的产生——人机混合体

### 论证推理链

**论据 / 案例 / 事实**

- 三层次用于设计师（详见卷三）。若建在机器内，可避险、保护、学习。
- **马+骑手 vs 汽车+驾驶者**（图2.2）：马提供本能主导，骑手意识主导，双方共管行为；智能汽车同样——车本能、人意识、合作于行为。马或智能汽车也在尝试意识层控制。
- 马：避危险地带、按地面调速、避障；学复杂规范后可奔跑跳跃、必要时放慢、与他马/人保持距离。现代汽车：感测危险、稳定性、刹车速度、车道、距危及时刹。
- 并非总是人管意识：马可要慢下来、想回家、摔骑手、不理会指令。不难想象汽车执意转向、因加油/进食/休息离开公路，或被路边广告吸引偏离。
- 20 世纪初驾驶者提供本能+行为+意识全面控制。科技进步后车接手发动机内部、油量、换挡；防滑刹、防抖、巡航、车道维持使车承担越来越多**行为层**。
- 21 世纪车越来越有意识层：自适应巡航持续判车距；导航盯是否遵循指示；监控驾驶者并提醒或直接纠正；仅必要时完全接管。
- 有朝一日汽车不需要驾驶者，人都是乘客（聊天、阅读、睡觉）；爱开车的人会有专门场地，像今日爱骑马的人。作者相信这在 21 世纪内会来临。运输用车将具备三层全部功能，兼顾客适健康：光、温、食、饮、娱乐。
- 拟人论：机器认知情绪增进后，套用的特质或许恰当准确。

**推导**

最精彩的未来科技是与人建立共生的：车与驾驶像马与骑手，但分担层次不同。混合体将在全自动驾驶到来后消失——仍有车、有乘客，车拥有全部三层。

**结论**

人机混合体是过渡形态：本能已大量在车，行为在争夺，意识正在被车接手。

**启示**

设计过渡期产品时明确：哪一层由谁负责、何时移交、人如何知道自己还在不在回路里。

### 实操方法与设计原则

- 用三层分工画系统：不要默认「人永远管意识」。
- 电梯开门、吸尘避坠是可做的本能；不要宣称已有意识层反思。

## 四、目标、行动和感觉的鸿沟

### 论证推理链

**论据 / 案例 / 事实**

- 今日「智慧型」洗衣机、洗碗机、自动真空、汽车、电脑、电话、游戏：**不智能，反应灵敏**。设计团队预设状况、写入程序。
- 人：上千万专职神经细胞（光声触味平衡温压痛、内部肌体位置），对外在世界有复杂表象与预测。
- 机器感应器有限，测的与人接收的不一样：可测人感觉不到的频率、红外、无线电、超范围声波；动作上人有灵活四肢手指，机器不灵巧但功率更大。
- 人与机器目标不同；很多人甚至不认为机器有目标。机器越聪明越会按明确目标评估并实施步骤。情绪对人行为和解释很重要；机器无情绪或仅有初级、与人差别大。

**推导**

问题在于反应系统很少直接衡量真正需要注意的东西，只能测传感器能探测的。心理知觉 ≠ 物理感测。把自动引进现用机器时须谦虚面对失败，充分了解机制差别。

**结论**

鸿沟在感知、动作、目标与情绪四条线上同时存在。

## 五、共同领域：人机沟通的基本限制

### 论证推理链

**论据 / 案例 / 事实**

- 克拉克：艾伦与芭芭拉的共同领域随共处时间变广；行动配合根植其上。同文化背景使人快速有效互动。偷听典型：「你知道吗？」「当然。」——缺共同领域的外人不知所云。
- **人—人可共享，机器—机器可联通，人—机没有。**
- 机器间握手：电视与机顶盒、电脑上网、手机搜信号；最明显是传真机颤声——商议电码、速度、解析度，再传送并确认。像陌生人先交换共同认识的人与兴趣。工程师花大量时间定国际标准（技术、法律、政治谈判）。
- 人从经历学习，共同领域随时间增长；同样状况下艾伦—芭芭拉与艾伦—查尔斯互动可不同。机器几乎不能学习（实验室少数系统外归纳很差）。
- 回头看章首三个未来状况：机器不能读心、不能知传感器外的活动、不能用颐指气使充分表达。冰箱取蛋可能是给别人；车查日程选风景路——除自然语言外都可能，且若允许人做主则是友善建议；房子嫉妒邻居不太可能，标杆/最佳实务却可能，不必趾高气扬。
- 设计者只能按经费与当时科技，从有限传感器资料推论；范围内无突发则大多良好，超出则不能完成。

**推导**

表面上相同的前提会因「状况不同」引出不同行动。目标、行动、感觉的基本差别使人机甚至不能在「世界上正在发生什么、要采取什么、要达成什么」上一致。缺乏共同领域是超级鸿沟。

**结论**

自然谈话式互动因共同领域缺失而很难；若只建议不强制、把假定与共通处弄清楚，经双方都能阐释的内在行为与自然互动，仍可能实现合作——即第三章。

**启示**

- 能握手的机器对机器标准，不要误当成已经能与人握手。
- 产品策略：建议 + 人做主 > 强制 + 静默。

### 实操方法与设计原则

- 避免危险的办法：只做建议、让人了解和选择，不强加无法理解的操作。
- 不要用自然语言傲慢口吻包装统计猜测。

## 段落总结序列

主旨：日常智能是反应灵敏而非真智能；汽车+驾驶是分层共生的混合体；人机因无共同领域而难以对话，只建议不强制才可行。
