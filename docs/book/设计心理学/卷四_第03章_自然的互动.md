# 卷四 第03章 自然的互动

## 本章位置

上章指出人机没有共同领域，自然谈话很难，但可走「双方都能阐释的内在行为」。本章展开这条路：自然信号与内隐沟通、示能作为设计师—产品—用户的共享沟通、马/马车的松紧缰绳、**戴佛特自行车的可预测性**、自然安全与风险补偿，以及酷博特、外骨骼、赛格威这类**应激自动化**（人做意向，机器放大力量）。下一章把梭罗「人成为工具的工具」接到车道维持、车群车队与半自动化的危险中间态。

## 核心论点

1. **哔哔灯闪是最不自然、资讯最少、最烦人的信号**；家居/汽车已有几十上百种，工业医疗还在激增，同时响起时会淹没真正危险。
2. **自然信号**（水沸、路感、火焰形状、马达声）提供持续、下意识、空间与材质信息，且较少扰人。
3. **内隐沟通**是日常行为的可诠释副作用，不需专门学习；智能产品应靠它告知而不打断。
4. **示能**不仅是物—行动者关系，也是设计师经产品与用户的共享沟通（苏萨说服了作者）。
5. **与智能机器双向沟通**可借马/马车的松—紧连续控制、策略脚本（playbook）、以及戴佛特原则：**机器应可预测，人来适应**；机器猜人的动机只会混乱或危险。
6. **自然安全**：看起来更危险反而可能更安全（风险补偿/风险稳态）；应用须谨慎，且不要把东西**实际**做得更危险。
7. **应激自动化**（动力辅助、酷博特、外骨骼、赛格威）是人机自然协作的范例：人控意向，机器补力量，操作者甚至不觉得有机器。

## 关键概念补全

**本体感受系统（proprioceptive system）**：从半规管到肌肉、肌腱、关节，感知身体位置与方向。

**内隐沟通（implicit communication）**：卡斯托佛朗奇——别人可诠释的自然副作用，利用日常行为的知觉形态，不需特殊学习、训练或传递。

**安抚杂音（comfort noise）**：线路太静时人为加回的声音，实为内隐确认「仍在接通」。

**示能（affordance）**：吉普森——动物/人对某物可能实施的活动，是关系不是固定性能；无论是否可见都存在。作者强调**可见性**对设计的价值。苏萨：示能是设计师与用户的沟通。

**策略脚本（playbook）**：米勒团队——人机共享任务模式，像球队按战术比赛；操作者选脚本表达意向，或机器显示自己选了哪套。

**风险补偿 / 风险稳态（risk compensation / risk homeostasis）**：环境看起来更安全后，人做更危险的事，事故率可不变。威尔德提出后对原因程度有争论，对现象本身少质疑。

**共享空间（Shared Space）**：蒙德门等——去掉传统信号标志护栏，混合车流，让使用者互相负责。

**酷博特 / 协作机器人（Cobot）**：科尔盖特与佩什金——人机共同控制、共享智慧；可设虚拟墙与路径。

## 一、自然的互动：从经验中获取的教训

### 论证推理链

**论据 / 案例 / 事实**

- 图3.1 会发哨声的壶：简单技术，听到哨声就去查看（郝斯特摄影）。设计师以为物品在「沟通」，其实多是单向发信息。
- 洗衣机/洗碗机/微波炉定时器的哔哔难以分辨，作者夫妇在厨房与洗衣间来回跑。
- 自然声音：物件移动、剐蹭、碰撞产生；透露空间位置、材质（叶、枝、金属、木、玻璃）、活动（跌落、滑动、破裂、关闭）；静止物也经反射重构空间感。人通常未意识到自己多依赖声音。
- **水沸腾**：温度升高时蒸汽声自然变化，至尖锐急促而壶发稳定悦耳哨音；围起壶嘴留小缝即可，从缓慢微弱不稳定到持续增大。听几次就大致能判时间，无需电子器件。
- 汽车故意把「路况」以声音和方向盘振动反馈给驾驶；电钻的马达声与手感对精确钻孔重要；厨师爱煤气炉因火焰形状判炉温，抽象刻度盘较差。
- 小型自动吸尘器行进声表示在忙；软管堵塞时马达声**增大**（不是更用力，而是无空气阻力转得更快——作者脚注特意「逮到你了」）。
- 自动化困难：故障却要人接手且常无事先提醒 → 用自然、持续性信息回馈来警示。

**推导**

单一信号有用，许多不和谐信号则分心、不悦、危险。人擅长综合视听味触与本体感受；自然信号传递信息不扰人，提供持续觉察。设计师最容易用简单音调与闪光，却是最差一类。

**结论**

未来日常用品应寻求自然产生的状态提示（振动、声音、光线变化），作为典范。

**启示**

先问设备能否用工作本身的副产品当反馈，再考虑加电子哔哔。

### 实操方法与设计原则

- 自然信号应让人辨识来自上下前后、材质构成、事件是否急切。
- 让自然回馈成为其他系统的典范。

## 二、隐含的讯号和沟通

### 论证推理链

**论据 / 案例 / 事实**

- 实验室太整齐 → 作者猜没多少事；喜欢杂乱 = 活力投入。杂乱是活动的内隐信号。
- 足迹、垃圾、摊开的书：符号学称记号/信号，侦探称线索（福尔摩斯）。
- 老式国际长途的喀哒嘶嘶让人知接线进展；线路变静后有人以为没接通就挂 → 工程师加回「安抚杂音」，实为内隐确认。
- 无「耳皮」：不能像垂眼皮那样关掉听觉。劳斯莱斯曾夸时速 96 km 时最大噪音是车内电子时钟。过静则听不到救护车、喇叭、风雨；路感消失则不知安全车速。电动车静得驾驶员不清是否在工作，行人下意识靠声音，会被静车/自行车吓到。盲人协会建议轮毂/轮轴发随车速变化的自然声。有厂商用很不自然的「哔哔」提醒引擎在运作。
- 塞波把自鸣壶哨子做成 E 与 B 调和弦。紧急信号（救护、火警、烟雾）则**故意刺耳**。
- 触觉：音量旋钮过中点的清脆短音；淋浴须手动按升温才能超预设水温；商用飞机油门止挡——紧急时可越过，伤发动机次于坠机。
- 纸书磨损、折角、便利贴、划线边注；电子文档电脑知道读过哪些——黑尔、赫兰、罗布鲁斯基、麦肯莱斯团队在电子文件上留「哪些章节最常被读」的记号。污渍破损是使用与重要性的自然指标，电子可借用其优点而不真损坏材料。

**推导**

声音提供反馈也扰人：办公室工厂家居追求安静，但过静危险。不自然、无意义的声音几乎都令不快；精心设计的声音仍可能烦，可能的话避免。视觉与触觉是选项。内隐互动：无须语言文字、无须勉强，简单线索指出可行方案。

**结论**

内隐沟通是告知而不打扰的有力工具。下一节挖出示能。

### 实操方法与设计原则

- 少用不顺耳声音、降音量、减频繁瞬变；在宜人气氛中轻微变化即可沟通。
- 紧急才用刺耳。
- 机械止挡：日常限制 + 紧急可越过。
- 电子「使用痕迹」模拟磨损。

## 三、使用「示能」进行沟通

### 论证推理链

**论据 / 案例 / 事实**

- 苏萨（里约热内卢）电邮反对作者对示能的定义：「示能是设计者与用户的沟通。」作者先答：示能是已存在的关系，与沟通无关。她是对的；作者赴巴西一周，为其《符号学工程》写封底：设计若是设计师、产品、用户之间的共享沟通、科技只是媒介，设计哲学会积极改变。
- 吉普森：示能是对某物可能实施的活动；椅对成人可坐、撑、投、藏，对婴儿/蚂蚁/大象则不同。不论是否明显、可见、被发现，都存在。
- 作者用于设计时强调可见性：不知道就不值钱（至少当下）。一生碰到成千上万物品大多能用，还会「黑马」式解决（折纸垫桌脚、报纸贴窗遮日）——与内隐沟通有关，今称示能。
- 《纽约时报》评圣皮埃尔大教堂（菲尔米尼）：地面微倾引导走向圣坛，「你自然知道走向哪儿」，不带强迫、无单一指引。
- 被动物品等我们行动：按电视钮换台、走转推拉。设计挑战：事前知可能操作与如何操作；进行中知状态；事后知改变了什么。从家电到网站到老式汽车，挑战大且常失败。

**推导**

未来自动、自主、智能机器更依赖直觉示能来告诉人如何沟通，机器也要以此与外界沟通。可见示能在最佳时不让人觉察被引导。

**结论**

示能是双向沟通的基础设施；但自主智能机器的问题不能单靠可见示能解决，必须双向：人→机且机→人。

## 四、与自动化的智能设备的沟通：松紧缰绳、策略脚本、戴佛特自行车

### 论证推理链

**论据 / 案例 / 事实**

- 布蓝兹维：佛雷米西解释骑马关键是放松 vs 收紧缰绳。紧 = 人直接控、表达意向；松 = 马更自主，骑手可做他事甚至睡觉。两端之间连续。紧时马仍可不配合；松时仍可用缰、喝、夹腿微调。图3.2 四轮马车：车夫不像骑在背上那么紧，更像非职业者开现代车；松紧概念仍适用。动物自主或人控程度经缰绳的示能做内隐沟通。
- 作者开模拟车：紧——人管油门刹车方向，车用方向盘「往后顶」暗示距前车太近要减速、「往前收」催加速。松——车过积极，几乎闭眼可让它开。遗憾：展示未让驾驶者选择给车多少控制权；紧急时须能很快交还控制且不影响处理非常状况的注意。
- **策略脚本**：米勒团队——共享任务模式沟通计划、目标、方法、资源，像有经验的部属。重点在飞机：脚本或表明如何起飞达巡航高度；自主运行时须随时表明如何运作，以便人立刻介入改策略。书面列表耗精力，家居普通人需要简单显示。商用复印机已类似：五十份、双拼、双面、装订、自动分页，图示翻页、对齐长短边、堆叠高度=进度。松操作时，显示状态类似脚本，让人知程序与进度。
- **戴佛特城的自行车**：荷兰小城，运河、窄街，危险来自蜂群自行车而非汽车。市中心车与行人混。招待保证：绝对安全，只要别伸手、别试着躲避、别突然停或猛转——**让人能预测**，匀速稳定方向。骑行者已算过路径；行人若斗智则不堪设想。图3.3：环保好，对行人危险；可预测、不要试图「帮助」骑车人。
- 行人 vs 自行车+骑行者：后者是人动力+人智慧的结合体，并不缺智慧，缺的是对行人的沟通。接近时已太晚磋商。方法：一方规划路线，另一方行为可预测，无须协调。
- 若不能与「人操纵的智能设备」（自行车）协调，凭什么认为与智能设备协作更容易？不应让聪明机器去了解操作者心思、推测动机、预测下一步——会错，且使机器行动不可预测。双方互猜一定混乱。
- 哪一边应可预测？两边同样聪明则如行人与骑车人，有共识即可。通常人智力和普遍认知远超设备，且无共同领域 → **最好机器可预测，操作者反应**。策略脚本帮人了解机器所循程序。
- **如果机器试着推测人的动机再猜行动，轻则混乱，重则极端危险。**

**推导**

马与骑手模式强，但还要研究如何把意愿最好传给系统。内隐沟通+示能是强大自然概念：系统设计为可独立自主，互动程度能自然变化。

**结论**

可预测性是关键设计法则。家居智能设备尤其需要简单、低训练成本的状态显示。

**启示**

- 提供连续的控制权滑杆（松—紧），紧急可瞬间收回。
- 用图示脚本代替文字计划表。
- 不要做「猜你下一步」的机器，除非猜错的代价可忽略且可关闭。

### 实操方法与设计原则

- 松紧连续，不是开关。
- 机器显示正在用的策略，用低认知负荷方式。
- 戴佛特法则：保持可预测；机器侧承担可预测性。

## 五、自然安全

### 论证推理链

**论据 / 案例 / 事实**

- 哪类机场意外少？平坦温和易起降（图森）还是有山多风（圣迭戈、香港）？答案：**危险的机场**——飞行员更警觉。图森一例：视野清晰天气温和导致过分自信，靠防撞「拉升」才免灾（即第二章飞机呼叫）。
- 杂志报道蒙德门副题：「让驾驶看起来更危险，反而可以使开车更安全。」
- 主观风险影响行为：怕飞机不怕坐车或车里被雷击；2006 年全美雷击毙约五十人，民航空难乘客死亡三人。把活动设计得更安全常不降事故率 → 风险补偿。安全带、摩托盔、美式足球垫、滑雪高筒鞋、防滑刹与稳定控制都改变行为，事故率仍可一样。投保盗窃险后对财物不上心；设救护队增加敢冒险的登山者。
- 风险稳态：系统维持稳定安全水平；看起来更安全 → 更冒险 → 实际安全仍一样。威尔德 20 世纪提出（译文一处写 20 年代、注释写 80 年代），争论在原因与程度。
- **反过来用**：拆红绿灯、停车标志、斑马线、宽街、专用自行车道；设环岛、减街宽。已用于艾比、伊普斯威奇、奥斯坦德、马金甲、德拉赫滕。不改高速公路对信号规则的需要。伦敦肯辛顿主街路面意外下降 40%，拟用于展览路。共享空间：人管理交通，须考虑其他使用者，回到良好举止；据称另一优点是减少事故。
- 政策难：不能完全避免车祸；一宗致命车祸市民就会要求信号、灯、行人专用道、加宽。
- 艾略特、麦科尔、肯尼迪提出的认知机制：复杂环境增认知负荷与感知风险 → 较慢车速；拱桥弯道等自然路况平抑车速且易被接受；强调公路/乡镇交界增强觉察或降速；阻隔远方视野或打断直路；制造不确定性；综合方法比单独有效但可能视觉干扰、成本高；路边活动（停车、行人、自行车）帮减速。
- 居家跌倒与中毒是意外伤死主因：可否让浴缸看起来更滑、楼梯看起来更险、可吞物看起来像毒药？（作者以问句提出）
- 现代车太舒适：听不到路噪、无震动、与高温无缘、音乐聊天甚至手机（免提通话危险性与酒驾一样，斯特雷耶等）。自动化再把稳定、刹、车道接走，驾驶者离开真实操作。
- 不能把人赶到车外当马车夫。电子驾驶（电脑代机械）已部分用于油门刹车；方向盘将来也可电子，用电机/液压给「路感」。届时可模仿打滑、剧振、松弛摇摆方向盘。问题：驾驶员会以为车坏了；制造商问「为何生产有时被认为运转不正常的产品？」作者：不是让**汽车**看起来更危险，而是让人觉得**环境**更危险——像陷车辙、泥泞、冰雪时怪路不怪车，干净高速则归功于车。
- 不是把东西实际做得更危险；应继续真安全（防滑刹、稳定、烟感、头盔、防护罩）。自动有效只在一定范围；人若一开始更小心，意外时自动才更有效。
- 作者自己也不十分确定：有人会想「路没那么滑，车只是想让我慢」。故意吓人不是好营销。但假设仍有真实性：过舒适会让人注意不到真正危险，需要把真实危险状况**重现回来**（作为信息，不是真增危）。

**推导**

感觉上的安全与实际上的安全有差别。逆向风险补偿难成政策，但自然路况与反馈可唤起觉察。归之于环境而非汽车，才导向「越险越小心」。

**结论**

自然安全依赖行为，不依赖更多警告牌。争议大，须与真正工程安全并行，不可替代。

### 实操方法与设计原则

- 用路感、振动、自然路况提供危险信息，而不是只靠要解释的符号。
- 把「环境险」与「车坏了」分开，避免错误概念模型。
- 真安全装置仍要保留。

## 六、应激自动化

### 论证推理链

**论据 / 案例 / 事实**

- 动力辅助刹车与方向盘：人机自然协作基本例子。
- **酷博特**：佩什金电邮：「最聪明的物件是能与人智力互补的，而不是尝试超越人的。就像最聪明的老师。」人机共同控制。用于搬运、汽车组装、仓储：酷博特找存储空间，人用视力、灵巧、解题技巧；可沿导向平面推。放大力量：人施很小力，觉自己在完全控制，甚至不觉得有机器。装发动机：不必高架提升机或全自动智能起重机，挂绳轻提，机器人感力并放大；移位旋转放低只需轻推拉。可设虚拟墙与路径：往墙推会被自然客气地拒绝，可当帮手先推到「墙边」再沿线走。其他应用：遥控插配的虚拟墙、魔术鼠标避免滑出下拉菜单、手术机器人导引器械、装配线把仪表板备胎座椅车门无碰撞移到目标。
- **机械外骨骼**：穿在身上，感动作并放大。当时尚未实现、概念阶段。拥护者：建房、灭火、危险环境、提起重物、跳更高，以及残疾人康复——松紧缰绳：病人主导=拉紧，机器人主导=放松。
- **赛格威**：两轮，人机共生；站上去自动共平衡；前倾进、后倾停、侧倾转弯。比自行车自然好用，但像马一样不适合所有人，要技巧与注意力。图3.4。
- 对照刻板互动：飞机自动驾驶、汽车定速巡航——假设人慎重设定、开启、系统自动，出问题则人立刻解决。

**推导**

自然、反应性的案例说明：恰当应用机器智能与协作，可真正共生——人机互动最佳境界。刻板模式把人排除回路，直到突然要人回来。

**结论**

应激自动化 = 人的意向 + 机器的力量/约束，感觉像自己在做。这是对「全面接管」的替代。

**启示**

优先设计「放大你正在做的」而不是「等你设定后把你踢出去」。康复与驾驶都可用松紧连续改变主导。

### 实操方法与设计原则

- 互补而非超越。
- 虚拟约束以「像真有墙」的方式拒绝，不强迫感。
- 对照检查：你的自动是酷博特式还是巡航式？

最小标签集：陈述 / 必要依据 / 限定 / 例外 / 可替换例证 / 次要观点 / 过渡/场景

1. 【过渡/场景】哨声壶图：物品多是单向发信息；需要能协调行动、与自动机器合作无间的方法。
2. 【第一档·陈述】现代设备信号爆炸；单一有用，同时不和谐则分心危险，家居中真警报可能被淹没。
3. 【第二档·可替换例证】夫妻分辨洗衣/洗碗/微波定时器，来回奔波。
4. 【第一档·必要依据】人擅长自然信号：视听本体感受；自然声给位置、材质、活动与空间，且不扰人。设计师爱用的音调闪光最不自然、资讯最少、最烦人。
   （本段是第5、6段的必要依据）
5. 【第二档·可替换例证】水沸与壶哨的连续变化；车路感、电钻手感、煤气火焰 vs 抽象刻度；吸尘行进声与堵塞时音调升高。
6. 【第一档·陈述】内隐沟通=可诠释的行为副作用（卡斯托佛朗奇）；足迹、乱实验室、电器声让人知何时介入、何时忽略。
7. 【第二档·可替换例证】国际长途安抚杂音；过静的车与电动车危险，盲人协会建议随速自然声；塞波和弦壶 vs 故意刺耳的急救信号。
8. 【第二档·可替换例证】旋钮中点触觉、淋浴升温锁、飞机油门止挡；电子文档模拟书的磨损痕迹。
9. 【第一档·陈述】作者承认苏萨：示能是设计师—产品—用户共享沟通。吉普森定义是关系；设计要可见。教堂微倾「自然知道走向哪儿」。
   （示能详见卷一）
10. 【第一档·限定】未来自主机器不能单靠可见示能；必须双向沟通。
11. 【第一档·必要依据】佛雷米西松/紧缰绳：连续控制权；紧时马仍可不听，松时人仍可微调。马车更像普通驾驶。模拟车：方向盘顶/收暗示快慢；缺「选择给车多少权」且紧急须能迅速交还。
    （本段是第12、13段的必要依据）
12. 【第二档·可替换例证】策略脚本共享计划；复印机图示份数双面装订与堆叠进度。
13. 【第一档·陈述】戴佛特自行车：行人保持可预测，不要斗智；缺的是沟通时间不是智慧。机器应可预测，人来反应；机器猜动机则混乱或危险。
14. 【第一档·陈述】自然安全：危险机场更安全；风险补偿/稳态；共享空间去掉传统管制，伦敦一例事故降 40%。政策脆弱，一宗致命车祸即可逆转。
15. 【第一档·限定】不是把产品实际做更危险；用反馈让人觉察环境风险（怪路不怪车）；真安全装置仍要。作者对「故意吓人的车」存疑，但过舒适会使人看不见真危险。
16. 【例外】紧急刺耳信号、专业驾驶员关闭自动、油门越过止挡——通例「要自然、要安静」在此不适用。
17. 【第一档·陈述】应激自动化：酷博特互补智力、放大力量、虚拟墙；外骨骼概念与康复松紧；赛格威用身体倾斜。对照巡航/自动驾驶的「设定后踢出回路直到出事」。自然反应性协作是人机最佳境界。
