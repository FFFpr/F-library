# 第十篇 孙恩、卢循之乱

## 本章定位与核心主张

本章专论东晋末年孙恩、卢循之乱，主张此事不能只看成一次海岛“妖贼”起事，而必须从社会阶级、宗教信仰、地理关系三方面合起来看。孙恩、卢循、徐道覆在江东士族眼中属于晚渡、婚宦失类的“荒伧”或等于寒人；他们又同为五斗米道（天师道）中人；其武力以水师为主，栖泊海屿，投水为仙，与滨海琅邪的宗教环境、家世遗传相连。

更关键的一层是：五斗米道在江东不仅取得庶民信仰，也取得士族乃至皇室中心人物的信仰。孝武帝、会稽王司马道子皆长育于天师道环境中。晋代天师道传播于世胄高门本为隐伏势力，若渐染及于皇族，则政治上立即发生巨变。西晋赵王司马伦废惠帝而自立是一例，东晋孙恩之乱的主因亦由于皇室中心人物早成天师道的信徒。五斗米道向士族特别是向皇室中心人物传播成功之日，也就是教主及上层人物最理想的发动叛乱之时。孙泰因与司马元显交厚而朝士莫敢言，事发被诛；孙恩逃海，乘元显纵暴吴会，旬日之间八郡响应，众数十万。

## 关键概念补全（术语先讲）

**天师道 / 五斗米道。** 本章与第四篇所用“天师道”“五斗米道”是同一系统的两种称呼。其为教，“咸去邪累，澡雪心神，积行树功，累德增善，乃至白日升天，长生世上”（《魏书》一百十四《释老志》）。所追求的便是长生。孙恩号其党曰“长生人”，即天师道或五斗米道的“种民”，是宗教称呼。《太平经》有云：种民，圣贤长生之类也。天师道徒有以“长生”为名的，汉有阴长生，晋有范长生。

> 💡 相关前置概念与推导详见：[04_第四篇_西晋末年的天师道活动.md]（赵王伦废立为西晋末年天师道活动之一；孙秀为琅邪五斗米道徒）

**婚宦失类与晚渡江。** 北人过江晚的，必婚宦失类；婚宦一旦失类，即为社会所鄙视，不论其往者是否为名族。江东王、谢诸族方盛时，北人晚渡者，朝廷悉以伧荒遇之，虽复人才可施，皆不得践清途。这是一个社会问题，连皇帝也不能改变。卢循、杨佺期、杜坦都属于这一类。在江东士族心目中，他们只是荒伧。

**土断与南来下层北人。** 孙恩世居南方，与其他南来下层北人一样，经过土断，已变成南方的低下阶级。土断是按实际居住地把侨寓户口编入当地，其社会效果之一，是把一部分北人降为“南人”中的低下等级。

> 💡 相关前置概念与推导详见：[09_第九篇_东晋与江南士族之结合.md]（土断后北来下等阶级亦列为南人，为南朝三分期中陈朝社会基础的伏笔）

**荒伧 / 伧荒。** 南朝用“伧”称中州人，晚渡而婚宦失类者更被“以伧荒遇之”“以荒伧赐隔”。与第九篇义兴周氏骂“诸伧”不同：那里的“伧”是对一般中州人的敌视；这里的“荒伧”是清途之内对晚渡失类者的排斥。

**尸解与水解、水仙。** 五斗米道有尸解之说，尸解有刀、兵、水、火之解。孙恩以投水为成水仙，是水解之说。妇女囊麓盛婴儿投于水，告之曰“贺汝先登仙堂，我寻后就汝”；孙恩赴海自沉，妖党及妓妾谓之“水仙”，投水从死者百数。水仙之说为海滨宗教之特征。

**郁洲。** 孙恩栖泊之所。《抱朴子·内篇》四《金丹》：海中大岛屿，若徐州之郁洲。地在今江苏省灌云县东北，昔为岛屿，今已与大陆连接。《水经注》淮水篇谓东北海中有大洲谓之郁洲，《山海经》所谓郁洲在海中者，言是山自苍梧徙此，山中犹有南方草木；崔季珪叙《述初赋》言山工有仙士石室。郁洲为神仙居处，而适与于吉、宫崇的神书（《太平清领书》）所出处至近。

**“之”“道”不避家讳。** 六朝人最重家讳，而“之”“道”等字则在不避之列，所以然之故虽不能详知，要是与宗教信仰有关。简文帝字道万，其子又名道生、道子，俱足证其与天师道的关系。

**服食之术。** 司马道子厚爱孙泰或五斗米道，在于五斗米道有服食之术，得之可以长生。吴兴内史虞啸父妻裴氏有服食之术，常衣黄衣，状如天师，道子甚悦之，令与宾客谈论。

## 论证推理链

### 一、先看社会阶级：孙恩、卢循、徐道覆都不是江东清途中人

- **论据 / 案例 / 事实：** 孙恩在第四篇《西晋末年的天师道活动》中曾经提及。他是赵王司马伦的谋士琅邪孙秀的族人。孙秀本为琅邪小吏，供给使。潘岳之父潘芘为琅邪太守，他曾遭到潘岳的挞辱。潘岳“不以人遇之”（《世说新语·仇隙》注引王隐《晋书》）。他得志是随赵王司马伦造反。司马伦失败，孙氏的命运可知。琅邪孙氏本属低下的阶级，何况又出了一个叛逆孙秀。孙恩世居南方，与其他南来下层北人一样，经过土断，已变成南方的低下阶级。但他的叔父孙泰却是东晋的一个将军、太守，并以五斗米道得到了三吴士庶的信仰。孙恩是他的继承者。
- **论证推导：** 孙恩一边是低下阶级、叛逆族人、土断后的南方低下等级，一边又通过孙泰掌握了三吴士庶的宗教崇拜。阶级低与宗教势力大，二者叠在一起，才构成“乱”的社会位置。
- **核心结论：** 孙恩所属，是南来下层北人经土断后的低下阶级，同时又是五斗米道在江东的继承人。
- **延伸推论：** 后来他能聚合亡命、自海上攻上虞、袭会稽，既靠宗教，也靠这个被清途排斥的社会位置。

### 二、卢循：范阳名族而婚宦失类，在江东只是荒伧

- **论据 / 案例 / 事实：** 《晋书》卷一百《卢循传》：卢循字于先，小名元龙，司空从事中郎卢谌之曾孙。《晋书》卷四十四《卢钦传》附卢志子《谌传》：谌名家子，早有声誉，才高行洁，为一时所推。值中原丧乱，与清河崔悦、颍川荀绰、河东裴宪、北地傅畅并沦陷非所，虽俱显于石氏，恒以为辱。谌每谓诸子曰：“吾身没之后，但称晋司空从事中郎尔。”卢氏为范阳涿人，是范阳名族。但到卢谌，“沦陷非所”，在后赵做了官，此之谓“婚宦失类”。子孙过江晚。北人晚渡江的，必婚宦失类，而婚宦一旦失类，即为社会所鄙视，不论其往者是否为名族。
- **同类例证杨佺期：** 《晋书》八十四《杨佺期传》：弘农华阴人，汉太尉杨震之后。自震至准，七世有名德。祖林值乱没胡，父亮少仕伪朝，后归国，终于梁州刺史。佺期自云门户承籍，江表莫比，有以其门地比王珣者，犹恚恨，而时人以其晚过江，婚宦失类，每排抑之。恒慷慨切齿，欲因事际以逞其志。《晋书》九十九《桓玄传》：佺期为人骄悍，常自谓承籍华胄，江表莫比，而玄每以寒士裁之。排抑晚过江、婚宦失类的士族人物，在江东是一个普遍现象，非止杨佺期一人。
- **同类例证杜坦：** 《资治通鉴》一百二十四宋文帝元嘉二十三年七月：时江东王、谢诸族方盛，北人晚渡者，朝廷悉以伧荒遇之，虽复人才可施，皆不得践清途。杜预之后、散骑常侍杜坦曾对孝武帝说：他本是“中华高族”，西晋丧乱，先世杜耽（预子）播迁凉土，世业相承，不替其旧，直以南渡不早，便以荒伧赐隔；“圣朝虽复拔才，臣恐未必能也”。孝武帝默然不应。这是一个社会问题，连皇帝也不能改变。
- **论证推导：** 与孙恩一同起兵的卢循便属于杨佺期、杜坦一类。范阳卢氏奕世高华，并不能抵消“沦陷非所”与过江晚。江东的清途标准，看的是南渡早晚与婚宦是否失类，不是远祖是否名族。
- **核心结论：** 在江东士族心目中，卢循只是荒伧。
- **延伸推论：** 荒伧身份解释了他何以与同样被排斥的孙氏结合；但结合的更内在纽带，还要看五斗米道。

### 三、范阳卢氏是否五斗米道：家世环境与婚媾两条线

- **论据 / 案例 / 事实：** 琅邪孙氏自孙秀至孙恩“世奉五斗米道”，《晋书》卷一百《孙恩传》有明言。史称卢循为“妖贼帅”，《晋书》卷一百《卢循传》称卢循“娶孙恩妹”，从这两条材料已可见卢循之必为五斗米道信徒无疑。卢谌（卢循的曾祖）的伯祖卢钦，曾官琅邪（《晋书》四十四《卢钦传》有“累迁琅邪太守”之言），而琅邪是五斗米道的发祥地之一，于吉、宫崇、孙秀都是琅邪的五斗米道徒。卢谌的从母又是刘琨的妻子（见《晋书》四十四《卢谌传》）。当赵王司马伦执政之时，“琨父子兄弟并为伦所委任”。刘琨曾“与孙秀子会率宿卫兵三万距成都王颖”（《晋书》六十二《刘琨传》）。赵王伦的废立，为西晋末年天师道的活动之一。卢谌既与赵王伦的死党刘琨为姻戚，而伯祖卢钦又曾为琅邪太守，是其家世环境殊有奉天师道即五斗米道的可能。从卢循娶五斗米道徒孙恩之妹为妻来看，疑范阳卢氏也是世奉五斗米道，与孙氏同为五斗米道世家。否则，南朝士族婚嫁最重门第，以范阳卢氏的奕世高华，虽曾婚宦失类，亦不致与妖寒的孙氏联姻。
- **旁证卢悚、许龙：** 《晋书》八《废帝海西公纪》：咸安二年十一月，妖贼卢悚遣弟子殿中监许龙晨到其门，称太后密诏，奉迎兴复。帝初欲从之，纳保母谏而止，因叱左右缚之，龙惧而走。许龙或即许迈同族，卢悚者即卢循同族，提出以见东晋末年天师道与政治之关系。
- **论证推导：** 卢循为五斗米道，先由“妖贼帅”与娶孙恩妹可以直接坐实；范阳卢氏是否世奉，则用琅邪太守、刘琨姻戚、赵王伦集团这组家世环境来推“殊有可能”，再用“不致与妖寒孙氏联姻”来加强“世家”的推测。卢悚、许龙一条，用来说明东晋末年天师道一再介入皇位兴复，不是孙恩一次孤立事件。
- **核心结论：** 卢循必为五斗米道信徒；范阳卢氏疑亦世奉五斗米道，与孙氏同为五斗米道世家。卢循与孙恩的结合，宗教与阶级（同为失类、同被目为妖寒/荒伧）是叠合的。
- **延伸推论：** 若无宗教婚媾，仅凭范阳高华，卢氏本不必与琅邪低下的孙氏合作；乱事的核心组织是教，不是旧门第。

### 四、徐道覆：表面似贵族，过江晚，婚宦失类，等于寒人

- **论据 / 案例 / 事实：** 《魏书》九十七《岛夷刘裕传》有“琅邪人徐道覆”之谓。实际徐道覆当为东海人。东海与琅邪甚近，均隶徐州。东海徐氏郡望颇高，在南北朝时出过不少有名的人物。《南史》三十二《张邵传》有东海徐文伯、徐嗣伯。徐文伯之父徐道度为兰陵太守，以善疗疾有名于宋文帝之时。祖徐秋夫，仕至射阳令；曾祖徐熙，仕至濮阳太守，亦以医术著名。徐文伯与徐嗣伯为从兄弟，得家传医学。《北史》九十《艺术传下》又有《徐謇传》及徐謇从孙《之才传》。徐謇为徐文伯之弟。徐之才为徐雄之子、徐文伯之孙，以医术著名于北齐，位至侍中、太子太师。东海徐氏自徐熙以来，世传医学。此当与天师道有关。《南史·徐文伯传》称徐熙“好黄、老，隐于秦望山，有道士过，求饮，留一葫芦与之，曰：‘君子孙宜以道术救世，当得二石。’熙开之，乃《扁鹊镜经》一卷，因精心学之，遂名震海内。”从中不难看出东海徐氏精医术及与天师道的关系。徐道覆其为五斗米道信徒，可以无疑。徐道覆像卢循一样，表面似贵族，然过江晚，婚宦失类（徐为卢的姊夫），等于寒人。
- **论证推导：** 把徐道覆从“琅邪人”订正为东海人，是为了接到东海徐氏世传医学、好黄老、受道士《扁鹊镜经》这一条线上，从而证明其五斗米道身份。姊夫关系则把他织进孙—卢的婚姻网。
- **核心结论：** 与孙恩、卢循一同起兵的徐道覆，为五斗米道信徒，社会位置等于寒人。
- **延伸推论：** 三人组合是：低下/失类的北人 ＋ 五斗米道世家网络 ＋ 海滨地理。后面陈霸先用三吴土著、始兴溪子为武将，与卢循“三吴旧贼”“始兴溪子，拳捷善斗”正同，说明这类武力以后还会再出。

### 五、孙恩何以能在东晋末年起兵于江东：先看五斗米道在上下层的发展

- **论据 / 案例 / 事实：** 《资治通鉴》一百十五晋安帝义熙六年称卢循“所将之众，皆三吴旧贼，百战余勇，始兴溪子，拳捷善斗，未易轻也”（何无忌参军殷阐语）。“三吴旧贼”是指原孙恩所部而言。关于孙恩何以能在东晋末年起兵于江东，要明白东晋末年五斗米道在江东的发展，特别要明白五斗米道在江东上层阶级中的发展。东晋在淝水之战以后，司马道子与司马元显父子当政，政治十分腐败，世族的奢侈直追西晋贵族，下层吴人由于“役、调深刻”（闻人奭语，见《晋书》六十四《会稽文孝王道子传》）十分痛苦。孙恩的叔父孙泰在江东行五斗米道，孙泰“浮狡有小才，诳诱百姓，愚者敬之如神，皆竭财产，进子女，以求福庆”。他得到了下层吴人的信仰。更有进者，上层吴人甚至连皇帝孝武帝、当政者司马道子父子也信仰他。《晋书·孙恩传》在说了百姓敬仰孙泰之后，又说：王珣言于会稽王道子，流之于广州。广州刺史王怀之以泰行郁林太守，南越亦归之。太子少傅王雅先与泰善，言于孝武帝，以泰知养性之方，召还。道子以为徐州主簿，犹以道术眩惑士庶。稍迁辅国将军、新安太守。黄门郎孔道、鄱阳太守桓放之、骠骑谘议周勰等皆敬事之，会稽世子元显亦数诣泰求其秘术。
- **论证推导：** 这说明司马道子虽从王珣之言，暂流孙泰于广州，但后来仍召还任用，曾以之担任主簿、将军、太守等职。孝武帝、司马道子、司马元显以下许多官吏之所以都对孙泰青眼相看，是因为他们都需要五斗米道。下层因役调深刻而“竭财产、进子女，以求福庆”；上层因需要养性、秘术而敬事之。教团因此同时咬住士与庶。
- **核心结论：** 孙泰所集徒众，是三吴的士与庶。五斗米道在江东上层阶级中的发展，是孙恩能起兵的前提。
- **延伸推论：** 朝士皆惧泰为乱，以其与元显交厚，咸莫敢言——上层信仰本身就构成政治保护，直到会稽内史谢輶发其谋。

### 六、司马道子厚爱五斗米道：服食长生，不惜降节

- **论据 / 案例 / 事实：** 《晋书》八十四《王恭传》：吴兴内史虞啸父妻裴氏有服食之术，常衣黄衣，状如天师。道子甚悦之，令与宾客谈论，时人皆为降节。恭抗言曰：“未闻宰相之坐有失行妇人。”坐宾莫不反侧，道子甚愧之。
- **论证推导：** 这说明司马道子之厚爱孙泰或五斗米道，在于五斗米道有“服食之术”，得之可以长生。如此秘术，如能求得，虽降节于五斗米道失行妇人，又有何惜？其他官吏之爱敬五斗米道，亦可作如是观。
- **核心结论：** 上层信仰的具体内容是服食、养性、长生，不是一般的“迷信”空话。
- **延伸推论：** 王恭抗言只能使道子“甚愧”，不能切断宰相与天师道的关系；政治中心已经被秘术吸住。

### 七、孝武帝与司马道子皆长育于天师道环境：简文帝求嗣

- **论据 / 案例 / 事实：** 孝武帝与会稽王为兄弟。关于他们的出生，《晋书》三十二《孝武文李太后传》：始简文帝为会稽王，有二子，俱夭。自道生废黜，献王早世，其后诸姬绝孕将十年。帝令卜者扈谦筮之，曰：“后房中有一女，当育二贵男，其一终盛晋室。”时徐贵人生新安公主，以德美见宠，帝常冀之有娠，而弥年无子。会有道士许迈者，朝臣时望多称其得道。帝从容问焉，答曰：“当从扈谦之言，以存接纳之道。”帝然之，更加采纳。又数年无子。乃令善相者召诸爱妾而示之，皆云“非其人”。又悉以诸婢示焉。时后为宫人，在织坊中，形长而色黑，宫人皆谓之“昆仑”，既至，相者惊云：“此其人也。”帝以大计，召之侍寝，遂生孝武帝及会稽文孝王及鄱阳长公主。
- **《真诰》（涵芬楼重印道藏本）八《甄命授》第四：** 我按九合内志文曰：竹者为北机上精，受气于玄轩之宿也。所以园虚内鲜，重阴含素。亦皆植根敷实，结繁众多矣。公（后注：凡云公者，皆简文帝为相王时也）试可种竹于内北宇之外，使美者游其下焉。尔乃天感机神，大致继嗣，孕既保全，诞亦寿考。……六月二十三日中候夫人告公（孝武壬戌生。此应是辛酉年）。灵草荫玄方。仰感旋曜精。洗洗繁茂萌。重德必克昌。紫微夫人作。福和者当有二子。盛德命世。（福和似是李夫人贱时小名也。今《晋书》名俊容，二子即孝武并弟道子也。按，俊容，《晋书·孝武文李太后传》作陵容，当据此改正。）同夜中候告。（右三条杨书。）
- **《太平御览》六百六十六引《太平经》：** 濮阳者不知何许人。事道专心，祈请皆验。简文帝为世子无嗣时，使人祈请于濮阳。于是中夜有黄气起自西南，遥入室。尔时李皇后怀孝武。（刘敬叔《异苑》四亦载此事。）
- **论证推导：** 据上引简文帝求嗣的事，可知孝武帝及会稽王司马道子，皆长育于天师道环境中。简文帝字道万，其子又名道生、道子，俱足证其与天师道的关系。六朝人最重家讳，而“之”“道”等字则在不避之列，所以然之故，虽不能详知，要是与宗教信仰有关。孝武帝名曜，字昌明，其名字皆见于上引《真诰》紫微夫人诗中。此诗为后来附会追作，或竟实有此诗，简文即取其中之语以名其子，皆可不必深论。但可注意的是天师道对于竹的为物，极称赏其功用。琅邪王氏世奉天师道，世传王子猷（王徽之）好竹（见《世说新语·简傲》、《太平御览》三百八十九引《语林》及《晋书》八十《王徽之传》等），疑不仅为高人逸致，或亦与宗教信仰有关。
- **核心结论：** 孝武帝与司马道子所以信仰五斗米道，因为他们从出生起就在天师道环境中；皇室中心人物早成天师道的信徒。
- **延伸推论：** 晋代天师道传播于世胄高门，本为隐伏的势力，若渐染及于皇族，则政治上立即发生巨变。西晋赵王司马伦的废惠帝而自立，是其一例，前已证明。东晋孙恩之乱，其主因亦由于皇室中心人物早成天师道的信徒。

### 八、孙泰欲起、孙恩发动：士庶多从，八郡响应

- **论据 / 案例 / 事实：** 《晋书·孙恩传》在谈到孙泰深得东晋统治者敬仰后，曾云：泰见天下兵起，以为晋祚将终，乃扇动百姓，私集徒众，三吴士庶多从之。于时朝士皆惧泰为乱，以其与元显交厚，咸莫敢言。会稽内史谢輶发其谋，道子诛之。恩逃于海。众闻泰死，惑之，皆谓蝉蜕登仙，故就海中资给。恩聚合亡命得百余人，志欲复仇。及元显纵暴吴会，百姓不安，恩因其骚动，自海上攻上虞，杀县令，因袭会稽，害内史王凝之，有众数万。于是会稽谢鍼、吴郡陆瓌、吴兴丘尪、义兴许允之、临海周胄、永嘉张永及东阳、新安等凡八郡，一时俱起，杀长吏以应之，旬日之中，众数十万。起来响应孙恩的陆瓌，出于吴郡四姓之一的陆氏；谢鍼，出于会稽四姓之一的谢氏；丘尪出于吴兴著姓丘氏；他们都是士族。
- **论证推导：** 孙泰欲起兵，是因为五斗米道不仅已取得江东庶民而且已取得江东士族的信仰。孙泰所集徒众，是三吴的士与庶。孙泰虽然未及发动，但他的侄儿孙恩毕竟发动了。在孙泰欲起兵之前，五斗米道已成为一种隐伏于朝野的大势力。乘天下兵起，皇帝中心人物耽溺于五斗米道的秘术，孙泰叔侄认为足可发动群众，一试锋芒。杀害王凝之，也落在天师道世家的语境里（王凝之出于世奉天师道的琅邪王氏，本章以“害内史王凝之”作为起兵过程的事实）。八郡响应而以吴郡陆、会稽谢、吴兴丘这些士族具名为代表，用来证明响应者不是只有“愚者”。
- **核心结论：** 孙恩、卢循之乱因此发生。换言之，五斗米道向士族特别是向皇室中心人物传播成功之日，也就是五斗米道的教主及上层人物（多半是如同陆瓌、谢鍼等的士族人物）最理想的发动叛乱之时。
- **延伸推论：** 元显纵暴吴会是直接导火索，但若无朝野隐伏的大势力，海上百余人不可能旬日之间变成数十万。

### 九、五斗米道特征：长生人、烧邑刊井、投水成仙

- **论据 / 案例 / 事实：** 《晋书·孙恩传》：于是恩据会稽，自号征东将军，号其党曰“长生人”。诸贼皆烧仓廪，焚邑屋，刊木埋井，虏掠财货，相率聚于会稽。其妇女有婴累不能去者，囊麓盛婴儿投于水，而告之曰：“贺汝先登仙堂，我寻后就汝。”刘裕与刘敬宣并军击之于郁洲，恩遂远进海中。及桓玄用事，恩复寇临海，太守辛景讨破之。恩穷蹙，乃赴海自沉，妖党及妓妾谓之“水仙”，投水从死者百数。《晋书》八十四《刘牢之传》：恩浮海奄至京口，战士十万，楼船千余。闻牢之已还京口，乃走郁洲。
- **论证推导：** “长生人”不是普通的部曲称号，而是宗教种民。《太平经》谓种民为圣贤长生之类；天师道追求白日升天、长生世上。烧仓焚屋、刊木埋井，是把现世产业毁掉，与“先登仙堂”的来世逻辑一致。妇女投儿于水、孙恩自沉、妓妾从死，把死亡说成登仙，使军事失败转化为宗教完成。
- **核心结论：** 孙恩、卢循起兵的五斗米道特征表现得很突出：“长生人”是教称，投水是水解成仙。
- **延伸推论：** 刘裕后来率京口楚子平孙、卢，既是军事结局，也是江左政权转入楚子之手的起点。

### 十、何以是海屿“妖贼”：郁洲神仙、水师、琅邪旧巢、水解

- **论据 / 案例 / 事实：** 郁洲为孙恩栖泊之所。《抱朴子·内篇》四《金丹》以徐州之郁洲为海中大岛屿。《水经注》三十《淮水篇》：东北海中有大洲谓之郁洲，《山海经》所谓郁洲在海中者也。言是山自苍梧徙此云，山中犹有南方草木。崔季珪之叙《述初赋》言：郁洲者故苍梧之山也；闻其工有仙士石室，乃往观焉，见一道人独处休休然，不谈不对。据此，可知郁洲之地为神仙居处，而适与于吉、宫崇的神书（《太平清领书》）所出处至近。孙恩、卢循武力以水师为主，所率徒党必多习于舟楫之海畔居民。其以投水为登“仙堂”，自沉为成“水仙”，来源于五斗米道尸解之说。尸解有刀、兵、水、火之解（见《太平御览》六百六十四《道部·尸解》引《登真隐诀》）。孙恩以投水为成水仙，是水解之说。尸解于孙恩之所以表现为水解，与滨海地区琅邪五斗米道的发生、发展有关。孙氏本出琅邪，而琅邪为于吉、宫崇神书所出之地。水仙之说为海滨宗教之特征。西晋末年赵王司马伦之败，孙秀等“或欲乘船东走入海”（《晋书》五十九《赵王伦传》），即后来其族人孙恩败则入海、返其旧巢之惯技。
- **论证推导：** 地理（郁洲近神书所出、海屿可栖泊）、武力形态（楼船、海畔居民）、宗教技术（水解）、家世惯技（孙秀欲入海）四条收束到同一点：海屿“妖贼”不是偶然遭际。
- **核心结论：** 孙恩卢循之所以为海屿“妖贼”，是因为有环境的熏习，家世的遗传，非一朝一夕偶然遭际所致。
- **延伸推论：** 从赵王伦到孙恩，琅邪孙氏的政治一宗教活动有一条连续线：得势则乱朝，失势则入海。第四篇与第十篇应合读。

## 史料用法与讲授细节

1. **三方面开场：阶级、宗教、地理，不可单线。** 先钉三人的社会位置，再证五斗米道，再讲海屿水解。
2. **孙恩先回第四篇。** 孙秀小吏、潘岳不以人遇、随赵王伦造反，用来说明琅邪孙氏本低下且有叛逆标记；土断说明孙恩已成南方低下阶级；孙泰则说明教权可以抬出将军、太守。
3. **卢循用“名族—失类—荒伧”三段。** 卢谌嘱子但称晋司空从事中郎，是“沦陷非所”的自我羞耻。杨佺期、杜坦不是旁支故事，而是证明排抑晚渡是普遍现象，连皇帝也不能改。
4. **卢氏奉道用“直接证据＋家世可能＋婚媾反证”。** 妖贼帅、娶孙恩妹为直接；卢钦琅邪太守、刘琨姻戚、赵王伦集团为可能；“奕世高华不致与妖寒联姻”为反证。讲授时须标明“疑”“殊有可能”，不要把推测说成铁证。
5. **卢悚、许龙只提出以见天师道与政治之关系。** 许龙或即许迈同族，卢悚即卢循同族，点到为止。
6. **徐道覆：先订正籍贯，再接东海徐氏医学—黄老。** 《魏书》称琅邪人，讲者订为东海；《扁鹊镜经》、道士留葫芦，用来连天师道。徐为卢姊夫，等于寒人。
7. **殷阐“三吴旧贼、始兴溪子”一条，既解释卢循兵力，又预示陈霸先用同类武力。**
8. **孙泰传要读出“流放—召还—官职—秘术”的反复。** 王珣请流广州，王雅以养性之方召还，道子用为徐州主簿、辅国将军、新安太守；孔道、桓放之、周勰敬事，元显求秘术。上层需要五斗米道，是反复的原因。
9. **裴氏衣黄衣状如天师，用来把“需要”落实为服食长生。** 王恭抗言是反衬。
10. **求嗣一组材料最密：《晋书》李太后传、《真诰》种竹与紫微夫人诗、《太平御览》引《太平经》黄气入室、《异苑》。** 孝武名曜、字昌明见于诗中，附会或实有皆不必深论；重点是长育于天师道环境。福和／俊容／陵容的名字校正，是讲授中的文献细节。
11. **王徽之好竹，疑与天师道称赏竹之功用有关，不仅是高人逸致。** 琅邪王氏世奉天师道，与此相接。
12. **起兵经过要强调：士庶多从；朝士因元显交厚莫敢言；泰死而众谓蝉蜕登仙；元显纵暴为导火索；八郡士族具名响应。**
13. **宗教特征与地理特征应分开讲再合并。** 长生人←《太平经》种民、《释老志》长生；水解←《登真隐诀》尸解门类；郁洲←《抱朴子》《水经注》《述初赋》；入海惯技←赵王伦传孙秀欲乘船东走。
14. **刘牢之传的战士十万、楼船千余，用来证水师为主、徒党多为海畔居民。**
15. **收束句必须落到“环境熏习、家世遗传，非偶然遭际”。** 这是本章对“妖贼”二字的历史化。

## 知识点全量梳理

- 孙恩、卢循之乱须从社会阶级、宗教信仰、地理关系三方面看。
- 孙恩：赵王伦谋士琅邪孙秀族人；孙秀本琅邪小吏，遭潘岳挞辱，“不以人遇之”，随伦造反；孙氏低下且有叛逆；孙恩世居南方，土断后为南方低下阶级；叔父孙泰为将军、太守，以五斗米道得三吴士庶信仰；孙恩为其继承者。
- 卢循：字于先，小名元龙，卢谌曾孙；范阳涿人，名族；卢谌沦陷后赵，嘱子但称晋司空从事中郎；婚宦失类，子孙过江晚。
- 晚渡必婚宦失类，失类即被鄙视，不论往者是否名族。
- 杨佺期：弘农杨震之后，自云江表莫比，比王珣犹恚恨；晚过江，婚宦失类，每被排抑；桓玄以寒士裁之。
- 元嘉二十三年通鉴语：王谢方盛，晚渡北人悉以伧荒遇之，不得践清途。
- 杜坦：杜预之后，先世播迁凉土，以南渡不早被荒伧赐隔；告孝武帝，帝默然。
- 卢循在江东士族心目中只是荒伧，与杨佺期、杜坦一类。
- 孙氏自孙秀至孙恩世奉五斗米道。
- 卢循为“妖贼帅”，娶孙恩妹，故必为五斗米道。
- 卢钦累迁琅邪太守；琅邪为五斗米道发祥地之一（于吉、宫崇、孙秀）。
- 卢谌从母为刘琨妻；琨父子兄弟为赵王伦所委任；刘琨与孙秀子会率宿卫拒成都王颖。
- 卢氏家世环境殊有奉天师道之可能；又因不致与妖寒孙氏联姻，疑卢氏亦世奉，与孙氏同为五斗米道世家。
- 咸安二年妖贼卢悚遣许龙称太后密诏迎海西公；许龙或许迈同族，卢悚即卢循同族。
- 《魏书》称徐道覆琅邪人，实当为东海人；东海与琅邪近，均隶徐州。
- 东海徐氏郡望高：徐熙、秋夫、道度、文伯、嗣伯、謇、之才，世传医学；徐熙好黄老，得道士《扁鹊镜经》。
- 徐道覆为五斗米道信徒无疑；为卢循姊夫；过江晚，婚宦失类，等于寒人。
- 卢循所将：三吴旧贼（原孙恩所部），始兴溪子拳捷善斗；与后来陈霸先用三吴土著、始兴溪子（如侯安都）为武将正同。
- 淝水战后司马道子、元显当政，政治腐败，世族奢侈直追西晋，下层吴人役调深刻。
- 孙泰浮狡有小才，诳诱百姓，愚者敬如神，竭财产进子女求福庆；得下层吴人信仰。
- 上层亦信仰：王珣请流广州，王怀之使行郁林太守，南越亦归之；王雅以知养性之方言于孝武，召还；道子用为徐州主簿、辅国将军、新安太守；孔道、桓放之、周勰敬事；元显数求秘术。
- 道子厚爱五斗米道，因有服食之术可长生；裴氏衣黄衣状如天师，道子令与宾客谈论；王恭斥宰相之坐有失行妇人。
- 简文帝求嗣：二子俱夭，诸姬绝孕将十年；扈谦筮后房有女当育二贵男；许迈劝从扈谦、存接纳之道；相者指织坊黑长宫人“昆仑”（李陵容，贱时小名或作福和，《真诰》作俊容，《晋书》作陵容）；生孝武、道子、鄱阳长公主。
- 《真诰》教简文种竹于内北宇之外以求继嗣；紫微夫人诗有曜、昌明、二子盛德命世；或附会或实有，不必深论。
- 《太平经》／《异苑》：濮阳祈请，黄气自西南入室，李皇后怀孝武。
- 孝武、道子皆长育于天师道环境；简文字道万，子名道生、道子；“之”“道”不避家讳，与宗教信仰有关。
- 天师道极称赏竹；王徽之好竹，疑与宗教信仰有关；琅邪王氏世奉天师道。
- 天师道染及皇族则政治巨变：赵王伦废立为一例；孙恩之乱主因亦皇室中心人物早成信徒。
- 孙泰见天下兵起，以为晋祚将终，私集徒众，三吴士庶多从；朝士惧而不敢言；谢輶发谋，道子诛泰；众谓蝉蜕登仙，海中资给。
- 孙恩聚合亡命百余人复仇；因元显纵暴吴会，海上攻上虞，袭会稽，害王凝之，众数万。
- 八郡响应：会稽谢鍼、吴郡陆瓌、吴兴丘尪、义兴许允之、临海周胄、永嘉张永及东阳、新安；旬日众数十万。陆、谢、丘皆士族。
- 五斗米道隐伏朝野，乘皇室耽溺秘术而发动。
- 孙恩自号征东将军，党号“长生人”；烧仓焚屋，刊木埋井，虏掠聚会稽。
- 妇女投婴儿于水，贺其先登仙堂；恩赴海自沉，从死者谓之水仙。
- 刘裕、刘敬宣击之于郁洲；桓玄时复寇临海，辛景破之。
- 浮海至京口，战士十万，楼船千余；闻刘牢之还，走郁洲。
- 郁洲：徐州海中大岛，灌云东北；《山海经》郁洲在海中，传自苍梧徙来；有仙士石室；近于吉、宫崇《太平清领书》出处。
- 武力以水师为主，徒党多海畔习舟楫之民。
- 投水成仙来自尸解；孙恩为水解；与琅邪滨海五斗米道相关；水仙为海滨宗教特征。
- 赵王伦败，孙秀等欲乘船东走入海，即孙恩败则入海返旧巢之惯技。
- “长生人”＝种民；天师道追求长生世上、白日升天；汉阴长生、晋范长生以长生为名。
- 海屿“妖贼”出于环境熏习、家世遗传，非偶然。

## 题外话

除了本章主要内容外，作者还讨论了/提及了：1. 潘岳“不以人遇”孙秀、杨佺期恨人以门地比王珣、桓玄以寒士裁佺期，以及杜坦当面向孝武帝陈“荒伧赐隔”而帝默然不应，2. 海西公时卢悚、许龙称太后密诏奉迎兴复，许龙或即许迈同族，以及东海徐熙隐秦望山得道士《扁鹊镜经》、徐氏医学延至北齐徐之才，3. 裴氏衣黄衣状如天师而宰相降节、李太后在织坊中形长色黑被呼“昆仑”、《真诰》福和／俊容／陵容的异文校正、王徽之好竹或非仅高人逸致，以及阴长生、范长生之以“长生”为名、崔季珪《述初赋》中郁洲仙士石室不谈不对的道人。
