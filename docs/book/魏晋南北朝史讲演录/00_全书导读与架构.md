# 全书导读与架构

## 书是什么、笔记如何读

《魏晋南北朝史讲演录》是万绳楠一九四七年至一九四八年在北平清华大学历史研究所，听陈寅恪讲述魏晋南北朝史时所作的听课笔记，一九八六年整理出版。整理时参考了五十年代高等教育部代印材料，以及《金明馆丛稿初编》《二编》等已刊论文，力求符合讲授观点；万绳楠同时声明：本稿终究是笔记，不能称为陈寅恪的著作，错误由整理者负责。

> 💡 文本性质、整理原则与万绳楠的史学史判断，详见：[00_整理说明.md]

本扫描件为超星/SSReader 打印的图像 PDF，无文字层；笔记据中文 OCR 整理。目录中的「编后」在本扫描件中没有独立正文，全书止于第二十一篇「佛教之于四声」之末（原书约第 368 页）。OCR 有形近错字与个别残句，笔记已据上下文订正专名，但不把订正后的引文当作精确校勘本。

## 一条主线、三组问题

全书不是按皇帝年表平铺的断代通史，而是用**阶级分析与集团分析**（万绳楠认为集团分析实际上也是阶级分析）把三百年史事串成问题链。开篇第一句方法论就是：魏晋兴亡不是两姓胜败，而是儒家豪族与非儒家寒族的胜败。

由此展开三组互相咬合的问题：

1. **谁在统治、凭什么统治**  
   士族与寒族、名教与法术、清谈与格义、天师道、恩幸与官制。南方的答案从东晋与吴姓结合，转到北府楚子，再转到梁末士族覆灭与陈朝溪、俚武力；北方的答案从崔浩「齐整人伦」转到孝文帝汉化，再转到六镇反动、高齐鲜卑化/西胡化、宇文氏关陇集团。

2. **胡与汉如何分开、又如何合一**  
   「民族以文化分，不是以血统分」是贯穿胡族诸篇的总原则。徙戎、五胡种姓、汉化与胡汉分治、坞壁、人口三向流动，都是在问：部落解散没有、兵民分开没有、文化改了没有。北朝不能过早统一南北，关键往往不在「南军太弱」，而在北方内部的民族与兵制问题尚未解决。

3. **文物、宗教、声音如何移动**  
   江陵陷落后南学北传、关陇用《周礼》另造精神系统、佛教作为「夷」的律度集团插入华夏、寇谦之清整天师道、转读佛经三声与永明四声，是同一套「文化交流可以指认其输入与拟配」的方法，收到学术史与文学史上。

前言预先点出的三个「新问题」，可当作阅读路标：

- 民族以文化分，不以血统分 → 第六、七、十五至十九篇  
- 陈朝是南方蛮族创立的朝代 → 第九、十一、十二篇  
- 东汉、袁绍、孙吴、西晋统治者属于同一阶级 → 第一篇附论吴、蜀

## 建议读法

1. **若只取方法**：整理说明 → 第一篇 → 第七篇（文化分民族）→ 第十二篇（陈朝与蛮族）→ 第十七、十九篇（六镇与关陇）。  
2. **若跟江左一条线**：第一篇附论吴 → 第八、九、十、十一、十二、十三篇。  
3. **若跟北朝一条线**：第五至七篇 → 第十四至十九篇。  
4. **若跟宗教与学术**：第三篇格义 → 第四、十篇天师道 → 第二十、二十一篇。

各篇已按「自闭环」写过：术语先补，跨章只用引用块指向对应文件，不必按页码翻原书也能读完一章。

## 讲授方法上可反复看见的操作

- 先定**社会阶级/集团**，再解释政策、时尚、宗教与制度，不把一姓兴亡当终点。  
- 引书必落到纪传、志、注、类书；对《通鉴》删文、胡注、旧谱，常反过来证明「不了此处」。  
- 种族问题先问：原姓还是改姓、部落解散没有、语言与葬地在哪里。  
- 佛教、道教、四声，都还原为可以指认的输入、拟配与再造，而不是空论哲理。
