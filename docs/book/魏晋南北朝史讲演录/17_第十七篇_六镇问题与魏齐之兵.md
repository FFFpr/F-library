# 第十七篇 六镇问题（附魏齐之兵）

## 本章定位与核心主张

本篇把“六镇”从边防地名做成北朝后期历史的总枢纽：**不仅要注意防北（柔然），而且要注意防南；不仅要注意防边，而且要注意六镇对南北朝乃至隋、唐历史的影响。六镇起兵最大的现实问题，在改变了北朝的历史。**

全文六节合成一条长链：

1. **六镇的含义有时代性**：原指怀朔、武川、抚冥、柔玄、怀荒、沃野，后来变为北方城镇的总称，应该是“六镇及其他”。北魏设防本是甸服四面设防，南方威胁一度比柔然更重；州置营户是防要害、尤其防南的旧制。破六韩拔陵败后把降户二十万置于冀、定、瀛，不是简单失策，而是旧制加现实（不能把人送到已兴起的尔朱氏势力范围）。
2. **北魏的兵分鲜卑兵与非鲜卑兵**：禁旅与六镇将卒多为代北部落苗裔，有贵族性；非鲜卑兵中最重要的是高车（敕勒），六镇兵中主要者似为高车，且高车部落未解散，故镇兵保持部落性质、特别善战。此外有丁零、胡、氐、羌及被迫当兵的汉人、吴人。兵民分开，兵主要用于防守打仗，民从事耕桑；兵民之分在这个意义上也就是胡汉之分。
3. **六镇起兵最重要的原因**：镇人原有三重特性——职业为军人、社会阶级为贵族、种族文化为鲜卑。孝文帝迁洛后，职业军人与鲜卑文化未变，社会阶级被降为府户，仕宦、复除权没有了。洛阳羽林虎贲因张仲瑀请排抑武人而暴打张家，是六镇起兵的前奏。正光五年丙申诏把有军贯者都看作低下阶级府户，虽说免为民、改镇为州，仍要三五简发去打仗，使强宗子弟、良家酋帅彻底失望，火上加油。**就基本性质来说，六镇之叛是对孝文帝汉化政策的一大反动。**
4. **六镇兵三次转手**：破六韩拔陵 → 葛荣 → 尔朱荣（尔朱兆）→ 高欢。高欢“因之以成大业”，建立东魏与北齐。北齐所领“六州”即六镇及其他。宇文泰是武川镇人，西魏北周也与六镇军人有关。六镇军人是北齐、北周的统治者；从这个意义上说，起兵提高了六镇军人的地位。
5. **北齐的兵**：东魏及北齐之初承北魏，兵民分离，鲜卑当兵、汉人耕织。文宣帝有“百保鲜卑”与华人“勇士”，有所创革，但未改兵民、胡汉之分。河清三年令：十八受田输租调，二十充兵，把军镇与州县、当兵与种田结合起来，胡人当兵、汉人耕织及军镇与州县分治的时代过去，这是北朝兵制上的很大变化。
6. **杨隋、李唐并非出自六镇**：高齐出怀朔、宇文出武川，旧史明文无疑；杨忠高祖曾为武川镇司马，不能据此谓杨氏出自武川；李氏自称家于武川，但李熙、李天赐葬赵州昭庆，碑称“维王桑梓”，葬地即家世居住地，与武川说不合。

## 关键概念补全（术语先讲）

**六镇的时代性。** 用“六镇”这个名词，应注意它的时代性，不然便不能了解它的含义。六镇原指怀朔、武川、抚冥、柔玄、怀荒、沃野；后来变为北方城镇的总称，应该说是“六镇及其他”。后文北齐的“六州大都督”“六州流民大都督”所领恒、云、燕、朔、显、蔚等州，就是北边军镇改置的州，既是六镇兵所出之地，又是六镇流人聚居之处——仍是“六镇及其他”。前人每注重六镇设立在北御柔然；本篇要求同时看防南、防边，以及它对南北朝至隋唐的影响。

**甸服四面设防。** 《元和郡县图志》云州条：道武帝建都于此，东至上谷军都关，西至河，南至中山隘门塞，北至五原，地方千里，以为甸服。甸服四面都在设防之列。北魏尚未取得青徐之时，南方威胁比之于北方柔然的威胁，似乎还要重些，因此必须防南。

**军府与营户。** 道武帝平中山后，多置军府以相威摄。定州凡有八军，军各配兵五千，食禄主帅军各四十八人；中原稍定，八军之兵渐割南戍，一军兵才千余，然主帅如故。杨椿表罢四军，减帅一百八十四人。州有宗子稻田，屯兵八百户，年常发夫三千、草三百车修补堤堰；椿以屯兵惟输此田课、更无杂役，闲月即应修治，不容复劳百姓，亦表罢，朝廷从之。屯兵从何而来？配降人为营户，是北魏旧制：太平真君五年北部民杀莫孤、率五千余落北走，追击后余众徙居冀、相、定三州为营户；延兴元年沃野、统万二镇敕勒叛，徙其遗迸于冀、定、相为营户；延兴二年连川敕勒谋叛，徙配青、徐、齐、兖为营户。营户不限于哪一州，各州都有。州置营户为北魏防要害的政策；冀、定、相配置营户，正是为了防南，且有利于发卒南讨（太和二十一年诏冀、定、瀛、相、济五州发卒二十万将以南讨）。

**代北部落之苗裔。** 《文献通考·兵考》：（北魏）兵戎乃其所以为国；羽林、虎贲则宿卫之兵，六镇将卒则御侮之兵，往往皆代北部落之苗裔，其初藉之以横行中国。自注：孝文诏军士自代来者皆以为羽林、虎贲。“代北部落”指三十六大部落、九十九小部落。《魏书·序纪》成皇帝毛“统国三十六，大姓九十九”；《官氏志》亦谓安帝统国，诸部有九十九姓。禁旅与六镇将卒多由他们担当，这是鲜卑兵。这种兵带贵族性，地位颇高，“不但不废仕宦，至乃偏得复除”（《广阳王深传》）。不过到孝文帝迁洛实行汉化之后，地位有改变。

**复除。** 指免除赋役。镇人当初“偏得复除”，是贵族性的经济特权；太和以后失去复除，与“号曰府户、役同厮养”连在一起。

**高车 / 敕勒 / 狄历 / 丁零。** 《魏书·高车传》：高车初号狄历，北方以为敕勒，诸夏以为高车、丁零；其语略与匈奴同而时有小异，或云其先匈奴之甥。太祖时分散诸部，唯高车以类粗犷、不任使役，故得别为部落。北魏解散部落，高车为一例外。非鲜卑兵中最重要的是高车兵；禁军中有高车羽林郎将、高车虎贲将军、高车虎贲将等官，为禁军中有高车军之证。羽林、虎贲之名到孝文帝才有，但禁军与禁军中有高车兵，则魏初以来已是如此。六镇兵中主要者似为高车人。高车有东西二部，六镇以西部高车居多数；西部即恒州代郡之西，沃野、怀朔、武川等镇均在代西。沃野、统万二镇敕勒即西部高车。叱列延庆“代西部人也，世为酋帅”；《通鉴》有西部高车叱列杀鬼，可知叱列氏为西部高车。斛律洛阳为西部敕勒；高祖斛律倍侯利道武时率户内属，父斛律那为第一领民酋长，斛律氏亦西部高车。柔玄镇有“二部敕勒”，即高车东西二部。

**未改姓与部落未解散。** 孝文帝所改汉姓，大体仍保持胡姓者如慕容氏，但是少数。未改姓的，多是部落未解散的，且多是未迁至洛阳而仍留在边镇的人。此种人以高车为多，但不限于高车，如斛律氏、贺拔氏、库狄氏等。斛律氏未见改姓；贺拔氏《官氏志》后改为何氏，然边镇贺拔允、贺拔胜、贺拔岳仍姓贺拔；库狄氏后改为狄氏，边镇库狄干、库狄洛、库狄盛、库狄昌、库狄丰乐仍姓库狄。六镇兵保持部落性质、特别善战，原因即在高车人多、部落未解散。在北魏的兵中，鲜卑（就纯血统言）之次，恐即高车。汉人为兵不占重要地位，重要的是鲜卑与高车军。

**国人与非国人（兵制含义）。** 拓跋焘与宋盱眙守将臧质书：今所遣斗兵尽非我国人；城东北是丁零与胡，南是三秦氐、羌；丁零死正可减常山、赵郡贼，胡死正减并州贼，氐羌死正减关中贼。所谓尽非我国人，即尽非代北鲜卑。非国人的少数民族兵除打仗，也用于戍守。尉元表：徐州戍兵多是胡人，前有呼延笼达、王敕负罪叛乱，宜以彭城胡军换取南豫州徙民之兵转戍彭城，又以中州鲜卑增实兵数。此种兵地位甚低。汉兵例：柳元景所俘二千余人多河内人，自言“虐虏见驱，后出赤族，以骑凌步，未战先死”；所谓以骑凌步，是北魏以鲜卑本部人为骑兵，以非国人为步兵，打仗以鲜卑骑兵压迫非鲜卑步兵先出。吴兵：毛修之没于统万，太武获之，以修之领吴兵讨蠕蠕大檀，拜吴兵将军、领步兵校尉。吴兵也是汉人为兵者。

**兵民分离 / 胡汉分治。** 《刘洁传》：郡国之民虽不征讨，服勤农桑，以供军国，实经世之大本，府库之所资。兵用于防守和打仗，民从事耕桑。《地形志》恒、朔、云、蔚、显、廓、武、西夏、宁、灵等十州，“永安已后，禁旅所出，户口之数并不得知”——因为它们都是军事重镇、军府所在，军人众多；所谓户口数指民户之数，不是军人之数，也表明兵是兵、民是民。北魏的兵主要由鲜卑及其他少数民族充当，农业主要由汉人担负；兵民之分在这个意义上也就是胡汉之分。《官氏志》：道武帝天赐元年诸州各置都尉以领兵；文成帝太安三年以诸部护军各为太守。这是兵民胡汉分治的反映。

**府户。** 魏兰根说：中年以来，有司乖实，号曰府户，役同厮养，官婚班齿，致失清流。本是有军贯的镇兵被登记、称呼成低贱的军户。元深说在镇者“便为清途所隔”。明帝正光五年丙申诏则把州镇凡是有军贯或军籍的人，都看作了低下阶级——府户；这与魏兰根“有司乖实，号曰府户”不同：前者是有司错误贬称，诏书却把贬称做成了官方定性。

**房分。** 一个姓的人有的去边镇当兵，有的留在京师当官，此之谓房分。元深：“往世房分，留居京者得上品通官，在镇者便为清途所隔。”魏兰根：“本宗旧类，各各荣显，顾瞻彼此，理当愤怨。”迁洛以后，留居平城的迁到洛阳，受汉化洗礼，各各荣显；到边镇当兵的被号为府户。

**改镇为州，罢削旧贯。** 李崇求改镇为州，意即将有军贯的兵改之为民，将特殊情形改为普通情形。魏兰根建议：改镇立州，分置郡县，凡是府户悉免为民，入仕次叙一准其旧，文武兼用，威恩并施，国家庶无北顾之虑。朝廷以“旧典难革”不许。丙申诏虽说“诸州镇军贯，元非犯配者，悉免为民，镇改为州”，但仍要“三五简发，讨彼沙陇”，所以不能起安抚作用。

**三五简发。** 按民丁比例抽兵（与第十四篇元嘉二十七年发“三五民丁”同一类说法）。镇人刚被“免为民”，立刻又按民丁法抽去打仗，等于贵族身份既已失去，连“免为民”的实惠也不完整。

**六镇镇人的三重特性。** 职业为军人，社会阶级为贵族，种族文化为鲜卑。迁都之后，职业军人、鲜卑文化二者未变，社会阶级则被降低。六镇一带无法汉化：军人仍是军人，胡化仍是胡化，社会地位在太和以后被降为府户。

**六镇兵三次转手。** 第一次：破六韩拔陵转到葛荣手上，葛荣赖之以继续与洛阳统治者作斗争。第二次：从葛荣转到镇压者尔朱荣手上，尔朱荣欲倚之壮大自己。第三次：从尔朱氏转到高欢手上，高氏赖之以建立东魏与北齐。《隋书·食货志》：“寻而六镇扰乱，相率内徙，寓食于齐、晋之郊，齐神武因之，以成大业。”

**尔朱氏与契胡。** 尔朱荣为北秀容羯人，保持部落组织，未改姓氏。先居于尔朱川，因为氏，常领部落，世为酋帅。高祖羽健，登国初为领民酋长，率契胡武士一千七百人从驾平晋阳、定中山，诏割方三百里封于秀容，长为世业。太祖欲迁之南秀容，羽健以北秀容差近京师、不愿更迁远地而止。“契胡”即羯胡，为魏收所改。这支北边羯人是落后的羯人；魏初解散部落，《官氏志》只记高车未解散，其实这支羯人部落也未解散。

**河阴之变。** 武泰元年四月，尔朱荣惑武卫将军费穆之说，引迎驾百官于行宫西北，云欲祭天，列骑围绕，责天下丧乱、明帝暴崩之由，纵兵杀害，王公卿士死者一千三百余人，皇弟、皇兄并亦见害，灵太后、少主其日暴崩。京邑士子不一存，率皆逃窜。杀洛阳朝士、逐京邑士子，是六镇鲜卑化军人的目的，尔朱荣代替他们办到了。费穆是禁军将领，禁军已经发动过反对张仲瑀求铨别选格的暴乱；杀朝士可以说是费穆假手羯胡武力完成的。

**齐晋之郊与六州。** 《隋书》所谓齐，指武州齐郡。钱大昕考：武州武定元年置，治雁门川；与繁畤等郡寄治有关。“齐晋之郊”即六镇镇人寓食之地，是尔朱氏的势力范围。北齐有“六州大都督”“领六州鲜卑酋长大都督”“六州流民大都督”；斛律金“领恒、云、燕、朔、显六州大都督”，钱大昕谓六州即神武所领六州兵，但六州之名尚少其一，史有脱文，盖脱蔚州。《孙搴传》“大括燕、恒、云、朔、显、蔚、二夏州、高平、平凉之民以为军士”，蔚州与上五州连称，可证《斛律金传》脱蔚州。这六州都是北魏以北边军镇改置的州。钱氏又谓：改镇为州，魏收史言之不详，惟怀朔改为朔州，怀荒、御夷改为蔚州，薄骨律改为灵州，见于《地形志》。概言之，六州即六镇及其他。

**百保鲜卑与勇士。** 魏武帝西迁，六坊之众从武帝而西者不能万人，余皆北迁。文宣受禅，六坊之内更加简练，每一人必当百人，任其临阵必死，然后取之，谓之“百保鲜卑”。又简华人之勇力绝伦者，谓之“勇士”，以备边要。说明文宣对兵制有所创革，但并未改变兵民（兵农）、胡汉之分的性质。

**河清三年令。** 邻居十家为比邻，五家为闾里，百家为族党。男子十八以上六十五以下为丁，十六以上十七以下为中，六十六以上为老，十五以下为小。率以十八受田、输租调，二十充兵，六十免力役，六十六退田、免租调。五兵尚书分掌宿卫、丁帐、蕃兵、河南潼关以东及河北潼关以西诸州发召征兵等。北魏均田、三长之后，就胡汉职业而言，胡人虽同为编户并被圈给土地，但仍不耕织，专讲骑射，耕织交给奴婢，状如清兵入关圈地之制；农业与纺织主要仍在汉人之手。河清三年把军镇与州县、当兵与种田结合起来，即兵由州县受田农民充当，兵民、兵农不再各成一个系统。

## 论证推理链

### （一）六镇含义及北魏的设防问题

**论点一：六镇一词有时代性，原为六名，后为北方城镇总称；研究六镇须同时看防北、防南及其对北朝至隋唐的影响。**

- **论据 / 案例 / 事实：** 原指怀朔、武川、抚冥、柔玄、怀荒、沃野；后来变为北方城镇总称，“六镇”应该是六镇及其他。前人每注重北御柔然。甸服东至军都关、西至河、南至隘门塞、北至五原，四面设防。未得青徐时，南方威胁似乎比柔然更重。《杨椿传》：平中山后多置军府，定州八军各五千，后渐割南戍，一军才千余而主帅如故；又有屯兵八百户。
- **推导：** 若把六镇只写成防柔然的北墙，就看不见南边军府之多、南防之重要，也看不见后来“六镇及其他”如何变成北齐“六州”兵源与流民概念。名词的时代性，就是制度史的阶段性。
- **结论：** 六镇研究必须突破“只防柔然”的习惯；起兵最大的现实问题是改变了北朝的历史。
- **延伸：** 防南的军府、营户布局，直接解释了拔陵败后降户为何被送冀、定、瀛，而不是送回恒州以北。

**论点二：配降人为营户是北魏旧制，为的是防要害、尤其防南；拔陵降户入冀定瀛，符合旧制与当时不能入尔朱之地的现实，不能简单说成失策。**

- **论据 / 案例 / 事实：** 真君五年北部民余众徙冀、相、定为营户；延兴元年沃野、统万敕勒遗迸徙冀、定、相为营户；延兴二年连川敕勒徙配青、徐、齐、兖为营户。太和二十一年冀、定、瀛、相、济发卒二十万南讨。破六韩拔陵来逼，广阳王深前后降附二十万人，与行台元纂表求在恒州北别立郡县安置，不从；诏杨昱分散之于冀、定、瀛三州就食。深谓：此辈复为乞活矣，祸乱当由此而作。既而鲜于修礼叛于定州，杜洛周反于幽州。或谓未从元深之言实为失策，鲜于修礼之起即出此。
- **推导：** 作者反驳：此种论点未注意历史情况与恒州以北现实情况。历史上，配置降户于冀、定、瀛等州为旧制，这些地方本有军府，可以安插降户。现实上，当时尔朱荣势力已在恒、代以北兴起，是一种半独立势力，北魏自不能把降户徙入尔朱氏所据之地。
- **结论：** 不能说北魏未从元深之言为失策。
- **延伸：** 降户入河北后，鲜于修礼、杜洛周仍起，说明旧制能“安插”不能“消化”；河北由此成为六镇兵力进入中原的跳板，为后文三次转手准备地理条件。

### （二）北魏的兵

**论点三：北魏兵有鲜卑与非鲜卑两种；鲜卑禁旅、六镇将卒多代北部落苗裔，带贵族性；迁洛汉化后地位改变。**

- **论据 / 案例 / 事实：** 《通考》羽林虎贲宿卫、六镇将卒御侮，皆代北部落苗裔；孝文诏自代来者皆以为羽林、虎贲。三十六国、九十九姓。贵族性：不废仕宦，偏得复除。
- **推导：** “兵戎乃其所以为国”说明国家建立在这支贵族部落兵上。汉化崇文鄙武之后，同一批人的社会位置翻转，这是第三节起兵的前提。
- **结论：** 鲜卑兵是国之爪牙，也是后来“府户化”时最有势力、最能反弹的人群。
- **延伸：** 洛阳羽林虎贲与六镇将卒同出代北苗裔，故洛阳武人暴动可以是六镇起兵的前奏。

**论点四：非鲜卑兵中最重要的是高车；六镇兵主要者似为高车，部落未解散，故特别善战。**

- **论据 / 案例 / 事实：** 禁军有高车羽林郎将等官。六镇很早即配高车为营户；西部高车居沃野、怀朔、武川一带。叱列、斛律为西部高车；柔玄有东西二部敕勒。太祖分散诸部，唯高车别为部落。边镇斛律、贺拔、库狄多不改姓或改而未行。纯血统鲜卑之次恐即高车。
- **推导：** 解散部落是要把部落兵编进国家；高车例外，等于在北边留下完整的部落武装。六镇“胡化仍是胡化”，不只是文化守旧，而是组织上仍是部落。善战与难治是同一件事的两面。
- **结论：** 六镇兵保持部落性质、特别善战，原因即在高车人多、部落未解散。
- **延伸：** 尔朱契胡部落同样未解散（第四节），北边于是有高车与契胡两块未被编散的部落武力，后来分别成为镇兵主力与收编镇兵的力量。

**论点五：此外还有其他少数民族及汉人军队，地位甚低；打仗以鲜卑骑兵压迫非鲜卑步兵先出。汉人为兵不占重要地位。**

- **论据 / 案例 / 事实：** 拓跋焘与臧质书：斗兵尽非国人，丁零、胡、氐、羌各减其本地“贼”。尉元请换彭城胡军、增中州鲜卑。柳元景所俘河内人“以骑凌步，未战先死”。毛修之领吴兵讨蠕蠕。
- **推导：** “非国人”既是民族身份，也是战场上的消耗品逻辑：先死的是丁零、胡、氐、羌与汉步，鲜卑骑在后逼。吴兵、河内兵证明汉人可被强迫为兵，但作者明确：汉人为兵不占重要地位，重要的是鲜卑与高车军。
- **结论：** 兵的等级秩序是：代北鲜卑（国人、骑兵、贵族）—高车（部落未散、镇兵主力）—其他胡与汉（非国人、步兵、地位低）。
- **延伸：** 这一等级与第七篇胡汉分治、第十四篇“骑兵胡人、步兵汉人”的淝水结构相通。

**论点六：兵民分开，兵民之分即胡汉之分。**

- **论据 / 案例 / 事实：** 刘洁“郡国之民虽不征讨，服勤农桑，以供军国”。恒州以下十州户口不可知，因是军府、军人众多，户口指民户。诸州置都尉领兵，诸部护军改为太守。
- **推导：** 民户数字统计不到军镇，说明户籍系统本身按兵/民切开。都尉领兵、护军改太守，是同一套分治在官称上的滑动。
- **结论：** 农业主要由汉人担负，兵主要由鲜卑及其他少数民族充当；兵民之分也就是胡汉之分。
- **延伸：** 第五节河清三年令的意义，正是后来一度打破这套分离；但东魏北齐之初首先全盘继承它，高欢对军士的鲜卑语/华语两套号令，就是这套分离的日常形态。

### （三）六镇起兵的原因

**论点七：要从元深、魏兰根及正光五年丙申诏三组话来读起兵原因；镇人原是贵族军人，太和、迁洛以后变成府户，这是最重要的原因。**

- **论据 / 案例 / 事实：**
  - **元深上书：** 昔皇始以移防为重，盛简亲贤，拥麾作镇，配以高门子弟，以死防遏，不但不废仕宦，至乃偏得复除，当时人物慕为之。及太和在历，李冲当官任事，凉州土人悉免厮役，丰沛旧门仍防边戍，自非得罪当世，莫肯与之为伍。征镇驱使，但为虞候、白直，一生推迁不过军主。往世房分，留居京者得上品通官，在镇者便为清途所隔；或投彼有北，多复逃入胡乡；乃峻边兵之格，镇人浮游在外，皆听流兵捉之。于是少年不得从师，长者不得游宦，独为匪人，言之流涕。自定鼎伊洛，边任益轻，唯底滞凡才出为镇将，转相模习，专事聚敛；或有诸方奸吏，犯罪配边，为之指踪，政以贿立。李崇求改镇为州，朝廷未许。而高阙戍主率下失和，拔陵杀之，敢为逆命。
  - **李崇 / 魏兰根：** 改镇为州，罢削旧贯，帝以旧典难革不许。魏兰根说李崇：缘边诸镇控摄长远，昔时初置，地广人稀，或征发中原强宗子弟，或国之肺腑，寄以爪牙。中年以来，有司乖实，号曰府户，役同厮养，官婚班齿，致失清流；而本宗旧类各各荣显，顾瞻彼此，理当愤怨。宜改镇立州，分置郡县，府户悉免为民，入仕次叙一准其旧，文武兼用，威恩并施，此计若行，国家庶无北顾之虑。
  - **作者归纳：** 沿边诸镇军人有贵族性。房分造成同姓荣枯对照。六镇一带无法汉化，军人仍是军人，胡化仍是胡化，社会地位则被降为府户。职业军人、鲜卑文化未变，社会阶级被降低，仕宦、复除权利也没有了。
- **推导：** 起兵不是“边民受不了苦”的一般民变，而是一批曾经“人物慕为之”的高门子弟、良家酋帅，看见同姓房分在洛阳“各各荣显”，自己却虞候、白直、军主到死，且被奸吏镇将聚敛。李崇、魏兰根的对策是取消军贯特殊性，恢复他们的仕宦与清流；朝廷不许，等于拒绝修复贵族契约。
- **结论：** 从魏兰根、元深所说，可以了解六镇镇人原来具有职业为军人、社会阶级为贵族、种族文化为鲜卑三种特性；迁都后前二者中的阶级一维被抽掉。
- **延伸：** “无法汉化”与第十六篇“鲜卑贵族士族化必须在洛阳完成”对接：汉化政策的中心只覆盖迁洛集团，北镇被定义成汉化的外侧，于是汉化本身制造了敌人。

**论点八：排抑武人、不使预在清品，洛阳已先爆一次；羽林虎贲焚张彝第，是六镇起兵的前奏。**

- **论据 / 案例 / 事实：** 张彝第二子仲瑀上封事，求铨别选格，排抑武人，不使预在清品。众口喧喧，立榜大巷，克期会集，屠害其家。神龟二年二月，羽林、虎贲几将千人至尚书省诉骂，求其长子尚书郎始均不获，以瓦石击公门；持火掳掠，直造其第，捶辱极意，焚其屋宇。始均回救其父，拜伏请命，羽林就加殴击，生投之烟火中，尸骸不复可识，唯以髻中小钗为验。仲瑀伤重走免，彝仅有余命，后卒。官为收掩羽林凶强者八人斩之。须知禁军和六镇将卒往往皆代北部落苗裔，其初籍之以横行中国；孝文迁洛，“以夏变夷”，遂至崇文鄙武，把武人排斥在清途之外。
- **推导：** 排抑武人在洛阳犹如此，在边镇就更加可想而知。洛阳武人还能聚到尚书省、烧大臣家；镇人连“清途”的边都摸不到，只能叛。同出代北苗裔，使两次爆发属于同一社会集团的前后浪。
- **结论：** 洛阳羽林虎贲发难，实际是六镇起兵的前奏。
- **延伸：** 河阴之变中费穆假手尔朱荣杀朝士，作者明确把它接在这次反张仲瑀暴乱之后：禁军的目的一以贯之，只是执行者换成了契胡武力。

**论点九：正光五年丙申诏把有军贯者都看作府户，虽免为民、改镇为州，仍要三五简发，只能火上加油。**

- **论据 / 案例 / 事实：** 沃野镇人破六韩拔陵起于明帝正光五年三月；八月丙申下诏。诏文追述：诸州镇城人本充爪牙，服勤征旅；献文以来差割强族、分卫方镇；孝文迁洛，选良家酋帅，增戍朔垂，戎捍所寄，实惟斯等。先帝本拟酬锡，因南边告警、兵连积岁，兹恩仍寝，怨叛之兴，颇由于此。今诸州镇军贯，元非犯配者，悉免为民，镇改为州，依旧立称。此等世习干戈，率多劲勇，今既甄拔，应思报效，可三五简发，讨彼沙陇，冲锋斩级，自依恒赏。作者指出两点：第一，从道武帝到孝文迁都以前，一直实行差割强族、分卫方镇，选良家酋帅、增戍朔垂。第二，此诏把有军贯的人都看作了低下阶级府户，与魏兰根“有司乖实，号曰府户”不同。虽然免为民、改镇为州，可是仍要三五简发去打仗。而自魏初起，六镇军人的贵族成分一直保持下来，直到孝文帝仍是选良家酋帅增戍朔垂。
- **推导：** 诏书用官方语言承认他们“本充爪牙”，又用“免为民”把他们从贵族军人降成普通编户，再用三五简发送回战场。边镇军卒中那些强宗子弟、良家酋帅彻底失望：不仅仕宦、复除从此绝望，而且将永远被人贱视；他们震惊自己真的成为府户了。
- **结论：** 丙申诏丝毫也未起到平息叛乱的作用，而只能是火上加油。
- **延伸：** 六镇之叛也有其他原因，但强宗子弟、国之肺腑、高门子弟、良家酋帅在迁洛后被当作弃儿、变成低下阶级府户，却是最重要的原因。这种人在六镇军卒中最占势力。

**论点十：就基本性质来说，六镇之叛是对孝文帝汉化政策的一大反动。**

- **论据 / 案例 / 事实：** 上述三重特性中，汉化改变的是阶级与清途，未改变其军人职业与鲜卑文化；崇文鄙武、检门望、排武人，是汉化政策中心（贵族文士化）的直接产物。
- **推导：** 反动的对象不是某一镇将、某一赋税，而是迁洛汉化所重建的社会阶梯：文官清流在上，武人府户在下。镇人要恢复的是皇始以来“高门子弟、不废仕宦、偏得复除”的旧契约。
- **结论：** 基本性质是对孝文汉化的一大反动。
- **延伸：** 第十八篇指出：这种反动在北齐的鲜卑化中表现出来——北齐依靠六镇军人，鲜卑化贵族反对、排斥与杀害汉人或汉化之人。

### （四）六镇兵的转手，北齐的建立

**论点十一：六镇兵经过三次转手，最终到高欢手上，高氏赖以建东魏、北齐；尔朱氏虽杀朝士、禽葛荣而不可一世，败在把六镇军人又交给了高欢。**

- **论据 / 案例 / 事实：**
  - **第一次：** 破六韩拔陵 → 葛荣，葛荣赖之以继续与洛阳统治者斗争。
  - **尔朱氏之起：** 北秀容契胡，部落未散。荣为安北将军、都督恒朔讨虏诸军，至肆州，刺史尉庆宾闭城不纳，荣攻拔之，署从叔羽生为刺史，执庆宾，兵威渐盛，朝廷不能罪责。成为左右北魏政局的力量，却在起兵赴洛、大杀朝士及打败葛荣以后。
  - **河阴之变：** 惑费穆之说，杀王公卿士一千三百余人，灵太后、少主暴崩，京邑士子逃窜。杀朝士是六镇鲜卑化军人的目的，尔朱代他们办到；费穆是禁军将领，禁军已有反张仲瑀暴乱，杀朝士是假手羯胡武力。
  - **第二次转手（禽葛荣）：** 葛荣横行河北，自邺以北列阵数十里，箕张而进。尔朱荣大破之，于阵擒葛荣，余众悉降。荣以贼徒既众，若即分割恐其疑惧或更结聚，乃普告各从所乐，亲属相随，任所居止，群情喜悦，数十万众一朝散尽；待出百里之外，乃始分道押领，随便安置，各得其宜；擢其渠帅，量力授用，新附者皆安。时人服其处分机速。槛车送葛荣赴阙。这数十万人交给侄子尔朱兆率领。
  - **第三次转手：** 《隋书》六镇扰乱，相率内徙，寓食齐晋之郊，高欢因之成大业。齐晋之郊在尔朱势力范围。《北齐书·神武纪》：葛荣众流入并、肆者二十余万，为契胡陵暴，皆不聊生，大小二十六反，诛夷者半，犹草窃不止。尔朱兆患之，问计于神武。神武曰：六镇反残，不可尽杀，宜选王素所腹心者私使统焉，若有犯者直罪其帅，则所罪者寡。兆以为善。贺拔允请用神武，神武拳殴之，折其齿，曰：生平天柱时，奴辈伏处分如鹰犬，今日天下安置在王，而阿鞠泥敢诬下罔上，请杀之。兆以神武为诚，遂以委焉。六镇反残二十余万就是这样转到高欢手上。
- **推导：** 尔朱荣的成功有两步：替镇人泄了对洛阳文官的恨（河阴），又用“先纵后押”把葛荣数十万众拆开再收编，避免整块复叛。他的失败在于：契胡陵暴使这批人大小二十六反；他把统领权交给高欢，以为高欢殴辱贺拔允是对自己忠诚，其实是把“六镇反残”整块让出。高欢得到的不是离散农民，而是仍然成军、需要“罪其帅”来约束的镇兵集团。
- **结论：** 最重要的原因是尔朱氏所得六镇军人又转入高欢之手；高欢因之以成大业。
- **延伸：** 《隋书》“寓食于齐晋之郊”与钱大昕对武州齐郡、雁门川的考订，把“因之成大业”落到具体地理：不是抽象的河北，而是尔朱势力圈里的六镇流人聚居地。

**论点十二：北齐“六州”即六镇及其他；宇文泰出武川，西魏北周亦与六镇军人有关；起兵提高了六镇军人的地位，他们成为齐、周的统治者。**

- **论据 / 案例 / 事实：** 赵郡王琛为六州大都督、领六州鲜卑酋长大都督；孙腾为六州流民大都督；斛律金领恒、云、燕、朔、显六州大都督。钱大昕谓即神武所领六州兵，脱蔚州；《孙搴传》燕恒云朔显蔚连称可证。六州皆北边军镇所改。钱氏又列怀朔→朔州，怀荒、御夷→蔚州，薄骨律→灵州。《地形志》改镇为州言之不详。宇文泰是武川镇人。
- **推导：** “六州”不是普通行政区划，而是镇兵与镇人流民的编制名称；“鲜卑酋长大都督”“流民大都督”说明既保持部落酋帅结构，又承认其流移状态。钱氏补蔚州、考改镇为州，是为了证明：北齐的军事人口仍叫“六镇及其他”。宇文泰出武川，则西边政权同样坐在镇人之上。
- **结论：** 六镇军人是北齐、北周的统治者；从这个意义上说，六镇起兵提高了六镇军人的地位。
- **延伸：** 地位提高后，他们把对汉化文官的仇恨带进朝廷，即第十八篇的鲜卑化；西边则另走府兵、关陇道路，即第十九篇。杨隋李唐是否也“出自六镇”，必须另辨，以免把“镇人建立的政权”误延成“隋唐皆六镇苗裔”。

### （五）北齐的兵

**论点十三：东魏及北齐之初继承北魏，兵民分离，鲜卑当兵、汉人耕织；高欢用两套号令维持这一分工。**

- **论据 / 案例 / 事实：** 《通鉴》梁武帝大同三年：高欢每号令军士，常令丞相属代郡张华原宣。其语鲜卑则曰：汉民是汝奴，夫为汝耕，妇为汝织，输汝粟帛，令汝温饱，汝何为陵之？其语华人则曰：鲜卑是汝作客，得汝一斛粟、一匹绢，为汝击贼，令汝安宁，汝何为疾之？时鲜卑共轻华人，唯惮高敖曹。欢号令将士常鲜卑语，敖曹在列，则为华语。《隋书·经籍志》有《鲜卑号令》一卷，周武帝撰。这与北魏“服勤农桑以供军国”、征讨由鲜卑及其他少数民族担任，是一致的。
- **推导：** 同一事实，对鲜卑说成“汉民是奴”，对汉人说成“鲜卑是作客”，是有意用双重谎言维持兵农胡汉分离，防止两边互相仇杀到自己无法控制。高敖曹在场改用华语，说明鲜卑语号令是默认，汉语是例外。周武帝也有《鲜卑号令》，可见这套军语不是高欢私制，而是北朝军中通例。
- **结论：** 东魏兵制无疑是北魏兵制的承袭。
- **延伸：** 第十八篇高洋自认“鲜卑车马客”、朝士骂汉儿，是这套号令在政治文化上的升级：从军中分工变成朝廷仇汉。

**论点十四：文宣“百保鲜卑”与华人“勇士”是创革，未改兵民、胡汉之分；河清三年十八受田、二十充兵，才把军镇与州县、当兵与种田结合起来，胡人当兵、汉人耕织的时代过去。**

- **论据 / 案例 / 事实：** 西迁后六坊从武帝而西者不能万人，余皆北迁，给常廪，春秋赐帛。文宣于六坊内简练，一人必当百人、临阵必死，曰百保鲜卑；又简华人勇力绝伦者曰勇士，以备边要。河清三年定邻里族党与丁中老小，十八受田输租调，二十充兵，六十免力役，六十六退田免租调。五兵尚书掌诸郡督告身、宿卫、丁帐、蕃兵及河南、河北诸州发召征兵。北魏均田三长后，胡人虽为编户、圈给土地，仍不耕织，专讲骑射，耕织交奴婢，状如清兵入关圈地；农业纺织主要仍在汉人。河清三年以前，军镇与州县、当兵与种田、胡人与汉人是分离的。
- **推导：** 百保鲜卑把六坊鲜卑加成精锐禁卫，勇士把部分汉人加成边防军，似乎打开汉人当兵的口子，但作者强调性质未变：禁卫仍标“鲜卑”，汉人勇士只“备边要”，兵农胡汉之分仍在。河清令把“受田的州县农民”与“充兵”写成同一条生命历程，五兵尚书按州掌丁帐、发召，兵不再自成军镇系统。这才是制度级变化。
- **结论：** 河清三年法令把军镇与州县、当兵与种田结合起来，兵民、兵农不再各成一个系统；胡人当兵、汉人耕织的时代，军镇与州县分治的时代过去了。这是北朝兵制上的一个很大的变化。
- **延伸：** 变化发生在北齐中期，并不能抹掉北齐赖以建国的六镇鲜卑化武装性格；第十八篇的鲜卑化、西胡化，与兵制条文可以并存。西魏北周的府兵改革是另一条消灭民族界限的路，第十四篇已预告，第十九篇展开。

### （六）杨隋、李唐非出自六镇

**论点十五：高齐出怀朔、宇文出武川，无疑；谓杨隋、李唐亦出自六镇，难于成立。**

**杨隋**

- **论据 / 案例 / 事实：** 《周书·杨忠传》：杨忠，弘农华阴人，小名奴奴。高祖元寿，魏初为武川镇司马，因家于神武树颓。父祯，以军功除建远将军；魏末丧乱，避地中山，结义徒讨鲜于修礼，遂死之。忠年十八客游泰山，会梁兵攻郡，被执至江左，在梁五年，从北海王颢入洛；颢败，尔朱度律召为帐下统军；尔朱兆轻骑入洛阳，忠预焉。后出武川，过故宅，祭先人。作者问：父死于中山，何以本人客游泰山？疑与邢杲之乱有关。《高凉王孤传》附上党王天穆传：杜洛周、鲜于修礼为寇，瀛、冀诸州人多避乱南向；幽州邢杲拥率部曲拒洛周、葛荣，垂将一载；广阳王深等败后，杲南度居青州北海界。灵太后诏流人所在皆置郡县，选豪右为守令。青州刺史表置新安郡以杲为太守，未报；台申汰简，以杲从子子瑶资荫居前，授子瑶河间太守，杲深耻恨遂反。流人先为土人凌忽，闻杲起，率来从之，旬朔之间众逾十万，齐人号为“榆贼”（河南人常笑河北人好食榆叶）。疑杨忠在鲜于修礼破灭之后，随河北流民入青州，追随邢杲，因而得以客游泰山。《隋书·外戚传》：高祖外家吕氏，其族盖微；平齐之后求访不知所在；开皇初济南有吕永吉，自称姑字苦桃，为杨忠妻；乃追赠外祖双周为齐郡公，于齐州立庙。吕苦桃为杨忠之妻、文帝之母。从文帝母系看，疑杨家本系山东杨氏。《杨忠传》谓出武川、过故宅祭先人，是因为高祖元寿魏初曾作武川镇司马，因家于神武树颓。
- **推导：** 武川对杨氏是高祖一代的官宦寄居，不是族源。父死中山、己走泰山—青州流民线、妻为齐人吕氏，三条都把生活重心拉向山东河北，而不是六镇军贯。过武川故宅祭先人，只能证明那里有过一座宅，不能证明杨氏“出自武川”。
- **结论：** 吾人不能据此谓杨氏出自武川。
- **延伸：** 这一辨伪切断“隋也是六镇军人政权”的过度推论；隋的统一在第十四篇里被解释为民族问题最后解决，而不是六镇集团的又一次胜利。

**李唐**

- **论据 / 案例 / 事实：** 李唐曾自称李氏源出陇西，曾家于武川。《册府元龟·帝王部·帝系》：唐高祖姓李氏，陇西狄道人；先出自李暠，为凉武昭王；子歆，歆子重耳，生熙，起家金城镇将，后以良家子镇于武川，都督军戍百姓之务，终于位，因遂家焉。生天赐，天赐生虎，虎生昞，渊即昞之世子。李氏是否出自陇西，姑且不论。若出自武川，则从李熙起应葬武川。然而《唐会要·帝号》：献祖宣皇帝讳熙，葬建初陵，在赵州昭庆县界；懿祖光皇帝讳天赐，葬启运陵，亦在赵州昭庆县界。《元和郡县图志》赵州昭庆县：本汉广阿，皇十三代祖宣皇帝建初陵，高四丈，周回八十步；皇十二代祖光皇帝启运陵，高四丈，周回六十步；二陵兆域周回一百五十余步，在县西南二十里。河北省隆平县唐光业寺碑：追上宣皇帝、光皇帝及后谥号，颂词有“维王桑梓，本际城池”。李熙、李天赐父子共茔而葬，光业寺碑有“维王桑梓”之语。
- **推导：** 李氏累代所葬之地，即其家世居住之地，绝无疑义。自称武川是帝系叙述；昭庆二陵与“桑梓”是空间事实。二者冲突时，作者取葬地与桑梓，不取自述。
- **结论：** 谓李唐出自武川，与李熙父子墓在昭庆及隆平光业寺碑“维王桑梓”之言均不合。
- **延伸：** 本篇以“杨隋李唐非出自六镇”收束，是为了把六镇的历史作用限制在：它改变了北朝，造就了齐、周统治者；不等于隋唐皇室的族源也是六镇。府兵、关陇如何通向隋唐，要在第十九篇另讲，不能用“都出自武川”一句话接通。

## 史料用法与讲授细节

- **开篇先教名词的时代性。** “六镇及其他”反复出现：先指定六名，再放到营户、降户、六州、改镇为州，每次都提醒不要把词用死。
- **防南用《杨椿传》的数字。** 八军各五千、割南戍后一军千余、主帅四十八人、罢四军减帅一百八十四、屯兵八百户、年发夫三千与草三百车——用军府编制证明南防曾经重于北防。
- **营户三条徙民诏 + 太和南讨发卒，做成“旧制”证据链。** 然后再引入深二十万降户、杨昱分散冀定瀛、深预言“复为乞活”。反驳“失策”时，分历史（旧制、本有军府）与现实（尔朱半独立，不能徙入）两层，示范如何用制度史驳事后诸葛亮。
- **兵制先引《通考》总论，再分鲜卑 / 高车 / 其他。** 九十九姓、《官氏志》高车官、西部高车姓氏（叱列、斛律）、未改姓诸例，一层层证“六镇主要者似为高车”“部落未解散故善战”。
- **臧质书是讲“非国人”逻辑的极明文。** 丁零、胡、氐、羌各减其本地贼，把民族身份、地域治安与战场消耗写成一句话。柳元景俘兵“以骑凌步”用来翻译这套逻辑如何作战。毛修之吴兵补汉人兵种，随即声明不占重要地位，防止读者把吴兵写成北魏主力。
- **兵民分离用《刘洁传》定性句 +《地形志》十州无户口。** “户口不得知”被读成：统计对象是民不是兵，故军镇州看不见民户数。都尉、护军改太守，回指第七篇胡汉分治。
- **起兵原因指定三组文本：元深、魏兰根、丙申诏。** 讲授上不另起“经济剥削”“民族起义”等外加框架，先让这三组话互相证明。元深与魏兰根一致处（贵族性、房分、府户、改镇为州）先抽出来；丙申诏与魏兰根的差异（有司妄号 vs 诏书确认府户）单独强调，用来解释诏书为何火上加油。
- **张彝事件写到“髻中小钗为验”。** 细节越惨，越说明洛阳武人仇恨之深，也越能支撑“前奏”判断。收尾用《通考》原句“籍之以横行中国”与“以夏变夷、崇文鄙武”对撞。
- **丙申诏几乎通篇转述。** 从道武爪牙讲到孝文选良家酋帅，再讲酬锡因南边战争而寝，再讲免为民、改镇为州、三五简发。作者自己标出“两个值得注意的地方”，讲课节奏是：先听诏书自我表扬，再指出它把人定性为府户并立刻抽兵。
- **转手第三节最详的是尔朱处分降众与高欢骗取统兵。** 葛荣数十万“一朝散尽—百里外再押领—擢渠帅”被称作“处分机速”；高欢折贺拔允齿、自称鹰犬，被读成取得尔朱兆信任的表演。两次都是“如何接管镇兵”的技术分析，不是单纯道德评价。
- **钱大昕出现多次。** 齐郡、六州脱蔚州、改镇为州史文不详，用来补魏收的省略。本篇是全书中把清人考异直接织进论证的一节。
- **高欢两套号令几乎全文照录。** 奴/作客对举，再补高敖曹在列则用华语、《鲜卑号令》书名，把语言、民族、兵农绑在一起。
- **河清令与五兵尚书对读。** 受田—输租调—充兵—免役—退田是一条人生时间表；五兵按地区掌丁帐、发召，证明兵从州县出。圈地、奴婢耕织的比喻，用来说明均田后胡人形式上是编户、职业上仍不农。
- **杨李辨伪用“生活轨迹 vs 自述”。** 杨忠：泰山—邢杲榆贼—吕苦桃齐人。李唐：自述武川 vs 昭庆二陵与“维王桑梓”。陇西问题“姑且不论”，只打武川这一仗，显示裁断范围的克制。

## 知识点全量梳理

- 六镇原指怀朔、武川、抚冥、柔玄、怀荒、沃野；后为北方城镇总称，应是六镇及其他。
- 须兼看防北、防南、防边及对南北朝至隋唐的影响；起兵改变了北朝历史。
- 甸服：东军都关，西河，南隘门塞，北五原。未得青徐时南防似乎重于柔然。
- 平中山后多置军府；定州八军各五千，后渐割南戍；杨椿罢四军、罢屯田役夫。
- 配降人为营户是旧制：真君五年北部民，延兴元年沃野统万敕勒，延兴二年连川敕勒；各州都有营户，为防要害、防南、便于南讨。
- 拔陵降附二十万分散冀、定、瀛就食；元深请恒州北置郡县安置，不从；不能视为失策（旧制 + 尔朱已据恒代以北）。鲜于修礼起于定州，杜洛周起于幽州。
- 北魏兵：鲜卑兵 + 非鲜卑兵。羽林虎贲宿卫，六镇将卒御侮，多代北三十六国、九十九姓苗裔；贵族性：不废仕宦，偏得复除；迁洛后地位变。
- 高车：狄历/敕勒/丁零；语近匈奴；独不解散部落。禁军有高车官。六镇主要者似为西部高车（沃野、怀朔、武川）；叱列、斛律等。边镇多未改姓（斛律、贺拔、库狄）。镇兵部落性、善战由于高车未散。鲜卑之次恐即高车。
- 非国人兵：丁零、胡、氐、羌（焘与臧质书）；徐州胡戍（尉元）；河内汉步“以骑凌步”；毛修之吴兵。汉兵不占重要地位。
- 兵民分离：民耕桑供军国；恒州以下十州户口不可知（军府、军人多，户口指民）；都尉领兵、护军改太守 = 兵民胡汉分治。
- 起兵最要原因：镇人原为贵族军人+鲜卑文化；迁洛后阶级降为府户，失仕宦复除。房分：在京荣显，在镇隔于清途。镇将凡才聚敛，奸吏配边。
- 李崇、魏兰根请改镇为州、府户免为民，旧典难革，不许。
- 张仲瑀请排抑武人、不使预清品；神龟二年羽林虎贲焚张彝第，始均被投火中。是六镇起兵前奏。崇文鄙武、以夏变夷。
- 正光五年三月拔陵起；八月丙申诏：追述差割强族、选良家酋帅，免非犯配军贯为民、改镇为州，但仍三五简发讨沙陇。诏书把军贯者看作府户，火上加油。
- 六镇之叛基本性质：对孝文汉化政策的一大反动。强宗子弟、良家酋帅在镇人中最占势力。
- 三次转手：拔陵→葛荣→尔朱荣（兆）→高欢。
- 尔朱荣：北秀容契胡（羯），部落未散；起于恒朔；河阴杀朝士一千三百余人（费穆、禁军目的）；禽葛荣，数十万先散后押，交尔朱兆。
- 葛荣余众流入并肆二十余万，为契胡陵暴，二十六反；高欢请以腹心统之、罪其帅，殴折贺拔允齿以取信，得“六镇反残”。
- 齐晋之郊 = 六镇寓食地 = 尔朱范围；钱大昕考武州齐郡。
- 北齐六州：恒云燕朔显蔚（斛律金传脱蔚）；即六镇兵所出及流人聚居；改镇为州史文不详，可知者怀朔→朔，怀荒御夷→蔚，薄骨律→灵。
- 宇文泰武川人；六镇军人是齐周统治者；起兵提高其地位。
- 东魏北齐初：兵民分离，鲜卑兵、汉人耕织；高欢两套号令；鲜卑轻华人，惮高敖曹；号令多用鲜卑语。
- 文宣：百保鲜卑（六坊简练，一人当百）；勇士（华人勇力绝伦，备边）。有创革，未改兵农胡汉之分。
- 河清三年：邻里族党、丁中老小；十八受田输租调，二十充兵，六十免役，六十六退田。五兵尚书掌丁帐发兵。兵由州县受田农民充当；军镇/州县、兵/农、胡/汉分离的时代过去。均田后胡人圈地而不耕、奴婢耕织之状，至此才变。
- 高齐出怀朔，宇文出武川，无疑。
- 杨忠：弘农华阴；高祖武川司马，家神武树颓；父死中山讨鲜于修礼；本人客游泰山，疑随邢杲流民（榆贼）；妻吕苦桃齐人；不能谓杨氏出自武川。
- 李唐自述陇西、家武川；李熙、李天赐葬赵州昭庆建初、启运陵；光业寺碑“维王桑梓”；葬地即居住地，与武川说不合。陇西出身姑且不论。
