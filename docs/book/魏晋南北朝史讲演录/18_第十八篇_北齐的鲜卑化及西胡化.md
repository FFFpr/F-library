# 第十八篇 北齐的鲜卑化及西胡化

## 本章定位与核心主张

本篇把北齐的民族问题收束到一个总原则：**我国历史上的民族，如魏晋南北朝时期的民族，往往以文化来划分，而非以血统来划分。** 少数民族汉化了，便被视为“杂汉”“汉儿”“汉人”；汉人接受某少数民族文化、与之同俗，便被视为某少数民族人。少数民族与少数民族之间也是这样：接受另一族的文化风俗，便被视为那一族的人，本民族反而隐蔽不显。北魏的鲜卑族便是一个很杂的民族。研究北朝民族问题，不应过多考虑血统，而应注意“化”的问题。

在这个原则下，本篇两节互证：

1. **北齐鲜卑化：** 最高统治者高氏血统为汉人，因累世北边、习其俗而同鲜卑；皇室及许多“汉人”官僚自认为鲜卑人，反对的是汉人和汉化的胡人。最大事件是后主因韩长鸾之言屠杀“汉儿文官”崔季舒等。出现这种反常情况，是因为北齐依靠六镇军人；六镇起兵本是对孝文帝汉化政策的反动，这种反动在北齐的鲜卑化中表现出来了。
2. **北齐西胡化：** 鲜卑或鲜卑化贵族沉溺于西域的歌舞、游戏与玩物，甚至想做“龟兹国子”；朝廷起用大批西域胡人专门从事游乐。按照“化”的原则，若继续沉溺，将会为西胡所同化。这些鲜卑贵人最反对汉化，却最热心西胡化。西胡人的来源，可上溯孝文帝迁洛以来洛阳城南四夷馆一带的商胡；魏亡后归入北齐，不仅影响北齐，也影响隋唐。

## 关键概念补全（术语先讲）

**以“化”分，不以血统分。** 这是本篇的方法论，也是对第七篇“以文化区分民族”的北齐实证。具体操作标准是：看文化习俗，不看家谱上的种姓。因此会出现四种交叉：汉人而鲜卑化（高欢、韩长鸾、高德政、高隆之）；鲜卑而自认鲜卑（娄氏）；胡人而汉化，即被当作汉人（和士开、源师）；鲜卑化贵族再西胡化（武成、后主周围）。血统在讲课中只用来标明“出发时是什么”，判断“现在是什么”一律看“化”。

**鲜卑化。** 指久居鲜卑地区，接受鲜卑文化，与之同俗，不仅被人们目为鲜卑人，自己也把自己视作鲜卑人。“化”指文化习俗而言。“化”比血统重要，鲜卑化人也就是鲜卑人。北齐鲜卑化风气极盛。鲜卑化贵族所反对的是汉人和汉化的胡人。

**西胡化。** 指那些鲜卑或鲜卑化贵族，沉溺于西域的歌舞、游戏与玩物中，甚至想做“龟兹国子”。北齐起用大批西域胡人，专门从事游乐。按照“化”的原则，如果那些鲜卑贵族继续沉溺下去，将会为西胡所同化，变成西胡人或西胡化人。

**高氏的血统与“化”。** 《魏书·高湖传》附高谧传：谧恒侍献文帝讲读，拜兰台御史，寻转治书，掌摄内外，弹纠非法，甚见信赏，延兴二年卒。《北齐书·神武纪》：湖生四子，第三子谧，仕魏位至侍御史，坐法徙居怀朔镇；谧生皇考树；神武生而丧母韩氏，养于同产姊婿镇狱队尉景家；神武既累世北边，故习其俗，遂同鲜卑。其后柔玄镇人杜洛周反于上谷，神武与同志从之，丑其行事，遂奔葛荣，又亡归尔朱荣于秀容。这两段记高欢父祖十分清晰：祖父高谧为治书侍御史，深得献文帝信任，后坐法徙怀朔；曾祖为高湖。或云此为冒认；作者认为远祖可冒认，三代以内要冒认是不可能的。毫无疑问，高欢为高湖之后，籍贯为渤海，民族为汉人——说他是汉人，是就血统而言。累世（高谧、高树、高欢三世）北边，习其俗，遂同鲜卑——这就是“化”。血统上是汉人，化上已经是鲜卑化的人。

**娄氏。** 高欢妻娄昭君，赠司徒内干之女；少明悟，强族多聘之，不肯行；见神武于城上执役，惊曰“此真吾夫也”，使婢通意，又数致私财使以聘己，父母不得已而许。太后寝疾，用巫言，改姓石氏。《官氏志》“神元皇帝时余部诸姓内入者”有匹娄氏，后改为娄氏。娄昭君即匹娄昭君，就血统、文化论，娄氏都是鲜卑人。

**汉化的胡人。** 和士开：清都临漳人，其先西域商胡，本姓素和氏；甚得武成帝及后主信任，后为琅邪王高俨所杀。高俨为后主弟，斛律光云：“天子弟杀一汉，何所苦。”是直认和士开为汉人。胡人汉化者即被认为是汉人，于此又得一例。源师之源，为秃发氏所改。源贺自署河西王秃发傉檀之子，傉檀为乞伏炽盘所灭，贺自乐都来奔；太武帝谓“卿与朕同源，因事分姓，今可为源氏”。源师血统上为鲜卑人；后主时为尚书郎中，与高阿那肱谈“龙星见，须雩祭”，被骂为“汉儿强知星宿”。民族以化分，不以血统分，这又是一例。

**握槊。** 北齐鲜卑贵人包括武成皇后胡氏在内都喜爱握槊。胡三省注：握槊亦博塞之戏。刘禹锡《观博》记其器：有博齿，用骨，棱四均，镂以朱墨，耦而合数，取应日月，视其转止，依以争道；以其用必投掷，以博投诏之。又尔朱世隆与元世隽握槊，忽闻局上砉然有声，一局子尽倒立，世隆甚恶之，既而及祸。李延寿曰：握槊此盖胡戏，近入中国；云胡王有弟一人遇罪将杀之，从狱中为此戏上之，意孤则易死也。作者的重点不是博戏谱，而是：不过是一种胡戏，可惊的是北齐鲜卑贵人如胡后、韩长鸾陷之深。

**龟兹国子。** 寿阳陷没，韩凤与穆提婆闻告败，握槊不辍，曰：“他家物，从他去。”后帝使于黎阳临河筑城戍，曰：急时且守此作龟兹国子；人生如寄，唯当行乐，何用愁为。《通鉴》记提婆等白：假使国家尽失黄河以南，犹可作一龟兹国；左右嬖臣共赞和之，帝大喜，酣饮鼓舞，仍使于黎阳临河筑城戍。作者读为：此举是真欲划河作龟兹国，一以自保，二以及时行乐。不是韩、穆少数人的思想，连后主及左右嬖臣也无不作此等想法。

**洛阳四夷馆与西胡来源。** 《洛阳伽蓝记》城南永桥以南、圜丘以北、伊洛之间，夹御道有四夷馆：西夷来附者处崦嵫馆，赐宅慕义里。自葱岭以西至于大秦，百国千城莫不款附，商胡贩客日奔塞下；乐中国土风因而宅者不可胜数，附化之民万有余家，天下难得之货咸悉在焉。自孝文迁洛以来，北魏洛阳西胡众多。北齐的西胡也就是他们的子孙。和士开其先即西域胡商，本姓素和氏；父名安，魏末作过中书舍人、仪州刺史。魏亡后，这众多的西胡都归入北齐政权之下。

## 论证推理链

### （一）北齐的鲜卑化

**论点一：划分民族应看“化”不看血统；北魏鲜卑本已是很杂的民族，北齐把这一原则用到极端。**

- **论据 / 案例 / 事实：** 开篇总论：汉化则被视为汉儿，接受鲜卑文化则自他都被视为鲜卑；少数民族之间互相同化，本民族隐蔽不显。北魏鲜卑族很杂。
- **推导：** 若按血统，高欢是渤海汉人，和士开是西域商胡，源师是秃发鲜卑，韩长鸾是汉人黎阳系统——朝廷上应是一盘杂姓。按“化”，他们重新排队：鲜卑化者为一群，汉化者为一群，西胡化者再从鲜卑化群里分出。政治仇恨沿着“化”的边界走，不沿着血统走。
- **结论：** 研究北朝民族问题，不应过多考虑血统，应注意“化”。
- **延伸：** 这一原则上承第七篇“以地域区分民族将让位于以文化区分民族”，下启本篇所有个案；也解释第十四篇北齐骂“汉儿”何以能出自汉人血统的韩凤。

> 💡 相关前置概念与推导详见：[07_第七篇_胡族的汉化及胡汉分治.md]

**论点二：高齐皇室血统为汉，累世北边而鲜卑化，自认为鲜卑人。**

- **论据 / 案例 / 事实：** 高谧侍献文、为治书侍御史，坐法徙怀朔；高树、高欢三世北边，习其俗，遂同鲜卑。远祖可冒认，三代以内不可能冒认，故高欢为高湖之后、渤海人、血统汉人。娄氏匹娄，血统文化皆鲜卑；见高欢城上执役而求聘。高洋问杜弼治国当用何人，对曰“鲜卑车马客，会须用中国人”，显祖以为此言讥我——因为他自认为鲜卑车马客。杨愔死时，废帝高殷谓“岂敢惜此汉辈”，也是自认为鲜卑人。
- **推导：** 徙怀朔是“化”的起点：御史家族一旦进入镇的习俗圈，三世即可同鲜卑。高洋把“鲜卑车马客”听成指自己，高殷把杨愔说成“汉辈”，说明自我认同已经翻转，不再需要别人来“认定”他们是鲜卑。娄氏求聘城上执役者，是鲜卑贵女选择鲜卑化汉人，婚姻加固认同。
- **结论：** 高齐皇室自认自己是鲜卑人，原因即在已经鲜卑化。
- **延伸：** 第十七篇高欢两套号令（汉民是奴 / 鲜卑是作客）在这里得到身份注释：发号令的人自己站在鲜卑一边。

**论点三：与皇室并不很亲的汉人官僚，同样可以自认为鲜卑人，并反对立汉妇为后。**

- **论据 / 案例 / 事实：** 文宣欲建中宫，高隆之、高德政言：“汉妇人不可为天下母，宜更择美配。”杨愔请依汉魏故事，不改元妃；德政犹固请废后，而立段昭仪，欲以结勋贵之援。帝竟不从，立李祖娥（赵郡李希宗之女）。高德政字某，渤海人，父显，魏沧州刺史。高隆之本姓徐，云出自高平金乡，父为姑婿高氏所养，因从其姓；后有参议之功，高祖命为从弟，仍云渤海人。二人血统上都是汉人。
- **推导：** 反对李祖娥，不是因为他们比高洋更“纯鲜卑”，而是因为他们已经鲜卑化，自认为鲜卑人，要把“天下母”限制在非汉族类。德政欲立段昭仪以结勋贵之援，说明鲜卑化政治要拉的是勋贵，不是汉魏故事。高隆之连姓都是养子、从弟系统，更证明“渤海高氏”可以是政治身份，“鲜卑人”才是他们的自我归属。
- **结论：** 血统上的汉人可以坚定地反对“汉妇人不可为天下母”；鲜卑化风气极盛，由此可见。
- **延伸：** 第十四篇娄氏骂李祖娥“汉老妪”、废帝“岂敢惜此汉辈”，与本节是同一组故事的完整版；本篇补上高德政、高隆之，说明排汉不只是皇后、皇帝的家务，而是鲜卑化官僚的共同立场。

**论点四：鲜卑化贵族反对的对象包括汉化的胡人；和士开、源师被直接叫作“汉”。**

- **论据 / 案例 / 事实：** 和士开先世西域商胡、素和氏，却被斛律光称为“汉”。源师血统鲜卑（秃发—源），因谈龙星雩祭，被高阿那肱骂“汉儿强知星宿”。
- **推导：** 和士开若按血统是西胡，按后来西胡化风气本可算“自己人”；但他走的是汉化官宦路，就被划到汉那边，以至于杀他可以说成“天子弟杀一汉”。源师谈星历祭祀，触犯的是“汉儿强知”的文化边界：鲜卑化权臣不允许汉化胡人用中原知识说话。
- **结论：** 胡人汉化者即被认为是汉人；民族以化分，不以血统分，和士开、源师又是两例。
- **延伸：** 同一人和士开，在第二节又以西域商胡、善握槊、弹胡琵琶的面貌出现——说明一个人可以同时被不同“化”的标准切割：对斛律光是“汉”，对武成、胡后是西胡伎能宠臣。

**论点五：后主屠杀崔季舒等“汉儿文官”，是北齐民族成见最集中的事件；根源是政权依靠六镇军人，六镇反动在鲜卑化中兑现。**

- **论据 / 案例 / 事实：** 韩长鸾名凤，黎阳人，父韩永兴做过青州刺史；自己做过都督，血统为汉人，可是鲜卑化了，自以为是鲜卑人。对朝士十分仇视，经常骂“狗汉大不可耐，唯须杀却”。后主要去晋阳，崔季舒与从驾文官联名进谏，韩长鸾上奏：汉儿文官连名总署，声云谏止向并，其实未必不反，宜加诛翦。后主即召已署表官人集含章殿，以崔季舒、张雕、刘逖、封孝琰、裴泽、郭遵等为首，并斩之殿廷。北齐民族成见很深，表现为占据统治地位的鲜卑化人，反对、排斥与杀害汉人或汉化之人。北齐之所以出现此种反常，是因为北齐的建立依靠六镇军人；六镇军人作为保持鲜卑化的武装集团，本是洛阳汉化文官集团的反对者。六镇起兵是对孝文帝汉化政策的反动。这种反动，在北齐的鲜卑化中表现出来了。
- **推导：** 韩凤血统是汉，骂的是“狗汉”，杀的是联名谏幸晋阳的文官——仇恨对准的是汉化文官职能本身，不是血缘。崔季舒等“声云谏止向并”被说成“未必不反”，把制度性谏诤翻译成种族性谋反，正是洛阳清途与六镇武人长期对立的语言。反常之处在于：一个汉人血统的政权，系统地杀害汉人文官；用“化”来看则毫不反常：统治者是鲜卑化的六镇集团。
- **结论：** 北齐鲜卑化 = 六镇反汉化在建国后的制度化。
- **延伸：** 第十四篇用同一组杀戮证明北齐不能善调民族关系、故亡于周；本篇补上“何以会如此”的机制。北周用苏绰、卢辩，走的是相反的“化”。

### （二）北齐的西胡化

**论点六：西胡化是鲜卑化贵族的另一条“化”路：最反对汉化，却最热心西域歌舞、胡戏、胡人弄权；按“化”的原则，继续沉溺就会变成西胡化人。**

- **论据 / 案例 / 事实：** 《北齐书·恩幸传》：西域丑胡、龟兹杂伎，封王者接武，开府者比肩，非直独守弄臣，且复多干朝政。和士开善握槊、能弹胡琵琶，由此得宠；武成时恒令其与太后握槊，出入卧内，遂与太后为乱；累至尚书令、录尚书，封淮阳王。韩凤与高阿那肱、穆提婆共处衡轴，号称三贵。寿阳陷，凤与提婆握槊不辍，曰他家物从他去；又欲于黎阳临河筑戍作龟兹国子，君臣应和若此。齐主以波斯狗为仪同、郡君，分其干禄。何海及子洪珍皆为王，洪珍卖官。史丑多之徒“胡小儿”等数十，咸能舞工歌，亦至仪同、开府、封王；眼鼻深险，无可用，非理爱好，排朝贵，尤为人士所疾恶。鲜卑贵人爱好西胡习俗到了何种程度：胡小儿能以工于歌舞封王，波斯狗也能受封仪同郡君。武成皇后胡氏等皆爱握槊；握槊为胡戏，胡后、韩长鸾陷之深。黄河以南犹可作一龟兹国、唯当行乐，不是少数人的思想，后主及左右嬖臣无不作此等想法，故有黎阳筑戍之举：真欲划河作龟兹国，一以自保，二与韩、穆、何海、何洪珍、胡小儿、波斯狗等及时行乐。
- **推导：** 鲜卑化本已拒绝汉化文官；西胡化则提供另一套享乐的文化认同，既不回到洛阳式汉化，也不保持边镇那种“职业军人、部落善战”的严肃胡化，而是把西域伎乐做成朝廷空气。封王、开府、仪同给了丑胡、胡小儿甚至波斯狗，等于用官爵系统为西胡习俗背书。黎阳划河的设想，把国土收缩写成“作一个龟兹国”，是西胡化从娱乐进入政治地理想象。
- **结论：** 这些鲜卑贵人最反对汉化，却最热心西胡化。
- **延伸：** 第十六篇末“胡化并非全为退化，而是胡汉再交混的新局面”，在这里得到一种否定性的例证：交混也可以通向弄臣政治与国土自弃，而不通向第十四篇所说的民族问题解决。

**论点七：西胡化要有西胡人；北齐西胡来自孝文迁洛以来洛阳的商胡附化之民，魏亡后归入北齐，并影响隋唐。**

- **论据 / 案例 / 事实：** 《洛阳伽蓝记》四夷馆、崦嵫馆、慕义里：葱岭以西至于大秦，商胡贩客日奔塞下，附化万有余家，难得之货咸在。和士开先世即此类商胡，父安魏末已入中书、刺史系统。魏亡，西胡归北齐。
- **推导：** 西胡化不是北齐突然从西域“进口”一批人，而是迁洛开放西夷居处之后，两三代商胡已经住在中国、有宅有官，入齐后从伎乐与玩物方向俘获鲜卑化宫廷。没有洛阳那“万有余家”，和士开、胡小儿、波斯狗的政治空间难以想象。
- **结论：** 北齐的西胡也就是洛阳西胡的子孙；他们不仅影响到北齐的历史，而且影响到隋唐的历史。
- **延伸：** 影响隋唐只点到为止，本篇不展开；它提醒读者：西胡化不是北齐的孤癖，而是迁洛以来西夷入居这条线的下行。与第十七篇“杨隋李唐非出自六镇”合看：隋唐所受北朝遗产，既有镇兵—府兵—关陇，也有洛阳商胡这一支，不能单用六镇解释。

## 史料用法与讲授细节

- **先立“化”的定义，再进入高氏家世。** 开篇不先讲高欢是不是汉人，先把“杂汉 / 汉儿 / 视为鲜卑 / 本民族隐蔽”讲成规则，后面所有例子都是规则的填空。
- **用三代不可冒认，堵住“高氏伪造渤海郡望”的怀疑。** 高谧侍讲、治书侍御史、坐法徙镇，情节具体；作者承认远祖可冒，把可信区间收在三代以内，这是史料方法上的自我限制。
- **“累世北边，故习其俗，遂同鲜卑”被指定为“化”的经典表述。** 血统一句、化一句，拆开讲，防止混成“所以高欢其实是鲜卑”。
- **娄后见城上执役而求聘、寝疾改姓石氏。** 前一事写鲜卑贵女的择偶眼光，后一事写巫俗，都服务于“文化习俗”，不是言情。
- **杜弼“鲜卑车马客，会须用中国人”是一句反证。** 高洋“以为讥我”，比任何谱牒都能证明自我认同。废帝“汉辈”、高德政“汉妇人不可为天下母”、斛律光“杀一汉”、高阿那肱“汉儿强知星宿”、韩凤“狗汉”“汉儿文官”，连成一条骂名谱。作者让读者听见北齐朝廷的日常语言。
- **和士开、源师用来做“汉化胡人 = 汉人”的对照实验。** 一个西胡、一个秃发，都被叫汉；规则的普遍性靠跨血统重复。
- **崔季舒含章殿之诛，第十四篇已用过，本篇补韩凤的血统与动机。** 重出不是疏忽：十四篇用来比北周、解释不能统一；本篇用来证“化”与六镇反动。同一史料，两处功能不同。
- **西胡化一节几乎是《恩幸传》的结构化转写。** 先总括封王开府、多干朝政，再和士开握槊琵琶乱宫，再三贵对寿阳陷没的态度，再波斯狗、何氏、胡小儿。最后用《通鉴》把“龟兹国”从口语坐实为黎阳筑戍的政治行动。
- **握槊注疏保留刘禹锡、尔朱世隆恶兆、李延寿胡王弟狱中造戏。** 作者称之为“不过是一种胡戏”，重点在“陷之深”，不是要读者学会玩。
- **《洛阳伽蓝记》放在节末，回答“西胡人从何而来”。** 先写宫廷沉溺，再补人口来源，避免把西胡化写成几个宠臣的偶然。葱岭至大秦、万有余家、难得之货，用来说明规模，不是铺陈都市风光。影响隋唐只一句，留作开放结尾。

## 知识点全量梳理

- 民族往往以文化划分，不以血统划分；汉化则被视为汉儿，接受某族文化则被视为该族；北魏鲜卑是很杂的民族。研究北朝民族应重“化”。
- 北齐最高统治者高氏：血统汉（高湖—高谧—高树—高欢，渤海），累世北边而鲜卑化。三代以内不可能冒认。
- 高谧：献文侍讲、治书侍御史，坐法徙怀朔。高欢养于尉景家；从杜洛周，丑其事，奔葛荣，归尔朱荣。
- 娄昭君：匹娄氏，血统文化皆鲜卑；城上见高欢执役而求聘；寝疾改姓石氏。
- 高洋自认鲜卑车马客（杜弼对）；高殷谓“岂敢惜此汉辈”。
- 高德政、高隆之血统汉人，反对立李祖娥，曰汉妇人不可为天下母；德政欲立段昭仪结勋贵；帝仍立后。高隆之本姓徐，被高欢命为从弟。
- 鲜卑化贵族反对汉人及汉化胡人。
- 和士开：西域商胡，素和氏；斛律光称为汉。源师：秃发—源，鲜卑血统，被高阿那肱骂汉儿强知星宿。
- 韩长鸾（凤）：黎阳人，血统汉而鲜卑化；骂狗汉唯须杀却；借谏幸晋阳屠杀崔季舒、张雕、刘逖、封孝琰、裴泽、郭遵等。
- 北齐民族成见以化分；表现为鲜卑化人反对、排斥、杀害汉人或汉化之人。
- 原因：依靠六镇军人；六镇是洛阳汉化文官的反对者；六镇起兵是对孝文汉化的反动，在北齐鲜卑化中表现出来。
- 西胡化：沉溺西域歌舞、游戏、玩物，欲作龟兹国子；起用大批西域胡人游乐；继续则将被西胡同化。
- 西域丑胡、龟兹杂伎封王开府，多干朝政。和士开以握槊、胡琵琶得宠，与太后乱。韩凤、高阿那肱、穆提婆号三贵。
- 寿阳陷而握槊不辍；欲划黄河以南作龟兹国，黎阳临河筑戍；后主及嬖臣皆作此想。
- 波斯狗为仪同郡君；何海、何洪珍封王卖官；胡小儿工歌得开府封王，排朝贵。
- 握槊：胡戏、博塞；刘禹锡记其制；李延寿记胡王弟狱中造戏；胡后、韩长鸾陷之深。
- 西胡来源：孝文迁洛后洛阳四夷馆、崦嵫馆、慕义里，葱岭以西至大秦，附化万余家。和士开父安魏末已仕。魏亡，西胡入齐，影响北齐及隋唐。
- 鲜卑贵人最反对汉化，却最热心西胡化。

## 题外话

本篇在“化”的主线之外，还写到：高谧当官而行、弹纠非法；高欢生而丧母、养于尉景家，从杜洛周而“丑其行事”；娄后使婢通意、数致私财使高欢聘己，父母不得已而许，后又用巫言改姓石氏；高隆之由徐氏被高氏姑婿所养、再被高欢命为从弟；源贺因太武帝“同源分姓”而得源氏；龙星见须雩祭的郊祀话题；握槊的形制、尔朱世隆一局子尽倒立的恶兆、胡王弟狱中造戏以求“孤则易死”的传说；波斯狗受封分禄；胡小儿“眼鼻深险，无可用，非理爱好”；洛阳慕义里青槐绿柳、难得之货咸在的都市描写。

除了本章主要内容外，作者还讨论了/提及了：1. 远祖可以冒认、三代以内不可能冒认，用来肯定高欢出于高湖、渤海的血统叙述，2. 握槊作为胡戏的形制、流传及李延寿所记“胡王弟狱中造戏”的传说，用来说明北齐贵人沉溺之深，3. 《洛阳伽蓝记》所记迁洛以后西夷馆、商胡附化万余家，用来追溯北齐西胡人的来源，并指出其影响及于隋唐。
