# 第十四篇 南北对立形势分析

## 本章定位与核心主张

本篇把东晋南北朝的南北对峙，收束成一条可以检验的总命题：**经济与武备上是北强南弱；北朝却不能过早吞并南朝，关键不在南北军力对比，而在北朝内部民族与文化问题尚未解决。** 民族问题一旦解决，北朝潜在的经济与武备力量就能发挥出来，南北即合；合的方式也不是北方一举并吞，而是北方力量渐次南移、带蚕食性。南朝多次北伐不能成功，则另有四条结构性限制：物力、武力、运输、南北人心。

本篇三节互相扣合：第一节用户口与兵制证明北强南弱；第二节用后赵、前秦淝水、北魏孝文、北齐北周对比，说明“强而不能早统”的原因；第三节用北伐诸例说明南朝为何推不回去。淝水之战不是孤立的战役故事，而是第二节用来解剖“民族分配与组织有缺口”的核心案例。

> 💡 相关前置概念与推导详见：[07_第七篇_胡族的汉化及胡汉分治.md]（胡汉分治、以文化而非血统划分民族）、[15_第十五篇_北魏前期的汉化与崔浩问题.md] 与 [16_第十六篇_北魏后期的汉化与孝文帝政策.md]（汉化正逆流、迁洛争正统）、[17_第十七篇_六镇问题与魏齐之兵.md]（六镇起兵与北齐所依）、[19_第十九篇_宇文氏府兵及关陇集团.md]（府兵由鲜卑部酋分属制转向华夏兵农合一）。

## 关键概念补全（术语先讲）

**户口即国力。** 本篇反复强调：古代农业社会以男耕女织为底，人口是经济极重要的因素。比较南北强弱，先比编户齐民的户数、口数，不先比个别战役的胜负。北方户口长期高于南方，作者据此直接推出“人口的优胜也就是经济的优胜”。

**胡汉之别在军事上的含义。** 南北军事分别被概括为胡汉之别。北朝战争主力是胡人部落兵：领兵酋长与部属情谊如父子，组织严密；兵种以骑兵为主，战斗力强；骑兵必须用斥候（侦察、候望）。南朝同北兵作战，常在夜间袭击北营，目的就是躲避北兵斥候。北朝军事优势可压缩为三语：**组织之密、骑术之精、斥候之明**。北宋吕颐浩论金兵，除骑射习惯外，组织严密、斥候运用灵活，非宋兵所能及——作者借此说明古代少数民族军队往往都有这一特点，并非金朝独有。

**部落兵 / 代北部落兵。** 羯族石勒“以大单于镇抚百蛮”，用石虎为单于元辅，即令其率领胡族部落兵。《文献通考·兵考》谓拓跋氏起自云朔，“兵戎乃其所以为国”：羽林、虎贲是宿卫之兵，六镇将卒是御侮之兵，往往皆代北部落之苗裔，北魏之初即藉之以横行中国。西魏府兵制前期为鲜卑兵制、部酋分属制；府兵八柱国出自北魏鲜卑八国、八部之制，后期变化本篇只点出“此当另述”。

> 💡 相关前置概念与推导详见：[19_第十九篇_宇文氏府兵及关陇集团.md]

**国人与非国人。** 石勒“号胡（羯）为国人”，用人为办法把胡羯抬成“自己人”，把其余胡人与汉人打成非国人。石虎大兴劳役、兵役，巨大灾难落到非国人身上；石虎死后，冉闵反过来利用“赵人”诛诸胡羯，死者二十余万，“国人”几乎灭绝，后赵因之灭亡。这是本篇论证“民族关系未弄好则不能成功”的第一例。

**文化正统与士族。** 作者提出一条贯穿本篇的统一原则：历史上的统一不能从血统着手，要看文化高低——文化低的服从文化高的，次等文化服从高等文化；文化最高的是汉人中的士族。要统合汉人与各种胡人，就要推崇汉化；要汉化就要推崇汉人；推崇汉人莫过于推崇士族。当时中原衣冠多随东晋渡江，汉人正统似在南方，故苻坚坚持南伐：不攻取东晋，便不能自居于汉人正统，也就不能降服鲜卑等族，汉人也有离心倾向。孝文帝迁都洛阳，则是另一条争正统的路线：秦汉以来北部两个文化中心是长安与洛阳；北方汉人士族并不以江左政权为依归；洛阳为东汉、魏晋故都，北朝汉人有“认庙不认神”的观念，谁能定鼎嵩洛，谁便是文化正统所在。正统论中也有“谁得中原地方，谁便是正统”的说法。假定不能并吞南朝，也要定鼎嵩洛；单是定鼎而不搞汉化也不行。

> 💡 相关前置概念与推导详见：[16_第十六篇_北魏后期的汉化与孝文帝政策.md]

**淝水之战在本篇中的位置。** 它不是用来证明“南军忽然变强”，而是用来证明：苻坚南伐的目的是用夺取文化正统来解决民族问题；战败后崩溃的是本部氐兵精华，鲜卑、羌人无损失，民族分配与组织上的缺口因此爆开，前秦立即瓦解。

**北府兵。** 东晋与苻坚对峙时，东边谢石、谢玄所倚，有新近组成的北府兵。洛涧之役，刘牢之率北府劲卒夜袭梁成垒，歼灭氐军主力之一。到南朝，北府楚子集团已在逐渐腐化中——这是第三节解释南朝武力不足时补的一句。

**因粮于敌。** 江南驴马极少，军运几乎只能走水路；水运不济，北伐军便只能就地取敌方粮食。水运与因粮于敌二者有一个做不到，南朝就难言北伐。沈括《梦溪笔谈》把“师行因粮于敌”视为最急之务，并计算：打仗的兵七万人，若用人负粮需三十万人；若用牲畜运粮，虽负多费寡，但牧养不时则畜多疫死，一畜死则所负并弃，较之人负利害相平。运输困难使南朝很难发动大规模、持久的北伐。

**六镇鲜卑化武人集团 vs 洛阳汉化文官集团。** 孝文帝迁洛后，被迁到洛阳的鲜卑人汉化了，留在北镇的鲜卑人却保持旧俗。边镇鲜卑化武人与洛阳汉化文官矛盾尖锐，引发六镇暴动，北魏自身分裂。北齐依靠六镇鲜卑化变兵建立，上层反对汉人及汉化胡人；北周能任用汉人士族、改革府兵，民族界限在军队中消失，故能灭齐，再经隋时内徙六镇鲜卑汉化，北朝民族问题最后解决，南北统一才实现。

> 💡 相关前置概念与推导详见：[17_第十七篇_六镇问题与魏齐之兵.md]、[18_第十八篇_北齐的鲜卑化及西胡化.md]

## 论证推理链

### （一）北强南弱之形势

**论点一：南方户口长期低于北方，故经济上北胜南。**

- **论据 / 案例 / 事实：** 《晋书·苻坚载记》记苻坚入邺宫阅前燕名籍：郡一百五十七，县一千五百余，户约二百四十五万余，口约九百九十八万余——这是前燕户口。《通典·食货典》历代盛衰户口条综计：三国战争后，魏平蜀得户二十八万、口九十四万；当时魏氏本户约六十六万余、口约四百四十余万；晋武帝太康元年平吴，得吴户口远少于北方，全国合计户约二百四十五万余、口约一千六百余万，为“晋之极盛”。其后宋孝武帝大明八年，南方户仅约九十余万、口约四百六十余万；陈亡之时隋所收户五十万、口约二百万。北朝方面：后魏户约三百三十七万余；北齐亡时户约三百余万；后周大象中户约三百五十九万、口约九百万余。作者自己复述比较：魏户口已远高于吴蜀合计口数；前燕、后魏、后周的户、口，都明显高于宋、陈。
- **推导：** 在以耕织为基础的农业社会里，编户多少直接决定耕作、纺织与赋役总量。数字不是点缀，而是经济优劣的尺度。
- **结论：** 南北比较，经济上北方远胜南方；人口优胜即经济优胜。
- **延伸：** 后文北齐据山东、经济胜过据关中的北周，仍被北周所灭——说明“经济优胜”是潜在条件，还要看民族问题是否解决；但南朝对北朝的资源劣势，在第三节北伐失败中会再次被调用。

**论点二：军事上北朝亦胜南朝，根子是部落兵与骑兵—斥候体制。**

- **论据 / 案例 / 事实：** 北朝主力为胡人部落兵，酋长与部属情谊如父子，组织严密，以骑兵为主，必用斥候。南人夜袭北营，意在躲斥候。石勒将刘征寇南沙，都尉许儒遇害，进入海虞；次年复寇娄县，掠武进。石堪遣韩雍救马头不及，遂寇南沙、海虞，俘获五千余人。石虎自率众南寇历阳，临江而旋，京师大震。刘征、韩雍已打到江南吴郡乃至毗陵之境，石虎打到长江北岸历阳，建康受到很大威胁。石勒以大单于镇抚百蛮、石虎为单于元辅，即部落兵体制。《文献通考》又指北魏羽林虎贲、六镇将卒皆代北部落苗裔。
- **推导：** 羯族对南方的早期进攻已经把强弱异势摆出来，不必等到北魏极盛。组织、骑术、斥候三者互相加强：无部落情谊则组织不密，无骑兵则斥候体系失去载体，无斥候则骑兵优势难以展开。
- **结论：** 北朝军事胜于南朝，可用“组织之密、骑术之精、斥候之明”概括。
- **延伸：** 西魏府兵前期仍是鲜卑部酋分属制，八柱国来自八国八部——北朝武力传统一直延续到西魏；后期变为华夏兵制，要到本篇第二节末及第十九篇才交代。

### （二）北朝不能过早统一南北的原因（附淝水之战）

**论点三：北朝不能一举并吞南朝，主因是内部民族与文化问题未解决。**

- **论据 / 案例 / 事实：** 北朝政治上的统治者是胡人中的少数胡人；其下另有占绝大多数的其他胡人与汉人。整个胡族不及汉人多，统治者胡人又不及被统治者胡人多。问题不仅在胡汉之间，也在胡与胡之间。以此极少数人统治极大多数不同种族，问题遂至无穷。
- **推导：** 军事、经济上的“北强”被内部民族结构抵消。不先解决“谁是国人、谁代表文化正统、如何统合胡与胡、胡与汉”，外部统一无法完成。
- **结论：** 北朝之所以不能很快统一，主要在内部民族与文化问题没有解决。
- **延伸：** 下面三个失败/半成功案例（石勒石虎、苻坚、孝文帝）都是这条总因的分疏。

**论点四：石勒不能成功，在于未将“国人”与非国人的关系弄好。**

- **论据 / 案例 / 事实：** 石勒号胡羯为国人。石虎时期劳役、兵役的巨大灾难落到非国人的汉人与其他胡人身上。石虎死后，冉闵利用“赵人”诛诸胡羯，死者二十余万，国人几乎灭绝，后赵灭亡。
- **推导：** 人为制造的国人/非国人等级，先把灾难压给非国人，再激起非国人的报复性屠杀，统治族群自身被消灭。
- **结论：** 后赵亡于民族关系的制度性撕裂，不是亡于南朝反攻。
- **延伸：** 这为苻坚问题作铺垫：民族关系未弄好，外部军事行动会反噬内部。

**论点五：苻坚必欲南伐，是要用东晋所代表的文化正统来统合胡汉；淝水战败立即瓦解，是因为损失的全是本部氐人，鲜卑、羌人无损伤。**

- **论据 / 案例 / 事实：** 史家以为苻坚灭前燕、迁鲜卑于长安及其附近，造成恶果；淝水战败，鲜卑遂起。作者要解决两个问题：苻坚何以进攻东晋？淝水战败何以立即导致前秦瓦解？
  - **南伐动机：** 统一看文化不看血统；文化最高在汉人士族；中原衣冠多已渡江，汉人正统似在南方。不取东晋，不能自居正统，不能降服鲜卑等族，汉人也有离心。苻融曾说：陛下宠育鲜卑、羌、羯，布诸畿甸，旧人族类斥徙遐方；今倾国而去，如有风尘之变，慕容垂、姚苌皆我仇敌，思闻风尘、冀因其凶。作者认为苻坚岂能不知这隐忧？他正是因为了解民族问题未解决，才坚持南伐，取文化正统所在的东晋而代之。初不料淝水战败。
  - **兵力结构：** 南伐动用骑兵二十七万、步兵六十余万。骑兵为主力战斗兵，多为胡人；步兵用于运输，为汉人。东晋西边襄沔有桓冲，东边有谢石、谢玄及北府兵。太元八年五月，桓冲率众十万伐秦，攻襄阳；遣刘波等攻沔北诸城；杨亮攻蜀，拔五城；郭铨攻武当。苻坚分兵救襄阳、武当等，七月下诏大举南伐。布置以苻融督张蚝、慕容垂等步骑二十五万为前锋。八月发长安，九月至项城，十月苻融陷寿阳，慕容垂攻拔郧城（江夏郡云杜县），梁成等五万屯洛涧。
  - **洛涧之役：** 十一月，梁成五万人在洛涧西岸为刘牢之北府兵所败。《晋书·苻坚载记》记刘牢之率劲卒五千夜袭梁成垒，斩梁成及王显、王咏等十将，士卒死者万五。《谢玄传》记牢之五千人直指洛涧，斩梁成及成弟梁云，步骑崩溃争赴淮水，生擒梁他、王显、梁悌、慕容屈氏等。梁成所部为氐军主力之一，被歼。
  - **淝水之战：** 接着苻融所部二十余万又被全歼。《谢玄传》：玄、琰进，决战淝水南；苻坚中流矢，临阵斩融；坚众奔溃，自相蹈藉投水死者不可胜计，淝水为之不流，重以饥冻，死者十之七八。《朱序传》：谢石遣谢琰选勇士七八千人涉淝水挑战，坚众小却，朱序在军后唱“坚败”，众遂大奔。《苻坚载记》：苻融麾军却阵，欲待晋军半济而击，军遂奔退不可止；融驰骑略阵，马倒被杀；王师追至青冈一带，死者相枕；坚中流矢，单骑遁还淮北；诸军悉溃，惟慕容垂一军独全，坚以千余骑赴之。
  - **谁损失、谁独全：** 苻融、张蚝、慕容垂、梁成等二十五万中，损失最大的是洛涧梁成、寿阳苻融的军队，皆氏族精华。慕容垂所率鲜卑兵因西线桓氏兵强被分去郧城，未参加淝水，故独全。苻坚没料到溃败的是本部氐兵，鲜卑兵却无损伤。
  - **战后再分氐兵、转用鲜卑与羌：** 苻坚至渑池，慕容垂请至邺拜陵墓、张国威刑以安戎狄，坚许之，遣将率众三千送垂。垂已走，坚又怕其变，遣石越率卒三千、张蚝率羽林五千等分戍，留兵配毛当守洛阳——又是氐人精华、淝水遗众，被调去戍山东以防慕容垂。垂请去邺，因鲜卑根据地本在关东。前秦精锐即所谓“四帅子弟”，既一溃于淝水，又再分成于山东。坚回长安，不得不用鲜卑慕容泓、慕容冲之兵；二人变生肘腋，因缺乏氐兵相抗，又不得不用羌兵。羌人承鲜卑而起，苻坚最终被羌人姚苌所缢。
- **推导：** 南伐不是单纯的扩张冲动，而是想用“据有汉人文化正统”来压服境内鲜卑、羌、羯与汉人。这个赌注要求本部主力必须保持完整。洛涧、淝水连续歼灭氐军精华，又把残余氐兵调去防关东鲜卑，长安腹心空虚，鲜卑、羌人依次起事。民族分配与组织上的缺口，在战前苻融已经指出，战败后成为致命伤。
- **结论：** 苻坚败亡即在民族的分配与组织上有缺口：鲜卑、羌人无损失，损失的都是本部的人。淝水战败所以立即导致前秦瓦解，原因在此，不在“南军从此强过北军”。
- **延伸：** 这反证第一节的北强南弱并未被淝水推翻；它只证明北朝内部问题可以让“强”无法转化为统一。

**论点六：孝文帝迁洛行汉化，在争文化正统上相当成功，但仍未解决民族问题，北魏因六镇而分裂。**

- **论据 / 案例 / 事实：** 北方汉人士族并不向往南朝；洛阳为东汉、魏晋故都，有认庙不认神的观念；正统论中亦有据中原即为正统之说。孝文帝迁洛、行汉化，目的正在统合胡汉、确保北魏统治。被迁到洛阳的鲜卑人汉化了，留在北镇的鲜卑人保持旧俗；边镇鲜卑化武人集团与洛阳汉化文官集团矛盾尖锐，卒致六镇暴动。六镇尽叛，北魏分裂成两半。
- **推导：** 定鼎嵩洛加汉化，可以争取北方士族承认的文化正统，却把鲜卑群体本身撕成“洛阳汉化文官”与“北镇胡化武人”两块。争正统的成功，同时制造了新的内部对立。
- **结论：** 孝文帝仍旧没有解决民族问题；北魏不仅未能并吞南朝，自身也未能保住。
- **延伸：** 六镇起兵本篇只点到为止，详细论证交给第十七篇；北齐、北周的对比则紧接此条，说明“解决/不解决民族问题”决定谁能把北强转化为统一。

**论点七：北齐经济胜过北周而亡于周，因北齐不能善调民族关系，北周能解决，隋时民族问题最后解决，南北才统一。**

- **论据 / 案例 / 事实：** 《隋书·食货志》：“寻而六镇扰乱，相率内徙，寓食于齐、晋之郊。齐神武（高欢）因之，以成大业。”北齐依靠六镇鲜卑化变兵建立，上层统治者反对汉人和汉化的胡人。高欢之妻娄氏骂高洋之妻李祖娥（赵郡李希宗之女）为“汉老妪”一类蔑称。支持李祖娥的杨愔死时，废帝谓“岂敢惜此汉辈”。后主高纬时，韩凤骂朝士为“狗汉大不可耐，唯须杀却”。后主要去晋阳，崔季舒与从驾文官连名进谏，韩凤奏“汉儿文官连名总署，声云谏止向并，其实未必不反，宜加诛戮”，后主召已署表官人集含章殿，以崔季舒、张雕、刘逖、封孝琰、裴泽、郭遵等为首斩于殿廷。作者评：这样排斥汉人，在少数民族中尚少见。北周则重用汉人士族苏绰、卢辩，协助宇文泰治理。府兵制初为鲜卑兵制、部酋分属制，经周武帝与隋文帝改革，变成华夏兵制、兵农合一制，民族界限在军队中消失。北周灭北齐；隋时内徙的六镇鲜卑汉化，北朝民族问题最后解决，南北统一因此能够实现。南并于北，不是北方一举并吞，而是北方力量渐次南移，带蚕食性。
- **推导：** 山东经济优于关中，本应有利于北齐；但北齐把六镇鲜卑化武装的反汉倾向变成朝廷政策，汉人士族被骂、被杀，内部力量互相抵消。北周走相反的路：信任士族、改造兵制，把民族界限从军队中抹掉，潜在的北朝强力才释放出来。
- **结论：** 当北朝民族问题尚未解决之时，则南北分；一旦解决，则南北合。问题一解决，北朝内部便无民族冲突，潜在的强有力经济与武备力量遂能发挥，南朝抵挡不住。
- **延伸：** 统一的形态是渐次南移、蚕食，不是一次战役决定。这与淝水“一战并未改变北强南弱、却拆掉前秦”形成对照。

### （三）南朝北伐何以不能成功

**论点八：东晋南朝北伐皆未成功，原因有四：物力南不及北，武力南不及北，运输困难，南人不热心北伐、北人也不热心南人的恢复。**

以下四点各自成链，合起来“决定了南方北伐的无成”。

**（1）物力**

- **论据：** 南朝国力较北朝为弱，资源不及北方，尤其不及山东。第一节所引《通典》南北户口之差即是证据。
- **推导：** 北伐是持久消耗，户口与资源劣势会在补给线上放大。
- **结论：** 物力南不及北，是北伐无成的第一因。
- **延伸：** “尤其不及山东”为后来北齐据山东仍不能统一作伏笔：山东资源对南朝是达不到的高地，对北朝内部则是北齐的优势，但优势仍被民族政策抵消。

**（2）武力**

- **论据：** 南朝兵卒素质、纪律不及北兵，骑兵甚少。宋文帝元嘉二十七年伐魏，“以兵力不足，悉发青、冀、徐、豫、二兖等州三五民丁”，“又募中外有马步众艺武力之士应科者，皆加厚赏”；而“江南白丁轻进易退，卒以败师”（《文献通考·兵考》）。北府楚子集团到南朝已在逐渐腐化中。
- **推导：** 兵不足则发民丁、募市人；民丁无训练，故轻进易退。北府本是东晋少数能与北兵相抗的集团（洛涧已证明），入南朝却腐化，意味着南朝失去最接近北朝战斗力的那一支。
- **结论：** 武力南不及北。
- **延伸：** 这与第一节“组织、骑术、斥候”三条对照：南朝缺的不是个别勇将，而是整套兵种与纪律。

**（3）运输**

- **论据：** 江南驴马极少，军运唯有水路；水运不济便只能因粮于敌。二者有一项做不到，便难言北伐。沈括计算七万作战兵的负粮规模，人运需三十万，畜运则疫死风险使利害与人负相平。桓温北伐关中，本待麦熟取为军资，苻健芟苗清野，军粮不属，收三千余口而还。刘裕北伐南燕，议者忧南燕若刈粟清野则“非唯难以有功，将不能自反”；刘裕料鲜卑贪而“不及远计，进利克获，退惜粟苗”，必不能清野，后果然慕容超不能清野，包围广固时河北居民荷戈负粮而至者日以千数，遂灭南燕。其后伐后秦，王镇恶等在潼关下受阻，军又乏食，后得“义租”，才继续向关中。桓温曾以河南粗平，将移都洛阳；孙绰以为须先扫平梁、许，清定河南，运漕之路既通，然后尽力开垦、广田积谷，渐为徙者之资——作者称为卓识。
- **推导：** 水路若阻塞，粮道不通，北伐与移都洛阳都不可能。因粮于敌取决于敌人是否清野、当地居民是否肯供粮，二者都不可控。桓温败于清野，刘裕成于敌不能清野且河北供粮，反证运输条件决定战役能否持续。
- **结论：** 运输困难使南朝很难发动大规模、持久的北伐；勉强行之，必然无功，徒招损失。
- **延伸：** 孙绰把“运漕—开垦—移都”排成顺序，说明即使军事上暂时得河南，没有漕路与积谷，政治中心也无法北还。

**（4）人心**

- **论据：** 南渡北人对北伐的态度，可以王羲之为代表。王羲之与会稽王笺，陈殷浩不宜北伐：庙算须审量彼我，方全而后动；今功未可期而遗黎歼尽；千里馈粮自古为难，况转运西输许洛、北入黄河；以区区吴越经纬天下十分之九，不亡何待；须“根立势举，谋之未晚”。作者认为这代表南渡北人的一般看法，与只知苟且偷安的腐朽势力反对北伐有差别。即使刘裕，也不想久滞北方：义熙十三年八月克复长安，十一月因刘穆之卒即从长安南返，关中后来丢给赫连勃勃。未曾南渡的北人，既受少数族统治者长期统治，民族意识和其他关系转趋模糊，对南朝北伐也不感兴趣。《资治通鉴》晋哀帝兴宁二年：燕太宰慕容恪将取洛阳，先遣人招纳土民，远近诸坞皆归之，乃使军于盟津、成皋。慕容恪能招纳远近土民，正因为土民民族意识模糊。
- **推导：** 南渡北人并非全是苟安，而是算过物力、粮道、遗黎之后主张先“根立势举”；主持北伐者得地也不肯久驻。北方土民既已模糊民族意识，坞壁可归慕容氏，不必等南朝。南北两边都缺少把北伐做成“恢复运动”的社会热情。
- **结论：** 南人不热心北伐，北人也不热心南人的恢复。
- **延伸：** 这与第二节“北方士族并不以江左为依归、认庙不认神”相呼应：文化正统可以在洛阳被北朝争取，北方土民更不会为江左政权而战。

## 史料用法与讲授细节

- **先给总表，再给战例。** 户口用《晋书》载记与《通典》盛衰户口条做成南北长时段对照，然后才说石氏南寇、淝水、北伐。数字残缺处，作者在正文里用“九十余万 / 四百六十余万 / 五十万 / 二百万”等约数自己复述一遍，讲课逻辑靠复述而不是靠读者去对原表。
- **军事三语是压缩后的分析工具。** “组织之密、骑术之精、斥候之明”先由部落兵制推出，再用吕颐浩论金兵作旁证，最后用石勒、石虎南下证实“强弱异势可以看得很清楚”。
- **淝水被拆成“两个问题 + 兵力结构 + 两场歼灭 + 战后分配”。** 先问动机与瓦解原因，再讲骑兵胡人、步兵汉人，再讲洛涧歼梁成、淝水歼苻融，再讲慕容垂独全、氐兵再分山东、转用鲜卑与羌。战役叙述服务于“民族分配有缺口”，不是为了铺陈战术。
- **同一事件用多种史书对读。** 洛涧、淝水同时引《苻坚载记》《谢玄传》《朱序传》，互相补“夜袭 / 半济 / 朱序唱败 / 融马倒被杀 / 垂军独全”。北伐则《桓温传》《宋书·武帝纪》《王镇恶传》《王羲之传》《通鉴》分层。
- **北齐排汉用一组口语史料。** 娄氏骂“汉老”、废帝“汉辈”、韩凤“狗汉”“汉儿文官”，再落到含章殿集体处斩。作者特意评“在少数民族中尚少见”，把政策态度从制度分析推进到空气与语言。
- **北周对照只点关键人名与兵制方向。** 苏绰、卢辩、府兵由部酋分属到兵农合一，细节留给后篇；本篇只要读者看见“民族问题解决与否”这一对照轴。
- **运输节用计算加正反战例。** 沈括的三十万人负粮是“数量级直觉”；桓温清野失败 vs 刘裕不能清野而成功，是同一原理的正反实验；孙绰移都之议把军事问题提升为漕运—农业—政治中心的顺序问题。
- **人心节区分两种“不热心”。** 王羲之不是腐朽苟安，刘裕不是没有能力而是不肯久滞，北方土民是意识模糊。三种不热心机制不同，合成“北伐无社会基础”。

## 知识点全量梳理

- 南北比较：经济、武备北方远胜南方；古代人口为经济极重要因素。
- 东晋南北朝南方人口比北方少得多；前燕、魏晋、宋、陈、后魏、北齐、后周的户口对照，南方一直低于北方。
- 北朝军事：胡人部落兵、骑兵、斥候；优势三语：组织之密、骑术之精、斥候之明。
- 石勒、石虎已打到吴郡、毗陵、历阳，建康受威胁；石氏兵制为大单于—单于元辅领部落兵。
- 北魏羽林虎贲为宿卫，六镇将卒为御侮，皆代北部落苗裔。
- 西魏府兵前期：鲜卑兵制、部酋分属制；八柱国来自鲜卑八国八部。
- 北朝不能早统：内部民族与文化问题；统治者是胡人中的少数，问题在胡汉之间也在胡与胡之间。
- 石勒“号胡为国人”；冉闵诛胡羯，后赵亡。
- 统一看文化不看血统；推崇汉化—推崇汉人—推崇士族；苻坚南伐为争正统以统胡汉。
- 淝水：骑兵二十七万、步兵六十余万；洛涧歼梁成氐军；淝水歼苻融部；慕容垂鲜卑兵未参加故独全；战后氐兵再分山东；转用慕容泓、慕容冲及羌兵；苻坚为姚苌所缢。
- “四帅子弟”一溃淝水、再分成山东。
- 孝文帝迁洛行汉化，争正统相当成功；北方士族认庙不认神；定鼎嵩洛仍须汉化。
- 洛阳鲜卑汉化 vs 北镇保持旧俗 → 六镇暴动 → 北魏分裂。
- 北齐依六镇变兵，排汉；北周用苏绰、卢辩，府兵改革为华夏兵农合一；隋时六镇鲜卑汉化，民族问题最后解决，南北合；统一带蚕食性。
- 总公式：民族问题未解决则南北分，解决则南北合。
- 北伐四因：物力、武力、运输、人心。
- 元嘉二十七年发三五民丁，江南白丁轻进易退；北府集团渐腐化。
- 因粮于敌；沈括运粮计算；桓温遇芟苗清野而退；刘裕因慕容超不能清野且河北供粮而灭南燕；王镇恶潼关乏食，得义租后续进。
- 孙绰：先通运漕、广田积谷，然后言移都洛阳。
- 王羲之“须根立势举，谋之未晚”；刘裕克长安即南返，关中入赫连勃勃；慕容恪招纳土民，诸坞归之，北方土民民族意识模糊。
