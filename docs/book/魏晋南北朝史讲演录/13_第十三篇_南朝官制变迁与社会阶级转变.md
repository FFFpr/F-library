# 第十三篇 南朝官制的变迁与社会阶级转变的关系

## 本章定位与核心主张

本章把目光从政权转移与种族集团，转到国家机构本身：南朝官制为什么看起来名实不符，而这种名实不符又怎样对应社会阶级的变动。第十一篇说宋齐梁以武装善战的豪族为君主、以文化高门为公卿；第十二篇说梁末士族消灭、寒人与南方土著兴起。本篇补上制度这一环：楚子已经代替世族做了皇帝，九品中正却还在，高门仍要占住高级职位；皇帝既不能把他们从高位上赶走，又要把大权抓到自己手上，于是从机构上想办法——在同一系统中把重权寄给原来微不足道的小官，在不同系统之间让此系统侵夺彼系统。结果是：高官如宰相、领军有名而无实权，低官如中书舍人、制局监、外监、典签无名而有重权；正官不重要，兼差反而重要；文官武官、中央地方都可以戴上宰相桂冠，事权分散，互相牵扯。权力由高级官吏移于低级官吏，实质上即由最高贵族移于最低阶级。有权者作为恩幸，对皇帝必俯首帖耳；无权者职责不明，大家互相牵扯，对于唯予一人的君主专制，却有莫大的好处。看南朝的官制，只有从阶级的变动去看，才能看清楚。

中国的君主专制制度要求集权于皇帝一身。至如何集权，则视时代的不同而各有其方式。但有一点是相同的，即在一个系统或一个机构中，名实不符；在不同系统之间，此一系统的权力为旁一系统所侵夺。这是一个通则，非仅止是南朝如此。不然，皇帝便很难把大权都抓到自己手上。如果各个部门、各个地方、各个官吏都有实权，名实相符，互不相妨，那皇帝还能有权？

## 关键概念补全（术语先讲）

**九品中正与高门占位。** 六朝到刘裕为皇帝，阶级已起变化，楚子代替世族做了皇帝。但九品中正制度还存在，贵族、高门谁都不想做职位低的官吏，九品中正制度多少还能起到保证他们做高官的作用。皇帝也不可能把他们从高级职位上都驱逐出去，无论哪个皇帝，还需要他们的支持。于是皇帝便从机构上想办法。国家机构在古代，是保证君主专制的工具，如何设置，如何利用，权力都操于皇帝。一般说在南朝，高门仍做大官，寒族做小官。

**名实不符（系统内）。** 君主为与贵族争权，在同一个系统中，把重权寄给原系微不足道的小官。这种小官既为重权所寄，渐次变成真宰相大臣。中书舍人、制局监、外监、典签都是这一类。品位不提高，职名仍旧，权却压过其上司。

**系统之间的侵夺。** 不是一个系统，甲系统可以管乙系统的事，乙系统也可以管甲系统的事。如在文官系统与武官系统之间，皇帝便用武将来夺文官的权力。领军将军本掌内军，可预问政治，实际也是宰相；后来领军之权又移于制局监及外监。只要掌机密、录尚书、综机权、管朝政、侍中、给事中、受顾命，皆为宰相。宰相可以由中书、门下、尚书、扬州、大将军、卫尉等不同系统的人同时来做。

**中书舍人 / 通事舍人 / “四户”。** 中书监、令为魏文帝曹丕所置，用以分外朝尚书台阁之权。晋舍人在中书省中位居九品，本是极小的官吏。江左置通事郎，管司诏诰；其后郎还为侍郎，而舍人亦称通事。东晋舍人可以管司诏诰，权力有所上升。舍人之职品位既低，自可选用寒人，士族亦不屑于为此小官。宋孝武时犹士庶杂选，明帝时专为佞幸，全由寒人中选出。齐初舍人亦为诏文，中书侍郎之职被侵；齐明帝建武之时，诏命始不关中书，专出舍人，中书令之权又被侵夺。舍人成了真宰相。省内舍人四人，各住一省，世谓之“四户”，既总重权，势倾天下。其下有主书、令史，旧用武官，宋改文吏，天下文簿板籍入副其省，有如尚书外司。陈承梁，中书通事舍人为八品（《隋书》二十六《百官志上》）。

**制局监与外监。** 领军掌内外兵要。宋孝建以来，制局用事，与领军分兵权，典事以上皆得呈奏，领军拱手而已。制局小司本属领军，今专典兵力；征兵动众，断于外监之心；谴辱威福，恣于典事之口。制局监皆近幸。这一如中书令的权力为舍人所夺。

**典签 / 签帅。** 故事，府州部内论事，皆签，前直叙所论之事，后云谨签，日月下又云某官某签，故府州置典签以典之。本五品吏，宋初改为七职。宋氏晚运，多以幼少皇子为方镇，时主皆以亲近左右领典签，典签之权稍重。大明、泰始，长王临藩，素族出镇，莫不皆出教命于内，刺史不得专其任。典签递互还都，一岁数反，时主与之闲言，访以方事。刺史行事之美恶，系于典签之口，莫不折节推奉。威行州郡，权重蕃君。诸州唯闻有签帅，不闻有刺史。齐明帝诛异己，诸王见害，悉典签所杀，竟无一人相抗。

**兼差重于正官。** 特别是对皇帝的亲信来说，如果不兼一个地位低但有实权的官，则他的正官无论做得多大，也不起作用。梁朝朱异自迁尚书仪曹郎后便“入兼中书通事舍人”，此后迁转至于中领军，都是“舍人如故”。如果不兼一个舍人，就不能做宰相的事。

**恩幸。** 有权的小官作为恩幸，对皇帝必俯首帖耳。他们有权，不过是因为唯皇帝的意志是从，得到皇帝的宠信。《南史》有《恩幸传》，中书舍人、制局监、外监、典签的事迹多出其中。

## 论证推理链

### 一、通则：君主专制下的名实不符与系统互侵

- **论据 / 案例 / 事实：** 中国的君主专制制度要求集权于皇帝一身。如何集权，视时代而各有方式，但有一点相同：在一个系统或一个机构中，名实不符；在不同系统之间，此一系统的权力为旁一系统所侵夺。这是一个通则，非仅止是南朝如此。如果各个部门、各个地方、各个官吏都有实权，名实相符，互不相妨，那皇帝还能有权？
- **论证推导：** 先立通则，再入南朝，是为了避免把舍人、典签看成南朝特有的“乱政”或道德腐败。名实不符是集权技术：上司有名，亲信有实；甲系统牵制乙系统。
- **核心结论：** 南朝官制的“怪”，首先是专制集权的通则在这一时代的具体方式。
- **延伸推论：** 具体方式由阶级状况决定——高门占高位去不掉，所以只能把权寄到小官身上。下一点转入阶级。

### 二、阶级已变，九品中正仍在：高门做大官，寒族做小官，皇帝从机构上想办法

- **论据 / 案例 / 事实：** 六朝到刘裕为皇帝，阶级已起变化，楚子代替世族做了皇帝。但九品中正制度还存在，贵族、高门谁都不想做职位低的官吏，九品中正多少还能保证他们做高官。皇帝也不可能把他们从高级职位上都驱逐出去，无论哪个皇帝，还需要他们的支持。国家机构如何设置、如何利用，权力都操于皇帝。一般说在南朝，高门仍做大官，寒族做小官。
- **论证推导：** 帝位已经换了阶级（楚子），用人管道却仍保护旧阶级（中正→高官）。这个错位，不能用废中正、逐高门来解决，因为皇帝还需要高门支持。能做的，是在不废其“大官”的前提下，把“重权”另寄。
- **核心结论：** 君主为与贵族争权，在同一个系统中，把重权寄给原系微不足道的小官。这种小官既为重权所寄，渐次变成真宰相大臣。
- **延伸推论：** 第十一篇“善战豪族为君、文化高门为卿”的共治，在官制上表现为：卿的位子还在，卿的权被抽空。

### 三、中书舍人：从九品小吏到“四户”真宰相

- **论据 / 案例 / 事实：** 《南史》七十七《恩幸传》序：至如中书所司，掌在机务。在晋中朝，常为重寄。于时舍人之任，位居九品。江左置通事郎，管司诏诰。其后郎还为侍郎，而舍人亦称通事。元帝用琅邪刘超，以谨慎居职。宋文世秋当、周赳并出寒门。孝武以来，士庶杂选，如东海鲍照以才学知名，又用鲁郡巢尚之，江夏王义恭以为非选。及明帝世，胡母颢、阮佃夫之徒，专为佞幸矣。齐初亦用久劳及以亲信，关表启，发署诏敕。颇涉辞翰者，亦为诏文，侍郎之局复见侵矣。建武世，诏命始不关中书，专出舍人。省内舍人四人，所谓四省，其下有主书、令史，旧用武官，宋改文吏，人数无员，莫非左右要密。天下文簿板籍，入副其省，万机严秘，有如尚书外司。
- **四户与茹法亮：** 同卷《吕文显传》：吕文显，临海人也。永明元年，为中书通事舍人。与茹法亮等迭出人为舍人，并见亲幸。时中书舍人四人各住一省，世谓之“四户”，既总重权，势倾天下。同卷《茹法亮传》：茹法亮，吴兴武康人也。宋大明中，出身为小史。历斋干扶侍。孝武末年，鞭罚过度。校猎江右，选白衣左右百八十人，皆面首富室，从至南州，得鞭者过半。法亮忧惧，因缘启出家得为道人。武帝即位，仍为中书通事舍人。与会稽吕文度、临海吕文显并以奸谄得幸武帝。法亮、文度并势倾天下，太尉王俭常谓人曰：“我虽有大位，权寄岂及茹公！”
- **论证推导：** 中书监、令本是曹丕用来分尚书之权的。晋舍人九品，极小。东晋称通事，管诏诰，权始升。品位低，故可选用寒人，士族不屑。宋孝武犹士庶杂选，巢尚之为“人士之末”，江夏王义恭以为非选——说明此时高门还在抵制。到宋明帝，胡母颢、阮佃夫之徒专为佞幸，全由寒人中选出。齐初代写诏文，侵侍郎；建武诏命专出舍人，侵中书令。舍人成了真宰相。四户各住一省，文簿板籍入副，有如尚书外司，是机构上的坐实。王俭出身琅邪王氏，王导之后，一流士族，而茹法亮出身小史、面首、道人（僧徒），王俭连他的权也不如——士族权力降低到了什么程度，所谓“高官”职位，不过是一个空名义或一种安慰而已。
- **核心结论：** 一个部门，首脑无权而下属却有大权，首脑为士族，下属为寒门，首脑为传统的旧的政治力量，下属为皇帝的亲信。这种格局，便在加强君主的专制。
- **延伸推论：** 陈承梁，通事舍人仍为八品：品级不提，权已是真宰相。位高者无权（多为士族），有权者位很低（多为寒人），谁都反不了皇帝。这是南朝皇帝加强君主专制的妙方。

### 四、制局监与外监：领军拱手守虚位

- **论据 / 案例 / 事实：** 《资治通鉴》一百四十七梁武帝天监七年春正月：乙亥，以南兖州刺史吕僧珍为领军将军。领军掌内外兵要，宋孝建以来，制局用事，与领军分兵权，典事以上皆得呈奏，领军拱手而已。及吴平侯萧昺在职峻切，官曹肃然。制局监皆近幸，颇不堪命，以是不得久留中，丙子，出为雍州刺史。胡注：先用僧珍，次日出昺。《南史》七十七《恩幸传·茹法亮传》：（吕）文度为外监，专制兵权，领军将军守虚位而已。同卷论曰：制局小司，专典兵力，云陛天居，互设兰锜，羽林精卒，重屯广卫。若征兵动众大兴力役，优剧远近，断于外监之心，谴辱威福，恣于典事之口。
- **论证推导：** 《通鉴》之言说明制局小司本属领军。领军掌内外兵要，今制局小司专典兵力，征兵动众断于外监之心，典事以上皆得呈奏，领军将军也就变成拱手守虚位了。这一如中书令的权力为舍人所夺。从梁吴平侯萧昺为领军，以“在职峻切”遭到制局监的排挤、次日即出为雍州刺史，可看出制局势力的牢固：真想管事的领军，待不住。
- **核心结论：** 兵权领域重复了中书领域的同一格局：长官虚位，小司近幸专典。
- **延伸推论：** 吕僧珍与萧昺一日之内的人事安排，是讲授“先安一个、次日挤一个”的制度史细节，不是普通迁转。

### 五、典签：权重蕃君，诸州唯闻签帅

- **论据 / 案例 / 事实：** 《南史》七十七《恩幸传·吕文显传》：故事，府州部内论事，皆签，前直叙所论之事，后云谨签，日月下又云某官某签，故府州置典签以典之。本五品吏，宋初改为七职。宋氏晚运，多以幼少皇子为方镇。时主皆以亲近左右领典签，典签之权稍重。大明、泰始，长王临藩，素族出镇，莫不皆内出教命，刺史不得专其任也。宗悫为豫州，吴喜公为典签。悫刑政所施，喜公每多违执。悫大怒曰：“宗悫年将六十，为国竭命，政得一州如斗大，不能复与典签共临！”喜公稽颡流血乃止。自此以后，权寄弥隆，典签递互还都，一岁数反，时主与之闲言，访以方事。刺史行事之美恶，系于典签之口，莫不折节推奉，恒虑不及。于是威行州郡，权重蕃君。
- **诸王如囚：** 同书四十四《齐武帝诸子传·巴陵王子伦传》：先是高帝、武帝为诸王置典签帅，一方之事，悉以委之。每至觐接，留心顾问，刺史行事之美恶，系于典签之口，莫不折节推奉，恒虑弗及，于是威行州部，权重蕃君。武陵王晔为江州，性烈直不可忤，典签赵渥之曰：“今出都易刺史。”及见武帝相诬，晔遂免还。南海王子罕戍琅邪，欲暂游东堂，典签姜秀不许而止。还谓母曰：“儿欲移五步亦不得，与囚何异！”言行举动不得自专，求衣求食，必须咨访。永明中巴东王子响杀行事刘寅等，武帝闻之，谓群臣曰：“子响遂反。”戴僧静大言曰：“诸王都自应反，岂唯巴东！”武帝问其故，答曰：“天王无罪，而一时被囚，取一挺藕，一杯浆，皆咨签帅，不在则竟日忍渴。诸州唯闻有签帅，不闻有刺史。”竟陵王子良尝问众曰：“士大夫何意诣签帅？”参军范云答曰：“诣长史以下皆无益，诣签帅便有倍本之价，不诣谓何？”子良有愧色。及明帝诛异己者，诸王见害，悉典签所杀，竟无一人相抗。
- **论证推导：** 典签本是府州办“签”的小吏，品在五、七。权变重，是因为皇帝用亲近左右去监视幼少皇子和后来的长王、素族刺史。宗悫“不能复与典签共临”是旧式刺史尊严的一次爆发，以喜公稽颡暂止，此后权寄弥隆——说明反抗不能扭转结构。一岁数还都、与皇帝闲言，使典签成为中央插在州里的耳目；美恶系于其口，故折节推奉。诸王移五步不得、求藕求浆皆咨签帅、不在则竟日忍渴，把“权重蕃君”写成日常生活。戴僧静“诸王都自应反”是当时人的制度批评。范云“倍本之价”说明士大夫已按权而不是按官阶去走门路。明帝杀诸王悉由典签下手、无人相抗，是这一制度的尽头：地方上的“君”连自保的兵力与亲信都没有。
- **核心结论：** 朝廷上，皇帝把将相之权交给制局小司、外监、舍人；地方上，皇帝把刺史之权交给典签。但将相刺史之职均不废，制局监、外监、舍人、典签品级均不提。
- **延伸推论：** 像中书通事舍人，陈承梁皆循其制官，仍为八品。位高者无权（多为士族），有权者位很低（多为寒人），谁都反不了皇帝。这是南朝皇帝加强君主专制的妙方。

### 六、正官不重要，兼差反而重要：朱异“舍人如故”

- **论据 / 案例 / 事实：** 这就派生出了另一种现象，正官不重要，兼差反而重要。特别是对皇帝的亲信来说，如果不兼一个地位低但有实权的官，则他的正官无论做得多大，也不起作用。梁朝的朱异，自迁尚书仪曹郎后，便“入兼中书通事舍人”。其后，迁鸿胪卿、太子右卫率，加员外常侍，迁散骑常侍，迁右卫将军，改加侍中，迁左卫将军，领步兵，直到太清二年迁中领军，都是“舍人如故”。如果不兼一个舍人，就不能做宰相的事。
- **论证推导：** 朱异的迁转单看起来是不断升高：卿、率、常侍、卫将军、侍中、中领军，已是文武高位。但史笔反复写“舍人如故”，等于标明：真正使他能办事的，始终是那个低品兼差。正官是面子和阶序，兼差是管道。
- **核心结论：** 兼差比正官重要，是因为正官无实权，所兼之差才有实权。
- **延伸推论：** 第十二篇朱异的侈靡与提城门，是同一人的社会面；本篇“舍人如故”是他的制度面。寒士能薰灼内外，靠的是舍人这根管子接到皇帝，不是靠鸿胪卿或中领军的本职。

### 七、武官预政、多系统皆可称宰相：事权不可能分明

- **论据 / 案例 / 事实：** 再者，不是一个系统，甲系统可以管乙系统的事，乙系统也可以管甲系统的事。如在文官系统与武官系统之间，皇帝便用武将来夺文官的权力。像领军将军，《宋书》四十《百官志下》称领军将军“掌内军”，即统禁省之兵。领军可预问政治，实际也是宰相。《宋书》四《少帝纪》谓少帝即位，“以尚书仆射傅亮为中书监，司空徐羡之、领军将军谢晦及亮辅政”。同书八《明帝纪》谓明帝死时，袁粲、褚渊、刘勔、蔡兴宗、沈攸之同被顾命。按袁粲为尚书令，褚渊为护军将军（宋时护军掌外军），刘勔为领军将军。所谓“辅政”“受顾命”，即都是宰相。《宋书》六十三《沈演之传》记沈演之于元嘉二十年迁侍中，右卫将军如故。宋文帝曾对沈演之说：“侍中、领、卫，望实优显，此盖宰相便坐，卿其勉之。”这是武官如领军将军为宰相、预问政治之证。领军权力移于制局监及外监，这二监的参预政治，就更容易看出了。《南史》七十七《恩幸传》谓齐东昏侯时，茹法珍、梅虫儿并为制局监，他们与东昏侯的“左右应敕捉刀之徒并专国命”。后来他们又并为外监，口称诏敕，中书舍人王咺之与相唇齿。同中书舍人一样，他们都是真宰相。
- **《文献通考》的宰相定义：** 《文献通考》四十九《职官考三·宰相》：按此则或掌机密，或录尚书，或综机权，或管朝政，或单侍中，或给事中，或受顾命，皆为宰相也。只要戴上这些桂冠，不管是哪一个系统的官，便是宰相，便可管别一个系统或几个系统的事。同书举魏晋之例：魏文帝以刘放、孙资为中书监、令，并掌机密。晋武帝诏以荀勖为中书监、侍中，协赞朝政。张华为中书令、侍中，刘卞谓华曰：“公居阿衡之地。”东晋庾亮、庾冰相次为中书监。至冰经纶时务，升擢后进，朝野注心，咸曰贤相。殷浩为扬州刺史，参综朝权。王敦为大将军、侍中，上表曰：“臣备位宰辅。”谢安为中书监、录尚书事。这是魏晋时期中书监、中书令、侍中、扬州刺史、大将军、录尚书事之为宰相者。之所以为宰相，是因为或掌机密，或赞朝政，或为中书令、中书监、侍中、录尚书事，或参综朝权。中书监、令属中书省，侍中属门下省，扬州刺史为地方官，大将军为武职，录尚书事应属尚书省。它们都可以是宰相，可见宰相之杂。这使得事权不可能分明。
- **论证推导：** 武官预政，先用宋少帝、明帝顾命名单和文帝“宰相便坐”一语钉住：领军、护军、侍中、卫将军都可以是宰相。再把权下移到制局监、外监：东昏时近幸专国命、口称诏敕，与舍人唇齿，同为真宰相。通考用来说明“宰相”在魏晋南北朝不是一个专官，而是一串桂冠；南朝把这套“杂”用到极致。
- **核心结论：** 宰相之杂，使事权不可能分明；皇帝正要这种不明。
- **延伸推论：** 下一节用宋文帝同时多个侍中、齐东昏“六贵”，把“人多、力散、君集”说破。

### 八、宰相顿有数人：宋文帝的分散与齐“六贵”的诛灭

- **论据 / 案例 / 事实：** 《通考》续云宋文帝初，徐羡之为司空、录尚书事。后以江湛、王僧绰俱为侍中，任以机密。后又以殷景仁为侍中左卫将军，与侍中右卫将军王华、侍中左卫将军王昙首、侍中刘湛四人俱居门下。初王弘为江州刺史，加侍中，后征辅政，以为侍中、司徒、录尚书事。而弘弟昙首为文帝所任，与华相持。华常谓己力用不尽，每叹息云：“宰相顿有数人，天下何由得理！”（“理”，《宋书》六十三《王华传》作“治”。）刘湛母忧去职，后征为太子詹事，加给事中，与殷景仁并被任遇。湛常云：“今代宰相何难，此正可当我南阳郡汉代功曹耳。”（“代”，《宋书》六十九《刘湛传》作“世”。）沈演之为侍中、卫将军，文帝谓之曰：“侍中、领、卫俱为优重，此盖宰相便坐，卿其勉之。”同时几个人侍中，也就都是宰相。王华说“宰相顿有数人，天下何由得理”，殊不知宋文帝正是要使宰相人多，事权分散，大家的力量都用不尽，以便皇帝集中权力于一身。刘湛说当时做宰相正像做南阳郡功曹那样容易。他是太子詹事，被加上一个“给事中”的官名，便成了宰相。文帝说侍中、领军将军、卫将军都是“宰相便坐”，实际并不止此。
- **齐之六贵：** 《通考》续云：齐王俭为侍中、尚书令，常谓人曰：“江左风流宰相，惟有谢安。”盖自况也。明帝顾命，江祏兄弟及始安王遥光、尚书令徐孝嗣、领军萧坦之，更日贴敕，时呼为“六贵”。（《南史》六《梁本纪上·武帝》：时扬州刺史始安王遥光、尚书令徐孝嗣、右仆射江祏、右将军萧坦之、侍中江祀、卫尉刘暄更直内省，分日帖敕，世所谓“六贵”。）皆宰相也。这六个在齐东昏侯之初同时担任宰相职责的人，他们的本官是：扬州刺史、尚书令、右仆射、右将军、侍中、卫尉。雍州刺史萧衍说：政出多门，乱其阶矣。《诗》云：“一国三公，吾谁适从？”况今有六，而可得乎！嫌隙若成，方相诛灭（《梁书》一《武帝纪上》）。
- **论证推导：** 政出多门就等于谁都没有实际的宰相的权力，不论谁都难管事，不论何事都互相牵扯。到头来一个个都要被皇帝诛灭。“六贵”的命运便是如此。真正有权的，唯皇帝一人。中书舍人、制局监、外监之所以有权，也不过是因为他们唯皇帝的意志是从，得到皇帝的宠信。王华叹力用不尽，文帝正要他用不尽；刘湛觉宰相像郡功曹，说明桂冠贬值；王俭自况谢安，对照的是茹法亮“权寄岂及茹公”——风流宰相的自我期许，压不过舍人。萧衍用《诗》一国三公推到六贵必相诛灭，既是观察，也是他自己起兵的口实。
- **核心结论：** 各个系统的人都可以做宰相，在皇帝看来是无关痛痒的，因为宰相本来有名无实。人多了，反而可收牵制之效。
- **延伸推论：** 有名无实的宰相（士族、宗室、大臣）与无名有实的恩幸（舍人、外监），是同一集权设计的两面。

### 九、总括：权力下移即阶级下移；必须从阶级变动看官制

- **论据 / 案例 / 事实：** 概括言之，南朝官制名实不符，高官如宰相、领军，有名而无实权，低官如舍人、制局监无名而有重权。文官如中书监、令的宰相权，从历史来看，是层层下降的。东晋犹有通事郎管司诏诰，后却将通事的职务交给舍人，称通事舍人，郎还为侍郎。舍人由此取得了管司诏诰的权力。有点文化的，后又代写诏文，侍郎之职于是被侵夺。到齐明帝之时，诏命专出舍人，中书令也等于虚设了。宰相不做宰相事，正官即使如朱异大到做散骑常侍、中左右卫将军、领军，也要兼一个舍人。兼差比正官重要，是因为正官无实权，所兼之差才有实权。至于各个系统的人都可以做宰相，在皇帝看来，是无关痛痒的，因为宰相本来有名无实。人多了，反而可收牵制之效。权力由高级官吏移于低级官吏，实质上即由最高贵族移于最低阶级。这是由于当时的皇帝不想由高阶层的人做高阶层的事，而倚之以另一阶层造成。南朝官制名实不符，包含了社会变动的意义。而有权者作为恩幸，对皇帝必俯首帖耳。无权者职责不明，本为刺史，如参综朝权，也可管到别一个系统的事。大家互相牵扯，对于唯予一人的君主专制政治制度的加强，却有莫大的好处。这是南朝职官制度的特点。看南朝的官制只有从阶级的变动去看，才能看清楚。
- **论证推导：** 最后一段把机构史还原成阶级史：权的下移＝贵族的失权＝寒人／最低阶级的得权。皇帝“不想由高阶层的人做高阶层的事”，是主观；九品中正仍让高门坐高位，是约束；寄权于小官、兼差、多宰相，是办法。恩幸必须帖耳，因为权来自宠，不来自门第或本官。无权者互相牵扯，反叛形不成单一中心。
- **核心结论：** 南朝官制名实不符，包含了社会变动的意义；不从阶级变动看，就只看见紊乱。
- **延伸推论：** 与第十二篇合观：都邑士族在社会上被消灭之前，已经在官制上被抽空；寒人在陈朝与南方土著共掌政权之前，已经作为舍人、典签、外监预握真权。制度下移与社会下移是同一过程的两个侧面。

## 史料用法与讲授细节

1. **开篇先讲专制通则，再讲南朝阶级错位。** 通则：系统内名实不符，系统间互相侵夺。没有这一层，舍人典签会被讲成“宦官式败政”。
2. **刘裕为帝＝楚子代世族，与九品中正仍在，必须对举。** 高门做大官、寒族做小官是外观；重权寄小官是内里。
3. **中书舍人用《恩幸传》序作年代尺：** 晋九品 → 江左通事郎／舍人亦称通事 → 元帝刘超谨慎 → 宋文秋当、周赳寒门 → 孝武士庶杂选（鲍照、巢尚之，义恭以为非选）→ 明帝胡母颢、阮佃夫专为佞幸 → 齐初亲信署诏、侵侍郎 → 建武诏命专出舍人。这条尺不能打乱。
4. **四户：四人各住一省，文簿板籍入副，如尚书外司。** 机构史要讲到“省”的实体，不只讲“得宠”。
5. **王俭“权寄岂及茹公”是全篇最响的对照。** 必须交代茹法亮：小史、斋干、白衣左右、鞭罚忧惧出家为道人、再入为舍人。一流士族 vs 面首道人。
6. **制局、外监用天监七年吕僧珍／萧昺连日人事，《通鉴》胡注“先用僧珍，次日出昺”。** 吕文度外监专制兵权，领军守虚位。论赞“断于外监之心，恣于典事之口”宜读出。
7. **典签先讲“签”的文书起源，再讲权如何重。** 宗悫怒、喜公稽颡是转折；一岁数还都是机制；子罕东堂、子响藕浆、戴僧静“诸王都自应反”、范云“倍本之价”、明帝诸王皆死于典签，是递进的生活化证据。
8. **品级不提是“妙方”的关键。** 陈舍人八品，职不废、品不升、权已夺。谁都反不了皇帝。
9. **朱异迁转要列到中领军，每次都标“舍人如故”。** 与第十二篇侈靡传互见，但本篇只取制度意义。
10. **宰相之杂：先宋少帝辅政、明帝顾命的具体名单（徐羡之、傅亮、谢晦；袁粲、褚渊、刘勔等），再文帝“宰相便坐”，再通考桂冠定义，再魏晋诸例（刘放孙资、荀勖、张华、庾亮庾冰、殷浩、王敦、谢安）。** 让学生看到“杂”有长时段。
11. **王华“何由得治”、刘湛“汉代功曹”、王俭自况谢安、萧衍“一国三公况今有六”，四句话是四个观察者对同一设计的反应。** 讲者站在文帝／皇帝设计一边解释，不必同意王华的行政理性。
12. **六贵本官要列全：扬州、尚书令、右仆射、右将军、侍中、卫尉。** 命运是相诛灭；真权仍在皇帝与恩幸。
13. **收束段几乎是本章的主题句，宜整段掌握：** 权由高级官吏移于低级官吏＝由最高贵族移于最低阶级；名实不符包含社会变动；必须从阶级变动看官制。
14. **与前后篇的接法：** 不要在本篇重讲楚子、蛮族的史事，只用“阶级已变”“最低阶级”把制度接到第十一、十二篇的社会史。

## 知识点全量梳理

- 君主专制要求集权一身；方式因时而异，通则是：系统内名实不符，系统间权力互侵。各部门若名实相符互不相妨，皇帝便难有权。
- 刘裕为帝，楚子代世族；九品中正仍在，高门不做低官，中正保证高官；皇帝不能尽逐高门，仍需其支持，故从机构上想办法。
- 南朝一般：高门做大官，寒族做小官；重权寄于原微不足道的小官，渐成真宰相。
- 中书监、令：曹丕置，以分尚书之权。
- 晋舍人九品，极小；江左通事郎管诏诰，其后郎还为侍郎，舍人亦称通事，权上升。
- 品位低，选用寒人；士族不屑。
- 元帝用刘超，谨慎居职。
- 宋文：秋当、周赳出寒门。
- 孝武：士庶杂选；鲍照以才学；巢尚之人士之末，义恭以为非选。
- 明帝：胡母颢、阮佃夫专为佞幸，全出寒人。
- 齐初：久劳亲信，关表启，发署诏敕；能文者亦为诏文，侵侍郎。
- 建武：诏命不关中书，专出舍人，侵中书令；舍人真宰相。
- 舍人四人四省＝四户，总重权，势倾天下；主书令史，宋改文吏，无员，左右要密；文簿板籍入副，如尚书外司。
- 吕文显临海，永明中书通事舍人，与茹法亮迭出入。
- 茹法亮吴兴武康：小史，斋干扶侍，白衣左右，忧鞭罚出家为道人，齐武时舍人；与吕文度、吕文显奸谄；势倾天下。
- 王俭：琅邪王氏，王导后，一流士族，太尉，叹“我虽有大位，权寄岂及茹公”。高官成空名安慰。
- 格局：首脑无权（士族、旧力量），下属有大权（寒门、皇帝亲信）→ 加强君主专制。
- 领军掌内外兵要；孝建以来制局用事，分兵权，典事以上得呈奏，领军拱手。
- 天监七年：吕僧珍为领军；吴平侯萧昺在职峻切，制局近幸不堪，次日出为雍州。
- 吕文度外监专制兵权，领军守虚位。
- 征兵动众断于外监之心，谴辱威福恣于典事之口。
- 典签：源于府州文书“签”；本五品吏，宋初七职。
- 宋晚幼少皇子为方镇，亲近左右领典签，权稍重；大明泰始，长王、素族出镇亦不得专，教命内出。
- 宗悫豫州 vs 吴喜公，不能与典签共临；其后权寄弥隆。
- 典签一岁数还都，皇帝闲访问方事；刺史美恶系其口；威行州郡，权重蕃君。
- 齐高帝武帝置典签帅，一方之事悉委之。
- 武陵王晔为赵渥之诬，免还；南海王子罕游东堂，姜秀不许，“移五步亦不得，与囚何异”；求衣食必须咨访。
- 巴东子响杀刘寅等，帝曰反；戴僧静：诸王都自应反；取藕一杯浆皆咨签帅，不在则竟日忍渴；诸州唯闻签帅，不闻刺史。
- 竟陵子良问何意诣签帅；范云：诣长史以下无益，诣签帅有倍本之价。
- 明帝诛诸王，悉典签所杀，无一人相抗。
- 将相刺史职不废，小司品不提；陈舍人八品。位高无权（士族），有权位低（寒人）。此为加强专制妙方。
- 正官不重要，兼差重要；不兼低位实权官，正官再大不起作用。
- 朱异：仪曹郎起兼通事舍人，经鸿胪、右卫率、员外常侍、散骑、右卫、侍中、左卫领步兵，至太清二年中领军，皆舍人如故；不兼舍人不能做宰相事。
- 甲乙系统可互管；皇帝用武将夺文官权。
- 领军掌内军（禁省兵），可预政，实际是宰相；护军掌外军。
- 少帝：徐羡之、傅亮、谢晦辅政。明帝顾命：袁粲（尚书令）、褚渊（护军）、刘勔（领军）、蔡兴宗、沈攸之。
- 文帝谓沈演之：侍中、领、卫，宰相便坐。
- 东昏：茹法珍、梅虫儿制局监，与应敕捉刀之徒专国命；后为外监，口称诏敕，与舍人王咺之唇齿；皆真宰相。
- 通考：掌机密、录尚书、综机权、管朝政、侍中、给事中、受顾命，皆宰相；不管哪一系统，皆可管别系统。
- 魏晋宰相之杂：刘放孙资中书监令；荀勖中书监侍中；张华中书令侍中（阿衡）；庾亮庾冰中书监；殷浩扬州刺史参综朝权；王敦大将军侍中自称宰辅；谢安中书监录尚书。中书、门下、扬州、大将军、尚书皆可。
- 宋文帝同时多侍中皆宰相；王华叹宰相顿有数人何由得治；帝正要人多力散，已力用不尽。
- 刘湛太子詹事加给事中即宰相，自谓如南阳郡汉代功曹。
- 王俭自况谢安风流宰相。
- 六贵：遥光（扬州）、徐孝嗣（尚书令）、江祏（右仆射）、萧坦之（右将军）、江祀（侍中）、刘暄（卫尉），分日帖敕。
- 萧衍：政出多门，一国三公况有六，嫌隙成则相诛灭。六贵命运如此。
- 真权唯皇帝；舍人、制局、外监有权因宠信、唯意志是从。
- 中书权层层下降：通事郎→通事舍人→代写诏文侵侍郎→建武专出舍人，令虚设。
- 权力由高级官吏移于低级官吏＝由最高贵族移于最低阶级；皇帝不想高阶层做高阶层的事，倚另一阶层。
- 名实不符包含社会变动；恩幸帖耳；无权者职责不明、互相牵扯；利于唯予一人。
- 南朝职官特点必须从阶级变动看才清楚。
