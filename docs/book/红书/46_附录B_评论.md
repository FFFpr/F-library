# 附录B：评论

## 本章位置

本附录是荣格对自己部分章节与意象的事后评论，不是另一次幻想叙事。编译者按《修改的草稿》页码分三条：86–89页、103–119页、127–150页。编者注分别对应于本书约155–163、164–172、173–184页，内容对得上第一卷「神秘戏剧」三章：以利亚与失明的莎乐美、火山口中的第二次下降、两条蛇与善恶。它补在图版附录之后、宇宙学附录之前：先有 [45_附录A.md](45_附录A.md) 的图像档案，本篇用概念把已发生的幻象说清楚，再交 [47_附录C.md](47_附录C.md) 的「普天大系」。

## 核心论点

**发生了什么：** 无新的幻想情节。荣格重读已写下的意象，说明它们为何要叫「神秘戏剧」，以及每一物件（房子、水晶、夏娃、花园、向左走、玛利亚、狮子、孩子、双蛇）在他事后的诠释里是什么。

**荣格对幻想的诠释（主张）：**

1. **这些意象是被见证的隐喻性幻象，不是像其他章节那样被体验的简单经验。** 它们人格化无意识思想，更唤出思考与诠释；荣格把它们总称为「神秘戏剧」。它们不是意识事先编好的 allegory。
2. **老智者=逻各斯（精神原则：理解、洞察、预见、法规、智慧）；少女=爱洛斯（情感原则：欲望、渴望、驱力、活跃、快乐和痛苦）。** 二者对立又彼此依赖。先知形象适合逻各斯；爱洛斯是倒进容器的酒，不是河床。
3. **莎乐美并非爱洛斯的精确化身：** 她失明、从属于以利亚，品性上是杀圣人者并与父亲乱伦。失明=不完整。男人灵魂更倾逻各斯，故逻各斯已征服并弄瞎爱洛斯；必须让爱洛斯重新获得视力。
4. **被压抑的心灵活动会退化成恶习；** 摆脱痛苦的路是接受灵魂中被压抑的部分，爱自己的劣势甚至恶习，使堕落内容重新发展。停留在无斗争的「天堂」=谋杀圣人。接受未发展看起来像罪与堕落，却比牺牲另一面维持秩序更大。
5. **向左走是盲目的爱洛斯走向心脏一侧（不受意识意志控制）；** 没有逻各斯，跟着走是罪。只有意识作为概念存在，向左才被允许。水晶=期待性注意力的最大专注。
6. **夏娃/奥德修斯=爱洛斯的肉体侧；玛利亚/彼得/教皇/佛祖=精神侧。** 精神的爱可伪装成世俗力量驱力。佛祖舍弃苦乐进入空无；若自我走这条路，身后重集的激情可变成嗜血的迦梨。爱洛斯不能离开肉体。
7. **第三种可能是亲子关系（以利亚父、莎乐美妹、自我儿子/哥哥）——基督教儿童期解决。** 它能驯化激情，但孩子渴望成长；逃回儿童期会在爱洛斯与精神力量之间来回霸占。莎乐美称玛利亚为母亲=自我变成基督=离开儿童期并「取代」基督——同时自我处于绝对劣势与孤独，并非自我膨胀。
8. **善与恶作为两条蛇同样危险。** 自我应扎根中点；不无条件向善投降表现为黑蛇攻击；不参与邪恶表现为黑蛇长出白头。对立暂时失效，人被放到中间位置，但明晰的世界观仍未到达。

条目前的三个词——「年龄」「男性」「生活方式的对立转化」——是本评论的题记，正文未再展开定义。

## 关键概念补全

**神秘戏剧：** 荣格给这组意象起的总名。强调它们更像被见证的隐喻，而非其他章里那些可直接认知的简单经验。它们以幻象出现，事后才显出不可与其他经验相比。

**逻各斯：** 精神原则。后人之一是努斯（Nous，理智），理智曾与情感、预感、感觉混在一起；逻各斯包含这混合却不是其结果，而是支配它的独立形式：理解、洞察、预见、法规、智慧。老先知是其隐喻。体现坚持。给予形式，如河床。

**爱洛斯：** 非精神原则，即情感。包含并支配所有基本灵魂活动，目的不是给形式而是实现形式：容器里的酒、河中的水。欲望、渴望、驱力、活跃、快乐和痛苦。命令与坚持之处也是消解与运动之处。年轻少女意味着运动。未失明的爱洛斯也管理所有灵魂基本活动。

**原始意象：** 属于一般人类历史、不属于个人、不朽；人人拥有，反复出现在思想家和诗人作品中。有秘密力量，对理性与灵魂同样起作用，如咒语与魔法，导致上升也导致诱惑。在人「全然是人」之处抓住人。编者注[2]：荣格借用雅各布·布克哈特描述浮士德和俄狄浦斯原始意象的隐喻，曾在《力比多的转化与象征》（1912，《荣格全集B》§56n）引用。

**以利亚：** 幻象中的老先知。评论中他=逻各斯的人格化。房子表示逻各斯与爱洛斯永远栖息在我们身上。斜靠大理石狮子时，狮子=力量，石头=牢固。

**莎乐美：** 以利亚之女。连续秩序的象征；从属于逻各斯。失明=缺陷与对父亲的依赖。圣经形象：希律王之女，杀圣人，乱伦——用来解释「坏形式」：原则失去尊严后的堕落。向左摸索=爱洛斯走不吉利/心脏一侧。

**水晶：** 增强的创造性注意力所产生的物体意象；自古用来制造幻象。不是魔法道具本身，而是「更强的创造性注意的专注」。用于看见最初无法理解、位置更深的形象。

**夏娃 / 玛利亚：** 爱洛斯的肉体母亲（诱惑、树与蛇）对精神母亲（肉体的童贞）。只看见夏娃=失明；意识唤起带来爱洛斯的精神视野。

**奥德修斯 / 彼得 / 教皇 / 佛祖 / 迦梨：** 水晶或幻象序列里的自我投射。奥德修斯：冒险，终回母亲般的潘妮洛普；误入赛斯与卡里布索。彼得：被拣选的石头、钥匙（捆绑与松开）。教皇：神在地上戴三重冠的统治者。佛祖：舍弃苦乐、入空无、火碰不到。迦梨：前方征服后激情在身后重集、无理性之眼与仁慈时的毁灭嗜血女神；评论引其祭祀咒语。

**儿童期解决：** 把关系改写成父/妹/子，类似「神在基督教儿童期的概念」。日常可用孩子般状态驯化激情；缺陷是孩子要长大，且抛弃儿童期等于撤掉来自基督教世界观的情绪—习惯道德依赖。

**西门·马格斯与海伦：** 评论说老人与少女也可叫这个名字，但「重要的是他们都是圣经中的人物」——以利亚与莎乐美这一对才标出此刻心灵混乱的特点。西门·马格斯：原文只作为可替换的人名对出现，未展开生平。

## 论证推理链

### 一、86–89页：神秘戏剧、逻各斯与爱洛斯、莎乐美的失明

编者注[1]：页码指《修改的草稿》，对应于本书155–163页（即「神秘遭遇」）。

- **论据/案例/事实**
  - 题记：年龄；男性；生活方式的对立转化。
  - 意象很难被强迫发声，却极具隐喻性，故「应该说话」。与以往经验不同：更多被见证，而非被体验。
  - 场景在黑暗大地深处=明亮意识空间之下的内在深度。下沉=把精神目光从外物转到内在黑暗。注视黑暗且不带意识期待，才让背景自己呈现，不受意识假设干扰。
  - 意识把握不住呈现出来的强大心理活动。老智者与年轻少女出乎意料步入视野；此轮廓反复出现于人类精神。
  - 房子=固定住所=二人永远栖息在我们身上。
  - 大厅发光墙=未识别、唤起好奇之物，把创造性卷入织进更深意象；由此出现水晶。
  - 夏娃+树与蛇=诱惑（已包含在莎乐美中）→奥德修斯式冒险→阳光花园：红花树=爱欲情感发展，井=稳定来源，冷水不醉=逻各斯（莎乐美后来说先知的深「井」）。
  - 以利亚说他与女儿总是合一；但原则是两个。莎乐美转向「我」，因爱洛斯需要帮助。
- **论证推导过程：** 先定性这组幻象（见证/隐喻/人格化思想），再把人物钉到逻各斯—爱洛斯对上。女儿从属关系若按「对立原则」则不成立，故莎乐美只能是「同一类的一种」，失明是证据。男人灵魂偏逻各斯，解释了征服、失明、以及为何爱洛斯会由「不愉快」的莎乐美来代表。花园的井把爱欲发展说成也是知识来源——爱洛斯一侧并非纯混乱。
- **核心结论：** 必须让被征服的爱洛斯恢复视力；诠释这些意象是正当的，因为它们本来就靠近思维。
- **延伸推论/现实启示：** 原始意象能侵入、占有、消耗个体，即使理解力与情感反抗。蛇最清晰地标出这种危险：夜间、怪异，当逻各斯与爱洛斯都还作为未识别的无意识原则起作用时，蛇与二者都相连。

原则与压抑（同条后续）：

- **论据/案例/事实：** 原则须有独立尊严；失去则呈坏形式。压抑使心灵活动退化成恶习；公开或秘密的恶习取代合法活动→人格不统一、道德痛苦、真实疾病。唯一出路：接受被压抑部分，爱劣势甚至恶习，让堕落内容再发展。逻各斯统治处有持久秩序；天堂隐喻=无斗争=无发展→被压抑者退化=谋杀圣人。逻各斯像希律王因弱点不能保护圣人，只保住自己，导致爱洛斯堕落；只有违抗统治原则才能走出未得发展的坚持。天堂故事重复：蛇缠树，亚当应当受诱惑。每一种发展都带来未发展；未发展中发展几乎无价值，发展又是最高价值。必须抛弃或明显放下这最高价值才能照顾未发展；接受未发展像罪、错步、堕落、沉入更深——事实上这比牺牲存在的另一面维持有序更大，故会受堕落支配。
- **论证推导过程：** 从莎乐美的「坏」推到一般法则：不是爱洛斯本恶，而是原则被压成恶习。无冲突的完美状态会谋杀它本应保护的圣人。
- **核心结论：** 下降去照顾未发展，不是失败，是比片面秩序更大的行动。
- **延伸推论/现实启示：** 想摆脱人格分裂之苦，必须爱自己的劣势。

### 二、103–119页：向左、水晶中的精神力量、儿童期与取代基督

编者注[3]：对应于本书164–172页（即「引导」）。

幻想对话/场景层（评论所复述）：同一深处；火山口加强巨洞感（不活跃却猛烈喷出）。莎乐美盲目向左摸索，蛇跟着同一方向。以利亚唤回她。自我如孩子般感到渺小。以利亚问意图，「我」承认盲目。水晶中先出现神之母抱孩子，再有彼得、钥匙、教皇；佛祖在火中；多臂女神/迦梨。后以利亚向左走，莎乐美已有视力；以利亚斜靠石狮。莎乐美称玛利亚为母。结尾：忧郁，对高高静静燃烧、被蛇包围的火焰。

评注层：

- **论据/案例/事实**
  - 幻觉中最微不足道的细节都举足轻重。左=不吉利=非意识意志与选择的一侧=心脏一侧。蛇=魔法力量，也出现在动物驱力被不知不觉激起时；魔法效果=着魔+用动物本能强调思想与情感。
  - 向左盲目=无目的意图，需要引导，但须是逻各斯而非意识意图。失明是痛苦，须治愈；进一步看，她或无辜，坏或因失明。
  - 唤回莎乐美=逻各斯力量已超越爱洛斯；蛇也顺从。二者结合的强观点→自我渺小，以孩子气表达。
  - 无逻各斯而跟盲目爱洛斯向左：不可能或应被制止。从逻各斯看，盲目跟着是罪：片面，违反「必须永远争取达到意识最高水平」（人性在此，否则与动物无异）。引基督：「如果你知道自己在做什么，你便受到祝福；如果你不知道自己在做什么，你会受到诅咒。」编者注[4]：此句为《路加福音》6章4节在《伯撒抄本》中的杜撰插入；J.K.艾略特编《伪新约》68页；荣格1952年《答约伯书》（《荣格全集第11卷》§696）引用。只有意识被当作概念存在，向左才可能被允许。
  - 概念的第一步=意识到运动的目的；以利亚问意图；所承认的只有渴望、希望，要解开前一意象的混乱。意识化在莎乐美心中搅起模糊快感（洞察=疗盲）=迈向治愈爱洛斯。
  - 自我劣势：从未注视心灵深度，只认意识世界为有效，否认内在冲动；下降像罪疚、背叛意识理想。因解开混乱的欲望大于自卑之厌，自我把自己交给逻各斯；视野仍空，故打开更深，用水晶=期待性注意力的最大专注。
  - 夏娃↔玛利亚：肉体诱惑之母 vs 童贞与精神之母。爱洛斯先向肉体后向精神。只见夏娃则失明。第一种结局：奥德修斯终回潘妮洛普。第二种：彼得/钥匙/教皇。精神力量运动的片面：夏娃幻象误入奥德赛（赛斯、卡里布索）；神之母使欲望离肉体、走向卑微的精神崇拜。爱洛斯在肉体受谬误控制，在精神中升到肉体谬误之上，几乎不知不觉变成精神；肉体之上的力量伪装成爱；精神甩掉爱的覆盖——自以为爱精神，实则统治肉体。越有力越少爱；越不爱精神越有肉体力量。精神的爱以精神伪装变成世俗力量驱力。
  - 基督靠承受痛苦征服世界；佛祖靠舍弃苦乐征服苦乐，进入空无（不归）。佛祖更高：不靠控制肉体获乐，已超越苦乐，火碰不到；基督仍须不断更大努力去征服激情。若活跃自我走向佛祖状态：人不必死，激情会离开。我们岂不就是自己的激情？激情离开后在自我眼睛看不到的身后重集；无理性之眼、无仁慈，火成迦梨。引咒：「啊，迦梨……愿你得到血的荣耀！」莎乐美必绝望：爱洛斯变成精神则爱洛斯不能离肉体存在。对抗肉体劣势=对抗女性灵魂（象征力图压制意识、对抗精神的一切）。自我从冲突形象的注视中返回。
  - 逻各斯与爱洛斯再结合，似已征服精神/肉体冲突。向左改由逻各斯带头，且带着现已有视力的双眼。先入更大黑暗，再被红光（爱洛斯）微照。自我不能发亮光；爱洛斯至少提供认识的机会——若逻各斯协助。
  - 石狮上的以利亚=逻各斯的力量与牢固。意识在更深、已更新的环境中再出现。自我更渺小，被严重不属于自己的东西淹没，避开自己的方向；以利亚控制发展中的意识。
  - 水晶要传达的想法=精神力量=自我被诱去冒充先知。遇阻抗情感则躲到幕后。自我既不能盲目跟爱洛斯，就用精神力量交换损失——人类生命中常见；爱洛斯迫使人在力量里找替代。诡计几乎注意不到：作为规则的自我不能享用自己的权利，因它没拥有权利，而被权利魔鬼拥有。于是自我易把以利亚当成自己的重要人格；意识已预知这欺骗。
  - 鲜活形象不应视为个人的（即使个人倾向负责）。它们只像手和脚属于人格中较小部分；手和脚的出现不是人格特征，至多是其个体特征。特征在于这一对被叫作以利亚与莎乐美（也可叫西门·马格斯与海伦），且是圣经人物——此乃此刻心灵混乱的特点之一。
  - 排除夏娃可能与玛利亚象征后，第三可能=亲子：父/妹/子哥，避开肉体与精神两极端。类似基督教儿童期的神概念；莎乐美像玛利亚以可怕诱惑补上缺失的母亲。这解决有疏通效果，因似乎完全可能。人人身上有孩子；老人身上这甚至是唯一仍有活力的内容；可随时求助，饱满而忠实；一切（含不吉利）可通过再变成孩子而无害。日常生活中这样做就够；把自我带回孩子可驯化激情，火焰常在孩子般哀叹中熄灭。基督教教育以千百圣歌赞美诗灌输孩子概念，使这剂药更显满意。
  - 莎乐美说玛利亚是他们的母亲=破坏性：孩子解决得不到发展，立刻推出「若玛利亚是母，自我就是基督」。若保持孩子：莎乐美只是小妹，以利亚是慈父，自我以孩子信任把策略留给父亲。缺陷：每个孩子渴望成长；因怕爱洛斯而回孩子→孩子朝精神力量长；因怕精神危险逃回儿童期→被爱洛斯霸占。精神的儿童期只是过渡，不是人人能停。爱洛斯向自我显示不可能成为孩子。抛弃儿童期的后果不是（许多人可承受的）教条与宗教可能性的损失，而是更深远的态度——超越基督教世界观、曾为个体生命思想提供可靠方向的那一层。即使早已不修炼、不后悔，人仍直觉行事，仿佛原始观点仍正当。人们不认为被弃世界观须被新的取代；更不清楚弃基督教世界观会侵蚀当代道德感。抛弃儿童期=不再对来自该世界观精神的道德观有情绪或习惯依赖。例：思维完全自由，对爱洛斯的态度仍停在旧基督教观点。不能再毫无疑问地等待时代，否则仍是儿童期。只拒教条=只在理智解放，更深情感仍走旧路。多数人未意识到这造成与自己不和；后代会不断意识到。注意到的人恐惧地发现：抛弃重新开始的儿童期会把他们逐出当下时代，不能再循任何传统；进入无路无边界的未知，因已弃所有确立方向。很少人认识到；大部分半途而废，以愚昧精神状态保持泰然。不紧不慢不合所有人口味；有人宁愿自暴自弃，也不愿依附一种世界观并抛弃习惯旧路；宁愿冒死进入无路的黑暗土地，即使激发全部胆怯。
  - 「玛利亚是母亲」=自我是基督=已离开基督教儿童期并取代基督。假定由此推出自我极度重要最荒谬；相反，自我绝对劣势。以前的优势是作为强大形象背后的人群之一员；现在换成孤独落寞，像耶稣一样孤独地活在自己世界，却无伟人特征。与世界格格不入需要伟大支撑，自我体验到的是荒谬贫乏——故莎乐美的透露可怕。超越基督教世界观却没有明确做到→虚伪深渊、极度孤独、无法隐藏事实。人想说服自己没那么糟，但的确很糟。抛弃关系到群集本能上能发生的最糟之事，再加上令人退缩的任务。摧毁易，重建难。
  - 结尾忧郁 vs 被蛇围着的高高静静燃烧的火焰=奉献与魔法冲动成对；对疑惑恐惧有有效对应：「你的自我充满不安和怀疑，但持续奉献的火焰在你心中燃烧得更猛烈，你命运的冲动变得更强大。」
- **论证推导过程：** 第二次下降把爱洛斯的问题从「失明女儿」推进到「肉体母亲 vs 精神母亲 vs 儿童期亲子」。精神侧的胜利会偷换成权力驱力，或把激情赶到身后变成迦梨——所以不能用佛祖式空无来解决爱洛斯。冒充先知是权利魔鬼的诡计。儿童期药有效且被基督教教育加持，但莎乐美一句「玛利亚是母亲」把药打碎，把人抛到「取代基督」的孤独里；评论反复强调这不是自我膨胀。最后用奉献之火与蛇的魔法冲动，给尚未有新世界观的人一对仍在工作的内在事实。
- **核心结论：** 向左必须有意识概念；爱洛斯必须被治愈而不是被精神化掉；儿童期不是终点；「我是基督」在体验上是贫乏与孤独。
- **延伸推论/现实启示：** 只在理智上拒绝教条、情感仍走旧路，会造成与自己不和，后代会看见。明确抛弃而无新方向，等于无路之地。

### 三、127–150页：双蛇、中点、善恶暂时失效

编者注[5]：指173–184页（即「终解」开端的山脊、双蛇）。

- **论据/案例/事实：** 上一意象的深远预感使自我陷入怀疑混乱，于是渴望超越困惑、更大明晰——表现为悬垂的山脊。逻各斯似乎引路。两组对立：两条蛇；白昼与黑夜。光亮=善，黑暗=恶；二者都以不可抗拒的蛇的形象出现。「谎言在这里隐藏一种想法」：遇黑蛇会像遇白蛇一样惊讶；颜色不驱散恐惧；善与恶或许同样危险，迷惑人的力量同时在二者中。善本质上应被视为一种并不比恶危险的原则。自我决定靠近白蛇就像接近黑蛇，即使它相信必须更多地托付给善。但自我扎根中点，固定在此，观察两种原则在内部争斗。留在中间=恶的进步（因绝不无条件向善投降会伤害恶）——表现为黑蛇攻击。自我没有参与邪恶=善的胜利——黑蛇长出白色的头。蛇消失=善恶对立已无效，或至少失去当前意义。对自我=从恒久不变的道德观点的无条件力量中释放，喜欢从两极解放出来的中间位置。但明晰清晰的观点都没得到，故继续上升到最终高点，或许会产生渴望已久的世界观。
- **论证推导过程：** 善被画成白蛇并不等于安全。中点不是调和主义口号，而是：不把自身无条件交给任何一极。黑蛇咬过来证明「中点伤害了恶」；黑蛇变白头证明「未参与恶」。对立从舞台上撤走之后，人得到的是位置，不是已经完成的世界观。
- **核心结论：** 站在善恶之间的中点，比投奔「善」的颜色更重要；对立可暂时失效，解释仍未完成。
- **延伸推论/现实启示：** 无条件向善投降本身可以是一种危险。

## 实操方法与教学细节

本章以评注为主，不是逐步技术规程。原文仍给出可操作的态度与程序：

- **不要强迫意象发声；** 让它作为幻象出现，事后再诠释。这些「神秘戏剧」更须思考，不能用对待简单经验的同一套认知。
- **注视黑暗、不带意识期待，** 好让背景自己呈现。下沉=把目光从外物转到内在深度。
- **幻觉细节全都举足轻重**（左右、蛇的方向、失明、颜色）。
- **水晶=把期待性注意力加到最大；** 用于看见更深、起初不懂的形象。
- **向左（心脏/非意识意志）必须有逻各斯作为概念：** 先承认自己对意图的无知与渴望；盲目跟着是罪。引文标准是「知道自己在做什么」。
- **对待压抑：** 接受被压抑部分，爱劣势甚至恶习，让其再发展；不要用无斗争的秩序去谋杀圣人。
- **不要把鲜活形象当成「我的人格」或拿来冒充先知；** 它们像手和脚，只是人格较小部分。意识要预知「权利魔鬼」的交换。
- **儿童期解决可用在日常生活驯化激情，但不能当终点；** 只拒教条而情感仍走旧路，会与自己不和。
- **善恶双蛇：** 扎根中点观察内在争斗；不要因为白就无条件投降。对立失效后仍须继续上升，因明晰尚未到来。
- **避坑：** 用精神力量补偿爱洛斯的损失；用佛祖式空无赶走激情（身后成迦梨）；把「我是基督」听成自我伟大；半途而废却泰然自若。

12. 【第一档·陈述】在「我」这里逻各斯更高一筹：以利亚说他与女儿总是合一。但逻各斯与爱洛斯并未合一，是两个。此情况中逻各斯已使爱洛斯失明并征服之。若如此，使逻各斯摆脱爱洛斯的控制也开始必要，爱洛斯将重获视力。故莎乐美转向「我」，爱洛斯需要帮助；也因此「我」能注视这意象。男人灵魂更倾逻各斯而非爱洛斯，爱洛斯更具女人本质。逻各斯征服爱洛斯既解释失明，也解释爱洛斯由莎乐美这不愉快形象代表：她品性恶劣，谋杀圣人，与父亲乱伦。
13. 【第一档·陈述】原则须有独立尊严；失去则失去基础，呈坏形式。心灵活动与品质的发展若被压抑退化所剥夺，就变成恶习。公开或秘密恶习取代合法活动→人格不统一=道德痛苦与真实疾病。想摆脱此苦只剩一条路：接受灵魂中被压抑部分，爱自己的劣势甚至恶习，使堕落内容重新发展。
14. 【第一档·陈述】逻各斯统治处有秩序，但非常持久。天堂隐喻=无斗争=无发展适合那里→被压抑活动退化、失去价值=对圣人的谋杀。谋杀发生是因逻各斯像希律王，因弱点不能保护圣人，只能保住自己，导致爱洛斯堕落；只有违抗统治原则才能走出未得发展的坚持。天堂故事不断重复：蛇缠树，亚当应当受诱惑。
15. 【第一档·陈述】每一种发展都带来未发展，而未发展能够得到发展；未发展状态下发展几乎无价值，发展又无疑是最高价值。人必须抛弃这价值、或至少明显放下，才能照顾未发展。这与发展鲜明对立（发展或是最好最高成就），故接受未发展像罪、错步、堕落、沉入更深——事实上这比牺牲存在的另一面停留在有序状态更大，因此会受堕落支配。

18. 【第一档·必要依据】爱洛斯最初带来最严肃的问题，故莎乐美入场，盲目向左摸索。幻觉中最微不足道的细节都举足轻重。左=不吉利=不朝右（意识、意志、选择）而走向心脏一侧（较不受意识意志控制）。蛇总朝同一方向，凸显向左。蛇=魔法力量，也在动物驱力被不知不觉激起时出现；它们经得住爱洛斯的运动，这怪异强调像魔法一样作用于我们：着魔，并借助动物本质的本能冲动强调思想与情感。
19. 【第一档·陈述】向左是盲目的=无目的意图，故需引导，但不是意识意图而是逻各斯。以利亚唤回莎乐美；失明是痛苦，须治愈。进一步审视至少部分消除偏见：她似乎无辜，坏或应归因于失明。
20. 【第一档·陈述】逻各斯唤回莎乐美=确定其力量已超越爱洛斯。蛇也顺从逻各斯；它依赖二者是为强调意象的力量与重要性。这魔法的自然结果、二者结合的强观点=强烈感到自我渺小不重要，通过孩子气的感觉寻求表达。
21. 【第一档·限定】无逻各斯干预而跟随盲目爱洛斯向左：不可能或应被有效制止。从逻各斯看，盲目跟着是罪：片面，违反人必须永远争取达到意识最高水平的法则（人性在此，否则与动物无异）。基督：「如果你知道自己在做什么，你便受到祝福；如果你不知道……你会受到诅咒」（编者注[4]：《伯撒抄本》插入句）。只有意识被当作概念存在，向左才可能被允许。无逻各斯介入就不可能形成这概念。
22. 【第一档·陈述】形成概念的第一步=意识到运动的目的或意图。以利亚问「我」的意图；必须承认盲目=对意图无知。唯一得到认可的是渴望、希望，要解开第一个意象造成的混乱。
23. 【第一档·陈述】这意识化在莎乐美心中搅起模糊快感：意识=洞察=疗盲。必须迈出治愈爱洛斯的一步。
24. 【第一档·陈述】自我仍处劣势：无知阻止它进一步调查；不知方向；从未把目光投向心灵深处，只认眼睛所见与意识力量，视意识世界为有效，有意无意否认内在冲动。面对深度只能沮丧。意识上界的信念如此坚定，下降到原我深度就像罪疚、对意识理想的背叛。
25. 【第一档·陈述】因解开混乱的欲望大于对自卑的厌恶，自我把自己交给逻各斯的引导。视野仍无答案，故须打开更深；需要水晶=期待性注意力的最大专注。水晶中第一个意象：神的母亲带着孩子。
26. 【第一档·陈述】此意象与第一幻象的夏娃相关又相反：夏娃=肉体诱惑与肉体之母；神之母=肉体童贞与精神之母。爱洛斯先向肉体后向精神。夏娃是肉体侧，玛利亚是爱洛斯的精神一面。只看见夏娃=失明；意识唤起带来爱洛斯的精神视野。第一种情况：自我成奥德修斯，结局是变老的男人回到母亲般的潘妮洛普身边。
27. 【第一档·陈述】接下来自我被描绘成彼得：被拣选的石头，教堂建于其上。钥匙=捆绑与松开的力量，把人带到教皇：神在地上戴三重冠的统治者。
28. 【第一档·陈述】自我卷入朝向精神力量的运动，片面性证明这一点。夏娃幻象误入奥德赛，至赛斯与卡里布索。神之母使欲望脱离肉体，带向卑微的精神崇拜。爱洛斯在肉体内受谬误控制，在精神中升到肉体谬误之上，几乎不知不觉变成精神；肉体之上的力量伪装成爱，精神甩掉爱的覆盖：自以为爱精神，实则统治肉体。越有力越少爱；越不爱精神越有肉体力量。因其力在肉体之上，精神的爱以精神伪装变成世俗力量驱力。
29. 【第一档·陈述】基督以承受痛苦征服世界；佛祖以舍弃苦乐征服世上苦乐，进入空无（不归的状态）。佛祖甚至是更高精神力量，不靠控制肉体获乐，因已超越苦乐。基督仍须不断、甚至更大努力去征服激情；佛祖已远离如大火包围他的激情，不受影响，火碰不到。
30. 【第一档·限定】若活跃自我走向这种状态：人不必因此死去，激情会离开。我们岂不是自己的激情？激情离开后，自我作为只看前方的意识永远看不到身后——身后正是激情在前方被征服后重新集结处。无理性之眼引导、无仁慈缓和，大火成毁灭嗜血的迦梨，从内部吞噬生命。引其祭祀咒。莎乐美必对这结局绝望：它可能把爱洛斯变成精神，而爱洛斯不能离开肉体。对抗肉体劣势时，自我对抗的是女性灵魂——她象征力图压制意识、对抗精神的一切。故自我从对体现自身冲突的形象的注视中返回。
31. 【第一档·陈述】逻各斯与爱洛斯再结合，好像已征服精神与肉体的冲突，似乎知道解决之道。向左起初从爱洛斯开始，现在从逻各斯开始；带着原先失明、现在有视力的双眼。先入更大黑暗，再被红光（爱洛斯）某种程度照亮。自我不能发亮光；爱洛斯至少提供认识某些东西的机会——哪怕仅仅引入一种情境，若逻各斯能协助。
32. 【第一档·陈述】以利亚斜靠大理石狮子：狮子=皇家动物=力量，石头=无法动摇的牢固→逻各斯的力量与牢固。意识再次最先出现，但在更深、环境已更新之处。自我体验渺小，把自己从所知世界移得更远，在此意识到自己的价值与意义；被严重不属于自己的东西淹没，完全避开自己的方向。以利亚获得对发展中意识的控制。
33. 【第一档·陈述】水晶所要传达的想法=精神力量=自我被诱去冒充先知。这想法遇阻抗情感便无法再与意识对抗，躲在幕后。自我不能盲目跟爱洛斯，于是用精神力量交换这损失（人类生命中常见）。巨大损失几乎不可避免，爱洛斯迫使人至少在力量范围内找替代。发生方式怪异狡猾，几乎注意不到。故作为规则的自我不能享用自己的权利：它没拥有权利，而被权利魔鬼拥有。于是自我很容易把以利亚这活生生的现实加到自己身上，视其为自己的重要人格。但意识已预知这欺骗。
34. 【第一档·限定】鲜活形象的出现不应视为个人的，即使个人明显倾向为其出现负责。它们只像手和脚属于人格较小部分；仅手和脚出现不是人格特征，若有特征也只是其个体特征。故自我的特征是：老人与少女被称作以利亚和莎乐美（也可称西门·马格斯与海伦），而重要的是他们都是圣经人物。此乃此刻心灵混乱的特点之一。
35. 【第一档·陈述】对精神力量诱惑的意识把爱洛斯问题再次推到前台，并排除夏娃可能性与玛利亚象征。剩下第三可能：亲子关系，避开肉体与精神两极端——以利亚父、莎乐美妹、自我儿子兼哥哥。类似神在基督教儿童期的概念；莎乐美像玛利亚以可怕诱惑弥补仍缺失的母亲。基督教解决有不可否认的疏通效果，因似乎完全可能。人人身上有孩子；老人身上这甚至是唯一仍有活力的内容。可随时求助这孩子般内容：取之不尽的饱满精神与忠实。一切、甚至不吉利之物，都能通过重新变成孩子而无害。
36. 【第一档·续】最重要的是日常生活中这么做就够。甚至可把自我带回孩子以驯化激情；激情火焰更常在孩子般哀叹中熄灭。像孩子一样像一剂满意的药，尤其因基督教教育以千百圣歌赞美诗把孩子概念灌入心中。
37. 【第一档·陈述】因此莎乐美认为玛利亚是他们母亲的说法更具破坏性：孩子般解决得不到发展，立刻引出——若玛利亚是母亲，自我不可避免就是基督。孩子解决本可消除疑虑：莎乐美只是小妹，以利亚是慈父，其智慧洞察会用孩子般信任把自我留在他的策略那里。
38. 【第一档·限定】孩子解决的不幸缺陷：每个孩子渴望成长。成为孩子关系到燃烧的欲望和对长大的急不可耐。因怕爱洛斯危险而回孩子→孩子将朝精神力量发展；因怕精神危险逃回儿童期→被爱洛斯力量霸占。
39. 【第一档·陈述】精神的儿童期是过渡，不是人人能停留。此情况中爱洛斯向自我显示不可能成为孩子。以为抛弃儿童期不可怕的人，是不懂后果。被抛弃的不是（许多人可承受的）古老基督教观点及其宗教可能性，而是更深远的态度：远远超越基督教世界观、为个体生命与思想提供可靠且经得住考验之方向的那一层。即使早已远离修炼且不后悔，人仍直觉行事，仿佛原始观点仍正当。人们不认为被弃世界观须被新世界观取代；尤其不清楚弃基督教世界观会侵蚀当代道德感。抛弃儿童期=不再对迄今有效、来自该世界观精神的道德观有情绪或习惯依赖。
40. 【第一档·续】例如：思维完全自由，对爱洛斯的态度仍停在旧基督教观点。不能再毫无疑问地平静等待我们的时代，否则仍是儿童期。仅拒绝教条=只在理智层解放，更深情感仍走旧路。多数人未意识到这如何使他们与自己不和；后代会不断意识到。注意到的人恐惧地认识到：抛弃重新开始的儿童期会把他们逐出当下时代，不能再循任何传统；进入无路无边界的未知，因已抛弃所有确立方向。很少人能认识到；大部分半途而废，以愚昧精神状态保持泰然。不紧不慢不合每一人口味；有人宁愿自暴自弃，也不愿依附一种世界观并完全抛弃习惯旧路；宁愿冒死进入无路的黑暗土地，即使激发全部胆怯。
41. 【第一档·陈述】莎乐美说玛利亚是他们的母亲=自我是基督=自我已离开基督教儿童期并取代基督。由此假定自我极度重要最荒谬；相反，自我处于绝对劣势。以前的优势是强大形象背后的人群之一员；现在换成孤独落寞，像耶稣一样孤独生活在自己世界，却无伟人优秀特征。与世界格格不入需要伟大支撑，自我体验到的是荒谬可笑的贫乏。这解释莎乐美透露何以可怕。
42. 【第一档·限定】无论谁超越基督教世界观却没有明确做到，都将落入虚伪深渊、极度孤独、缺乏任何隐藏事实的方式。人想说服自己没那么糟，但它的确很糟。抛弃关系到能发生在群集本能上的最糟之事，更不用说背上令人退缩的任务。摧毁容易，重建很难。
43. 【第一档·陈述】意象以忧郁结束，但与被蛇包围、高高却静静燃烧的火焰相对立。奉献与蛇所代表的魔法冲动成对出现，成为对疑惑恐惧不安的有效对应：自我充满不安和怀疑，但持续奉献的火焰燃烧更猛，命运的冲动更强。
44. 【过渡/场景】条目「127~150页」（编者注[5]：指173–184页）。
45. 【第一档·陈述】第二个意象的深远预感使自我陷入怀疑的混乱。于是出现可理解的欲望：超越困惑、获得更大明晰——如悬垂的山脊意象。逻各斯似乎引路。接下来两组对立：两条蛇；白昼与黑夜。光亮=善，黑暗=恶；二者都以不可抗拒的蛇的形象出现。这里隐藏的想法极重要：遇黑蛇会像遇白蛇一样惊讶；颜色不驱散恐惧；二者或许同样危险，迷惑力量同时在善与恶中。善本质上应被视为并不比恶危险的原则。自我决定靠近白蛇就像接近黑蛇，即使它相信必须更多地托付给善而非恶。但自我扎根中点并被固定，观察两种原则在自己内部的争斗。
46. 【第一档·陈述】仍留中间=恶的进步（绝不无条件向善投降会伤害恶）→黑蛇攻击。自我没有参与邪恶=善的胜利→黑蛇长出白色的头。
47. 【第一档·陈述】蛇消失=善恶对立已无效，或至少失去当前意义。对自我=从迄今恒久不变的道德观点的无条件力量中释放，喜欢从两极解放出来的中间位置。但明晰清晰的观点都没得到，故持续上升到最终高点，或许会产生渴望已久的世界观。
