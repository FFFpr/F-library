# 第一卷　第七章　谋杀英雄

## 本章位置

本章属第一卷《来者的路》（Liber Primus）正文第七篇，页码约 261–270。上一章 [15_第一卷_第06章_精神的分裂.md](15_第一卷_第06章_精神的分裂.md) 已把「走向地狱即变成地狱」、灵魂与「我」的内战，以及「无名之辈射杀王子」的预感推到极限；本章把那一预感做成幻象：在黎明的高山上谋杀西格弗雷德。谋杀之后，深度精神给出一句「最高的真理只有一个，同时又很荒谬」，紧张以大雨释放，并出现彩色花园的第二幻象。评注层把「杀英雄」讲成杀自己身上已老去的神，好让新神得以出生——下一章 [17_第一卷_第08章_神的孕育.md](17_第一卷_第08章_神的孕育.md) 即由此展开。

## 核心论点

**幻想层（发生了什么）**

1. 第二天夜里，「我」与一位年轻人埋伏在高山石路上，用枪射杀坐在人骨战车上的西格弗雷德；随即逃跑，天降倾盆大雨。
2. 事后「我」几乎被折磨致死，确信必须杀死自己，否则解不开「谋杀英雄」之谜。
3. 深度精神说：「最高的真理只有一个，同时又很荒谬。」这句话像甘雨，把高度紧张一扫而空。
4. 第二幻象：白色丝绸中的人走在被红、蓝、绿光笼罩的花园里。「我」判定自己已跨越深度，并「通过犯罪获得新生」。

**评注层（荣格对幻想的诠释）**

5. 人不仅生活在白天，也生活在梦中；有时最伟大的事业是在梦中完成的。杀神不能一蹴而就，凡人只能装成刺客去接近已老的神。
6. 神希望被战胜，因为他们需要重生。人们杀掉王子，是因为他们杀不掉、也不知道要杀掉自己身上的神。
7. 现实同时是白昼与黑夜、意义与荒谬；意义只是荒谬与荒谬之间的过渡。
8. 西格弗雷德是「我」最珍视的力量、勇敢与荣耀；公平再战只会自己被暗杀。要活下去只能狡猾。雨是死者的泪，带来埋葬与重生，长出「青春焕发的神」。

## 关键概念补全

**西格弗雷德（Siegfried）**：古德国、古挪威史诗中的英雄王子。本章幻想里他坐人骨战车、吹号角、被埋伏枪杀。评注称他为金发碧眼的德意志英雄。编者注补充：十二世纪《尼伯龙根之歌》写其骑射与赤金号角；妻布伦希尔特被骗在其要害作记号，导致他受伤被杀；瓦格纳改编为歌剧《尼伯龙根的指环》。1912 年荣格在《力比多的转化与象征》中视其为力比多象征（编者注，非本章正文定义）。

**深度精神**：第一卷中对「我」说话的内在声音。本章它给出「真理同时又很荒谬」的句子，使谋杀后的紧张崩解。

**刺客 / 杀神**：评注说凡人不能在一次战斗中把神杀掉，只能装成刺客接近他。编者注记《草稿》在「刺客」处续写「犹大」。

**反基督 / 恶龙**：评注说基督钉十字架后进入阴间、变成地狱，因而披上反基督的外衣（恶龙）；古人以「反基督人」意象宣告新神诞生。

**意义与荒谬**：成对出现的存在方式，如白昼与黑夜互相需要；单独存在的只有「白昼和黑夜」这一整体，亦即「意义和荒谬」这一整体。

## 论证推理链

### （一）幻想：谋杀西格弗雷德

- **论据/案例/事实**
  - 黎明、高山、年轻人同行；西格弗雷德号角回荡；人骨战车沿陡坡飞下；石路转弯处开枪，当场毙命；逃跑时大雨；事后几乎被折磨死，觉得必须自杀才能解谜。
- **论证推导过程**
  - 幻象把上一章「无名之辈射杀王子」做成具体行动。「我」与年轻人是刺客，英雄是敌人。雨紧接谋杀而来。折磨来自「必须杀死自己」与「必须杀死英雄」之间的同一谜。
- **核心结论**
  - 在幻象里，英雄已被杀掉；解开此谜的代价被体验为「杀死自己」。
- **延伸推论/现实启示**
  - 原文此处尚未把英雄等同于「优势功能」；那是编者所引 1925 年讲座的后释，见下文编者注，不是本章评注正文。

### （二）深度精神的句子与第二幻象

- **论据/案例/事实**
  - 「最高的真理只有一个，同时又很荒谬。」紧张如久旱逢甘雨被扫空。第二幻象：白丝绸、红蓝绿光的花园。结语：「我已经跨越深度。我通过犯罪获得新生。」
- **论证推导过程**
  - 谋杀造成的伦理与心理死结，不能用「更高的正确」解开，只能用「真理=荒谬」这一对等把紧张泄掉。花园彩光是跨越深度之后的景象，不是对谋杀的道德开脱，而是「犯罪」被当作新生的通道。
- **核心结论**
  - 跨越深度的标志：能同时持有最高真理与荒谬；新生来自这场「犯罪」，而非来自洗白它。

### （三）评注：杀神只能当刺客；神要被战胜才能重生

- **论据/案例/事实**
  - 那夜生命受威胁，因为必须杀掉自己的主和神。凡人不能一次战斗杀神，只能装成刺客接近。神希望被战胜以便重生。人们杀王子，是杀不掉、也不知要杀自己身上的神。
- **论证推导过程**
  - 白天的英雄崇拜把「神」安在王子/英雄身上。神一旦老去，最高真理变成最大谎言。杀外在英雄是替代动作：真正该死的是内在已老的神。神自己需要这场死，否则无法重生。
- **核心结论**
  - 谋杀英雄在评注里等于（间接地）谋杀自己身上的旧神；刺客姿态是凡人唯一能接近神的方式。
- **延伸推论/现实启示**
  - 编者注：《草稿》点出「犹大」。勿把「当刺客」写成可照做的伦理建议——正文说的是内在神的死亡与重生。

### （四）评注：白昼/黑夜、意义/荒谬是同一现实

- **论据/案例/事实**
  - 神老则成阴影、无意义、走下坡。白昼需要黑夜，黑夜需要白昼；意义需要荒谬，荒谬需要意义。二者都不能独自存在。通过自己而存在的现实=白昼和黑夜=意义和荒谬。正午与午夜都稍纵即逝；意义是荒谬与荒谬之间的过渡。
- **论证推导过程**
  - 从神的衰老推出价值翻转（真理→谎言，白昼→黑夜），再把翻转写成结构：对立项互为条件。现实不是「只要意义」，而是意义与荒谬的交替。谋杀带来的「荒谬」因此不是对意义的取消，而是意义的过渡带。
- **核心结论**
  - 「最高真理同时又很荒谬」在评注里被展开为存在论：现实=意义∧荒谬。
- **延伸推论/现实启示**
  - 编者注：《草稿》说同行年轻人是「我自己的年轻版」——谋杀并非独自完成。

### （五）评注：西格弗雷德、德意志诸神与新神

- **论据/案例/事实**
  - 西格弗雷德拥有「我」最珍视的伟大、美好、力量、勇敢、荣耀；公平再战，「我」必败，被暗杀的将是「我」自己；存活只能靠狡猾与欺骗。不要妄评：德意志森林中的金发蛮族，把挥铁锤的雷电之神出卖给脸色苍白、像鸡貂一样钉在木头上的近东之神；生命驱力迫使他们出卖原始诸神、圣树与对森林的敬畏。西格弗雷德之死将使德意志人民受苦，故「我」宁愿杀自己也不愿杀他，但又想与一位新神一起生活。基督入阴间、披反基督/恶龙外衣，古人以此宣告新神。越逃神，越落入神手。
- **论证推导过程**
  - 英雄=已内化的理想力量。公平对决等于用旧神的规则打败自己。出卖森林诸神的历史被用来禁止读者从外面审判这场谋杀。新神的欲望压过对西格弗雷德的不忍。基督—反基督的翻转，与「神必须被战胜才能重生」同构。
- **核心结论**
  - 杀西格弗雷德是为了与新神一起活；旧英雄再完美，也必须让路。
- **延伸推论/现实启示**
  - 编者注：《草稿》作「超越基督的英雄」；荣格对亚菲说，德意志人民的夸大意志（如西格弗雷德防线）即此英雄；心中声音：「若无法理解梦，必须将自己射杀。」这些是编者所引后日评论，不是本章评注正文。

### （六）评注：雨、死者与青春之神

- **论据/案例/事实**
  - 大雨=巨大泪流=死亡束缚所蓄紧张的释放=身上死者的哀悼，带来埋葬与重生；雨水肥沃大地，长出新麦，即青春焕发的神。
- **论证推导过程**
  - 幻象里的雨被译成哀悼仪式：死者被埋，神以麦的形象再出。紧张释放与「甘雨」那句话、与谋杀后的解脱同属一条链。
- **核心结论**
  - 谋杀的完成形态是埋葬—肥沃—新神，而不是单纯的消灭。
- **延伸推论/现实启示**
  - 编者注指向弗雷泽《金枝》论神的死亡与复活；荣格 1912 年《力比多的转化与象征》曾引用。此为编者互见，不是本章展开的人类学证明。

## 实操方法与教学细节

本章以幻象叙事与评注为主，未给出可逐步照做的技术规程。仍可从正文抽出的态度与程序：

- **先承受幻象，再等那句「荒谬」**：谋杀后的折磨被一句「最高真理同时又很荒谬」泄掉，而不是被道德解释泄掉。
- **记下雨与第二梦**：正文把雨写成紧张释放，把花园彩光写成跨越深度；不要先用「这只是隐喻」跳过感官细节。
- **区分两层**：枪、战车、大雨、花园是幻想层；白昼/黑夜、刺客、反基督是评注层。不要把评注里的「当刺客」直接做成生活策略。
- **避坑（据编者所引后日材料，非正文步骤）**：1925 年讲座称，若不理解此梦，内在声音要求「将自己射杀」——那是解开谜的压迫感，不是行动指令。正文本身说的是「几乎被折磨致死」的确信。
