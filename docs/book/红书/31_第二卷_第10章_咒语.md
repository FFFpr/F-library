# 第二卷 第十章 咒语

## 本章位置

上一章末尾已给出姿势：蛋放在面前，看着它，用目光的温暖孵化，「咒语如下」。本章几乎全是对着蛋中之神的诗体咒语，夹插图占位；空页与纯图不算段。花体字抄本无本章标题，标题出自草稿。编者注：Image 50 至 60 象征描绘吉尔伽美什的再生。咒语之后转入散文评注：蛋中之神无法亵渎、诸神之死只剩一蛋、因爱而孵化而非砸碎；要的不是统治的力量，而是光、暖与生命。打开蛋见 [32_第二卷_第11章_蛋的打开.md](32_第二卷_第11章_蛋的打开.md)。预备姿势见 [30_第二卷_第09章_第二天.md](30_第二卷_第09章_第二天.md)。

## 核心论点

**发生了什么（咒词层）**

1. 圣诞已到，神在蛋中。吟咒者轮流自称母亲（卑微少女、不知如何生出）、细心的父亲、旷野牧羊人、惊恐的神圣动物、远方怀疑的东方智者，以及环绕滋养神种的蛋本身。
2. 神被说成双重：永恒空洞与充满、黑暗与光明、下与上；繁中有简、荒谬中有意义、束缚中有自由、胜即败、年轻中的年老、否定之肯定。中间之道的光包在蛋里，由重硬如石到熔化透明、明亮流动。
3. 「阿门」连呼：始祖、东方之星、遍开的花、林中突然跑出的鹿、远水上传来的歌声、开始也是结束。接着是从未说出的话、从未发出的光、无与伦比的困惑、没有终点的路。
4. 召唤病友顶破外壳：铺毯洒红花、备饭、礼物、起舞、建房、仆人就绪、羊群、红酒、金盘水果；敲牢门把耳朵贴上。时间延长，事不宜迟；没有你则可怜、歌已唱完。
5. 许诺顺从一切指示：开所有门、按你意愿下跪与转向；上升又下降、移动又静止、看见又看不见、听到又听不到、肯定又否定；活在难以理解与无爱中，再回头去理解、去爱，忠于你的律法。
6. 「请来到我们身边」五叠：内心渴望、精神理解、火温暖、医术医治、身体孕育；孩子来到父母处。问地、天、海、风、火，与所有人、国王、智者全身心寻找，最终发现你在蛋中。
7. 献祭清单：杀掉贵人（一青年一老人）、划开皮肤洒血、弃父母、夜变昼而正午梦游、弃所有神并践踏律法、吃不洁、弃剑穿女装、毁城堡在沙上玩耍、砸碎盔甲、耕种却任水果腐烂、伟大变渺小、渺小变伟大、远景与近景目标对调——「所以我已经准备好了」。

**荣格对咒语的评注**

8. 「但是，我还没准备好，因为我还没有接受扼住我的心的东西。」可怕的是神被禁闭在蛋中：巨人曾令人跌倒，现在几乎不用手就能拯救、可放进口袋。亵渎口袋中的蛋不值得——这是无法亵渎的神。宁肯亵渎一个尚可亵渎的神。
9. 诸神之死：人把他们放进口袋；神话终结，只剩一蛋，或许可以消灭这最后的蛋以终结神族。上下左右都是欺骗，抓住的是空气。但打倒巨人是出于爱：减轻重量、收进母亲般的蛋，不是为了砸碎坟墓般的壳。父神若必须死，童神须在母亲般的心中诞生。只要生命与光暖，不寻求统治；无太阳的精神会变成身体的寄生虫，神能滋养精神。

## 关键概念补全

**蛋中之神 / 圣诞**：咒词开篇「圣诞已经到来，神在蛋中」。编者注分别引《路加福音》2:8–11（旷野牧人得报救主诞生）与《马太福音》2:1–2（东方占星家见星来朝）。正文把吟咒者写成牧人、东方智者、母亲与父亲，不是另写一篇福音。

**双重特质**：空洞/充满、暗/明、下/上、繁/简、荒谬/意义、束缚/自由、胜/败、老/少、否定/肯定。编者注：这些特质与《审视》中第二、三次布道时阿布拉克萨斯的特质类似。

**中间之道的光**：被包在蛋中，萌芽初期，激情而压抑，如梦等待记忆流逝，由石硬到熔化透明。

**哈朗亚格嘎（金卵）**：编者注图片故事：梨俱吠陀中金卵孕育梵天；荣格藏书中「致未知的神」赞美诗被剪下；奥义书纸条称原我亦名哈朗亚格嘎。此为图注，不是咒词自称。

## 论证推理链

幻想对话在本章很少；层次是：图下咒词（按节）→ 散文评注。以下把咒词按插图分节摘入，不写成「这是咒语」一笔带过。

### （一）节：圣诞与角色叠唱（Image 50–51）

- **论据/案例/事实**
  - 「圣诞已经到来，神在蛋中。」已为神备昂贵红毯，产自日出之地；他将被东方绚烂之光环绕。
  - 「我是他的母亲，一个卑微的少女，生出神，自己却不知道如何生出。」「我是细心的父亲，保护着少女。」「我是牧羊人，在黑暗的旷野中看护着羊群时接收信息。」「我是神圣的动物，惊恐地站在那里，无法理解正在出现的神。」「我是来自东方的智者，在远方怀疑这个奇迹。」「我又是蛋，环绕又滋养着里面神的种子。」
- **论证推导过程**
  - 同一吟咒者占据马槽故事里的多个位置，最后把自己等同于蛋：不是旁观神，而是成为神的容器。
- **核心结论**
  - 孵化开始于「神在蛋中」与「我是蛋」。

### （二）节：双重特质与蛋中之光（Image 52–53）

- **论据/案例/事实**
  - 「庄重的时刻变长。我的人性又很可怜且饱受折磨。因为我要生育。神啊，你如何使我快乐？」
  - 「他是永恒的空洞和永恒的充满。一切都与他不同，而他又与一切相似。永恒的黑暗和永恒的光明。永恒的下和永恒的上。他有双重特质。繁中有简。荒谬中有意义。束缚中有自由。胜利时也是失败。年轻中的年老。否定之肯定。」
  - 「啊！中间之道的光，被包在蛋中，萌芽初期，充满激情，压抑。充满期待，如梦，在等待记忆的流逝。像石头一样沉重，坚硬。已经熔化，变得透明。明亮地流动，翻转。」
- **论证推导过程**
  - 生育的折磨把神写成一切对立的同时成立；光在蛋中经历石→熔→流。
- **核心结论**
  - 所孵的不是单一光明，而是双重神；中间之道尚被包着。

### （三）节：阿门、未说出的话、赦免（Image 54–56）

- **论据/案例/事实**
  - 「阿门，你是始祖。阿门，你是东方之星。阿门，你是遍开的花朵。阿门，你是森林中突然跑出的鹿。阿门，你是从遥远的水上传来的歌声。阿门，你是开始也是结束。」
  - 「一句从未说出的话。一道从未发出的光。无与伦比的困惑。还有一条没有终点的路。」
  - 「我原谅这些话语，就像你原谅我渴望你炽热的光一样。」
- **论证推导过程**
  - 阿门把神叫成起源、星、花、鹿、歌声与始终；紧接着承认话与光都尚未发生，路没有终点；原谅不充分的话语。
- **核心结论**
  - 召唤与无能并存：神被命名，同时仍是未说的话、未发的光。

### （四）节：请顶破外壳；备宴（Image 57）

- **论据/案例/事实**
  - 「起来吧，你这古老夜晚中华美的火。我亲吻你最初的开端。我的双手已经铺开地毯，把大量的红花洒在你的面前。站起来吧，病倒的朋友，顶破外壳吧。」
  - 已备：饭、礼物、舞、房子、仆人、绿色旷野中的羊群、杯中红酒、金盘芬芳水果。敲牢门，耳朵贴门上。「时间延长了，事不宜迟。没有你我们会很可怜，我们的歌已经唱完。」
- **论证推导过程**
  - 神仍是「病倒的朋友」、仍在「牢门」里；人间礼仪已齐，缺的是破壳。
- **核心结论**
  - 咒语从命名转为催生：顶破外壳。

### （五）节：完全顺从与难以理解（Image 58）

- **论据/案例/事实**
  - 「没有你，我们会痛苦无比，唱尽我们的歌。我们讲发自肺腑的话。你还想要什么？我们还有什么能够满足你？我们为你打开所有的门。你想我们在哪里下跪我们就在哪里下跪。……把高变成低。……给予和索取。」
  - 「我们想要向右走，但根据你的指示，我们转向左。我们上升，我们又下降；我们移动，我们又保持静止；我们看见，我们又看不见；我们听到，我们又听不到；我们肯定，我们又否定；永远听从你的话语。」
  - 「我们无法理解，我们活在难以理解中。我们不去爱，我们活得没有爱。我们又回过头来，我们去理解，并活在理解中。我们去爱，又活在爱中，忠于你的律法。」
- **论证推导过程**
  - 先交出方向与感官，活在无理解无爱中，再回头进入理解与爱——以「你的律法」为准，不是以事先的理解为准。
- **核心结论**
  - 顺从先于理解；理解与爱是后来才「回头」加上的。

### （六）节：请来；寻遍元素，发现在蛋中（Image 59–60）

- **论据/案例/事实**
  - 「请来到我们身边」×5：发自内心地渴望；用精神理解；用火温暖；用医术医治；用身体孕育。「孩子，来到你的父母这里吧。」
  - 「我们问地。我们问天。我们问海。我们问风。我们问火。」与所有人、所有国王、所有智者、全身心寻找。「最终我们发现你在蛋中。」
- **论证推导过程**
  - 向外问遍元素与权威，终点不是天上的王座，而是面前的蛋。
- **核心结论**
  - 寻找的结果是：神不在别处，在蛋中。

### （七）节：颠倒生活的献祭清单（Image 61）

- **论据/案例/事实**
  - 「我已经为你杀掉一名贵人献祭，一名年轻人和一名老人。我已经用刀子划开自己的皮肤。我已经将自己的鲜血洒到你的祭坛上。我已经抛弃自己的父母，因此我可以和你生活在一起。我已经把自己的黑夜变成白天，像梦游人一样在正午行走。我已经抛弃所有神，践踏律法，吃下不纯洁的东西。我已经扔掉自己的剑，穿上女人的衣服。我已经破坏自己坚固的城堡，像孩子一样在沙上玩耍。我看到战士排成战斗的队形，我用锤子砸碎自己的盔甲。我耕种自己的土地，任水果腐烂。我把一切伟大的事情变渺小，又把一切渺小的事情变伟大。我把最远景的目标和最近景的目标进行交换，所以我已经准备好了。」
- **论证推导过程**
  - 准备被写成一系列自我颠倒：贵贱、男女装、城堡与沙戏、耕种与腐烂、远近目标对调。
- **核心结论**
  - 咒词自称「已经准备好」；下一节散文立刻反对。

### （八）评注：尚未准备好；因爱而孵，不要砸蛋

- **论据/案例/事实**
  - 「但是，我还没准备好，因为我还没有接受扼住我的心的东西。」可怕的是神被禁闭在蛋中。努力成功令人高兴，恐惧使人忘记危险。牛角巨人曾令人跌倒，现在几乎不用手就能救、可放口袋。这些曾是自古统治你的神。「我宁愿亵渎神，这样，我至少有一个神可以亵渎，但亵渎一个口袋中的蛋是不值得的。这是一个无法亵渎的神。」
  - 恨神的凄惨；触摸自己变尘土，触摸神他躲进蛋；推地狱之门是面具笑声与傻瓜音乐；冲上天则舞台发抖、提词人晕倒。「不是真的上，也不是真的下，左和右都是欺骗。你抓住的是空气。」「这就是诸神之死：人类把他们放进口袋中。这是神话的终结，除了一个蛋之外，什么都没留下。」或可消灭这最后的蛋以终结神族。
  - 「这是怎么发生的？」打倒是因悲伤与爱，无人是他的对手。为爱减轻重量、缩小外形、收进母亲般的蛋。要砸碎坟墓般易碎的外壳吗？「而我不是在吟诵孵化他的咒语吗？」不愿除去对巨人的爱；愿像照顾孩子一样照顾毫无防御的神。「我们不是神的儿子吗？为什么神不是我们的孩子？如果我的父神必须死，那么童神一定会在我母亲般的心中诞生。」「只有爱神的人才能让神倒下」，神在承诺再生之人的心中死去。
  - 「我们并非需要你的力量，而是生命。」「力量能给我们什么？我们不寻求统治。我们想要生活，我们想要光和温暖。」绿地需要太阳；精神需要神的光暖。「没有太阳的精神会变成身体的寄生虫，但神能滋养精神。」
- **论证推导过程**
  - 口袋中的蛋=无法亵渎=神话终结的剩余。选择不是消灭最后的蛋，而是因爱孵化：父死而童神生；要生命不要统治。
- **核心结论**
  - 咒语的完成条件是接受「扼住心的东西」：爱这个毫无防御的神，而不是砸壳或炫耀已把神放进口袋。

## 实操方法与教学细节

原文把孵化写成可照做的姿态（承接上一章）：

1. 蛋放在面前（神最初的形式）。
2. 看着它。
3. 用目光产生的温暖孵化它。
4. 按节吟咒：承认自己是母/父/牧人/动物/东方智者/蛋；呼唤双重神与中间之光；阿门命名；请病友破壳并备宴；许诺顺从与回头去爱；请来身边并问遍元素；呈上颠倒生活的清单。
5. 停在「已经准备好了」之后，检查是否真的接受扼住心的东西；不要把「可放进口袋」当成胜利去砸蛋。
6. **避坑**：亵渎口袋中的蛋（不值得，也无法亵渎）；为力量与统治求神；无太阳地让精神寄生于身体；把上下左右的舞台当成真的上、真的下。
