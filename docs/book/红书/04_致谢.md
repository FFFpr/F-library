# 致谢

## 本章位置

索努·沙姆达萨尼感谢使 2009 年版《新书》得以完成的机构与个人。它接在霍尔尼前言之后，他本人的长篇导读之前。前言里的出版决策见 [03_前言.md](03_前言.md)；导读见 [05_导读_新书——荣格之红书.md](05_导读_新书——荣格之红书.md)。

## 核心论点

1. 未出版复本仍在流通，此书终将以某种形式进入公众视野；正式版本依赖大量合作。
2. 前 C. G. 荣格继承人协会（2008 年解散）于 2000 年春决定出版；霍尔尼策划，鲍曼签署协议，协会承担大部分开支。
3. 编辑与翻译达到现有水平，主要靠腓利门基金会及其董事会、捐赠人和研究机构的持续资助；沙姆达萨尼负责文本组织、序言和整体架构。
4. 家族允许查阅图书馆与档案馆、誊抄《黑书》与修正花体字抄本，以及诺顿的编辑设计、扫描印刷、2006 年起凯博斯与派克加入翻译，共同构成这个版本。

## 关键概念补全

**腓利门基金会**：为出版荣格未发表作品而成立的募资机构。本篇说 2004 年起支持本项目；没有其董事会，编辑和翻译不可能达到今天的水平。

**花体字抄本**：荣格用花体字誊入红皮书的那一层。乌尔里希·霍尔尼制作修正后的抄本；休·米尔斯坦与约翰·萨普拉将其扫描合成数字图片。

**卡莉·拜恩斯**：本篇感谢引用其通信与日记；后文英译/编者按会再出现她的抄本。

## 论证推理链

### （一）正式出版是机构决定，不是个人兴趣

- **论据/案例/事实**
  - 2000 年春，前继承人协会经激烈讨论后决定出版；执行委员委托霍尔尼策划。鲍曼于 2000 年秋签署出版协议，协会承担大部分开支。
  - 感谢：茨魏费尔（策划技术）、唐纳德·库珀基金会（捐助）、毛尔（法律合同）、拉·罗萨与弗里茨（合同谈判）。
  - 2003 年博盖特基金会与匿名捐赠者资助编辑；2004 年起腓利门基金会资助。
- **论证推导过程**
  - 把「决定—签约—开支—后续基金」按年排出，说明没有协会与基金，编辑翻译无法进行。
- **核心结论**
  - 此书能够以现在的学术水准出版，取决于 2000 年的组织决定和此后的持续资助。

### （二）研究、家族、翻译、印制是同一条工作链

- **论据/案例/事实**
  - 思想史研究：1993–1998 惠康基金会，1999 跨文化心理学院，1998–2001 索伦基金会；工作环境在伦敦大学学院医学史中心。同事保密 13 年。
  - 家族：霍尔尼修正花体字抄本；苏珊娜·霍尔尼誊抄《黑书》；1999、2001、2003 三次家族报告；彼得、安德烈、维尔尼·荣格提供图书馆、手稿与档案馆协助。
  - 出版：芙洛蒂与维贡引介吉姆·梅尔斯；贝克、维贡、吴负责设计；罗斯文本编辑；奥德里斯科尔协助；扫描用声纳系统定位以匹配花体字细密程度；萨维尼提供影片工作室；蒙达多里印刷。
  - 2006 年凯博斯与派克加入翻译，定期电话会议做微观讨论；派克找到若干重要典故。
  - 口述与专业咨询：1920 年代圈子氛围、达达主义与艺术—心理学冲突、埃及文、图片 155、阿拉伯文献词、密特宗拉教仪式、无声之书（Mutus Liber）、J. B. 郎的论文与书信等。
- **论证推导过程**
  - 学术编辑、家族档案、视觉复制、翻译校勘缺一则版本不成立。致谢名单按功能分组，等于一张工作流程图。
- **核心结论**
  - 沙姆达萨尼「主要负责文本组织、序言和整体架构」，其余环节由上列合作完成。
- **延伸推论/现实启示**
  - 他用《新书》104 页注 29 的驴子自比，表示卸下重担——把编者自我位置写进文本内部的典故。

## 实操方法与教学细节

本章不是方法教程。对读者有用的版本信息是：

- **资金与机构时间轴**：2000 决定与签约 → 2003 博盖特等 → 2004 腓利门 → 2006 增补英译。
- **文本工作分工**：霍尔尼修正花体字抄本；苏珊娜·霍尔尼誊《黑书》；沙姆达萨尼组织文本与序言；凯博斯、派克、沙姆达萨尼合作翻译。
- **视觉复制**：花体字抄本扫描合成数字图，定位精度须配得上荣格书写。
- **避坑**：不要把这个版本的缺陷（沙姆达萨尼自己承认「无论有什么样的缺陷」）当成无机构支持的个人译稿。
