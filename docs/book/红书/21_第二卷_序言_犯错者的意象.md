# 第二卷　序言　犯错者的意象

## 本章位置

第一卷《来者的路》在 [20_第一卷_第11章_终解.md](20_第一卷_第11章_终解.md) 收束后，本书进入 Liber Secundus（第二卷）。本页几乎没有荣格自己的叙述，而是用《耶利米书》两段经文为整卷题词：警告「出于自己心思的异象」与「出于耶和华之口的话语」不可混为一谈。卷题「犯错者的意象」对应《手写的草稿》里的「彷徨中的冒险」。下一章幻想从塔楼上的等待开始，见 [22_第二卷_第01章_红人.md](22_第二卷_第01章_红人.md)。全书结构索引见 [00_全书导读与架构.md](00_全书导读与架构.md)。

## 核心论点

1. **经文层（非荣格自撰）**：不可听从那些使你们存虚幻希望的先知；他们的异象出于自己的心思，不是出于耶和华的口（《耶利米书》23章16节）。
2. **经文层**：冒神之名宣称「我做了梦」的先知，是用自己心中的诡诈、互相传述梦，使人像列祖因巴力一样忘记神的名；做了梦的可以把梦述说出来，但得了话语的必须忠实传讲；禾秆不能和麦子相比（同书23章25–28节）。
3. **编者注所记荣格后来的用法**（不是本章荣格正文）：他在《心理类型》（1921）中直接引用这几段（路德版《圣经》的拉丁文），并评论说：基督向世界呈现无意识内容的形式一旦被宣布对所有人有效，个体幻想便变得没有价值、甚至被视为异端，诺斯替教与其后异教如此，耶利米的告诫也如此。
4. **草稿层**：本卷序的手稿标题曾是「彷徨中的冒险」，现行标题「犯错者的意象」是后来的定名。

本章没有「发生了什么」的幻想叙事；全部是题词与编者说明。

## 关键概念补全

**Liber Secundus / 犯错者的意象**：第二卷卷名。正文此处未解释何谓「犯错者」；《手写的草稿》作「彷徨中的冒险」，提示本卷将以彷徨中的遭遇为骨架。

**耶利米**：经文自署为「万军之耶和华」借先知之口的宣告。本章只给出23章16节与25–28节，不另述先知生平。

**巴力**：经文用来对照「列祖因巴力忘记了我的名」——用别的崇拜对象替换神之名。本章不作神话学展开。

**异象 / 梦 / 话语**：经文把三种东西分开：出于己心的异象、互相传述的梦、得自耶和华而须忠实传讲的话。禾秆与麦子的比喻用来压低「只有梦」的那一侧。

> 💡 第一卷已把「灵魂说话」与「时代精神」对置，见 [10_第一卷_第01章_重新找回灵魂.md](10_第一卷_第01章_重新找回灵魂.md)。本卷题词则从相反方向警告：并非一切内在影像都等于神的话。

**编者注中的「折断线」**：脚注[1]引1932年荣格论毕加索文，谈精神分裂症患者绘画里形式层面的分裂（「折断线」）。该注印在本页，但内容不解释卷题，只旁及「分裂」的视觉形式；须标明这是编者注，不是序言正文。

## 论证推理链

### （一）题词：异象不是口谕

- **论据/案例/事实**
  - 23章16节：不要听从向你们说预言的先知；他们使你们存虚幻的希望；异象出于自己的心思，不是出于耶和华的口。
- **论证推导过程**
  - 经文先定罪名（虚幻希望），再给判准（来源是己心还是神口）。第二卷以「意象」为题，开篇却把「自己的心思所产」从「神的口」里划出去。
- **核心结论**
  - 有异象、有预言，不等于有神的话。
- **延伸推论/现实启示**
  - 原文未在本页由荣格再引申；启示仅止于题词本身的警告。

### （二）题词：梦可述说，话语须忠实；禾秆不是麦子

- **论据/案例/事实**
  - 23章25–28节：先知冒神之名说「我做了梦」；意念是诡诈；互传己梦使人忘记神的名，如同列祖因巴力忘记；做了梦的让他把梦述说出来；得了话语的该忠实传讲；禾秆怎能和麦子相比。
- **论证推导过程**
  - 经文并不禁止述梦，禁止的是把梦冒充神名、用梦替换神名。梦与话语被分成两种职分，再用禾秆/麦子压低前者的重量。
- **核心结论**
  - 梦可以被讲；但不能靠互传梦来代替忠实传讲所得的话。
- **延伸推论/现实启示**
  - 原文未另作现实引申。编者注[2]把这几句接到「个体幻想被宣布为异端」的历史命运上，见下一小节。

### （三）编者注：荣格后来如何征引这段经文

- **论据/案例/事实**
  - 沙姆达萨尼注[2]：荣格在《心理类型》中以拉丁文引用路德版这几段，并写道：基督呈现无意识内容的形式已被广泛接受、被宣布对所有人有效，因此个体的所有幻想已变得没有价值、甚至被视为异端，诺斯替教与之后所有异教如此，耶利米的告诫也如此（《荣格全集第6卷》§81）。
  - 注[3]：《手写的草稿》写的是「彷徨中的冒险」（353页）。
  - 注[1]：1932年论毕加索文中，荣格说只有有精神障碍的人才能产生精神分裂的症状；形式特征是分裂，以「折断线」贯穿绘画（《荣格全集第15卷》§208）。
- **论证推导过程**
  - 注[2]把题词从「假先知」转到「被官方化的一种无意识呈现形式」如何使其他幻想失效。这是编者用后期著作来说明为何本卷以耶利米开篇，不是荣格在本页亲口论证。
  - 注[3]保存卷题的更早措辞，把「犯错者的意象」与「彷徨」连在一起。
  - 注[1]与经文主题关联弱，属图版/形式旁注。
- **核心结论**
  - 就编者所引：本卷题词可被读成对「唯一种被批准的内在形式」的抗议；就手稿：本卷首先是彷徨中的冒险。
- **延伸推论/现实启示**
  - 原文（荣格本页）没有；后期评论属于编者层。

## 实操方法与教学细节

本章以题词与编者注为主，未给出可逐步照做的技术规程。仍可操作的态度只有经文自己提出的程序：

- 梦可以述说，但先分清「述梦」与「传神的话」。
- 问来源：这段异象是出于自己的心思，还是被当作口谕？
- 不要用互相传述的梦替换所当忠实传讲的内容（禾秆不要冒充麦子）。
- 读本页时把方括号内经文、荣格未写的编者注、手稿异文分成三层，不要混成「荣格在序言里主张……」。
