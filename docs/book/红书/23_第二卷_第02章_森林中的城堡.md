# 第二卷　第二章　森林中的城堡

## 本章位置

上一章（[22_第二卷_第01章_红人.md](22_第二卷_第01章_红人.md)）里，「我」从魔鬼处得到一点快乐，绿外套长叶。本章是「第二天夜里」的第二次冒险：黑暗森林迷路，沼泽中的古堡，心不在焉的老学者，以及被当作小说陈词滥调的苍白女儿。评注把她与第一卷的莎乐美／以利亚对应，并转向男性特质与女性特质、真实界限与人为障碍、自己特有的地狱。下一夜遇见独眼流浪汉，见 [24_第二卷_第03章_卑微的人.md](24_第二卷_第03章_卑微的人.md)。第一卷神秘遭遇中的莎乐美与以利亚见 [18_第一卷_第09章_神秘遭遇.md](18_第一卷_第09章_神秘遭遇.md)。

## 核心论点

**幻想层：发生了什么**

1. 「我」在黑暗森林迷路（编者注指出但丁《地狱》亦以诗人迷林开篇），借宿沼泽中古堡；主人是整夜沉浸书中的老学究，除塔楼仆人外无人。
2. 卧床时出现「老人藏美貌女儿」的小说式念头，「我」知其陈腐仍无法驱走；午夜苍白女孩进门，问「你最终还是来了？」
3. 「我」先把她当作品位低下的鬼故事／小说人物；她哭着要求被当作真人。她自称是老人的独女、早逝母亲的意象，因爱而非妒恨被囚。
4. 「我」终于说相信她是真实的；她说自己被陈词滥调施了魔法，解救的咒语就是不再在彼此之间说陈词滥调。她称童话是小说的大母神，陈词滥调里才有所寻的智慧。
5. 「我」说爱她但已结婚；她说「甚至陈腐的现实也是一位拯救者」，代莎乐美问好后消失，留下一堆玫瑰。

**评注层**

6. 没有外在冒险就没有内在冒险；从魔鬼得到的快乐把人带去冒险，从而发现下限即上限，必须碰到真实界限。人为／同胞期待的障碍不是真界限；培养自己的对立才能平衡，而这不是英雄式行为。
7. 本场是被扭曲的神秘：莎乐美与以利亚变成老学者与苍白被囚的女儿。必须把从前爱的体验为无用，去艳羡从前嘲笑的；接受荒谬的一刻，少女转化并显出自主意义。
8. 人同时有男性特质与女性特质；最具男性特质的男人拥有女性特质的灵魂（反之亦然）。不要在异性身上找自己缺少的那一半。接受自己的女性特质（对男人）或男性特质（对女人）带来完整，并摆脱对异性的奴役；看起来荒谬、无力、庸俗。
9. 学者为外在思想而活、抛弃自己，灵魂会蒙羞，进陌生人房间乞求认可。灵魂需要的是愚蠢而非智慧。超越性别须保留人性，按当下情境而非一般性原则行动。
10. 通往未来的路进入自己特有的地狱（由自己一直拒绝的东西构成）。对挡住去路、激起鄙视或愤怒的一切给予足够重视，才能把灵魂给予无灵魂者，救回他者的生命。不能同时在山上又在山谷，但道路可以从山上到山谷再回来；地狱有不同层级。

## 关键概念补全

**老学者 / 被囚的女儿**：本场幻想人物。评注说他们是第一卷以利亚与莎乐美在「生活」层面的扭曲表象。女儿明说「我代莎乐美向你问好」。编者注[5]引1951年《科莱女神的心理学》：幽灵般的存在是阿尼玛的特征——此为编者所引后期用语，正文本章未用「阿尼玛」一词。

**陈词滥调**：女儿说自己被它施了魔法；解救是不再在彼此之间说陈词滥调。她主张被叫做陈词滥调的东西才包含要寻找的智慧；传说证明她普通、需要救赎。

**童话是小说的大母神**：女儿的命题——口口相传千年的内容来自人类终极真理，比当代热门小说更有普遍效力。编者注[4]引里克林论童话为愿望满足、以及荣格后来把童话视为原型表现——后者是编者层。

**真实界限 vs 随机障碍**：评注区分生命真正的限度与想象／同胞期待人为设置的障碍；只有碰到它们并取得平衡时才能看见。

**男性特质 / 女性特质 / 人**：评注主张二者并非男女各有其专利；「人在哪里」是追问。灵魂的性别说不清；越男性化，身上的女性特质越被蔑视。编者注[8]把这套说法接到1921年《心理类型》的阿尼玛／阿尼姆斯——须标为编者注。

**自己特有的地狱**：由一直拒绝、用诅咒或脚踢逐出圣殿的东西构成；不是「值得一看」的别人的地狱。魔鬼在此是幻想的路标。

## 论证推理链

### （一）幻想：迷林、古堡、学究、失眠中的陈腐念头

- **论据/案例/事实**
  - 黑暗车道、沼泽、古堡、旧仆人、白墙黑柜、学者书房、黑袍老人。老人心不在焉，几乎忘记借宿者。粗床单硬枕头。塔楼里只有仆人。
  - 「我」先羡慕与书相伴的孤独，随即冒出「藏女儿」的小说主题，自骂荒谬、魔鬼的瘟疫，仍感到必须让这些思想出现，「吞下苦果胜过含在口中」。
  - 失眠、发冷、脚步、门响、苍白女孩进门。
- **论证推导过程**（叙事）
  - 精神追罕见与隐秘时，普通的那一层以最陈腐的小说形式回来；驱赶无用，因为还会卷土重来。
- **核心结论**
  - 必须让「空洞的幻想」出现，而不是把它变得更强大或更美好。

### （二）对话：她是不是真人；陈词滥调与解救的咒语

- **论据/案例/事实**
  - 「我」怕自己必须在地狱里写出一直唾弃的低品位小说。女孩指责他把她当成小说人物。「我」要求确认她是真人；她跪哭。她是老人独女、亡母意象，因爱被囚。「我」仍觉一字不差出自图书馆小说。
  - 若她是真人就值得怜悯；「我」说相信她真实。她发光：被陈词滥调施魔法；不说陈词滥调就是解救的咒语。童话＞热门小说；陈词滥调才含智慧；她非常普通，也可在现实中生活得更好。
  - 「我」已结婚仍说爱她。她：陈腐的现实也是拯救者；代莎乐美问好；消失，遗玫瑰。
- **论证推导过程**
  - 承认「真实」先于解释。婚姻这一「陈腐现实」打断浪漫拯救剧，本身完成救赎。莎乐美的问候把本场接回第一卷。
- **核心结论**
  - 把被当成套话的形象当作真人，套话的魔法才解；现实的限制可以是拯救者而不是扫兴。

### （三）评注：界限、荒谬、男性／女性、学者的灵魂、自己的地狱

- **论据/案例/事实**
  - 无外在冒险则无内在冒险。快乐带来冒险，下限＝上限。不了解局限会撞上想象与同胞期待的人为障碍；生命要跳出则与自己冲突。真界限不可预知，只有接触并平衡时可见。平衡要培养对立，这令内心最反感，因不是英雄行为。
  - 为找路有时必须后退。莎乐美／以利亚→学者／苍白女儿。接受荒谬的一刻看见转化。
  - 男人须在自己身上找女性特质（一开始就有）；女人亦然。最具男性的男人有女性灵魂。接受另一半像堕落、被奴役；「自己成为女人」可摆脱对女人的奴役。白鸟因屈辱而可飞；变成一个人，灵魂才回到自己身上。
  - 推倒人为高墙会看见浩瀚与恐惧，古老沉睡者醒来，白鸟是信使；须把有序世界变得糟糕才不至于过度脱离自己。内在世界与外在世界同样无边；只活一个世界的是愚蠢的人，永远不伦不类。
  - 为研究对象而活等于为外在思想而活；老人抛弃自己，灵魂进陌生人房间乞求认可。学者会议上因名字、讲得更好、观点被改动而怒。灵魂要愚蠢不要智慧。
  - 超越性别须留人性；按情境不按一般性原则。止于人性的人擅长铭记原则；原则有贡献，但不能用它超越性别。此时此刻的超越像不眠之夜、发烧、毒雾；魔鬼以枯燥无味出现。
  - 自己的地狱由拒绝物构成。要重视挡住去路、激起鄙视愤怒的一切。价值观把人往上拉，存在像铅往下坠；路上可以同时活出两者。地狱有不同层级（编者注：但丁九层）。
- **论证推导过程**
  - 快乐→冒险→碰到平庸与陈腐→必须承认其为真实→这迫使男人碰自己的女性特质（非英雄）→学者是反例（外在化）→拒绝之物组成个人地狱，重视它们才能救回无灵魂者。
- **核心结论**
  - 完整要求接受自己最厌恶的那一半与最陈腐的形象；道路（而非同时占据两极）拯救人。
- **延伸推论/现实启示**
  - 草稿[6]：排除外在生活不会使内在更富，只更贫、更多痛苦，魔鬼开始出现；抛弃内在则外在也贫；平衡才是出路。

## 实操方法与教学细节

本章以叙事／评注为主，仍可操作的态度：

- **让陈腐念头出现**：驱赶还会回来；「吞下苦果胜过含在口中」。
- **先承认真人，再解释**：对内在形象说「你是真实的」是解救咒语；不要一上来用「这是小说套话」解除其效力。
- **用现实限制当拯救者**：已结婚这一「陈腐」打断了拯救剧，女孩称之为拯救。
- **找真实界限**：不要把同胞期待的墙当成自己的限度；只有碰到并在对立中平衡时才看见。
- **在自己身上找另一半**：男人不要只在女人身上找女性特质。接受时会觉得荒谬、无力、庸俗——评注说必须接受荒谬。
- **进自己的地狱时**：冷静观察激起鄙视或愤怒的一切；重视挡住去路的，不要把厌恶之物放在当下与未来之间。
- **避坑**：不要只活精神的隐秘或只活外在研究；不要用一般性原则「一劳永逸」地超越性别而丧失人性；不要与魔鬼为伍陷入盲目欲望。
- **草稿警告**：若以为内在生活是唯一的生活，大错；抛弃外在则内在更贫。

33. 【第一档·陈述】精神追罕见与隐秘时，普通的东西在受伤；为找路有时必须后退。本场是扭曲的神秘：莎乐美与以利亚变成老学者与苍白女儿。必须把从前爱的体验为无用，艳羡从前嘲笑的。接受荒谬的一刻，看见少女的转化与自主意义。深入探索荒谬的渴望足以改变人。
34. 【第三档·过渡/场景】设问：男性特质是什么？男人需要多少女性特质才能完整？
35. 【第一档·陈述】女人亦须有男性特质才能完整。在异性身上只找对应特质，世界上便只有男人与女人，人在哪里？须在自己身上找到另一半（一开始就有）。人类同时拥有两性特质。无法说出灵魂的性别；最具男性的男人有女性灵魂，反之亦然。越男性化离真正的女性越远。从魔鬼得快乐并冒险即接受快乐；须决定快乐破坏还是提升。与魔鬼为伍会陷入盲目欲望；独自则心中有人性，把女人当人、唤回自己的女性特质，看起来愚蠢女子气。必须接受荒谬。让最具男性的男人接受女性特质是痛苦的，因显得荒谬、无力、庸俗。
36. 【第一档·陈述】这像失去美德、堕落。女人接受男性特质亦然。最具男性的男人因需要女人而成为其奴隶；自己成为女人可摆脱奴役。接受女性特质带来完整（女人接受男性特质亦然）。
37. 【第一档·陈述】男人身上的女性特质与魔鬼绑在欲望路上（女人身上的男性特质亦然），故人不愿接受另一半。一旦变成自己所愚弄的人，白色灵魂之鸟能飞；屈辱吸引它。神秘靠近，太阳从坟墓升起。作为男人／女人，灵魂在异性那里；变成一个人，灵魂才回到自己身上。
38. 【第一档·陈述】留在人为边界里只能在两道高墙间走，看不见浩瀚。推倒高墙则浩瀚与不确定激起恐惧，古老沉睡者醒来，白鸟是信使。混乱漩涡中有永恒彷徨。人既属有序世界，也活在灵魂的彷徨世界；须把有序世界变得糟糕，才不至于过度脱离自己。
39. 【第一档·陈述】灵魂的世界遭遇干旱。向外看是森林群山星空；向内看则近变成无边，内在世界与外在同样无边无际、并不贫瘠。人生活在两个世界；只活其中一个的是愚蠢的人，永远不伦不类。
40. 【第一档·陈述】把生命专注于研究仍是外在生活——为外在思想、为研究对象而活，不是为自己。老人沉浸别人的书与思想、抛弃自己，灵魂蒙羞，进每一个陌生人的房间乞求未给予的认可。
41. 【第一档·必要依据】故老学者以有失尊严的方式追求认可：名字未被提则怒，别人讲得更好则沮丧，观点被稍改则势不两立。灵魂需要的是愚蠢而非智慧。超越性别上的男性特质却未超越人性时，女性特质不屑转化成有意义的存在。最难的是超越性别又保留人性；用一般性原则超越就会变得像原则一样枯燥、顽固、没有人性。（本段是第40段「学者灵魂乞求认可」的必要依据）
42. 【第一档·限定】可出于人性超越性别，但不要因「大多数情境适用」的一般性原则去超越；没有什么一劳永逸适用于每一种独特情境。按人性即按当下情境，可能牺牲原则。你不是原则。止于人性的人擅长铭记原则；原则对精神有贡献，但不能用它超越性别。须把性别放在心中，才能从梦中醒来进入现实。
43. 【第一档·陈述】完成此时此刻的超越像不眠之夜，即超越自己的对立面；如发烧、毒雾。感官到极限时，魔鬼以枯燥无味出现。人愿阻止情感到达对立面，痛斥美好世界之外的一切，视之为人类厌恶的糟粕与拾人牙慧。
44. 【第一档·陈述】不要把厌恶之物放在当下与未来之间。通往未来的路进入自己特有的地狱：齐膝瓦砾、精疲力竭的气息、侏儒般的激情之火，魔鬼是幻想的路标。
45. 【第一档·陈述】自己的地狱由一直拒绝、用诅咒或脚踢逐出圣殿的东西构成；人像愚蠢好奇的傻瓜盯着桌边碎片而来，不是像痛苦美女或骄傲难民。愤怒适合你；亵渎神明的话能拯救生命。进入地狱则须对挡住去路的给予足够重视；冷静观察激起鄙视或愤怒的一切，才能完成面对苍白少女时的奇迹：把灵魂给予无灵魂者，救回他者的生命。价值观往上拉，存在像铅往下坠；不能同时活在两种互相排斥的状态，但路上可以同时活出两者。不能既在山上又在山谷，道路从山上到山谷再回来。开始有趣，之后渐入黑暗。地狱有不同层级。
