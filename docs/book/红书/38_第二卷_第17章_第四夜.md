# 第二卷 第十七章 第四夜

## 本章位置

本章接第三夜：人已被吊在生命之树的两极之火中间，并被要求站在怀疑中生长。拉丁题 Nox quarta（第四夜）。编者注日期 1914 年 1 月 19 日。灵魂清脆发声，要求在「这里和那里、是和否、上和下、左和右」之间升起门、建设空中通道——这是全书把对立说成必须通行、而不是必须消灭的枢纽。幻想从厨房醒来、还书、拉开绿帘进入瓦格纳《帕西法尔》式剧场，再转入评注：真正接受他者、自我愚弄、唤醒大地之子。下一章灵魂潜入洪水，捞出战争、魔法、宗教三件指向未来的古老之物。

## 核心论点

**发生了什么（幻想叙事）**

1. 晨风响彻山间；在两极之火与永恒困惑中「夜晚被征服」。灵魂要求：对立之间应有自由通道，天平指针轻摇，火不被风灭，溪流向最深目标，野兽沿古老路线从生到死、从死到生。
2. 主人公不知自己醒着还是睡着。灰色暮光之虫在高墙上抽搐地笑——原来厨娘说他睡了一个多小时。他读《效法基督》第二十一章「在主那里找到安歇」，每个字都像带着问号。厨娘是图书管理员的厨娘，管理员是美食家。
3. 还书时他问管理员是否在厨房里「孵过梦」；管理员对这种想法不感兴趣。他拉开接待室绿帘：克林格索尔的魔法花园、剧院。管理员=安福塔斯（病、胃不好），厨娘=昆德丽（失望愤怒）；克林格索尔与帕西法尔都像他自己。帕西法尔接住扔来的羽毛。
4. 他既是观众又入戏：耶稣受难礼中跪下；帕西法尔黑盔、狮皮、现代黑裤。无古内曼兹为其祝圣。他在帕西法尔身上认出自己，脱去历史盔甲与忏悔裙，自己洗脚洗手，穿上便服，走出场景，走向那个仍在跪祷的自己，站起来再次变成自己。

**荣格对幻想的诠释**

5. 真愚弄、真怀疑、真对立：接受自己必须真正接受他者。肯定里并非所有否定为真，否定里所有肯定都是谎言；因人能今日在肯定、明日在否定，故真/谬概念会屈服，肯定与否定作为存在却不屈服。
6. 只确定「一个」是对他者的阻抗。他者也在我们身上；误解渴望、更紧抓已有的那一个，会把一个喂肥、把他者饿死，因脂肪窒息、被缺乏吞掉。病「只能这样」但「不必这样」：人有自由去创造。
7. 不能愚弄自己的人会被别人愚弄；接受自我愚弄，神圣与英勇倒下，才成为完整的人。天赋与携带者不是一回事，常以个性为代价存活；只活在天赋里即拒绝他者，变得可笑。
8. 神进入生命时，人须为神回到贫穷，接下丑陋与可笑，把困惑从神身上卸下。深度仍要更多：真正的「接受」不是冷酷高傲，而是含糊的神圣–邪恶的快乐，如以利沙伏在孩子身上使之回暖。最低下部分=大地之子，非善非恶、非人性，形状像蛇。耶稣受难日使身上的基督完整，人自己降入地狱。用肮脏的水受洗，拥抱双性不洁的大地之子；黑色的人如影子，拒绝他则变成恐惧。通往原始与未来的门已打开。

## 关键概念补全

**对立之间的空中通道**：灵魂不是要取消是/否、上/下、左/右，而是升起门，使光能从街道一端照到另一端，天平指针轻轻摇摆。野兽走的是「从生到死，从死到生」的太阳之路。这与第三夜「只知上与下的差异」相接，但把对立说成必须通行的通道，而非仅供树木单向生长的两极。

**孵梦**：希腊神庙中睡以求梦的修炼。主人公用来讽刺管理员：他热爱厨娘做的美食，却从未在自己的「厨房」里求梦——不知道厨房为他准备什么。

**克林格索尔 / 安福塔斯 / 昆德丽 / 帕西法尔 / 古内曼兹**：瓦格纳歌剧《帕西法尔》人物。编者注概述圣杯、矛、伤与少年取回矛的情节，并记 1913 年苏黎世讨论及日后《心理类型》中的诠释。正文本身只呈现：管理员与厨娘入戏，巫师与少年都像「我」，最后脱下盔甲自己洗净。

**他者**：不是外面的敌人，而是「也在我们身上」、被「一个」的确定性所排斥的那一面。只满足于一个，对他者的渴望会被误解成「还要更多的同一个」。

**自我愚弄**：别人愚弄你可以归罪于他们；不能愚弄自己的人，会被别人愚弄。神圣与英勇是对他者的愚弄。

**大地之子**：要唤醒的黑暗人物；完全非人性，非善非恶，同时是性未成熟的男人和女人；形状像蛇；死者最大声的呼喊；被拣选因为他最被拒绝。不需要血、奶、酒，而要人奉献血肉。

**耶稣受难日**：主死亡、降入地狱、完成神秘之日。使身上的基督完整，人自己进入地狱——因为基督的王国覆盖世界，唯地狱在其外。要把基督的王国扩张到地狱，须「从一下降到二」，把心撕碎再结合。

## 论证推理链

### （一）灵魂：对立之间应有通道

- **论据/案例/事实**：晨风；生命仍受永恒困惑支配、被两极之火拉伸，但「夜晚被征服了」。灵魂要求：门升起；这里/那里、是/否、上/下、左/右之间自由通道；空中通道；光穿过平坦街道；天平轻摇；火不被吹灭；溪流向最深目标；野兽沿古老游戏道路去聚食场，生死如太阳之路不中断；一切踏上这条路。
- **论证推导过程**：通道、天平、不灭的火、流向最深目标的水、循环的太阳之路，都不是「选一边消灭另一边」，而是让对立可通行、可摇摆、可往复。
- **核心结论**：第四夜的课题是建设对立之间的通道，而不是在两极之火里被撕成单边。
- **延伸推论/现实启示**：随后他自己立刻陷入「白昼还是黑夜、睡着还是清醒、活着还是已死」——通道尚未建成时，对立变成自我玩弄。

### （二）厨娘、还书、孵梦

- **对话场景**：暮光之虫的笑原来是厨娘：你睡了一个多小时。他问是否在厨房睡着、「母神的世界是真的吗」（编者注指向歌德《浮士德》下到母神世界）。厨娘让他喝水。他读第二十一章安歇于主，每个字都像问号。厨娘是管理员的厨娘，管理员是美食家。
- **评注层**：走出时自问：管理员真的知道厨房为他准备什么吗？他肯定没有睡到神庙里求梦。还书对话：管理员觉得祷告书枯燥，对厨娘则「具启发性」；问「你在自己的厨房中孵过梦吗？」——「我对这种奇怪的想法不感兴趣。」他反讽：你已经学到很多关于自己厨房本质的方法。
- **核心结论**：精神的「图书馆」与身体的「厨房」分裂：管理员享用美食却不孵梦，不知道自己的厨房。
- **延伸推论/现实启示**：读安歇于主的句子入睡，每个字仍带着问题——安歇并未取消问号。

### （三）《帕西法尔》剧场：脱下盔甲成为自己

- **论据/案例/事实**：绿帘后是高顶大厅与花园，立刻联想到克林格索尔的魔法花园。病的管理员=安福塔斯，生气的厨娘=昆德丽；克林格索尔拿着他放在耳后的羽毛，且像「我」；帕西法尔也像「我」，冷静接住恶狠狠扔来的羽毛。观众就是他自己。受难礼须跪下。帕西法尔黑盔、狮皮、现代黑裤；无古内曼兹赎回之物、又为他祝圣。昆德丽远处抱头笑。观众在帕西法尔身上认出自己。
- **论证推导过程**：他脱下层层历史盔甲与荒谬绶带，穿忏悔裙到泉水旁，无陌生人帮助而自洗手脚，再脱忏悔裙穿便服，走出场景，走向仍跪着的观众-自己，站起来再次变成自己。
- **核心结论**：拯救者、巫师、病人、观众都是「我」的角色；路不是让古内曼兹祝圣，而是自己脱掉历史与忏悔的戏服。
- **延伸推论/现实启示**：编者注详述瓦格纳情节；正文的要点是「没有古内曼兹要赎回的东西」——外部祝圣缺席，自己完成洗净。

### （四）真正的他者：一个与他者的裂缝

- **关键对白（评注层 [2]）**：「如果它不是真的愚弄，那愚弄是什么呢？……想要接受自己的人必须真正接受自己的他者。」肯定中并非所有否定为真，否定中所有肯定都是谎言；人能在肯定与否定间日夜切换，故真/谬概念屈服，肯定与否定作为存在不屈服。
- **论证推导过程**：只对一个确定=保护、阻抗他者。一个不够，因为他者也在我们身上。误解渴望、更追求已有的那一个 → 他者更强烈坚持 → 若盲目追求一个，裂缝撕开：一个饮食过度而慵懒，他者饥饿而脆弱 → 脂肪窒息 + 被缺乏吞掉。这是病，见过太多；「只能这样，但它不必这样。」人被赋予自由去克服成因，因为人可以创造。通过接受他者的精神痛苦到达自由，成长才开始。
- **核心结论**：确定性若只覆盖一个，就是对他者的战争；成长从接受他者的痛苦开始。

### （五）自我愚弄与天赋

- **论据/案例/事实**：别人愚弄我，我可把罪归他们、忘记愚弄自己。不能愚弄自己的人将被别人愚弄。神圣与英勇是对他者的愚弄。特殊才能者受害于「我就是这种天赋」，天赋常以携带者个性为代价存活；个性被天赋的缺陷打上印记，是天赋的对立面。人永远在天赋之下。接受他者才能背负天赋、避开缺陷；只活在天赋中即拒绝他者、跨过标记——天赋是超出人类本质的自然现象，他并不具备，于是说别人愚弄他，其实是自己抛弃他者才变得可笑。
- **核心结论**：完整来自接受自我愚弄；天赋不是身份。卸下崇高角色，为了他者成为自己。
- **延伸推论/现实启示**：神进入生命时，为神回到贫穷，扛起丑陋可笑与应受谴责者，把困惑从神身上释放，「为神的行动铺好道路」。深渊是否已空？下方仍有急迫等待者。

### （六）如何唤醒死者：以利沙式的接受、大地之子、降入地狱

- **论据/案例/事实**：深度仍要更多。 inv 死者：血、奶、红酒、对死者的爱、与死者乱伦、与尸体交合——「我说的是『接受』，你却想要『占有，拥抱，交媾？』」随转述《列王记下》以利沙伏在孩子身上至身体回暖、七次鼻息、睁眼。真正的接受是含糊的神圣–邪恶的快乐，带着厌恶、淫乱的恐惧、性的不成熟——人用这种快乐唤醒死者。最低下部分像沉睡的死者，需要包含未分善恶的生命温暖。这不是目标，是道路和十字路口，是疾病与康复之始，是可恶行为与有益象征之母，是创造力最原始形式、暗流、自然的第一位神秘老师。形状像蛇；是大地之子。不需要血奶酒，而要人的血肉；直到精神把被肢解的身体放上祭坛，才听见他是最痛苦、最被拒绝因而被拣选的那一个。
- **论证推导过程**：深度沉默，他已出现在众生之间，带来不安、冲突、怀疑与充满。「阿门，一切都结束了。不真实的东西是真实的……」真正的耶稣受难日：使身上基督完整 → 自己降入地狱。谁能把基督王国扩到地狱？谁能清醒地酩酊？谁能从一到二、撕心再结合？「我是他，无名的人」：贬低自己、把自己当他人来提升，从而接受自己；分成两半再用自己结合；因渺小才意识到强大接近。不洁之水的洗礼，拥抱一夜之间变成男人的双性不洁兄弟；黑马已离他而去。黑色的人如影子：离开则跟随，不为他着想则怪异在旁，拒绝则变成恐惧。须纪念、设祭、在桌上为他留一整盘食品；世人因此认为他自私。地下震动：通往原始与未来的门打开，平凡背后的深渊张口，大地归还所藏。
- **核心结论**：接受他者/大地之子，必须降到地狱、用肮脏的水、以含糊的生命快乐唤醒，而不是用解释、高傲或自我惩罚。
- **延伸推论/现实启示**：编者注 Image117/119/121–123 涉及阿特马维克图、哲人石、卡与腓利门等日后材料，属图注层，不是本章论证步骤。

## 实操方法与教学细节

- **对立通道（灵魂给出的程序）**：不要关掉是/否、上/下；升起门，让通道空出来；让天平指针可以轻摇；让火不被风灭；让水流向最深目标；让生死循环像太阳之路一样不被打断。
- **对自己的厨房**：问「我是否在自己的厨房里孵过梦」，不要只享用「管理员」那一侧的美食与书。
- **脱戏服**：认出各个角色都是自己之后，自己洗，不要等古内曼兹祝圣；脱下历史盔甲，也脱下忏悔裙，穿回便服。
- **接受他者**：先意识到他者在自己身上，再跨入；不要把「还想要」理解成「还要更多的同一个」。接受自我愚弄，卸下神圣英勇的角色。
- **接受的品质**：不是冷酷、高傲、深思熟虑、谄媚、自我惩罚，而是含糊的、能结合更高之物的快乐。
- **对黑色的人**：纪念、设祭、留食物；拒绝会使他变成恐惧。世人会说你自私——因为他们看不见你把时间献给这位朋友。
- **避坑**：只确定一个；只活在天赋里；把「接受」做成占有与玷污；用良好基础、纯粹良知、守法的爱去「成功地」穿越——原文问：谁能这样到达地狱？

16. 【第三档·过渡/场景】管理员问好，说他回来了。
17. 【第三档·过渡/场景】他说明在旁边厨房读完，没想到是对方的厨房。
18. 【第三档·过渡/场景】管理员说没问题，希望厨娘没有失礼。
19. 【第三档·过渡/场景】他说厨娘很好，自己拿着书睡了一下午。
20. 【第二档·限定】管理员：祷告书对我们都很枯燥。
    (本段划定第8段那本书在「我们」一侧无启发)
21. 【第一档·必要依据】他说特别是对我们而言；但对厨娘很有启发。
    (本段是第20段的必要依据)
22. 【第三档·过渡/场景】管理员承认：对她而言是这样。
23. 【第一档·陈述】他问：你在自己的厨房中孵过梦吗？
24. 【第二档·可替换例证】管理员对这种奇怪想法不感兴趣。
    (本段旁证第15段「没有孵梦」)
25. 【第二档·次要观点】他反讽：你已学到很多关于自己厨房本质的方法。晚安。
    (本段旁证第23段)
26. 【第一档·陈述】拉开绿帘：克林格索尔的魔法花园与剧院。管理员=病的安福塔斯，厨娘=愤怒的昆德丽；克林格索尔与帕西法尔都像他自己。帕西法尔接住扔来的羽毛。
27. 【第三档·过渡/场景】场景转换：观众加入最后一幕，观众就是他自己。
28. 【第一档·陈述】受难礼中跪下。帕西法尔黑盔、狮皮、现代黑裤；无古内曼兹祝圣。他在帕西法尔身上认出自己，自洗、脱戏服、走出场景，再变成自己。评注开始：真愚弄、真怀疑、真对立；接受自己必须真正接受他者；肯定与否定作为存在不屈服，真/谬概念会屈服。
29. 【第一档·必要依据】只确定一个是对他者的阻抗。一个不够，因为他者也在我们身上。误解渴望、更抓已有的那一个。
    (本段是第28段「接受他者」的必要依据)
30. 【第一档·陈述】他者更强烈坚持；盲目追求一个则撕开裂缝：一个过饱慵懒，他者饥饿脆弱，因脂肪窒息、被缺乏吞掉。
31. 【第一档·限定】这是病，只能这样却不必这样。人有自由创造。通过接受他者的精神痛苦到达自由，成长开始。
    (本段划定第30段「病」可被克服)
32. 【第一档·陈述】不能愚弄自己的人会被别人愚弄。接受自我愚弄，神圣英勇倒下，才成为完整的人。神圣英勇是对他者的愚弄。
33. 【第一档·必要依据】天赋与携带者不是一回事，常以个性为代价。接受他者才能背负天赋；只活在天赋里即拒绝他者，变得可笑。
    (本段是第32段的必要依据)
34. 【第一档·陈述】神进入生命时，为神回到贫穷，接下丑陋可笑，把困惑从神身上卸下，为神的行动铺路。下方仍有急迫等待者。
35. 【第一档·陈述】深度仍要更多。真正的接受不是占有与交媾，而是如以利沙伏在孩子身上使之回暖：含糊的神圣–邪恶的快乐，用以唤醒死者。
36. 【第一档·必要依据】最低下部分需要未分善恶的生命温暖。这是道路而非目标，是创造力最原始形式、自然的神秘老师，形状像蛇。
    (本段是第35段的必要依据)
37. 【第一档·陈述】他是大地之子，完全非人性；死者最大声的呼喊。不要血奶酒，而要血肉。他被拣选因为最被拒绝。
38. 【第三档·过渡/场景】深度沉默了。他已出现在众生之间，带来不安、冲突、怀疑与充满。
39. 【第一档·陈述】真正的耶稣受难日：使身上基督完整，自己降入地狱。谁能把基督王国扩到地狱？谁能从一到二、撕心再结合？
40. 【第一档·陈述】我是无名的人，对自己一无所知，甚至隐去名字。
41. 【第一档·必要依据】尚未存在、仅即将形成。贬低自己、当他人来提升，从而接受自己；分成两半再结合。因渺小才意识到强大接近。
    (本段是第40段的必要依据)
42. 【第一档·陈述】用不洁之水受洗，拥抱双性不洁的大地之子；他一夜成男人，黑马已离去。
43. 【第一档·陈述】黑色的人如影子，拒绝则成恐惧；须纪念与设祭。世人因此说他自私。地下震动，通往原始与未来的门打开，大地归还所藏。
