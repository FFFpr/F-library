# 后记

## 本章位置

这是荣格 1959 年为《新书》所写、写到句子中间即停止的后记，位于第三卷《审视》之后、图版附录之前。它从作者自己的时间点解释：为何倾注十六年仍未写完。前接 [43_审视.md](43_审视.md)；图版见 [45_附录A.md](45_附录A.md)。出版史中对同一中断的叙述见 [03_前言.md](03_前言.md)。

## 核心论点

1. 他为这部作品倾注十六年；1930 年与炼金术的邂逅使他离开它。
2. 最终结束在 1928 年到来：好友威尔海姆寄来《黄金之花的秘密》文稿；书中内容自己进入现实，他不再继续创作。
3. 对肤浅的人而言它像疯狂之作；若不能吸收原始经验的强大力量，它也可能已是一部完整作品。借助炼金术，他最终把这些经验整合成一个整体。
4. 他一直知道经验中有宝贵内容，只知道用「宝贵的」方式写下：尽可能做成书，并重新经历一切、画出涌现的意象。
5. 他知道这项工作非常不适合自己，仍要对它保持忠诚——句子在「即使另外一种可能性从未……」处中断。

## 关键概念补全

**威尔海姆（卫礼贤）**：本后记所称好友，1928 年寄来《黄金之花的秘密》文稿。荣格把收到此稿当作创作《新书》的「最终结束」。

**《黄金之花的秘密》**：后记称为一部炼金术经典。荣格说其中内容找到自己进入现实的道路，故不再继续写《红书》。

**炼金术**：1930 年的邂逅使他离开《新书》。后记主张：炼金术帮助他把原始经验整合成整体；若无此整合，经验的力量可能使他把书写成「完整」却可能等于未能吸收。

**原始经验**：后记用来指写入《红书》的那些内在经历。它们力量强大；「吸收」与「整合成整体」被当成比把书写完更优先的任务。

> 💡 1959 年补誊、补画与此后记同时中断，见 [03_前言.md](03_前言.md)

## 论证推理链

- **论据/案例/事实**
  - 十六年工作；1930 年转向炼金术；1928 年收到《黄金之花的秘密》；停止创作。
  - 两种读法：肤浅者视为疯狂；作者自认若不能吸收原始经验，书反而可能显得「完整」。
  - 工作方式：做成书 + 重新经历 + 画出涌现的意象；明知不适合仍保持忠诚。
  - 编者注：此段在花体字抄本第 190 页；第 189 页一个句子中间誊抄突然中断，后记用正常书写写在次页，也在句子中间停止。
- **论证推导过程**
  - 先给出停止的外部时间（1928/1930 与炼金术、卫礼贤来稿），再解释停止不是抛弃经验，而是经验已能「进入现实」、并用炼金术整合。于是「未完成」被解释成整合成功的副作用，而不是单纯的放弃。最后把书写方式规定为「宝贵的」：书与画是重新经历，不是润色文辞。忠诚的誓言停在未写完的假设句上，与花体字誊抄的中断形式一致。
- **核心结论**
  - 《红书》停止，是因为原始经验已经通过炼金术被整合进现实；书本身可以、也确实保持未完成。
- **延伸推论/现实启示**
  - 用「像不像疯狂」来判断本书，正是后记所警告的肤浅读法；关键在读者能否吸收经验的力量。

## 实操方法与教学细节

- **如何写下「宝贵」经验（荣格自述）**：尽最大可能做成书；通过重新经历一切；画出涌现的意象。不是先写成论文再配图。
- **何时可以停**：当材料自己找到进入现实的道路（他举《黄金之花的秘密》），整合可以转到另一套语言（炼金术），而不必把誊抄进行到底。
- **避坑**：不要因为未完成或「像疯狂」就否定其中的宝贵内容；也不要把「不适合」当成可以不忠诚的理由——他写到自己仍要保持忠诚。
- **版本提示**：后记与花体字正文一样中断，现行结尾不是闭合的结论段。
