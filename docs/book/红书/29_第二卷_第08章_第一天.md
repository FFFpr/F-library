# 第二卷 第八章 第一天

## 本章位置

本章属第二卷《犯错者的意象》（Liber Secundus）中段，紧接把阿谟尼乌斯与红人推开之后的东行。上一章见 [28_第二卷_第07章_早期神庙的遗迹.md](28_第二卷_第07章_早期神庙的遗迹.md)：评注层明说，折磨巨大，正因为「并不是无缘无故地把两个放荡和堕落的人物推开」。本章幻想层发生在「第三天夜里」：黑白路面（火与冰）、山顶遭遇来自东方的巨人吉尔伽美什，科学话语使他瘫痪。评注层把这场遭遇读成内在对立的相遇，并决定在寒夜中守着受伤的神。通向次日如何救他： [30_第二卷_第09章_第二天.md](30_第二卷_第09章_第二天.md)。

编者注（沙姆达萨尼）：手写草稿题为「第七次冒险：第一天」；修改草稿作「7，伟大的遭遇，第一天，来自东方的英雄」。幻想日期注为 1914 年 1 月 8 日。

## 核心论点

**发生了什么（幻想叙事）**

1. 「我」光脚走入荒山窄谷：路一面是炽热铁块，一面是冰，必须从冰上走；山顶通道里，头生牛角、持双刃斧的巨人吉尔伽美什迎面而来，双方都恐惧。
2. 「我」自称来自西方，用地球为圆、绕日、无限空间、人永不能到太阳等「科学」回答他关于西方与太阳沉落的问题；巨人把斧砸碎，把碎片当作「最后的祭品」扔向太阳，像孩子一样哭着倒下，称这话语是比提亚玛特军队更强的毒魔法。
3. 夜寒中「我」生火。巨人追问火柴、飞行器、表；得知西方人并不长生、神已被科学夺走信仰能力。「我」说生活是一脚踏冰、一脚踏火；向东是为寻找没有的阳光。巨人警告过强光线会使人失明。两人在火边睡下。

**荣格对幻想的诠释**

4. 向南是难耐的孤独，向北是死去世界的冰冷，退回西方则有知识技能却无太阳；故抛弃一切向东，像孩子一样不发问、只等待。
5. 外在的黑白路、火与冰，是内在对立的意象；被拒绝的东西仍是本质的一部分，摧毁其外在形式并不等于征服自己。
6. 东来的巨人与西来的「我」互为倒影：他要下沉追落日，我要上升追日出；他强而盲，我弱而跛；蛇的语言（科学/逻各斯）咬中脚跟，使神降到人间。
7. 两种真理须在火边共存：失明者将跛足，跛足者将失明；不要僭越对方那一半路，否则人盲、神瘫。神惧怕人；人须守着受伤的神，否则生命会在半途中断。
8. 古人称拯救性语言为逻各斯；理性教育把毒药散向世界，使巨人（身上那位永恒的彷徨者）远离毒药却使周围瘫痪。应用这支毒箭射向内部的巨人，而不是射向同胞；不要杀掉他。

## 关键概念补全

**吉尔伽美什**：本章幻想中的专名。原文称他为巨人、长着牛角的人、强大的公牛、最强大的人；后文评注称他为神、公牛神、来自东方的英雄。他持斩牛式双刃斧，胸甲锃亮，黑须挂宝石。不要用本章未写的史诗情节去补他的生平。

**提亚玛特**：巨人说蠕虫的毒魔法「比提亚玛特的军队还要强大」。编者注：在巴比伦神话中，提亚玛特是诸神之母，发动对魔鬼军队的战争。后文「摔倒公牛、撕碎狮子、抗击提亚玛特军队的强大猎人」，编者注指草稿还写「像大卫用弹弓杀葛利亚」；并注荣格在《力比多的转化与象征》中讨论马杜克杀提亚玛特创世，故「强大猎人」相当于马杜克——此为编者注，不是荣格本章正文的定义。

**西方 / 东方**：幻想里「我」从西方来，太阳沉入大海之外的空旷空间；巨人问这是否通往西方世界的正确道路。编者注：在埃及神话中，西方世界（尼罗河西岸）是冥界。评注里西方=知识技能而无太阳的黑暗；东方=每日日出、阳光过强以致失明。

**两种真理**：「我」对外在的认知（科学）与神父对内在的真理相反，但对「我」而言二者都是真理。巨人半坐起，称这句话有用。

**逻各斯**：评注称，古人把拯救性的语言称为逻各斯，认为它表现神圣的理性；其最后命运是变成蛇与阴间恶龙，使人人中毒。编者注指向第二卷第四章；又注《心理类型》中思维与情感属理性功能——后者是编者注，不是本章荣格正文。

**毒 / 科学**：巨人称科学为使自己跛足的毒药、毒魔法、无形的蛇咬脚跟。尼采《快乐的科学》「毒药的学说」是编者注所引，不是荣格本章自己的引述。

## 论证推理链

### （一）幻想：火冰之路与吉尔伽美什

- **论据/案例/事实**
  - 第三天夜里，荒山、窄谷、岩壁；光脚被锯齿石划伤。路顺畅后一边白一边黑：黑侧是炽热铁块，白侧是冰，必须走冰。石盆地上有通往山顶的窄路。山顶另一侧巨响如岩石撞击；通道中巨人迎面而来。
  - 巨人：头生两只牛角，亮甲，卷曲黑须挂宝石，闪光双刃斧如斩牛斧。脸巨大、苍白、皱纹深，杏仁眼吃惊。「我」认出：这是吉尔伽美什。他双手双膝发抖。
- **论证推导过程**
  - 对话层：「我」像蠕虫挡路求饶。巨人不要他的命，问来处。答：从西方来，西方大海冲刷海岸。巨人连问太阳是否沉入海中、海之外是哪里。「我」答：太阳沉入大海之外的空旷空间；地球是圆的，绕着太阳转。巨人眼中愤怒与恐惧，前进一步。
- **核心结论**
  - 尚未进入科学长段，双方已经互相害怕：最强的公牛在发抖，「我」也发抖。

### （二）幻想：科学话语砸碎不朽

- **论据/案例/事实**
  - 「我」坚持：有被证明正确的科学，人乘船环球，学者能量太阳到地表的距离；地球是天体，在无限空间中。只要是人，永远无法到达太阳，永远无法不朽。
  - 巨人用石头砸碎斧头：「对抗无限和永恒的虚无 / 对抗空洞」，武器无用，应自我摧毁。西方太阳沉入云中。他把斧的碎片扔向太阳：「最后的祭品」，然后像孩子一样哭。
  - 称「我」为蠕虫，问在哪里吸到毒药。「我」答：毒药就是科学；国人从小受其滋养，故仍是侏儒；看见巨人时，觉得双方都中了毒。巨人：毒魔法比提亚玛特的军队更强；瘫痪平躺，求神救「被无形的蛇咬到脚跟而倒下」的儿子。
- **论证推导过程**
  - 巨人要答案，不要先找人帮忙：「顺其自然」；若今夜死去是应得的。他追问：神父所讲不像毒药，是否有两种真理。「我」：外在认知 vs 内在真理。巨人半坐起：「这句话真有用。」
- **核心结论**
  - 科学作为「毒」击倒的不是外敌，而是对不朽土地、到达太阳的信仰；两种真理的区分使巨人从彻底瘫痪中略起。
- **延伸推论/现实启示**
  - 原文此处尚未展开评注；启示要等到 [2] 层。

### （三）幻想：火柴、飞行、表，以及冰火中的生活

- **论据/案例/事实**
  - 「我」生火。巨人视火柴为法术；「我」说人人都有，还能乘机器飞。巨人几乎指为谎话。「我」出示表。原文下一句说话人作「以：」（当依上下文为巨人）：来自西方神圣世界，是否长生。「我」：没有什么比我们更容易老去；科学尚未对抗死亡；法术来自几个世纪对外界的观察与科学研究。
  - 「我」：人习惯科学这毒药，也变得跛足；失去力量，又通过掌握自然力量找回来。宁愿牺牲一部分生命力量，也不在无准备时与科学不期而遇——连最强的人、神都会因此死亡。
  - 巨人不再认西方为神佑之地，渴望东方智慧的清澈源泉。问：你们不再有神了吗？「我」：只有言语，有人说言语强大但无人注意。科学已剥夺信仰能力。怎么生活：「一只脚踏在冰中，另一只脚踏在火中，其他的就听天由命。」因不安而向东找阳光。巨人：地球既圆，没有太阳升起之处；东方阳光过强会失明。互相渴望对方的世界。火边睡下。
- **论证推导过程**
  - 技术神迹（火、飞、计时）并不能换来不朽或信仰；西方用掌握自然来补偿跛足，东方用阳光补偿，但两边都伤。
- **核心结论**
  - 现代生活被说成冰与火之间的听天由命；东行是找阳光，不是找另一套可以到达太阳的地理。

### （四）评注：为何东行；外在对立即内在对立

- **论据/案例/事实**
  - [2]：南=孤独激烈难耐；北=死去世界冰冷的死亡；退回西方=知识技能，却受无太阳之黑暗。故抛弃一切向东，像孩子不发问、只等待。花草地与春林之后，第三天夜里沉重如峭壁。入口窄路。折磨巨大，因推开两个放荡堕落人物；「毫不怀疑地吸收自己拒绝的东西」。接受对自己的作为，却拒绝作用在自己身上的东西。
  - 脚底被烧焦又冰冻；走到另一端却踩碎蛇头，毒液由脚跟入体，蛇比以前更毒。拒绝的仍是本质的一部分；摧毁其外在形式，只是暂时的外在，并未征服自己。
- **论证推导过程**
  - 「外在的对立是我内在对立的意象。」认识到这一点后保持沉默，思考灵魂中对立的分歧。外在对立可伤脚底，人仍能追遥远目标。
- **核心结论**
  - 征服外在对立容易，征服自己没有发生；毒因被拒绝而更强。

### （五）评注：早晨与黑夜的边缘；蛇与神

- **论据/案例/事实**
  - 最高点望东时，一人从东追消逝的阳光而来：我渴望阳光他渴望黑夜；我想上升他想下沉；我矮如孩子他伟岸如英雄；知识使我跛，阳光充满使他盲。他来自光明，我来自黑暗；他神我蛇；他古代我现代；他无知我有知识；他幻想我头脑清晰；他勇敢强大我懦弱狡猾。双方震惊。
  - 「追逐高升的人是渺小的，寻求下沉的人是伟大的。」神像太阳不猎杀蠕虫；蠕虫瞄准脚跟，为他准备下沉的必需品。一点点毒，巨人无声尝苦果——「能够致所有神于死地」。最亲爱最美丽的朋友要像太阳一样和「无边际的母亲」结婚。「蛇和神是多么相近啊，甚至可以说是完全相同。」曾经拯救的语言变成刺入脚跟的毒蛇。
  - 外在对立让开后，自己的对立站到面前互相挡路。蛇的语言战胜危险，道路仍阻：我从瘫痪变成失明，巨人为逃失明而瘫痪。我到不了太阳盲目的力量，他到不了永远多产的黑暗子宫。最强者倒下，神降到人间。编者注：草稿续写「这是我在梦中见到的。」
- **论证推导过程**
  - 对立项成对互换位置；语言/逻各斯既救又杀；神与蛇相近到同一。
- **核心结论**
  - 胜利是跛与盲的互换，不是到达对方的目的地。

### （六）评注：火边的两种真理；不要杀掉内部的巨人

- **论据/案例/事实**
  - 力量必须站到生命这一侧；外在生活范围应缩小。隐秘孤独的火种：火、山洞、暗林、稀落房屋、静溪、冬与夏夜、小船马车、罕见昂贵住所带来的安全。耐心增长。失明与跛足的人来到孤独火前，听两种真理，漫漫长夜共享火。原始的火必须再燃，因世界的夜广阔冰冷。火前的话模糊深刻，为生命指路。失明者应跛，以免跑进深渊；跛者应盲，以免蔑视自己够不到的东西。二者须感到无助，才尊重圣火。
  - 逻各斯：人类身上许多非理性需要理性拯救；等得够久，诸神变成蛇与阴间恶龙，逻各斯亦然，最后人人中毒。我们却使身上那位永恒彷徨的巨人远离毒药，同时散播毒药使周围瘫痪，因为想教育整个世界变得理性。有些人思维理性，有些人情感理性，都是逻各斯的仆人，秘密成为蛇的崇拜者。
  - 把自己囚于钢铁、每日抽打：击碎自己却未征服自己，只是帮巨人加剧瘫痪、加速失明。让他品尝逻各斯，一小滴即足以使他瘫痪。他是美丽有爱的兄弟，人却用毒箭射同胞——「瘫痪游戏是毫无价值的猎物」。值得张弓的是摔倒公牛、撕狮、抗提亚玛特军队的猎人。
  - 若像他一样活出自己，他会迅猛跑来；若忘记可怕武器，他会抓你为奴、让你对抗自己。不要杀掉他；要把神圣的塞巴斯蒂安绑在树上，一支支缓慢理性地把箭射进抽搐身躯——每一箭挽救一个矮小跛足的兄弟。常有误解：人总想破坏外部的美丽和最爱，却从不对内部采取相同手段。
- **论证推导过程**
  - 火是中点：人性与神性之间的光。教育全世界理性=对外射毒；应对准内部巨人，且不杀死他。
- **核心结论**
  - 两种残缺在火边互相限制，才不落入深渊或蔑视；逻各斯必须尝给巨人，而不是用来猎杀同胞。
- **延伸推论/现实启示**
  - 「人类总是想要破坏自己外部的美丽和最爱，却从来不对内部采取相同的手段」——把苦行、强迫理性施加于他人，等于饶恕内部巨人。

### （七）评注：一半对一半；神惧怕人；守夜

- **论据/案例/事实**
  - 东方没有带来可饮的光源，只带来病态堕落的他。只需走完自己这一半，另一半由他完成。人僭越神的一半则盲，神僭越人的一半则瘫。神性与人性都需要存在；人站在神面前，神也站在人面前。道路正中是火。
  - 神圣原始力量盲目，因已变成人的面孔；人是神性的面孔。神来则求怜悯，「神就是带有爱的恐怖」。古人：「落在永生之神的手中是可怕的。」（编者注：《希伯来书》10:31）他们曾把自己变成树一样绿、向东攀升，落入活神之手而屈膝。只有可怕的哭声能阻止神；神直面自己的面孔，神惧怕人。
  - 神若跛，必须支持他。黑夜吞毒时，兄弟在光明中屠狮斩龙，直到要射太阳，才遇阴影蠕虫。他本质是盲目过度渴望与狂暴；「我」的本质是看见聪明的局限与无能。他是公牛神，曾伤雅各的腰，如今「我」使他跛（编者注引创世记 32:24–29 雅各摔跤改名以色列）。要把他的力量据为己有，故须保住重伤者的性命。
  - 人只会站着说「是的，就是这样」，等事情发生，因为神病了；曾见他死后脸上蜥蜴般恶毒的光。若无法治疗神，生命将在半途中断。故选择在寒冷长夜中守着他。
- **论证推导过程**
  - 力量与盲目、重生与虚无互相拒绝；治疗神=守夜，不是再发明一套解释。
- **核心结论**
  - 神人各走一半；火在中间；不要让神死在「观察事情将会如何发生」的空话里。

## 实操方法与教学细节

本章以叙事/评注为主，未给出可逐步照做的实验规程。仍可从原文抽出程序与避坑：

- **先走完黑白路，再在山顶相遇**：外在对立（火与冰）只伤脚底；不要在脚底烫伤处停下来解释全世界。
- **外在对立出现时保持沉默**：认它是内在对立的意象后，「开始保持沉默，并思考我灵魂中对立的分歧」。
- **不要先摧毁被拒绝者的外在形式**：拒绝的仍在体内；踩碎蛇头会使毒更强。
- **两种真理并置，不要选边教育全世界**：对巨人讲外在科学而不否认神父的内在真理；火边让盲者跛、跛者盲。
- **活出自己，让巨人自己跑来**：若忘记「可怕的武器」，会被他抓去当奴隶、对抗自己。
