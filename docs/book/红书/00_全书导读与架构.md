# 全书导读与架构

## 版本与阅读说明

本书笔记依据仓库 `z-library` 中的中文 PDF：《红书》，（瑞士）荣格（C. G. Jung）著，（英）索努·沙姆达萨尼（Sonu Shamdasani）编译，周党伟译。纸版由机械工业出版社 2016 年出版，ISBN 978-7-111-55144-7。源文件约 1057 页、16 MB，有文字层，未做 OCR。笔记只根据该文件的文字层，不以他书或记忆补章。

荣格本人多称这部作品为《新书》（Liber Novus）；红皮革封面使之通称《红书》。中译本为研究保留页下注、图注、页边标注和原稿分页；叙述遭遇与事后诠释分层出现，编者用 `[1]` `[2]` `{ }` `[Image]` 等符号标出。读法见 [06_中译者按.md](06_中译者按.md)、[08_编者按.md](08_编者按.md)。

本文件是据全书整理的导读，不对应原书某一连续章节的原始段落。各章笔记文末另有该章的段落总结序列。

## 作者要回答的总问题

人在时代精神（要实用、要证明、要解释）之下，如何重新找到被丢失的灵魂，并在不被集体律法吞没的前提下，走完「自己的路」？

荣格的总答案写在 1957 年引子里：**追寻内在意象的那些年是生命中最重要的时光，后来的科学著作只是对外在分类、详尽阐述和整合进生命；那个神圣的起点已经包含一切。** 全书不是体系教科书，而是 1913 年起「直面无意识」的记录：先让幻想如戏剧展开，再以第二层文字检视它们。第一卷找回灵魂并下降；第二卷在彷徨的遭遇里犯错、孕育、献祭；第三卷审视自我，并由腓利门向死者布道。1959 年后记承认：与炼金术和《黄金之花的秘密》相遇后他停止誊抄，因为经验已经「进入现实」。

## 一条主线：从丢失的灵魂到与自己独处

贯穿三卷的不是「证明无意识存在」，而是一条可走的内在道路：

- **呼唤**：四十岁外物已齐，洪水幻象到来，必须对灵魂说话，而不是再增加身外之物。
- **下降**：沙漠、地狱、谋杀英雄（西格弗雷德）、神的孕育；以利亚、莎乐美与蛇构成神秘遭遇。
- **彷徨与犯错**：红人、城堡、隐士、死亡、吉尔伽美什、咒语与蛋、地狱与献祭、圣愚与诸夜、预言与魔法、十字架道路。
- **魔法与升天**：腓利门表明魔法不可学；神升天后，试金石变成「与自己独处」。
- **审视**：教化空洞的自我；腓利门向已拒绝基督教信仰的死者七次布道；人是门户，人有自己的星。

与这条道路平行的，是几种必须同时抓住的对立，而不是选边：

| 对立 | 大致所在 |
|---|---|
| 时代精神 / 深度精神 | 第一卷序言起 |
| 意义 / 无意义（终极意义是二者融合） | 第一卷序言、沙漠、恩宠 |
| 自己的路 / 他人的律法 | 序言末、十字架道路、审视 |
| 出于己心的异象 / 须忠实传讲的话语 | 第二卷序言《耶利米书》题词 |
| 理性 / 魔法 | 第二卷第二十一章 |
| 自我 / 原我（原我不是神） | 第三卷《审视》 |
| 相信 / 知道 | 七次布道 |

## 文本的三层，不要压成一层

| 层 | 是什么 | 常见标记 |
|---|---|---|
| 幻想 / 对话 | 夜里的遭遇、对灵魂说话、人物出场 | 常恢复为《黑书》顺序，编者或标 `[1]` |
| 评注 / 第二层 | 荣格事后对自己或「亲爱的朋友」作诠释 | 常标 `[2]` |
| 编者注 | 沙姆达萨尼的手稿异文、典故、年代 | 页脚注、图注、`[HI]` `[Image]` |

把评注里的句子当成幻想里已经发生的事，或把编者注当成荣格主张，都会读错。手稿本身未完成：花体字抄本中断，《审视》未进花体字，1959 年后记停在一句中间。当前印本是编者组合，不是作者定稿。

## 阅读时可抓住的操作顺序

正文给出的不是实验室规程，但态度与程序反复出现：

1. 先写、先看、先进入幻想，不要先用科学诠释「谋杀」它（第一卷序言：理解是桥，解释常武断）。
2. 对灵魂说话，把灵魂当作独立生命，而不是研究对象（第一章）。
3. 欲望对象不是灵魂；意象才是灵魂的财富。
4. 接受无意义、沙漠、疯狂中属于自己的那一块，而不是用时代精神把它们删掉。
5. 走自己的路，不要把荣格的遭遇当成律法；第二卷开篇又从反面警告：并非一切梦都等于神的话。
6. 魔法在第二十一章被说成不可学；终点是与自己独处，而不是获得秘法。
7. 《审视》中：原我不是神；布道教「知道」而非「相信」。

## 本书明确不作的事

- 不是《荣格全集》式的学术论文；荣格 1957 年末明言《黑书》《红书》不具备他所谓的学术特征，不希望收入全集。
- 不是已完成的封闭启示录；花体字与后记都中断。
- 不是把读者变成荣格：序言禁止把他的路当律法。
- 中译本出版说明要求批判接受：作者有时代烙印，部分观点偏于主观。
