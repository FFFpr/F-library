# 附录C

## 本章位置

本附录是编译者从荣格《黑书5》163–178页节选的开篇，日期标为1916年1月16日，自称「普天大系」宇宙学的初始草图。它给 [45_附录A.md](45_附录A.md) 里那幅符号图提供对应的说话：蛇/人/神的层级、青蛙神、鸽子、阿布拉克萨斯与「唯一的神」。它不接在《审视》叙事之后往下讲故事，而是把同一套宇宙图像用对话和定义写出来。前一篇是荣格对「神秘戏剧」的评论：[46_附录B_评论.md](46_附录B_评论.md)；本篇为全书附录之末。

## 核心论点

**发生了什么（文本场景）：** 1916年1月16日的记录。先有一句「神的力量是可怕的」，随即一个声音要「我」更多地体验它，并划分人生三时代。然后「我」问灵魂去了哪里，接着以第一人称陈述宇宙层级；后半是对「唯一的神」与阿布拉克萨斯当如何相处的长篇告诫。灵魂在结尾以母亲/调停者的身份说话。

**荣格/文本对这套宇宙学的主张：**

1. **人必须把上和下、神和动物绑在自己身上，否则裂成互不相通的三截：** 蛇（动物式自我）、人类的灵魂、天空的灵魂（鸟）。正常秩序是：蛇在下，人在中，神在上。
2. **下方链条与上方链条对举。** 蛇之外是菲勒斯，然后地球、月亮、冰冷空洞的外在空间。上方是鸽子或天空的灵魂，爱与先觉在此结合；蛇身上则是有毒与敏锐结合。
3. **太阳与月亮是神的两只眼睛：** 月亮是空洞的眼睛、通往死亡空间的十字路口；精神的太阳是充满的眼睛、通往普累若麻（充满的上界）的十字路口。二者是它们自己的象征，都是神；其他神的象征是行星。
4. **青蛙或蟾蜍之神没有大脑，是基督教的神与撒旦的结合；** 本质像火焰，像爱洛斯，但他是神，爱洛斯只是魔鬼。人生「第二个时代」是儿子的统治，这儿子被称为青蛙神；第三时代将是分配与和谐力量的时期。
5. **只可崇拜处在中间的「唯一的神」；对阿布拉克萨斯要记住、不要崇拜、不要寻找、也不要幻想能逃。** 阿布拉克萨斯是宇宙之神、创造性驱力、形式与物质，在所有光暗之神以上；崇拜他会增加他在你身上的力量。
6. **人通过「个体化原则」追求绝对个体性：** 把普累若麻的绝对消解集中成一颗无限小的闪耀恒星（蓝光、冰冷、孤独、超越死亡）。不完成个体化的灵魂成为围攻生者的死者，或变成遥远恒星。
7. **作为人，你是自己恒星之神的痛苦心脏；作为神，你在自己的世界里就是阿布拉克萨斯。** 在此世必须接受阿布拉克萨斯的强迫并活出生命；逃离痛苦等于无意识地抓住他，唯一的神就得不到火。

## 关键概念补全

**《黑书5》：** 荣格的私人笔记第5册。本附录标明节选开篇163–178页，是「普天大系」宇宙学的初始草图。编者注指出草图见附录A。

**普天大系：** 一套把人、蛇、鸟、天母、菲勒斯、日月、阿布拉克萨斯与「唯一的神」安置在同一图里的宇宙学。附录A给图例，本篇给讲解。

**普累若麻：** 本篇定义为「充满的上界」。精神的太阳是通往它的十字路口。它无限大；人把它集中到最大张力时，它变成无限小的闪耀恒星。诸神是「普累若麻和永恒空洞的澄清，是永恒品质的轮廓」。

**个体化原则：** 本篇用语，不是从别的书搬来的后期定义。人「追求绝对的个体性」，途径是不断集中在普累若麻的绝对消解之上，使普累若麻成为一颗小太阳般的个体恒星。不遵循者「最终都不能成为神，因为他不能忍受个体性」。围攻我们的死者，是尚未完成此原则的灵魂。

**青蛙神 / 蟾蜍之神：** 「没有大脑」，基督教的神与撒旦的结合；本质像火焰。声音称人生第二时代为「儿子的统治时代，你称他为青蛙神」。图例中他等于阿布拉克萨斯（见附录A）。

**阿布拉克萨斯：** 宇宙之神，极度强大可怕；创造性也是被创造的；强迫、毫不留情；既是宇宙的生命也是宇宙的死亡。人越摆脱他越接近死亡，死后仍被他降服。人在自己的世界里也是阿布拉克萨斯。不要寻找他，他会像爱洛斯一样找到你。

**唯一的神：** 处在中间、已到来、极美友善、孤独、星星一般、一动不动；比父亲更聪明老练；给人快乐与和平，因已超越死亡与一切改变。崇拜、祷告、合一都只应对他。他「离你很近，比你的灵魂离你还近」。他自己在其遥远世界里也是一个阿布拉克萨斯，但不在「你这里」。

**蛇 / 鸽子：** 蛇在下：地上的灵魂（附录A图例）；有毒与敏锐结合；敏锐是「魔鬼的理解力」，能在你不怀疑处找到蛛丝马迹。鸽子是天空的灵魂：爱与先觉结合。分裂时，天空的灵魂以鸟的形式与诸神同住，人对它一无所知。

**菲勒斯 / 天空之母 / 大地：** 在「我」之外：天空之母，对应部分是菲勒斯；菲勒斯的母亲是大地，其目标是成为天上的母亲。天空之母是天界的女儿，对应大地；被精神的太阳照亮，对应月亮。天空之母是「诸神秩序中的魔鬼」，居住在天界。

**爱洛斯：** 本篇说爱洛斯「只是一个魔鬼」；阿布拉克萨斯像爱洛斯但更是神。唯一的神看见地球会试图使它生育，是「他的爱洛斯使他陷入」痛苦之处。

**先觉：** 与爱一起在鸽子/天空的灵魂中结合。本篇未另下定义。

> 💡 爱洛斯与逻各斯作为心灵对立力量的长篇评论，见：[46_附录B_评论.md](46_附录B_评论.md)

**诸神：** 讨人喜欢或不讨人喜欢，非个人，恒星的灵魂，影响力，驱力，灵魂的祖父，天界的统治者。既不危险也不友好；强大但谦逊。不计其数。带来超级基础：自身包含所有品质又一无所有；人的完全消解；死亡和永恒的生命。

## 论证推理链

### 一、编者说明与三时代

- **论据/案例/事实：** 编者（沙姆达萨尼）标明：节选自《黑书5》163–178页，是「普天大系」宇宙学的初始草图。日期：1916年1月16日。正文起句：「神的力量是可怕的。」声音：「你甚至应该更多地体验它。你在人生的第二个时代，第一个时代已经被征服。这是儿子的统治时代，你称他为青蛙神。第三个时代将紧随其后，这是分配和和谐力量的时期。」
- **论证推导过程：** 可怕的神力不是叫人退开，而是叫人「更多地体验」。历史被切成三截：已征服的第一时代；当前儿子/青蛙神的统治；尚未到来的分配与和谐。
- **核心结论：** 本篇宇宙学从「现在是青蛙神的第二时代」开口，不是从抽象图表开口。
- **延伸推论/现实启示：** 无超出原文的时代表。

### 二、绑住上下，否则三分

对话场景：「我的灵魂，你你去哪里了？你到动物那里去了吗？」（文字层叠字「你你」，照录。）

评注层（第一人称宇宙陈述）：

- **论据/案例/事实：** 「我将上和下绑在一起，我将神和动物绑在一起，我身上一部分是动物，另一部分是神，第三部分是人。蛇在下，人在中，神在上。蛇之外是菲勒斯，接着是地球，然后是月亮，最后是冰冷空洞的外在空间。上方是鸽子或天空的灵魂，爱和先觉在这里结合，就像有毒和敏锐在蛇身上结合一样。敏锐是魔鬼的理解力，它总能探测到更小的东西，在你不会怀疑的地方找到蛛丝马迹。」若没有通过结合上下来结合自己，则分裂为：蛇——自我以这个或其他动物形式漫无目的行走，魔鬼般生活在自然中，激发恐惧和渴望；人类的灵魂——永远活在你里面；天空的灵魂——与诸神居住，远离你，你一无所知，以鸟的形式出现。三部分相互独立。
- **论证推导过程：** 完整的人不是单纯的人，而是把动物（下/蛇）与神（上/鸽子）绑在中间这一截上。松开绳子，不是「更纯粹」，而是三截各自乱跑：兽性的自我、内住的人魂、远走的鸟魂。
- **核心结论：** 宇宙层级首先是一种自我构造：绑，或裂。
- **延伸推论/现实启示：** 敏锐（能见微知著）被放在蛇/魔鬼一侧，与鸽子一侧的爱和先觉对举——理解力可以是「有毒的」。

### 三、天母、日月、诸神、普累若麻

- **论据/案例/事实**
  - 在我之外：天空之母 ↔ 菲勒斯；菲勒斯之母=大地，目标是成为天上的母亲。
  - 天空之母是天界的女儿 ↔ 大地。
  - 天空之母被精神的太阳照亮 ↔ 月亮。月亮=通往死亡空间的十字路口；精神的太阳=通往普累若麻的十字路口。月亮是神空洞的眼睛，太阳是神充满的眼睛。看见的日月是象征，且「太阳和月亮是它们自己的象征，都是神」。其他神的象征是行星。
  - 天空之母是诸神秩序中的魔鬼，住在天界。
  - 诸神：非个人的恒星灵魂；影响力、驱力、灵魂的祖父、天界统治者（空间中或力量中）。不危险也不友好；强大而谦逊；普累若麻与永恒空洞的澄清；永恒品质的轮廓。不计其数；超级基础：包含所有品质又一无所有；人的完全消解；死亡与永恒生命。
- **论证推导过程：** 可见的天体不是「仅仅是天体」，而是神的眼睛或神自己的象征。普累若麻作为充满，与月亮一侧的空洞/死亡空间成对。诸神既不是道德上的保护者也不是单纯的威胁，而是品质的轮廓——多到可以取消人。
- **核心结论：** 上界有一张对应表（天母/菲勒斯、日/月、充满/空洞），诸神是这张表的「澄清」，不是人格化的唯一上帝。
- **延伸推论/现实启示：** 无。

### 四、个体化：把无限大收成蓝星

- **论据/案例/事实：** 人通过个体化原则变化，追求绝对个体性，办法是一直集中在普累若麻的绝对消解之上。由此使普累若麻达到最大张力，本身成为闪耀恒星：无限小，对普累若麻的无限大。越集中，个体恒星越强；闪光的云包围它，沉重星体形成如小太阳，喷出火焰。故称 egw[eimi]sumplanozumin。编者注[1]：希腊文意为「我是一颗星，和你一起游荡」，出自阿尔布雷希特·迪特里希《密特拉密教仪式》（莱比锡，1903）8页5行；荣格将此句刻在波林根家里的石头上。太阳是神和灵魂的祖父；个体恒星也一样。其光蓝色，如遥远恒星；在遥远太空，冰冷孤独，超越死亡。「为了获得个体性，我们需要更大的死亡。」又称 ei eoi este。编者注[2]：「你是神。」出自《约翰福音》10章33–34节（犹太人指责耶稣僭妄；耶稣引律法「我说你们是神」）。统治地球的人不计其数，恒星与统治天界的神也不计其数。此神免于人类死亡；孤独对他可以是天堂也可以是地狱。不遵循个体化原则的人最终不能成为神，因不能忍受个体性。围攻我们的死者：未完成个体化的灵魂，或已变成遥远恒星的灵魂。只要我们未完成，死者就指责并围攻，无法逃脱。此处原文有图；编者注[3]：普天大系草图见附录A，563页。
- **论证推导过程：** 个体性不是从群体里「挑出来」那么简单，而是把那个会把人完全消解掉的充满，收成一颗又冷又远的蓝星。代价明确写出：更大的死亡、孤独（可天堂可地狱）、以及未完成者死后仍来围攻。密特拉仪式句与约翰福音句都是编者注明的出处，不是荣格在本段里展开的考证。
- **核心结论：** 「成为神」在本篇=完成个体化=忍受那颗孤独蓝星；不是崇拜阿布拉克萨斯。
- **延伸推论/现实启示：** 死者的围攻被解释为个体化未完成的压力，不是另给一套鬼魂学。

### 五、青蛙神、唯一的神、阿布拉克萨斯

- **论据/案例/事实**
  - 青蛙/蟾蜍之神：无大脑；基督教的神与撒旦的结合；本质像火焰；像爱洛斯但是神（爱洛斯只是魔鬼）。
  - 「唯一的神，对他的崇拜已经到来，他处在中间。」只能崇拜他，其他神不重要。
  - 阿布拉克萨斯让人害怕，将他与「我」分离是一种释放。不必寻找，他会找到你，像爱洛斯。他是宇宙之神；创造性驱力；形式和形态，如物质和驱力；在所有光与黑暗的神之上。把灵魂拉走投入生育。创造性也被创造。自我重生的周期：几天、几月、几年、人的一生、几世纪、人类过程、生命过程、天体过程。强迫，毫不留情。崇拜他=增加他在你身上的力量→难以忍受；清除他=可怕的麻烦。越摆脱他越接近死亡（他是宇宙生命也是宇宙死亡）→死后再次被降服。故：牢记他，不要崇拜他，不要想象能逃；他一直在身边。必须在生命中间，被死亡完全包围；伸展四肢像钉在十字架上，吊死在他身上，可怕，难以忍受。
- **论证推导过程：** 中间那一位（唯一的神）才是崇拜对象。阿布拉克萨斯不是用来祈祷的，也不是用来消灭的：消灭等于找死，崇拜等于把他养大。剩下的态度是「记住、活在中间、像被钉住那样承受」。
- **核心结论：** 宇宙生命本身（阿布拉克萨斯）不可当神来拜，也不可当敌人来灭。
- **延伸推论/现实启示：** 「你必须在生命的中间，被死亡完全包围」——生命与死亡不是先后两段，而是同时张开的十字架。

### 六、你既是心脏也是阿布拉克萨斯；如何活

- **论据/案例/事实**
  - 唯一的神：美、友善、孤独、星一般、不动；比父亲聪明老练；可靠；带你穿过阿布拉克萨斯的黑暗与死亡恐惧；给快乐与和平（已超越死亡与改变）。他不是阿布拉克萨斯的仆人/朋友；他自己就是一个阿布拉克萨斯，但不在你那里，而在他自己遥远的世界——因为你自己就是一个神，在自己的年代、创造和人类中自我重生，对他们的强大如同阿布拉克萨斯之于你。
  - 「你自己就是创造者和被创造出的存在。」「你有唯一的神，你在不计其数的神中变成自己唯一的神。」
  - 作为神：你是自己世界里伟大的阿布拉克萨斯。作为人：你是神的心脏，以伟大的阿布拉克萨斯的形式出现在他的世界里——可怕、强大、疯狂的供体；分配生命之水、生命之树的精神、魔鬼的血液、死亡使者。你是自己唯一恒星神的痛苦心脏；该神是他自己世界的阿布拉克萨斯。故你渴望他、爱他、为他而活。你害怕此世的阿布拉克萨斯（人类世界的统治者）。接受他强迫你做的事，他是生命主宰，无人能逃。不接受：他折磨你至死，你的神的心脏也受折磨，如同「基督唯一的神在去世的时候遭受的巨大痛苦」。
  - 人类痛苦无终点，因生命无终点；无人能看见终点；即使到了也无人承认。对人无终点，对诸神则是终点。
  - 基督之死没有带走世界的痛苦。他的生命所教：若个体能对抗阿布拉克萨斯的力量活出自己的生命，会令唯一的神高兴。唯一的神从地球痛苦转移到其爱洛斯使他陷入处：他看见地球就试图使它生育，忘记世界已交给他、他就是此世的阿布拉克萨斯。于是唯一的神变成人，再把人拉升进入他，唯一的神再次完整。
  - 摆脱阿布拉克萨斯的力量≠撤离它；无人能脱离，只能受支配。基督使自己受其支配，仍被他以可怕方式杀掉。
  - 只能借助活出生命来摆脱：活到有助于你的水平。即使如此，仍受其力量与欺骗支配；但同一水平上，你身上的恒星之神获得渴望和力量，欺骗的恶果与人类的失望落到他身上。痛苦与失望冰冷充满阿布拉克萨斯的世界；生命的温暖下沉到灵魂深度、人的中点，那里唯一的神的蓝星微弱闪烁。
  - 逃离阿布拉克萨斯的恐惧=逃离痛苦与失望=仍害怕=出于无意识的爱抓住他，唯一的神得不到火。能通过痛苦和失望拯救自己：渴望如成熟果实落下，顺重力朝中点，蓝光在此升起。
  - 不要逃离、不要寻找；感受强迫但不要抗拒，才能活下去、赎回自己。阿布拉克萨斯的工作需要完成：在你自己的世界你就是他，并强迫你的生物完成你的工作；在这里你是受他控制的生物，必须学会完成生命的工作。
  - 「为什么都是这样？」世界可疑。这是神无尽的无限愚蠢，而你知道的却是无尽的智慧。它也是犯罪、难以饶恕的罪，因此也是最高的爱和美德。
  - 活出生命，不要逃离；认识其必要性。一种意义：不要怕他、不要爱他。另一种意义：要怕他、要爱他。「他是地球的生命，这足够说明一切了。」
- **论证推导过程：** 同一结构套了两层：在人类世界，阿布拉克萨斯统治你；在你作为神的世界，你统治你的造物。基督示范的不是消灭世界主宰，而是对抗其力量活出个体生命——即使仍会被杀掉。逃离痛苦会把火扣住，蓝星点不着；把痛苦过完，渴望才因重力落到中点。对阿布拉克萨斯的态度必须自相矛盾（怕/爱与不怕/不爱），因为「他是地球的生命」。
- **核心结论：** 救赎路径是活，不是逃；崇拜对象是中间的唯一之神，不是生命本身的强迫者。
- **延伸推论/现实启示：** 世界可同时是愚蠢、罪、与最高的爱——本篇要求把这三句一起读，不选一句。

### 七、神的多样性；灵魂作为调停者

- **论据/案例/事实：** 必须认识神的多样性。不能把一切结合成一个存在；若你不是具有人的多样性的一个人，唯一的神也不是具有神的多样性的一个神。唯一的神：善良、有爱、引导、治愈。全部的爱与崇拜都应给他；向他祷告、与他合一；他比灵魂更近。灵魂自称：母亲，体贴又可怕地包围；滋养也使你堕落；预备东西和毒药。她是你与阿布拉克萨斯的调停者；教你艺术，保护你摆脱阿布拉克萨斯；站在你与无所不包的阿布拉克萨斯之间。她是你的身体、阴影、在此世的效力、在神的世界中的表现、光辉、呼吸、气味、魔法力量。「如果你想与人生活在一起，你应该呼唤我，但如果你想上升到人类世界之上，与恒星的神圣和永恒的孤独生活在一起，你应该呼唤唯一的神。」
- **论证推导过程：** 多样性不是对「唯一」的否定：人的多样与神的多样同构。灵魂不是唯一的神，而是中间人——既保护你摆脱阿布拉克萨斯，又用毒药与堕落包围你。两条呼唤：跟人在一起呼灵魂；要恒星孤独呼唯一的神。
- **核心结论：** 日常与人共处走灵魂；超越人类世界走唯一的神；阿布拉克萨斯仍不是祈祷对象。
- **延伸推论/现实启示：** 原文把「艺术」算在灵魂的教导里，与附录A 1955年说明中「艺术属于圣童的精神世界」可对照，但本篇未做这一对照。

## 实操方法与教学细节

本章是宇宙学陈述与告诫，不是逐步技术手册。原文仍给出可执行的态度与程序：

- **绑：** 把上/下、神/动物绑在自己身上，避免裂成蛇、人魂、鸟魂三截互不相通。
- **只崇拜中间的唯一之神：** 祷告、合一、全部的爱；其他神「不重要」。
- **对阿布拉克萨斯：** 牢记；不崇拜；不寻找；不幻想能逃；感受强迫但不抗拒；活到「有助于你的水平」；完成生命的工作。一种意义不怕不爱，另一种意义又怕又爱。
- **不要逃离痛苦和失望：** 逃离等于无意识抓住阿布拉克萨斯，唯一的神得不到火。让渴望如成熟果实按重力落到中点。
- **两条呼唤：** 与人生活→呼唤灵魂；上升至恒星孤独→呼唤唯一的神。
- **避坑（原文）：** 崇拜阿布拉克萨斯会把他养大到难以忍受；清除他会带来可怕麻烦并在死亡中被他重新降服；不接受其强迫则人与「神的心脏」一并被折磨致死。
