# 全书导读与架构

## 版本与阅读说明

本书据李泽厚《美的历程》生活·读书·新知三联书店「李泽厚集」本整理笔记。版权页载：2009 年 7 月北京第 1 版，2014 年 3 月第 13 次印刷；ISBN 978-7-108-03037-5；约 163 千字，插图 109 张。英文书名见丛书扉页：*The Path of Beauty*。简体字版权由三民书局授权三联书店在中国大陆独家出版。

源文件为扫描 PDF（约 225 页、无文字层），笔记依据同一文件的中文 OCR 文本。识别有个别错字，行文已按上下文校正明显讹误（如「饕餮」「狞厉」「宋元」），不以他书或记忆补章。

封面引冯友兰：这是一部中国美学和美术史、文学史、哲学史、文化史。易中天称其以十几万字完成「美的历程」，高屋建瓴而疏密得当。作者自谓是「匆匆迈步」的巡礼，不是细部鉴赏手册。

## 作者要回答的总问题

中国古典文艺从远古到明清，何以能串成一条可感的「美的历程」？凝冻在彩陶、青铜、诗文书画、石窟、小说戏曲中的时代精神，为何仍能感染今天的人？

作者的总答案是：**美是积淀了社会内容的自然形式**；艺术作品是「打开了的时代魂灵的心理学」；人性不是先验神性，也不是官能兽性，而是感性中有理性、个体中有社会。各时代的主导审美风貌，最终（而非直接）受经济生活与社会结构制约，又通过巫术礼仪、儒道互补、门阀与世俗地主、市民等因素层层曲折地起作用。

## 一条主线：积淀

「积淀」是贯穿全书的方法关键词：

- **对象一方**：自然形式（色彩、线条、形象、程式）里积淀了社会内容。
- **主体一方**：感官愉快里积淀了观念、想象、理解，于是不同于动物性快感，成为审美感情。
- **历史一方**：原来「有意味的形式」因反复仿制，可能失去原初巫术含义，变成一般形式美；但民族心理结构仍与古典作品同构，这是艺术永恒性的秘密之一。

克乃夫·贝尔（Clive Bell）提出「美是有意味的形式」（significant form），却陷入「有意味的形式 ↔ 审美感情」的循环。作者用积淀论给它历史内容：几何纹、书法、戏曲程式之所以「有意味」，是因为写实形象、社会情感曾溶化在形式里。

## 十章逻辑地图

全书按时代精神的主导风貌推进，不是按门类平列的美术通史。

```text
远古巫术图腾（龙飞凤舞）
    → 早期奴隶制的狞厉崇高（青铜饕餮）
        → 北中国实践理性（先秦理性精神）
            ↔ 南楚神话激情（楚汉浪漫主义）
                → 人的觉醒与文的自觉（魏晋风度）
                    → 宗教艺术由苦难到世俗（佛陀世容）
                        → 青春抒情 vs 规范典范（盛唐之音）
                            → 心境意绪与韵味（韵外之致）
                                → 山水三境：无我 / 诗意特写 / 有我（宋元山水意境）
                                    → 市民、浪漫、感伤、批判（明清文艺思潮）
```

与这条时间轴平行的，是几组对照：

| 对照 | 大致归属 |
|------|----------|
| 外在事功 / 内在人格 | 汉代 vs 魏晋 |
| 内容溢出形式 / 形式与内容严格结合 | 李白、张旭 vs 杜甫、颜真卿、韩愈 |
| 无我之境 / 有我之境 | 北宋全景山水 vs 元人笔墨写意 |
| 儒（礼乐、载道、兼济）/ 道（自然、审美、独善） | 第三、八章的互补结构 |
| 北中国理性化 / 南楚巫风 | 第三、四章 |

作者还标出中国古代社会**三大转折起点**：魏晋、中唐、明中叶。中唐被特别强调为「承前启后」、比盛唐更关键的文艺史节点。

## 阅读本书时可用的鉴赏框架

作者虽写史，却给出可操作的观看顺序：

1. 先问：这一时代「人」被摆在何处？是征服外物、是内在风神、是心境意绪，还是市井人情？
2. 再问：主导部类是什么？远古是陶器纹饰与歌舞，殷周是青铜与金文，魏晋是诗与书法人物，唐是诗与书，宋元是词与山水，明清是小说戏曲。
3. 再问：形式里积淀的是巫术、宗教、伦理，还是已经净化为笔墨、程式、韵味？
4. 最后对照：同一题材在魏 / 唐 / 宋，或汉 / 六朝 / 唐俑上，气势、静穆、世俗如何位移。

## 本书明确不作的事

- 不为巫术与宗教、神话与礼仪的先后次序作专门考辨。
- 不把艺术与经济作成简单对应；承认部类不平衡，但不同意因此放弃总体规律。
- 鸟瞰式巡礼，细部价值要另作专门研究。
