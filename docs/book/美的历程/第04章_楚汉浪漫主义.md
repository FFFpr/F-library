# 第04章 楚汉浪漫主义

## 本章位置

北中国理性节节胜利时，南中国仍保存氏族社会与神话—巫术传统。本章论屈原所代表的楚文化如何流入两汉，成为主宰汉代艺术的美学思潮。

> 北中国礼乐理性：[第03章_先秦理性精神.md](第03章_先秦理性精神.md)

## 核心论点

1. 屈原作品集中代表南方神话—巫术文化；《离骚》把原始浪漫想象与理性觉醒期的个体人格溶成整体，是抒情诗真正光辉的起点。两千年来艺术水平上或只有《红楼梦》可相比。
2. **汉文化在文艺上就是楚文化**：制度汉承秦制，文学艺术却保持南楚本色。
3. 汉代艺术真正主题是**人对客观世界的征服**；神仙世界是此岸的延长，不是苦难的彼岸。
4. 风格是**气势与古拙**：运动、力量、速度；粗轮廓、无细节修饰；铺天盖地满幅构图。这是整体性的民族精神，尚未分文人/民间。

## 一、屈骚传统

### 论证推理链

**论据**

- 儒家把「黄帝四面」解为派四大臣治四方，删《诗经》使「怪力乱神」消失；南方则保存在《楚辞》《山海经》（蒙文通以为南方产品）。
- 《离骚》：美人香草、望舒飞廉、巫咸夕降、「路曼曼其修远兮，吾将上下而求索」；主人公执着、忧伤、愤世。
- 《天问》：神话向历史过渡的疑问系列。
- 王逸：沅湘「信鬼而好祠」，作歌乐鼓舞以乐诸神，故有《九歌》。
- 王夫之释《九辩》：绍古体（可溯夏初）、可被管弦、激昂淋漓异于风雅、为汉赋之祖。四点：源远流长；可歌可舞、本是集体巫术；尚未受儒家诗教严格束缚；开汉赋。
- 刘邦、项羽核心来自楚；四面楚歌、《大风歌》、西汉宫廷楚声主导。
- 庄子属南方体系：屈有《远游》，庄有《逍遥游》。
- 马王堆帛画、洛阳卜千秋墓壁画：女娲蛇身、神魔、人神杂处，与《招魂》四方不可托的恐怖世界/求仙祝福世界同属浪漫巫风。

**推导**

东汉以后儒学、历史故事侵入画面，南北混同：神话与历史、节操与荒忽并陈。原始神话相对褪色，人世占据更多位置，但浪漫幻想仍是楚汉艺术的灵魂。

**结论**

不了解楚汉一脉，很难阐明两汉艺术。它是先秦理性的辅车，不是对立取消。

## 二、琳琅满目的世界

### 论证推理链

**论据**

- 儒家规定艺术「厚人伦，美教化」，但汉艺术并未受狭隘功利束缚。
- 神仙：秦皇汉武求不死药；羽化登仙是对人生的全面肯定，要永恒延续，不是否定现世（对比第六章佛教迷狂）。
- 画像石分层：伏羲女娲至夏桀；孝子；刺客；车马。或风伯雷公与捕兽同台。
- 山东武梁祠、河南南阳、四川成都及嘉祥宋山：宴乐百戏、庖厨、冶铁、农耕、东王公西王母、孔子见老子、羽人玉兔……从贵族享乐到下层劳动，猪圈鸡舍也认真刻画。
- 黑格尔论 17 世纪荷兰小画派：对日常的津津玩味肯定了人民对生活的热爱；汉更宏伟，是统一帝国的征服主题。
- 王延寿《鲁灵光殿赋》：奔虎虬龙、图画天地、忠臣孝子「靡不载叙」。
- 汉赋：《子虚》《上林》到《两都》《两京》，「苞括宇宙，总览人物」；班固铺陈城郭市井、沟塍、上林奇兽。虽堆砌拙笨，广度后世难再及。
- 工艺：马王堆素纱禅衣、金缕玉衣、汉镜、漆器——作者称为空前绝后（瓷器、木家具除外），因为战国至西汉顶峰的世代工匠集体手工业，不计工时。

**推导**

神不再威吓支配人间，人要上天分享神的快乐：是人对神的征服。历史故事与世俗场景构成双翼。人溶化在外在环境中，不在自身精神世界中——故心胸开阔、气派雄沉，尽管粗重拙笨。

**结论**

应从「征服世界的对象化」去欣赏汉画与汉赋，才能估定汉赋作为一代文学正宗的价值。

## 三、气势与古拙

### 论证推理链

**论据**

- 弯弓射鸟砖、长袖陶俑、奔马、说书俑、荆轲刺秦、车马战斗、卜千秋人神动物行列：无细节、无个性抒情，高度夸张的大动作。
- 《马踏飞燕》= 速度；匕首入柱 = 速度的瞬间。
- 对比：唐俑有动作却少狂放气势；唐三彩马鲜艳但气势不及汉马；天龙山唐雕肌肉凸出，仍逊汉石雕的整体力量；宋画像砖细微姣好，生命感距汉很远。
- 构图满幅不留空白，似笨拙，却是丰满朴实，近农民画，异于后世空灵。

**推导**

人物以其事迹、行动、对外在世界的关系表现存在价值，不是以心灵个性。古拙（比例不合、直线棱角、过长袖过弯腰）是展示运动力量的必要因素。民间与文人尚未分化：从画像石到乐府、壁画、工艺、陶俑、隶书，呈现的是整体民族精神。唐多「胡气」（中外交融），汉更是中华本土：楚来的天真狂放 + 古拙气势。

**结论**

气势与古拙浑然一体。汉的蓬勃整体性力量，后代难以企及。

## 段落总结序列

### 屈骚传统

- 当北方文化以理性精神逐步摆脱巫术礼制时，南方因保留较多氏族社会遗存，仍发展着绚丽的图腾神话传统。《楚辞》《山海经》和庄子等共同构成奇异想象与炽烈情感弥漫的文化背景，其文艺代表便是屈原。
- 屈原之所以深远影响后世文艺，在于其作品集中代表了根基深厚的南方神话巫术文化。与儒家把神话理性化、历史化并从《诗经》中排除“怪力乱神”不同，屈原保存了活泼的远古想象。
- 《离骚》以香草美人、神巫龙蛇和奇异天地构成鲜艳深沉的想象世界；所引诗句又写佩饰芳香、坚持修养和至死不改，显示主人公对理想人格的执着。
- 苍梧、悬圃、羲和等神话意象把主人公置于飞驰的宇宙旅程，“路漫漫其修远兮，吾将上下而求索”集中表现其永不停息的真理追求。
- 《离骚》把原始神话的多义浪漫想象，与理性觉醒后执着、忧愤而独立的个体人格熔为一体。它由此成为中国抒情诗光辉的起点和难以比肩的典范。
- 《天问》以连续发问把远古神话同历史意识连接起来，表现理性觉醒时代由神话向历史的过渡；相关诘问是这一过渡的直接诗歌证据。《九歌》等楚辞作品本为祭神歌舞的延续，具有源于远古、可配管弦、情感淋漓想象自由等特征，并成为汉赋的源头。
- 汉代虽在制度上承秦制，在文艺和意识形态上却延续南楚乡土本色，刘邦、项羽及宫廷楚声均可为证。楚汉浪漫主义由此成为与先秦理性精神相辅相成、主宰两汉艺术的又一伟大传统。
- 与《诗经》和北方先秦散文相比，汉代艺术充满伏羲女娲、西王母、仙人和奇禽怪兽等神话符号；马王堆帛画、卜千秋墓壁画与《远游》《招魂》的意象相通。天上、人间、地下混融为人神杂处的怪诞世界，说明汉代艺术直接承继了南方神话巫术传统。
- “十日代出，流金铄石”以十日并出的灼热灾异渲染东方不可停留的险境，是《招魂》构造恐怖神话空间的一环。
- 蛇、巨狐和九首雄虺等怪兽构成南方吞噬魂魄的威胁，这段招魂辞以密集异兽强化南方世界的野性恐怖。
- 流沙、雷渊写西方险阻，峨峨增冰和千里飞雪写北方酷寒；两组诗句依方位铺陈魂无处可托，推动“归来”的反复呼告。
- 天界九重关门有虎豹守卫，九首巨人和豺狼也会伤人；这段诗句破除上天即乐土的想象，继续为召魂归返现世服务。
- 幽都由九曲角的土伯把守，这一短句把地下世界也设为不可进入的恐怖禁区，使天地四方皆险的结构趋于完整。
- 土伯血污的手指、虎首牛身的怪状补足幽都守卫的可怖形象，以具体肉身细节强化地下世界吞噬人的威胁。
- 《招魂》着意表现恶兽伤人的否定世界，墓葬帛画和壁画则更多表现登仙祈福的肯定世界。二者虽取向不同，都以幻想、巫术、神秘符号保存并延续远古传统的原始活力和野性。
- 汉武帝以后儒学与历史经验逐渐进入文艺，使南方神话、北方历史、儒家节操、道家奇谈和谶纬迷信交织共存。各种生命、鬼神、人物与图腾并列，仍形成想象丰富、情感粗豪的浪漫世界。
- 东汉画像石第一组分层并列伏羲女娲等诸神、尧舜禹桀等历史人物、孝子与刺客故事以及现实车马。这样的层次安排直接显示神话、历史、伦理与现实共同进入艺术画面。
- 另一画像的四层依次刻诸神乘翼龙、风雨雷电诸神、人与怪兽搏斗、众人捕猎野兽。分层描写展示自然神力、人兽斗争和现实行动在同一视觉体系中的连续展开。
- 与马王堆帛画相比，东汉画像中的神话色彩减退，人世、历史和现实的比重上升，反映文明发展和理性渗入。不过远古浪漫幻想仍是汉代艺术的灵魂，并进一步表现为运动、气势和古拙的形式风格。

### 琳琅满目的世界

- 汉代艺术虽负有儒家教化功用，却未受狭隘功利信条束缚，而让神话与历史、神人与禽兽共同构成丰满多彩的世界。这个对象化世界表现了人的力量，其真正主题是人对客观世界的征服。
- 汉代神仙世界不同于六朝佛教的苦难迷狂，它以长生、登仙表达对现实人生永恒延续的愉快渴望。仙境不是与现实对立的彼岸，因此原始神话、历史人物与现实生活可以自然混居。
- 汉代神仙形象也不同于远古图腾和青铜饕餮，不再以现实威权震慑人，而成为人的主观愿望和艺术幻想。其基调乐观开朗，是人要分享神的快乐、把神化为自身延伸，体现的不是神征服人而是人征服神。
- 与神仙幻想并列的，是对历史和现实生活的充分肯定；汉画像石既宣扬孝义圣贤，也偏爱刺杀、宴会等富于激情和戏剧性的故事。儒家教义虽进入画廊，仍遮不住深厚充沛的浪漫激情。
- 与历史故事的时间回顾相映，山东、河南、四川画像石和画像砖把宴乐、百戏、出行、狩猎、战争等世俗生活铺展为空间图景。关于多种战法和兵器的记载，证明汉代艺术广泛收纳现实制度与行动。
- 画像下两层刻车骑与庖厨，上层刻琴瑟、吹奏、舞蹈和杂技；这段简短分层说明贵族出行、饮食与娱乐被并置为完整生活图景。
- 冶铁图按熔炼、锤凿的流程表现工人集体劳动，既记录汉代生产技术，也让被遮蔽的奴隶劳动进入艺术世界。
- 垦荒图写丛林野兽之间农夫引牛、扶犁、执鞭劳作，以具体分工表现农业生产的辛苦和人开拓自然的行动。
- 河南画像罗列投壶、侏儒舞、剑舞、角抵和乐舞等节目，证明汉代艺术对世俗竞技、娱乐和表演形态兴趣广泛。
- 四川画像砖上图把射猎水鸟、游鱼、莲花和枯树组织成统一景观，下图接续农事；山东嘉祥画像石则开始以多层结构并列神话和现实。两例共同展示汉画像包容自然、狩猎与生产的能力。
- 嘉祥第一石第一层以东王公为中心，配列有翼羽人和日中之鸟，并与另一石的西王母、蟾蜍、玉兔形成对应。这一层承担天界神仙体系的视觉表达。
- 第二层由左右两组乐舞人物构成，一组抚琴，一组踏鼓起舞；它把现实宴乐置于神仙图像之下，表现人间生活的欢乐。
- 第三层细刻灶、烟囱、炊具、肉食、汲水与宰杀等庖厨供膳活动，多人分工操作使日常劳动过程清晰可见。这一层说明最普通的饮食生产也成为严肃的艺术题材。
- 第四层仅刻两名骑者和一辆载人曲辕车，以简洁车骑场面收束第一石的分层叙事，并补入出行生活。
- 第四石纵横尺寸相近，画面分为三层；这一独立说明交代作品的物理规格和结构，为随后逐层解读建立框架。
- 第四石上层以端坐昆仑神座的西王母为中心，羽人、玉兔、蟾蜍和鸡首羽人围绕其侧。长生灵药、玉泉等符号共同营造具体而热闹的仙界。
- 中层描绘王者在殿中受群臣朝谒，人物沿斜梯携物而上，并有儿童相随。它把现实政治秩序和宫廷礼仪嵌入神话图像之下。
- 下层刻单马车、立乘者、持戟吹管者和前导骑吏，以行进队列表现现实出行和仪仗活动。
- 第五石纵横尺寸与前石相近，但画面分为四层；这段规格说明再次提示同组画像以多层构图容纳不同世界。
- 第五石第一层近似东王公仙界图，却增加三珠树和疑似扁鹊针灸的场面。神仙符号与现实医疗行为并置，体现汉画像神话和生活混融的特点。
- 第二层描绘孔子向老子问礼，项橐居中，颜回、子路等随侍其后。该层把著名思想史故事视觉化，使历史教化题材进入多层画像。
- 第三层仍为庖厨汲水，却以滑轮代替桔槔，与其他石刻的井台装置不同。这一细节既补足日常供膳场景，也保存了具体生产工具的差异。
- 第四层写车驾停驻、骑者抱锦囊、冠者持板和女子坐地，形成一个带有情节悬念的现实人物场景。它以行动关系补充画像对出行生活的观察。
- 这些画像从仙界、贵族享乐直至下层劳动，把天上地下、历史现实、生产娱乐和各种动物全部纳入描绘。马驰鸟飞、人神杂陈的密集对象构成充满旺盛生命力的“琳琅满目的世界”。
- 如荷兰小画派以日常细节肯定征服海洋后的现实生活，汉代艺术认真刻画谷仓、火灶、猪圈等寻常事物，也表现对世间生活的热爱和延续愿望。更宏大的帝国背景使其神话、历史和现实图景共同歌颂人对物质世界与自然的征服。
- 《鲁灵光殿赋》所写奔虎、虬龙、朱鸟、神仙以及帝王忠孝人物，证明当时建筑、雕塑和壁画原本五彩斑斓。引文以密集列举重现汉代艺术把天地万物、神话历史和伦理人物尽数收入画面的盛况。
- 这段反问承接《鲁灵光殿赋》，确认其所描绘的正是神话、历史、现实三者混合的五彩浪漫世界，并收束前述图像证据。
- 汉赋由楚辞发展而来，却脱离歌舞成为“不歌而诵”的纯文学；其铺陈山水、城市、宫殿、人物和百业的写法，与汉代视觉艺术“包罗宇宙”的时代精神一致。所引赋句以金城、街市和货物流通开篇，为这种全面夸饰提供实例。
- 班固赋文进一步铺陈都城人口、娱乐、农田、水利、交通、宫苑与异域珍禽，显示统一帝国的富庶和广阔。该长篇列举在论证中具体展示汉赋以无数物质对象构造盛世图景的方法。
- 文学不受画面限制，汉赋因而能把山川、城市、物产、宫殿、服饰、狩猎和歌舞作最大范围的堆叠夸扬。其粗重拙笨正来自一个自信繁荣的民族把精神溶入外部世界、全面肯定征服成果的需求，这也是评价汉赋与汉代造型艺术的关键。
- 汉代漆器、铜镜、织锦等工艺品把同一时代精神凝缩于精巧器物，其空前水平来自战国至西汉成熟至顶峰的世袭工匠集体手工业。纱衣、金缕玉衣、汉镜和漆器既是巨大奴隶劳动的成果，也是人征服物质世界的具体见证。

### 气势与古拙

- 人对世界的征服落实到具体形象、图景和意境，便表现为力量、运动和速度；三者共同构成汉代艺术“气势与古拙”的基本风貌。
- 汉代画像砖、陶俑和墓壁画不重细节、个性或内心抒情，而以夸张姿态、巨大动作和简洁轮廓表现飞扬流动的力量。无论马踏飞燕、荆轲刺秦还是静态人物，速度和内在运动都使行为事迹成为主体价值的证明，并形成不可阻挡的气势。
- 汉代艺术以行动而非细微面容表现世界征服，因此比例失常、棱角突出等“古拙”恰好强化了运动和力量。过度弯腰、长袖与直线直角都服从动作夸张的需要，使气势与古拙浑然一体。
- 与唐宋画像、陶俑和雕刻相比，汉代作品虽幼稚粗糙，却更富运动速度、雄浑力量和旺盛生命。唐宋艺术的威武、艳丽或工整均难以达到汉代整体气势的高度。
- 汉代构图满幅铺陈、不留空白，虽显笨拙，却形成后世空灵精致艺术无法替代的丰满、朴实和开放意境。它以古拙轮廓释放整体民族的运动力量，区别于后世个人写意，并集中呈现由楚文化而来的本土浪漫主义。
