# 第05章 魏晋风度

## 本章位置

作者采「魏晋封建说」：这是继先秦之后第二次社会形态变异。庄园经济与门阀士族登场；两汉经学崩溃。本章把「魏晋风度」扩至晋宋，以人的觉醒、文的自觉、阮籍与陶潜为三节。

> 汉代的外在事功与古拙气势：[第04章_楚汉浪漫主义.md](第04章_楚汉浪漫主义.md)

## 核心论点

1. 魏晋不是腐朽反动的玄学时代，而是哲学重新解放、思辨深度空前的时期。
2. 新思潮的基本特征是**人的觉醒**：对生命、意义、命运的重新发现。表面的人生无常、及时行乐，深藏对生活的强烈欲求。
3. **文的自觉**（鲁迅评曹丕时代「为艺术而艺术」）：相对两汉功利文艺，确认诗文自身价值。
4. 阮籍把政治迫害的哀伤写得深沉美丽；陶潜把人的觉醒提到田园中的深刻人生境界。二人是魏晋风度最高代表，而非建安七子或颜谢。

---

## 一、人的主题

### 论证推理链

**论据**

- 经济：城市商品相对萎缩，庄园巩固；农奴化与人身依附。九品中正、士庶天隔（《宋书·恩幸传序》等）。
- 思想：王充《论衡》再发现；仲长统、王符、曹操诸葛亮法家观念、刘劭《人物志》、佛经翻译；名法道重新被探究。
- 《古诗十九首》及苏李诗（作者认为应在东汉末或更晚）：「生年不满百」「人生忽如寄」等与离别、相思揉杂。钟嵘「一字千金」。
- 曹氏父子、阮籍、陆机、刘琨、王羲之《兰亭序》「固知一死生为虚诞」、陶潜，同一哀伤音调。
- 建安风骨：人生哀伤与「烈士暮年，壮心不已」「慷慨多气」交融。
- 嵇康「非汤武而薄周孔」被杀；阮籍差点被何曾以败俗劝杀。墓砖出现竹林七贤，挤进神仙忠臣行列。
- 《世说新语》：王右军「飘如游云」，嵇康「岩岩若孤松」。品评重心从节操转为才情风神。
- 哲学：王弼「以无为本」；圣人茂于神明、同于人情（何劭《王弼传》）。
- 绘画：谢赫六法，「气韵生动」居首；陆探微「穷理尽性，事绝言象」；顾恺之「传神写照正在阿堵」。
- 「言不尽意」：通过有限言象把握无限本体，与「以形写神」同构。

**推导**

对外在权威（经术、谶纬、鬼神、道德节操）的怀疑，才有内在人格觉醒。生命短促本是普遍命题，魏晋之所以千古传诵，因含具体时代内容：战乱疫疠，徐陈应刘一时俱逝，曹丕曹植只活四十岁。传统功业学问不可靠，个人存在的意义突出。

门阀有庄园与世袭特权，心思由环境转向内心、由经学转向艺术。药、酒、姿容、谈玄、山水，衬托所谓魏晋风度。两汉五彩世界（动的行为）让位于魏晋五彩人格（静的玄想）。

**结论**

「气韵生动」「以形写神」「言不尽意」是人的主题的具体审美表现，影响久远。

## 二、文的自觉

### 论证推理链

**论据**

- 曹丕：年寿荣乐有尽，「未若文章之无穷」（《典论·论文》）。华丽好看与「不朽」追求相联。
- 两汉：司马相如、东方朔「优畜之」；文学与经术未分家；《盐铁论》「文学」指儒生。范晔始立文苑传，仍不及儒林有名。
- 陆机《文赋》：诗缘情而绮靡；创作心理「精骛八极，心游万仞」——作者称为中国美学史上头一回专门描述。
- 钟嵘区分经国文符与吟咏情性；《文心雕龙》把「文」提到「道之文」「天地之心」。
- 玄言诗到山水诗：郭璞、谢灵运当时声名高而作者认为并不成功——自然与生活心境未溶一体（那要到宋元），只积累了格律、语汇、音韵。
- 五言取代四言：钟嵘「五言居文词之要，是众作之有滋味者」。沈约四声八病、对仗，发掘汉字形式美。
- 曹植被比「人伦之有周孔」，因起调、炼字、对句、音调、结语的有意识做诗，划开与难以句摘的汉魏古诗的界线。王夫之倒更称《燕歌行》「古今无两」，但当时审美重曹植「词采华茂」。

**推导**

书法同样自觉：汉隶变真行草楷，由无名行当变为名士专业。陆机《平复帖》、二王诸帖，线的风神即魏晋风度。谢赫把「骨法用笔」（线）置于象形、赋彩、位置、模写之上。康德也说线条比色彩更具审美性质；中国线的艺术与抒情诗同为文化—心理结构的表现。

**结论**

文的自觉是美学概念，不单指文学。药、酒、姿容、神韵，必须加上华丽词章，才构成魏晋风度。

## 三、阮籍与陶潜

### 论证推理链

**论据**

- 艺术与政治不平衡：潇洒风度产生于动荡血污。何晏、嵇康、二陆、张华、潘岳、郭璞、刘琨、谢灵运、范晔、裴頠等第一流人物被杀。「广陵散于今绝矣」。
- 阮籍《咏怀》：一身不自保、终身履薄冰；欲冲天又「宁与燕雀翔」；大醉六十日拒联姻；口不臧否。鲁迅谓《思旧赋》刚开头就煞尾，同一政治高压。
- 陶潜：鲁迅指出《述酒》说当时政治，不能超于尘世、不能忘掉死。苏轼塑造的超脱形象并非实际陶潜。他是政治退避者：密网鱼骇，逃禄归耕。
- 陶仍执着生死：「人生似幻化」；疑夷齐颜回之报；信天师道（陈寅恪说）而实际取无神论/怀疑论，与阮籍「神仙志不符」相通。老庄并不能真正解答人生之谜，直到齐梁佛教鼎盛才似乎「解决」。
- 陶诗中自然成为生活一部分，不是谢灵运式的错彩镂金死物。《归园田居》等平淡有生意。

**结论**

两种境界：陶——超然事外（作者特别说明不是「超然世外」，那种超世要到苏轼），平淡冲和；阮——忧愤无端，慷慨任气。只有从政治迫害与忧生之嗟理解，魏晋风度才有真正深度。

> 苏轼的「对社会的退避」见：[第08章_韵外之致.md](第08章_韵外之致.md)

除了本章主要内容外，作者还讨论了/提及了：1. 黄巾主体为农民起义，2. 崔寔《四民月令》、颜之推《家训》、王戎钻李、谢灵运伐山开路所反映的庄园经营，3. 何晏因政治失败被歪曲，4. 吕凤子论愉快/不愉快感情与线条流利或艰涩，5. 王瑶《中古文人生活》。

## 段落总结序列

### 人的主题

- 魏晋是继先秦之后又一社会形态剧变期：城市与商品经济衰退，庄园自然经济扩张，依附性农民增多，门阀士族由此登上历史舞台。
- 社会变迁促使两汉经学及谶纬迷信崩溃，门阀士族的新世界观和人生观随之兴起。
- 作者反对把魏晋玄学一概视为腐朽反动，认为这是哲学重新解放、理论思维空前深化的活跃时期，王弼正是其杰出代表。
- 这一解放历程始于东汉末年：王充《论衡》重新流行，现实政论、法家观念、《人物志》与佛经翻译共同形成不同于两汉的新思潮。
- 注释指出，魏晋门阀士族仍积极经营庄园、发展生产，玄学和文艺也尚未堕入齐梁时期的没落与陈腐。
- 门阀至齐梁、周隋才完全没落；此前思想环境较为自由，名、法、道诸家复兴，并产生了思辨的“纯”哲学和抒情的“纯”文艺，构成思想史上的飞跃。
- 作者由此追问：东汉末至魏晋的新世界观、人生观及其文艺美学表现，究竟具有怎样的基本特征？
- 其核心就是“人的觉醒”：人逐渐摆脱两汉神学目的论与谶纬宿命论的控制，而文艺和审美心理最敏感、直接地呈现了这一曲折进程。
- 《古诗十九首》及苏李诗以日常人生为题直抒胸臆，集中咏叹生命短促、人生无常，开创了一代诗风。
- 《古诗十九首》中“生年不满百”等诗句反复感叹人生如寄、寿命难固与死亡不可逃，形成沉重而悲远的时代音调。
- 曹操、曹丕、曹植、阮籍、陆机、刘琨、王羲之、陶潜等人的诗文都咏叹生命短暂与时光易逝，说明人生无常已成为当时世界观和社会心理的核心。
- 人生无常的悲叹表面消极，实则源于对旧权威的怀疑和对个体生命的强烈执着；乱世死亡的现实使人重新发现自身存在的意义，并以建功、亲近自然或政治忧愤等不同方式赋予“人的觉醒”以积极的美学深度。
- 人的觉醒伴随着对旧礼法、旧信仰与旧价值的反抗；尽管嵇康、阮籍等遭受迫害，重才性、尚个体人格的新风气仍战胜虚伪礼教，使人的内在才情、品格和精神状态成为崇敬中心。
- 这里的“人”具体指门阀士族；九品中正制使人物品评成为社会中心，才情、气质、格调与风貌取代外在节操，形成《世说新语》所体现的脱俗人格理想。
- 《世说新语》以孤松、玉山等自然意象描写嵇康的挺拔与醉态，借漂亮的外在风貌表现高超的内在人格，体现门阀士族的审美趣味。
- 庄园经济、世袭地位与政治特权使士族由外界转向内心和自然；嵇康“目送归鸿，手挥五弦”等诗句写出游心玄远、超然自得的境界，药、酒、玄谈与山水共同构成魏晋风度。
- 魏晋玄学由外在自然转向内在本体，以“无”为无限可能性的根源；这种重精神本体、轻外在功业的哲学，与艺术中崇尚人格风神相呼应，推动抒情诗和人物画成熟。
- “气韵生动”与“以形写神”要求艺术透过形貌尤其眼神表现人物的内在精神，而非铺陈外部事件，因而与玄学和人物品评共同体现魏晋风度。
- “言不尽意”主张借有限言象领悟不可穷尽的玄理和神情，与“气韵生动”“以形写神”同属人的觉醒在审美上的表现，并成为影响深远的中国艺术原则。

### 文的自觉

- 鲁迅称曹丕时代为“文学的自觉时代”；相对于两汉文艺的教化功利，“人的主题”提供新内容，“文的自觉”提供新形式，二者结合成为魏晋艺术准则。
- 曹丕认为寿命与荣乐有限而文章可以不朽，因此提倡华美文章；文章的长久流传实质上是个体精神的不朽，也是“人的主题”的具体体现。
- 两汉文学只是宫廷、经术与政治的附庸，文人也多凭大臣、史官等身份立世；文学和其他艺术取得独立价值，是魏晋“文的自觉”与“人的主题”的共同产物。
- 门阀贵族获得相对独立的社会地位后，更看重由文学保存个人思想、情感、精神和品格，因而确认诗文自身的价值，不再仅把它当作政治工具。
- 曹丕的新观念迅速扩展为对文辞、文体、文思、批评和文集的系统研究；陆机《文赋》的诗句描绘感物兴思与心游万仞的创作心理，表现出高度自觉的文学意识。
- 对创作心理的专门探究由曹丕、陆机延续至南朝；钟嵘区分吟咏情性之诗与经世儒学，刘勰《文心雕龙》则系统研究创作规律，并把文章提升到天地之“道”的高度。
- 玄言诗和山水诗试图以形象谈玄、写景，却因自然只是贵族观赏和思辨的对象而缺乏真情与生命；不过这些作品仍为后世积累了格律、语汇、修辞和音韵财富。
- 五言诗在建安至六朝间成熟，较四言容量更大，又把汉代杂言规范为标准诗体；四声八病说和对仗等探索，则充分发掘了汉语音义的形式美。
- 曹植有意识地炼字、造句、对仗与调声，因而被钟嵘推为诗艺典范；曹丕《燕歌行》虽成就极高，却因近于自然流出的民歌而在崇尚华饰的时代评价较低，反映了“文的自觉”对华丽形式的极端追求。
- “文的自觉”并不限于文学；谢赫以“骨法用笔”突出线条自身的审美价值，显示魏晋绘画开始自觉总结创作规律，也彰显中国诗与线描艺术的民族特色。
- 魏晋书法使线条艺术高度纯化，真、行、草、楷及笔意章法日趋丰富；陆机、二王等人的作品以优美线条表现飘逸超群的精神风貌，成为魏晋风度的集中显现。

### 阮籍与陶潜

- 艺术与社会现实并不平衡：潇洒超逸的魏晋风度产生于动荡、灾难与血污之中，其表面风流之下潜藏着深重的苦恼、恐惧和忧患。
- 魏晋南北朝政权更替频繁，众多一流名士死于政治清洗；他们外表轻世洒脱，内心却因忧生惧祸而更执着人生，这种矛盾构成魏晋风度深刻的一面。
- 阮籍《咏怀诗》以隐晦方式写残酷政治中的人生哀伤；繁华殿堂终生荆棘、驱马远去的诗意，表现盛衰无常与避祸之心。
- 阮籍“一身不自保，何况恋妻子”等诗句写严霜岁暮中的生命危机，表达乱世中自身难保的悲凉。
- 阮籍“胸中怀汤火”等诗句写内心如受煎熬、世事变化无穷，表现谋虑再多也无法摆脱祸患的焦灼。
- 阮籍“终身履薄冰，谁知我心焦”等诗句直陈随时可能丧命的恐惧，写出谨慎自保而无人理解的痛苦。
- 阮籍既渴望高飞脱俗、延年自保，又不得不向现实低头；他的沉醉、慎言与拒婚皆源于欲言不能的政治矛盾，其诗把迫害之痛写得深沉美丽，赋予魏晋风度真正的积极意义和美学力量。
- 陶潜并非不问世事，而是像阮籍一样主动回避政治；他的诗文既揭示功名与网罗之险，又持续追问生死和报应，体现魏晋怀疑主义无法解决人生之谜的共同困境。
- 陶潜真正实行归耕，以不委屈人格取代功名荣华，并在劳动、饮酒、读书、作诗与自然中获得安顿；他笔下平畴、春雨和桑麻融入真实生活，把“人的觉醒”提升为更深沉的人生态度。
- 陶潜《归园田居》“种豆南山下”等诗句写早出晚归的田间劳作，虽衣沾夕露仍坚持心愿，表现守志归耕的坚定。
- 陶潜“暧暧远人村”等诗句描绘村落炊烟、深巷犬吠与桑巅鸡鸣，营造宁静质朴而富有生活气息的田园。
- 陶潜“户庭无尘杂”等诗句写摆脱仕途樊笼、重返自然后的清静与闲适。
- 陶潜的自然描写看似平凡客观，却以高度自觉、独立真实的人格为根基，成就了平凡而难以企及的美。
- 阮籍与陶潜分别创造忧愤慷慨和超然平淡两种艺术境界；二人以最深刻的方式表现魏晋风度，因而成为这一时代最优秀的人格代表。
