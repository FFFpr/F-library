# 第05章 魏晋风度

## 本章位置

作者采「魏晋封建说」：这是继先秦之后第二次社会形态变异。庄园经济与门阀士族登场；两汉经学崩溃。本章把「魏晋风度」扩至晋宋，以人的觉醒、文的自觉、阮籍与陶潜为三节。

> 汉代的外在事功与古拙气势：[第04章_楚汉浪漫主义.md](第04章_楚汉浪漫主义.md)

## 核心论点

1. 魏晋不是腐朽反动的玄学时代，而是哲学重新解放、思辨深度空前的时期。
2. 新思潮的基本特征是**人的觉醒**：对生命、意义、命运的重新发现。表面的人生无常、及时行乐，深藏对生活的强烈欲求。
3. **文的自觉**（鲁迅评曹丕时代「为艺术而艺术」）：相对两汉功利文艺，确认诗文自身价值。
4. 阮籍把政治迫害的哀伤写得深沉美丽；陶潜把人的觉醒提到田园中的深刻人生境界。二人是魏晋风度最高代表，而非建安七子或颜谢。

---

## 一、人的主题

### 论证推理链

**论据**

- 经济：城市商品相对萎缩，庄园巩固；农奴化与人身依附。九品中正、士庶天隔（《宋书·恩幸传序》等）。
- 思想：王充《论衡》再发现；仲长统、王符、曹操诸葛亮法家观念、刘劭《人物志》、佛经翻译；名法道重新被探究。
- 《古诗十九首》及苏李诗（作者认为应在东汉末或更晚）：「生年不满百」「人生忽如寄」等与离别、相思揉杂。钟嵘「一字千金」。
- 曹氏父子、阮籍、陆机、刘琨、王羲之《兰亭序》「固知一死生为虚诞」、陶潜，同一哀伤音调。
- 建安风骨：人生哀伤与「烈士暮年，壮心不已」「慷慨多气」交融。
- 嵇康「非汤武而薄周孔」被杀；阮籍差点被何曾以败俗劝杀。墓砖出现竹林七贤，挤进神仙忠臣行列。
- 《世说新语》：王右军「飘如游云」，嵇康「岩岩若孤松」。品评重心从节操转为才情风神。
- 哲学：王弼「以无为本」；圣人茂于神明、同于人情（何劭《王弼传》）。
- 绘画：谢赫六法，「气韵生动」居首；陆探微「穷理尽性，事绝言象」；顾恺之「传神写照正在阿堵」。
- 「言不尽意」：通过有限言象把握无限本体，与「以形写神」同构。

**推导**

对外在权威（经术、谶纬、鬼神、道德节操）的怀疑，才有内在人格觉醒。生命短促本是普遍命题，魏晋之所以千古传诵，因含具体时代内容：战乱疫疠，徐陈应刘一时俱逝，曹丕曹植只活四十岁。传统功业学问不可靠，个人存在的意义突出。

门阀有庄园与世袭特权，心思由环境转向内心、由经学转向艺术。药、酒、姿容、谈玄、山水，衬托所谓魏晋风度。两汉五彩世界（动的行为）让位于魏晋五彩人格（静的玄想）。

**结论**

「气韵生动」「以形写神」「言不尽意」是人的主题的具体审美表现，影响久远。

## 二、文的自觉

### 论证推理链

**论据**

- 曹丕：年寿荣乐有尽，「未若文章之无穷」（《典论·论文》）。华丽好看与「不朽」追求相联。
- 两汉：司马相如、东方朔「优畜之」；文学与经术未分家；《盐铁论》「文学」指儒生。范晔始立文苑传，仍不及儒林有名。
- 陆机《文赋》：诗缘情而绮靡；创作心理「精骛八极，心游万仞」——作者称为中国美学史上头一回专门描述。
- 钟嵘区分经国文符与吟咏情性；《文心雕龙》把「文」提到「道之文」「天地之心」。
- 玄言诗到山水诗：郭璞、谢灵运当时声名高而作者认为并不成功——自然与生活心境未溶一体（那要到宋元），只积累了格律、语汇、音韵。
- 五言取代四言：钟嵘「五言居文词之要，是众作之有滋味者」。沈约四声八病、对仗，发掘汉字形式美。
- 曹植被比「人伦之有周孔」，因起调、炼字、对句、音调、结语的有意识做诗，划开与难以句摘的汉魏古诗的界线。王夫之倒更称《燕歌行》「古今无两」，但当时审美重曹植「词采华茂」。

**推导**

书法同样自觉：汉隶变真行草楷，由无名行当变为名士专业。陆机《平复帖》、二王诸帖，线的风神即魏晋风度。谢赫把「骨法用笔」（线）置于象形、赋彩、位置、模写之上。康德也说线条比色彩更具审美性质；中国线的艺术与抒情诗同为文化—心理结构的表现。

**结论**

文的自觉是美学概念，不单指文学。药、酒、姿容、神韵，必须加上华丽词章，才构成魏晋风度。

## 三、阮籍与陶潜

### 论证推理链

**论据**

- 艺术与政治不平衡：潇洒风度产生于动荡血污。何晏、嵇康、二陆、张华、潘岳、郭璞、刘琨、谢灵运、范晔、裴頠等第一流人物被杀。「广陵散于今绝矣」。
- 阮籍《咏怀》：一身不自保、终身履薄冰；欲冲天又「宁与燕雀翔」；大醉六十日拒联姻；口不臧否。鲁迅谓《思旧赋》刚开头就煞尾，同一政治高压。
- 陶潜：鲁迅指出《述酒》说当时政治，不能超于尘世、不能忘掉死。苏轼塑造的超脱形象并非实际陶潜。他是政治退避者：密网鱼骇，逃禄归耕。
- 陶仍执着生死：「人生似幻化」；疑夷齐颜回之报；信天师道（陈寅恪说）而实际取无神论/怀疑论，与阮籍「神仙志不符」相通。老庄并不能真正解答人生之谜，直到齐梁佛教鼎盛才似乎「解决」。
- 陶诗中自然成为生活一部分，不是谢灵运式的错彩镂金死物。《归园田居》等平淡有生意。

**结论**

两种境界：陶——超然事外（作者特别说明不是「超然世外」，那种超世要到苏轼），平淡冲和；阮——忧愤无端，慷慨任气。只有从政治迫害与忧生之嗟理解，魏晋风度才有真正深度。
