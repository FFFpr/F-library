# 第09章 宋元山水意境（段落总结序列）

据原书四个小节分别作序列。条数等于该节物理段数。OCR 明显误识已改正（关仝、吴道子、元稹、韩滉、女史箴、坐穷泉壑、夏圭、赵孟頫、朱耷、青卞、笪重光等）。

## 缘起

主旨：绘画高峰在宋元，且主要指山水，可与青铜礼器并称；山水画真正独立约在中唐前后，成熟高峰在宋，因为比人物牛马更间接于人事；它是世俗地主的艺术：隐逸从政治退避变为社会性退避，人与自然的牧歌式宁静是基本音调，禅宗与老庄构成思想条件。

与章首常用的四点总论（独立时间、世俗地主、三里程、无我非无情感）不完全重合：本标题只交代高峰位置、独立过程、阶级与思想条件，三里程从「无我之境」起陈述。

1. 【第一档·陈述】雕塑高峰在六朝与唐，绘画高峰在宋元，这里主要指山水。山水成就超过许多部类，与相隔数千年的青铜礼器交相辉映，同为世界艺术史上罕见的美的珍宝。

2. 【第一档·限定】六朝已有宗炳《画山水序》一类谈论，但顾恺之摹本山树与敦煌背景仍是「人大于山，水不容泛」，山水还只是人事环境的背景符号，谈不上独立审美意义的风景画。
   (本段限定第1段：宋元高峰之前，六朝所谓山水尚未独立)

3. 【第二档·可替换例证】隋唐进展不大；《展子虔游春图》作者从文献与鉴定看大概是伪品、非隋作。重要变化在盛唐：「山水之变，始于吴，成于二李」；吴道子重线条（有笔无墨），这一倾向扩到山水，影响后世。
   (本段是第4段的可替换例证：盛唐吴道子、二李是独立前的关键一变)

4. 【第一档·陈述】山水画真正独立似在中唐前后：宗教意识衰淡，人世景物获有现实性格。人物、牛马因与人事更直接，先从宗教艺术分化出来；山水花鸟作为主要题材的成熟更晚，高峰应属宋代。郭若虚「佛道人物仕女牛马近不及古；山水林石花鸟古不及近」；邵博「本朝画山水之学，为古今第一」。

5. 【第一档·必要依据】审美由人事、仕女牛马转到山水花鸟，是后期封建社会里世俗地主心理的曲折反映。门阀隐逸基本上是政治性退避，宋元隐逸是社会性退避，故广而深；由野而朝、由村而城的士大夫需要丘园作为荣华的心理补充。郭熙《林泉高致》「不下堂筵，坐穷泉壑」说的正是这个本意。城市发达的宋代反而成熟山水，正如欧洲风景画成熟于资本主义阶段。画面中的渔樵不是劳动颂歌，是掩盖痛苦的农村理想画：「非无舟人，止无行人」。
   (本段是第4段的必要依据：说明高峰何以在宋、何以是世俗地主的艺术)

6. 【第一档·必要依据】禅宗从中晚唐到北宋愈益流行，其准泛神论与老庄亲近自然的态度相近：从自然求了悟，以丘园泉石长久于院落笙歌。以禅喻诗当时已风行，以禅说画不必等到董其昌「画禅室」。
   (本段是第4段的必要依据：山水成熟的思想条件)

## 无我之境

主旨：宋元山水经历北宋、南宋、元三个里程；第一种是北宋全景式的无我之境——情感不直接外露，通过较客观的自然整体传达宽泛多义的生活理想；董源写江南平远、范宽写关陕雄杰，差异来自地域真景，同属这一境。

- 陈述：直接说出本标题某条主旨，给该条一个定义；没有这段则该条主旨缺命题，是必需的
- 必要依据：给出主旨所依赖的机制或定义；删掉则主旨不能成立，是不可取缔的、必需的。与可替换例证互替：先出现的机制用本标签
- 可替换例证：用作品、引文、场景旁证主旨；同标题还有同类例子，这段是可替换的。与必要依据互替：机制已有之后的作品、引文、场景用本标签

1. 【第一档·陈述】延续千年的中国山水画不是一成不变的。宋元便经历北宋（主要是前期）、南宋、元三个里程，呈现出三种不同面貌和意境。

2. 【第二档·可替换例证】当时文献以李成、关仝、范宽三家为北宋主要代表：李成烟林清旷、关仝石体坚凝、范宽峰峦浑厚。今人概括为关仝峭拔、李成旷远、范宽雄杰。
   (本段是第8段的可替换例证：三家是第一种意境的风格标本)

3. 【第一档·必要依据】三种风格主要来自对自己熟悉地区的真实描写：齐鲁之士惟摹营丘，关陕之士惟摹范宽。李成特点在齐鲁烟云平远；范宽「山从人面起」，来自终南太华间的艰苦写生。
   (本段是第8段的必要依据：董源、范宽之异是地域真景，不是南北宗)

4. 【第一档·必要依据】关、范、李都学荆浩；荆浩以刻苦熟悉真景为特征，「凡数万本，方如其真」。他提出山水「六要」，核心是「度物象而取其真」：似得其形遗其气，真者气质俱盛。人物画的「气韵生动」由此转到山水：在形似基础上表达内在风神。
   (本段是第7段的必要依据：无我之境仍要求对自然的真实而概括的把握)

5. 【第一档·必要依据】既要精细观察四时朝暮、地区位置，又要有概括性：「见其大意而不为刻画之迹」，是移入情感的形象想象的真实，不是西画感知幻觉。不取定点透视与光影，要整体境界的情绪感染；可行可望不如可游可居。王维「江流天地外，山色有无中」即这种广阔境界。
   (本段是第6段的必要依据：全景无我如何造成宽泛的审美效果)

6. 【第一档·陈述】这一特色完整表现在北宋（特别是前期）整体描绘自然的山水中，构成宋元第一种意境。画面基本塞满，或山峦重叠，或一望无际；审美感受宽泛丰满而不确定，并不指向某一固定诗意，却使人感到牧歌式的人与自然关系，想象更自由。

7. 【第一档·陈述】这是绘画中高度发展了的「无我之境」。所谓无我，不是没有艺术家的情感思想，而是这种情感不直接外露，甚至创作时并不自觉；通过较客观地描写对象，传达更为宽泛、多义的主题。陶诗「暧暧远人村」「采菊东篱下」是诗中的无我；画因无语词更宽泛。关仝、范宽、董源以及巨然、燕文贵、许道宁等五代北宋作品都如此。

8. 【第一档·陈述】李成真迹早已「无李论」，荆、关尚欠成熟。实际能作为第一种意境主要代表的，是董源与范宽：一写江南平远，以抒情优美胜；一写关陕峻岭，以戏剧性壮美胜。这不是南北宗或青绿水墨之异，而是地域真景的差别，仍同属无我之境。

## 细节忠实和诗意追求

主旨：从北宋前期到南宋，「无我之境」向「有我之境」推移；院体把细节真实和诗意追求推到顶峰，马远、夏圭小品是第二种意境；它仍从属于对自然的真实再现，是过渡，基本仍属无我；贡献在形似中求神似、有限中出无限，北宋雄浑、南宋秀丽。

注意：无人并非「无我」，有人并非「有我」。本书二境与王国维原意也不尽相同。

最小标签集：陈述、必要依据、限定。

- 陈述：直接说出本标题某条主旨，给该条一个定义；没有这段则该条主旨缺命题，是必需的
- 必要依据：给出主旨所依赖的机制或定义；删掉则主旨不能成立，是不可取缔的、必需的。与可替换例证互替：先出现的机制用本标签
- 限定：缩小并定义主旨的适用范围；没有这段则适用范围不清，对该边界是必需的

1. 【第一档·陈述】随着时代变化，诗画趣味也在变。从北宋前期经后期到南宋，「无我之境」逐渐向「有我之境」推移。

2. 【第一档·必要依据】这一推移与占画坛统治地位的院体有关。宫廷画院甚至皇帝本人参与创作，把细节逼真发展到顶峰：「孔雀升高必先举左」、月季四时花蕊不同。工笔花鸟成为这一标准的最好体现，并影响到山水。虽已有苏轼等人的文人墨戏相对抗，统治阶级意识仍主导，细节真实成为画坛重要趋向。
   (本段是第6段的必要依据：第二种意境的细节真实从何而来)

3. 【第一档·必要依据】与细节真实并行、更值得重视的是对诗意的自觉提倡。画院以诗句考试：「嫩绿枝头红一点」「踏花归去马蹄香」；「野水无人渡，孤舟尽日横」魁画舟人卧尾横笛，意谓「非无舟人，止无行人」；「竹锁桥边卖酒家」只在竹外挂酒帘。要求既含蓄又准确地达到诗意。
   (本段是第6段的必要依据：第二种意境的诗意标准从何而来)

4. 【第二档·限定】宋代文化发达，细节真实和诗意符合这个阶级在「太平盛世」中的趣味；但这主要是从书面诗词而不是从现实生活中寻求诗意，虽优雅却纤细。
   (本段限定第3段：诗意追求的社会范围与纤细性)

5. 【第二档·陈述】这种趣味在北宋后期即已形成，到南宋院体到达最高水平和最佳状态，创造出与北宋前期很不相同的另一种意境。

6. 【第一档·陈述】马远、夏圭及大量南宋小品——深堂琴趣、寒江独钓、风雨归舟等——在有限场景的工致描绘里，传达出较确定的诗情。不再是北宋那种整体多义、繁复全景；「马一角」大片空白，空间感突出。题材场景小了，刻画精了，诗意更确定。这是宋元山水的第二种艺术意境。

7. 【第一档·限定】这是不是「有我之境」？是，又不是。相对第一种，主观情感有更多直接表露；相对下一阶段，它在忠实描写和抒情上都还保持比较客观的态度。诗意追求仍从属于对自然景色的真实再现。它处在无我到有我的过渡中，是厚重的院体画而非意气的文人画，基本仍应属「无我之境」。
   (本段限定第1、6段：第二种意境仍是过渡，不可径称作有我)

8. 【第一档·陈述】第二种意境是重要开拓：细节真实与诗意并举，使前者不流于匠气、后者不流于空疏；形似中求神似，有限中出无限；对称走向均衡，计白当黑。地域特色消退，普遍性增大。北宋以雄浑崇高胜，南宋以秀丽优美胜，两美并峙。

## 有我之境

主旨：元文人画是第三种意境即有我之境：文学趣味与笔墨相对独立的美压倒形似，倪瓒为主要代表；明清个性解放是其进一步发展；诗、词、曲约略对应三境，只在限定意义上，不可刻板。

- 陈述：直接说出本标题某条主旨，给该条一个定义；没有这段则该条主旨缺命题，是必需的
- 必要依据：给出主旨所依赖的机制或定义；删掉则主旨不能成立，是不可取缔的、必需的。与可替换例证互替：先出现的机制用本标签

- 可替换例证：用作品、引文、场景旁证主旨；同标题还有同类例子，这段是可替换的。与必要依据互替：机制已有之后的作品、引文、场景用本标签

1. 【第一档·陈述】王世贞总结「五变」：大小李；荆关董巨；李范；刘李马夏；黄公望王蒙。作者将前几变归入第一种（北宋）与第二种（南宋），最后一变是元四家；并认为倪瓒比大痴、黄鹤更能作为元画亦即第三种意境的主要代表。

2. 【第一档·必要依据】元画与宋画最重要的差异来自社会急剧变化带来的审美趣味变异。蒙古入主，江南士人屈辱，一部分人放弃「学优则仕」，寄情文艺。院体随宋亡而衰，领导权落到在野文人。文人画作为一种体现时代精神的潮流，从历史整体和现存作品看，应从元四家算起（虽可追溯苏、米）。
   (本段是第1段的必要依据：第三种意境何以落在元代文人)

3. 【第一档·必要依据】文人画首先是文学趣味异常突出。第二种意境里形与神、境与意尚和谐；元代则主观意兴绝对压倒形似。气韵生动不再放在客观对象上，而完全放在主观意兴上。倪瓒「逸笔草草，不求形似，聊以自娱」「写胸中逸气」；吴镇：墨戏，词翰之余。这是宋画主流所没有的。
   (本段是第8段的必要依据：有我之境的意兴压倒形似)

4. 【第一档·必要依据】与文学趣味并行的是对笔墨的突出强调：线条、墨色可以具有不依存于景物的相对独立的美，把线的艺术推上最高阶段。书法与绘画密切结合。赵孟頫「石如飞白木如籀」「书画本来同」。任何逼真摄影不能替代绘画，正在于笔墨本身的审美意义。画师、书家兼诗人从此成为理想。
   (本段是第8段的必要依据：有我之境如何靠笔墨传达心境)

5. 【第二档·可替换例证】元画大兴画上题字作诗，有时多达百字，有意识成为构图的重要部分；朱红印章在水墨中增加沉着与力量。唐人题款常藏于石隙，宋人一般不使之过分侵占画面。
   (本段是第8段的可替换例证：题跋与印章加重文学趣味)

6. 【第二档·可替换例证】水墨从此压倒青绿。线的飞沉、墨的枯湿、点皴已足以描绘对象、表述心意，不必拘于自然色彩。吴镇引「意足不求颜色似，前身相马九方皋」。
   (本段是第8段的可替换例证：水墨是笔墨意兴的落实)

7. 【第一档·陈述】重点既不在忠实再现，画面不必追求北宋的多样或南宋的精巧；景物可以非常平凡简单，意兴却很浓厚。倪瓒总是几棵小树、一个茅亭、远抹平坡，无人物动态，却传出闲适无奈、淡淡哀愁和地老天荒式的寂寞。自然景物成了「不能不尽」的主观心意的手段。

8. 【第一档·陈述】这当然是标准的「有我之境」。欧阳修已说「萧条淡泊，此难画之意」，王安石「欲寄荒寒无善画」：自然界本身并无所谓萧条淡泊，要通过山水传达这种心境本极困难，这一困难由元画创造性地解决。它与北宋、南宋三分鼎足。

9. 【第二档·限定】元四家中黄公望《富春山居图》、王蒙重迭山岩，比起倪瓒更为辽阔或浓密，但其美学特征同样是追求笔墨、讲究意趣的萧疏淡雅，同样是有我之境。
   (本段限定第7、8段：有我不以疏简构图为唯一形态)

10. 【第二档·可替换例证】有我之境发展到明清，形成浪漫主义洪流。元人形似基本还在，「不较似与不似」乃夸张之词；石涛、朱耷以至扬州八怪进一步抛弃形似，个性空前突出。这种个性元画只有萌芽，宋人基本没有。
    (本段是第8段的可替换例证：有我在明清的去向)

11. 【第一档·必要依据】美学理论与实践行程大体一致。宋：位置经营，「因性之自然，究物之微妙」。元：「法心源」、趣、兴、写意，「不可以形似求之」。董其昌引东坡诗为元画、晁以道诗为宋画；宋画先观气象终求其理，元画先观天真次观笔意。这些区别正是无我与有我的表现。
    (本段是第8段的必要依据：有我在理论上如何被说出)

12. 【第一档·限定】雕塑三类型、诗/词/曲三境界与山水三意境约略相通：诗境厚重宽大，词境精工细巧，曲境酣畅直率。诗多无我，词多有我，曲则突出的有我。这只在极为限定的意义上来说；区分是相对的，不可当作公式刻板以求，有的作品是过渡或综合。理论上的区划是为了帮助而不是束缚观赏。
    (本段限定第1段：三境与诗词曲的对应不可公式化)

13. 【第三档·过渡/场景】三种意境中也各有优秀和拙劣，各人也可随自己的兴趣有所偏爱。
