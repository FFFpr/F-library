# 第01章 龙飞凤舞

## 本章位置

接开篇「从记不清的岁月起头」，讨论文明门槛之前的审美萌芽：工具感受、装饰与巫术、龙凤图腾、原始歌舞，以及彩陶几何纹如何变成「有意味的形式」。青铜纹饰的前奏在章末出现，直接通向下一章。

> 开篇巡礼见：[前言.md](前言.md)

## 核心论点

1. 对工具「合规律性」形体的感受，与「装饰品」上的自觉加工，相隔数十万年，性质不同：前者是物质生产中的**物化**，后者是观念幻想的**物态化**，已属上层建筑胚胎。
2. 审美此时尚未独立，潜藏在巫术礼仪即远古图腾活动中。
3. 「龙」「凤」是东西两大部族联盟的图腾旗帜；「龙飞凤舞」形容的是狂热的巫术礼仪，不是静观。
4. 彩陶几何纹由动物写实逐渐抽象符号化，内容积淀为形式，这才是贝尔所说「有意味的形式」的历史起源。
5. 新石器晚期纹饰由活泼走向神秘恐怖，为殷商青铜作前导。

## 一、远古图腾

### 论证推理链

**论据 / 事实**

- 1970 年代河姆渡、磁山、裴李岗、密县莪沟等遗址，把中国文明曙光推到近八千年前。裴李岗约 7500 年，仰韶早期约 6000 年。
- 旧石器：元谋、蓝田、北京人、山顶洞人。欧洲式洞穴壁画尚待发现，但石器从北京人「无定形」到丁村人尖状、球状、橄榄形，再到山顶洞人均匀规整。
- 山顶洞装饰（引贾兰坡）：钻孔砾石、石珠、兽牙、骨管、海壳等，穿孔多呈红色，似用赤铁矿染穿带。另在尸体旁撒红粉。
- 神话：女娲伏羲「人首蛇身」；《山海经》北、西、南多「人面蛇身/龙身」，东方较少（闻一多《伏羲考》表）。《竹书纪年》伏羲系统有长龙、潜龙、居龙等氏。烛龙/烛阴「人面蛇身而赤」「视为昼、暝为夜」。
- 闻一多：龙以蛇身为主，接受兽脚、马毛、鬣尾、鹿角、狗爪、鱼鳞须。
- 凤：东方集团；帝俊、舜、少昊、后羿、蚩尤、商契；「天命玄鸟，降而生商」；《左传》昭公十七年「鸟名官」。郭沫若：玄鸟即凤凰。
- 人首蛇身陶器器盖（图版）：仍爬行、无角无脚。战国楚画仍有在凤的图像下祈祷。

**推导**

红色对山顶洞人已不只是动物性刺激，而被赋予社会性符号含义：对象上自然形式积淀社会内容，主体上官能愉快积淀观念想象。这与制造工具不同，标志着包含宗教、艺术、审美在内的巫术礼仪开始。

女娲伏羲若剥去后世人间化面纱，观念中是巨大龙蛇；「其神皆人面蛇身」即诸氏族图腾标志。蛇图腾融合他族而成「龙」；鸟图腾神化为「凤」。西（炎黄）胜东（夷）而融合，蛇添翼为龙，凤相对独立保存。

**结论**

龙飞凤舞是史前两面图腾旗帜，从旧石器渔猎经新石器农耕、母系到父系，直到夏商奴隶制门槛。它们「是又不是」原始艺术：仍是巫术符号，但形式里积淀的如醉如狂的社会意识，使感受获得超感觉价值——审美意识的萌芽。

**启示**

看远古「装饰」不要按后世「为美而美」去理解；先问它在礼仪中的符号功能。

### 关键区分：物化 vs 物态化

| | 劳动工具 | 装饰 / 撒红粉 |
|--|--|--|
| 内容 | 现实功利 | 幻想（想象） |
| 生产 | 物质生产 | 精神生产、意识形态 |
| 人化 | 社会生活外化在工具上（真物化） | 观念外化在物品上（物态化） |
| 与繁殖 | 与种族繁殖同为基础 | 属宗教、艺术、哲学胚胎的上层建筑 |

作者借用马克思「自然的人化」「人的对象化」，但强调二者不可混同。

## 二、原始歌舞

### 论证推理链

**论据**

- 文献：击石拊石、百兽率舞；巫舞雩；帝俊子始为歌舞；葛天氏三人操牛尾歌八阕；伏羲神农女娲作琴瑟笙簧。
- 杜佑《通典》：乐在耳为声、在目为容，故假干戚羽旄、发扬蹈厉。
- 王国维：楚辞之「灵」以巫兼尸，为后世戏曲萌芽。
- 《乐记》：诗言志、歌咏声、舞动容，三者本乎心。
- 青海大通上孙家寨舞蹈纹彩陶盆：五人一组，手拉手，头侧斜道似发辫，下腹饰物似尾。

**推导**

图腾所标记的是狂热活动过程，不是康德式静观。歌、舞、剧、画、神话、咒语在远古是未分化的混沌统一体。礼（巫术礼仪）与乐（原始歌舞）二而一，与氏族兴衰相连。后世才分化：礼 → 政刑典章，乐 → 文学艺术。

继龙凤之后进入英雄/祖先崇拜（契、稷神异诞生；舜驯象、羿射日、禹治水）。神话人间化、理性化，要到春秋战国才完成。此前图腾歌舞仍笼罩意识形态。

彩陶盆舞蹈图是写实又寓意的巫术场面，不是「大树下草地」的休闲舞；须与同时期几何纹观念一致，比欧洲洞穴壁画更抽象、更神秘。

**结论**

「龙飞凤舞」应理解为图腾的演习形式。英雄时代取代神人同一，是下一阶段理性化的前奏。

## 三、「有意味的形式」

### 论证推理链

**论据**

- 神农传说对应相对和平的母系期；仰韶、马家窑彩陶多鱼、狗、蜥蜴、鸟、蛙，半坡尤多鱼纹；人面含鱼。闻一多《说鱼》的生殖祝福，作者猜或可上溯半坡。
- 世界通例：新石器纹饰走廊以几何纹为主，不是动物纹。江南印纹陶讨论中，有人主张叶脉、水波模拟说；作者不同意「装饰已分化」及简单模拟说，较取蛇图腾盘曲说。
- 考古描述：半坡几何纹由鱼纹演变；庙底沟由鸟纹；马家窑螺旋由鸟、波浪垂幛由蛙；半山漩涡、马厂大圆圈为拟日纹；鸟→金乌、蛙→蟾蜍，与日月崇拜相关（严文明等）。
- 造型：大汶口陶猪（定居、养猪传统）；三足器来自实用（便于烧火），稳定、坚实、简洁、刚健，发展为礼器「鼎」。
- 晚期：直线压倒曲线，封闭重于连续；龙山空心尖三角形、半山—马厂红黑锯齿；日照石纹样及东北陶器已靠近殷商青铜。巫鸿所举早期玉雕鹰鸟与殷商图腾有关。

**推导**

由再现到表现、写实到符号化，是内容到形式的积淀。几何纹当年有严重图腾含义，不是纯形式快感。贝尔的循环（有意味的形式决定审美感情，审美感情又来自有意味的形式）用积淀打破：线条来自写实形象，意义已溶化其中。

但随重复仿制，原初意味可能流失，变成一般装饰美、形式美。色彩更原始（有动物性反应基础），线的感受需要更多观念与理解，充分发展要到制陶期。线既是空间对象，也是时间过程，可象征情感运动，犹如歌舞的抽象升华。

晚期纹饰神秘化，对应黄帝、尧舜传说中的战争、父家长制、早期奴隶制方向：权威加重。

**结论**

美在形式而不即是形式。离开自然形体没有美，只有形式也不成其为美。「有意味的形式」= 积淀了社会内容的自然形式。

**启示**

看彩陶不要只说「好看的图案」；先追溯母题（鱼/鸟/蛙）的可能图腾含义，再看它如何抽象。晚期「恐怖」不是退步，是社会结构变化在形式上的凝冻。

### 鉴赏操作要点

- 半坡：直线几何，鱼图腾线索。
- 庙底沟：曲线，鸟纹线索。
- 马家窑 → 半山/马厂：漩涡、圆圈、拟日、拟蛙。
- 席地面对陶器纹饰的「静的观照」，或从「手拉手」歌舞的「动的过程」演化而来（作者以问句提出）。
- 三足器：不模拟四足兽或两足鸟，是实用上的形式创造。

## 概念补全

**图腾（Totem）**：氏族用以自我标志、并相信与之有神秘亲属关系的动物/植物/自然力。本书暂不讨论它与巫术、神话、礼仪的严格定义之争。

**有意味的形式**：贝尔用以强调纯形式审美、为后期印象派辩护的命题。作者保留「形式本身能引起特殊感情」这一卓见，补上历史积淀，避免循环论证。

除了本章主要内容外，作者还讨论了/提及了：1. 摩尔根《古代社会》马克思摘要论想像与神话，2. 列维-斯特劳斯与血族结构，3. 马家窑人首纹与「断发文身」首先是巫术而非美观，4. 锯齿/三角或与「山」及男性生殖崇拜、方格或与土地死亡、圆形或与天体周行有关等尚待探究的猜测，5. 夏与蛇—龙图腾（姒、己均蛇）的文献线索。

## 段落总结序列

### 远古图腾

- 河姆渡、磁山、新郑等新石器遗址的发现表明，中国史前文化远比以往所知悠久灿烂，近八千年前已显露文明曙光。
- 从北京人、丁村人到山顶洞人，石器与骨器日趋规整精致，显示人类开始感受形体、色彩和秩序。作者区分实用工具中的“物化”与装饰、葬俗中的观念“物态化”，认为后者开启了社会意识形态，并走向巫术礼仪和图腾活动。
- 引文说明人类想象力在早期文明阶段生成神话、传奇和传说。山顶洞人用红色装饰并在尸体旁撒红粉，已赋予色彩以社会性的象征意义，表明宗教、艺术和审美尚未分化而共同潜藏于巫术礼仪中。
- 远古图腾与巫术礼仪已无法复原，只能借经后世改写的神话、传奇和传说，约略推想原始人的想象与符号观念。
- 多部古籍关于女娲造物、补天、造人、设婚姻以及伏羲教渔猎、作八卦的引文，集中展示二者作为远古文明创造者的神话形象。
- 从结网渔猎到创制八卦的漫长原始历史被凝聚在女娲、伏羲身上，作者据此推测二者可能代表中国最早期的远古文化。
- 作者追问女娲、伏羲的原始身份，指出剥去后世人间化外衣后，他们本是巨大龙蛇，并以女娲“人面蛇身”的记载为证。
- 《山海经》注与《帝王世纪》的简短引文分别记载伏羲、女娲人首蛇身，为二者的龙蛇原型提供文献证据。
- 中国远古神人和英雄多呈人首蛇身，《山海经》虽也记载其他人兽复合形象，但龙蛇形态尤为突出；所引山经对成群山神的蛇身人面作了集中描述。
- 本段续引《山海经》“龙身而人面”的记载，并列出闻一多整理的人面蛇身或龙身诸神资料，显示这一形象广泛分布于多地神话系统。
- “人面蛇身”的众神实为众多远古氏族的图腾和标志；《竹书纪年》所列伏羲系统的各类“龙氏”也证明当时存在庞大的龙蛇氏族群。
- 《山海经》关于烛龙、烛阴的引文描写一种赤色人面蛇身、能支配昼夜寒暑风息的巨大神灵，保存了较完整的龙蛇原始想象。
- 烛龙至女娲的人面蛇身形象可视为先民早期的“人心营构之象”，也可能是长期笼罩诸多氏族、部落与联盟的共同观念标志。
- 闻一多认为龙以蛇身为主体，综合多种动物特征，可能象征蛇图腾氏族不断战胜并融合其他部落。龙蛇形象从远古传说、文字、青铜纹饰延续至周汉艺术，因其强大生命力而成为史前艺术的代表。
- 新石器遗址出土的人首蛇身陶器盖，可能是流传久远的神异龙蛇最早的造型表现。
- 这一陶塑仍无角无足、贴地爬行而十分粗陋，但其人首已仿佛预示龙将腾空飞舞，成为众多氏族联盟的图腾旗帜；段末古籍引文补充夏族乘龙、化龙的传说。
- 注释以“姒”“己”与蛇的关联推测夏部族承续蛇龙图腾，又引研究说明早期龙是以角标示神异性的蛇，甲骨文、金文龙字可资证明。
- 与龙蛇并起的凤鸟是东方部族集团的图腾，帝俊、舜、少昊、后羿、蚩尤、商契等传说均与之相连；《说文》《诗经》《山海经》引文从形貌、商族诞生和九凤神话等方面提供依据。
- 《山海经》引文记载五彩之鸟与帝俊关系密切，用以补证东方集团的鸟图腾崇拜。
- 这条仅标明《山海经·大荒东经》的短引文承接上一段，注明五彩之鸟材料的文献出处。
- 凤如同龙一样，是现实动物被夸张和神化后的巫术图腾；龙、凤所代表的东西部族在战争中逐渐融合，西部炎黄集团胜出后龙居主位，而凤仍保持相对独立并延续到殷商、战国图像。
- “龙飞凤舞”概括了从旧石器渔猎、新石器农耕到早期奴隶制门槛前长期高扬的两面史前图腾旗帜。
- 龙凤图腾既是又不只是原始艺术：它们本是巫术礼仪与观念意识的物态化符号，但其中积淀的社会情感、观念和理性使自然形式获得超感觉价值，由此孕育审美意识与艺术创作。

### 原始歌舞

- 原始审美和艺术不是静观，而是狂热、虔诚又严整的巫术礼仪活动；后世歌、舞、剧、画、神话与咒语当时混为一体，现存图像、传说和八卦只是其强烈信仰与情感的凝固符号。
- 《尚书》《周官》《山海经》《吕氏春秋》等引文记载击石而舞、巫舞祈雨、持牛尾歌舞及远古圣王制乐器，后世《通典》则说明舞蹈借道具、动作和声容表达内在意旨，共同保存原始歌舞史料。
- 《乐记》将乐与舞相联，其中足蹈手舞、执干戚羽饰而奋厉的描述，正可理解为戴假面、插羽毛的图腾舞蹈。
- 王国维指出楚辞中的“灵”是装扮并模拟神灵的群巫，这种有情节的仪式已孕育戏剧和文学。歌、舞、诗、咒语与器乐原本同属图腾礼仪，后来才分化为政治典章之“礼”和文学艺术之“乐”。
- 图腾歌舞分化后，父权社会的英雄与祖先崇拜继龙凤神话而起，契、稷、舜、羿、鲧、禹等故事突出神异身世和功业。神话逐渐人间化、理性化并让位于政治历史，但原始图腾活动直至春秋战国前仍笼罩社会意识。
- 新石器彩陶盆上的五人组舞蹈图案以整齐、轻盈而写实的姿态印证原始歌舞，却不是闲暇娱乐，而是佩戴图腾饰物、执行祈祷功能的严肃巫术礼仪。其造型兼具动态写实、几何规范与神秘寓意。
- 翩跃起舞只是巫术礼仪的活动形态，原始歌舞实为龙凤图腾的操演方式。

### 有意味的形式

- 新石器前期母系氏族社会大体和平安定，神农教民农耕及人与麋鹿相安的古籍引文，呈现这一社会阶段及其图腾艺术的温和背景。
- “与麋鹿共处”可理解为驯鹿，仰韶彩陶上的鱼、犬、蜥蜴、鸟蛙和人面含鱼虽有图腾巫术性质，却整体传达生动、纯朴、天真而健康的童年气派。
- 半坡彩陶尤多鱼纹和人面含鱼，作者推测它们可能象征生殖繁盛与氏族延续，并进一步追问鱼形同龙蛇图腾的关系，同时强调这些都仍是待证猜想。
- 新石器陶器的主流纹饰是抽象几何纹，其起源长期存在争论。作者反对把几何纹简单解释为生活对象的模拟或独立装饰需求，更赞同其源自蛇等图腾形象的观点。
- 仰韶、马家窑纹样显示动物形象由写实再现逐渐抽象、符号化，图腾内容积淀为形式、观念积淀为感受，由此形成“有意味的形式”。所引考古描述以鱼纹融合与简化的规律说明这一演变。
- “有如图一、二、三”是简短图示说明，提示读者结合前三幅演变图观察鱼形逐渐几何化的过程。
- 这则简短图版说明指出鸟纹从写实走向写意和动态表现，并以图四展示其演化。
- 研究引文认为主要几何纹由动物纹演化，螺旋纹源于鸟纹，波浪曲线纹与垂幛纹源于蛙纹，二者或分别代表不同氏族图腾；图五、图六用于展示这种变形关系。
- 引文强调陶器纹饰不仅是装饰艺术，更是共同体物质文化的表现，通常作为氏族图腾或其他崇拜的标志。
- 分析认为半坡、庙底沟和马家窑的几何纹分别由鱼、鸟、鸟与蛙等图腾演化，其线形差异可对应不同氏族部落。
- 从半坡、庙底沟到马家窑，蛙纹和鸟纹具有连续演化脉络：由写实、生动、多样逐步变为图案化、格律化和规范化，而两类母题始终并存。
- 马家窑鸟纹逐渐漩涡化，继而发展为半山、马厂时期模拟太阳的圆形纹样，说明鸟纹与拟日纹存在内在联系。
- 古代鸟、蛙神话可能源于图腾崇拜，后来分别演化为象征日、月的金乌与蟾蜍。彩陶中相关母题长期延续，显示它们联系着民族信仰与传统观念，图七用以展示这种关联。
- 庙底沟、马家窑纹饰的具体演化顺序仍复杂而待深入研究，但动物形象由写实多样走向抽象规范的总体规律已有充分依据；这些纹饰也确有神圣的氏族图腾内涵，而非纯形式装饰。
- 审美不同于动物性感官快感，在于感受中包含观念和想象；美是积淀社会内容的自然形式，因而依赖形式却不等同于形式本身。
- 克莱夫·贝尔以“有意味的形式”与“审美感情”互相定义，陷入循环论证；作者以积淀说解释形式和感受中都融有特定社会内容，从而破解这一问题。随着时代变迁和重复仿制，原有意味会淡化，图腾纹样遂转成一般装饰美与形式感。
- 陶器几何纹以线条运动为核心，线的审美比色彩更依赖观念、想象与理解，并建立在新石器制陶生产对形体和规律的熟练掌握上。农耕生活、巫术情感及节奏、对称等形式规律积淀在线纹中，使静态陶纹成为原始歌舞及祈祷过程的抽象升华。
- 陶器造型中，陶猪反映中国先民早期定居、养猪与精耕生活，三足器则从实用需要创造出稳定、坚实、简洁、刚健的形式感，并最终发展为礼器“鼎”。
- 形式脱离写实后会按自身规律发展并反过来塑造人的感受，但其演变仍受社会结构和意识形态制约。新石器晚期的纹饰由早期活泼开放转向僵硬、封闭和威吓，反映战争、父权制及阶级统治的加强，并成为殷商青铜纹饰的前导。
