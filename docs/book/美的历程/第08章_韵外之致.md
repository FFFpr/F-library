# 第08章 韵外之致

## 本章位置

中唐是封建社会由前期到后期的转折（两税法为法律标志）。作者认为：真正展开文艺灿烂图景、各部门普遍成熟的，往往不是盛唐，而是中晚唐。本章三节：中唐百花、士人内在矛盾、苏轼作为矛盾的人格化身。

> 杜颜韩立法：[第07章_盛唐之音.md](第07章_盛唐之音.md)

## 核心论点

1. 宋太祖不杀士大夫、文臣无欧刀之辟，皇帝成整个地主阶级政权中心；白衣卿相增多。这一格局始自中唐。
2. 安史之乱后经济仍繁荣，上层奢华；进士沉浸声色词章。诗、文、书、画个性真正成熟，风格繁多。
3. 以儒家载道为基础的美学与「独善」、闲适、官场厌倦形成深刻矛盾；矛盾充分展开是后期封建社会的特点。
4. 时代精神不在马上而在闺房，不在世间而在心境。最成功的是山水画、爱情诗、宋词、宋瓷。司空图《诗品》、严羽《沧浪诗话》成为后期美学代表，讲韵味、意境。
5. 苏轼把进取与退隐的双重心理推到新质变：对**整个社会/人生**的空漠（不只是对政治的退避），为元画元曲及明中叶浪漫思潮、直至《红楼梦》「悲凉之雾」作先驱。

---

## 一、中唐文艺

### 论证推理链

**论据**

- 赵宋：保全柴氏、不杀士大夫、不加农田之赋。唐宰相多出门阀，宋相反。杜甫仍夸阀阅；宋则不大突出。
- 长安贞元后侈于游宴、书画、牡丹；白居易「天宝末年时势装」，宽袖代窄袖。科举极于德宗之世（陈寅恪）。
- 诗：大历十才子、韦柳韩、李贺、元白、贾岛卢仝，晚唐李商隐、杜牧、温庭筠。汉魏至盛唐可见时代之分、难见个性之别；中唐后个性突出（绘画个性要到明清才充分）。
- 文：韩柳为后世宗师，当时更流行元白；骈体四六同时大放异彩（李商隐）。
- 书：颜的成熟期、柳楷、李阳冰篆。
- 画：宗教画解体；人物、牛马、花鸟、山水独立。张萱、周昉《簪花仕女图》：丰硕盛装、露肩裸臂，再现上层审美。

**结论**

除先秦外，中唐上与魏晋、下与明末，是三个较开放时期之一。中唐特点是世俗地主在文化领域多样化开拓，为后期封建打基础。七律成熟、词出现、古文扩展、楷书普及，若无中唐巩固，形式也难以流传。人们常把盛唐拖到中唐；从发展史看，更重要的是承前启后的中唐。

风格上开始染孤冷、伤感，更接近杜甫：规范、意义、格律。

## 二、内在矛盾

### 论证推理链

**论据**

- 元白「文章合为时而著」；杜牧亦赞楚骚「言及君臣理乱」。钟嵘、刘勰着重感物；韩白要回到两汉经学，把文艺绑在伦理政治上。白居易《新乐府序》规定为君为民为物为事而作，辞质言直——明确而狭隘。讽喻诗当时并不如《长恨歌》传诵广远。
- 现实：皇帝不英明、仕途不顺利。白居易于甘露之变「当君白首同归日，是我青山独往时」，幸免清洗。庶族可以抽身，不像阮籍嵇康必须卷入。于是讽喻之后作闲适诗。
- 同一韩愈：韩文进攻通俗，韩诗孤僻冷峭。柳宗元《小石潭记》峭洁清远，「凄神寒骨」——标准中唐，绝非盛唐之音。
- 朱熹、苏轼已批评韩愈好道之名而未乐其实；韩自己贪名位、好声色。卫道者（王安石到王船山）不满，作者认为这倒真实表现了进士集团「很善于生活」。
- 矛盾分化：载道一面 → 宋代理学文艺观；沉浸世俗一面 → 真正的文艺主题。唐宋而后哲学与文艺（除禅宗外）分道扬镳。
- 晚唐五代北宋：李商隐、温韦、花间、晏几道、柳永、秦观、范仲淹、辛弃疾词例。词境一句一意变成一首一境，比兴多于赋，写日常细景。李商隐「夕阳无限好，只是近黄昏」最适合比拟五代北宋词：闲暇欢乐而有日暮哀愁。
- 司空图：韵外之致、味外之旨、象外之象。严羽反以才学、议论、文字为诗，讲兴趣、妙悟。严羽主观崇李杜，时代风会使他客观上更近王孟。画论逸品居神品之上；宋瓷细洁净润、色调单纯，上异唐之鲜艳，下异明清俗丽。

**结论**

后期美学中心是韵味、意境、情趣，不是前期的文笔体裁之分。人生态度的追求替代人格理想的树立。

### 诗境 / 词境（操作区分）

- 诗常一句一意，含义阔大，形象众多。
- 词常一首才一意，形象细腻，主观感情色调更浓。
- 「落花人独立，微雨燕双飞」「自在飞花轻似梦，无边丝雨细如愁」是诗中所无的另一种境界。

## 三、苏轼的意义

### 论证推理链

**论据**

- 苏是诗文书画全才，成就本身未必高过屈陶李杜；字不如诗文，诗文不如词，词数量也不算多。影响巨大是因为典型意义。
- 一面：忠君、上皇帝书、对熙宁变法的温和保守，甚至迁腐（责备李白从永王）。
- 留给后人的主要形象是另一面：一生并未真正归田，但诗文中的人生空漠，比口头/事实的退隐更深刻。不是阮陶那种具体政治哀伤，而是对整个人生目的的怀疑。对社会的退避实际上做不到（做出家和尚仍要吃饭）。
- 《赤壁赋》：沧海一粟、哀吾生之须臾、变与不变、清风明月、道士飘渺——都与空漠相联。
- 词：「世事一场大梦」「也无风雨也无晴」「小舟从此逝」；传说郡守以为他真逃了，其实在睡觉——逃不掉人世大罗网。
- 美学：朴质无华、平淡自然，反对雕琢；独把陶潜抬到极峰（唐时陶并不显赫）。《方山子传》中弃富贵居山的「异人」是理想人格标本。「人生到处知何似，应似飞鸿踏雪泥」。
- 朱熹宁赞王安石也不喜苏；王夫之亦然——感到对当时秩序有潜在破坏性。

**结论**

苏没法做封建社会的否定者，但其趣味开了通向元明清浪漫与《红楼梦》的路。
