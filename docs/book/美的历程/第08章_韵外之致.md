# 第08章 韵外之致

## 本章位置

中唐是封建社会由前期到后期的转折（两税法为法律标志）。作者认为：真正展开文艺灿烂图景、各部门普遍成熟的，往往不是盛唐，而是中晚唐。本章三节：中唐百花、士人内在矛盾、苏轼作为矛盾的人格化身。

> 杜颜韩立法：[第07章_盛唐之音.md](第07章_盛唐之音.md)

## 核心论点

1. 宋太祖不杀士大夫、文臣无欧刀之辟，皇帝成整个地主阶级政权中心；白衣卿相增多。这一格局始自中唐。
2. 安史之乱后经济仍繁荣，上层奢华；进士沉浸声色词章。诗、文、书、画个性真正成熟，风格繁多。
3. 以儒家载道为基础的美学与「独善」、闲适、官场厌倦形成深刻矛盾；矛盾充分展开是后期封建社会的特点。
4. 时代精神不在马上而在闺房，不在世间而在心境。最成功的是山水画、爱情诗、宋词、宋瓷。司空图《诗品》、严羽《沧浪诗话》成为后期美学代表，讲韵味、意境。
5. 苏轼把进取与退隐的双重心理推到新质变：对**整个社会/人生**的空漠（不只是对政治的退避），为元画元曲及明中叶浪漫思潮、直至《红楼梦》「悲凉之雾」作先驱。

---

## 一、中唐文艺

### 论证推理链

**论据**

- 赵宋：保全柴氏、不杀士大夫、不加农田之赋。唐宰相多出门阀，宋相反。杜甫仍夸阀阅；宋则不大突出。
- 长安贞元后侈于游宴、书画、牡丹；白居易「天宝末年时势装」，宽袖代窄袖。科举极于德宗之世（陈寅恪）。
- 诗：大历十才子、韦柳韩、李贺、元白、贾岛卢仝，晚唐李商隐、杜牧、温庭筠。汉魏至盛唐可见时代之分、难见个性之别；中唐后个性突出（绘画个性要到明清才充分）。
- 文：韩柳为后世宗师，当时更流行元白；骈体四六同时大放异彩（李商隐）。
- 书：颜的成熟期、柳楷、李阳冰篆。
- 画：宗教画解体；人物、牛马、花鸟、山水独立。张萱、周昉《簪花仕女图》：丰硕盛装、露肩裸臂，再现上层审美。

**结论**

除先秦外，中唐上与魏晋、下与明末，是三个较开放时期之一。中唐特点是世俗地主在文化领域多样化开拓，为后期封建打基础。七律成熟、词出现、古文扩展、楷书普及，若无中唐巩固，形式也难以流传。人们常把盛唐拖到中唐；从发展史看，更重要的是承前启后的中唐。

风格上开始染孤冷、伤感，更接近杜甫：规范、意义、格律。

## 二、内在矛盾

### 论证推理链

**论据**

- 元白「文章合为时而著」；杜牧亦赞楚骚「言及君臣理乱」。钟嵘、刘勰着重感物；韩白要回到两汉经学，把文艺绑在伦理政治上。白居易《新乐府序》规定为君为民为物为事而作，辞质言直——明确而狭隘。讽喻诗当时并不如《长恨歌》传诵广远。
- 现实：皇帝不英明、仕途不顺利。白居易于甘露之变「当君白首同归日，是我青山独往时」，幸免清洗。庶族可以抽身，不像阮籍嵇康必须卷入。于是讽喻之后作闲适诗。
- 同一韩愈：韩文进攻通俗，韩诗孤僻冷峭。柳宗元《小石潭记》峭洁清远，「凄神寒骨」——标准中唐，绝非盛唐之音。
- 朱熹、苏轼已批评韩愈好道之名而未乐其实；韩自己贪名位、好声色。卫道者（王安石到王船山）不满，作者认为这倒真实表现了进士集团「很善于生活」。
- 矛盾分化：载道一面 → 宋代理学文艺观；沉浸世俗一面 → 真正的文艺主题。唐宋而后哲学与文艺（除禅宗外）分道扬镳。
- 晚唐五代北宋：李商隐、温韦、花间、晏几道、柳永、秦观、范仲淹、辛弃疾词例。词境一句一意变成一首一境，比兴多于赋，写日常细景。李商隐「夕阳无限好，只是近黄昏」最适合比拟五代北宋词：闲暇欢乐而有日暮哀愁。
- 司空图：韵外之致、味外之旨、象外之象。严羽反以才学、议论、文字为诗，讲兴趣、妙悟。严羽主观崇李杜，时代风会使他客观上更近王孟。画论逸品居神品之上；宋瓷细洁净润、色调单纯，上异唐之鲜艳，下异明清俗丽。

**结论**

后期美学中心是韵味、意境、情趣，不是前期的文笔体裁之分。人生态度的追求替代人格理想的树立。

### 诗境 / 词境（操作区分）

- 诗常一句一意，含义阔大，形象众多。
- 词常一首才一意，形象细腻，主观感情色调更浓。
- 「落花人独立，微雨燕双飞」「自在飞花轻似梦，无边丝雨细如愁」是诗中所无的另一种境界。

## 三、苏轼的意义

### 论证推理链

**论据**

- 苏是诗文书画全才，成就本身未必高过屈陶李杜；字不如诗文，诗文不如词，词数量也不算多。影响巨大是因为典型意义。
- 一面：忠君、上皇帝书、对熙宁变法的温和保守，甚至迁腐（责备李白从永王）。
- 留给后人的主要形象是另一面：一生并未真正归田，但诗文中的人生空漠，比口头/事实的退隐更深刻。不是阮陶那种具体政治哀伤，而是对整个人生目的的怀疑。对社会的退避实际上做不到（做出家和尚仍要吃饭）。
- 《赤壁赋》：沧海一粟、哀吾生之须臾、变与不变、清风明月、道士飘渺——都与空漠相联。
- 词：「世事一场大梦」「也无风雨也无晴」「小舟从此逝」；传说郡守以为他真逃了，其实在睡觉——逃不掉人世大罗网。
- 美学：朴质无华、平淡自然，反对雕琢；独把陶潜抬到极峰（唐时陶并不显赫）。《方山子传》中弃富贵居山的「异人」是理想人格标本。「人生到处知何似，应似飞鸿踏雪泥」。
- 朱熹宁赞王安石也不喜苏；王夫之亦然——感到对当时秩序有潜在破坏性。

**结论**

苏没法做封建社会的否定者，但其趣味开了通向元明清浪漫与《红楼梦》的路。

> 《红楼梦》中这一因素的成果：[第10章_明清文艺思潮.md](第10章_明清文艺思潮.md)

除了本章主要内容外，作者还讨论了/提及了：1. 刘晏理财、杨炎两税，2. 孙棨《北里志》宣宗重进士，3. 高棅、宋濂、胡应麟对中晚唐诗派的分疏，4. 谭献、沈祥龙论词比兴，5. 黄休复《益州名画录》逸品居上。

## 段落总结序列

### 中唐文艺

- 中唐以两税法为标志，开启封建社会由门阀士族向世俗地主主导的转折，至宋代最终定型；皇权成为整个地主阶级的政权中心，科举出身的士大夫地位空前提高，社会由重门第转向重文臣与文化。
- 这种延续到宋代的社会文化变迁，最早正从中唐发端。
- 安史之乱后社会经济仍继续繁荣，上层生活日趋奢华闲适，科举进士沉浸于都市宴游、声色和词章，盛唐的军功向往与反叛豪气逐渐消退；与此同时，文艺却由雄豪单一转向多彩繁盛，诗书画各门类在中晚唐普遍取得高度成就。
- 中唐以后，诗人不再主要以时代或诗派面目出现，而形成韩愈、柳宗元、白居易、李贺、贾岛等各具辨识度的风格，并延伸至李商隐、杜牧、温庭筠等晚唐名家，诗歌个性由此真正成熟。
- 各家评论虽对时代分期略有不同，却都指出元和以后名家横绝、风格纷呈：韩愈鸿伟、柳宗元精工、刘禹锡雄奇、白居易浩博，孟郊、贾岛、李贺、卢仝以及晚唐诸家也各逞才力。
- 中唐诗坛名家辈出，散文同样繁盛；韩柳古文、元白通俗诗文与传统骈体四六并行发展，说明当时并非一体独尊，而是多种文风竞相放彩。
- 中唐书法也呈多元繁盛之势，颜真卿书艺趋于成熟，柳公权楷书和李阳冰篆书各具特征并影响后世。
- 中唐绘画中宗教画迅速解体，人物、牛马、花鸟、山水获得独立发展；韩幹、韩滉、张萱、周昉等人的世俗题材与《簪花仕女图》中的富贵闲乐，形象再现了上层社会的审美趣味。
- 中唐与魏晋、明末同属古代思想较开放自由的时期，其特点是世俗地主在文化思想领域全面开拓并走向成熟；七律、词、散文和楷书等形式正因中唐的百花齐放而得以巩固流传，所以中唐比通常被强调的盛唐更具承前启后意义。
- 中唐美学已失去李白、张旭的飞逸和杜甫、颜真卿的刚健，洒脱中开始染上孤冷、伤感与忧郁；同时它继承杜甫的道路，在严格格律和形式规范中追求意义与美，并使这一审美观念得到巩固发展。

### 内在矛盾

- 从中唐开始，一种影响后期封建文艺的深刻矛盾逐渐酝酿形成。
- 杜甫、颜真卿、韩愈以及元白、杜牧都倾向以儒家政治伦理规定文艺的现实使命，试图取代魏晋以来重感物抒情的观念；白居易甚至把诗文限定为为君、为民、为事而作的实用工具，因忽视艺术自身规律而显得狭隘，其讽喻诗的成就也不及《长恨歌》等抒情作品。
- 士大夫一面以儒家理想追求仕途、兼济天下，一面又因皇权昏暗和官场倾轧转向独善其身，形成热心政治却又退出现实的双重性；白居易由讽喻转向闲适、韩愈文章与诗歌风貌相反、柳宗元和韦应物兼具愤激与超脱，都是这种矛盾的艺术表现。
- 柳宗元山水文字峭洁清远、遗世独立，是中唐而非盛唐的典型产物；儒家的“兼济”与道家的“独善”虽古已有之，却到中唐以后的后期封建社会才充分展开为具有时代和阶级深意的矛盾。
- 韩愈口倡儒家道统，现实生活却追逐名位、财富与声色，真实体现了世俗地主知识分子既标榜道德又善享生活的性格；此后前一面发展为宋代理学及其文艺观，后一面则把世俗体验变成真正的艺术主题，使哲学与文艺逐渐分离。
- 晚唐五代以来的优秀诗词由盛唐的功业和行动转向细腻的感官、爱情与心绪，山水画、爱情诗、宋词和宋瓷遂成为成功门类；时代精神从马上转入闺房、从世间转入心境，盛唐的博大、中唐的退缩萧瑟和晚唐向日常生活与词境的过渡，根源都在社会变迁。
- 词以长短句集中刻画细微心绪，通过普通日常景物的白描和比兴赋予对象浓厚主观色彩；相较诗境的一句一意、形象众多和阔大浑厚，词境往往全篇凝成一境，显得细腻、微妙而新巧。
- 词创造了花轻似梦、雨细如愁的亲切小境，即便书写家国愁和征夫恨，也转用更细密、更易动情的形式，呈现诗中少见的审美境界。
- 词境虽尖新细窄，不及诗境阔大浑厚，却擅长表现人的心情意绪，尤其能细腻亲切地描写爱情，因此长期受到青年男女喜爱。
- 李商隐“夕阳无限好，只是近黄昏”最能象征五代北宋词的时代心理：景色幽闲绚丽，却已失去旭日般的蓬勃朝气，并始终笼罩着百无聊赖和淡淡哀愁。
- 中唐至北宋的艺术发展，使风格、韵味和意境成为美学中心；司空图追求“韵外之致”“象外之象”，严羽强调兴趣、气象和妙悟，都要求艺术创造可意会难言传的境界，进一步深化了中国美学重抒情表现的传统。
- 严羽主观上推崇汉魏盛唐和李杜，实际理论却因时代潮流而偏向王孟式的空灵、含蓄、平淡与自然；山水画、宋词、陶潜地位上升、逸品观和宋瓷的细洁高雅，也共同汇成以追求韵味为核心的一代美学风神。

### 苏轼的意义

- 苏轼是中晚唐以来文艺思潮和士大夫矛盾心理的典型化身；他的单项艺术成就未必能比肩屈原、陶潜、李白、杜甫，却因把进取与退隐的双重心态推进到新的质变点，而在文艺史和美学史上影响巨大。
- 苏轼一面忠君爱国、坚守儒家正统，一面通过诗文表达比政治退避更深的社会与人生退避；他怀疑人生和世事的意义，渴望解脱却无法真正逃离社会，《赤壁赋》中的人生短促、天地无穷及清风明月之慰，正表现这种沉重空漠和勉强排遣。
- 苏词含蓄地反复书写劳生有限、世事如梦、孤栖无依和营营难忘，即使说“也无风雨也无晴”或欲驾舟远逝，仍透出无法摆脱尘世的孤独与倦怠。
- 苏轼并未真的“江海寄余生”，因为人无法逃出社会；他借佛老寻求安慰，把人生空幻、求超脱而不得的心绪化为自然平淡、朴质无华的审美理想，并由此推尊陶渊明，使陶诗以苏轼所阐释的平淡真味成为后世艺术高峰。
- 《方山子传》写方山子出身勋贵、家资丰厚，本可仕进享乐，却弃车马冠服而独居穷山，并与当地隐逸异人交往。
- 方山子或许正是苏轼理想化的人格标本，他不逐富贵、不合流俗而任侠自适，体现了苏轼在太平世道中独特的退隐向往。
- 苏轼以飞鸿踏雪泥比喻人生偶然，即使表现随遇而安的乐观，内里仍潜藏彻底解脱的出世意念；这种对既有秩序具有潜在破坏性的审美态度，成为元代文艺、明代浪漫思潮乃至《红楼梦》悲凉意识的重要先驱。
