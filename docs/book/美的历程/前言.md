# 前言（开篇巡礼）

本书没有独立标名的长篇序言。正文开始前有一段不列入「目次」的开场，相当于全书的导游词。封面另有冯友兰、易中天的评语，版权页说明版本。以下按这段开场整理。

## 核心论点

中国还很少专门的艺术博物馆。若对史实不熟，仍可在历史文物中作一次「美的巡礼」：彩陶、青铜、汉代工艺、北朝雕塑、晋唐书法、宋元山水，以及屈原、陶潜、李白、杜甫、曹雪芹等人的想象画像，直接可感的是这个文明古国的**心灵历史**。时代精神的火花在此凝冻、积淀，传留并感染后来者的思想、情感、观念、意绪。

本书所要匆匆走过的，就是这样一个美的历程。起点必须从「遥远得记不清岁月的时代」开始。

## 论证推理链

**论据 / 事实**

- 作者点名的视觉标本：人面含鱼的彩陶盆、古色斑斓的青铜器、汉代工艺、秀骨清像的北朝雕塑、笔走龙蛇的晋唐书法、说不尽的宋元山水画（OCR 作「朱元」，据上下文为宋元）。
- 文学家谱系与上述器物并列，说明「美的历程」兼跨造型与语言艺术。
- 地点提示：北京天安门前的中国历史博物馆（今国家博物馆前身语境中的历史陈列）。

**推导**

器物与诗人画像之所以能「一唱三叹、流连不已」，不是因为它们只是考古标本，而是因为其中凝冻了各时代的精神。参观可以绕开编年史实，仍碰到民族的情感结构。

**结论**

美学巡礼有独立于「熟悉史实」的入口：从可感形式进入心灵历史。

## 实操细节

- **怎么看博物馆**：不必先背断代，先让形式打动自己，再问「这里凝冻的是哪种时代精神」。
- **全书节奏**：作者预告是「匆匆迈步」，细部鉴赏不是本书任务；结语将再次承认鸟瞰的局限。

除开场巡礼外，书前还出现：丛书名「李泽厚集」、三联书店；冯友兰「几部大书」之评；易中天「凤毛麟角」「天网恢恢，疏而不漏」之评；CIP 将本书归入「艺术史—中国」（J120.9）；责任编辑舒炜、史行果，装帧罗洪；定价 56.00 元。封底列出同集其他著作，如《批判哲学的批判》《华夏美学·美学四讲》《中国古代思想史论》等。

除了本章主要内容外，作者还讨论了/提及了：1. 中国专门艺术博物馆之少，2. 用历史博物馆替代艺术馆作美育入口，3. 诗人「想像画像」与文物同等作为心灵史材料。

## 段落总结序列

### 封面评语

- 冯友兰评价《美的历程》是一部涵盖中国美学、美术、文学、哲学与文化史的“大书”。
- 易中天赞誉本书以十几万字纵览中华审美历程，既高屋建瓴又疏密有致，在从容巡礼中触及文明古国的心灵历史。

### 开场巡礼

- 作者邀请读者从彩陶、青铜器、雕塑、书法、宋元山水画及历代文学家形象中展开审美巡礼；这些作品凝聚时代精神，保存并感染着后人的思想情感，构成中华文明的心灵史。
- 作者以设问承接开场，提出这段审美历程应从何处起步。
- 答案是从年代已难以追记的遥远史前时代开始。
