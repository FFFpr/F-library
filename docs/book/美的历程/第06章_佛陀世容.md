# 第06章 佛陀世容

## 本章位置

魏晋风度的理想人格，在佛教成为国教后，借巨型佛像表现出来。本章以石窟（尤其敦煌）为线索，分北魏、唐前期、中晚唐至宋三型，看民族如何接受、改造、消化并最终摆脱佛教迷狂。

> 「秀骨清相」与门阀审美：[第05章_魏晋风度.md](第05章_魏晋风度.md)

## 核心论点

1. 宗教艺术首先是宣传品与膜拜对象，美的形式为宗教内容服务；同时又是现实苦难的折射。
2. 北魏：印度本生的悲惨故事 + 宁静超脱的佛身 = 刺激性迷狂；雕塑高峰是概括性极大的理想神。
3. 唐前期：净土变与慈祥人间化的佛——以欢乐幻想取代残酷苦修；儒家渗进佛堂，君君臣臣各有职守。
4. 中唐以后走向世俗：供养人大于菩萨，现实出行图占洞窟；禅宗统一信仰与日常生活；宋塑已是世俗的人。作者个人推重魏型，因更发挥雕塑「以静态人体轮廓表达高度概括理想」的种类特性。

中国古代社会三大转折起点：魏晋、中唐、明中叶。中唐变化在本章「走向世俗」已出现。

---

## 一、悲惨世界（魏）

### 论证推理链

**论据**

- 北魏、南梁先后宣布佛教为国教。石窟比庙宇在战乱中易保存（道宣语）。
- 普遍题材：割肉贸鸽（尸毗王）、舍身饲虎、须达拏好施、五百强盗挖眼。画面选割肉、饲虎等极端痛苦，衬飞天流畅线条。黑格尔：在苦痛中意识到所舍弃之物的价值（作者认为完全适合此处）。
- 现实：汉末至唐统一四百年，白骨蔽野、路断千里的记载史不绝书；「假慕沙门，实避调役」。业有三报（现报、生报、后报）。
- 洞窟主人是雕塑。云冈早期威严 → 龙门、敦煌、麦积山成熟期秀骨清相、长脸细颈、衣褶飘动，去尽烟火。佛不显示仁爱关怀，而是对世间的完全超脱。
- 云冈佛像「令如帝身」，脸上脚下黑痣同帝体（《魏书·释老志》）。梁武帝赎身巨款与百姓「卖儿贴妇钱」投入同一佛像，对象化要求却不同。
- 陆探微「秀骨清相」、顾恺之「清羸示病」；北朝认江东衣冠礼乐为正朔。印度式接吻、扭腰、性刺激被排除，形式全面中国化。

**推导**

人愈渺小，佛身愈高大。壁画愈血肉淋漓，中央佛愈宁静——肉体愈摧残，心灵被表现为愈丰满。具体形象高于抽象教义：悲惨场景也可读成对压迫的无声抗议。

**结论**

北魏美学：激昂、狂热、紧张、粗犷；雕塑则是智慧思辨、内容宽泛不定的理想神。

## 二、虚幻颂歌（隋至盛唐）

### 论证推理链

**论据**

- 隋塑方面大耳、短颈粗体，过渡到唐的健康丰满。佛更慈祥，愿接近世间。一铺像分工明确：本尊祥和、阿难温顺、迦叶认真、菩萨文静、天王威武、力士暴烈。
- 沙门拜王者、报父母；僧官有俸；《报父母恩重经》流行；儒佛道由攻诘到协调。天王力士是「大棒」，菩萨是「胡萝卜」，本尊无为而无不为——具体而微的李唐佛国。龙门奉先寺大佛被作者比为中国雕塑中的「阿波罗」。
- 壁画：饲虎贸鸽消失，代以净土变——琉璃为地、七宝楼阁、乐队飞天。维摩由「清羸示病」变为健壮老头。马由瘦劲而丰肥，飞天由男而女。
- 「恶友品」：求宝、刺盲、弹筝、公主、复明、大团圆——与北魏悲惨故事趣味惊人不同。
- 社会：均田尚在，门阀下坡，世俗官僚地主得势；边疆发愿文向往「转生中国」。

**推导**

精神统治改为用诱人的天堂，不再用吓人的苦难。雕塑与壁画由强烈对比的崇高，变为互补和谐的优美。天上与人间相互接近。

**结论**

唐型：不离人间又高出人间。跪在经变前是钦羡追求，心理不同于北魏的畏惧与自我舍弃。

## 三、走向世俗（中唐—宋）

### 论证推理链

**论据**

- 中唐：两税法、货币租、科举、非身份性地主。盛唐高大菩萨行列消失，经变场景占满墙壁；晚唐五代经变种类多而神像少，色彩俗艳。供养人形象愈来愈大。
- 《张议潮统军出行图》《宋国夫人出行图》以现实写真占据佛窟显位。中原吴道子让位于周昉、张萱。生活小景（得医、耕作、挤奶）增多。山水从「人大于山」的符号背景变为可独立观赏（如宋代《五台山图》）。
- 《劳度叉斗圣变》：斗法如说书娱乐。寺院俗讲多讲王陵、季布、伍子胥，「所言无非淫秽鄙亵之事」（赵璘），是宋人平话先声。
- 禅宗：不必出家苦修；「担水砍柴，莫非妙道」；从凡人圣更要从圣入凡。宗教哲学将被宋儒替代。
- 宋代洞窟：大而无精神，菩萨如剪纸，图案呆板回纹。宋塑（大足、晋祠、麦积山）面容柔嫩妩媚，侍女像已无宗教意味。韩幹宗教画已被记为贵族家妓写真。

**结论**

三种美的类型（只是大体）：魏以理想胜，宋以现实胜，唐以二者结合胜。各有优劣；作者较推重第一种。
