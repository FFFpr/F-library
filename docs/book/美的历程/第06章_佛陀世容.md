# 第06章 佛陀世容

## 本章位置

魏晋风度的理想人格，在佛教成为国教后，借巨型佛像表现出来。本章以石窟（尤其敦煌）为线索，分北魏、唐前期、中晚唐至宋三型，看民族如何接受、改造、消化并最终摆脱佛教迷狂。

> 「秀骨清相」与门阀审美：[第05章_魏晋风度.md](第05章_魏晋风度.md)

## 核心论点

1. 宗教艺术首先是宣传品与膜拜对象，美的形式为宗教内容服务；同时又是现实苦难的折射。
2. 北魏：印度本生的悲惨故事 + 宁静超脱的佛身 = 刺激性迷狂；雕塑高峰是概括性极大的理想神。
3. 唐前期：净土变与慈祥人间化的佛——以欢乐幻想取代残酷苦修；儒家渗进佛堂，君君臣臣各有职守。
4. 中唐以后走向世俗：供养人大于菩萨，现实出行图占洞窟；禅宗统一信仰与日常生活；宋塑已是世俗的人。作者个人推重魏型，因更发挥雕塑「以静态人体轮廓表达高度概括理想」的种类特性。

中国古代社会三大转折起点：魏晋、中唐、明中叶。中唐变化在本章「走向世俗」已出现。

---

## 一、悲惨世界（魏）

### 论证推理链

**论据**

- 北魏、南梁先后宣布佛教为国教。石窟比庙宇在战乱中易保存（道宣语）。
- 普遍题材：割肉贸鸽（尸毗王）、舍身饲虎、须达拏好施、五百强盗挖眼。画面选割肉、饲虎等极端痛苦，衬飞天流畅线条。黑格尔：在苦痛中意识到所舍弃之物的价值（作者认为完全适合此处）。
- 现实：汉末至唐统一四百年，白骨蔽野、路断千里的记载史不绝书；「假慕沙门，实避调役」。业有三报（现报、生报、后报）。
- 洞窟主人是雕塑。云冈早期威严 → 龙门、敦煌、麦积山成熟期秀骨清相、长脸细颈、衣褶飘动，去尽烟火。佛不显示仁爱关怀，而是对世间的完全超脱。
- 云冈佛像「令如帝身」，脸上脚下黑痣同帝体（《魏书·释老志》）。梁武帝赎身巨款与百姓「卖儿贴妇钱」投入同一佛像，对象化要求却不同。
- 陆探微「秀骨清相」、顾恺之「清羸示病」；北朝认江东衣冠礼乐为正朔。印度式接吻、扭腰、性刺激被排除，形式全面中国化。

**推导**

人愈渺小，佛身愈高大。壁画愈血肉淋漓，中央佛愈宁静——肉体愈摧残，心灵被表现为愈丰满。具体形象高于抽象教义：悲惨场景也可读成对压迫的无声抗议。

**结论**

北魏美学：激昂、狂热、紧张、粗犷；雕塑则是智慧思辨、内容宽泛不定的理想神。

---

## 二、虚幻颂歌（隋至盛唐）

### 论证推理链

**论据**

- 隋塑方面大耳、短颈粗体，过渡到唐的健康丰满。佛更慈祥，愿接近世间。一铺像分工明确：本尊祥和、阿难温顺、迦叶认真、菩萨文静、天王威武、力士暴烈。
- 沙门拜王者、报父母；僧官有俸；《报父母恩重经》流行；儒佛道由攻诘到协调。天王力士是「大棒」，菩萨是「胡萝卜」，本尊无为而无不为——具体而微的李唐佛国。龙门奉先寺大佛被作者比为中国雕塑中的「阿波罗」。
- 壁画：饲虎贸鸽消失，代以净土变——琉璃为地、七宝楼阁、乐队飞天。维摩由「清羸示病」变为健壮老头。马由瘦劲而丰肥，飞天由男而女。
- 「恶友品」：求宝、刺盲、弹筝、公主、复明、大团圆——与北魏悲惨故事趣味惊人不同。
- 社会：均田尚在，门阀下坡，世俗官僚地主得势；边疆发愿文向往「转生中国」。

**推导**

精神统治改为用诱人的天堂，不再用吓人的苦难。雕塑与壁画由强烈对比的崇高，变为互补和谐的优美。天上与人间相互接近。

**结论**

唐型：不离人间又高出人间。跪在经变前是钦羡追求，心理不同于北魏的畏惧与自我舍弃。

## 三、走向世俗（中唐—宋）

### 论证推理链

**论据**

- 中唐：两税法、货币租、科举、非身份性地主。盛唐高大菩萨行列消失，经变场景占满墙壁；晚唐五代经变种类多而神像少，色彩俗艳。供养人形象愈来愈大。
- 《张议潮统军出行图》《宋国夫人出行图》以现实写真占据佛窟显位。中原吴道子让位于周昉、张萱。生活小景（得医、耕作、挤奶）增多。山水从「人大于山」的符号背景变为可独立观赏（如宋代《五台山图》）。
- 《劳度叉斗圣变》：斗法如说书娱乐。寺院俗讲多讲王陵、季布、伍子胥，「所言无非淫秽鄙亵之事」（赵璘），是宋人平话先声。
- 禅宗：不必出家苦修；「担水砍柴，莫非妙道」；从凡人圣更要从圣入凡。宗教哲学将被宋儒替代。
- 宋代洞窟：大而无精神，菩萨如剪纸，图案呆板回纹。宋塑（大足、晋祠、麦积山）面容柔嫩妩媚，侍女像已无宗教意味。韩幹宗教画已被记为贵族家妓写真。

**结论**

三种美的类型（只是大体）：魏以理想胜，宋以现实胜，唐以二者结合胜。各有优劣；作者较推重第一种。

> 中唐作为封建社会前期到后期的转折，在文艺上的展开见：[第08章_韵外之致.md](第08章_韵外之致.md)

除了本章主要内容外，作者还讨论了/提及了：1. 太武帝灭佛与文成帝复法营云冈，2. 「秃头官家」之讥，3. 姚秦设僧正为公给食俸之始，4. 杜牧制文赞僧「利根事佛，余力通儒」，5. 朱诗（宋诗）与理学的清凉贫乏可与宋窟互参。

## 段落总结序列

### 悲惨世界

- 宗教既是麻痹人的幻觉，也可能寄托对现实苦难的抗议；中国佛教石窟艺术随南北朝至宋代的社会变化而中国化，并最终走向衰亡，显示华夏理性传统逐渐战胜神秘迷狂。
- 北魏是中国石窟艺术的早期阶段，云冈、敦煌、麦积山壁画多采用印度佛传与本生题材，其中割肉贸鸽、舍身饲虎、须达拏施舍和五百强盗等故事最常见。
- 尸毗王为救鸽子割下自己的血肉，直至以全身抵偿，最终证明鹰鸽是神的试探；壁画以镇定高大的王与凶狠刽子手、惊惧众人相对照，在肉体惨痛中突出心灵的平静与崇高。
- “舍身饲虎”讲小王子为救饿虎刺身流血并跳下山岩，最终被虎吃得只剩残骸，父母悲痛后在当地建塔纪念。
- 壁画用连续场景描绘饿虎、坠崖、噬食、悲泣与建塔，尤突出王子饲虎的惨烈一幕，以更阴森的苦难反衬灵魂的善良美丽。
- 这种无条件牺牲生命的教义既是统治者的自我安慰，也是使百姓顺从的麻药；北魏壁画以荒凉环境、奔放线条和剧烈动态营造狂热紧张的气氛，正如黑格尔所说，以自觉承受苦痛来证明心灵的丰富。
- 须达拏太子为实践布施，先后送出国宝、车马、衣物，最后连恐惧哭泣的亲生儿女也捆起交给乞求者，凸显反常而残酷的自我牺牲。
- 五百强盗起兵失败后被处以剜眼重刑，佛为他们恢复视力，使其全部皈依佛法。
- 这些血腥故事虽宣扬忍受苦难和来世报偿，却也以具体形象无声控诉现实压迫；长期战乱、屠杀、饥荒和疾疫使人们转向轮回因果，并在石窟中寄托希望、压抑反抗，因此其艺术保存了那个时代沉重而狂热的历史情感。
- 洞窟以雕塑为主、壁画为衬；北魏佛像从威严庄重发展到秀骨清相，以宁静、睿智和超脱对照四周惨烈图景，凝聚人们对公平与理想的渴望，也折射现实中的无奈。
- 佛像仍是当时社会形体与精神理想的凝聚，不同阶级又赋予它不同诉求；北魏造像融合帝王权威、门阀士族的智慧风度与南朝审美，并排除印度艺术的感官刺激，形成全面中国化的一代精神形象。

### 虚幻颂歌

- 隋唐的统一、和平与稳定改变了佛教艺术；自北周、隋至盛唐，雕塑和壁画逐步形成与北魏“悲惨世界”相对的崭新美学典型。
- 隋塑由秀骨清相转向朴拙厚重，唐塑则呈现健康丰满的体态与亲切人情味；佛不再是高不可攀的思辨神，而成为关怀现世、可供祈求的权威主宰。
- 唐代洞窟如舒适房间，佛、弟子、菩萨、天王和力士的身份、职能及神态明确分化；形象因而更具体、更世俗，神秘莫测的精神性相对减弱。
- 佛教进一步受儒家与皇权支配，教义、组织和伦理都向封建政治靠拢；唐代造像以尊卑有序、刚柔并济的群体组成“天上的李唐王朝”，既高于人间又亲近人间，奉先寺大佛是其杰出代表。
- 唐代壁画由牺牲惨剧转向“净土变”的极乐世界，以楼阁、乐舞、彩云与花木构成华丽欢乐的幻境；舞蹈美、女性美和圆润线条取代北魏的狂放运动，从描述苦难求慰藉转为幻想幸福求满足。
- “恶友品”讲善友太子寻得宝珠后遭恶友夺宝刺瞎，流落异国并与公主相爱，最终复明归国、宽赦恶友，全家团圆。
- 善友故事与北魏惨烈本生故事趣味迥异，其富于中国人情世态的大团圆，体现了隋唐雕塑和壁画的新时期精神。
- 审美理想的变化根源在现实生活：统一繁荣、门阀衰落与世俗地主兴起带来新的社会心理，并共同渗入佛教及其艺术。
- 社会苦难减轻后，宗教统治由恐怖牺牲转向诱人的天堂许诺；唐代雕塑与壁画由崇高的矛盾对比变为优美的和谐互补，以宫廷贵族生活为蓝本唱出幸福梦想的幻景颂歌。

### 走向世俗

- 除先秦外，中国古代社会有魏晋、中唐、明中叶三大转折，它们都鲜明改变了意识形态、文艺和美的理想。
- 中唐均田制和租庸调瓦解，货币税、贸易与科举发展，世俗地主势力上升，社会崇尚奢华享乐；中国封建社会由此转入后期，并在北宋完成转变，敦煌壁画也清楚反映这一过程。
- 中唐以后，高大的菩萨行列让位于铺满墙面的繁复“经变”，人物减少而场景与装饰增多；至晚唐五代，色彩趋于俗艳，线条也由劲健圆润变得纤秀甚至草率。
- 神像缩小而供养人增大，现实中的贵族按尊卑长幼盛装排列；这表明人间生活已比西方极乐世界更具吸引力，壁画开始真正转向现实。
- 晚唐五代敦煌的《张议潮统军出行图》和《宋国夫人出行图》直接描绘现实生活，却在佛教石窟中占据显著位置。
- 《张议潮统军出行图》以战马、旌旗、鼓角和军政队列歌颂民族英雄，《宋国夫人出行图》则描写车马、杂技与乐舞；世俗场景大举进入佛国，标志宗教艺术即将让位于现实艺术。
- 壁画中的宴会、阅兵、行旅、耕作、挤奶、拉纤等“生活小景”日益增多，许多已与宗教无关；这意味着人世生活战胜天国信仰，艺术形象超越宗教教义。
- 山水楼台也摆脱北魏时期的符号化背景地位，转向写实并获得独立观赏价值，宋代《五台山图》即为代表。
- 五代《劳度叉斗圣变》以树、风、宝池、白象等连续斗法构成戏剧冲突；它主要靠世俗故事性娱乐观众，而非凭教义劝人崇拜，宗教虔诚因而逐渐退出艺术。
- 唐代寺院“俗讲”多采用民间传说和历史故事招徕听众，内容已远离佛经与玄学思辨，成为宋代平话和市民文艺的先声。
- 中唐禅宗以日常生活即是妙道、从圣入凡为核心，取消烦琐仪式、苦修和偶像崇拜，使信仰与生活合一；它在理论上对应宗教艺术的世俗化，并预示佛教哲学将让位于宋儒世俗哲学。
- 宋代敦煌石窟虽规模宏大，却因宗教精神消退而图式呆板、贫乏无力，只有写实山水楼台尚可观赏；这种艺术状态与重议论、伦常而少激情和思辨的宋代理学相近。
- 唐宋宗教形象日益成为现实人物的写照；大足、晋祠、麦积山等宋塑以柔美、具体、可亲的妇女形象取代魏代思辨神和唐代主宰神，实际已越出宗教艺术范围。
- 中国佛教艺术经历了天人对立、接近和谐到完全合一，也经历了宗教艺术兴盛至消亡；魏以理想胜、宋以现实胜、唐以二者结合胜，作者更推崇魏式造像以静态人体高度概括理想的雕塑特性。
