# 第03章 先秦理性精神

## 本章位置

青铜「开放期」已进入理性主义。本章专论春秋战国：儒家把礼乐纳入实践理性，道家从审美与创作规律上补充儒家；《诗经》与诸子散文的赋比兴；木构宫殿建筑如何体现同一精神。

> 巫史文化的退场：[第02章_青铜饕餮.md](第02章_青铜饕餮.md)

## 核心论点

1. 先秦总思潮是理性主义：摆脱原始巫术，奠定汉民族的文化—心理结构。
2. **儒道互补**是两千多年中国思想的基本线索。孔子用实践理性重新解释礼乐；庄子抓住「言不尽意」、超功利审美，主要影响创作规律。
3. 中国诗以抒情胜，情感必须客观化；赋比兴是情与想象、理解结合的途径。「不道破一句」成为重要标准。
4. 中国建筑以宫殿（活人君主的世间居所）而非神庙为代表：平面铺开、时间性游历、线的飞檐，排斥宗教迷狂。园林以「道」补「儒」。

---

## 一、儒道互补

### 实践理性（先补概念）

作者所谓实践理性：把理性贯彻在日常伦常与政治中，不作抽象玄思。不是康德原义的照搬，而是用来概括孔学特征。

### 论证推理链

**论据**

- 孔子答宰我「三年之丧」：把丧制建立在「子生三年然后免于父母之怀」的亲子心理上（「于女安乎」）。
- 「礼云礼云，玉帛云乎哉；乐云乐云，钟鼓云乎哉。」乐须：诉诸普遍感官愉快；联系伦理感情与政治。
- 荀子《乐论》、《乐记》：乐者乐也；治世、乱世、亡国之音与政通；「乐统同，礼辨异」。
- 郭沫若：古代「乐」可含诗、舞、绘画、建筑、仪仗、田猎、肴馔，以音乐为代表。
- 孔子「敬鬼神而远之」「知其不可而为之」→ 荀子「制天命而用之」、《易传》「天行健」；另一面演化为庄子泛神论。
- 「匹夫不可夺志」→ 孟子浩然人格；另一面 → 庄子遗世独立。
- 荀子「性无伪则不能自美」vs 庄子「天地有大美而不言」。
- 《庄子·秋水》《天道》：可以言论者粗，意之所随不可言传。

**推导**

孔子把宗教三要素（观念、情绪、仪式，普列汉诺夫定义）消溶在亲子血缘的世间关系中，情感不导向神学偶像。于是中国艺术重情理结合、以理节情，而非禁欲、认知愉快或柏拉图式迷狂、亚里士多德式净化。这与《乐论》vs 亚里士多德《诗学》（情感塑造 vs 认识模拟/净化）的差异一致。

中国美学范畴多是功能性的（阴阳、和同、气势、韵味）：重对立渗透而非冲突，重生命意兴而非模拟可信，重阳刚阴柔而非宿命崇高——均可追溯到先秦理性的「中和」。

儒道表面入世/出世对立，实则互补：兼济与独善、身在江湖心存魏阙成为士人常规。儒家狭隘功利常束缚艺术；道家以浪漫想象、个性、自然生命冲击之。儒家影响主题内容，道家影响审美与创作规律；而艺术作为意识形态，重要性恰恰在审美规律。

**结论**

塑造中国人世界观、艺术理想的，是儒道相反相成，不是单一孔学。

## 二、赋比兴原则

### 论证推理链

**论据**

- 真正文学作品首推《诗经》国风与诸子散文。举《柏舟》《黍离》《风雨》《蒹葭》《采薇》等：短小而深沉的抒情，异于他民族长篇叙事史诗。
- 朱熹：赋者敷陈直言；比者以彼比此；兴者先言他物引起所咏。
- 《文心雕龙》：比附、兴起。钟嵘：言有尽而意无穷，兴也；因物喻志，比也。
- 王夫之：「不道破一句」；司空图「不着一字，尽得风流」；严羽「羚羊挂角」。
- 李东阳：比兴托物寓情，胜于正言直述之易穷。
- 汉儒把《关雎》说成「后妃之德」等，作者斥为政治谜语，但认为这种附会不自觉地反映了诗从巫史宗教文献（诗言志≈载道、记事）变为抒情文学的历史。
- 散文：孟文浩荡排比、庄文奇诡想象、荀谨严、韩峻峭；《孟子》「率兽食人」、《庄子》鲲鹏——说理而成为文学，因情感、理解、想象按不同比例结合。

**推导**

任何情感抒发都未必是艺术。主观情感须与特定想象、理解结合而客观化。「比兴」使外物染色彩、情感成形象，故非模拟、非任意发泄、非概念认识。「啊，我多么悲哀」只是概念。赋在国风中是记事状物的白描；先秦散文可视为「赋」原则从混沌复合体中分化为说理，其中一部分因气势、飘逸（情感性）而成为审美对象——民族特征是情感性有时比形象性更使文字成为艺术。

**结论**

赋比兴应从作品形象的美学特征去阐明，不要像经师那样细分死抠。

## 三、建筑艺术

### 论证推理链

**论据**

- 半坡已见方/长方形土木建筑，木构而非石构成为中国特色（原因作者称似无解答）。
- 《诗经》「如翚斯飞」「作庙翼翼」：舒展如翼、四宇飞张。
- 春秋战国建筑热：《左传》《国语》美室、美台；吴王姑苏台；齐襄公筑台。秦写放六国宫室、阿房「上可以坐万人」、始皇陵兵马俑场面可与金字塔比，但是平面展开的群体，不是向上堆起的尖顶。
- 「百代皆沿秦制度」，秦汉唐宋明清建筑美学风格相当一致。
- 长城无严格对称，但每段体制雷同，空间连续展示时间绵延。
- 飞檐使沉重屋顶呈向上挺举；塔中国化后呈整数式节奏（大雁塔层次疏朗 vs 小雁塔较近异域；吴哥寺为繁复堆积对照）。
- 元、明城门：元较薄而斜，略近伊斯兰；明厚实直立更雄浑。
- 晚期园林打破宫殿严格对称，借景、虚实，与山水画兴起相关，仍不离平面理性：「以玩赏的自由园林（道）来补足居住的整齐屋宇（儒）」。

**推导**

他民族代表建筑多为神庙；中国代表是宫殿，祭神也在与生活相连的「大房子」中。儒学替代宗教后，更贯彻神人同在：指向人间联想而非神秘上苍；内部空间平易而非令人恐惧的空旷；材料是暖和的木而非阴冷的石。空间意识转化为时间进程——慢慢游历，而非被扔进巨大幽闭空间。这与山水「可游可居」一致（见第九章）。

**结论**

建筑中的实践理性：实用、入世、理智、历史因素占优势，排斥反理性迷狂。浪漫风味的园林也未越出古典理性范围。

除了本章主要内容外，作者还讨论了/提及了：1. 孔学作为中国文化代名词的世界史事实，2. 「口之于味有同嗜」等孟子论共同美感，3. 扬雄评虞夏商周之书的浑灏，4. 朱自清《诗言志辨》、蒙文通论诗与记事，5. 《论语》「山节藻棁」「朽木不可雕」所反映的建筑装饰。
