# 第03章 先秦理性精神

## 本章位置

青铜「开放期」已进入理性主义。本章专论春秋战国：儒家把礼乐纳入实践理性，道家从审美与创作规律上补充儒家；《诗经》与诸子散文的赋比兴；木构宫殿建筑如何体现同一精神。

> 巫史文化的退场：[第02章_青铜饕餮.md](第02章_青铜饕餮.md)

## 核心论点

1. 先秦总思潮是理性主义：摆脱原始巫术，奠定汉民族的文化—心理结构。
2. **儒道互补**是两千多年中国思想的基本线索。孔子用实践理性重新解释礼乐；庄子抓住「言不尽意」、超功利审美，主要影响创作规律。
3. 中国诗以抒情胜，情感必须客观化；赋比兴是情与想象、理解结合的途径。「不道破一句」成为重要标准。
4. 中国建筑以宫殿（活人君主的世间居所）而非神庙为代表：平面铺开、时间性游历、线的飞檐，排斥宗教迷狂。园林以「道」补「儒」。

---

## 一、儒道互补

### 实践理性（先补概念）

作者所谓实践理性：把理性贯彻在日常伦常与政治中，不作抽象玄思。不是康德原义的照搬，而是用来概括孔学特征。

### 论证推理链

**论据**

- 孔子答宰我「三年之丧」：把丧制建立在「子生三年然后免于父母之怀」的亲子心理上（「于女安乎」）。
- 「礼云礼云，玉帛云乎哉；乐云乐云，钟鼓云乎哉。」乐须：诉诸普遍感官愉快；联系伦理感情与政治。
- 荀子《乐论》、《乐记》：乐者乐也；治世、乱世、亡国之音与政通；「乐统同，礼辨异」。
- 郭沫若：古代「乐」可含诗、舞、绘画、建筑、仪仗、田猎、肴馔，以音乐为代表。
- 孔子「敬鬼神而远之」「知其不可而为之」→ 荀子「制天命而用之」、《易传》「天行健」；另一面演化为庄子泛神论。
- 「匹夫不可夺志」→ 孟子浩然人格；另一面 → 庄子遗世独立。
- 荀子「性无伪则不能自美」vs 庄子「天地有大美而不言」。
- 《庄子·秋水》《天道》：可以言论者粗，意之所随不可言传。

**推导**

孔子把宗教三要素（观念、情绪、仪式，普列汉诺夫定义）消溶在亲子血缘的世间关系中，情感不导向神学偶像。于是中国艺术重情理结合、以理节情，而非禁欲、认知愉快或柏拉图式迷狂、亚里士多德式净化。这与《乐论》vs 亚里士多德《诗学》（情感塑造 vs 认识模拟/净化）的差异一致。

中国美学范畴多是功能性的（阴阳、和同、气势、韵味）：重对立渗透而非冲突，重生命意兴而非模拟可信，重阳刚阴柔而非宿命崇高——均可追溯到先秦理性的「中和」。

儒道表面入世/出世对立，实则互补：兼济与独善、身在江湖心存魏阙成为士人常规。儒家狭隘功利常束缚艺术；道家以浪漫想象、个性、自然生命冲击之。儒家影响主题内容，道家影响审美与创作规律；而艺术作为意识形态，重要性恰恰在审美规律。

**结论**

塑造中国人世界观、艺术理想的，是儒道相反相成，不是单一孔学。

## 二、赋比兴原则

### 论证推理链

**论据**

- 真正文学作品首推《诗经》国风与诸子散文。举《柏舟》《黍离》《风雨》《蒹葭》《采薇》等：短小而深沉的抒情，异于他民族长篇叙事史诗。
- 朱熹：赋者敷陈直言；比者以彼比此；兴者先言他物引起所咏。
- 《文心雕龙》：比附、兴起。钟嵘：言有尽而意无穷，兴也；因物喻志，比也。
- 王夫之：「不道破一句」；司空图「不着一字，尽得风流」；严羽「羚羊挂角」。
- 李东阳：比兴托物寓情，胜于正言直述之易穷。
- 汉儒把《关雎》说成「后妃之德」等，作者斥为政治谜语，但认为这种附会不自觉地反映了诗从巫史宗教文献（诗言志≈载道、记事）变为抒情文学的历史。
- 散文：孟文浩荡排比、庄文奇诡想象、荀谨严、韩峻峭；《孟子》「率兽食人」、《庄子》鲲鹏——说理而成为文学，因情感、理解、想象按不同比例结合。

**推导**

任何情感抒发都未必是艺术。主观情感须与特定想象、理解结合而客观化。「比兴」使外物染色彩、情感成形象，故非模拟、非任意发泄、非概念认识。「啊，我多么悲哀」只是概念。赋在国风中是记事状物的白描；先秦散文可视为「赋」原则从混沌复合体中分化为说理，其中一部分因气势、飘逸（情感性）而成为审美对象——民族特征是情感性有时比形象性更使文字成为艺术。

**结论**

赋比兴应从作品形象的美学特征去阐明，不要像经师那样细分死抠。

## 三、建筑艺术

### 论证推理链

**论据**

- 半坡已见方/长方形土木建筑，木构而非石构成为中国特色（原因作者称似无解答）。
- 《诗经》「如翚斯飞」「作庙翼翼」：舒展如翼、四宇飞张。
- 春秋战国建筑热：《左传》《国语》美室、美台；吴王姑苏台；齐襄公筑台。秦写放六国宫室、阿房「上可以坐万人」、始皇陵兵马俑场面可与金字塔比，但是平面展开的群体，不是向上堆起的尖顶。
- 「百代皆沿秦制度」，秦汉唐宋明清建筑美学风格相当一致。
- 长城无严格对称，但每段体制雷同，空间连续展示时间绵延。
- 飞檐使沉重屋顶呈向上挺举；塔中国化后呈整数式节奏（大雁塔层次疏朗 vs 小雁塔较近异域；吴哥寺为繁复堆积对照）。
- 元、明城门：元较薄而斜，略近伊斯兰；明厚实直立更雄浑。
- 晚期园林打破宫殿严格对称，借景、虚实，与山水画兴起相关，仍不离平面理性：「以玩赏的自由园林（道）来补足居住的整齐屋宇（儒）」。

**推导**

他民族代表建筑多为神庙；中国代表是宫殿，祭神也在与生活相连的「大房子」中。儒学替代宗教后，更贯彻神人同在：指向人间联想而非神秘上苍；内部空间平易而非令人恐惧的空旷；材料是暖和的木而非阴冷的石。空间意识转化为时间进程——慢慢游历，而非被扔进巨大幽闭空间。这与山水「可游可居」一致（见第九章）。

**结论**

建筑中的实践理性：实用、入世、理智、历史因素占优势，排斥反理性迷狂。浪漫风味的园林也未越出古典理性范围。

除了本章主要内容外，作者还讨论了/提及了：1. 孔学作为中国文化代名词的世界史事实，2. 「口之于味有同嗜」等孟子论共同美感，3. 扬雄评虞夏商周之书的浑灏，4. 朱自清《诗言志辨》、蒙文通论诗与记事，5. 《论语》「山节藻棁」「朽木不可雕」所反映的建筑装饰。

## 段落总结序列

### 儒道互补

- 春秋战国以氏族公社结构解体为背景，在思想文化领域形成摆脱巫术宗教、奠定民族文化心理的理性主义潮流。儒家代表这一潮流的正面发展，道家则构成其对立而互补的一面。
- 汉民族的文化心理与中华艺术的独特面貌，都应追溯到先秦孔学；孔子对民族性格的塑造是不可否认的历史事实，孔学成为中国文化的世界性象征并非偶然。
- 孔子以理性主义重新解释古代礼乐，把原始文化纳入日常生活、伦常感情和政治观念中的实践理性，而不走抽象玄思的道路；孟子、荀子继而完成了这条儒学路线。
- 儒学实践理性的基本特征，是怀疑或无神的世界观与积极进取的人生观相结合，并以心理和伦理的统一为核心。宰我质疑三年之丧的对话，引出孔子以人的真实感受而非外在教条解释礼制。
- 孔子让宰我以是否心安来判断能否废除丧礼，又以子女前三年受父母怀抱之爱说明三年之丧的情感依据。这段引文为礼制根植于亲子之爱的论证提供直接文本。
- 三年之丧被解释为亲子之爱的自然延伸，使外在强制规范转化为内在情感需求，也使礼乐由事神转为服务于人。由此形成中国艺术重情理平衡、伦理性满足而非禁欲、纯认识快感或神秘迷狂的审美特征，并显示出《乐论》与《诗学》的中西差异。
- 儒家也以实践理性重新解释“乐”，强调艺术既应诉诸具有普遍性的感官愉悦，又须联系社会伦理情感和现实政治。孔孟引文展示了这种转化，至荀子学派和《乐记》而成为系统的中国早期美学。
- 《荀子·乐论》和《乐记》的引文把乐视为人情必需，并要求以合宜的形式感发善心；声音发自内心，又随治乱兴亡而变化。这为艺术兼具情感塑造和政治关联的观点提供经典依据。
- “《乐记·乐本》”标明前段关于声音生于人心、音乐与政治相通之论的出处，使引文成为《乐记》美学思想的直接证据。
- 郭沫若指出古代“乐”广泛涵盖音乐、诗舞、造型艺术乃至仪仗田猎等感官享受，由此说明《乐记》实际总结的是以音乐为代表的整体艺术美学。它确认审美具有内在情感性，同时强调艺术能够陶冶民心、移风易俗并反映社会政治。
- 中国美学因重情感感受而不重认识模拟，遂多从功能、关系和韵律立论，强调对立面的协调、生命意兴的表达及情理结合。其“中和”原则以及阴柔、阳刚等审美形态，都可追溯到先秦理性精神。
- 理性精神也是名家、法家等先秦诸派的共同倾向；在美学和艺术上，庄子道家作为儒家的对立面与补充，与儒家共同塑造了中国人的人生观、文化心理和审美理想。
- 孔子的怀疑精神、进取态度和人格尊重，分别向荀子、《易传》、孟子和庄子等不同方向展开，使入世儒家与出世道家形成互补。儒家重人工制作和社会功用，道家重自然、审美独立与个性想象，后者冲破功利束缚并以珍爱生命的审美态度补充儒学。
- 《庄子》关于言不尽意的引文揭示形象大于思想、想象重于概念和创作须凝神等审美规律。儒家主要从社会功用和主题内容影响文艺，道家则建立人与对象的超功利审美关系，更多影响艺术创造规律。

### 赋比兴原则

- 文学以文字为材料并诉诸想象，成熟晚于感官性的造型艺术；甲骨文、金文等虽有审美片段，真正的文学应首推《诗经·国风》和先秦诸子散文。《柏舟》《黍离》《风雨》《蒹葭》《采薇》等引文集中展示了中国诗歌以短篇抒情为主的开端。
- 这些诗作的具体事由虽多已难考，却凭真挚情感、生动形象和反复回环的语言至今动人。它们不同于古代长篇叙事史诗，以短小深沉的实践理性抒情奠定了中国美学的民族特色。
- 后人从《诗经》归纳出影响两千余年的赋、比、兴原则，其中朱熹把赋释为直陈、比释为譬喻、兴释为先言他物以引出所咏。讨论重心落在比兴，因为它关涉情感如何转化为艺术这一根本问题。
- 中国文学虽以抒情见长，但情感不能任意宣泄，必须同特定的想象和理解结合而客观化，才能获得普遍感染力。“比”和“兴”正是完成这种结合的具体途径。
- 刘勰、钟嵘等人的界说表明，比兴都借外物景象寄托情志，使景物染上情感、情感化为融合理解与想象的客观形象。王夫之、司空图、严羽、李东阳等所推崇的“不道破”“不着一字”和“言有尽而意无穷”，都说明比兴创造了不可由概念穷尽的审美意味。
- 比兴的价值正在于综合情感、想象和理解，使“托物寓情”比直陈更有感染力；单说“我很悲哀”只是概念，情感须借景物客观化才能成为诗。后世“以景结情”和以乐景写哀等理论，正沿此逻辑发展。
- 比兴应作为艺术形象的美学原则理解，不宜被注释家机械细分或附会成政治谜语；但汉儒的附会也曲折反映了诗歌从巫史文化的宗教政治文献向个体抒情艺术过渡的历史。只有置于先秦理性主义兴起的背景中，才能看清《国风》从祭神、记事与礼制中解放出来的意义。
- “赋”主要是白描式的记事、状物、抒情和表意，先秦散文以此从远古复合体中分化为说理工具。孟、庄、荀、韩及《左传》之所以成为文学典范，关键常不在形象，而在文字中传达的浩荡、奇诡、谨严、峻峭等情感风貌，显示散文同样需要情感、理解与想象的交融。
- 《孟子》以“率兽食人”的层层问答谴责暴政，《庄子》则以鲲鹏巨大的奇想开启逍遥境界；两段引文分别为说理散文的排比气势和夸张想象提供范例。
- 孟文以整齐排比增强逻辑推理的情感力量，形成不可阻挡的浩荡气势；庄文以奇诡夸张的想象和散整相间的句法，使议论化入形象而呈现飘逸。二者都因情感、理解和想象的不同配合而成为文学，与中国诗歌的民族审美一脉相通。

### 建筑艺术

- 中国造型艺术中的线与音乐一样在时间过程中展开，并以受理性节制的情感表现民族审美。以抽象线条和体积为对象的建筑，也体现了这种情感中有理性的美。
- 中国自新石器时代即形成方形或长方形的土木建筑传统，木构而非石构成为长期特色；《诗经》所写的飞张屋宇表明木建筑很早已有审美功能。春秋战国新兴贵族又掀起追求华美的建筑热潮，使建筑由避风雨的实用物转为炫示与欣赏的艺术。
- 战国建筑热潮在秦统一后营建阿房宫时达到顶点；文献关于秦每灭一国便仿建其宫室的记载，显示秦代宫殿群规模极其宏大。
- 《史记》对阿房宫前殿、阁道和南山阙门的夸张尺度描写，具体证明秦代宫殿以巨大空间、绵延通道和群体联系营造宏伟气象。
- 中国木构建筑不以孤立单体为中心，而以平面铺展、彼此连接的群体布局取胜；秦始皇陵和兵马俑坑延续了这种宏大而复杂的整体结构。它可与金字塔媲美，却不同于后者独立向上堆起的尖顶形态。
- 后世建筑沿袭秦制，秦汉、唐宋至明清虽历时久远，基本保持先秦奠定的体制与一致的美学风格。
- 这一贯穿中国建筑史的核心风格，就是本章所说的实践理性精神。
- 中国主要建筑是供现实君主生活的宫殿宗庙，而非脱离世俗的神殿，因此以平面铺展、温暖木质和亲近日常的空间取代高耸、阴冷与神秘恐惧。建筑群把空间体验转化为人在楼台亭阁间逐步游历的时间过程，重在实用生活情调与环境和谐，排斥反理性的宗教迷狂。
- 建筑的严格对称表现严肃、方正和秩序，单体虽低矮平淡，群体却以错落配合和统一中的变化形成雄浑气势。长城虽整体不对称，却以重复段落绵延万里，把空间连续化为时间延续，并象征民族的持久活力。
- 木构屋顶、曲线飞檐、宽厚正身和阔大台基以线条形成向上飞动而又安定实用的节奏；传入中国的宝塔也被改造成层次分明的整数式节奏。大小雁塔及元明城门的比较进一步表明，疏朗比例、厚实直立和雄浑气象都沿着先秦理性精神发展。
- 宫殿既服务世间生活和游乐，自先秦起便容纳繁富的绘画、雕塑及斗拱、门窗、色彩等装饰。“金铺玉户”“雕梁画栋”等说法说明精细美术与实用建筑长期融为一体。
- 封建后期园林打破宫殿的严格对称，以曲折空间、借景和虚实手法把人工环境同自然山水联为有机整体，表达更自由的文人审美。其浪漫趣味仍未越出平面铺展和现实生活情调的理性框架，本质上是以道家的自由园林补充儒家的整齐屋宇。
