# 译后记

黄一心，2023 年春季写于中国江苏省无锡市。他说明自己按信、达、雅来译，并尽可能把文字写得简洁。不足之处欢迎指正。

## 核心论点

下一场传染病若到来，不总结这次的不足就会更惨烈。前事不忘，后事之师。总结既要从各地情况展开，也要从各学科展开。这本书四十五位人类学家和社会学家写的不是感染率和死亡率，而是疾病压在贫穷者和弱势群体肩上的重担。

## 论证

疫情始于 2019 年末，2020 年肆虐全球，影响健康、生活、经济以及文化、习俗。勒诺尔·曼德森与阿约·瓦尔贝格、南希·J·伯克共同编辑。书名译为《病毒载量：COVID-19 时代下的人类学研究》。

人类学是研究人类的科学。英国学术界通常分成生物人类学和社会人类学。美国学术界通常分成考古学、体质人类学、文化人类学和语言学。医学人类学是文化人类学的一个分支。研究人类本身重要，也不容易。1949 年后中国大陆高等学校取消人类学系及其课程，1980 年代拨乱反正后恢复课程和研究，正在逐步发展。译本或许能为推广人类学、特别是医学人类学做一点贡献。

阅读不需要医学、人类学或其他学科的专业知识，识字并且有兴趣就可以。书也能帮助了解各地民族历史、风俗习惯和社会组织。译者举了三例：印度的裹尸布窃贼写出高峰时期葬礼中的挣扎；罗马尼亚罗姆人的历史、现状，以及他们行之有效的非正式捐款（贿赂）和其他办事方法，寓意深长也有趣味；2020 年 4 月土耳其宗教事务局发表「伊斯兰教对疾病爆发的看法」，主旨是疫情不单纯由病毒引起，而是由人类自身道德沦丧造成，病毒应被视为真主阿拉的一个教训，科学和技术不应被视为克服困难的帮手，而是造成这种困难的原因。总统埃尔多安发表类似讲话，称将通过耐心和祈祷克服这种流行病。其他许多章也是有见解的调查研究。

感谢曼德森、共同编辑和其他作者，以及伦敦大学学院出版社同意译成中文。多位友人读了初稿。夫人蔡葆芬承担家务并给予支持，否则难以完成。单位主管、同事和出版社编辑提供了支援和劳动。

除了本章主要内容外，作者还讨论了/提及了：1. 1949 年后人类学系在中国大陆高校被取消、1980 年代恢复；2. 译者夫人的家务劳动被写成完成本书的条件。

## 段落总结序列

主旨两条：一，译这本书是为了在下一场疫之前记下各地和各学科已经显出的不足；二，医学人类学写的是压在弱者肩上的重担，不要求读者先有专业训练。

最小标签集：陈述、必要依据、可替换例证、过渡/场景。

1. 【第一档·陈述】不总结 2020 年的不足，下一次传染病可能更惨烈。总结要同时看各地情况和各学科。
2. 【第一档·必要依据】四十五位作者由曼德森、瓦尔贝格和伯克编辑。内容不是感染率和死亡率，而是贫穷者和弱势群体肩上的重担。
   (本段是第1段的必要依据)
3. 【第二档·可替换例证】英国人类学分生物与社会两支，美国分考古、体质、文化和语言学四支，医学人类学属文化人类学。1949 年后中国大陆高校取消该系，1980 年代恢复。识字有兴趣即可读。裹尸布窃贼、罗姆人的非正式捐款、土耳其宗教事务局把疫情说成道德沦丧和阿拉的教训，是译者点出的三则可读之处。
   (本段旁证第2段)
4. 【第三档·过渡/场景】信达雅与致谢：友人、蔡葆芬、单位和出版社。署名为 2023 年春，江苏无锡。
