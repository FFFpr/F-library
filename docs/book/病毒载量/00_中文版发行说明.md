# 中文版发行说明

生命中不可承受之重：《病毒载量》中文版发行说明。作者为国立台湾大学出版中心主任张俊哲。

## 核心论点

中文版把这本书引进华语世界，是因为新冠的隐性社会后果和下一波传染病的政经应对，在公开的防疫资讯里着墨不够。开放获取是原书的发行方式，中文版沿用同一方式。

## 论证

**论据。** 新冠蔓延冲击健康，也冲击经济、文化和社会，幅度超出预期。互联网上各国防疫资讯不难取得，但政经层面如何面对隐性影响和可能再来的传染病，讨论不多。英文原著得到世界卫生组织支持，由勒诺尔·曼德森等人类学者合著，在疫情仍严峻的 2021 年由伦敦大学学院出版社出版。

**推导。** 不同政经制度和文化里，人承受病毒的社会耐受力以及劫后处境差距很大。台大出版中心因此发行繁体中文译本，既让本书在华语世界发声，也承担大学社会责任（University Social Responsibility）。英文原著一开始就是开放获取，中文版同样免费下载，并限量印纸本。部分图片因版权与英文版不同。

**结论。** 译本要同时展示新冠与人类社会学的跨领域结果，并为下一波疫情研究铺路。

**延伸。** 张上淳在疫情期间担任中央流行疫情指挥中心专家咨询小组召集人，他的推荐序被发行说明称为「台湾之章」：用医学专业和防疫视野说明本书要旨，并留下台湾政府举措和全民防疫的记录。

疫情趋缓之后，病毒载量不再被说成「生命中不可承受之重」。发行说明把诚实面对防疫成效、带着谦卑检讨，写成比载量数字更重的事。曼德森等人留下的纪录和反省，被期待长期影响防疫策略。

除了本章主要内容外，作者还讨论了/提及了：1. 感谢译者与出版中心同仁；2. 纸本是为习惯纸书的读者限量印刷。

主旨有两条，与发行说明标题下的主张一致：一，中文版要补上新冠在政经与社会耐受力上的讨论；二，开放获取和大学社会责任是发行方式本身。
